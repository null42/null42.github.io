# 理论一章节复盘溯源表

本复盘以《深度基础强化第二部分》课件第 1–72 页及已验收伴随讲义为主，按概念和设计链重构，不按页码复述。

| 复盘模块 | 主要课件页 | 重构目的 |
|---|---:|---|
| 任务、角色与控制定义 | 1–4 | 把控制器放回参考、对象、测量、扰动和约束的完整问题中 |
| 四旋翼物理与控制分配 | 5–12 | 从旋翼平方转速建立总推力和三轴力矩，再解释 PD 的物理作用 |
| 框图、闭环与节点方程 | 13–19、35–44、70–72 | 由求和点和分支点写方程，扩展到 L、S、T 与内部稳定 |
| LTI、冲激响应与卷积 | 20–30 | 重建“冲激分解—时移—缩放—叠加—卷积”的完整证明 |
| 拉普拉斯与传递函数 | 31–46、54–61 | 强调零初值、卷积乘法、通道定义和分段信号构造 |
| 极点、模态与稳定性 | 47–53、62–69 | 用部分分式连接极点、残值、时间尺度、重复极点与稳定性 |
| 综合 PD 设计 | 8–12、38–40、47–53 | 将课件偏航模型提升为“指标—极点—参数—扰动—控制量”的完整设计例 |
| 数字控制迁移 | 第 1 页课程路线及全章控制连接 | 明确本章连续模型只是采样、延迟、保持和代码部署的基准 |
| 易错点与 A–D 测试 | 全章 | 将课件计算题提升为可迁移的推导、验算和独立设计能力 |

## 补充边界

- `L/S/T/KS/GS`、约束控制分配、SIL/PIL/HIL 是为建立后续控制设计接口所作的必要补充，不替代课件主线。
- 章节综合例沿用课件四旋翼偏航与 PD 语境，数值为讲义自设，用于演示参数匹配与工程验收。
- 数字控制迁移检查表只给设计接口；采样、离散化与代码实现将在第三部分系统展开。
