# 第二章第 115–135 页来源地图

| 课件页 | 课件主线 | 讲义展开 |
|---:|---|---|
| 115–117 | 离散/连续无记忆 LTI，恒等系统 | 严格推导 `h=Kδ`，辨析有限记忆与无记忆 |
| 118–119 | 可逆系统及纯延迟逆系统 | 给出 `h*h_inv=δ`，区分数学可逆与因果实时实现 |
| 120–123 | 离散/连续因果条件与卷积上下限 | 从未来输入项推出负时间冲激响应为零；统一支集交集法 |
| 124–126 | 阶段总结、无记忆/可逆/因果速查 | 组织为由 h 判断系统性质的结构化方法 |
| 127–128 | 稳定充分条件 | 用三角不等式推导绝对可和/可积条件 |
| 129–131 | 稳定必要性 | 构造相位匹配的有界输入，使输出等于 `Σ|h|` 或 `∫|h|` |
| 132 | 理想微分器稳定性练习 | 明确纠正以 `∫δ′=0` 替代绝对可积的错误；理想微分器不是 BIBO 稳定 |
| 133–135 | 单位阶跃响应及与冲激响应关系 | 离散累计/差分、连续积分/微分，并连接实验辨识与控制指标 |

## 来源边界与校正

- 定义、证明路线、纯延迟例题和阶跃响应关系来自课件第 115–135 页。
- 第132页课件的稳定性结论不满足其前面给出的绝对可积条件。本讲义保留题目来源，但依据 BIBO 定义给出高频正弦反例并明确校正。
- 最小相位、噪声稳健辨识和控制延迟属于必要拔高。
