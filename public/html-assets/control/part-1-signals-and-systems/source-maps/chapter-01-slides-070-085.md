# 第一章第 70–85 页来源地图

对应课件：`信号与系统（深度强化版）.pptx`。

| 课件页 | 课件主线 | 讲义中的必要展开 |
|---:|---|---|
| 70 | 连续/离散时间系统定义、简单系统示例 | 明确输入集合、输出、时间变量和初始条件 |
| 71 | 串联、并联互联 | 用算子复合与算子相加写出统一表达式 |
| 72 | 负反馈互联及 `A/(1+AF)` | 从内部信号方程推导闭环关系，提示算子次序与稳定性 |
| 73 | 无记忆与记忆系统、累加器/延迟/积分器例子 | 给出“固定当前时刻、检查输入访问时刻”的判定法 |
| 74 | 可逆系统、逆系统及累加器逆运算 | 补充一一性、定义域限制与反例策略 |
| 75–76 | 因果定义与例题；稳定性引入 | 统一使用观察时刻与未来输入判据，区分时变系数和未来依赖 |
| 77 | BIBO 稳定定义及 `tx(t)`、`e^{x(t)}` 例题 | 区分“全称证明”和“单个反例”两种证明方向 |
| 78–79 | 时不变定义、`sin[x(t)]` 与冲激反例 | 展开“先系统后移位/先移位后系统”双路径检验 |
| 80–84 | 线性定义；`tx(t)`、取实部、`2x+3` 例题 | 补充标量域、`T{0}=0` 必要条件、仿射与增量线性化 |
| 85 | 第一章小结 | 重构为进入 LTI、卷积和控制理论前的能力门槛 |

## 来源边界

- 六类性质的定义、例题和讲授顺序严格跟随课件第 70–85 页。
- 量词写法、证明模板、控制连接、工作点增量模型和实时可实现性属于讲义扩展，用于帮助迁移到后续控制课程。
- 练习题与答案为讲义原创；所有否定结论均要求给出严格反例。
