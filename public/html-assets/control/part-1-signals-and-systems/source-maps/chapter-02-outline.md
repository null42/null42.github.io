# 第二章“线性时不变系统”课件来源总图

对应课件：`信号与系统（深度强化版）.pptx` 第 86–151 页，共 66 页。

## 章节主线

本章利用 LTI 的线性与时不变性，把任意输入分解为移位冲激的加权和/积分，从单位冲激响应唯一确定系统输出；随后用卷积代数研究互联结构，并把无记忆、可逆、因果、稳定与阶跃响应全部改写为对冲激响应的条件；最后连接差分/微分方程、框图实现和广义函数。

| 内部知识链 | 课件页码 | 课件内容 |
|---|---:|---|
| 1. 离散冲激分解与卷积和 | 86–97 | 章节导入；LTI 定义；离散信号冲激分解；卷积和推导；右/左边指数序列例题 |
| 2. 连续冲激近似与卷积积分 | 98–103 | 矩形脉冲逼近；连续信号冲激积分表示；卷积积分推导；`e^{-at}u(t)*u(t)` 例题 |
| 3. 卷积性质与系统互联 | 104–114 | 交换、分配、结合；并联与级联；微分、积分、移位；与冲激/阶跃卷积 |
| 4. 用冲激响应判断 LTI 性质 | 115–135 | 无记忆、可逆、因果、稳定；绝对可和/可积充要条件；单位阶跃响应 |
| 5. 差分/微分方程与框图 | 136–141 | 初始松弛；一阶差分方程的冲激响应；IIR；延迟/加法/增益框图；积分器实现连续系统 |
| 6. 广义函数与奇异函数层级 | 142–151 | 冲激的广义函数解释；理想窄脉冲；冲激偶与高阶导数；重复积分、阶跃与斜坡；章节小结 |

## 讲义扩展边界

- 课件页序、公式、图解方法与例题是讲义的主骨架。
- 允许补充：卷积支集交集法、变量角色辨析、证明中的量词、数值实现风险、控制器中的延迟/积分器/微分器连接。
- 不允许把本章改写成脱离课件页序的抽象模板；每个扩展必须服务于理解课件推导或迁移到后续控制设计。
