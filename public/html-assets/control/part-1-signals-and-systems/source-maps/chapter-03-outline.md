# 第三章“周期信号的傅里叶级数表示”课件来源总图

对应课件：`信号与系统（深度强化版）.pptx` 第 152–248 页，共 97 页。

## 章节主线

本章把第二章建立的 LTI 卷积语言转向频域：复指数通过 LTI 系统时只改变复幅值，因此它是系统的特征函数；周期信号可由谐波复指数叠加，傅里叶级数系数就是各谐波权重。连续和离散傅里叶级数建立后，课件进一步讨论收敛、性质、Parseval 关系，并把每个谐波乘以系统频率响应，最终进入滤波器分析。

| 内部知识链 | 课件页码 | 课件内容 |
|---|---:|---|
| 1. 频域视角、特征函数与 CTFS 基础 | 152–168 | 章节导入；复指数是连续/离散 LTI 特征函数；周期复指数基；CTFS 三种形式；正交性；分析/综合公式；周期矩形脉冲谱 |
| 2. CTFS 收敛与性质 | 169–185 | 均方逼近；收敛条件；Dirichlet 条件；线性、时移、反转、尺度、相乘；共轭对称；Parseval |
| 3. CTFS 综合例题 | 186–197 | 矩形波复算；时移；三角波微分法；周期冲激串；由系数约束恢复信号 |
| 4. DTFS 基础、系数与收敛 | 198–215 | N 个不同谐波基；合成/分析公式；系数周期；正弦与周期矩形序列例题；有限项精确重构 |
| 5. DTFS 性质与例题 | 216–222 | 周期卷积、差分、Parseval；由性质和系数约束重构序列 |
| 6. 傅里叶级数通过 LTI 系统 | 223–233 | H(s)、H(z) 与频率响应；谐波逐项加权；连续/离散输出例题 |
| 7. 滤波应用与小结 | 234–248 | 频率选择滤波；RC 低通/高通；一阶递归数字滤波器；移动平均低通；一阶差分高通；章节总结 |

## 讲义扩展边界

- 课件页序、公式、谱图、例题和教师强调是讲义主骨架。
- 允许补充：正交投影观点、复系数的幅相解释、谱线与包络、收敛边界、数字控制中的谐波响应与采样实现。
- 不允许提前把本章改写成完整傅里叶变换或拉普拉斯/z 变换课程；相关内容只作为明确的后续接口。
