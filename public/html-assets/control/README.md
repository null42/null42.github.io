# 控制理论课程正式讲义

本目录承载严格依据指定课件制作的正式学习材料。固定学习顺序为：

1. 信号与系统深度强化；
2. 控制理论深度强化；
3. 数字控制器实战；
4. 基础验收后再进入系统辨识、最优控制、数据驱动控制和模型预测控制。

## 目录职责

- `part-1-signals-and-systems/companion/`：学习者入口；按真实章节组织，一章一个连续主文档，内部仍保持 PPT 页序。
- `part-1-signals-and-systems/fragments/`：内部制作与验收片段，不作为正式学习入口。
- `part-1-signals-and-systems/review/`：章节全部伴随讲义通过用户验收后才生成的复盘资料。
- `part-1-signals-and-systems/exercises/`：与讲义分离的完整答案。
- `part-1-signals-and-systems/figures/`：经复核的本地 SVG 图形。
- `part-1-signals-and-systems/source-maps/`：逐页课件内容、页面演进和补充边界记录。
- `part-2-control-theory/`：第二部分控制理论材料，遵循同样的伴随讲义—验收—复盘流程。
- `advanced-previews/`：现有快速专题的索引，不计入正式学习进度。

第一份样章覆盖《信号与系统（深度强化版）》第 1–18 页并已通过用户验收。自 2026-07-30 起，样章与后续页段只作为内部片段，统一聚合进章节主文档；首页不再按十几页列出学习单元。

持续有效的规范见 `../docs/superpowers/specs/2026-07-28-control-course-companion-notes-design.md`。
