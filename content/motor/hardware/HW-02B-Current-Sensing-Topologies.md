# HW-02B 电流采样拓扑：低侧·高侧·在线的选型决策

**副标题：从电阻位置到相数配置，理解采样拓扑如何决定FOC性能边界**

---

## 1.  核心摘要  

**一句话讲清楚**：电流采样拓扑的选择——电阻放在哪里（低侧/高侧/在线）、放几个（单/双/三电阻）——直接决定了FOC系统的成本、精度、时序约束和适用转速范围，是硬件设计中最不可逆的架构决策。

**认知挂钩**：很多人以为电流采样拓扑就是"选几个电阻放哪"的问题，**这是严重误区！** 实际上，采样拓扑是FOC系统的"地基"——低侧采样限定了你只能在下管导通窗口采样，单电阻采样限定了你必须用SVPWM移相重构电流，高侧/在线采样虽然时序自由但共模电压挑战陡增。拓扑一旦选定，PCB画完，后续算法能做什么、不能做什么就基本锁死了。**换拓扑 = 换板子**，成本极高。

**与HW-02的关联**：
-  HW-02 讲的是信号链（电阻→放大→滤波→ADC），本模块讲的是拓扑架构（电阻放哪、放几个）
-  HW-02 的误差分析适用于所有拓扑，但不同拓扑的误差源权重不同
-  本模块是 HW-02 的架构级延伸，建议先掌握 HW-02 再阅读本文

## 2.  问题引入  

### 工程师的真实困惑

**场景1：低成本方案选型纠结**
```plain
工程师A:"老板要求BOM成本再降2块钱，让我把双电阻改成单电阻..."
问题现象:
- 单电阻方案软件复杂度暴增
- 低速启动性能差，客户投诉
- PWM移相导致电流纹波增大
- 最后还是改回双电阻，白折腾一个月
```

**场景2：高压平台采样失真**
```plain
工程师B:"48V平台用低侧采样好好的，换成310V高压平台后电流波形全乱了..."
问题现象:
- 低侧采样放大器被共模瞬态干扰
- 死区振铃耦合到采样信号
- 高速时下管导通时间极短，采样窗口不够
```

**场景3：伺服精度不达标**
```plain
工程师C:"双电阻低侧采样，Id始终有0.3A波动，伺服定位精度差..."
问题现象:
- 扇区切换时采样值跳变
- 过调制区域电流重建失真
- 换成三电阻后问题消失，但成本超标
```

### 核心问题

这些问题的根本原因是什么？

**答案**：采样拓扑与实际应用需求不匹配！

- 单电阻低速不行 → 拓扑固有的采样窗口不足
- 高压低侧失真 → 共模瞬态超出了放大器承受范围
- 双电阻扇区跳变 → 低侧采样的时序约束在过调制区无法满足

### 学习目标

读完本模块，你将能够：

 **理解二维分类矩阵** - 电阻位置 × 相数，9种拓扑的适用边界
 **掌握低侧采样** - 单/双/三电阻的原理、盲区、时序约束
 **理解高侧与在线采样** - 共模电压挑战与放大器选型
 **计算放大倍数** - 从满量程电流到ADC满量程的完整设计链
 **建立拓扑-算法关联** - 拓扑选择如何约束算法行为

## 3.  采样拓扑分类总览  

### 3.1 二维分类矩阵

电流采样拓扑由两个独立维度决定：

| 维度 | 选项 | 决策变量 |
|------|------|---------|
| **电阻位置** | 低侧 / 高侧 / 在线（相电流） | 共模电压、采样时序自由度 |
| **相数配置** | 单电阻 / 双电阻 / 三电阻 | BOM成本、电流重建方式、冗余度 |

二维组合共 9 种拓扑，但实际工程中有意义的组合如下：

```plain
                    单电阻          双电阻          三电阻
                ┌──────────────┬──────────────┬──────────────┐
  低侧采样      │  最常用(家电) │  最常用(工业) │  高性能伺服   │
  (下管源极→GND)│  成本最低      │  性价比最优    │  冗余校验     │
                ├──────────────┼──────────────┼──────────────┤
  高侧采样      │  极少使用      │  高压平台      │  高压伺服     │
  (母线+→上管漏极)│  无优势       │  任意时刻采样  │  全时域采样   │
                ├──────────────┼──────────────┼──────────────┤
  在线采样      │  不可能        │  高性能驱动    │  顶级伺服     │
  (相线串联)    │  (需至少两相)  │  连续相电流    │  真实三相电流 │
                └──────────────┴──────────────┴──────────────┘
```

### 3.2 拓扑对比总表

| 拓扑 | 电阻数 | ADC通道 | 放大器要求 | 采样时序约束 | 电流重建方式 | 典型BOM成本 | 适用场景 |
|------|--------|---------|-----------|-------------|-------------|------------|---------|
| 低侧单电阻 | 1 | 1 | 通用运放 | 极严 | SVPWM移相重构 | ¥2~5 | 家电风机 |
| 低侧双电阻 | 2 | 2 | 通用运放 | 中等 | $i_c = -(i_a + i_b)$ | ¥5~10 | 工业通用 |
| 低侧三电阻 | 3 | 3 | 通用运放 | 宽松 | 直接测量+冗余 | ¥8~15 | 高性能伺服 |
| 高侧单电阻 | 1 | 1 | 高CMRR运放 | 极严 | SVPWM移相重构 | ¥5~8 | 极少使用 |
| 高侧双电阻 | 2 | 2 | 高CMRR运放 | 无 | $i_c = -(i_a + i_b)$ | ¥10~20 | 高压工业 |
| 高侧三电阻 | 3 | 3 | 高CMRR运放 | 无 | 直接测量+冗余 | ¥15~30 | 高压伺服 |
| 在线双电阻 | 2 | 2 | 高CMRR运放 | 无 | $i_c = -(i_a + i_b)$ | ¥15~25 | 高性能驱动 |
| 在线三电阻 | 3 | 3 | 高CMRR运放 | 无 | 直接测量+冗余 | ¥20~40 | 顶级伺服 |

> **成本说明**：BOM成本仅含采样电阻+运放+外围阻容，不含PCB面积和研发成本。高侧/在线方案的隔离放大器或高CMRR运放是成本主要来源。

## 4.  低侧采样详解  

### 4.1 拓扑结构

采样电阻位于下管（低边MOSFET）源极与地（GND）之间：

```plain
        Vdc+
         │
    ┌────┤ Q1(上管)
    │    └────┬──────── A相输出 → 电机
    │         │
    │    ┌────┤ Q2(下管)
    │    │    └────┬───┐
    │    │         │   │
    │    │        Rs  │ ← 采样电阻
    │    │         │   │
    │    │        GND  Vout → 运放 → ADC
    │    │
   (B、C相结构相同)
```

**共模电压**：$V_{cm} \approx 0\text{V}$（下管导通时），这是低侧采样最大的优势。

### 4.2 优缺点

**优点**：
- 共模电压接近0V，对运放CMRR要求低，通用运放即可
- 电路简单，BOM成本低
- PCB布局容易，采样电阻接地端参考干净
- 是工业界最广泛使用的拓扑

**缺点**：
- **只能在下管导通期间采样**——这是最核心的时序约束
- 高占空比时下管导通时间短，采样窗口不足
- 过调制区域（占空比>95%）可能无法采样
- 采样时刻与PWM开关状态耦合，需精确同步

### 4.3 单电阻采样 

#### 原理

在直流母线负极串联一个采样电阻，利用SVPWM不同开关状态下母线电流等于不同相电流的对应关系，通过两次采样重建三相电流。

```plain
母线电流与开关状态的对应关系：

  有效矢量    导通相    母线电流
  ─────────  ────────  ──────────
  V1(100)    A相       +i_a
  V2(110)    A+B相     -i_c
  V3(010)    B相       +i_b
  V4(011)    B+C相     -i_a
  V5(001)    C相       +i_c
  V6(101)    A+C相     -i_b

  零矢量 V0(000)/V7(111)：母线电流 = 0
```

**重建流程**：
1. 在一个PWM周期内，利用两个不同的有效矢量各采样一次
2. 根据扇区确定两次采样分别对应哪相电流
3. 由基尔霍夫电流定律 $i_a + i_b + i_c = 0$ 计算第三相

```plain
扇区1的采样示例：

  PWM周期: |──V1(100)──|──V2(110)──|──V0(000)──|
                ↑             ↑
             采样1:i_a     采样2:-i_c

  重建: i_b = -(i_a + i_c) = -(i_a - (-i_c)) = -i_a - i_c
```

#### 盲区分析 

单电阻采样的根本困难在于：**有效矢量持续时间必须大于采样建立时间**。

**最小采样窗口**：

$$T_{min} = t_{dead} + t_{settle} + t_{ADC}$$

其中：
- $t_{dead}$：死区时间，典型 0.5~2μs
- $t_{settle}$：电流建立时间，典型 1~2μs
- $t_{ADC}$：ADC采样保持时间，典型 0.5~1μs

典型值：$T_{min} \approx 2\sim5\mu s$

**盲区产生条件**：

当调制比过低或过高时，某些有效矢量的持续时间小于 $T_{min}$：

```plain
盲区1：低调制比（低速/低电压）
  ─────────────────────────────────
  有效矢量时间 ∝ 调制比 m
  当 m < m_min 时，有效矢量时间 < T_min → 无法采样

  m_min = T_min / T_pwm
  示例：T_min=3μs, T_pwm=50μs(20kHz) → m_min = 0.06

盲区2：过调制（高速/高电压）
  ─────────────────────────────────
  某些有效矢量时间被压缩
  当 m > m_max 时，短矢量时间 < T_min → 无法采样

  m_max ≈ 1 - T_min / T_pwm
  示例：m_max ≈ 1 - 0.06 = 0.94

盲区3：扇区切换
  ─────────────────────────────────
  在扇区边界，两个有效矢量的持续时间接近
  可能两个都小于 T_min → 双盲区
```

**盲区补偿策略**：

| 策略 | 原理 | 代价 | 适用场景 |
|------|------|------|---------|
| PWM移相 | 延长有效矢量持续时间 | 电流纹波增大 | 低调制比 |
| 电压注入 | 在零矢量中插入测量脉冲 | 转矩脉动 | 低调制比 |
| 前值保持 | 用上一周期采样值替代 | 精度下降 | 短时盲区 |
| 开环启动 | 低速时V/F控制，达到阈值后切FOC | 切换瞬态 | 启动阶段 |
| 观测器辅助 | 用反电动势观测器估算盲区电流 | 算法复杂 | 全速度范围 |

### 4.4 双电阻采样 

#### 原理

在两相下管源极各放一个采样电阻，直接测量两相电流，第三相由基尔霍夫电流定律计算：

$$i_c = -(i_a + i_b)$$

```plain
采样示意：

  A相: Rs_a ──→ 运放 ──→ ADC_CH1 → i_a
  B相: Rs_b ──→ 运放 ──→ ADC_CH2 → i_b
  C相: i_c = -(i_a + i_b)  (计算得出)
```

#### 时序约束

双电阻低侧采样仍需在下管导通期间采样，但约束比单电阻宽松得多：

- **只需两相的下管同时导通**即可采样
- 在SVPWM的6个扇区中，至少有两相下管导通的区域占绝大部分
- **唯一限制**：当某相占空比接近100%时，该相下管导通时间极短

```plain
扇区与下管导通的关系：

  扇区  上管导通  下管导通     可采样相
  ────  ────────  ──────────  ──────────
   1    A        B, C        i_b, i_c
   2    A, B     C           i_c (仅一相！)
   3    B        A, C        i_a, i_c
   4    B, C     A           i_a (仅一相！)
   5    C        A, B        i_a, i_b
   6    A, C     B           i_b (仅一相！)

  注意：扇区2/4/6中，仅有一相下管导通时间足够
  → 需要选择合适的采样相组合
```

**工程实践**：通常选择采样A、B两相。在扇区2/4/6中，需要确保被采样相的下管有足够的导通时间。当占空比>95%时，可能需要切换采样相或使用过采样。

#### 优势与局限

**优势**：
- 算法简单，无需SVPWM移相
- 采样时序约束远小于单电阻
- 低速性能好，启动平稳
- 是工业界最主流的方案

**局限**：
- 仍受下管导通时间约束
- 过调制区域（m > 0.95）采样困难
- 第三相电流由计算得出，无冗余校验
- 两相采样增益不匹配会导致 $i_c$ 计算误差

### 4.5 三电阻采样 

#### 原理

三相下管源极各放一个采样电阻，直接测量三相电流：

$$i_a + i_b + i_c = 0 \quad \text{(冗余校验)}$$

```plain
采样示意：

  A相: Rs_a ──→ 运放 ──→ ADC_CH1 → i_a
  B相: Rs_b ──→ 运放 ──→ ADC_CH2 → i_b
  C相: Rs_c ──→ 运放 ──→ ADC_CH3 → i_c
```

#### 核心优势：任意时刻可采样

三电阻采样的关键优势在于：**无论哪个扇区，至少有两相下管导通时间足够**，可以选择导通时间最长的两相进行采样。

```plain
三电阻的采样策略：

  1. 检测三相下管导通时间
  2. 选择导通时间最长的两相采样
  3. 第三相可由计算或直接测量获得
  4. 三相测量值满足 i_a + i_b + i_c ≈ 0 (校验)

  过调制时：
  - 即使某相占空比=99%，另外两相占空比低
  - 仍然可以在另外两相采样 → 无盲区
```

#### 冗余校验

三电阻采样提供了天然的冗余校验能力：

$$|i_a + i_b + i_c| < \epsilon_{threshold}$$

若不满足，说明采样异常，可触发保护或降级处理：

```plain
校验策略：
  正常: |i_a + i_b + i_c| < 0.05 × I_rated → 采样可信
  告警: 0.05 × I_rated < |sum| < 0.1 × I_rated → 增益可能偏移
  故障: |sum| > 0.1 × I_rated → 采样链路异常，触发保护
```

## 5.  高侧采样详解  

### 5.1 拓扑结构

采样电阻位于上管漏极与母线正极（Vdc+）之间：

```plain
        Vdc+
         │
        Rs ← 采样电阻
         │
         Vout → 隔离/差分运放 → ADC
         │
    ┌────┤ Q1(上管)
    │    └────┬──────── A相输出 → 电机
    │         │
    │    ┌────┤ Q2(下管)
    │    │    └──────── GND
    │    │
   (B、C相结构相同)
```

**共模电压**：$V_{cm} = V_{dc}$，即母线电压。这是高侧采样的核心挑战。

### 5.2 共模电压挑战

| 母线电压 | 共模电压Vcm | CMRR=80dB时误差 | CMRR=100dB时误差 | CMRR=120dB时误差 |
|----------|------------|----------------|-----------------|-----------------|
| 24V | 24V | 2.4mV | 0.24mV | 0.024mV |
| 48V | 48V | 4.8mV | 0.48mV | 0.048mV |
| 310V | 310V | 31mV | 3.1mV | 0.31mV |
| 400V | 400V | 40mV | 4.0mV | 0.40mV |

> **计算方法**：$V_{error} = V_{cm} / 10^{CMRR/20}$

以48V/10A系统为例（$R_s = 5m\Omega$, $G = 20$）：
- CMRR=80dB → 电流误差 = $4.8mV / (20 \times 5m\Omega) = 48mA$ → 0.48% of 10A
- CMRR=100dB → 电流误差 = 4.8mA → 0.048%

**结论**：48V以下系统，CMRR≥80dB可接受；310V高压系统，CMRR必须≥100dB。

### 5.3 优缺点

**优点**：
- **任意时刻可采样**——不受下管导通时间约束
- 采样时序与PWM占空比解耦
- 高速过调制区域无盲区
- 可检测对地短路故障

**缺点**：
- 共模电压=母线电压，需要高CMRR差分放大器
- 高压平台需要隔离放大器，BOM成本高
- PCB布局要求高，差分走线必须对称
- 开关瞬态的共模跳变（$dv/dt$可达10~50V/ns）可能穿透放大器

### 5.4 放大器选型

| 放大器 | CMRR | 带宽 | 失调电压 | 供电范围 | 适用母线电压 |
|--------|------|------|---------|---------|------------|
| INA240 (TI) | 120dB | 400kHz | 5μV | 2.7~5.5V | ≤48V |
| INA281 (TI) | 110dB | 200kHz | 70μV | 2.7~5.5V | ≤80V |
| AD8418 (ADI) | 106dB | 1MHz | 200μV | 2.7~5.5V | ≤48V |
| AMC1301 (TI) | 隔离 | 200kHz | 200μV | 5V | 任意(隔离) |
| ACPL-C799 (Broadcom) | 隔离 | 200kHz | 1.5mV | 5V | 任意(隔离) |

> **选型原则**：母线≤48V可用高CMRR运放；母线≥100V建议用隔离放大器。

## 6.  相电流采样（在线采样）详解  

### 6.1 拓扑结构

采样电阻直接串联在电机相线（逆变器输出与电机之间）：

```plain
        Vdc+
         │
    ┌────┤ Q1(上管)
    │    └────┬──────── Rs ← 采样电阻
    │         │         │
    │    ┌────┤ Q2(下管) Vout → 差分运放 → ADC
    │    │    └──────── GND
    │    │              │
    │    │              └────→ 电机A相
    │    │
   (B、C相结构相同)
```

**共模电压**：$V_{cm}$ 在 $0 \sim V_{dc}$ 之间摆动，取决于开关状态。

### 6.2 共模电压分析

在线采样的共模电压随PWM开关状态实时跳变：

```plain
共模电压随开关状态变化：

  上管导通: Vcm = Vdc (相线被拉到母线电压)
  下管导通: Vcm = 0V  (相线被拉到地)

  共模跳变幅度 = Vdc
  共模跳变速率 dv/dt = Vdc / t_rise

  示例(310V系统):
    Vdc = 310V, t_rise = 50ns
    dv/dt = 310V / 50ns = 6200 V/μs !!
```

**这是所有拓扑中共模条件最恶劣的**——不仅共模电压高，而且高速跳变。

### 6.3 优缺点

**优点**：
- **真正的相电流**——测量的是电机绕组中的实际电流，不是重构值
- 任意时刻可采样，与PWM时序完全解耦
- 电流连续，无扇区切换跳变
- 可检测相线对地/对电源短路
- 过调制和方波调制区域仍可精确采样

**缺点**：
- 共模电压在0~Vdc之间高速摆动，对放大器要求极高
- 需要高CMRR + 高带宽的差分放大器
- PCB布局最困难——差分走线必须严格对称，靠近采样电阻
- BOM成本最高
- 放大器必须承受连续的共模瞬态冲击

### 6.4 放大器选型

在线采样对放大器的要求是所有拓扑中最苛刻的：

| 要求 | 指标 | 原因 |
|------|------|------|
| CMRR | ≥100dB（DC），≥80dB（100kHz） | 共模电压=Vdc |
| 共模瞬态抗扰度 | ≥10V/ns | 开关瞬态dv/dt |
| 带宽 | ≥1MHz | 电流环带宽需求 |
| 建立时间 | ≤1μs（从共模跳变后） | 采样时序裕度 |
| 失调电压 | ≤50μV | 电流精度 |

**推荐器件**：
- INA240：增强型PWM抑制，CMRR=120dB，专为此场景设计
- AD8418：带宽1MHz，适合高速应用
- 隔离方案（AMC1301等）：高压平台首选

### 6.5 三种拓扑对比总结

```plain
                    低侧采样          高侧采样          在线采样
                ┌──────────────┬──────────────┬──────────────┐
  共模电压      │ ≈0V           │ =Vdc(固定)    │ 0~Vdc(跳变)  │
  采样时序      │ 下管导通时     │ 任意时刻      │ 任意时刻      │
  运放要求      │ 通用运放       │ 高CMRR运放    │ 高CMRR+高带宽 │
  PCB难度       │ 低            │ 中            │ 高            │
  BOM成本       │ 低            │ 中~高         │ 高            │
  电流真实性    │ 重构(单/双)    │ 重构(单/双)   │ 直接测量      │
  过调制能力    │ 差            │ 好            │ 优            │
  短路检测      │ 仅对地短路     │ 对地+对电源   │ 对地+对电源   │
  适用母线电压  │ 任意           │ ≤48V或隔离    │ ≤48V或隔离    │
                └──────────────┴──────────────┴──────────────┘
```

## 7.  放大倍数计算  

### 7.1 完整计算链

从满量程电流到ADC满量程的信号链：

$$I_{max} \xrightarrow{R_{shunt}} V_{sense} \xrightarrow{G_{amp}} V_{out} \xrightarrow{ADC} D_{digital}$$

**核心公式**：

$$R_{shunt} \times I_{max} \times G_{amp} = \frac{V_{ADC\_FS}}{2}$$

其中：
- $I_{max}$：最大测量电流（峰值电流，含过载余量）
- $R_{shunt}$：采样电阻阻值
- $G_{amp}$：放大器增益
- $V_{ADC\_FS}$：ADC满量程电压（通常=参考电压 $V_{ref}$）
- 除以2：双向电流测量，中点偏置在 $V_{ref}/2$

**推导**：

$$V_{sense} = I_{max} \times R_{shunt}$$

$$V_{out} = V_{sense} \times G_{amp} + \frac{V_{ref}}{2}$$

$$V_{out\_max} = \frac{V_{ref}}{2} + I_{max} \times R_{shunt} \times G_{amp} \leq V_{ref}$$

$$\Rightarrow I_{max} \times R_{shunt} \times G_{amp} \leq \frac{V_{ref}}{2}$$

### 7.2 设计约束

三个变量（$R_{shunt}$、$G_{amp}$、$I_{max}$）中，$I_{max}$ 由应用决定，需在 $R_{shunt}$ 和 $G_{amp}$ 之间权衡：

| 约束 | 方向 | 原因 |
|------|------|------|
| 功耗 | $R_{shunt}$↓ | $P = I^2 \times R_{shunt}$，功耗影响效率和温升 |
| 分辨率 | $R_{shunt}$↑ 或 $G_{amp}$↑ | 电流分辨率 $= V_{LSB} / (R_{shunt} \times G_{amp})$ |
| 噪声 | $G_{amp}$↓ | 放大器噪声随增益放大 |
| 带宽 | $G_{amp}$↓ | 增益带宽积 $GBW = G \times BW$，增益越大带宽越窄 |
| 输入范围 | $R_{shunt}$↓ | $V_{sense}$ 不能超过放大器最大差分输入 |

**典型设计流程**：

```plain
步骤1: 确定 I_max (峰值电流 × 1.2 余量)
步骤2: 选择 R_shunt (功耗约束: P < P_rated/2)
步骤3: 计算 G_amp = V_ref / (2 × I_max × R_shunt)
步骤4: 选择最接近的标准增益值
步骤5: 反算实际满量程电流，校验是否覆盖 I_max
步骤6: 计算电流分辨率，校验是否满足精度要求
```

### 7.3 实例计算1：48V/10A 低侧双电阻方案

```plain
已知条件:
  母线电压: Vdc = 48V
  额定电流: I_rated = 10A
  峰值电流: I_peak = 15A (1.5倍过载)
  最大测量电流: I_max = 18A (含20%余量)
  ADC参考电压: V_ref = 3.3V
  ADC位数: N = 12

步骤1: 选择采样电阻
  功耗约束: P < 1W (选择额定功率2W的电阻)
  R_shunt < P / I_max² = 1 / 18² = 3.09mΩ
  选择 R_shunt = 3mΩ (标准值)

  校验功耗: P = I_rated² × R_shunt = 100 × 0.003 = 0.3W 
  峰值功耗: P_peak = I_peak² × R_shunt = 225 × 0.003 = 0.675W 

步骤2: 计算放大器增益
  G_amp = V_ref / (2 × I_max × R_shunt)
        = 3.3 / (2 × 18 × 0.003)
        = 3.3 / 0.108
        = 30.56

  选择标准增益: G = 30 (如INA240A3)
  或选择: G = 50 (如INA240A4)，需校验

  校验G=30:
    V_out_max = I_max × R_shunt × G + V_ref/2
              = 18 × 0.003 × 30 + 1.65
              = 1.62 + 1.65 = 3.27V < 3.3V 

  校验G=50:
    V_out_max = 18 × 0.003 × 50 + 1.65
              = 2.7 + 1.65 = 4.35V > 3.3V  超量程!

  → 选择 G = 30

步骤3: 计算电流分辨率
  1 LSB = V_ref / 2^N = 3.3 / 4096 = 0.806mV
  I_LSB = 1 LSB / (R_shunt × G)
        = 0.806mV / (3mΩ × 30)
        = 0.806 / 0.09
        = 8.96mA

  精度 = I_LSB / I_rated = 8.96mA / 10A = 0.09% (理论)

步骤4: 计算实际满量程
  I_FS = V_ref / (2 × R_shunt × G)
       = 3.3 / (2 × 0.003 × 30)
       = 18.33A

  I_FS > I_max = 18A 

步骤5: 结果汇总
  ┌──────────────────────────────────┐
  │  R_shunt = 3mΩ / 1% / 2W        │
  │  G_amp = 30 (INA240A3)           │
  │  I_FS = ±18.33A                  │
  │  I_LSB = 8.96mA                  │
  │  功耗(额定) = 0.3W               │
  │  功耗(峰值) = 0.675W             │
  └──────────────────────────────────┘
```

### 7.4 实例计算2：310V/20A 高侧方案

```plain
已知条件:
  母线电压: Vdc = 310V
  额定电流: I_rated = 20A
  峰值电流: I_peak = 30A (1.5倍过载)
  最大测量电流: I_max = 36A (含20%余量)
  ADC参考电压: V_ref = 3.3V
  ADC位数: N = 12

步骤1: 选择采样电阻
  功耗约束: P < 1W
  R_shunt < P / I_max² = 1 / 36² = 0.77mΩ
  选择 R_shunt = 0.5mΩ (标准值，低阻值降低功耗)

  校验功耗: P = I_rated² × R_shunt = 400 × 0.0005 = 0.2W 
  峰值功耗: P_peak = I_peak² × R_shunt = 900 × 0.0005 = 0.45W 

步骤2: 计算放大器增益
  G_amp = V_ref / (2 × I_max × R_shunt)
        = 3.3 / (2 × 36 × 0.0005)
        = 3.3 / 0.036
        = 91.67

  标准增益选择困难(无91.67倍标准器件)
  方案A: 选择 G = 100，降低 I_max 余量
    I_FS = 3.3 / (2 × 0.0005 × 100) = 33A
    33A < 36A → 峰值过载时可能超量程 

  方案B: 增大 R_shunt = 1mΩ
    G_amp = 3.3 / (2 × 36 × 0.001) = 45.83
    选择 G = 50 (INA240A4)
    I_FS = 3.3 / (2 × 0.001 × 50) = 33A → 仍不够 

  方案C: R_shunt = 1mΩ, G = 40
    I_FS = 3.3 / (2 × 0.001 × 40) = 41.25A > 36A 
    但 G=40 非标准值，需用外置电阻设定增益

  方案D: 使用隔离放大器(如AMC1301)
    AMC1301固定增益=8.2，差分输出±2V
    R_shunt = 2V / (8.2 × 36A) = 6.78mΩ
    选择 R_shunt = 6.8mΩ
    功耗: P = 20² × 0.0068 = 2.72W → 需5W电阻 

  → 选择方案C: R_shunt=1mΩ, G=40, 高CMRR运放

步骤3: 高侧采样的特殊约束
  共模电压 = 310V → 必须使用隔离放大器或高CMRR运放

  方案C修正: 使用隔离放大器 + 外部增益调整
    第一级: AMC1301 (隔离, G=8.2, 差分输出±2V)
    第二级: 运放差分转单端, G2 = 1.22
    总增益: G_total = 8.2 × 1.22 ≈ 10
    R_shunt = 3.3 / (2 × 36 × 10) = 4.58mΩ
    选择 R_shunt = 4mΩ
    I_FS = 3.3 / (2 × 0.004 × 10) = 41.25A 
    功耗: P = 20² × 0.004 = 1.6W → 需3W电阻

步骤4: 计算电流分辨率
  1 LSB = 3.3 / 4096 = 0.806mV
  I_LSB = 0.806mV / (4mΩ × 10) = 20.15mA
  精度 = 20.15mA / 20A = 0.1% (理论)

步骤5: 结果汇总
  ┌──────────────────────────────────────────┐
  │  R_shunt = 4mΩ / 1% / 3W                 │
  │  放大器: AMC1301(隔离) + 运放(G=1.22)     │
  │  总增益: G_total ≈ 10                     │
  │  I_FS = ±41.25A                           │
  │  I_LSB = 20.15mA                          │
  │  功耗(额定) = 1.6W                        │
  │  功耗(峰值) = 3.6W                        │
  │  隔离耐压: ≥500V                          │
  └──────────────────────────────────────────┘
```

## 8.  交叉视角  

> 采样拓扑不是孤立的硬件选择，它像多米诺骨牌一样，决定了下游算法模块能做什么、怎么做。本章节揭示拓扑选择与算法模块之间的深层耦合。

### 8.1 拓扑 → ALG-02（电流采样时序）

**核心关联**：采样拓扑直接决定了 [ALG-02](../algorithm/ALG-02-Current-Sampling-Timing.md) 中的时序约束等级。

| 拓扑 | ALG-02时序约束 | 具体影响 |
|------|---------------|---------|
| 低侧单电阻 | 极严 | 必须在两个有效矢量中各采样一次，窗口≥$T_{min}$，需PWM移相配合 |
| 低侧双电阻 | 中等 | 需在下管导通期间采样，避开死区振铃，扇区2/4/6需选相 |
| 低侧三电阻 | 宽松 | 选择导通时间最长的两相采样，过调制仍可工作 |
| 高侧/在线 | 无 | 任意时刻采样，时序完全自由 |

**工程启示**：如果你的系统对电流环带宽要求高（>5kHz），低侧单电阻方案几乎不可行——时序约束太严，采样延迟无法控制。

### 8.2 拓扑 → ALG-05（有感FOC）

**核心关联**：[ALG-05](../algorithm/ALG-05-Sensored-FOC.md) 的有感FOC控制性能受采样拓扑约束。

```plain
有感FOC的电流环执行频率 = PWM频率

低侧采样:
  → 采样时刻受限 → 电流反馈延迟大 → 电流环带宽受限
  → 双电阻: 带宽可达 PWM频率/10
  → 单电阻: 带宽可达 PWM频率/20 (移相开销)

高侧/在线采样:
  → 采样时刻自由 → 电流反馈延迟小 → 电流环带宽可达 PWM频率/5
  → 适合高速伺服应用
```

**有感FOC对拓扑的隐性需求**：
- 伺服定位（位置环）→ 需要高带宽电流环 → 倾向三电阻或在线采样
- 速度控制 → 电流环带宽适中 → 双电阻低侧即可
- 转矩控制 → 电流精度要求高 → 三电阻冗余校验有优势

### 8.3 拓扑 → ADV-HW-01（PWM与采样联动）

**核心关联**：[ADV-HW-01](../advanced/hardware-algorithm-bridge/ADV-HW-01-PWM-Current-Sampling.md) 讨论的PWM-ADC联动机制，其复杂度直接取决于采样拓扑。

| 拓扑 | PWM-ADC联动复杂度 | 需要的联动机制 |
|------|------------------|---------------|
| 低侧单电阻 | 最高 | SVPWM移相、采样窗口注入、扇区判断、盲区补偿 |
| 低侧双电阻 | 中等 | ADC在PWM谷底触发、扇区选相、死区后延迟采样 |
| 低侧三电阻 | 较低 | ADC在PWM谷底触发、动态选相 |
| 高侧/在线 | 最低 | ADC任意时刻触发即可 |

**单电阻采样的PWM联动是最复杂的**——ADV-HW-01中的移相时刻计算、采样窗口扩展、非对称PWM等机制，几乎都是为单电阻方案服务的。如果选了双电阻或三电阻，这些机制可以完全不用。

### 8.4 拓扑选择决策树

```plain
开始选型
  │
  ├─ 母线电压 ≤ 48V?
  │   ├─ 是 → 低侧采样可行
  │   │   ├─ 成本极敏感(家电)?
  │   │   │   ├─ 是 → 低侧单电阻 (接受低速限制)
  │   │   │   └─ 否 → 继续
  │   │   ├─ 需要过调制(m>0.95)?
  │   │   │   ├─ 是 → 低侧三电阻
  │   │   │   └─ 否 → 低侧双电阻 (性价比最优)
  │   │   └─ 需要冗余校验?
  │   │       ├─ 是 → 低侧三电阻
  │   │       └─ 否 → 低侧双电阻
  │   │
  │   └─ 否(母线>48V) → 高侧或在线
  │       ├─ 需要最高精度(伺服)?
  │       │   ├─ 是 → 在线三电阻 (隔离放大器)
  │       │   └─ 否 → 继续
  │       ├─ 需要过调制?
  │       │   ├─ 是 → 高侧双电阻或在线双电阻
  │       │   └─ 否 → 高侧双电阻
  │       └─ 成本敏感?
  │           ├─ 是 → 高侧双电阻 (隔离放大器)
  │           └─ 否 → 在线双/三电阻
```

## 9.  工程案例  

### 案例1：空调压缩机——单电阻FOC的低速困境

**项目背景**：
```plain
应用: 变频空调压缩机
电机: PMSM, 额定功率2.2kW, 额定转速3600rpm
控制器: STM32G030, 20kHz PWM
拓扑: 低侧单电阻
问题: 低频启动时(10~30Hz)电流波形严重失真,压缩机振动大
```

**诊断过程**：
```plain
步骤1: 示波器观察低速PWM波形 → 有效矢量时间仅1.2μs
步骤2: 计算最小采样窗口 → T_min = t_dead(1μs) + t_settle(1.5μs) + t_ADC(0.5μs) = 3μs
步骤3: 1.2μs < 3μs → 采样窗口不足,ADC采到的是开关噪声
步骤4: 确认盲区范围 → 调制比 m < 0.06 时无法采样
```

**根本原因**：低速低调制比时，SVPWM有效矢量持续时间小于最小采样窗口。

**解决方案**：
```plain
方案A: PWM移相 + 测量窗口注入
  在有效矢量中强制插入3μs测量窗口
  结果: 低速性能改善,但电流THD从5%升到8% 

方案B: 低速开环V/F启动 + 速度阈值切换FOC
  V/F控制启动到600rpm后切换FOC
  结果: 启动平稳,切换瞬态<50ms 

方案C(最终方案): 方案B + 自适应采样窗口
  低速: V/F启动
  中速: 单电阻FOC + 移相补偿
  高速: 单电阻FOC正常采样
  结果: 全速域平稳运行 
```

**经验总结**：单电阻方案的低速盲区是拓扑固有缺陷，无法完全消除，只能通过策略规避。

### 案例2：协作机器人关节——双电阻的扇区跳变

**项目背景**：
```plain
应用: 协作机器人关节电机
电机: PMSM, 额定转矩4.5Nm, 额定电流5A
控制器: STM32G431, 10kHz PWM
拓扑: 低侧双电阻(A、B相)
问题: Id电流在扇区切换时有0.2A跳变,导致定位抖动
```

**诊断过程**：
```plain
步骤1: 记录Id随电角度变化 → 每60°电角度出现一次跳变(=扇区边界)
步骤2: 分析扇区2时A相下管导通时间 → 占空比82%时仅3.6μs
步骤3: 采样时刻偏离下管导通中心 → 采样值含di/dt分量
步骤4: 计算di/dt误差 → di/dt=50A/ms, 偏离1μs → 50mA误差
```

**根本原因**：扇区切换时，被采样相的下管导通时间变化，导致采样时刻偏离电流平均值。

**解决方案**：
```plain
方案A: 动态调整ADC触发时刻
  根据占空比实时计算最佳采样点
  结果: 跳变降低到0.05A 

方案B(最终方案): 方案A + 扇区切换前后采样值加权
  在扇区边界使用前后两次采样的加权平均
  结果: 跳变降低到0.02A, 定位抖动消除 

方案C: 改用三电阻采样
  成本增加¥6, 但彻底消除扇区跳变 
  (客户不接受成本增加)
```

**经验总结**：双电阻低侧采样在扇区边界的跳变是固有的，高精度伺服应考虑三电阻或在线采样。

### 案例3：电动两轮车——48V平台低侧vs高侧之争

**项目背景**：
```plain
应用: 电动两轮车电机控制器
电机: PMSM, 额定功率1.5kW, 额定电流35A
母线电压: 48V (满电54.6V)
控制器: STM32F302, 15kHz PWM
初始方案: 低侧双电阻
问题: 满电54.6V时电流采样噪声大,低速有异响
```

**诊断过程**：
```plain
步骤1: 48V时电流波形正常,54.6V时噪声增大3倍
步骤2: 测量运放输入端共模电压 → 下管关断时Vcm跳变到54.6V
步骤3: 运放CMRR=80dB → 54.6V共模 → 5.46mV误差 → 109mA电流误差
步骤4: 检查PCB布局 → 采样电阻到运放的走线未做差分对称
步骤5: 示波器探测 → 开关瞬态有2~3μs的振铃耦合到采样信号
```

**根本原因**：48V满电时共模瞬态超出了低侧运放的抑制能力，PCB布局加剧了耦合。

**解决方案**：
```plain
方案A: 更换高CMRR运放(INA240, CMRR=120dB)
  54.6V共模 → 0.055mV误差 → 1.1mA电流误差 
  成本增加¥3/片 × 2 = ¥6

方案B: 优化PCB布局
  差分走线严格对称,缩短走线长度
  结果: 噪声降低50%,但仍不理想 

方案C(最终方案): 方案A + 方案B
  INA240 + 差分布线 + 地平面隔离
  结果: 噪声降低80%,异响消除 
```

**经验总结**：48V名义电压的系统，满电可达54.6V，共模瞬态不可忽视。低侧采样≠没有共模问题。

### 案例4：工业伺服驱动器——在线三电阻的极致方案

**项目背景**：
```plain
应用: 工业伺服驱动器
电机: PMSM, 额定功率2kW, 额定电流8A, 最高转速6000rpm
母线电压: 310V
控制器: TI C2000, 16kHz PWM
拓扑: 在线三电阻(隔离放大器)
要求: 转矩纹波<1%, 电流环带宽>2kHz
```

**设计方案**：
```plain
采样电阻: 5mΩ / 0.5% / 3W 合金箔电阻
放大器: AMC1301(隔离, G=8.2) + OPA388(差分转单端, G=1.5)
总增益: 8.2 × 1.5 = 12.3
满量程电流: I_FS = 3.3 / (2 × 0.005 × 12.3) = 26.8A
电流分辨率: I_LSB = 0.806mV / (0.005 × 12.3) = 13.1mA

关键设计要点:
  1. AMC1301隔离耐压5000V, 满足310V母线安全要求
  2. 在线采样不受PWM时序约束, 任意时刻可采样
  3. 三电阻冗余校验: |i_a+i_b+i_c| < 0.05×8A = 0.4A
  4. 过调制区域(m>0.95)仍可精确采样
  5. 方波调制(六步换相)区域仍可采样
```

**测试结果**：
```plain
转矩纹波: 0.8% (目标<1%) 
电流环带宽: 2.5kHz (目标>2kHz) 
Id偏置: 15mA (校准后) 
低速(10rpm)平稳运行 
过调制(m=0.98)无失真 
```

**经验总结**：在线三电阻是性能最极致的方案，但BOM成本高（3×AMC1301 ≈ ¥45），仅适合高端伺服。

### 案例5：无人机ESC——单电阻的极限挑战

**项目背景**：
```plain
应用: 无人机电子调速器(ESC)
电机: PMSM, 额定功率500W, 最高转速30000rpm
母线电压: 6S锂电池(22.2V~25.2V)
控制器: STM32G071, 48kHz PWM(高速时)
拓扑: 低侧单电阻
要求: BOM成本<¥15, 重量<5g
```

**设计挑战**：
```plain
1. 超高速(30000rpm = 500Hz电频率/2对极)
   → 每电角度周期仅2ms
   → 电流环必须在48kHz执行

2. 单电阻+48kHz PWM
   → PWM周期仅20.8μs
   → 采样窗口仅3~5μs
   → 移相空间极小

3. 锂电池电压波动
   → 22.2V~25.2V变化
   → 影响SVPWM调制比
```

**解决方案**：
```plain
1. 自适应PWM频率
   低速: 24kHz PWM → 采样窗口充足
   高速: 48kHz PWM → 电流环带宽够

2. 紧凑采样时序
   死区0.5μs + 建立0.8μs + ADC 0.3μs = 1.6μs最小窗口
   使用STM32G0的快速ADC(0.17μs转换时间)

3. 开环启动 + 无感FOC
   0~1000rpm: 开环V/F
   1000rpm以上: 单电阻FOC + 反电动势观测器

4. 极致BOM优化
   单电阻: 2mΩ/0.5W → ¥0.3
   运放: LMV358 → ¥0.5
   总采样BOM: <¥1
```

**经验总结**：单电阻方案在极致成本和体积约束下是唯一选择，但需要付出巨大的软件复杂度代价。

### 练习1：计算题——低侧双电阻方案设计

```plain
已知:
  母线电压: 24V
  额定电流: 15A, 峰值电流: 25A
  ADC: 12位, Vref = 3.3V
  PWM频率: 20kHz

要求:
1. 选择采样电阻阻值和规格
2. 计算放大器增益
3. 计算电流分辨率
4. 校验最小下管导通时间(占空比95%时)

参考答案:
1. I_max = 25×1.2 = 30A
   R_shunt < 1W/30² = 1.11mΩ → 选择1mΩ/1%/2W
   P = 15²×0.001 = 0.225W 
2. G = 3.3/(2×30×0.001) = 55 → 选择G=50(INA240A4)
   I_FS = 3.3/(2×0.001×50) = 33A > 30A 
3. I_LSB = 0.806mV/(1mΩ×50) = 16.12mA
   精度 = 16.12mA/15A = 0.11%
4. T_pwm = 50μs, 占空比95% → 下管导通 = 50×5% = 2.5μs
   T_min = 1μs(死区) + 1μs(建立) + 0.5μs(ADC) = 2.5μs
   刚好满足,但无余量  → 建议限制最大占空比≤93%
```

### 练习2：计算题——高侧方案增益链设计

```plain
已知:
  母线电压: 380V(三相AC整流)
  额定电流: 10A, 峰值电流: 15A
  ADC: 12位, Vref = 3.3V
  使用AMC1301隔离放大器(G=8.2, 差分输出±2V)

要求:
1. 计算采样电阻阻值
2. 设计第二级增益
3. 计算总精度(含隔离放大器误差)
4. 选择采样电阻功率等级

参考答案:
1. AMC1301差分输出范围±2V → 对应ADC单端0~3.3V
   差分→单端增益: V_adc = V_diff × G2 + 1.65V
   I_max × R_shunt × 8.2 ≤ 2V
   R_shunt ≤ 2/(8.2×18) = 13.6mΩ → 选择10mΩ
2. I_max = 18A(含余量)
   V_diff_max = 18×0.01×8.2 = 1.476V
   G2 = 1.65/1.476 = 1.118 → 选择G2=1.1
   V_adc_max = 1.476×1.1+1.65 = 3.274V < 3.3V 
3. AMC1301增益误差0.5% + 失调1.5mV + 第二级误差0.2%
   总误差 ≈ √(0.5²+0.2²) ≈ 0.54% + 失调误差
   失调电流误差 = 1.5mV/(10mΩ×8.2) = 18.3mA
4. P = 10²×0.01 = 1W → 选择10mΩ/1%/3W
```

### 练习3：分析题——盲区范围计算

```plain
已知:
  单电阻低侧采样方案
  PWM频率: 10kHz (Tpwm=100μs)
  死区时间: 1μs
  电流建立时间: 1.5μs
  ADC采样时间: 0.5μs

要求:
1. 计算最小采样窗口T_min
2. 计算低调制比盲区(m < m_min)
3. 计算过调制盲区(m > m_max)
4. 如果PWM频率提高到20kHz,盲区如何变化?

参考答案:
1. T_min = 1 + 1.5 + 0.5 = 3μs
2. m_min = T_min/T_pwm = 3/100 = 0.03
   对应线电压 ≈ 0.03 × Vdc/√3 ≈ 0.017 × Vdc
   48V系统: 约0.83V线电压 → 极低速
3. m_max ≈ 1 - T_min/T_pwm = 1 - 0.03 = 0.97
   超过97%调制比时出现盲区
4. T_pwm = 50μs(20kHz)
   m_min = 3/50 = 0.06 → 低调制比盲区扩大!
   m_max = 1 - 3/50 = 0.94 → 过调制盲区扩大!
   PWM频率越高,盲区范围越大,单电阻越难做
```

## 附录：快速计算公式汇总

### A. 放大倍数核心公式
```plain
R_shunt × I_max × G_amp = V_ADC_FS / 2

变形:
  R_shunt = V_ref / (2 × I_max × G_amp)
  G_amp = V_ref / (2 × I_max × R_shunt)
  I_FS = V_ref / (2 × R_shunt × G_amp)
```

### B. 电流分辨率
```plain
I_LSB = V_ref / (2^N × R_shunt × G_amp)
```

### C. 采样电阻功耗
```plain
P = I_rms² × R_shunt
P_peak = I_peak² × R_shunt
```

### D. 共模误差
```plain
V_error = V_cm / 10^(CMRR/20)
I_error = V_error / (R_shunt × G_amp)
```

### E. 单电阻盲区
```plain
T_min = t_dead + t_settle + t_ADC
m_min = T_min / T_pwm
m_max ≈ 1 - T_min / T_pwm
```

### F. 最小下管导通时间
```plain
T_on_min = T_pwm × (1 - D_max)
要求: T_on_min > T_min
```
