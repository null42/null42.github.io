## 双闭环FOC控制系统

核心概念&#9660;

#### 双闭环结构

内环（电流环）：控制Id和Iq跟踪参考值，带宽最高（1~5kHz）。外环（速度环）：控制转速跟踪参考值，输出Iq参考，带宽为电流环的1/3~1/5。Id参考通常设为0（表贴PMSM）或由MTPA计算（内置PMSM）。

#### 带宽分配原则

内环带宽 >> 外环带宽，确保内环快速响应、外环稳定。典型比例：$f_{bw(speed)} = f_{bw(current)}/(3\sim5)$。电流环带宽受PWM频率限制（通常$f_{bw}

#### 解耦控制

dq轴存在交叉耦合：$v_d = R_s i_d + L_d \frac{di_d}{dt} - \omega_e L_q i_q$，$v_q = R_s i_q + L_q \frac{di_q}{dt} + \omega_e L_d i_d + \omega_e \psi_f$。前馈解耦：在PI输出上叠加交叉耦合项$\omega_e L_q i_q$和$-\omega_e L_d i_d + \omega_e \psi_f$，实现dq轴独立控制。

#### 仿真验证

Simulink模型：PMSM模块 + Park/Clarke变换 + PI控制器 + SVPWM + 逆变器。验证项目：1)空载启动；2)阶跃负载；3)转速阶跃响应；4)电流波形正弦度；5)dq轴解耦效果。

仿真要点：双闭环FOC是PMSM控制的基础架构。先调电流环（内环），再调速度环（外环）。电流环调好后，速度环看到的被控对象近似为一阶惯性环节，PI参数设计有解析公式可循。

&#120791;关键公式&#9660;

$$v_d = R_s i_d + L_d \frac{di_d}{dt} - \omega_e L_q i_q$$d轴电压方程。交叉耦合项$-\omega_e L_q i_q$需前馈补偿。
$$v_q = R_s i_q + L_q \frac{di_q}{dt} + \omega_e(L_d i_d + \psi_f)$$q轴电压方程。反电动势$\omega_e\psi_f$和交叉耦合$\omega_e L_d i_d$需前馈补偿。
$$T_e = \frac{3}{2}p_n[\psi_f i_q + (L_d - L_q)i_d i_q]$$电磁转矩。表贴PMSM($L_d=L_q$)：$T_e = \frac{3}{2}p_n\psi_f i_q$，转矩仅与Iq成正比。

## 电流环参数设计

核心概念&#9660;

#### 被控对象模型

解耦后d轴（或q轴）电流环被控对象：$G_p(s) = \frac{1}{R_s + sL_d}$（一阶惯性环节）。时间常数$\tau_e = L_d/R_s$为电气时间常数。表贴PMSM的d轴和q轴参数相同。

#### PI参数解析计算

零极点对消法：PI零点对消被控对象极点，即$K_i/K_p = R_s/L_d$。闭环带宽$f_{bw} = K_p/(2\pi L_d)$。给定带宽后：$K_p = 2\pi f_{bw} L_d$，$K_i = K_p R_s / L_d = 2\pi f_{bw} R_s$。

#### 延迟补偿

实际系统存在延迟：PWM更新延迟（1个PWM周期）、电流采样延迟、计算延迟。总延迟约1.5个PWM周期。延迟使相位裕度降低，需适当降低带宽或增加微分补偿。

#### 仿真验证

验证项目：1)Id/Iq阶跃响应（超调

仿真要点：电流环参数设计是整个FOC系统的基础。零极点对消法给出解析公式，但实际需考虑延迟和离散化影响。仿真中先验证连续域参数，再验证离散化后的性能。

&#120791;关键公式&#9660;

$$K_p = 2\pi f_{bw} \cdot L_d$$电流环比例增益。f_bw=2kHz, Ld=5mH时Kp=62.8。
$$K_i = 2\pi f_{bw} \cdot R_s$$电流环积分增益。f_bw=2kHz, Rs=0.5&Omega;时Ki=6283。
$$\frac{K_i}{K_p} = \frac{R_s}{L_d}$$零极点对消条件。PI零点=被控对象极点，闭环传递函数为一阶。

练习题 (2)&#9660;

简单电流环Kp和Ki如何从电机参数计算？零极点对消法的原理是什么？查看参考参考解答

**计算公式：**

$$K_p = 2\pi f_{bw} \cdot L_d, \quad K_i = 2\pi f_{bw} \cdot R_s$$

其中$f_{bw}$为期望的电流环闭环带宽，$L_d$为d轴电感，$R_s$为定子电阻。

**零极点对消法原理：**

1. 被控对象：$G_p(s) = \frac{1}{R_s + sL_d} = \frac{1/L_d}{s + R_s/L_d}$，极点在$s = -R_s/L_d$

2. PI控制器：$G_c(s) = K_p + \frac{K_i}{s} = \frac{K_p s + K_i}{s}$，零点在$s = -K_i/K_p$

3. 令PI零点对消被控对象极点：$K_i/K_p = R_s/L_d$

4. 开环传递函数：$G_{ol}(s) = G_c \cdot G_p = \frac{K_p/L_d}{s}$，为纯积分环节

5. 闭环传递函数：$G_{cl}(s) = \frac{K_p/L_d}{s + K_p/L_d}$，一阶系统

6. 闭环带宽：$f_{bw} = \frac{K_p}{2\pi L_d}$，因此$K_p = 2\pi f_{bw} L_d$

**带宽选择：**$f_{bw} = f_{PWM}/10 \sim f_{PWM}/5$，PWM 10kHz时取1~2kHz。

## 转速环参数设计

核心概念&#9660;

#### 速度环被控对象

电流环调好后近似为一阶惯性：$G_{current}(s) \approx \frac{1}{\tau_c s + 1}$，$\tau_c = 1/(2\pi f_{bw})$。速度环被控对象：$G_{speed}(s) = \frac{K_t}{Js + B} \cdot \frac{1}{\tau_c s + 1}$。$K_t = 1.5p_n\psi_f$为转矩常数，J为转动惯量，B为摩擦系数。

#### PI参数设计

简化设计：忽略电流环动态（$\tau_c$小），被控对象近似为$K_t/(Js)$。PI零点对消惯量极点：$K_i/K_p = B/J$（通常B很小，Ki/Kp也很小）。带宽：$f_{bw(speed)} = K_p K_t/(2\pi J)$。给定带宽后：$K_p = 2\pi f_{bw} J / K_t$。

#### 带宽约束

速度环带宽受限于：1)电流环带宽的1/3~1/5；2)机械谐振频率的1/3；3)转速采样/滤波延迟。典型值：200~500Hz（伺服），50~200Hz（通用变频）。过高带宽激发机械谐振。

#### 仿真验证

验证项目：1)空载转速阶跃响应（超调

仿真要点：速度环带宽为什么是电流环的1/3~1/5？这是由时间尺度分离原则决定的。如果速度环带宽过高，电流环的动态延迟不可忽略，速度环看到的被控对象不再是一阶，而是二阶甚至更高阶，导致不稳定。

## 模糊PI双闭环控制

核心概念&#9660;

#### 模糊PI原理

用模糊推理替代固定PI参数：根据误差e和误差变化率ec，通过模糊规则实时调整Kp和Ki。大误差时增大Kp加速响应，小误差时减小Kp避免超调，增大Ki消除稳态误差。实现参数自整定。

#### 隶属度函数

输入变量e和ec的论域通常取[-3, 3]，分为7个模糊集：NB(负大)、NM(负中)、NS(负小)、ZO(零)、PS(正小)、PM(正中)、PB(正大)。隶属度函数常用三角形或高斯型，ZO附近密集、两端稀疏。

#### 模糊规则表

Kp规则：e大时Kp大（加速），e小ec大时Kp中（防超调），e小ec小时Kp小（稳态）。Ki规则：e大时Ki小（防积分饱和），e小时Ki大（消除稳态误差）。共49条规则（7&times;7）。

#### 解模糊与输出

解模糊方法：重心法（最常用）、最大隶属度法。输出为&Delta;Kp和&Delta;Ki的调整量，叠加到基础PI参数上：$K_p = K_{p0} + \Delta K_p$，$K_i = K_{i0} + \Delta K_i$。基础参数由零极点对消法确定。

仿真要点：模糊PI在负载大范围变化和参数不确定时优于传统PI。仿真中对比传统PI和模糊PI在：1)惯量变化2倍；2)负载突变；3)低速运行时的性能差异。

练习题 (2)&#9660;

简单模糊PI相比传统PI的优势是什么？隶属度函数如何设计？查看参考参考解答

**模糊PI优势：**

1. **参数自整定：**根据实时误差状态自动调整PI参数，无需人工整定

2. **适应性强：**负载变化、惯量变化、参数漂移时仍能保持良好性能

3. **响应优化：**大误差时快速响应，小误差时平稳无超调

4. **抗扰性好：**负载突变时参数自动调整，恢复更快

5. **非线性处理：**可处理传统PI难以应对的非线性特性

**劣势：**计算量大、规则设计依赖经验、稳定性证明困难

**隶属度函数设计：**

1. **论域选择：**输入e和ec归一化到[-3, 3]，输出&Delta;Kp和&Delta;Ki归一化到[-3, 3]

2. **模糊集划分：**7个集合{NB, NM, NS, ZO, PS, PM, PB}

3. **函数类型：**三角形（计算简单、最常用）或高斯型（平滑过渡）

4. **分布原则：**ZO附近密集（提高稳态精度），两端稀疏（提高鲁棒性）

5. **重叠度：**相邻隶属度函数重叠25~50%，确保平滑过渡

6. **对称性：**正负对称，确保正负误差响应一致

## 三闭环位置控制

核心概念&#9660;

#### 三闭环结构

最内环：电流环（1~5kHz）。中间环：速度环（200~500Hz）。最外环：位置环（50~200Hz）。位置环输出速度参考，速度环输出Iq参考，电流环输出电压参考。带宽递减：位置

#### 位置环用P控制

位置环只用比例(P)控制，不用积分(I)。原因：1)位置环已含积分环节（速度是位置的导数，位置=速度积分），加I会导致双积分系统不稳定；2)P控制即可实现零稳态误差（对阶跃输入）；3)I控制引入额外极点降低相位裕度。

#### 前馈补偿

速度前馈：将位置参考的导数（期望速度）直接叠加到速度环参考上，减少跟踪滞后。加速度前馈：将位置参考的二阶导数（期望加速度）叠加到电流环参考上。前馈不改变闭环稳定性，但显著提高跟踪精度。

#### 仿真验证

验证项目：1)位置阶跃响应（无超调或小超调

仿真要点：三闭环位置控制是伺服系统的标准架构。位置环只用P控制是关键设计决策。前馈补偿是提高跟踪精度的有效手段，不改变闭环稳定性但显著减小动态误差。

练习题 (2)&#9660;

简单位置环为什么用P控制不用PI控制？从传递函数角度分析。查看参考参考解答

**位置环用P不用PI的原因：**

1. **被控对象已含积分：**位置环的被控对象包含速度环+电机，从速度到位置是积分关系：$\theta(s) = \omega(s)/s$。即被控对象传递函数含$1/s$积分环节

2. **双积分不稳定：**如果位置环用PI控制器（含$1/s$），开环传递函数含两个积分$1/s^2$，即双积分系统。双积分系统的Nyquist曲线穿过(-1, j0)点附近，相位裕度极低（-180度），系统不稳定或临界稳定

3. **P控制已够：**被控对象含积分，P控制即可实现阶跃输入零稳态误差：$e_{ss} = \lim_{s\to0}\frac{s\cdot R(s)}{1+K_p\cdot G(s)} = 0$（当$G(s)$含$1/s$时）

4. **PI的I项危害：**

- 增加额外积分使系统阶数升高

- 相位裕度进一步降低

- 位置超调增大且难以消除

- 积分饱和导致大范围振荡

**特殊情况：**如果存在恒定负载扰动且要求零稳态误差，可在位置环加弱积分（Ki很小），但需仔细整定防止不稳定。

#### MTPA轨迹推导

练习题 (2)&#9660;

简单MTPA轨迹的物理意义是什么？如何用LUT实现MTPA？查看参考参考解答

**MTPA物理意义：**

MTPA（Maximum Torque Per Ampere）轨迹是在Id-Iq平面上，每个转矩等级对应的最小电流点连线。物理上，它利用了内置PMSM的磁阻转矩：通过注入负Id电流，虽然d轴电流本身不直接产生电磁转矩（$\psi_f i_q$项），但$(L_d-L_q)i_d i_q$磁阻转矩项在Id0时为正值，可以替代部分Iq产生的电磁转矩，从而在相同总转矩下减小总电流。

形象理解：Id-Iq平面上，恒转矩曲线为双曲线，恒电流曲线为圆。MTPA点是双曲线与最小圆的切点。

**LUT实现方法：**

1. **离线计算：**给定一系列$T_e$值（如0~10N&middot;m，步长0.1N&middot;m），对每个$T_e$求解MTPA条件，得到对应的$i_d^*$和$i_q^*$

2. **存储：**将$[T_e, i_d^*, i_q^*]$存入二维数组

3. **在线查表：**运行时根据转矩参考$T_e^*$，线性插值查找$i_d^*$和$i_q^*$

4. **优化：**可只存$i_d^*(T_e)$，$i_q^*$由转矩方程反算：$i_q^* = T_e^*/(1.5p_n(\psi_f + (L_d-L_q)i_d^*))$

5. **2D LUT：**考虑铁损和饱和，增加转速维度：$i_d^*(T_e, \omega)$，$i_q^*(T_e, \omega)$

## MTPA+弱磁综合策略

核心概念&#9660;

#### 弱磁原理

当转速升高到反电动势接近母线电压极限时，无法继续升速。通过注入负Id电流削弱气隙磁通（$d\psi/dt$减小），降低反电动势，实现超基速运行。弱磁区：$\omega > \omega_{rated}$，电压达到极限$V_s = V_{max}$。

#### 电压极限椭圆

电压约束：$(L_d i_d + \psi_f)^2 + (L_q i_q)^2 \leq (V_{max}/\omega_e)^2$。在Id-Iq平面上为椭圆，随转速升高椭圆缩小。电流极限：$i_d^2 + i_q^2 \leq I_{max}^2$为圆。工作点在电流圆和电压椭圆的交集中。

#### MTPA到弱磁过渡

低速区（&omega; base）：电压充足，沿MTPA轨迹运行。过渡条件：MTPA工作点触及电压极限椭圆，即$V_{MTPA} = V_{max}$。高速区（&omega; > &omega;base）：沿电压极限椭圆运行，Id更负（弱磁加深），Iq减小（转矩下降）。

#### 综合策略框图

1)转矩参考&rarr;MTPA LUT&rarr;Id_ref, Iq_ref初值；2)电压饱和检测：若$V_s > V_{max}$，增加负Id（弱磁）；3)电流限幅：$i_s \leq I_{max}$；4)最大转矩/弱磁轨迹跟踪。实现方式：电压反馈法、前馈计算法、LUT+插值法。

仿真要点：MTPA+弱磁综合是IPMSM全速域高效运行的核心策略。仿真中验证：1)基速以下MTPA运行效率；2)基速以上弱磁扩速范围；3)过渡区域平滑性；4)弱磁深度与转矩衰减关系。

&#120791;关键公式&#9660;

$$\omega_{base} = \frac{V_{max}}{\sqrt{(L_d i_d^{MTPA}+\psi_f)^2 + (L_q i_q^{MTPA})^2}}$$基速（MTPA轨迹触及电压极限的转速）。低于基速沿MTPA运行，高于基速进入弱磁。
$$V_s = \omega_e\sqrt{(L_d i_d + \psi_f)^2 + (L_q i_q)^2}$$所需电压幅值。$V_s > V_{max}$时需弱磁（增加负Id减小磁链）。

练习题 (2)&#9660;

**过渡条件：**

MTPA工作点所需电压$V_s$等于电压极限$V_{max}$时，即MTPA轨迹与电压极限椭圆相切。对应转速为基速$\omega_{base}$。
