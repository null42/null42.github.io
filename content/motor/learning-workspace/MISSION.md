# Mission: 电机控制全栈知识体系交互式学习

## 动机

作为有实践经验的电机控制工程师，需要将零散的知识系统化、体系化，建立从硬件底层到高级算法的完整认知框架。同时作为知识管理工具，方便后续查阅和分享。

## 目标

1. **全面掌握** 14条学习路径的核心知识，建立"硬件-算法-系统"三维认知
2. **知识管理** 将静态知识库转化为可交互、可追踪、可检索的学习资源
3. **深度理解** 通过交互式测验、可视化动画、代码对照深化理解
4. **工程转化** 将理论知识转化为可落地的工程判断力

## 当前水平

- 有实践经验：实现过有感FOC，理解SVPWM和电流采样
- 最近发展区：无感观测器设计、MTPA/弱磁、ADRC/MPC等高级算法
- 短板：控制理论系统化不足、硬件-算法桥接理解不深

## 学习策略

- 以算法路径为核心锚点，向硬件和控制理论双向辐射
- 每个模块：先读核心摘要 → 交互式课程深化 → 评估测验验证 → 代码对照实践
- 利用交叉引用系统建立模块间关联

## 成功标准

- 每条路径评估正确率 >= 80%
- 能独立解释硬件约束如何影响算法设计决策
- 能从零推导FOC坐标变换链和PI参数设计
