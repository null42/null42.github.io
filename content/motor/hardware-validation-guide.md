# 硬件验证指南

本指南定义 lxfoc 与电源专题进入实测闭环时的最低硬件验证要求。

## 默认平台

70% 阶段默认从低压 PMSM 平台开始：

| 项目 | 建议范围 |
|---|---|
| 母线电压 | 12 V 到 60 V |
| 电机 | 小功率 PMSM/BLDC |
| 电流采样 | 至少两相，已标定零偏和增益 |
| 位置传感器 | 编码器优先，无感算法需同时记录参考角度 |
| 通信 | 串口、USB CDC 或 CAN 转 CSV |
| 保护 | 过流、欠压、过压、急停可验证 |

高压 PFC、Vienna、LLC 等专题先做仿真和低风险台架，不默认要求直接接入 lxfoc 主库。

## lxfoc 基础算法验收

| 算法 | 指标 | 默认阈值 |
|---|---|---|
| Clarke/Park/SVPWM | duty 合法、dq 方向正确 | duty 100% 在 `[0,1]` |
| 电流 PI | 超调、稳定时间、稳态误差 | `<15%`、`<5 ms`、`<3%` |
| 有感 FOC | 速度阶跃和故障状态 | 无误触发、无 duty 越界 |
| V/F 与 I/F | 启动方向、电流保护 | 方向正确，保护有效 |
| 观测器 | 编码器角度对比 | 中高速稳态电角误差 `<5 deg` |

## 实验记录

每次实验必须保留：

1. `experiment_manifest.json`
2. `lxfoc_trace.csv`
3. `lxfoc_report.json`
4. 硬件照片或连接说明
5. 采样链路标定方法
6. 异常和失败记录

## 安全规则

- 首次上电必须限流。
- 首次闭环必须限转矩、限速度。
- 高压实验必须隔离、放电、单手操作和急停。
- 任何保护误触发都应保留 trace，不应直接删除。
- 无法确认电流采样极性时，不得进入闭环电流控制。

## 从 reviewed 到 verified

模块升级为 `verified` 必须同时满足：

1. proof 检查通过。
2. 实测 trace 可导入电控知识库工具链。
3. 报告指标满足模块阈值。
4. 至少一次人工复核确认实验条件可信。
5. 页面标注硬件平台和适用边界。
