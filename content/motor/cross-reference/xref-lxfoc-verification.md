#  交叉引用：lxfoc代码 ↔ KB理论一致性验证

> 来源：[交叉引用映射表](./cross-reference-map.md)

---

## 一、概述

### 1.1 目的
验证lxfoc核心算法模块的实现是否与motor-control-knowledge-base中的理论描述一致，发现差异并标记改进点，确保"理论指导代码、代码印证理论"的闭环。

### 1.2 覆盖范围
25个核心算法模块，分为6组：
- 控制环(7): current, speed, position, vf, field_weakening, mtpa, inductance_sat
- 观测器(7): smo, emf, flux, hfi, pll, speed, base
- 高级控制(4): adrc, deadbeat, lqr, mpc
- 参数辨识(3): resistance, inductance, flux
- 自整定(2): current_pi, speed_pi
- 数学/变换(2): pid, svpwm

### 1.3 验证方法
逐模块对比lxfoc .c源代码与KB理论文档，检查4个维度：
1. **公式一致性**: 代码中的数学公式是否与KB理论公式匹配
2. **算法结构一致性**: 代码执行流程是否与KB描述的算法步骤一致
3. **参数处理一致性**: 默认值、范围、自适应策略是否与KB建议一致
4. **边界条件一致性**: KB提到的特殊情况在代码中是否处理

### 1.4 状态标记
-  一致 |  部分一致 |  不一致
-  关键 |  建议 |  可选

## 三、控制环模块详细验证

### 3.1 current (电流环控制)

**源文件**: `lxfoc/control/lxfoc_control_current.c`
**KB参考**: [ALG-03](../algorithm/ALG-03-PI-Current-Regulator.md), [ADV-ALG-07](../advanced/algorithm/ADV-ALG-07-Feedforward-Decoupling.md), [ADV-ALG-13](../advanced/algorithm/ADV-ALG-13-PID-Structure-Tuning.md)

#### 公式一致性

| 代码公式 | KB理论公式 | 状态 | 差异说明 |
|---------|-----------|------|---------|
| `Ud_ff = -ω*Lq*Iq` | ALG-03: $v_d^* = PI_d(e_{id}) - \omega_e L_q i_q$ |  | 完全一致，d轴补偿q轴耦合 |
| `Uq_ff = ω*(Ld*Id + flux_pm)` | ALG-03: $v_q^* = PI_q(e_{iq}) + \omega_e (L_d i_d + \psi_f)$ |  | 完全一致，q轴补偿d轴耦合+反电动势 |
| `us_max = vbus * LXFOC_1_SQRT3` | ALG-03: 线性调制区最大相电压 $V_{dc}/\sqrt{3}$ |  | 完全一致 |
| `iq_current_limit = sqrt(i_max² - id_ref²)` | ALG-03电流圆约束: $I_{q,max} = \sqrt{I_{max}^2 - I_{d,ref}^2}$ |  | 完全一致，电流圆约束 |
| `uq_max = SQSUB(us_max, \|ud_out\|)` | ALG-03电压圆约束: $U_{q,max} = \sqrt{U_{s,max}^2 - U_d^2}$ |  | 完全一致，电压圆约束 |
| PI输出限幅: `ud_pi_max = us_max - \|ud_ff\|` | MC_Lib: PID_Id.F_OutMax = UsRef - Ud_ff |  | 前馈预留电压空间，与MC_Lib一致 |
| 前馈LPF: `alpha=0.15` | ADV-ALG-07: 建议对测量电流滤波后再用于前馈 |  | 代码增加了LPF，KB未指定具体alpha值 |

#### 算法结构一致性

| 代码流程 | KB描述流程 | 状态 | 差异说明 |
|---------|-----------|------|---------|
| 步骤0: 前馈解耦计算 | ALG-03 §2.2: dq解耦前馈 |  | 代码先算前馈再PI，与KB一致 |
| 步骤1: d轴PI控制 | ALG-03: PI_d(e_id) → Ud_pi |  | 一致 |
| d轴PI限幅预留前馈空间 | MC_Lib: PID_Id.F_OutMax = UsRef - Ud_ff |  | 代码实现了动态限幅 |
| 步骤2: 电流圆约束Iq限幅 | ALG-03: 电流圆约束 |  | 一致 |
| 步骤3: Iq_ref限幅 | ALG-03: Iq_ref经电流圆约束 |  | 一致 |
| 步骤4: 电压圆约束q轴PI限幅 | ALG-03: 电压圆约束 |  | 一致 |
| 步骤5: q轴PI控制 | ALG-03: PI_q(e_iq) → Uq_pi |  | 一致 |
| PI+前馈叠加后总电压限幅 | ALG-03: 输出限幅 |  | 代码有安全限幅保护 |

#### 参数处理一致性

| 代码参数 | KB建议 | 状态 | 差异说明 |
|---------|--------|------|---------|
| 前馈LPF alpha=0.15 | ADV-ALG-07: 建议滤波但未指定值 |  | 代码选值合理(258Hz@10kHz)，但KB无明确参考值 |
| 前馈使能默认ff_enable=1 | ADV-ALG-07: 建议高速使能 |  | 代码默认全速使能，KB建议低速可关闭 |
| kc_d/kc_q由cfg传入 | ADV-ALG-13: kc=1/Kp典型值 |  | 代码未设默认kc值，依赖用户配置 |
| NULL指针安全输出0 | KB未提及 |  | 代码额外安全措施 |

#### 边界条件一致性

| KB提到的特殊情况 | 代码是否处理 | 状态 | 差异说明 |
|----------------|------------|------|---------|
| 测量指针未绑定 | 是，输出安全值0并return |  | 代码有防御性检查 |
| id_ref超过i_max时iq无余量 | 是，iq_current_limit=0 |  | 代码处理了此边界 |
| i_max未配置(≤0) | 是，不限制 |  | 代码处理了此边界 |
| 电压圆SQSUB结果为负 | 是，uq_pi_max=MAX(..., 0) |  | 代码防御性保护 |
| 前馈参数不准导致过补偿 | 否 |  | KB ADV-ALG-07 §10.3提到过补偿风险，代码无Kff增益调节 |

#### 差异清单

| # | 差异描述 | 严重程度 | 改进建议 |
|---|---------|---------|---------|
| 1 | 前馈无Kff增益系数，无法调节前馈强度 |  | 增加Kff参数(0~1)，默认1.0，KB建议从0.5起步 |
| 2 | 前馈默认全速使能，低速时ω噪声被放大 |  | 可增加低速前馈禁用阈值 |
| 3 | kc抗饱和系数依赖用户配置，无默认值 |  | 可设默认kc=1/Kp或0.5 |

### 9.4 改进优先级建议

1. ** 紧急**: 修复ADRC LESO的b0*u项缺失
2. ** 紧急**: 为Deadbeat添加一拍延迟补偿和电压限幅
3. ** 紧急**: VF模块添加弱磁区电压限制
4. ** 重要**: Flux观测器实现gamma速度自适应
5. ** 重要**: HFI模块实现N/S极判断
6. ** 建议**: 其余级别改进按模块重要性排序：
   - 高优先：SMO sat()函数、Deadbeat精确离散化、LQR Q/R正定性检查
   - 中优先：EMF dI/dt预滤波、MPC多步约束、Inductance q轴测量
   - 低优先：SVPWM死区滞环、Base层切换/收敛、Speed T法测速
