CE-05: IP控制器——消除超调的比例项移位 ​

副标题：在PI控制器的参考输入端加一阶低通滤波器，你就得到了IP控制器——不是近似，而是精确等价难度： 中等 适用对象： 控制理论学习者、电机控制工程师 前置知识： CE-04

1. 核心摘要 ​

标准PI控制器中，比例项作用于误差 e=r−ye = r - ye=r−y，在闭环传递函数分子中产生 KpsK_p sKp​s 零点，导致"比例冲击（Proportional Kick）"和超调。IP控制器将比例项从误差路径移到反馈路径（−Kpy-K_p y−Kp​y），仅保留积分项作用于误差。结果是：闭环分母不变（极点、稳定性、扰动抑制完全相同），但分子中的 KpsK_p sKp​s 零点消失，阶跃响应从超调变为单调收敛。更深刻的是，在PI控制器参考输入端加一阶低通滤波器 F(s)=1/((Kp/Ki)s+1)F(s) = 1/((K_p/K_i)s + 1)F(s)=1/((Kp​/Ki​)s+1) 与IP控制器精确代数等价——这揭示了二自由度（2-DOF）控制的核心架构。

4. 为什么外部滤波而不是重写控制器？ ​

如果IP对阶跃响应更好，为什么不直接编码？

4.1 封闭系统 ​

商用伺服驱动器、电机控制器和PLC功能块出厂时具有固定的PID/PI结构。你无法修改固件。你可以在参考信号进入控制器之前对其进行滤波。一阶IIR滤波器每个采样只需两次乘加——基本免费。

4.2 二自由度（2-DOF）设计 ​

滤波等价揭示了2-DOF架构：

text
    r ──→ [F(s)] ──→ [PI] ──→ u ──→ [P(s)] ──→ y
                      ↑                         │
                      └─────────────────────────┘

你现在有两个独立的旋钮：

  1. PI增益 (Kp,Ki)(K_p, K_i)(Kp​,Ki​)——为扰动抑制调参。让它们激进。高刚度、快速负载恢复。滤波器会处理超调。

  2. 滤波器 F(s)F(s)F(s)——设 τ=Kp/Ki\tau = K_p/K_iτ=Kp​/Ki​ 得到IP等价的平滑跟踪。或故意设更长的 τ\tauτ 获得更柔和的启动。或在允许超调的激进机动中设为1（旁路）。或调度它——精确定位时紧滤波，大角度转动时松滤波。

这就是伺服性能与调节性能的独立调参——2-DOF控制的核心承诺。PI + 滤波器架构无需修改一行控制器代码即可实现。

4.3 无扰切换 ​

在"激进PI"和"平滑IP"行为之间切换只是滤波器参数的改变。没有增益切换，没有积分器复位，没有瞬态。改变 τ\tauτ，响应形状平滑变化。这在多模式系统（粗逼近→精定位、速度控制→力矩控制）中很重要。

5. D项怎么办？ ​

扩展到完整PID：IPD（或I-PD）控制器将比例和微分项都移到反馈路径：

U(s)=Kis(R(s)−Y(s))−KpY(s)−KdsY(s)U(s) = \frac{K_i}{s}(R(s) - Y(s)) - K_p Y(s) - K_d s Y(s)U(s)=sKi​​(R(s)−Y(s))−Kp​Y(s)−Kd​sY(s)

8. 滤波器不能做什么 ​

滤波等价有值得了解的局限：

关注点回答
滤波器会减慢扰动抑制吗？不会。滤波器在参考路径上。扰动在被控对象输入或输出进入——完全绕过滤波器。PI回路以全带宽看到扰动。
滤波器会在环路内添加相位滞后吗？不会。滤波器在反馈环路之外。环路增益、相位裕度和增益裕度不变。
对非线性被控对象有效吗？推导假设线性，但架构（比例-on-feedback，积分-on-error）对任何被控对象都有效。滤波等价对线性被控对象是精确的；对非线性被控对象，它仍是正确的结构——只是不再是精确的代数恒等式。
测量噪声呢？IP和滤波PI与标准PI的噪声特性相同。比例项在两种情况下都作用于 yyy（在PI中作用于 r−yr-yr−y，但噪声无论如何都通过 yyy）。没有区别。

  • β=1\beta = 1β=1 → 标准PI（比例作用于全误差）

  • 0<β<10 < \beta < 10<β<1 → 部分设定值加权（有些超调，更快上升时间）
