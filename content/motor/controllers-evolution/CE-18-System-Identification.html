CE-18: 系统辨识——模型从何而来 ​

副标题：System Identification: Where Models Come From难度：适用对象： 控制理论学习者、电机控制工程师 前置知识： CE-03（传递函数与状态空间基础）

1. 核心摘要 ​

每个控制器都需要模型。LQR需要A、B、C、D矩阵；PID需要被控对象来整定参数；MPC需要预测模型。这些模型都不是从第一性原理推导出来的——它们来自数据。系统辨识（System Identification）是控制理论中缺失的第一章：给定一堆输入输出数据 {u[k],y[k]}k=1N\{u[k], y[k]\}_{k=1}^N{u[k],y[k]}k=1N​，如何恢复产生这些数据的系统？本文从数据出发，详解ARX/ARMAX/OE三大模型族、最小二乘估计引擎、PRBS激励信号设计、模型阶次选择与验证方法，最终回答一个根本问题——模型从何而来，模型错了会怎样。

认知挂钩： 你精心设计的LQR/MPC控制器，优化的是一个不存在的电机——如果模型参数是错的。

2. 你不知道自己有的问题 ​

打开 servo_motor_pid.html。看那些参数：电枢电阻 R=2.0 ΩR = 2.0\ \OmegaR=2.0 Ω，转矩常数 Kt=0.12K_t = 0.12Kt​=0.12 N·m/A，转子惯量 J=0.0001J = 0.0001J=0.0001 kg·m²。这些数字从哪来的？

不是从麦克斯韦方程组来的。不是从电磁学的第一性原理来的。有人测量了它们——或者猜的，或者读了数据手册，或者从类似电机上抄来的。如果这些数字是错的，那么仿真中的PID、LQR和MPC都在为一个不存在的电机做优化。

现在想象你不在仿真。你有一个真实的电机在实验台上。一个微控制器。一个功率级。一个编码器。你想构建一个控制器。第零步不是整定增益。第零步是获取模型。

系统辨识回答一个问题：给定一堆输入输出数据 {u[k],y[k]}k=1N\{u[k], y[k]\}_{k=1}^N{u[k],y[k]}k=1N​，产生这些数据的系统是什么？

答案是肯定的——在我们将要理解的条件之下——这个过程就是系统辨识。

4. 模型结构：ARX、ARMAX、OE ​

噪声项 e[k]e[k]e[k] 是三大模型族分道扬镳的地方。它们对噪声如何进入系统的假设不同——而这个选择的影响比大多数人意识到的更大。

4.1 ARX：主力马 ​

ARX = 带外生输入的自回归模型（AutoRegressive with eXogenous input）。噪声在对象动态之前进入：

A(q−1)y[k]=B(q−1)u[k]+e[k]A(q^{-1}) y[k] = B(q^{-1}) u[k] + e[k]A(q−1)y[k]=B(q−1)u[k]+e[k]

其中 q−1q^{-1}q−1 是后移算子（q−1y[k]=y[k−1]q^{-1} y[k] = y[k-1]q−1y[k]=y[k−1]），且：

A(q−1)=1+a1q−1+⋯+anaq−naA(q^{-1}) = 1 + a_1 q^{-1} + \cdots + a_{n_a} q^{-n_a}A(q−1)=1+a1​q−1+⋯+ana​​q−na​B(q−1)=b1q−1+⋯+bnbq−nbB(q^{-1}) = b_1 q^{-1} + \cdots + b_{n_b} q^{-n_b}B(q−1)=b1​q−1+⋯+bnb​​q−nb​

改写为：

y[k]=B(q−1)A(q−1)u[k]+1A(q−1)e[k]y[k] = \frac{B(q^{-1})}{A(q^{-1})} u[k] + \frac{1}{A(q^{-1})} e[k]y[k]=A(q−1)B(q−1)​u[k]+A(q−1)1​e[k]

噪声滤波器共享对象的分母 A(q−1)A(q^{-1})A(q−1)。这意味着噪声被与对象相同的动态所着色。

ARX的巨大优势： 预测器 y^[k∣θ]\hat{y}[k \mid \theta]y^​[k∣θ] 关于参数是线性的：

y^[k]=−a1y[k−1]−⋯−anay[k−na]+b1u[k−1]+⋯+bnbu[k−nb]\hat{y}[k] = -a_1 y[k-1] - \cdots - a_{n_a} y[k-n_a] + b_1 u[k-1] + \cdots + b_{n_b} u[k-n_b]y^​[k]=−a1​y[k−1]−⋯−ana​​y[k−na​]+b1​u[k−1]+⋯+bnb​​u[k−nb​]

这是一个线性回归。堆叠 NNN 个数据点，参数从一次最小二乘求解中得出。无需迭代。没有局部极小值。一步得到全局最优。

代价： 当噪声实际上不是通过 1/A(q−1)1/A(q^{-1})1/A(q−1) 进入时，ARX是有偏的。偏差可能很大——即使有无限数据，估计值也收敛到错误值。

何时使用ARX： 当你想要快速的结果且没有强烈的噪声着色时。对任何数据的首次处理。对许多控制应用来说足够好。如果模型阶次足够高，ARX可以任意好地逼近任何线性系统（偏差随 na,nbn_a, n_bna​,nb​ 增加而缩小）。

4.2 ARMAX：噪声有自己的动态 ​

ARMAX = 带滑动平均噪声的ARX（ARX with Moving Average noise）：

A(q−1)y[k]=B(q−1)u[k]+C(q−1)e[k]A(q^{-1}) y[k] = B(q^{-1}) u[k] + C(q^{-1}) e[k]A(q−1)y[k]=B(q−1)u[k]+C(q−1)e[k]

其中 C(q−1)=1+c1q−1+⋯+cncq−ncC(q^{-1}) = 1 + c_1 q^{-1} + \cdots + c_{n_c} q^{-n_c}C(q−1)=1+c1​q−1+⋯+cnc​​q−nc​。

噪声有了自己的滤波器 C(q−1)C(q^{-1})C(q−1)，独立于 A(q−1)A(q^{-1})A(q−1)。这更现实：测量噪声通常具有与对象动态不同的频谱特性。

预测器变为：

y^[k]=B(q−1)C(q−1)u[k]+C(q−1)−A(q−1)C(q−1)y[k]\hat{y}[k] = \frac{B(q^{-1})}{C(q^{-1})} u[k] + \frac{C(q^{-1}) - A(q^{-1})}{C(q^{-1})} y[k]y^​[k]=C(q−1)B(q−1)​u[k]+C(q−1)C(q−1)−A(q−1)​y[k]

这关于参数是非线性的（cic_ici​ 出现在分母中）。你需要迭代优化——通常是预测误差最小化（PEM, Prediction Error Minimization）——这意味着局部极小值、初始化敏感性和更多计算。

何时使用ARMAX： 当噪声频谱明显不同于对象频谱，且你需要准确的参数估计（而不仅仅是好的预测）时。常见于计量经济学，在控制中较少使用，因为OE通常更受青睐。

4.3 OE：输出误差——控制工程师真正想要的 ​

OE = 输出误差（Output Error）。噪声在对象动态之后进入：

y[k]=B(q−1)F(q−1)u[k]+e[k]y[k] = \frac{B(q^{-1})}{F(q^{-1})} u[k] + e[k]y[k]=F(q−1)B(q−1)​u[k]+e[k]

其中 F(q−1)=1+f1q−1+⋯+fnfq−nfF(q^{-1}) = 1 + f_1 q^{-1} + \cdots + f_{n_f} q^{-n_f}F(q−1)=1+f1​q−1+⋯+fnf​​q−nf​。注意：使用 F(q−1)F(q^{-1})F(q−1) 而不是 A(q−1)A(q^{-1})A(q−1) 来强调它是对象分母，不是噪声分母。

噪声在输出端是白色的——不相关的、诚实的测量噪声。这是大多数控制应用的物理自然假设。

预测器是仿真输出，而不是一步前向预测：

y^[k]=B(q−1)F(q−1)u[k]\hat{y}[k] = \frac{B(q^{-1})}{F(q^{-1})} u[k]y^​[k]=F(q−1)B(q−1)​u[k]

这关于参数也是非线性的。 预测器涉及过去的仿真输出，而不是过去的测量输出。你需要迭代PEM。

何时使用OE： 当你关心模型的仿真特性时（控制设计时你确实关心）。OE直接最小化仿真误差。ARX最小化一步前向预测误差——这可能产生一步前向预测好但长时间仿真差的模型。对于MPC，你需要一个仿真好的模型。使用OE。

6. PRBS设计：如何激励系统 ​

你不能从输入从未改变的数据中辨识系统。你需要持续激励。输入频谱必须在对象有动态的所有频率上有功率。

6.1 为什么用伪随机二进制 ​

PRBS（伪随机二进制序列，Pseudo-Random Binary Sequence）在两个电平（+A,−A+A, -A+A,−A）之间切换，模式看起来随机但实际是确定性的、可重复的。它由带反馈的移位寄存器生成：

6.2 多长，多快 ​

法则1——周期 > 建立时间。 PRBS周期必须超过对象的建立时间。否则，对象在转换之间永远达不到稳态，你无法辨识直流增益。对于建立时间 Tsettle≈0.1T_{\text{settle}} \approx 0.1Tsettle​≈0.1 s 的电机，需要：

7. 模型阶次选择：一门艺术 ​

你事先不知道 na,nbn_a, n_bna​,nb​。你必须选择它们。

7.1 信息准则 ​

拟合递增阶次的ARX模型。对每个模型，计算：

AIC（赤池信息准则，Akaike Information Criterion）：

AIC=Nln⁡(σ^2)+2p\text{AIC} = N \ln(\hat{\sigma}^2) + 2pAIC=Nln(σ^2)+2p

BIC（贝叶斯信息准则，Bayesian Information Criterion，也称MDL——最小描述长度）：

BIC=Nln⁡(σ^2)+pln⁡(N)\text{BIC} = N \ln(\hat{\sigma}^2) + p \ln(N)BIC=Nln(σ^2)+pln(N)

其中 p=na+nbp = n_a + n_bp=na​+nb​ 是参数数量，σ^2\hat{\sigma}^2σ^2 是残差方差。

AIC和BIC以不同方式惩罚复杂度：BIC惩罚更重（通过 ln⁡N\ln NlnN），对大 NNN 更偏好简单模型。两者都在拟合质量与参数数量之间平衡。

绘制AIC随模型阶次变化的曲线。最小值是你的候选。但不要只选最小值——寻找"拐点"，即添加更多参数不再有显著帮助的地方。

7.2 过拟合的危险 ​

这是一个困住了所有人的陷阱。用1000个数据点拟合一个20阶ARX模型：

σ^train2=0.0003(看起来极好！)\hat{\sigma}^2_{\text{train}} = 0.0003 \quad \text{(看起来极好！)}σ^train2​=0.0003(看起来极好！)

现在计算验证集上的仿真误差：

RMSEval=0.47(糟糕)\text{RMSE}_{\text{val}} = 0.47 \quad \text{(糟糕)}RMSEval​=0.47(糟糕)

发生了什么？20阶模型有40个参数。1000个数据点，每个参数只有25个点。模型拟合了噪声，而不是信号。它记住了训练数据，但对系统一无所知。

这就是偏差-方差权衡（Bias-Variance Trade-off）：低阶模型偏差高（灵活性不足导致的系统误差）但方差低（跨不同数据集稳定）。高阶模型偏差低但方差高——它们随不同数据实现剧烈变化。

过拟合的普遍标志： 优秀的一步前向预测，糟糕的多步仿真。模型从真实的 y[k]y[k]y[k] 完美预测 y[k+1]y[k+1]y[k+1]——因为它记住了噪声模式。但当你仿真时（将预测输出反馈作为输入），误差累积并爆炸。这就是为什么OE验证是必不可少的：仿真模型，不要只做一步预测。

8. 验证：你的模型好不好？ ​

拟合训练数据的模型不一定是好模型。通过验证测试的模型才是。

8.3 交叉验证：金标准 ​

分割数据：70%用于辨识，30%用于验证。在辨识集上拟合。然后在验证集上使用仿真（不是一步前向预测）评估：

永远不要在训练数据上验证。这是系统辨识的基本规则。训练拟合总是随模型阶次提高而改善。验证拟合先达到峰值，然后随过拟合而退化。峰值就是你的模型阶次。

9.3 实际答案 ​

对于本项目使用的电机模型，连续时间参数被选择为物理上合理的，而不是从硬件辨识的。但如果你有一个真实的电机，工作流程将是：

  1. 施加PRBS电压信号，记录位置
  2. 通过最小二乘拟合ARX(2,2) → a^1,a^2,b^1,b^2\hat{a}_1, \hat{a}_2, \hat{b}_1, \hat{b}_2a^1​,a^2​,b^1​,b^2​

模型只需要好到足以控制即可。JJJ（惯量）5%的误差意味着LQR增益次优几个百分点——不是灾难性的。系统辨识是鲁棒的：你不需要完美，你需要的是足够。

10. 为什么辨识重要：GIGO ​

垃圾进，垃圾出（Garbage In, Garbage Out）。 这不是口号——这是定理。如果你的模型是错的，你的控制器为错误的被控对象做优化。失配可能导致：

  • 迟缓响应： 控制器以为对象比实际更重，所以过于保守
  • 振荡： 控制器以为对象响应比实际更快，所以过度驱动
  • 稳态误差： 错误的直流增益意味着前馈项是错的
  • 不稳定： 最坏情况——控制器在真实对象有180°相位滞后而模型未捕获的频率上施加控制

本项目中的每个控制器——servo_motor_pid.html 中的PID、lqr_explorer.html 中的LQR、servo_qp_mpc.html 中的MPC——都是为参数 R=2.0 ΩR = 2.0\ \OmegaR=2.0 Ω、L=0.005L = 0.005L=0.005 H、Kt=0.12K_t = 0.12Kt​=0.12 N·m/A、J=0.0001J = 0.0001J=0.0001 kg·m²、B=0.0005B = 0.0005B=0.0005 N·m·s/rad 的对象设计的。

如果真实电机的 J=0.0002J = 0.0002J=0.0002（惯量翻倍），LQR增益过于激进约 2\sqrt{2}2​ 倍。响应过冲。如果 R=4.0 ΩR = 4.0\ \OmegaR=4.0 Ω（电阻翻倍），电流环带宽减半——高频性能退化。这些都是系统辨识在你浪费时间为一个不存在的电机整定控制器之前就能捕获的真实效应。
