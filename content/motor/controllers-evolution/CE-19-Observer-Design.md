# CE-19: 观测器设计——从状态反馈到输出反馈的桥梁

**副标题：Observer Design: Bridging State Feedback to Output Feedback**
**难度：** 
**适用对象：** 控制理论学习者、电机控制工程师
**前置知识：** CE-12（LQR与状态空间方法）

---

## 1.  核心摘要

LQR给你 $u = -Kx$，但你永远无法测量 $x$。你只能通过有噪声、有延迟、不完整的传感器测量 $y = Cx$。观测器（Observer）不是附加组件——它是控制器的一半。本文从开环仿真的失败出发，详解Luenberger观测器的校正机制、极点配置原则、卡尔曼滤波器的统计最优性、控制与估计的对偶性、分离原理及其失效条件，以及实际工程中的传感器偏置、测量丢失和观测器饱和等关键问题。

**认知挂钩：** 观测器是将数学控制器连接到物理对象的机制——没有它，状态反馈只是一个美丽的虚构。

---

## 2. 状态反馈核心的谎言

每个状态空间控制器——LQR、极点配置、MPC——都始于同一个假设：**你知道完整的状态向量 $x$。** 控制律是 $u = -Kx$。它是一个点积。它优美、最优、有保证（LQR保证≥60°相位裕度），但它建立在一个虚构之上。

现实中，你永远没有完整的状态。传感器告诉你 $y$，不是 $x$：

- **你测量位置，不测量速度。** 正交编码器给你 $\theta$。要得到 $\dot{\theta}$，你需要微分——在频域中这会以 $\omega$ 倍放大噪声。在10 kHz采样率下，编码器量化噪声微分成"速度"后，不加重度滤波就无法使用。
- **你测量一个温度，不是整个温度场。** 反应器中一个点的热电偶无法告诉你10 cm外的温度、温度梯度或热通量。但热PDE有数百个状态。
- **你测量加速度，不是姿态。** IMU给你加速度计和陀螺仪读数。横滚和俯仰角是通过积分陀螺速率并与加速度计的重力向量融合*推断*出来的——那就是一个观测器。

把 $y$ 当作 $x$ 使用在两个方向上都是错误的。首先，$y$ 是低维的——$C$ 将状态投影到传感器能看到的范围。其次，$y$ 是被污染的——传感器噪声、量化、通信延迟。将 $u = -Ky$ 送入你精心设计的LQR，得到的是一个既不最优、在很多情况下也不稳定的控制器。

**观测器就是答案。** 它使用对象模型从 $y$ 和 $u$ 重构 $\hat{x}$。然后控制器把 $\hat{x}$ 当作 $x$ 使用。这就是**输出反馈（Output Feedback）**：测量 $y$，估计 $x$，用 $\hat{x}$ 控制。

---

## 3. 开环仿真：为什么需要校正

最简单的想法：在软件中运行对象模型的一个副本。

$$\hat{x}_{k+1} = A \hat{x}_k + B u_k$$

你知道 $u_k$（你计算了它）。你知道 $A$ 和 $B$（来自模型）。从某个猜测开始 $\hat{x}_0$，让模型运行。

这能工作——大约三个时间步。然后三件事毁了它：

1. **未知初始条件。** 对象从某个你不知道的 $x_0$ 开始。如果 $\hat{x}_0 \neq x_0$，估计从一开始就是错的，而且错误永远不会消失，因为没有校正机制。
2. **模型失配。** $A$ 和 $B$ 是近似值。真实电机有摩擦、齿槽转矩、发热导致的参数漂移。这些未建模动态导致 $\hat{x}$ 随时间偏离 $x$。
3. **扰动。** 意外的负载转矩、阵风、电压跌落——这些以开环模型看不到的方式改变 $x$。

开环仿真器积分误差，不校正误差。我们需要一种方法来**用测量值将估计拉向真值**。

---

## 4. Luenberger观测器：运行模型，用测量校正

David Luenberger（1964）有关键洞察。运行模型，但添加一个与**测量误差**成正比的校正项——你实际测量的（$y_k$）与模型预测你应该测量的（$C\hat{x}_k$）之间的差值：

$$\hat{x}_{k+1} = \underbrace{A \hat{x}_k + B u_k}_{\text{预测（开环）}} + \underbrace{L\,(y_k - C \hat{x}_k)}_{\text{校正}}$$

信号 $y_k - C\hat{x}_k$ 是**新息（Innovation）**——你的模型没有预测到的那部分测量。如果模型完美且 $\hat{x} = x$，新息为零（除了测量噪声）。如果 $\hat{x}$ 是错的，新息告诉你*方向*和*程度*。

$L$ 是**观测器增益矩阵**。它决定你多信任测量值vs模型：

- $L$ 大 → 重度信任测量值，收敛快，但放大传感器噪声
- $L$ 小 → 信任模型，平滑噪声，但收敛慢
- $L = 0$ → 开环仿真，无校正

误差动态说明了问题。定义 $e_k = x_k - \hat{x}_k$：

$$e_{k+1} = x_{k+1} - \hat{x}_{k+1} = (A x_k + B u_k) - \big(A \hat{x}_k + B u_k + L(C x_k - C \hat{x}_k)\big)$$
$$e_{k+1} = (A - LC)\, e_k$$

观测器误差按矩阵 $(A - LC)$ 的规律演化。如果 $(A - LC)$ 的所有特征值都在单位圆内（离散时间），误差收敛到零**无论初始猜测如何**。观测器是稳定的。收敛速率取决于这些特征值在单位圆内有多深。

在连续时间下，Luenberger观测器为：

$$\dot{\hat{x}} = A \hat{x} + B u + L (y - C \hat{x})$$

误差动态为 $\dot{e} = (A - LC) e$。稳定性要求 $(A - LC)$ 的所有特征值具有负实部。

## 5. 观测器极点配置：比控制器快，但不要太快

设计 $L$ 是一个极点配置问题。$(A - LC)$ 的特征值是**观测器极点**——它们决定估计收敛的速度。

经验法则：**将观测器极点放在控制器极点的2–5倍快处。**

| 如果控制器极点在... | 将观测器极点放在... | 理由 |
|---|---|---|
| $s = -10$ | $s = -20$ 到 $-50$ | 观测器在控制器的瞬态变得重要之前收敛 |
| $s = -2 \pm j3$ | $s = -4 \pm j6$ 到 $-10 \pm j15$ | 估计误差以2–5倍于闭环响应的速度衰减 |

为什么"更快"是好的：

- 控制器作用于 $\hat{x}$。如果 $\hat{x}$ 还在收敛而对象已经在响应，你在控制一个移动目标——有效动态退化。
- 启动时，$\hat{x}$ 从错误值开始。你希望它在参考阶跃到达之前收敛，或至少在前几个采样周期内。
- 对于LQR，分离原理（第7节）保证闭环极点是控制器极点（来自 $A-BK$）和观测器极点（来自 $A-LC$）的**并集**。如果观测器极点快得多，闭环响应由控制器极点主导——正是你设计 $K$ 所要的。

为什么"太快"是坏的：

- 快速观测器极点 → 大的 $L$ 增益 → 校正项 $L(y_k - C\hat{x}_k)$ 放大测量噪声。传感器噪声直接进入估计值，被 $L$ 缩放。
- 快速极点 → 宽带宽 → 观测器追踪高频传感器伪影，产生噪声 $\hat{x}$，控制器随后作用于它。你得到抖动的控制信号、增加的执行器磨损，以及激发未建模的高频对象模态。
- 存在一个根本权衡：**收敛速度 vs. 噪声灵敏度。** 卡尔曼滤波器（第6节）最优地解决了这个问题。

**通过极点配置计算 $L$：**

$(A - LC)$ 的特征值与 $(A^T - C^T L^T)$ 的特征值相同。这与控制器极点配置问题 $(A^T - C^T K^T)$ 的形式完全相同——对 $A^T - C^T \tilde{K}$ 配置极点，其中 $\tilde{K} = L^T$。这就是**对偶性（Duality）**（第6节）：通过对转置系统应用极点配置来设计 $L$。

在MATLAB中：`L = place(A', C', poles)'`——转置，为对偶系统设计"控制器"，再转置回来。

## 6. 卡尔曼滤波器：当你知道噪声统计特性时

Luenberger观测器手动配置极点。卡尔曼滤波器（Rudolf Kalman, 1960）通过提出一个统计问题来**最优地**选择 $L$：

> 给定对象被随机过程噪声 $w_k \sim \mathcal{N}(0, Q)$ 驱动，传感器被测量噪声 $v_k \sim \mathcal{N}(0, R)$ 污染，什么增益 $L_k$ 能最小化每一步的期望平方估计误差 $\mathbb{E}[\|x_k - \hat{x}_k\|^2]$？

系统模型：

$$x_{k+1} = A x_k + B u_k + w_k, \qquad w_k \sim \mathcal{N}(0, Q)$$
$$y_k = C x_k + v_k, \qquad v_k \sim \mathcal{N}(0, R)$$

$Q$ 是**过程噪声协方差**——你多信任模型。大 $Q$ 意味着模型不可靠（未建模动态、扰动）；滤波器应更信任测量值。

$R$ 是**测量噪声协方差**——传感器有多噪声。大 $R$ 意味着传感器差；滤波器应更信任模型。

卡尔曼滤波器与Luenberger观测器有**完全相同的结构**：

$$\hat{x}_{k+1} = A \hat{x}_k + B u_k + \underbrace{L_k}_{\text{最优增益}} (y_k - C \hat{x}_k)$$

但 $L_k$ 不是常数——它是时变的，由**前向Riccati递推**计算：

1. **预测**误差协方差：$P_{k+1}^- = A P_k A^T + Q$
2. **计算**最优增益：$L_k = P_k^- C^T (C P_k^- C^T + R)^{-1}$
3. **更新**协方差：$P_k = (I - L_k C) P_k^-$

在稳态下，$P_k \to P_\infty$，$L_k \to L_\infty$，滤波器变为具有卡尔曼增益的稳态Luenberger观测器。稳态协方差 $P_\infty$ 求解**滤波代数Riccati方程（FARE, Filter Algebraic Riccati Equation）**：

$$P = A P A^T - A P C^T (C P C^T + R)^{-1} C P A^T + Q$$

与DARE（控制器Riccati）比较：

| | 控制（LQR） | 估计（卡尔曼） |
|---|---|---|
| **Riccati变量** | $P$（代价函数） | $P$（误差协方差） |
| **方向** | 时间后向 | 时间前向 |
| **$A$ 的出现形式** | $A^T P A$ | $A P A^T$ |
| **权重** | $Q$ = 状态代价，$R$ = 控制代价 | $Q$ = 过程噪声，$R$ = 测量噪声 |
| **增益公式** | $K = (R + B^T P B)^{-1} B^T P A$ | $L = A P C^T (C P C^T + R)^{-1}$ |

卡尔曼增益 $L$ 从 $Q$ 和 $R$ 中产生，就像LQR增益 $K$ 从 $Q$ 和 $R$ 中产生一样。在两种情况下，你指定你关心什么，Riccati方程给你最优增益。区别：LQR从终端代价*后向*求解；卡尔曼从初始不确定性*前向*求解。

**实践中整定卡尔曼滤波器：**

你几乎永远不知道 $Q$ 和 $R$ 的确切值。它们成为**设计旋钮**：

- $Q/R$ 比值大 → 信任测量值，收敛更快，估计更噪声
- $Q/R$ 比值小 → 信任模型，估计更平滑，收敛更慢
- $Q$ 的对角元素对应你预期每个状态被未知效应扰动的程度。电机的速度状态比位置状态获得更大的 $Q$ 元素（速度受负载转矩影响；位置只是积分速度，模型处理得很好）。
- $R$ 的对角元素对应传感器噪声方差。量化为 $\pm 1$ 计数的编码器取 $R = 1/12$（均匀分布方差）。10 mV RMS噪声的模拟传感器取 $R = (0.01)^2$。

## 7. 对偶性：估计与控制是同一个问题的转置

控制与估计之间存在深层的结构关系。数学是相同的——你只需转置矩阵并交换时间方向。

**原始问题（控制）：** 设计 $K$ 使 $(A - BK)$ 的特征值在单位圆内。

$$x_{k+1} = A x_k + B u_k, \qquad u_k = -K x_k$$
$$x_{k+1} = (A - BK) x_k$$

**对偶问题（估计）：** 设计 $L$ 使 $(A - LC)$ 的特征值在单位圆内。

$$e_{k+1} = (A - LC) e_k$$

但 $(A - LC)$ 的特征值恰好是 $(A^T - C^T L^T)$ 的特征值。所以为 $(A, C)$ 设计观测器就是**恰好**为转置系统 $(A^T, C^T)$ 设计控制器：

| | $(A, B)$ 的控制器 | $(A, C)$ 的观测器 |
|---|---|---|
| **系统矩阵** | $A$ | $A^T$ |
| **输入矩阵** | $B$ | $C^T$ |
| **增益** | $K$ | $L^T$ |
| **闭环** | $A - BK$ | $A^T - C^T L^T$ |
| **Riccati** | $P = A^T P A - \ldots + Q$ | $P = A P A^T - \ldots + Q$ |

这种对偶性意味着：

- 任何控制器设计算法（极点配置、LQR、H∞）都可以通过转置系统复用于观测器设计。
- MATLAB命令 `dlqr(A, B, Q, R)` 给你 $K$。`dlqr(A', C', Q, R)` 给你 $L^T$——然后 $L$ 是其转置。卡尔曼增益就是对偶系统的LQR增益。
- 分离原理（第8节）是直接结果：组合系统的闭环特征值是 $(A-BK)$ 的特征值与 $(A-LC)$ 的特征值的并集。控制器和观测器极点不交互——它们被对偶性解耦。

## 8. 分离原理：独立设计，组合使用

分离原理是使输出反馈可处理的定理。它说：

> 像拥有全状态反馈一样设计 $K$。像控制器不存在一样设计 $L$。然后组合：$u_k = -K \hat{x}_k$，其中 $\hat{x}$ 来自观测器。闭环系统稳定，其极点恰好是控制器极点（来自 $A-BK$）加上观测器极点（来自 $A-LC$）。

**为什么有效。** 写出组合状态 $[x_k; e_k]$，其中 $e_k = x_k - \hat{x}_k$：

$$x_{k+1} = A x_k + B(-K \hat{x}_k) = A x_k - B K (x_k - e_k) = (A - BK) x_k + BK e_k$$
$$e_{k+1} = (A - LC) e_k$$

矩阵形式：

$$\begin{bmatrix} x_{k+1} \\ e_{k+1} \end{bmatrix} = \begin{bmatrix} A - BK & BK \\ 0 & A - LC \end{bmatrix} \begin{bmatrix} x_k \\ e_k \end{bmatrix}$$

块三角结构意味着特征值是对角块特征值的并集：$\text{eig}(A-BK) \cup \text{eig}(A-LC)$。控制器和观测器在误差动态中**解耦**。右上角的 $BK$ 项意味着估计误差*确实*影响状态——但它不影响稳定性，因为误差本身是稳定的并衰减到零。

**何时成立（线性情况）：**

- 无约束的线性时不变系统：分离原理是精确的、可证明的。
- LQG（线性二次高斯）：LQR控制器 + 卡尔曼滤波器 = 高斯噪声线性系统的最优输出反馈。你通过DARE设计 $K$，通过FARE设计 $L$，组合它们。那就是LQG。

**何时失效：**

| 场景 | 会发生什么 |
|---|---|
| **执行器饱和** | $u_k = \text{sat}(-K \hat{x}_k)$。实际 $u_k$ 与观测器假设的不同。模型失配 → 估计误差不按预测衰减。积分饱和和观测器饱和叠加。 |
| **非线性对象** | 误差动态不再是 $\dot{e} = (A - LC)e$——它涉及 $e$ 的高阶项。分离不成立。扩展卡尔曼滤波器（EKF）在每步线性化，但分离只是近似的。 |
| **模型失配** | 如果观测器的 $(A, B, C)$ 与真实对象不同，误差动态由失配驱动。分离原理假设完美的模型知识。 |
| **过程噪声与测量噪声相关** | 卡尔曼的推导假设 $w_k$ 和 $v_k$ 独立。如果它们相关（例如振动源同时影响对象和传感器），分离对稳定性成立但最优性丧失。 |

**实践要点：** 对于远离饱和的线性系统，分离原理有效，你可以将控制器设计和观测器设计视为独立任务。这就是为什么LQR + Luenberger是运动控制、航空航天和过程控制中的标准架构。对于非线性系统或饱和系统，你需要更复杂的组合（例如移动时域估计 + 非线性MPC）。

## 9. 实践中的观测器：教科书不告诉你的事

### 9.1 模型永远是错的

观测器并行运行一个模型。如果 $A$ 和 $B$ 是错的，预测步骤产生垃圾。校正项 $L(y - C\hat{x})$ 可以补偿——但只在观测器带宽内。慢参数漂移（电机发热）观测器可以追踪。未建模的非线性（静摩擦、间隙）它不能——它们产生持续的新息，观测器试图校正，导致有偏估计。

**对策：** 将参数不确定性视为过程噪声。增大 $Q$ 中相应的对角元素（卡尔曼）或放慢观测器极点（Luenberger）。你会得到一个更平滑但滞后于现实的估计——比快速但错误的估计更好的权衡。

### 9.2 传感器偏置

大多数传感器有直流偏移。陀螺有随温度漂移的偏置。加速度计有取决于安装对准的重力分量。编码器有未知的零位。

新息 $y_k - C\hat{x}_k$ 包含一个持续的偏置项。观测器无法区分传感器偏置和真正的状态误差——两者产生相同的新息特征。结果：估计收敛到有偏值。

**对策：增广状态。** 将偏置作为未知常数状态添加：

$$x_{\text{aug}} = \begin{bmatrix} x \\ b \end{bmatrix}, \qquad b_{k+1} = b_k$$

观测器现在同时估计对象状态和传感器偏置。这就是**偏置估计（Bias Estimation）**，是姿态估计（估计陀螺偏置和姿态四元数）和GPS/INS组合导航中的标准方法。

### 9.3 测量丢失

传感器会失效。GPS在隧道中丢失信号。编码器跳过计数。相机被遮挡。观测器必须处理没有测量的时期。

在测量丢失期间，观测器开环运行：$\hat{x}_{k+1} = A\hat{x}_k + Bu_k$（该采样点设 $L = 0$）。误差按 $e_{k+1} = A e_k$ 增长。如果 $A$ 稳定（对象本身稳定），误差有界。如果 $A$ 不稳定（倒立摆、火箭），误差无界增长——你需要备用传感器或不同策略。

**多速率卡尔曼滤波器**处理以不同速率到达的测量。GPS 1 Hz、IMU 100 Hz、相机 30 Hz。滤波器以IMU速率（100 Hz）预测，只在测量到达时应用校正步骤。每个传感器有自己的 $C$ 矩阵和 $R$ 协方差。这是每个无人机飞行控制器的架构。

### 9.4 观测器饱和

当执行器饱和时，实际 $u_k$ 小于命令值。观测器用命令的 $u_k$ 运行——但对象收到了更少。新息尖峰。观测器过度校正。估计发散。

**对策：** 将**实际**（饱和后的）$u_k$ 馈入观测器，而不是命令的 $u_k$。这是观测器抗饱和（Anti-windup），与积分器抗饱和同样重要。任何有饱和的系统都必须这样做。

## 10. 与本项目的联系

| 文档 | 观测器联系 |
|---|---|
| `lqr_explorer.html` | 假设全状态反馈——$u = -Kx$，位置和速度都"被测量"。这在教学上是清晰的，但在物理上不可能。要让LQR探索器在真实硬件上工作，你需要在编码器读数和LQR增益之间添加Luenberger观测器，从位置估计速度。 |
| `servo_motor_pid.html` | PID直接使用 $y$（位置）。微分作用通过差分近似速度——这是一个简单的观测器（模型 = 位置的零阶保持）。增大 $K_d$ 时看到的噪声放大就是观测器问题的缩影：差的噪声模型，临时滤波。 |
| `servo_qp_mpc.html` | MPC在预测模型中使用全状态。真实的MPC部署在上游运行卡尔曼滤波器——MPC的初始条件是估计器的 $\hat{x}_{k \mid k}$，而不是 $x_k$（未知）。 |
| `core_problems_controller_design.md` | 问题#1（测量）——观测器是解决方案。该文档中的表格映射了整个测量问题空间：卡尔曼、Luenberger、Smith预测器。本文深入探讨了前两个。 |
| `care_vs_dare.md` | DARE求解LQR中的 $K$。FARE（滤波ARE）求解卡尔曼滤波器中的 $P$——相同的代数结构，转置。DARE到FARE的对偶性是控制理论中最优美的结果之一。 |
| `trajectory_tracking_lqr_mpc.md` | 轨迹跟踪需要知道当前状态以计算与参考轨迹的误差。观测器从测量中提供该状态。没有它，轨迹跟踪是开环预测。 |
| `bellman_to_lqr.md` | 产生LQR的DP递推从全状态知识开始。观测器是使基于DP的控制从部分测量可实现的缺失环节。 |

**更深的模式：** 本项目中的每个控制器——PID、LQR、MPC——都需要知道状态。PID之所以能直接使用 $y$，是因为工业过程通常是一阶的（位置*就是*状态，没有隐藏动态）。LQR明确暴露了差距：它要求 $x$，迫使你面对测量问题。MPC的预测时域使差距更大：错误的初始状态 → 错误的预测 → 错误的控制。观测器不是可选的基础设施——它是将数学控制器连接到物理对象的机制。

## 11. 延伸阅读

**基础——原始论文：**
- Luenberger, D.G. (1964). "Observing the State of a Linear System." *IEEE Trans. Military Electronics*, 8(2), 74–80. —— 引入观测器结构的论文。出奇地易读。
- Kalman, R.E. (1960). "A New Approach to Linear Filtering and Prediction Problems." *ASME J. Basic Engineering*, 82(1), 35–45. —— 卡尔曼滤波器。密集但有回报。附录证明了增益的最优性。

**教科书——从应用到理论：**
- Franklin, G.F., Powell, J.D., & Workman, M.L. (1998). *Digital Control of Dynamic Systems*, 3rd ed. Ellis-Kagle Press. —— 第8–9章覆盖观测器设计和分离原理，有计算示例。最实用的处理。
- Åström, K.J. & Wittenmark, B. (1997). *Computer-Controlled Systems*, 3rd ed. Prentice-Hall. —— 第6章关于带观测器的极点配置设计；第7章关于卡尔曼滤波器。
- Anderson, B.D.O. & Moore, J.B. (1979). *Optimal Filtering*. Prentice-Hall. —— 卡尔曼滤波器的权威文本。严谨、完整。第3–4章覆盖离散时间滤波器及其性质。

**对偶性与分离原理：**
- Doyle, J.C., Francis, B.A., & Tannenbaum, A.R. (1992). *Feedback Control Theory*. Macmillan. —— 第6章在Youla参数化框架内将分离原理呈现为统一结果。
- Zhou, K., Doyle, J.C., & Glover, K. (1996). *Robust and Optimal Control*. Prentice-Hall. —— 第14章关于LQG和分离原理；完整一般性的数学结构。

**实践估计——实现导向：**
- Grewal, M.S. & Andrews, A.P. (2014). *Kalman Filtering: Theory and Practice Using MATLAB*, 4th ed. Wiley. —— 实现细节：协方差传播、数值稳定性（Joseph形式、UD分解、平方根滤波）、多速率和序贯更新。
- Brown, R.G. & Hwang, P.Y.C. (2012). *Introduction to Random Signals and Applied Kalman Filtering*, 4th ed. Wiley. —— 易读的入门，有MATLAB代码。传感器偏置估计和GPS/INS组合导航的良好处理。

**运动控制中的观测器：**
- Ellis, G. (2012). *Control System Design Guide*, 4th ed. Butterworth-Heinemann. —— 第13章关于伺服驱动中的Luenberger观测器：从编码器位置估计速度、实用整定规则、加速度前馈。
