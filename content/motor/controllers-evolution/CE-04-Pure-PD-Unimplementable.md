# CE-04: 纯PD控制的不可实现性

**副标题：理论说纯PD非因果且不可实现——但你的MCU代码却跑得好好的，两者都对**
**难度：** ★★★☆☆ 中等
**适用对象：** 控制理论学习者、电机控制工程师
**前置知识：** CE-03

---

## 1. 📌 核心摘要

纯PD控制器 $C(s) = K_p + K_d s$ 是非真（Improper）传递函数——分子阶次高于分母，意味着无限高频增益和因果性违反。理论上它不可能存在。然而嵌入式工程师在STM32上写 `D_out = Kd * (error - last_error)` 却工作正常，原因在于硬件中存在隐式低通滤波：采样率上限、电机电感与惯性的机械滤波、ADC前端的RC滤波、量化噪声地板。这些物理约束使纯微分不可能真正实现，但也恰好阻止了其有害效果。理解这一点，才能在需要显式滤波D项的场合（无人机、直驱电机、高分辨率编码器）做出正确设计。

**认知挂钩：** 你的"纯微分"代码之所以能用，不是因为你实现了纯微分，而是因为物理世界不允许纯微分存在。

---

## 1. 理论论证：非因果与非真

在拉普拉斯域中，纯PD控制器为：

$$C(s) = K_p + K_d s$$

传递函数**分子阶次为1，分母阶次为0**。这是一个*非真传递函数（Improper Transfer Function）*——分子阶次高于分母。

物理可实现的系统必须是**真（Proper）**的：分母阶次 ≥ 分子阶次。原因是因果性（Causality）。微分运算：

$$s X(s) \quad\longleftrightarrow\quad \frac{dx}{dt}$$

需要知道瞬时变化率。在频域中，$s = j\omega$。当 $\omega \to \infty$ 时，幅值 $|j\omega| \to \infty$。理想微分器具有**无限带宽**——它对阶跃的响应是一个冲激函数，需要无限能量和无限压摆率（Slew Rate）。没有任何物理组件（运放、晶体管、机械连杆）能做到这一点。

真传递函数的分母提供高频段的*滚降（Roll-off）*。纯PD缺少分母意味着没有滚降——增益无界攀升。

---

## 2. 工程论证：噪声放大

这是实际中真正致命的问题。

将 $s \to j\omega$。D项贡献：

$$|K_d \cdot j\omega| = K_d |\omega|$$

| 频率 $\omega$ | D项增益 |
|---|---|
| 1 rad/s | $K_d$ |
| 100 rad/s | $100 \cdot K_d$ |
| $10^4$ rad/s（16 kHz） | $10^4 \cdot K_d$ |
| $\to \infty$ | $\to \infty$ |

每个真实传感器信号都携带高频噪声——ADC的热噪声、附近开关转换器的EMI、通过机械结构耦合的振动、有限位深的量化误差。噪声幅度可能很小（几毫伏，一个ADC计数），但其频率内容可达数百kHz。

纯微分器将微小噪声乘以 $\omega$。在100 kHz处，1 mV的噪声尖峰变成628 V的控制命令。执行器饱和，电机尖叫，FET过热。这不是调参问题——这是结构性的。

**这就是为什么许多工业PID回路只用PI。** 它们完全禁用D项，以可靠性为代价接受较慢的响应，而不是冒噪声放大的风险。

---

## 3. 真正的解决方案：滤波PD（实用微分）

没有人部署纯PD。实际出货的是**滤波PD**——一个微分器级联一阶低通滤波器：

$$C(s) = K_p + \frac{K_d s}{1 + T_f s}$$

其中 $T_f$ 是滤波时间常数，有时表示为 $T_d / N$，$N = 5\sim20$。

现在分子阶次 = 1，分母阶次 = 1 → **真**。在低频段（$\omega \ll 1/T_f$）：

$$\frac{K_d s}{1 + T_f s} \approx K_d s$$

行为像纯微分器。在高频段（$\omega \gg 1/T_f$）：

$$\frac{K_d s}{1 + T_f s} \to \frac{K_d}{T_f}$$

增益**饱和**为常数 $K_d / T_f$。高频噪声被固定因子放大，而非被 $\omega$ 放大。噪声底噪升高——你仍需付出代价——但不会发散到无穷。

### 离散实现

在采样周期为 $T_s$ 的数字控制回路中，滤波微分是两步更新：

```c
// Kd*s/(1 + Tf*s) 的后向欧拉离散化
// D_state 是内部滤波器状态

D_state = D_state + (Ts / Tf) * (Kd * (error - prev_error) - D_state);
u = Kp * error + D_state;
```

这就是 `(error - last_error)` 乘以无限增益微分器与相同差分通过低通滤波器的区别。代码看起来相似——都使用 `error - last_error`——但滤波器状态限制了输出。

---

## 4. 那为什么我的裸机 `D_out = Kd*(error - last_error)` 能用？

每个嵌入式开发者都会问这个问题，答案揭示了一个重要事实：**你的硬件已经包含了隐式低通滤波器。** 你没有添加它们——它们一直都在。

### 4.1 采样周期 $T_s$ 是频率天花板

连续时间理论允许 $\omega \to \infty$。你的MCU定时器中断（例如1 kHz）限制了离散时间系统中能存在的频率。离散微分：

$$D[k] = K_d \frac{e[k] - e[k-1]}{T_s}$$

对任何有界输入序列都有有界输出。奈奎斯特频率 $f_s/2$ 是硬截止——高于它的频率无法表示。$e[k]$ 和 $e[k-1]$ 之差受信号在采样间最大压摆率限制，由于物理被控对象具有有限速度，该值是有界的。

**采样器本身充当抗混叠滤波器。** 高于奈奎斯特的频率被混叠，而非以无限增益通过。这本身就阻止了连续时间理论预测的无界放大。

### 4.2 电机是机械低通滤波器

假设你的微分项确实产生了尖峰高频电压命令。接下来会发生什么？

- **电气方面：** 电机绕组有电感 $L$。电流不能瞬时变化——$V = L\,di/dt$ 限制了压摆率。电感是一个截止频率 $\omega_c = R/L$ 的低通滤波器。
- **机械方面：** 转子有惯量 $J$。力矩产生角加速度 $\alpha = \tau/J$。1 ms的电压尖峰在下个采样到来之前几乎无法移动转子。典型舵机的机械时间常数 $\tau_m = J R / (K_t K_e)$ 为 10–100 ms——比控制回路慢一个数量级。

电机的传递函数 $P(s) = K / (s(Js + b)(Ls + R))$ 是严格真的（分母阶次3，分子阶次0）。在电气极点之后以 −60 dB/decade 滚降。高频控制命令在产生可观测运动之前就被机械衰减了。

### 4.3 传感器路径上的硬件滤波

在ADC值到达你的PID回路之前：

- 电位器或模拟输入引脚上的**RC滤波器**（通常 10 kΩ + 100 nF → $f_c \approx 160$ Hz）
- ADC采样保持电路中的**采样电容**
- 如果固件每个控制周期多次读取ADC，还有**过采样 + 平均**

即使你没有显式设计这些，大多数开发板和参考设计上都存在。进入 `error = setpoint - adc_value` 的信号已经是带限的。

### 4.4 量化使噪声触底

对于基于电位器的舵机，10位ADC和270°范围：

$$\text{分辨率} = \frac{270^\circ}{1024} \approx 0.26^\circ$$

小于0.26°的振动在ADC读数中产生**零变化**。量化充当死区——低于LSB的噪声永远到不了微分器。你的 `error - last_error` 大部分时间为0，只在轴实际移动时跳变±1个计数。

## 5. 直接差分何时会失败

隐式滤波在机械系统慢且传感器安静时有效。在以下情况下失效：

| 场景 | 失败原因 |
|---|---|
| **无人机飞控** | 机架轻（低惯量），电机转速10k+ RPM（快速响应），陀螺仪以8 kHz采样16位分辨率。机械滤波消失——500 Hz机架振动直接通过。没有D项LPF，ESC过热，无人机剧烈振荡。 |
| **音圈/直线电机平台** | 摩擦接近零，惯量低，带宽100+ Hz。执行器*可以*响应高频命令。微分噪声产生可听见的啸叫和微米级抖动。 |
| **高分辨率编码器** | 20位光学编码器可分辨亚角秒运动。量化不再使噪声触底——传感器好到能*看到*振动，D项将其放大。 |
| **极快控制回路** | 在20+ kHz采样率下，奈奎斯特上移。更多噪声频谱进入回路。采样器提供的免费滤波减少。 |
| **直驱电机（无减速箱）** | 减速箱将惯量乘以 $N^2$——100:1的减速箱给电机10,000倍的机械优势。直驱移除了这种滤波。每个力矩纹波都出现在输出中。 |

共同线索：**当机械时间常数接近控制回路周期时，隐式滤波消失。** 在 $\tau_m = 2$ ms的系统上运行1 ms控制回路，与在 $\tau_m = 100$ ms的系统上运行1 ms回路，本质上是不同的。

## 6. 深层要点："物理不可实现"到底意味着什么

这个表述是精确的，而非修辞。它同时意味着三件事：

1. **因果性。** 非真传递函数需要知道未来输入（时刻 $t$ 的微分依赖于 $t$ 和 $t + \varepsilon$ 处的信号）。没有物理设备可以违反因果性。

2. **能量。** 对阶跃求导需要无限瞬时功率。阶跃不连续性的能量分布在所有频率上；捕获全部能量意味着无限带宽，意味着无限能量。能量守恒禁止了它。

3. **近似始终存在。** 每个"纯"PD实现实际上都是滤波PD——只是滤波器由物理（电感、惯量、采样、量化）而非代码实现。问题从来不是*有没有*滤波器，而是隐式滤波器的截止频率是否适合你的应用。

理论没有错——它解释的是如果你移除所有物理约束会发生什么。你的MCU代码能用，是因为物理不允许你移除它们。

## 7. 实用建议

| 你的系统 | 建议 |
|---|---|
| **业余舵机，< 100 Hz回路** | 直接差分即可。机械部分滤波了10 Hz以上的一切。 |
| **带减速箱的直流电机，1 kHz回路** | 直接差分仍然可用。为安全起见在ADC上加移动平均滤波。 |
| **BLDC FOC，10 kHz电流环** | 滤波微分是必须的。$T_f = T_d / 10$ 是合理的起点。 |
| **无人机，8 kHz IMU** | 多级级联滤波是标配——D项一阶滤波，加上机架谐振处的陷波滤波器。这不是可选的。 |
| **高精度CNC** | D项通常完全避免。前馈 + PI 以零噪声放大完成工作。 |
