# CE-05: IP控制器——消除超调的比例项移位

**副标题：在PI控制器的参考输入端加一阶低通滤波器，你就得到了IP控制器——不是近似，而是精确等价**
**难度：**  中等
**适用对象：** 控制理论学习者、电机控制工程师
**前置知识：** CE-04

---

## 1.  核心摘要

标准PI控制器中，比例项作用于误差 $e = r - y$，在闭环传递函数分子中产生 $K_p s$ 零点，导致"比例冲击（Proportional Kick）"和超调。IP控制器将比例项从误差路径移到反馈路径（$-K_p y$），仅保留积分项作用于误差。结果是：闭环分母不变（极点、稳定性、扰动抑制完全相同），但分子中的 $K_p s$ 零点消失，阶跃响应从超调变为单调收敛。更深刻的是，在PI控制器参考输入端加一阶低通滤波器 $F(s) = 1/((K_p/K_i)s + 1)$ 与IP控制器**精确代数等价**——这揭示了二自由度（2-DOF）控制的核心架构。

**认知挂钩：** PI的超调不是调参失败，而是结构性缺陷——比例项通过同一误差信号同时看到参考和反馈，零点被"焊"进了拓扑。IP通过解耦两者来消除零点。

---

## 1. 问题：比例冲击

在标准PI控制器中，误差为 $E(s) = R(s) - Y(s)$——参考减反馈。控制输出为：

$$U(s) = \left(K_p + \frac{K_i}{s}\right) E(s) = K_p(R(s) - Y(s)) + \frac{K_i}{s}(R(s) - Y(s))$$

### 1.1 推导闭环传递函数

推导沿反馈回路的信号流进行。定义信号（省略 $(s)$ 以简化）：

- $R$：参考命令
- $Y$：被控对象输出（反馈）
- $E = R - Y$：跟踪误差
- $U$：控制器输出（控制量）
- $C$：控制器传递函数
- $P$：被控对象传递函数

**第一步——被控对象方程。** 输出是被控对象对控制信号的响应：

$$Y = P \cdot U$$

**第二步——控制器方程。** 控制信号是控制器对误差的响应：

$$U = C \cdot E$$

代入第一步：

$$Y = P \cdot C \cdot E$$

**第三步——误差定义。** 反馈控制将误差定义为参考减输出：$E = R - Y$。代入：

$$Y = P \cdot C \cdot (R - Y)$$

**第四步——合并 $Y$ 项。** 展开并将所有 $Y$ 项移到一边：

$$Y = P C R - P C Y \quad\Rightarrow\quad Y + P C Y = P C R \quad\Rightarrow\quad Y(1 + P C) = P C R$$

**第五步——通用反馈公式。** 除以 $(1 + PC)$：

$$T(s) = \frac{Y(s)}{R(s)} = \frac{P(s) C(s)}{1 + P(s) C(s)}$$

这是经典控制中最重要的公式。每个线性SISO反馈系统——PID、LQR、H∞——都归结为这个结构。

### 1.2 代入PI控制器

PI控制器的拉普拉斯形式为：

$$C(s) = K_p + \frac{K_i}{s} = \frac{K_p s + K_i}{s}$$

代入通用反馈公式：

$$T_{PI}(s) = \frac{P(s) \cdot \frac{K_p s + K_i}{s}}{1 + P(s) \cdot \frac{K_p s + K_i}{s}}$$

**消除嵌套分式。** 分子分母同乘 $s$：

- 分子：$P(s) \cdot (K_p s + K_i)$
- 分母：$s \cdot 1 + s \cdot \left[P(s) \frac{K_p s + K_i}{s}\right] = s + P(s)(K_p s + K_i)$

结果：

$$T_{PI}(s) = \frac{Y(s)}{R(s)} = \frac{P(s)(K_p s + K_i)}{s + P(s)(K_p s + K_i)}$$

### 1.3 零点现身

看分子：$K_p s + K_i$。$K_p s$ 项是一个**闭环零点**。当参考 $R(s)$ 阶跃时，$s R(s)$ 产生冲激类分量。比例增益 $K_p$ 放大瞬时误差并产生控制尖峰——**比例冲击**。结果是超调。

这不是调参失败。这是结构性的。零点被焊入了PI拓扑，因为比例项通过同一误差信号同时作用于参考*和*反馈。

---

## 2. IP控制器：将比例项与参考解耦

IP（Integral-Proportional）控制器通过一行结构性修改解决了这个问题：

| | PI | IP |
|---|---|---|
| **积分** | $K_i \int e\,dt$ | $K_i \int e\,dt$ |
| **比例** | $K_p e$ | $-K_p y$ |
| **微分** |（相同模式）|（相同模式）|

比例项仅作用于**反馈**，而非误差。积分器仍然作用于误差（以消除稳态误差）。控制律：

$$U(s) = \frac{K_i}{s}(R(s) - Y(s)) - K_p Y(s)$$

推导闭环传递函数：

$$T_{IP}(s) = \frac{Y(s)}{R(s)} = \frac{P(s) K_i}{s + P(s)(K_p s + K_i)}$$

比较 $T_{PI}$ 和 $T_{IP}$：

| | 分子 | 分母 |
|---|---|---|
| **PI** | $P(s)(K_p s + K_i)$ | $s + P(s)(K_p s + K_i)$ |
| **IP** | $P(s) K_i$ | $s + P(s)(K_p s + K_i)$ |

**分母完全相同。** 特征方程、极点位置和扰动抑制特性不变。唯一区别：分子失去了 $K_p s$ 零点。阶跃响应从超调变为单调——相同的稳定裕度，相同的刚度，零超调。

---

## 3. 滤波等价：PI + 低通 = IP

这是使IP控制器超越接线技巧的关键结果。

假设你无法修改控制器内部——PI结构已固化在固件中。取而代之，你在参考输入端放置滤波器 $F(s)$：$R^*(s) = F(s) R(s)$。滤波后的参考进入标准PI控制器。什么 $F(s)$ 能使整个系统等价于IP？

令滤波PI闭环等于IP闭环：

$$F(s) \cdot T_{PI}(s) = T_{IP}(s)$$

代入传递函数：

$$F(s) \cdot \frac{P(s)(K_p s + K_i)}{s + P(s)(K_p s + K_i)} = \frac{P(s) K_i}{s + P(s)(K_p s + K_i)}$$

约去公共分母和 $P(s)$：

$$F(s)(K_p s + K_i) = K_i$$

解 $F(s)$：

$$F(s) = \frac{K_i}{K_p s + K_i} = \frac{1}{\frac{K_p}{K_i} s + 1}$$

**$F(s)$ 是一阶低通滤波器**，时间常数 $\tau = K_p / K_i$——恰好是PI控制器的积分时间常数 $T_i$。截止频率：$\omega_c = K_i / K_p$。

这是精确的，不是近似。没有泰勒展开，没有"差不多"。代数完美对消。

---

## 4. 为什么外部滤波而不是重写控制器？

如果IP对阶跃响应更好，为什么不直接编码？

### 4.1 封闭系统

商用伺服驱动器、电机控制器和PLC功能块出厂时具有固定的PID/PI结构。你无法修改固件。你*可以*在参考信号进入控制器之前对其进行滤波。一阶IIR滤波器每个采样只需两次乘加——基本免费。

### 4.2 二自由度（2-DOF）设计

滤波等价揭示了2-DOF架构：

```text
    r ──→ [F(s)] ──→ [PI] ──→ u ──→ [P(s)] ──→ y
                      ↑                         │
                      └─────────────────────────┘
```

你现在有两个独立的旋钮：

1. **PI增益 $(K_p, K_i)$**——为扰动抑制调参。让它们激进。高刚度、快速负载恢复。滤波器会处理超调。

2. **滤波器 $F(s)$**——设 $\tau = K_p/K_i$ 得到IP等价的平滑跟踪。或故意设更长的 $\tau$ 获得更柔和的启动。或在允许超调的激进机动中设为1（旁路）。或调度它——精确定位时紧滤波，大角度转动时松滤波。

这就是**伺服性能与调节性能的独立调参**——2-DOF控制的核心承诺。PI + 滤波器架构无需修改一行控制器代码即可实现。

### 4.3 无扰切换

在"激进PI"和"平滑IP"行为之间切换只是滤波器参数的改变。没有增益切换，没有积分器复位，没有瞬态。改变 $\tau$，响应形状平滑变化。这在多模式系统（粗逼近→精定位、速度控制→力矩控制）中很重要。

## 5. D项怎么办？

扩展到完整PID：IPD（或I-PD）控制器将比例和微分项都移到反馈路径：

$$U(s) = \frac{K_i}{s}(R(s) - Y(s)) - K_p Y(s) - K_d s Y(s)$$

微分-on-feedback模式避免了"微分冲击（Derivative Kick）"——与比例冲击相同的问题，但更严重，因为对阶跃求导产生无限尖峰（理论上为冲激函数，实际中受速率限制饱和）。

完整PID的滤波等价略有不同：

$$F(s) = \frac{K_i}{K_d s^2 + K_p s + K_i}$$

这是二阶低通滤波器。原理相同：$K_p$ 和 $K_d$ 在分子中创建零点；滤波器对消它们。

---

## 6. 滤波器截止频率与调参的关系

滤波器截止频率 $\omega_c = K_i / K_p$ 从PI增益中自然涌现。这给出了设计规则：

| 如果PI调参为... | 则 $K_p/K_i$ 为... | 滤波器截止频率为... |
|---|---|---|
| **快速/激进** | 小 $T_i$ | 高——少量滤波，保持速度 |
| **慢速/保守** | 大 $T_i$ | 低——重滤波，但你本来就调得慢 |
| **Ziegler-Nichols** | $T_i \approx 0.85\,T_u$ | 约 $1.18/T_u$——中等滤波 |

如果你从PI增益推导滤波器，它会自动适应。为扰动抑制调 $K_p$ 和 $K_i$，然后计算 $\tau = K_p/K_i$ 作为参考滤波器。滤波器永远不需要独立调参。

---

## 7. 实现：三行代码

在离散时间（采样周期 $T_s$）中，一阶低通滤波器是指数移动平均：

```c
// PI控制器（不变）
error = reference_filtered - measurement;
integral += Ki * Ts * error;
u = Kp * error + integral;   // 标准PI

// 参考滤波器（新增——两行）
alpha = Ts / (Kp/Ki + Ts);   // 或预计算
reference_filtered = alpha * reference + (1 - alpha) * reference_filtered;
```

如果 $K_p/K_i$ 在线变化（自适应调参），在同一周期更新 `alpha`。滤波器状态已经有效——它跟踪当前滤波值，具有物理意义。

## 8. 滤波器不能做什么

滤波等价有值得了解的局限：

| 关注点 | 回答 |
|---|---|
| **滤波器会减慢扰动抑制吗？** | 不会。滤波器在参考路径上。扰动在被控对象输入或输出进入——完全绕过滤波器。PI回路以全带宽看到扰动。 |
| **滤波器会在环路内添加相位滞后吗？** | 不会。滤波器在反馈环路之外。环路增益、相位裕度和增益裕度不变。 |
| **对非线性被控对象有效吗？** | 推导假设线性，但*架构*（比例-on-feedback，积分-on-error）对任何被控对象都有效。滤波等价对线性被控对象是精确的；对非线性被控对象，它仍是正确的结构——只是不再是精确的代数恒等式。 |
| **测量噪声呢？** | IP和滤波PI与标准PI的噪声特性相同。比例项在两种情况下都作用于 $y$（在PI中作用于 $r-y$，但噪声无论如何都通过 $y$）。没有区别。 |

### 更深层的模式

PI→IP过渡是本项目中反复出现的主题的一个实例：**分离你能分离的。** PI通过单一误差信号耦合了跟踪和调节。IP解耦了它们——比例用于调节，积分用于跟踪。MPC进一步解耦——约束、预测和优化各有自己的机制。从PI到IP到2-DOF到MPC的进程是*解耦*的进程——将捆绑在一起的关注点逐一拆开。

## 10. 历史注记

IP控制器起源于1980–1990年代的工业运动控制，特别是在日本。安川、三菱和发那科伺服驱动器将"I-P控制"作为标准PI之外的配置选项提供。"I-P"（而非"IP"）在日本文档中常见，以避免与"知识产权（Intellectual Property）"混淆。

输入滤波等价在实践中更早被认识，但在学术文献中由以下工作形式化：

- **韩京清** (1995). The PID controller with set-point filter. *控制工程（中文）*. — 韩的ADRC工作始于同一观察：将比例项从参考上移开。
- **Åström, K.J. & Hägglund, T.** (1995). *PID Controllers: Theory, Design, and Tuning.* ISA. — 第3.4节涵盖设定值加权作为2-DOF参数化，其中IP（他们记号中 $\beta = 0$）是极端情况。

设定值加权公式推广了这个思想：

$$U(s) = K_p(\beta R(s) - Y(s)) + \frac{K_i}{s}(R(s) - Y(s))$$

- $\beta = 1$ → 标准PI（比例作用于全误差）
- $\beta = 0$ → IP（比例仅作用于反馈）
- $0 < \beta < 1$ → 部分设定值加权（有些超调，更快上升时间）

滤波等价 $F(s) = 1/((K_p/K_i)s + 1)$ 恰好是 $\beta = 0$，加上积分器提供的低通滤波器动态。
