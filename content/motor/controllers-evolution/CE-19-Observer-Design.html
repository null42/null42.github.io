CE-19: 观测器设计——从状态反馈到输出反馈的桥梁 ​

副标题：Observer Design: Bridging State Feedback to Output Feedback难度：适用对象： 控制理论学习者、电机控制工程师 前置知识： CE-12（LQR与状态空间方法）

1. 核心摘要 ​

LQR给你 u=−Kxu = -Kxu=−Kx，但你永远无法测量 xxx。你只能通过有噪声、有延迟、不完整的传感器测量 y=Cxy = Cxy=Cx。观测器（Observer）不是附加组件——它是控制器的一半。本文从开环仿真的失败出发，详解Luenberger观测器的校正机制、极点配置原则、卡尔曼滤波器的统计最优性、控制与估计的对偶性、分离原理及其失效条件，以及实际工程中的传感器偏置、测量丢失和观测器饱和等关键问题。

认知挂钩： 观测器是将数学控制器连接到物理对象的机制——没有它，状态反馈只是一个美丽的虚构。

2. 状态反馈核心的谎言 ​

每个状态空间控制器——LQR、极点配置、MPC——都始于同一个假设：你知道完整的状态向量 xxx。 控制律是 u=−Kxu = -Kxu=−Kx。它是一个点积。它优美、最优、有保证（LQR保证≥60°相位裕度），但它建立在一个虚构之上。

现实中，你永远没有完整的状态。传感器告诉你 yyy，不是 xxx：

  • 你测量位置，不测量速度。 正交编码器给你 θ\thetaθ。要得到 θ˙\dot{\theta}θ˙，你需要微分——在频域中这会以 ω\omegaω 倍放大噪声。在10 kHz采样率下，编码器量化噪声微分成"速度"后，不加重度滤波就无法使用。
  • 你测量一个温度，不是整个温度场。 反应器中一个点的热电偶无法告诉你10 cm外的温度、温度梯度或热通量。但热PDE有数百个状态。
  • 你测量加速度，不是姿态。 IMU给你加速度计和陀螺仪读数。横滚和俯仰角是通过积分陀螺速率并与加速度计的重力向量融合推断出来的——那就是一个观测器。

把 yyy 当作 xxx 使用在两个方向上都是错误的。首先，yyy 是低维的——CCC 将状态投影到传感器能看到的范围。其次，yyy 是被污染的——传感器噪声、量化、通信延迟。将 u=−Kyu = -Kyu=−Ky 送入你精心设计的LQR，得到的是一个既不最优、在很多情况下也不稳定的控制器。

观测器就是答案。 它使用对象模型从 yyy 和 uuu 重构 x^\hat{x}x^。然后控制器把 x^\hat{x}x^ 当作 xxx 使用。这就是输出反馈（Output Feedback）：测量 yyy，估计 xxx，用 x^\hat{x}x^ 控制。

3. 开环仿真：为什么需要校正 ​

最简单的想法：在软件中运行对象模型的一个副本。

x^k+1=Ax^k+Buk\hat{x}_{k+1} = A \hat{x}_k + B u_kx^k+1​=Ax^k​+Buk​

你知道 uku_kuk​（你计算了它）。你知道 AAA 和 BBB（来自模型）。从某个猜测开始 x^0\hat{x}_0x^0​，让模型运行。

这能工作——大约三个时间步。然后三件事毁了它：

  1. 未知初始条件。 对象从某个你不知道的 x0x_0x0​ 开始。如果 x^0≠x0\hat{x}_0 \neq x_0x^0​=x0​，估计从一开始就是错的，而且错误永远不会消失，因为没有校正机制。
  2. 模型失配。 AAA 和 BBB 是近似值。真实电机有摩擦、齿槽转矩、发热导致的参数漂移。这些未建模动态导致 x^\hat{x}x^ 随时间偏离 xxx。
  3. 扰动。 意外的负载转矩、阵风、电压跌落——这些以开环模型看不到的方式改变 xxx。

开环仿真器积分误差，不校正误差。我们需要一种方法来用测量值将估计拉向真值。

4. Luenberger观测器：运行模型，用测量校正 ​

David Luenberger（1964）有关键洞察。运行模型，但添加一个与测量误差成正比的校正项——你实际测量的（yky_kyk​）与模型预测你应该测量的（Cx^kC\hat{x}_kCx^k​）之间的差值：

x^k+1=Ax^k+Buk⏟预测（开环）+L (yk−Cx^k)⏟校正\hat{x}_{k+1} = \underbrace{A \hat{x}_k + B u_k}_{\text{预测（开环）}} + \underbrace{L\,(y_k - C \hat{x}_k)}_{\text{校正}}x^k+1​=预测（开环）Ax^k​+Buk​​​+校正L(yk​−Cx^k​)​​

信号 yk−Cx^ky_k - C\hat{x}_kyk​−Cx^k​ 是新息（Innovation）——你的模型没有预测到的那部分测量。如果模型完美且 x^=x\hat{x} = xx^=x，新息为零（除了测量噪声）。如果 x^\hat{x}x^ 是错的，新息告诉你方向和程度。

LLL 是观测器增益矩阵。它决定你多信任测量值vs模型：

  • LLL 大 → 重度信任测量值，收敛快，但放大传感器噪声
  • LLL 小 → 信任模型，平滑噪声，但收敛慢
  • L=0L = 0L=0 → 开环仿真，无校正

误差动态说明了问题。定义 ek=xk−x^ke_k = x_k - \hat{x}_kek​=xk​−x^k​：

ek+1=xk+1−x^k+1=(Axk+Buk)−(Ax^k+Buk+L(Cxk−Cx^k))e_{k+1} = x_{k+1} - \hat{x}_{k+1} = (A x_k + B u_k) - \big(A \hat{x}_k + B u_k + L(C x_k - C \hat{x}_k)\big)ek+1​=xk+1​−x^k+1​=(Axk​+Buk​)−(Ax^k​+Buk​+L(Cxk​−Cx^k​))ek+1=(A−LC) eke_{k+1} = (A - LC)\, e_kek+1​=(A−LC)ek​

观测器误差按矩阵 (A−LC)(A - LC)(A−LC) 的规律演化。如果 (A−LC)(A - LC)(A−LC) 的所有特征值都在单位圆内（离散时间），误差收敛到零无论初始猜测如何。观测器是稳定的。收敛速率取决于这些特征值在单位圆内有多深。

在连续时间下，Luenberger观测器为：

x^˙=Ax^+Bu+L(y−Cx^)\dot{\hat{x}} = A \hat{x} + B u + L (y - C \hat{x})x^˙=Ax^+Bu+L(y−Cx^)

误差动态为 e˙=(A−LC)e\dot{e} = (A - LC) ee˙=(A−LC)e。稳定性要求 (A−LC)(A - LC)(A−LC) 的所有特征值具有负实部。

5. 观测器极点配置：比控制器快，但不要太快 ​

设计 LLL 是一个极点配置问题。(A−LC)(A - LC)(A−LC) 的特征值是观测器极点——它们决定估计收敛的速度。

经验法则：将观测器极点放在控制器极点的2–5倍快处。

如果控制器极点在...将观测器极点放在...理由
s=−10s = -10s=−10s=−20s = -20s=−20 到 −50-50−50观测器在控制器的瞬态变得重要之前收敛
s=−2±j3s = -2 \pm j3s=−2±j3s=−4±j6s = -4 \pm j6s=−4±j6 到 −10±j15-10 \pm j15−10±j15估计误差以2–5倍于闭环响应的速度衰减

为什么"更快"是好的：

  • 控制器作用于 x^\hat{x}x^。如果 x^\hat{x}x^ 还在收敛而对象已经在响应，你在控制一个移动目标——有效动态退化。
  • 启动时，x^\hat{x}x^ 从错误值开始。你希望它在参考阶跃到达之前收敛，或至少在前几个采样周期内。
  • 对于LQR，分离原理（第7节）保证闭环极点是控制器极点（来自 A−BKA-BKA−BK）和观测器极点（来自 A−LCA-LCA−LC）的并集。如果观测器极点快得多，闭环响应由控制器极点主导——正是你设计 KKK 所要的。

为什么"太快"是坏的：

  • 快速观测器极点 → 大的 LLL 增益 → 校正项 L(yk−Cx^k)L(y_k - C\hat{x}_k)L(yk​−Cx^k​) 放大测量噪声。传感器噪声直接进入估计值，被 LLL 缩放。
  • 快速极点 → 宽带宽 → 观测器追踪高频传感器伪影，产生噪声 x^\hat{x}x^，控制器随后作用于它。你得到抖动的控制信号、增加的执行器磨损，以及激发未建模的高频对象模态。
  • 存在一个根本权衡：收敛速度 vs. 噪声灵敏度。 卡尔曼滤波器（第6节）最优地解决了这个问题。

通过极点配置计算 LLL：

(A−LC)(A - LC)(A−LC) 的特征值与 (AT−CTLT)(A^T - C^T L^T)(AT−CTLT) 的特征值相同。这与控制器极点配置问题 (AT−CTKT)(A^T - C^T K^T)(AT−CTKT) 的形式完全相同——对 AT−CTK~A^T - C^T \tilde{K}AT−CTK~ 配置极点，其中 K~=LT\tilde{K} = L^TK~=LT。这就是对偶性（Duality）（第6节）：通过对转置系统应用极点配置来设计 LLL。

在MATLAB中：L = place(A', C', poles)'——转置，为对偶系统设计"控制器"，再转置回来。

6. 卡尔曼滤波器：当你知道噪声统计特性时 ​

Luenberger观测器手动配置极点。卡尔曼滤波器（Rudolf Kalman, 1960）通过提出一个统计问题来最优地选择 LLL：

给定对象被随机过程噪声 wk∼N(0,Q)w_k \sim \mathcal{N}(0, Q)wk​∼N(0,Q) 驱动，传感器被测量噪声 vk∼N(0,R)v_k \sim \mathcal{N}(0, R)vk​∼N(0,R) 污染，什么增益 LkL_kLk​ 能最小化每一步的期望平方估计误差 E[\lVertxk−x^k∥2]\mathbb{E}[\lVertx_k - \hat{x}_k\lVert^2]E[\lVertxk​−x^k​∥2]？

系统模型：

xk+1=Axk+Buk+wk,wk∼N(0,Q)x_{k+1} = A x_k + B u_k + w_k, \qquad w_k \sim \mathcal{N}(0, Q)xk+1​=Axk​+Buk​+wk​,wk​∼N(0,Q)yk=Cxk+vk,vk∼N(0,R)y_k = C x_k + v_k, \qquad v_k \sim \mathcal{N}(0, R)yk​=Cxk​+vk​,vk​∼N(0,R)

QQQ 是过程噪声协方差——你多信任模型。大 QQQ 意味着模型不可靠（未建模动态、扰动）；滤波器应更信任测量值。

RRR 是测量噪声协方差——传感器有多噪声。大 RRR 意味着传感器差；滤波器应更信任模型。

卡尔曼滤波器与Luenberger观测器有完全相同的结构：

x^k+1=Ax^k+Buk+Lk⏟最优增益(yk−Cx^k)\hat{x}_{k+1} = A \hat{x}_k + B u_k + \underbrace{L_k}_{\text{最优增益}} (y_k - C \hat{x}_k)x^k+1​=Ax^k​+Buk​+最优增益Lk​​​(yk​−Cx^k​)

但 LkL_kLk​ 不是常数——它是时变的，由前向Riccati递推计算：

  1. 预测误差协方差：

Pk=(I−LkC)Pk−P_k = (I - L_k C) P_k^-Pk​=(I−Lk​C)Pk−​

实践中整定卡尔曼滤波器：

  • Q/RQ/RQ/R 比值小 → 信任模型，估计更平滑，收敛更慢

7. 对偶性：估计与控制是同一个问题的转置 ​

控制与估计之间存在深层的结构关系。数学是相同的——你只需转置矩阵并交换时间方向。

原始问题（控制）： 设计 KKK 使 (A−BK)(A - BK)(A−BK) 的特征值在单位圆内。

xk+1=Axk+Buk,uk=−Kxkx_{k+1} = A x_k + B u_k, \qquad u_k = -K x_kxk+1​=Axk​+Buk​,uk​=−Kxk​xk+1=(A−BK)xkx_{k+1} = (A - BK) x_kxk+1​=(A−BK)xk​

对偶问题（估计）： 设计 LLL 使 (A−LC)(A - LC)(A−LC) 的特征值在单位圆内。

ek+1=(A−LC)eke_{k+1} = (A - LC) e_kek+1​=(A−LC)ek​

但 (A−LC)(A - LC)(A−LC) 的特征值恰好是 (AT−CTLT)(A^T - C^T L^T)(AT−CTLT) 的特征值。所以为 (A,C)(A, C)(A,C) 设计观测器就是恰好为转置系统 (AT,CT)(A^T, C^T)(AT,CT) 设计控制器：

这种对偶性意味着：

  • 任何控制器设计算法（极点配置、LQR、H∞）都可以通过转置系统复用于观测器设计。
  • MATLAB命令 dlqr(A, B, Q, R) 给你 KKK。dlqr(A', C', Q, R) 给你 LTL^TLT——然后 LLL 是其转置。卡尔曼增益就是对偶系统的LQR增益。
  • 分离原理（第8节）是直接结果：组合系统的闭环特征值是 (A−BK)(A-BK)(A−BK) 的特征值与 (A−LC)(A-LC)(A−LC) 的特征值的并集。控制器和观测器极点不交互——它们被对偶性解耦。

8. 分离原理：独立设计，组合使用 ​

分离原理是使输出反馈可处理的定理。它说：

像拥有全状态反馈一样设计 KKK。像控制器不存在一样设计 LLL。然后组合：uk=−Kx^ku_k = -K \hat{x}_kuk​=−Kx^k​，其中 x^\hat{x}x^ 来自观测器。闭环系统稳定，其极点恰好是控制器极点（来自 A−BKA-BKA−BK）加上观测器极点（来自 A−LCA-LCA−LC）。

为什么有效。 写出组合状态 [xk;ek][x_k; e_k][xk​;ek​]，其中 ek=xk−x^ke_k = x_k - \hat{x}_kek​=xk​−x^k​：

xk+1=Axk+B(−Kx^k)=Axk−BK(xk−ek)=(A−BK)xk+BKekx_{k+1} = A x_k + B(-K \hat{x}_k) = A x_k - B K (x_k - e_k) = (A - BK) x_k + BK e_kxk+1​=Axk​+B(−Kx^k​)=Axk​−BK(xk​−ek​)=(A−BK)xk​+BKek​ek+1=(A−LC)eke_{k+1} = (A - LC) e_kek+1​=(A−LC)ek​

矩阵形式：

[xk+1ek+1]=[A−BKBK0A−LC][xkek]\begin{bmatrix} x_{k+1} \\ e_{k+1} \end{bmatrix} = \begin{bmatrix} A - BK & BK \\ 0 & A - LC \end{bmatrix} \begin{bmatrix} x_k \\ e_k \end{bmatrix}[xk+1​ek+1​​]=[A−BK0​BKA−LC​][xk​ek​​]

块三角结构意味着特征值是对角块特征值的并集：eig(A−BK)∪eig(A−LC)\text{eig}(A-BK) \cup \text{eig}(A-LC)eig(A−BK)∪eig(A−LC)。控制器和观测器在误差动态中解耦。右上角的 BKBKBK 项意味着估计误差确实影响状态——但它不影响稳定性，因为误差本身是稳定的并衰减到零。

何时成立（线性情况）：

  • 无约束的线性时不变系统：分离原理是精确的、可证明的。
  • LQG（线性二次高斯）：LQR控制器 + 卡尔曼滤波器 = 高斯噪声线性系统的最优输出反馈。你通过DARE设计 KKK，通过FARE设计 LLL，组合它们。那就是LQG。

何时失效：

实践要点： 对于远离饱和的线性系统，分离原理有效，你可以将控制器设计和观测器设计视为独立任务。这就是为什么LQR + Luenberger是运动控制、航空航天和过程控制中的标准架构。对于非线性系统或饱和系统，你需要更复杂的组合（例如移动时域估计 + 非线性MPC）。

9. 实践中的观测器：教科书不告诉你的事 ​

9.1 模型永远是错的 ​

观测器并行运行一个模型。如果 AAA 和 BBB 是错的，预测步骤产生垃圾。校正项 L(y−Cx^)L(y - C\hat{x})L(y−Cx^) 可以补偿——但只在观测器带宽内。慢参数漂移（电机发热）观测器可以追踪。未建模的非线性（静摩擦、间隙）它不能——它们产生持续的新息，观测器试图校正，导致有偏估计。

对策： 将参数不确定性视为过程噪声。增大 QQQ 中相应的对角元素（卡尔曼）或放慢观测器极点（Luenberger）。你会得到一个更平滑但滞后于现实的估计——比快速但错误的估计更好的权衡。

9.2 传感器偏置 ​

大多数传感器有直流偏移。陀螺有随温度漂移的偏置。加速度计有取决于安装对准的重力分量。编码器有未知的零位。

新息 yk−Cx^ky_k - C\hat{x}_kyk​−Cx^k​ 包含一个持续的偏置项。观测器无法区分传感器偏置和真正的状态误差——两者产生相同的新息特征。结果：估计收敛到有偏值。

对策：增广状态。 将偏置作为未知常数状态添加：

xaug=[xb],bk+1=bkx_{\text{aug}} = \begin{bmatrix} x \\ b \end{bmatrix}, \qquad b_{k+1} = b_kxaug​=[xb​],bk+1​=bk​

观测器现在同时估计对象状态和传感器偏置。这就是偏置估计（Bias Estimation），是姿态估计（估计陀螺偏置和姿态四元数）和GPS/INS组合导航中的标准方法。

9.3 测量丢失 ​

传感器会失效。GPS在隧道中丢失信号。编码器跳过计数。相机被遮挡。观测器必须处理没有测量的时期。

在测量丢失期间，观测器开环运行：x^k+1=Ax^k+Buk\hat{x}_{k+1} = A\hat{x}_k + Bu_kx^k+1​=Ax^k​+Buk​（该采样点设 L=0L = 0L=0）。误差按 ek+1=Aeke_{k+1} = A e_kek+1​=Aek​ 增长。如果 AAA 稳定（对象本身稳定），误差有界。如果 AAA 不稳定（倒立摆、火箭），误差无界增长——你需要备用传感器或不同策略。

多速率卡尔曼滤波器处理以不同速率到达的测量。GPS 1 Hz、IMU 100 Hz、相机 30 Hz。滤波器以IMU速率（100 Hz）预测，只在测量到达时应用校正步骤。每个传感器有自己的 CCC 矩阵和 RRR 协方差。这是每个无人机飞行控制器的架构。

9.4 观测器饱和 ​

当执行器饱和时，实际 uku_kuk​ 小于命令值。观测器用命令的 uku_kuk​ 运行——但对象收到了更少。新息尖峰。观测器过度校正。估计发散。

对策： 将实际（饱和后的）uku_kuk​ 馈入观测器，而不是命令的 uku_kuk​。这是观测器抗饱和（Anti-windup），与积分器抗饱和同样重要。任何有饱和的系统都必须这样做。

更深的模式： 本项目中的每个控制器——PID、LQR、MPC——都需要知道状态。PID之所以能直接使用 yyy，是因为工业过程通常是一阶的（位置就是状态，没有隐藏动态）。LQR明确暴露了差距：它要求 xxx，迫使你面对测量问题。MPC的预测时域使差距更大：错误的初始状态 → 错误的预测 → 错误的控制。观测器不是可选的基础设施——它是将数学控制器连接到物理对象的机制。

11. 延伸阅读 ​

基础——原始论文：

  • Luenberger, D.G. (1964). "Observing the State of a Linear System." IEEE Trans. Military Electronics, 8(2), 74–80. —— 引入观测器结构的论文。出奇地易读。
  • Kalman, R.E. (1960). "A New Approach to Linear Filtering and Prediction Problems." ASME J. Basic Engineering, 82(1), 35–45. —— 卡尔曼滤波器。密集但有回报。附录证明了增益的最优性。

教科书——从应用到理论：

  • Franklin, G.F., Powell, J.D., & Workman, M.L. (1998). Digital Control of Dynamic Systems, 3rd ed. Ellis-Kagle Press. —— 第8–9章覆盖观测器设计和分离原理，有计算示例。最实用的处理。
  • Åström, K.J. & Wittenmark, B. (1997). Computer-Controlled Systems, 3rd ed. Prentice-Hall. —— 第6章关于带观测器的极点配置设计；第7章关于卡尔曼滤波器。
  • Anderson, B.D.O. & Moore, J.B. (1979). Optimal Filtering. Prentice-Hall. —— 卡尔曼滤波器的权威文本。严谨、完整。第3–4章覆盖离散时间滤波器及其性质。

对偶性与分离原理：

  • Doyle, J.C., Francis, B.A., & Tannenbaum, A.R. (1992). Feedback Control Theory. Macmillan. —— 第6章在Youla参数化框架内将分离原理呈现为统一结果。
  • Zhou, K., Doyle, J.C., & Glover, K. (1996). Robust and Optimal Control. Prentice-Hall. —— 第14章关于LQG和分离原理；完整一般性的数学结构。

实践估计——实现导向：

  • Grewal, M.S. & Andrews, A.P. (2014). Kalman Filtering: Theory and Practice Using MATLAB, 4th ed. Wiley. —— 实现细节：协方差传播、数值稳定性（Joseph形式、UD分解、平方根滤波）、多速率和序贯更新。
  • Brown, R.G. & Hwang, P.Y.C. (2012). Introduction to Random Signals and Applied Kalman Filtering, 4th ed. Wiley. —— 易读的入门，有MATLAB代码。传感器偏置估计和GPS/INS组合导航的良好处理。

运动控制中的观测器：

  • Ellis, G. (2012). Control System Design Guide, 4th ed. Butterworth-Heinemann. —— 第13章关于伺服驱动中的Luenberger观测器：从编码器位置估计速度、实用整定规则、加速度前馈。
