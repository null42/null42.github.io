# CE-08: 控制器设计的九大核心问题

**副标题：从PID到非线性MPC，每一代控制器都是对同一组根本问题的回答**
**难度：** ★★★☆☆ 中等
**适用对象：** 控制理论学习者、电机控制工程师
**前置知识：** CE-03（频域分析基础）

---

## 1. 📌 核心摘要

剥去数学外衣，每个控制系统面对的都是同一组横亘在"完美跟踪"与"现实"之间的障碍：测量噪声与延迟、被控对象的惯性与滞后、执行器的物理约束、模型的不确定性、外部扰动、非线性特性、稳定性保证、实时计算限制，以及多目标之间的不可调和的权衡。这九大问题不是彼此独立的——它们相互叠加、彼此恶化。理解这些问题，就是理解控制理论为什么沿着从PID到LQR到MPC的路径演化。

**认知挂钩：** 火箭着陆同时激活了全部九个问题——噪声超音速GPS、巨大助推器惯性、发动机节流阀限制、不确定气动特性、阵风、非线性阻力、安全关键稳定性、毫秒级控制截止期、燃料与精度的竞争目标。没有任何单一技术能同时解决所有问题——这就是为什么工程控制器总是组合多种方案。

---

## 2. 概览

剥去数学外衣，每个控制系统面对的都是同一组横亘在你和完美跟踪之间的障碍。每个障碍催生了控制理论的一整个分支：

| # | 问题 | 含义 | 催生的技术 |
|---|------|------|-----------|
| 1 | **测量** | 你不知道真实状态——噪声、延迟、部分感知 | 卡尔曼滤波器（Kalman Filter）、Luenberger观测器、Smith预估器 |
| 2 | **惯性/延迟** | 被控对象不会立即响应——能量需要传递，质量需要加速 | 阻尼控制、基于模型的设计、前馈 |
| 3 | **约束** | 执行器有硬限制——电压、电流、力矩、变化率 | 约束优化、MPC、抗饱和（Anti-windup） |
| 4 | **模型不确定性** | 模型总是错的——参数漂移、动力学未建模 | 鲁棒控制（H∞）、自适应控制、滑模控制 |
| 5 | **扰动** | 未知外力作用于被控对象——风、负载变化、摩擦 | 扰动观测器（DOB）、自抗扰控制（ADRC）、内模原理 |
| 6 | **非线性** | 现实世界不是线性的——摩擦、饱和、空气动力学 | 增益调度、反馈线性化、非线性MPC |
| 7 | **稳定性** | 你需要保证系统不会崩溃 | 李亚普诺夫理论、无源性、小增益定理 |
| 8 | **计算** | 控制器必须在真实硬件上实时运行 | 显式MPC、热启动、高效QP求解器 |
| 9 | **多目标权衡** | 你不可能什么都要——速度 vs 超调、能量 vs 精度 | Pareto最优控制、H₂/H∞权衡、Q/R整定 |

这些问题不是孤立的。它们会叠加。火箭着陆同时激活了全部九个问题：噪声超音速GPS、巨大助推器惯性、发动机节流阀限制、不确定气动特性、阵风、非线性阻力、安全关键稳定性、毫秒级控制截止期、燃料与精度的竞争目标。没有任何单一技术能同时解决所有问题——这就是为什么工程控制器总是组合多种方案。

## 3. 测量——你不知道真实状态

### 问题

控制器计算 `u = f(测量状态)`。但你手上的只有：

- **噪声：** 传感器读数被污染——热噪声、量化、振动
- **延迟：** 测量迟到——传感器延迟、通信总线、计算时间
- **部分测量：** 你测量电机位置但不知道速度；房间温度只有一个点但不知道整个温度场

把原始测量当作真实状态使用会产生错误的控制动作。更糟的是，对噪声信号做差分（例如对位置差分得到速度）会放大高频噪声。PID中的微分作用因此臭名昭著——这就是为什么很多工业PID回路只用到PI。

### 解决方案：估计状态

核心思想：与被控对象**并行运行一个模型**，用测量值修正其状态。

**Luenberger观测器**（1964）。运行被控对象模型的一个副本，加上修正项：

$$\hat{x}_{k+1} = A \hat{x}_k + B u_k + L (y_k - C \hat{x}_k)$$

增益 $L$ 通过极点配置设计——将观测器极点放在控制器极点2~5倍远的地方。**分离原理（Separation Principle）** 保证你可以独立设计估计器和控制器。

**卡尔曼滤波器（Kalman Filter）**（1960）。同样的结构，但 $L$ 是在给定统计噪声模型下*最优*选择的：

| | 控制（LQR） | 估计（Kalman） |
|---|---|---|
| **Riccati方向** | 反向 | 正向 |
| **权重** | $Q$（状态代价），$R$（控制代价） | $Q$（过程噪声），$R$（测量噪声） |
| **最小化什么** | 状态误差 + 控制代价 | 估计误差协方差 |

卡尔曼 + LQR的组合就是 **LQG**——线性高斯系统的最优估计 + 最优控制。对偶性：估计和控制是同一套数学朝相反方向运行。

**Smith预估器**（1957）。针对纯测量延迟 $\tau$ 的专用方案。运行一个*不含*延迟的模型用于反馈，加上延迟模型失配的修正项。最初为化工过程控制开发（管道传输延迟可达数分钟）。至今仍在使用。

### 为什么这推动了控制器演进

- **PID** 假设测量 = 真实值。微分作用放大噪声；低通滤波是临时补丁。
- **LQR** 假设全状态反馈。实际中 → LQG（卡尔曼 + LQR）。
- **MPC** 通常在上游运行独立的估计器（卡尔曼滤波器、移动时域估计）。

## 4. 惯性/延迟——被控对象不会立即响应

### 问题

给电机加电压，它不会瞬间达到目标转速——转子有惯性。打开阀门，液柱有动量。开启加热器，热质吸收能量。

惯性储存能量并随时间释放。从控制器角度看，这感觉就像延迟：你发出指令，过一会儿才有响应。

### 为什么惯性本质上是延迟问题

相位滞后是共同机制：

- 一阶滞后 $1/(\tau s + 1)$：相位 $\to -90^\circ$
- 二阶系统：相位 $\to -180^\circ$
- 纯延迟 $e^{-\tau s}$：相位无界线性下降

三者以同样的方式破坏反馈稳定性。控制器推了一把，看不到响应，再推一把——等被控对象动起来时，控制器已经推过头了。超调、振荡、失稳。

### 解决方案：阻尼 + 预测

**阻尼**——PID的微分项、LQR的速度惩罚（$q_\omega$）、MPC的终端代价（$P$）——说的都是同一件事：*到达之前先减速。*

**前馈（Feedforward）**——不等误差出现，直接计算*应该*产生期望输出的控制量：$u_{\text{ff}} = G^{-1}(0) \cdot r$。PID的 $K_p r$ 项是零阶前馈。更高阶的版本逆置完整的被控对象模型。

**预测**——对于大惯性，纯反馈太慢。等你看到误差时已经来不及了。你必须预测被控对象要往哪里走。这就是MPC滚动时域的意义：它规划一条考虑被控对象迟缓性的轨迹。

### 模型开始值得付出的阈值

- 小惯性 → 纯反馈就够了 → PID足够
- 中等惯性 → 需要阻尼 → 带微分的PID、LQR
- 大惯性 → 需要预测 → 基于模型的前馈、MPC
- 巨大惯性 + 延迟 → 完整预测 + 约束 → MPC + 观测器

核心洞察：**惯性让模型变得重要。** 当被控对象响应快时，无知代价低。当它慢时，无知致命。

## 5. 约束——执行器有硬限制

### 问题

每个物理执行器都会饱和：电压轨、电流额定值、力矩限制、温度上限、变化率。一个要求12V电源输出30V的控制器是在要求不可能的事。

### 为什么简单的截断会失败

显而易见的修复——计算，然后截断——失败有三个原因：

1. **控制器不知道自己已经饱和。** 内部状态（积分器、估计器）假设指令的 $u$ 已经施加。但被控对象收到的更少。模型发散。

2. **积分器饱和（Integrator Windup）。** 积分项在饱和期间持续累积。当误差过零时，饱和的积分器导致巨大超调。抗饱和（Anti-windup）补丁了这个问题，但没有解决根因。

3. **约束最优解的结构不同。** 当求解器知道约束存在时，它找到的是*结构上不同*的控制序列——提前减速，避免不必要的饱和。简单截断是裁剪；约束优化是绕路。

### 解决方案：把约束嵌入优化

MPC在每个时间步求解一个二次规划（Quadratic Program, QP）：

$$\min_u J(x, u) \quad \text{s.t.} \quad u_{\min} \leq u \leq u_{\max}$$

约束进入优化，而不是后处理。求解器看到墙壁，规划绕过它。

**代价：** LQR离线求解一次Riccati方程。MPC在线每个时间步求解一个QP。实时优化的历史——内点法、有效集法、算子分裂、热启动——就是让这足够快的历史。

## 6. 模型不确定性——模型总是错的

### 问题

每个控制器都使用模型，显式的或隐式的。PID的模型是"P、I、D三项能搞定"。LQR的模型是A和B矩阵。MPC的模型是完整的预测动力学。

所有模型都是错的。参数漂移（电机电阻随温度升高，电池电压下降）。动力学被简化（柔性模态被当作刚体，摩擦被建模为线性粘性）。工作点变化（飞机在海平面 vs 40000英尺）。

为错误模型设计的最优控制器可能比为正确模型设计的次优控制器更差。这就是**鲁棒性问题（Robustness Problem）**。

### 解决方案谱系

**鲁棒控制（Robust Control）**（1980年代–）。设计控制器使其容忍指定的不确定性集合。如果真实被控对象在标称模型的某个有界扰动范围内，稳定性和性能得到保证。工具：H∞综合、μ综合、小增益定理、间隙度量。

H∞问题：找到一个控制器 $K$，最小化不确定性集合中所有被控对象上从扰动到误差的最坏情况增益：

$$\min_K \| T_{zw} \|_\infty$$

这产生故意保守的控制器——它们用标称性能换取有保证的鲁棒性。

**自适应控制（Adaptive Control）**（1950年代–）。与其为最坏情况不确定性设计，不如*在线估计参数*并更新控制器。模型参考自适应控制（MRAC, Model Reference Adaptive Control）：通过实时调整控制器增益迫使被控对象表现得像参考模型。自校正调节器：估计被控对象参数，重新计算控制器，应用。

权衡：鲁棒控制保证稳定性但保守。自适应控制可以达到更高性能但在瞬态期间有失稳风险（参数估计可能漂移，激励可能不足）。

**滑模控制（Sliding Mode Control）**（1970年代–）。不同的哲学：不建模不确定性，*压制*它。施加不连续控制律迫使状态到达"滑动面"并保持在那里，无论有界不确定性如何。代价：颤振（Chattering，高频切换），机械系统对此深恶痛绝。

**增益调度（Gain Scheduling）。** 实用的折中。在多个工作点设计控制器，根据测量的调度变量（空速、高度、温度）插值增益。在航空航天中广泛使用。理论上不优雅——设计点之间的稳定性没有保证——但它管用。

### 为什么这很重要

为标称模型最优但对不确定性脆弱的控制器在实践中毫无用处。每个实际部署都在与鲁棒性搏斗。LQR的有保证裕度（≥60°相位裕度，∞增益裕度）是其被广泛采用的重要原因——它们是*自动的*，不需要设计者单独验证。

## 7. 扰动——世界在推回来

### 问题

扰动是你无法控制的外力：

- 无人机上的阵风
- 电机上的负载力矩（机器人拾取零件）
- 电源电压波动
- 摩擦变化（磨损、温度）
- 传感器偏置随时间漂移

扰动不同于测量噪声。噪声腐蚀你*看到的*。扰动腐蚀被控对象*做的*。卡尔曼滤波器处理测量噪声。它不处理意外的负载力矩——除非你把扰动建模为增广状态（这正是扰动观测器所做的）。

### 解决方案：估计并抵消

**积分作用**是最古老的扰动抑制技术。积分器累积持续误差并调整控制来抵消它。内模原理（Internal Model Principle）：要抑制一个扰动，控制器必须包含该扰动的模型。恒定扰动需要积分器（$1/s$）。正弦扰动需要谐振器（$\omega/(s^2 + \omega^2)$）。

**扰动观测器（DOB, Disturbance Observer）**（1980年代–）。通过比较实际被控对象输出与模型预测来估计扰动：

$$\hat{d} = G_{\text{model}}^{-1}(y) - u$$

将估计值前馈抵消。简单、有效，在运动控制中广泛使用（机器人关节、硬盘驱动器）。

**自抗扰控制（ADRC, Active Disturbance Rejection Control）**（韩京清，1990年代）。用"总扰动"项扩展被控对象状态，将未知动力学、外力和非线性打包在一起。用扩张状态观测器（ESO, Extended State Observer）估计一切。用前馈抵消扰动。剩余动力学近似为纯积分链——控制起来轻而易举。ADRC在几乎不需要模型信息的情况下异常有效。

**前馈**来自可测量的扰动源。如果你能测量扰动（风速、来料温度），在反馈回路看到误差之前就前馈预补偿。

### 为什么这很重要

扰动抑制是区分玩具控制器和工业控制器的关键。PID的积分器是最小可行方案。ADRC和DOB更有原则。MPC可以将扰动模型纳入预测——但前提是扰动已知或可估计。

## 8. 非线性——现实世界不是线性的

### 问题

每个物理系统都是非线性的。摩擦有静摩擦和库仑分量（不仅仅是线性粘性的）。气动阻力与 $v^2$ 成正比。化学反应速率遵循Arrhenius方程（$e^{-E/RT}$）。晶体管饱和。齿轮有间隙。

线性控制理论在工作点附近有效（Taylor展开：小 $\theta$ 时 $\sin\theta \approx \theta$）。远离那个点，它失效。大攻角的飞行器、高速机器人、接近失控的化学反应器——线性假设崩溃。

### 解决方案谱系

**增益调度**（实用，广泛使用）。在许多工作点设计线性控制器，在它们之间插值。没有理论保证，但实践中管用（飞机飞行控制、发动机管理）。

**反馈线性化（Feedback Linearization）**（1980年代–）。找到非线性变量替换和控制律使闭环系统恰好线性。然后对线性化系统应用线性控制理论。需要精确模型。模型不确定时失效。

**滑模控制**（1970年代–）。不建模非线性。压制它。用高增益切换驱动状态到滑动面，然后滑向原点。对有界不确定性鲁棒。颤振是实际问题。

**反步法（Backstepping）**（1990年代–）。对于"严格反馈形式"的系统（级联积分器，每级有非线性），从最内层回路向外递归设计李亚普诺夫函数和虚拟控制。系统化且构造性——与反馈线性化不同，它可以处理某些类别的不确定性。

**非线性MPC**（2000年代–）。在线求解完整的非线性最优控制问题。每步最小化 $J$，满足 $x_{k+1} = f(x_k, u_k)$ 和约束——使用DDP（微分动态规划）、SQP（序列二次规划）或直接配点法。计算昂贵但越来越实用（SpaceX火箭着陆、波士顿动力机器人）。

### 为什么这很重要

非线性是前沿。PID、LQR和线性MPC处理接近平衡的系统。当系统在大范围状态空间中运动——摆起倒立摆、着陆火箭、激进机动——你需要非线性工具。从线性MPC到非线性MPC的演进镜像了从LQR到线性MPC的演进：每一步同时处理更多问题，代价是计算量。

## 9. 稳定性——你需要保证

### 问题

控制器在仿真中工作不够。你需要*证明*闭环系统不会崩溃，即使：

- 模型是近似的（鲁棒稳定性）
- 系统从远离平衡点出发（吸引域）
- 存在扰动（输入到状态稳定性）
- 控制器在连续被控对象上以离散时间实现（采样数据稳定性）

没有稳定性保证的控制器是隐患。PID可能被激进整定搞失稳——没有自动保护。这就是为什么LQR是革命性的：它*自动*保证60°相位裕度和无穷增益裕度，无论你选什么Q和R。

### 解决方案：李亚普诺夫理论及其后继

**李亚普诺夫稳定性（Lyapunov Stability）**（1892）。找到一个标量函数 $V(x) > 0$（$x \neq 0$ 时），沿轨迹递减（$\dot{V} < 0$）。如果这样的函数存在，原点稳定。这是几乎所有非线性稳定性分析的基础。

对于LQR，最优代价 $V(x) = x^T P x$ *就是*一个李亚普诺夫函数——Riccati方程保证它递减。这是控制理论中最优雅的结果之一：最优性蕴含稳定性。

**无源性（Passivity）**（1970年代–）。如果被控对象是无源的（它不产生能量），控制器也是无源的，则互连稳定。基于无源性的控制设计控制器来塑造能量函数，特别适用于机械和电气系统。

**小增益定理（Small-Gain Theorem）**（1960年代）。如果环路增益小于1，闭环稳定。这把Bode直觉（增益裕度）推广到非线性和互连系统。在鲁棒控制中大量使用。

**障碍函数（Barrier Functions）**（2010年代–）。对于安全关键系统，稳定性不够——你需要保证状态永远不进入不安全区域。控制障碍函数（CBF, Control Barrier Functions）约束控制输入使系统保持在安全集中。与控制李亚普诺夫函数（CLF, Control Lyapunov Functions）结合，产生既稳定又安全的控制器——用于自动驾驶、足式机器人、无人机群。

### 为什么这很重要

稳定性是不可谈判的。航空航天、医疗设备、自动驾驶——失败意味着死亡。从"仿真中工作"到"可证明安全"的进步是控制器设计中最困难也最重要的一步。这也是控制理论证明其价值的地方：没有李亚普诺夫，你只是在祈祷。

## 10. 计算——控制器也有限制

### 问题

控制器在真实硬件上运行，资源有限：

- **时间：** 控制回路有截止期（1 ms、100 µs、10 µs）
- **内存：** 嵌入式微控制器只有KB级，不是GB级
- **功耗：** 电池供电设备不能跑重优化
- **数值精度：** 定点DSP、单精度浮点

一个数学上完美但在1 ms回路中需要10 ms计算的控制器毫无用处。计算是控制器本身的约束。

### 解决方案谱系

**离线预计算。** LQR的吸引力在于Riccati方程离线求解一次——在线控制器只是 $u = -Kx$（一个点积）。这就是为什么LQR能在任何平台上运行。

**显式MPC（Explicit MPC）**（2002）。离线为*所有可能的*状态预求解QP。结果是将状态空间划分为多面体区域，每个区域有预计算的仿射控制律 $u = K_i x + b_i$。在线：找到状态在哪个区域（点定位），应用对应律。以LQR级在线代价处理约束。大问题复杂度爆炸（区域数量随时域指数增长）。

**热启动（Warm Starting）。** 状态只变化一个时间步。上一步的最优控制序列与这步非常接近。从那里初始化求解器——通常减少80%以上的迭代。OSQP和DAQP都支持。

**高效求解器。** QP求解器的选择主导在线计算量：
- **有效集法（Active-set methods）**（qpOASES, DAQP）：迭代少，适合小问题
- **内点法（Interior-point methods）**（CVXOPT, ECOS）：迭代多但可预测
- **算子分裂法（Operator splitting）**（OSQP, SCS）：一阶方法，可认证，GPU友好

**事件触发和自触发控制。** 不以固定速率计算。只在状态变化足够大时才计算。在稀疏事件场景下平均计算量减少10–100倍。

**多速率控制。** 快内环（电流控制）以100 kHz运行简单PI控制器。慢外环（位置MPC）以100 Hz运行。快环隐藏了慢环的延迟。

### 为什么这很重要

"在MATLAB中验证"和"在微控制器上运行"之间的鸿沟是大多数学术控制器的坟墓。实时实现是一等设计约束，不是事后补充。这就是为什么PID存活了一个世纪——它的计算代价基本为零。

## 11. 多目标权衡——你不可能什么都要

### 问题

每个控制器都在平衡竞争目标：

- **速度 vs 超调**——更快的上升意味着更多超调（线性系统中的水床效应）
- **跟踪 vs 能量**——激进跟踪消耗功率（LQR的Q vs R编码了这一点）
- **鲁棒性 vs 标称性能**——为最坏情况不确定性设计牺牲最佳情况性能
- **简单性 vs 最优性**——PID简单但次优；非线性MPC接近最优但复杂
- **探索 vs 利用**——在学习型控制中，尝试新动作风险即时性能下降

这些不仅仅是实现细节。它们是不可公度的（Incommensurable）——没有单一数字能捕捉"好坏"。你必须选择在每个Pareto前沿上坐在哪里。

### 解决方案：让权衡显式化

**LQR权重**（Q, R）是控制理论中最优雅的权衡编码。$Q$ 惩罚状态误差，$R$ 惩罚控制代价。比值 $Q/R$ 决定激进程度。Riccati解找到数学上最优的折中。你不需要*设计*折中——你声明你在乎什么，数学返回给定优先级下最好的控制器。

**多目标MPC。** 不用标量代价，对多个目标用显式权重优化。某些公式使用字典序排序（安全第一，然后性能，然后舒适度）。其他使用约束优化（最小化能量，满足跟踪误差 ≤ ε）。

**H₂ / H∞权衡。** H₂优化标称性能（期望行为）。H∞优化最坏情况鲁棒性。混合H₂/H∞设计平衡两者——良好的标称性能加上对指定不确定性界的鲁棒性保证。

**根本问题：** 没有控制器能超越被控对象物理施加的权衡。Bode积分公式说灵敏度函数的积分是守恒的——在一个频率上降低误差会在另一个频率上增加。水床效应是自然法则，不是工程限制。好的控制器设计不是消除权衡，而是让权衡可见并审慎选择。

## 12. 这些问题如何交互

问题会叠加。每个问题都使其他问题更难：

| 场景 | 测量 | 惯性 | 约束 | 模型不确定 | 扰动 | 非线性 | 你需要什么 |
|------|------|------|------|-----------|------|--------|-----------|
| 快速电机，好编码器，大功率放大器 | ✗ | ✗ | ✗ | ✗ | ✗ | ✗ | PID |
| 同上，噪声编码器 | ✓ | ✗ | ✗ | ✗ | ✗ | ✗ | PI + 滤波器，或LQG |
| 重型机械臂，好编码器 | ✗ | ✓ | ✗ | ✗ | ✗ | ✗ | LQR + 前馈 |
| 重型机械臂，变负载 | ✗ | ✓ | ✗ | ✗ | ✓ | ✗ | LQR + 扰动观测器 |
| 电压严格受限的电机 | ✗ | ✗ | ✓ | ✗ | ✗ | ✗ | MPC 或 PID + 抗饱和 |
| 老化电池（参数变化） | ✗ | ✗ | ✓ | ✓ | ✗ | ✗ | 自适应MPC |
| 风力涡轮机（柔性、阵风） | ✓ | ✓ | ✓ | ✓ | ✓ | ✗ | 增益调度鲁棒MPC |
| 火箭着陆 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | 非线性MPC + EKF |

### 分离原理在哪里崩溃

分离原理（估计器 + 控制器独立设计 = 稳定的组合系统）对线性系统成立。它在以下情况下崩溃：

- **约束激活**——控制器没有施加它说的量。估计器假设它施加了。估计发散。
- **模型错误**——估计器和控制器使用同一个错误模型。误差相关并放大。
- **系统非线性**——非线性系统没有一般的分离原理。

这就是为什么约束MPC + 卡尔曼滤波器可能在两个组件分别完美调优的情况下仍然失败。也是鲁棒MPC和移动时域估计（MHE）是活跃研究领域的原因——它们显式处理交互。

## 13. 演化弧线

控制理论不是随机演化的。每一代都是它能处理的问题集合增长的回应：

| 代际 | 测量 | 惯性 | 约束 | 模型不确定 | 扰动 | 非线性 | 核心工具 |
|------|------|------|------|-----------|------|--------|---------|
| **PID**（1920年代–） | 假设干净 | D项阻尼 | 抗饱和（补丁） | 手动重整定 | 积分器 | 无 | 三项误差反馈 |
| **LQR/LQG**（1960年代–） | 卡尔曼滤波 | Riccati → 最优阻尼 | 无 | 有保证裕度（自动） | 积分器（LQI） | 无 | 状态空间、Riccati |
| **鲁棒**（1980年代–） | H∞估计 | 结构化不确定性 | 纳入设计 | **核心焦点** | H∞扰动衰减 | 小增益定理 | H∞综合、μ综合 |
| **自适应**（1950–90年代） | 在线参数估计 | 适应惯性变化 | 可适应饱和限制 | **核心焦点** | 估计并抵消 | 某些类别（MRAC） | 在线估计、MRAC |
| **QP-MPC**（1980年代–） | 独立估计器 | 时域预测 | **核心焦点** | Min-max变体 | 可测扰动模型 | 无（仅线性） | 滚动时域QP |
| **非线性MPC**（2000年代–） | 移动时域估计 | 非线性预测 | 非线性约束 | 鲁棒NMPC变体 | 扰动模型 | **核心焦点** | DDP、SQP、实时迭代 |
| **学习型**（2010年代–） | 学习观测 | 学习动力学 | 学习安全滤波 | 学习不确定性集 | 学习扰动模式 | **隐式处理** | RL、GP-MPC、神经ODE |

演进方向是同时处理更多问题，用计算量支付。1960年无法在1 kHz求解QP。2020年可以。问题永远是：*给定我的系统实际面临的问题，能处理它们的最简控制器是什么？*

大多数系统不需要完整技术栈。慢动态、宽松规格的温度控制器用PI就行。汽车发动机需要增益调度MPC。火箭着陆需要一切。
