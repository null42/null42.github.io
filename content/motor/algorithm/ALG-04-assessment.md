## 一、概念理解题（★★☆☆☆）

### 题目1：死区时间导致的电压误差与电流极性的关系
**问题：** 三相逆变器中必须插入死区时间以防止桥臂直通，但死区会导致实际输出电压偏离理想电压。请说明：
1. 死区时间如何导致输出电压误差？误差方向与电流极性有什么关系？
2. 死区电压误差的定量表达式是什么？
3. 为什么死区效应在低速轻载时尤为严重？

**参考答案：**
1. 死区期间上下桥臂均关断，相电压由电流方向决定（通过续流二极管导通）：
   - 当电流 $i > 0$（流出逆变器）：死区期间电流通过下管续流二极管流通，输出电压被钳位到负母线，实际输出电压**低于**理想值，电压误差为**负**。
   - 当电流 $i < 0$（流入逆变器）：死区期间电流通过上管续流二极管流通，输出电压被钳位到正母线，实际输出电压**高于**理想值，电压误差为**正**。
   总结：电压误差方向与电流极性相反——电流为正时电压损失，电流为负时电压增加。

2. 死区电压误差的定量表达式：
   $$\Delta V_{dt} = -\frac{T_{dt} + T_{on} - T_{off}}{T_s} \cdot U_{dc} \cdot \text{sign}(i)$$
   其中 $T_{dt}$ 为死区时间，$T_{on}$ 为开关管开通延迟，$T_{off}$ 为关断延迟，$T_s$ 为PWM周期，$U_{dc}$ 为母线电压。简化模型（忽略开关延迟）：
   $$\Delta V_{dt} \approx -\frac{T_{dt}}{T_s} \cdot U_{dc} \cdot \text{sign}(i)$$
   该误差表现为与电流极性相关的方波电压，叠加在理想正弦电压上。

3. 低速轻载时死区效应严重的原因：
   - **低速时基波电压幅值小：** 死区电压误差幅值恒定（仅取决于 $T_{dt}$、$U_{dc}$），而基波电压随转速降低而减小。当基波电压与死区电压可比拟时，畸变率极高。
   - **轻载时电流过零点附近：** 电流幅值小，死区导致的电压误差使电流在过零点附近出现"平顶"畸变（零电流钳位），电流波形严重偏离正弦。
   - 定量举例：$U_{dc} = 24\text{V}$，$T_{dt} = 1\mu\text{s}$，$T_s = 50\mu\text{s}$，死区电压误差幅值 = $24 \times 1/50 = 0.48\text{V}$。若低速时基波相电压幅值仅2V，畸变率高达24%。

## 二、计算分析题（★★★☆☆）

### 题目2：零电流钳位效应的成因和影响
**问题：** 零电流钳位（Zero Current Clamping, ZCC）是死区效应中最棘手的问题之一。请分析：
1. 零电流钳位的物理成因是什么？为什么电流在过零点附近会"停滞"？
2. 零电流钳位对dq轴电流有什么影响？如何体现在电流波形上？
3. 某SPMSM在低速运行时，q轴电流出现周期性波动，频率为基波频率的6倍。请分析这是否与死区/零电流钳位有关，并说明原因。

**参考答案：**
1. **零电流钳位的物理成因：** 当相电流过零时，电流极性不确定，死区电压误差的方向也不确定。在电流过零点附近，死区电压误差试图将电流"推回"零点——电流刚过零向正方向增长时，死区效应产生负电压误差将其拉回；电流刚过零向负方向增长时，死区效应产生正电压误差将其推回。结果电流在零点附近"粘滞"，无法平滑过零，形成平顶区域。

   更深层的原因：在电流极性不确定区域，$\text{sign}(i)$ 函数发生跳变，死区补偿方向突变，导致控制量不连续。此外，电流过零时续流二极管压降（约1~2V）也加剧了钳位效应——电流需要克服二极管压降才能换向。

2. 对dq轴电流的影响：三相电流的零电流钳位导致相电流波形在过零点附近出现平顶畸变，相当于在基波电流上叠加了与电流同频的方波误差。经过Park变换后，方波误差在dq轴上表现为：
   - **6倍频脉动：** 三相方波误差在dq轴上产生6次、12次等偶次谐波脉动
   - **dq轴交叉耦合：** d轴电流出现与q轴电流相关的脉动，反之亦然
   - 电流环PI控制器无法完全抑制这种脉动（带宽有限），导致转矩脉动和速度纹波

3. 6倍频波动与死区直接相关。三相电流各有一个过零点/周期，三相的零电流钳位在dq轴上产生6次/电周期的脉动（因为三相组合效应使谐波次数为基波的6k倍）。这是死区效应的典型特征，可通过以下方法验证：
   - 增大死区时间，观察6倍频脉动是否加剧
   - 施加死区补偿，观察6倍频脉动是否减小
   - 提高电流幅值（远离零电流钳位区），观察脉动是否减小

## 三、工程实践题（★★★★☆）

### 题目3：基于电流极性的死区补偿方法及其局限性
**问题：** 最常用的死区补偿方法是基于电流极性的补偿：根据电流极性在输出电压上叠加补偿量 $\Delta V_{comp} = \frac{T_{dt}}{T_s} U_{dc} \cdot \text{sign}(i)$。请分析：
1. 该方法在电流过零点附近有什么问题？如何改进？
2. 补偿量的精确值受哪些因素影响？仅用 $T_{dt}$ 和 $U_{dc}$ 计算是否足够？
3. 某系统参数：$U_{dc} = 48\text{V}$，$T_{dt} = 0.5\mu\text{s}$，$T_s = 100\mu\text{s}$（10kHz），MOSFET开通延迟 $T_{on} = 30\text{ns}$，关断延迟 $T_{off} = 50\text{ns}$，续流二极管压降 $V_d = 1.2\text{V}$。计算精确的死区补偿电压，并与简化模型对比。

**参考答案：**
1. **电流过零点附近的问题：** $\text{sign}(i)$ 函数在过零点处不连续，补偿量在正负之间跳变，导致：
   - 补偿方向频繁翻转，电流在零点附近振荡
   - 噪声使电流极性判断不稳定，补偿量随机跳变
   - 零电流钳位区域无法正确判断极性，补偿失效

   **改进方法：**
   - **电流极性平滑化：** 用 $\tanh(i / i_{threshold})$ 或线性区替代 $\text{sign}(i)$，在过零点附近连续过渡
   - **滞回比较：** 设定正负极性切换的电流阈值，加入滞回宽度防止频繁切换
   - **基于电压模型的极性判断：** 不依赖电流极性，而是根据参考电压矢量角度判断各相电流极性（因为稳态时电流滞后电压约功率因数角）
   - **扰动观测器法：** 将死区电压视为扰动，通过观测器在线估计并补偿，避免极性判断问题

2. 精确补偿量受以下因素影响：
   - **开关管开通/关断延迟：** $T_{on}$ 使实际开通时刻滞后，$T_{off}$ 使实际关断时刻滞后，有效死区时间 = $T_{dt} + T_{on} - T_{off}$
   - **续流二极管压降：** 死区期间续流二极管导通，压降 $V_d$ 导致实际输出电压偏离母线电压
   - **器件压降：** MOSFET/IGBT的导通压降 $V_{ce,sat}$ 或 $R_{ds,on} \times i$ 影响输出电压
   - **母线电压波动：** $U_{dc}$ 不是恒定值，随负载和电网波动
   - **温度漂移：** 开关延迟和压降随温度变化

   仅用 $T_{dt}$ 和 $U_{dc}$ 的简化模型忽略了上述因素，在精度要求高的场合（如伺服控制）不够。

3. **简化模型：**
   $$\Delta V_{simple} = \frac{T_{dt}}{T_s} U_{dc} = \frac{0.5}{100} \times 48 = 0.24\text{V}$$

   **精确模型：**
   有效死区时间：$T_{eff} = T_{dt} + T_{on} - T_{off} = 0.5 + 0.03 - 0.05 = 0.48\mu\text{s}$
   死区电压误差：$\Delta V_{dt} = \frac{T_{eff}}{T_s} U_{dc} = \frac{0.48}{100} \times 48 = 0.2304\text{V}$
   二极管压降影响：$\Delta V_d = \frac{T_{eff}}{T_s} V_d = \frac{0.48}{100} \times 1.2 = 0.00576\text{V}$
   总补偿电压：$\Delta V_{comp} = \Delta V_{dt} + \Delta V_d = 0.2304 + 0.00576 = 0.2362\text{V}$

   简化模型误差：$(0.24 - 0.2362) / 0.2362 \times 100\% \approx 1.6\%$。本例中开关延迟和二极管压降影响较小（因为 $T_{dt}$ 相对较大），但在 $T_{dt}$ 很小（如100ns）的系统中，这些因素的影响比例显著增大，简化模型误差可达10%以上。
