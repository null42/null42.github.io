## 一、概念理解题（）

### 题目1：无差拍控制与PI控制的本质区别
**问题：** 无差拍电流预测控制（Deadbeat Current Control）是替代传统PI电流环的高性能控制策略。请说明：
1. 无差拍控制的基本原理是什么？为什么叫"无差拍"？
2. 无差拍控制与PI控制在控制结构上有什么本质区别？
3. 无差拍控制相比PI控制有哪些优势和劣势？

**参考答案：**
1. **无差拍控制基本原理：** 基于电机的离散电压方程，直接计算使电流在下一个控制周期达到参考值所需的电压矢量。即已知当前电流 $i(k)$ 和目标电流 $i^*(k+1)$，通过模型反解所需电压 $v(k)$。

   **"无差拍"含义：** 在理想模型和参数完全匹配的情况下，电流误差在一个控制周期内被完全消除（"一拍"达到目标），稳态误差为零，故称"无差拍"（deadbeat——迅速到位，无振荡）。

   离散电压方程（SPMSM为例）：
   $$i_q(k+1) = A_q i_q(k) + B_q v_q(k) + C_q$$
   其中 $A_q = e^{-R_s T_s / L_s}$，$B_q = (1 - A_q) / R_s$，$C_q$ 为反电动势耦合项。

   无差拍控制律：令 $i_q(k+1) = i_q^*(k+1)$，反解：
   $$v_q(k) = \frac{i_q^*(k+1) - A_q i_q(k) - C_q}{B_q}$$

2. **无差拍与PI的本质区别：**

   | 维度 | PI控制 | 无差拍控制 |
   |------|--------|-----------|
   | 控制策略 | 反馈控制，基于误差的增量调节 | 前馈+反馈控制，基于模型的直接计算 |
   | 设计方法 | 频域设计（零极点对消、对称最优） | 时域设计（离散模型反解） |
   | 参数依赖 | 中等（零极点对消依赖 $R_s/L_s$） | 极高（直接依赖 $R_s$、$L_s$、$\psi_f$） |
   | 响应速度 | 2~3个控制周期达到稳态 | 理论上1个周期达到稳态 |
   | 鲁棒性 | 较好（积分项可补偿参数偏差） | 较差（参数偏差直接导致稳态误差） |
   | 超调 | 有超调（取决于带宽设计） | 理论无超调（实际受延迟和参数影响） |
   - PI是"试错式"调节——根据误差方向和大小逐步逼近目标
   - 无差拍是"计算式"控制——根据模型直接算出需要的控制量，一步到位

3. **优势：**
   - 响应速度极快（一个控制周期），适合高动态性能要求的场合
   - 无需PI参数整定，控制律由电机参数直接计算
   - 天然补偿一拍延迟（预测下一拍的电流值），等效提高电流环带宽
   - 适合与MPC（模型预测控制）结合，实现多目标优化

   **劣势：**
   - 参数敏感性极高：$R_s$、$L_s$、$\psi_f$ 的偏差直接转化为电流稳态误差和振荡
   - 对模型精度要求高：忽略的非线性（饱和、交叉耦合）会导致性能下降
   - 延迟和未建模动态可能导致不稳定：实际系统存在一拍延迟、PWM非线性等，理想无差拍条件不满足
   - 缺乏积分作用：无法消除稳态误差（参数偏差时），需要额外积分器或扰动观测器
   - 计算量略大：需要实时计算指数项和反电动势补偿

## 二、计算分析题（）

### 题目2：一拍延迟对无差拍控制稳定性的影响及补偿方法
**问题：** 实际数字控制系统中，当前周期采样的电流用于计算电压，但计算出的电压要到下一个PWM周期才能更新输出，这就是"一拍延迟"。请分析：
1. 一拍延迟如何破坏无差拍控制的"一拍到位"特性？
2. 一拍延迟对无差拍控制稳定性的影响是什么？在什么条件下系统会失稳？
3. 常用的延迟补偿方法有哪些？请推导基于电流预测的延迟补偿公式。

**参考答案：**
1. **一拍延迟破坏无差拍特性的机制：** 理想无差拍控制假设 $v(k)$ 在 $k$ 时刻立即作用于电机，使 $i(k+1) = i^*(k+1)$。但实际系统中：
   - $k$ 时刻采样电流 $i(k)$
   - $k$ 时刻计算电压 $v(k)$
   - $v(k)$ 在 $k+1$ 时刻才通过PWM输出
   - $v(k)$ 实际影响的是 $i(k+2)$ 而非 $i(k+1)$

   因此，无差拍控制律应修改为：令 $i(k+2) = i^*(k+2)$，但 $i(k+1)$ 未知（尚未采样），需要预测。

2. **稳定性影响：** 含一拍延迟的系统，闭环特征方程从一阶变为二阶。以SPMSM的q轴为例，理想无差拍闭环极点在原点（一拍收敛），加入延迟后极点移动，可能出现：
   - 极点移出单位圆 → 系统不稳定
   - 极点靠近单位圆边界 → 振荡加剧

   **失稳条件：** 当电机电感较小、控制周期较大时，离散系统的 $B_q$ 系数较大，延迟导致闭环增益过大，极点逸出单位圆。定量条件与参数有关，一般来说，当 $R_s T_s / L_s$ 较大（即电气时间常数与控制周期可比拟）时，延迟影响更严重。

3. **延迟补偿方法：**

   **方法一：电流预测补偿**
   利用当前采样电流 $i(k)$ 和当前输出电压 $v(k-1)$（上一拍计算、本拍生效的电压），预测 $k+1$ 时刻的电流：
   $$\hat{i}(k+1) = A_q i(k) + B_q v(k-1) + C_q$$
   然后用预测值计算无差拍控制律：
   $$v(k) = \frac{i^*(k+2) - A_q \hat{i}(k+1) - C_q}{B_q}$$

   **方法二：Smith预估器**
   在控制律中引入延迟补偿环节，将延迟从闭环特征方程中移除：
   $$v(k) = \frac{i^*(k+1) - A_q \hat{i}(k+1) - C_q}{B_q}$$
   其中 $\hat{i}(k+1)$ 为Smith预估器的输出。

   **方法三：修改目标函数**
   不追求 $i(k+2) = i^*(k+2)$，而是设计最优控制律使 $i(k+2)$ 尽可能接近 $i^*(k+2)$，同时约束控制量变化率，避免过大的电压跳变。这是MPC的思路。

   **推导电流预测公式（方法一详细推导）：**
   离散状态方程：$i(k+1) = A_q i(k) + B_q v(k) + C_q$

   已知：$i(k)$（采样值），$v(k-1)$（上一拍输出电压）
   预测：$\hat{i}(k+1) = A_q i(k) + B_q v(k-1) + C_q$

   无差拍目标：$i(k+2) = i^*(k+2)$
   $i(k+2) = A_q i(k+1) + B_q v(k) + C_q$
   代入 $\hat{i}(k+1)$：
   $i^*(k+2) = A_q \hat{i}(k+1) + B_q v(k) + C_q$
   解得：
   $$v(k) = \frac{i^*(k+2) - A_q \hat{i}(k+1) - C_q}{B_q}$$
   $$= \frac{i^*(k+2) - A_q[A_q i(k) + B_q v(k-1) + C_q] - C_q}{B_q}$$
   $$= \frac{i^*(k+2) - A_q^2 i(k) - A_q B_q v(k-1) - A_q C_q - C_q}{B_q}$$

   该公式利用了 $i(k)$ 和 $v(k-1)$ 两个已知量，补偿了一拍延迟的影响。

## 三、工程实践题（）

### 题目3：无差拍控制对模型参数精度的敏感性分析
**问题：** 无差拍控制的最大工程挑战是参数敏感性。请分析：
1. 电阻 $R_s$ 偏差对无差拍控制的影响是什么？稳态误差如何计算？
2. 电感 $L_s$ 偏差对无差拍控制的影响是什么？稳定性如何受影响？
3. 某SPMSM参数：$R_s = 0.5\Omega$，$L_s = 1\text{mH}$，$\psi_f = 0.01\text{Wb}$，$T_s = 50\mu\text{s}$。控制中使用的参数为 $\hat{R}_s = 0.4\Omega$（偏差-20%），$\hat{L}_s = 1.1\text{mH}$（偏差+10%）。请计算：
   - 稳态电流误差（参考电流 $i_q^* = 10\text{A}$，$\omega_e = 1000\text{rad/s}$）
   - 闭环极点位置，判断稳定性
4. 提出至少两种降低参数敏感性的工程方法。

**参考答案：**
1. **$R_s$ 偏差的影响：**
   无差拍控制律中 $B_q = (1 - A_q)/R_s$，$R_s$ 偏差导致 $B_q$ 计算错误，输出电压幅值偏差。
   - $\hat{R}_s < R_s$：$B_q$ 偏大，计算电压偏小，电流跟踪不足，稳态误差为正（$i < i^*$）
   - $\hat{R}_s > R_s$：$B_q$ 偏小，计算电压偏大，电流超调甚至振荡
   - 稳态误差：$\Delta i_{ss} \approx \frac{\Delta R_s}{R_s} \cdot i^*$（一阶近似），即电阻偏差直接转化为电流偏差的相同比例

2. **$L_s$ 偏差的影响：**
   $A_q = e^{-R_s T_s / L_s}$，$L_s$ 偏差影响 $A_q$ 和 $B_q$。
   - $\hat{L}_s > L_s$：$A_q$ 偏大（衰减变慢），$B_q$ 偏大，控制增益偏大，可能导致振荡
   - $\hat{L}_s < L_s$：$A_q$ 偏小，$B_q$ 偏小，控制增益偏小，响应变慢
   - 稳定性：$L_s$ 偏差改变闭环极点位置。$\hat{L}_s$ 过大时，极点可能移出单位圆，系统不稳定。临界条件与 $R_s T_s / L_s$ 有关。

3. **具体计算：**
   实际参数：$R_s = 0.5\Omega$，$L_s = 1\text{mH}$
   使用参数：$\hat{R}_s = 0.4\Omega$，$\hat{L}_s = 1.1\text{mH}$

   **实际系统系数：**
   $A_q = e^{-0.5 \times 50\mu/1\text{m}} = e^{-0.025} = 0.9753$
   $B_q = (1 - 0.9753)/0.5 = 0.0494$

   **控制器使用的系数：**
   $\hat{A}_q = e^{-0.4 \times 50\mu/1.1\text{m}} = e^{-0.01818} = 0.9820$
   $\hat{B}_q = (1 - 0.9820)/0.4 = 0.0450$

   **稳态电流误差计算：**
   无差拍控制律（含一拍延迟补偿）：
   $v(k) = \frac{i^* - \hat{A}_q^2 i(k) - \hat{A}_q \hat{B}_q v(k-1) - \hat{A}_q \hat{C}_q - \hat{C}_q}{\hat{B}_q}$

   稳态时 $i(k) = i_{ss}$，$v(k) = v_{ss}$，简化分析（忽略反电动势项）：
   实际系统：$i_{ss} = A_q i_{ss} + B_q v_{ss}$ → $v_{ss} = (1 - A_q) i_{ss} / B_q = R_s i_{ss}$
   控制器输出：$v_{ss} = (1 - \hat{A}_q) i^* / \hat{B}_q = \hat{R}_s i^*$

   联立：$\hat{R}_s i^* = R_s i_{ss}$
   $i_{ss} = \hat{R}_s / R_s \times i^* = 0.4/0.5 \times 10 = 8\text{A}$
   稳态误差：$10 - 8 = 2\text{A}$，即20%偏差！

   考虑反电动势耦合（$\omega_e = 1000\text{rad/s}$）：
   实际反电动势：$E_q = \omega_e \psi_f = 1000 \times 0.01 = 10\text{V}$
   控制器使用的反电动势：$\hat{E}_q = \omega_e \hat{\psi}_f$（假设 $\psi_f$ 准确，$\hat{E}_q = 10\text{V}$）

   含反电动势的稳态：
   $v_{ss} = R_s i_{ss} + E_q = 0.5 \times 8 + 10 = 14\text{V}$
   控制器计算：$v_{ss} = \hat{R}_s i^* + \hat{E}_q = 0.4 \times 10 + 10 = 14\text{V}$
   一致，稳态电流仍为8A。

   **闭环极点分析（简化，忽略延迟补偿）：**
   闭环方程：$i(k+1) = A_q i(k) + B_q \cdot \frac{i^* - \hat{A}_q i(k)}{\hat{B}_q}$
   $= (A_q - B_q \hat{A}_q / \hat{B}_q) i(k) + B_q i^* / \hat{B}_q$

   闭环极点：$p = A_q - B_q \hat{A}_q / \hat{B}_q$
   $= 0.9753 - 0.0494 \times 0.9820 / 0.0450$
   $= 0.9753 - 1.0783 = -0.103$

   极点在单位圆内（$|-0.103| < 1$），系统稳定，但极点为负值，意味着响应会有一个周期的振荡（交替正负）。

4. **降低参数敏感性的工程方法：**

   **方法一：无差拍+积分器（DB-PI混合控制）**
   在无差拍控制律输出上叠加一个慢速积分器，消除参数偏差导致的稳态误差：
   $$v(k) = v_{DB}(k) + K_i \sum (i^* - i) T_s$$
   无差拍项提供快速响应，积分项消除稳态误差。积分增益 $K_i$ 应远小于无差拍增益，避免影响动态性能。

   **方法二：在线参数辨识**
   利用递推最小二乘法（RLS）或模型参考自适应（MRAS）在线辨识 $R_s$ 和 $L_s$，实时更新无差拍控制律中的参数：
   - $R_s$ 辨识：利用稳态电压-电流关系 $R_s = (V - E) / I$
   - $L_s$ 辨识：利用电流动态响应，$L_s = (V - R_s I - E) / (di/dt)$
   - 辨识周期应慢于控制周期（如每100个控制周期更新一次），避免噪声放大

   **方法三：鲁棒无差拍控制**
   在无差拍控制律中引入阻尼项，降低对参数的敏感性：
   $$v(k) = \frac{i^* - \alpha \hat{A}_q i(k) - \hat{C}_q}{\hat{B}_q}$$
   其中 $\alpha < 1$ 为阻尼系数（如 $\alpha = 0.9$），牺牲一拍收敛速度换取鲁棒性。极点从0移到 $(1-\alpha)\hat{A}_q$，远离不稳定边界。

   **方法四：滑模+无差拍混合控制**
   在无差拍控制基础上叠加滑模项，当电流误差超过阈值时激活滑模控制，提供强鲁棒性：
   $$v(k) = v_{DB}(k) + K_{sm} \cdot \text{sat}((i^* - i) / \phi)$$
