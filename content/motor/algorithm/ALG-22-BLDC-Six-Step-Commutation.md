## 1. 📌 核心摘要 ★★★☆☆ 🔰📚

- **一句话：** BLDC六步换相按转子每60°电角度切换一次导通状态，使定子磁场始终领先转子90°电角度附近，用最简单的开关逻辑实现无刷直流电机的转矩输出。

- **认知挂钩：** 如果说FOC是"用坐标系变换把交流电机当直流电机管"的精密方法，六步换相就是"干脆直接用方波把它当真正的直流电机管"的粗暴方法——绕组里通方波电流、转子位置只需知道6个离散区间，照样能让电机转起来。精度换来了简单，70%的应用场景够用。

### 核心流程

```mermaid
flowchart LR
    A["转子位置<br/>6区间检测"] --> B["查换相表<br/>确定导通相"]
    B --> C["两相导通<br/>一相浮空"]
    C --> D["PWM调压<br/>控制电流"]
    D --> E["转矩输出<br/>定子磁场领先转子"]
    E --> A
```

### 六步换相 vs FOC 速览

| 特性 | BLDC六步换相 | FOC矢量控制 |
|------|-------------|------------|
| 转子位置需求 | 6个离散区间（60°分辨率） | 连续角度（<1°分辨率） |
| 传感器 | 3个霍尔（或反EMF过零） | 编码器/观测器 |
| 电流波形 | 方波（两相导通） | 正弦波（三相同时导通） |
| 转矩脉动 | 大（换相纹波） | 小 |
| 电压利用率 | 100%（方波峰值=母线电压） | 86.6%（SVPWM线性区） |
| 转矩密度 | 相同铜损下接近，相同峰值电流下高约33% | 略低 |
| 控制复杂度 | 极低 | 高 |
| 低速性能 | 需特殊启动（无感时） | 优秀 |
| 典型应用 | 无人机/电动自行车/风机 | 伺服/机器人/电动汽车 |

### 为什么六步换相有效？

BLDC电机（梯形反电动势电机）的设计意图是：当转子旋转时，每相绕组的反电动势呈梯形波——平顶区占120°电角度，上升/下降沿各60°。六步换相的物理基础就是**利用这个平顶区**：

1. **平顶区导通**：当某相反电动势处于平顶区（幅值最大且恒定），将该相与另一平顶相通过H桥接入母线，电流流过两相产生转矩。
2. **120°导通角**：每相在一个电周期内导通120°（正向60°+负向60°），浮空240°。三相互差120°，任意时刻恰好两相导通。
3. **60°切换**：转子每转过60°电角度，平顶相组合就变化一次，因此每60°切换一次开关状态——一个电周期6步。

- **关键洞察：** 六步换相能工作，前提是反电动势是梯形波。如果用六步换相驱动正弦反电动势的PMSM，转矩脉动会显著增大——这是BLDC与PMSM的本质区别。

## 3. 📐 原理推导 ★★★★★ 📚

### 3.1 梯形反电动势电机模型

BLDC电机（TrAPZoidal PMSM）的反电动势呈梯形波。以A相为例，一个电周期内的反电动势：

$$
e_a(\theta_e) = \begin{cases}
+K_e \omega_m & 0 \leq \theta_e < \frac{2\pi}{3} \quad (\text{正平顶}) \\
+K_e \omega_m \cdot \left(2 - \frac{3\theta_e}{\pi}\right) & \frac{2\pi}{3} \leq \theta_e < \pi \quad (\text{下降沿}) \\
-K_e \omega_m & \pi \leq \theta_e < \frac{5\pi}{3} \quad (\text{负平顶}) \\
-K_e \omega_m \cdot \left(4 - \frac{3\theta_e}{\pi}\right) & \frac{5\pi}{3} \leq \theta_e < 2\pi \quad (\text{上升沿})
\end{cases}
$$

B、C相平移120°和240°。其中 $K_e$ 为反电动势常数，$\omega_m$ 为机械角速度。

**平顶区占120°电角度**，这是六步换相选择120°导通角的物理依据。

### 3.2 两相导通的转矩分析

假设当前转子位置处于A、C相反电动势平顶区（A正、C负），则导通路径为：

$$
V_{dc} = R_s(i_a - i_c) + L_s \frac{d(i_a - i_c)}{dt} + (e_a - e_c)
$$

由于 $i_a = -i_c = i$（两相串联，电流相等相反）：

$$
V_{dc} = 2R_s i + 2L_s \frac{di}{dt} + 2K_e \omega_m
$$

稳态时忽略电感项：

$$
i = \frac{V_{dc} - 2K_e \omega_m}{2R_s}
$$

**转矩**（只有永磁转矩，无磁阻转矩，因BLDC通常为表贴式 $L_d = L_q$）：

$$
T_e = \frac{P_{elec}}{\omega_m} = \frac{e_a i_a + e_b i_b + e_c i_c}{\omega_m} = \frac{2 K_e \omega_m \cdot i}{\omega_m} = 2 K_e i
$$

- **关键结论：** 稳态转矩与电流成正比，与直流电机完全一致——这正是"无刷直流电机"得名的原因。转矩系数 $K_t = 2K_e$（两相串联，反EMF为 $2K_e\omega_m$）。

> **对比FOC：** FOC中 $T_e = \frac{3}{2}p\psi_f i_q$，转矩系数是 $\frac{3}{2}p\psi_f$。六步换相中 $T_e = 2K_e i$，其中 $K_e$ 是相反电动势常数。由 $K_e = p\psi_f$，得六步换相转矩系数 $2K_e = 2p\psi_f$，FOC为 $1.5p\psi_f$。在相同峰值相电流 $i = i_q$ 下，六步换相转矩比FOC高约33%（$2/1.5$）；但若在相同铜损（有效值电流）下比较，两者接近——方波两相导通的铜损集中在2相，正弦波三相分摊，净转矩密度差异在5%以内。

### 3.3 换相序列——六步表

以转子角度 $\theta_e$ 为0°~360°电角度，定义6个区间，每个区间60°。霍尔传感器输出 $H_a H_b H_c$（3位）指示当前区间，控制器查表确定导通相：

| 步号 | $\theta_e$ 范围 | $H_a H_b H_c$ | 导通相 | 电流路径 | 转矩方向 |
|------|----------------|---------------|--------|---------|----------|
| 1 | 0° ~ 60° | 1 0 1 | A+ B- | Vdc→A→B→GND | + |
| 2 | 60° ~ 120° | 0 0 1 | A+ C- | Vdc→A→C→GND | + |
| 3 | 120° ~ 180° | 0 1 1 | B+ C- | Vdc→B→C→GND | + |
| 4 | 180° ~ 240° | 0 1 0 | B+ A- | Vdc→B→A→GND | + |
| 5 | 240° ~ 300° | 1 1 0 | C+ A- | Vdc→C→A→GND | + |
| 6 | 300° ~ 360° | 1 0 0 | C+ B- | Vdc→C→B→GND | + |

- **换相规律：** 每步只有一相上桥臂导通、一相下桥臂导通、第三相浮空。顺时针旋转时按步号1→2→3→4→5→6循环；逆时针旋转时反向6→5→4→3→2→1。

- **PWM施加位置：** 通常只对下桥臂施加PWM（上桥臂常通），或对上下桥臂都施加PWM（互补PWM+死区）。PWM占空比控制电流幅值从而控制转矩。

### 3.4 换相纹波分析

换相瞬间，电流从即将关断的相切换到即将导通的相。由于绕组电感的存在，电流不能瞬时变化：

- **换相过程：** 设从步1（A+ B-）切换到步2（A+ C-）。B相电流需从 $i$ 降到0，C相电流需从0升到 $i$。

- B相：$L_s \frac{di_b}{dt} = -V_{dc} - e_b$（B相下桥臂关断，通过续流二极管放电）
- C相：$L_s \frac{di_c}{dt} = V_{dc} - e_c$（C相下桥臂导通，电流上升）

由于 $e_b \approx +K_e\omega_m$（B相仍在平顶区尾段），B相续流时间：

$$
t_{fall} \approx \frac{L_s \cdot i}{V_{dc} + K_e \omega_m}
$$

C相上升时间：

$$
t_{rise} \approx \frac{L_s \cdot i}{V_{dc} - K_e \omega_m}
$$

- **关键现象：** $t_{rise} > t_{fall}$（上升慢、下降快），导致换相期间非导通相电流暂时不平衡，产生**换相转矩纹波**。纹波频率为6倍电频率（每60°换相一次）。

- **缓解措施：**
1. **换相重叠法**：提前导通下一相，让电流在换相前就开始建立
2. **电流过采样**：换相期间冻结PWM（不调制），等电流稳定后再恢复
3. **前馈补偿**：根据转速预计算换相重叠时间

## 4. 🔬 无感换相——反EMF过零检测 ★★★★☆ 🔧

### 4.1 为什么需要无感换相

霍尔传感器存在可靠性问题（振动、高温、安装精度），且增加成本。无感BLDC通过检测**非导通相的反电动势过零点**来获取转子位置，每60°一个过零点，正好对应一次换相。

### 4.2 过零检测原理

在任意时刻，两相导通、一相浮空。浮空相的端电压等于其反电动势（无电流流过，绕组压降为零）：

$$
V_{float} = e_{float} + \frac{V_{dc}}{2} \quad (\text{相对于母线中点})
$$

当浮空相反电动势过零（$e_{float} = 0$）时，端电压等于母线中点电压。**过零点后30°电角度即为下一次换相时刻**——这是因为过零点发生在平顶区之间的过渡沿中点，而换相应在平顶区开始时进行。

### 4.3 过零检测实现

```c
/* 反EMF过零检测——比较浮空相端电压与母线中点 */
typedef struct {
    float v_a, v_b, v_c;   // 三相端电压（ADC采样）
    float vbus_mid;        // 母线中点电压 = Vdc/2
    int   sector;          // 当前换相区间 1~6
} bldc_zcd_t;

/* 检测过零点，返回是否触发 */
int bldc_detect_zcd(bldc_zcd_t *b)
{
    float v_float;
    /* 确定浮空相 */
    switch (b->sector) {
        case 1: v_float = b->v_c; break;  /* A+B-导通，C浮空 */
        case 2: v_float = b->v_b; break;  /* A+C-导通，B浮空 */
        case 3: v_float = b->v_a; break;  /* B+C-导通，A浮空 */
        case 4: v_float = b->v_c; break;  /* B+A-导通，C浮空 */
        case 5: v_float = b->v_b; break;  /* C+A-导通，B浮空 */
        case 6: v_float = b->v_a; break;  /* C+B-导通，A浮空 */
    }
    /* 过零判断：浮空相电压穿越母线中点 */
    /* 上升过零（sector 1,3,5）或下降过零（sector 2,4,6）交替 */
    return (v_float > b->vbus_mid) || (v_float < b->vbus_mid);
}
```

### 4.4 30°电角度延迟

过零点到换相点之间有30°电角度延迟。实现方法：

**方法1：定时器延迟法**（适合稳速）

$$
t_{delay} = \frac{30°}{360° \cdot f_e} = \frac{1}{12 f_e} = \frac{1}{12 \cdot \frac{p \cdot n}{60}}
$$

其中 $f_e$ 为电频率，$p$ 为极对数，$n$ 为转速(rpm)。

**方法2：锁相环法**（适合变速，更鲁棒）

用PLL跟踪过零点序列，预测下一次过零和换相时刻，可平滑速度波动。这与 [ALG-07 无感观测器](ALG-07-Sensorless-Observers.md) 中的SMO+PLL结构类似。

### 4.5 无感启动——三段式启动

低速时反EMF幅值 $\propto \omega_m$ 趋于零，过零检测失效。必须采用**三段式启动**：

| 阶段 | 方法 | 转速范围 | 原理 |
|------|------|---------|------|
| 1. 预定位 | 强制给定换相 | 0 | 通某两相，转子被吸引到对应位置（磁阻最小） |
| 2. 强拖加速 | 开环换相，频率斜坡 | 0 ~ 10%额定 | 像同步电机一样强行拖动，频率从低到高 |
| 3. 切换闭环 | 检测到足够反EMF | >10%额定 | 切换到过零检测闭环 |

- **关键参数：** 强拖加速的斜率必须小于转子的机械跟随能力，否则"失步"——转子跟不上定子磁场，转矩崩溃。通常强拖电流设为额定电流的50%~80%以保证足够拖动力矩。

> **对比ALG-08：** [ALG-08 初始位置检测](ALG-08-Initial-Position-Detection.md) 解决的是FOC的0速定位问题，用脉冲注入法。BLDC六步换相的预定位更简单——直接通两相电流，转子自然对齐，但精度只有60°（一个换相区间），这对六步换相已足够。

## 5. 💻 代码实现 ★★★☆☆ 🔧

### 5.1 有感换相核心代码

```c
/* BLDC六步换相——有感（霍尔）版本 */

typedef struct {
    uint8_t hall;           /* 霍尔传感器状态 3位 */
    int    direction;       /* +1正转, -1反转 */
    float  duty;            /* PWM占空比 0~1 */
} bldc_t;

/* 换相表：[hall_state] = {上桥臂相, 下桥臂相} */
/* hall状态 0b101=5 → A+B-, 0b001=1 → A+C-, ... */
static const struct {
    uint8_t high_phase;    /* 上桥臂导通相 (0=A,1=B,2=C) */
    uint8_t low_phase;     /* 下桥臂导通相 */
} comm_table[8] = {
    /* hall: 000(无效) */
    {0xFF, 0xFF},
    /* hall: 001 → A+C- */
    {0, 2},
    /* hall: 010 → B+A-  (反转时) */
    {1, 0},
    /* hall: 011 → B+C- */
    {1, 2},
    /* hall: 100 → C+B-  (反转时) */
    {2, 1},
    /* hall: 101 → A+B- */
    {0, 1},
    /* hall: 110 → C+A- */
    {2, 0},
    /* hall: 111(无效) */
    {0xFF, 0xFF}
};

void bldc_commutate(bldc_t *m)
{
    uint8_t h = m->hall;
    /* 反转时交换上下桥臂的查表 */
    if (m->direction < 0) {
        h = ((h & 0x04) >> 2) | (h & 0x02) | ((h & 0x01) << 2); /* 简化示意 */
    }
    uint8_t hi = comm_table[h].high_phase;
    uint8_t lo = comm_table[h].low_phase;

    /* 关断所有相 */
    pwm_set_duty(0, 0); pwm_set_duty(1, 0); pwm_set_duty(2, 0);
    /* 上桥臂常通（可选PWM） */
    pwm_set_duty(hi, m->duty);
    /* 下桥臂PWM调制 */
    pwm_set_duty(lo, m->duty);
}
```

### 5.2 速度环控制

六步换相的速度环通常是PI控制器，输出PWM占空比：

```c
/* 速度测量：统计单位时间内换相次数 */
float bldc_measure_speed(bldc_t *m, uint32_t now_us)
{
    static uint32_t last_us = 0;
    static int step_count = 0;
    static uint8_t last_hall = 0;

    if (m->hall != last_hall) {
        step_count++;
        last_hall = m->hall;
    }

    float dt = (now_us - last_us) * 1e-6f;
    if (dt > 0.01f) {  /* 10ms计算一次 */
        /* 每电周期6步，step_count步对应 step_count/6 电周期 */
        float elec_freq = step_count / 6.0f / dt;  /* Hz */
        float mech_rpm = elec_freq * 60.0f / POLE_PAIRS;
        step_count = 0;
        last_us = now_us;
        return mech_rpm;
    }
    return -1;  /* 未到计算时刻 */
}
```

### 5.3 对比MC_LIB实现

MC_LIB的六步换相模块（[MC-LIB-Six-Step](./MC-LIB/MC-LIB-Six-Step.md)）提供了更完整的工程实现，包含三种换相方法切换（磁链法/反EMF法/比较器法）、堵转检测、偏置校准等。本模块的简化版用于理解原理，工程实现应参考MC_LIB。

## 6. ⚖️ 六步换相 vs FOC 选型决策 ★★★★☆ 💡

### 6.1 何时选六步换相

| 场景特征 | 原因 |
|---------|------|
| 成本敏感（<100元电调） | 霍尔0.3元 vs 编码器50元，8位MCU vs 32位浮点MCU |
| 转矩脉动可容忍（风机/水泵） | 负载惯量大，脉动被机械滤掉 |
| 调速范围窄（2:1~5:1） | 无需弱磁，无需低速大转矩 |
| 开发周期紧（<1月量产） | 查表换相1周出固件 |
| 振动环境（无人机/电动工具） | 霍尔离散检测抗振远强于高分辨率编码器 |

### 6.2 何时必须选FOC

| 场景特征 | 原因 |
|---------|------|
| 低速大转矩（<10rpm满载） | 六步换相无感低速失效，有感齿槽+换相纹波叠加 |
| 高精度位置控制（伺服/机器人关节） | 60°位置分辨率远不够 |
| 低噪声要求（家电/医疗） | 方波电流噪声大 |
| 宽调速范围（>10:1，需弱磁） | 六步换相弱磁实现困难 |
| 效率优先（电池供电长时间运行） | FOC的MTPA可提升5-15%效率 |

### 6.3 混合策略

高端无人机和电动车控制器常采用**混合策略**：

- **低速段**：用FOC（或六步+有感霍尔）保证启动转矩
- **高速段**：切换到六步换相无感，提升电压利用率和效率
- **切换点**：通常在反EMF足够过零检测的转速（10-15%额定转速）

> **对比ALG-09：** [ALG-09 高频注入](ALG-09-High-Frequency-Injection.md) 解决的是FOC的0速无感问题。BLDC的混合策略是另一个方向——不是让一个方法覆盖全速域，而是在不同速段切换不同方法。

## 7. 🎯 工程案例 ★★★★★ 🎯

### 案例1：植保无人机飞控——六步换相 vs FOC的抉择

- **需求：** 40kg载荷植保无人机，4个8008电机，单价电调预算<80元，要求5秒内启动到额定转速，续航20分钟。

- **分析：**
- 成本：4路电调×80元=320元（六步）vs 4×200元=800元（FOC），差480元
- 启动：六步三段式启动5秒内可达额定（强拖+切换）；FOC无感启动需HFI，调通周期2周
- 效率：六步电压利用率100% vs FOC的86.6%，续航多约8%
- 噪声：无人机本身噪声105dB，电机噪声差异可忽略

- **结论：** 选六步换相无感，成本、效率、开发周期三重优势，唯一劣势（转矩脉动）被大惯量螺旋桨滤掉。

### 案例2：协作机器人关节——为什么不能用六步换相

- **需求：** 6轴协作机器人，关节扭矩波动要求<2%，低速0.5rpm稳定运行（示教模式），位置精度±0.05°。

- **分析：**
- 位置精度：六步换相60°分辨率，即使有霍尔也只有约1°（60°/6步量化），远不够±0.05°
- 低速：0.5rpm时反EMF趋零，无感完全失效；有感霍尔的60°分辨率导致0.5rpm下每秒仅0.25步，步进式运行
- 转矩脉动：六步换相6倍电频率纹波，在关节处直接传递到末端，2%要求不可能达到

- **结论：** 必须用FOC+17位编码器，六步换相完全不适合精密伺服场景。

### 案例3：电动自行车控制器——成本与性能的平衡

- **需求：** 350W轮毂电机（外转子BLDC，极对数20），控制器成本<30元，调速范围0-25km/h，要求爬坡能力。

- **分析：**
- 外转子20极对数，低速大转矩需求（爬坡），无感启动需三段式
- 30元成本：8位MCU（如STM8S）+3个比较器（反EMF过零硬件检测）+6个MOSFET
- 六步换相在轮毂电机上效率约85%，FOC可到92%但成本翻倍

- **结论：** 六步换相无感+比较器硬件过零检测，成本最优方案。爬坡性能通过限流保护+人工启动助力（踩两下再拧把）弥补低速无感缺陷。

## 9. 📝 本节要点总结

1. **六步换相的本质**：按转子60°电角度切换导通相，利用梯形反EMF的平顶区，实现类直流电机的转矩控制。
2. **转矩系数**：$T_e = 2K_e i$（两相串联），相同铜损下与FOC的 $\frac{3}{2}p\psi_f i_q$ 相当，相同峰值电流下高约33%，但无法独立控制id/iq。
3. **换相纹波**：6倍电频率，源于电流换相时上升慢下降快的不对称，可通过重叠法/前馈缓解。
4. **无感检测**：浮空相端电压过零点，延迟30°电角度换相；低速失效需三段式启动。
5. **选型决策**：成本/效率/开发周期优先选六步，精度/低速/低噪/宽调速优先选FOC。
6. **混合策略**：低速FOC+高速六步切换，兼顾启动性能和高速效率，是无人机/电动车的高端方案。
