## 一、概念理解题（★★☆☆☆）

### 题目1：非线性磁链观测器低速优势的根源
**问题：** 为什么非线性磁链观测器在低速时性能优于SMO？请从信号幅值、噪声抑制和漂移补偿三个维度进行对比分析，并说明为什么SMO在低速时"失效"而非"精度下降"。

**参考答案：**

| 维度 | SMO | 非线性磁链观测器 |
|------|-----|----------------|
| **信号幅值** | 提取反电动势$e = \omega_e \psi_f$，低速时$e \to 0$，信号消失 | 提取磁链$\psi_f$，幅值与转速无关，低速时信号仍存在 |
| **噪声抑制** | 低速时反电动势信噪比极低，滑模控制量$z$中信号被噪声淹没 | 磁链幅值恒定，低速时信噪比远高于SMO |
| **漂移补偿** | 无积分环节，不存在漂移问题，但也没有低速信息 | 通过非线性反馈$-\gamma(\hat{\psi} - L_d i)$抑制漂移，低速时γ大，电流模型提供可靠参考 |

SMO在低速时"失效"而非"精度下降"的原因：反电动势$e = \omega_e \psi_f$与转速成正比，当$\omega_e \to 0$时，反电动势趋近于零，信号完全被噪声淹没，滑模面无法维持——这不是精度问题，而是可观测性丧失。而磁链$\psi_f$在整个速度范围内近似恒定，低速时仍可作为可观测量。

## 二、原理分析题（★★★☆☆）

### 题目2：反馈增益γ的作用与自适应设计
**问题：** 非线性磁链观测器方程为：
$$\frac{d\hat{\psi}_\alpha}{dt} = u_\alpha - R_s i_\alpha - \gamma(\hat{\psi}_\alpha - L_d i_\alpha)$$
1. 当$\gamma = 0$时，观测器退化为哪种形式？有什么问题？
2. 当$\gamma \to \infty$时，观测器趋近于哪种模型？有什么问题？
3. 为什么γ需要随速度自适应？如果γ固定为某个中间值会怎样？
4. 请设计一个指数衰减型γ自适应律，要求：零速时$\gamma = 3000$，额定转速时$\gamma = 10$，过渡平滑。

**参考答案：**

1. $\gamma = 0$时，方程退化为纯积分器：
   $$\hat{\psi}_\alpha = \int(u_\alpha - R_s i_\alpha)dt$$
   即ALG-07中的线性磁链观测器（电压模型）。问题：纯积分器存在直流漂移，Rs误差和电流偏置随时间累积，导致磁链估计持续偏移，角度估算失效。

2. $\gamma \to \infty$时，反馈项主导，要求$\hat{\psi}_\alpha - L_d i_\alpha \to 0$，即$\hat{\psi}_\alpha \to L_d i_\alpha$。这等价于电流模型：$\psi_{f\alpha} = 0$（忽略永磁体磁链），角度信息丢失。更准确地说，当γ很大时，观测器快速跟踪电流模型$\psi_\alpha^{model} = L_d i_d^{model} + \psi_f$，此时角度估计完全依赖电流模型，而电流模型本身需要角度估计值（Park变换），形成正反馈环路，高速时角度误差会被放大。

3. γ固定为中间值的问题：
   - 低速时γ不够大→漂移抑制不足→角度缓慢偏移
   - 高速时γ过大→电流模型误差被引入→角度精度下降
   - 无法同时满足低速抗漂移和高速高精度的需求
   - 自适应设计本质上是**在电压模型（高速可信）和电流模型（低速可信）之间动态切换权重**

4. 指数衰减型自适应律：
   $$\gamma(\omega) = \gamma_{min} + (\gamma_{max} - \gamma_{min}) \cdot e^{-|\omega|/\omega_c}$$
   其中$\gamma_{max} = 3000$，$\gamma_{min} = 10$。
   
   零速时：$\gamma(0) = 10 + 2990 \cdot e^0 = 3000$ ✓
   
   额定转速$\omega_{rated}$时：$\gamma(\omega_{rated}) = 10 + 2990 \cdot e^{-\omega_{rated}/\omega_c} = 10$
   
   解得：$e^{-\omega_{rated}/\omega_c} = 0$，实际取$e^{-\omega_{rated}/\omega_c} \approx 0$即可，即$\omega_c \approx \omega_{rated}/3 \sim \omega_{rated}/5$。

### 题目3：直流漂移问题与非线性补偿机制
**问题：** 纯积分磁链观测器存在直流漂移问题：
$$\psi = \int(e_{ac} + e_{dc})dt = \psi_{ac} + e_{dc} \cdot t$$
1. ALG-07中线性磁链观测器用低通滤波器替代纯积分来抑制漂移，请分析这种方法在低速时的根本矛盾。
2. 非线性磁链观测器的反馈补偿项$-\gamma(\hat{\psi}_\alpha - L_d i_\alpha)$如何解决这个矛盾？请从频域角度分析。
3. 假设Rs存在2%误差，$R_s = 0.5\Omega$，稳态电流$i_\alpha = 5A$，$\gamma = 2000$，$\psi_f = 0.05Wb$。计算稳态磁链估计误差和对应的角度误差。

**参考答案：**

1. 低通滤波器替代纯积分的矛盾：
   - 传递函数：$G(s) = \frac{1}{s + \omega_c}$
   - 低速时信号频率$\omega_e$很低，要有效滤波需$\omega_c \ll \omega_e$，但这会导致严重的相位滞后$\phi = -\arctan(\omega_e/\omega_c)$
   - 例如：$\omega_e = 10$ rad/s（约1.6Hz），$\omega_c = 5$ rad/s时，相位滞后$\phi = -63.4°$，角度误差巨大
   - 若$\omega_c = 50$ rad/s减小相位滞后，则直流抑制能力大幅下降
   - **根本矛盾：截止频率无法同时满足低速相位精度和直流抑制**

2. 非线性补偿的频域分析：
   将观测器方程拉普拉斯变换：
   $$\hat{\psi}_\alpha(s) = \frac{1}{s + \gamma}(u_\alpha(s) - R_s i_\alpha(s)) + \frac{\gamma L_d}{s + \gamma} i_\alpha(s)$$
   
   转子磁链估计：
   $$\hat{\psi}_{f\alpha}(s) = \hat{\psi}_\alpha(s) - L_d i_\alpha(s) = \frac{s}{s + \gamma} \cdot \frac{u_\alpha(s) - R_s i_\alpha(s)}{s} - \frac{\gamma L_d}{s + \gamma} i_\alpha(s)$$
   
   第一项$\frac{s}{s+\gamma}$是**高通滤波器**——直流分量（漂移）被阻断，交流分量（有用信号）通过。这正是解决漂移问题的关键：纯积分器$\frac{1}{s}$产生的直流累积被高通特性消除。
   
   第二项是电流模型的低通滤波版本——低速时（γ大）电流模型主导，提供可靠的磁链参考。
   
   **与低通滤波器替代法的本质区别：** 低通滤波法$\frac{1}{s+\omega_c}$在信号通带内引入相位滞后；非线性补偿法$\frac{s}{s+\gamma}$在信号通带内相位趋近0°（当$\omega \gg \gamma$时），高速时几乎无相位失真。

3. 稳态误差计算：
   - Rs误差：$\Delta R_s = 0.02 \times 0.5 = 0.01\Omega$
   - 电压模型误差：$\Delta e = \Delta R_s \cdot i_\alpha = 0.01 \times 5 = 0.05V$
   - 稳态时$\frac{d\hat{\psi}_\alpha}{dt} = 0$，由观测器方程：
     $$0 = \Delta e - \gamma \cdot \Delta\hat{\psi}_{f\alpha}$$
     $$\Delta\hat{\psi}_{f\alpha} = \frac{\Delta e}{\gamma} = \frac{0.05}{2000} = 2.5 \times 10^{-5} Wb$$
   - 角度误差：$\Delta\theta \approx \frac{\Delta\hat{\psi}_{f\alpha}}{\psi_f} = \frac{0.000025}{0.05} = 0.0005 \text{ rad} \approx 0.029°$
   
   **对比纯积分器：** 纯积分器1秒后漂移$\Delta\psi = 0.05 Wb$，角度误差$\approx 45°$。非线性补偿将稳态误差降低了2000倍（等于γ值），效果显著。

## 三、工程实践题（★★★★★）

### 题目4：观测器方程的离散化与数值稳定性
**问题：** 非线性磁链观测器连续时间方程为：
$$\frac{d\hat{\psi}_\alpha}{dt} = u_\alpha - R_s i_\alpha - \gamma(\hat{\psi}_\alpha - L_d i_\alpha)$$
1. 分别用前向欧拉法、双线性变换（Tustin法）和精确离散化（零阶保持）推导离散方程。
2. 分析三种方法的数值稳定性条件。当$T_s = 50\mu s$，$\gamma = 5000$时，哪种方法可能不稳定？
3. 在STM32G431（Cortex-M4，168MHz，硬件FPU）上实现精确离散化版本，估算计算耗时。exp()函数是否有必要？如何优化？
4. Whan-FOC项目中的LESO使用了Simulink生成的代码，其积分步长为0.0001s（10kHz）。如果将控制频率提高到20kHz，LESO的数值稳定性是否会受影响？为什么？

**参考答案：**

1. 三种离散化方法：

   **前向欧拉法：**
   $$\hat{\psi}_\alpha(k+1) = \hat{\psi}_\alpha(k) + T_s[u_\alpha(k) - R_s i_\alpha(k) - \gamma(\hat{\psi}_\alpha(k) - L_d i_\alpha(k))]$$
   化简：
   $$\hat{\psi}_\alpha(k+1) = (1 - \gamma T_s)\hat{\psi}_\alpha(k) + T_s[u_\alpha(k) - R_s i_\alpha(k) + \gamma L_d i_\alpha(k)]$$

   **双线性变换（Tustin法）：**
   $$\hat{\psi}_\alpha(k+1) = \frac{2 - \gamma T_s}{2 + \gamma T_s}\hat{\psi}_\alpha(k) + \frac{T_s}{2 + \gamma T_s}[(u_\alpha(k) - R_s i_\alpha(k) + \gamma L_d i_\alpha(k)) + (u_\alpha(k-1) - R_s i_\alpha(k-1) + \gamma L_d i_\alpha(k-1))]$$

   **精确离散化（零阶保持）：**
   $$\hat{\psi}_\alpha(k+1) = e^{-\gamma T_s}\hat{\psi}_\alpha(k) + \frac{1 - e^{-\gamma T_s}}{\gamma}[u_\alpha(k) - R_s i_\alpha(k) + \gamma L_d i_\alpha(k)]$$

2. 数值稳定性分析：

   **前向欧拉法：** 稳定条件为$|1 - \gamma T_s| < 1$，即$\gamma T_s < 2$。
   当$T_s = 50\mu s$，$\gamma = 5000$时：$\gamma T_s = 0.25 < 2$，稳定。
   但若$\gamma = 50000$：$\gamma T_s = 2.5 > 2$，**不稳定**！

   **双线性变换：** 无条件稳定。$\frac{2 - \gamma T_s}{2 + \gamma T_s}$的绝对值始终小于1（当$\gamma > 0$时）。

   **精确离散化：** 无条件稳定。$e^{-\gamma T_s} \in (0, 1)$（当$\gamma > 0$时）。

   **结论：** 前向欧拉法在$\gamma$很大时可能不稳定。实际中$\gamma_{max}$通常不超过5000，$\gamma T_s = 0.25$，远小于2，前向欧拉法是安全的。但如果需要更大的$\gamma$（如某些零速应用），应使用双线性变换或精确离散化。

3. 精确离散化在STM32G431上的实现：

   计算量分析：
   - 1次exp()计算：软件浮点库约50~100个时钟周期 ≈ 0.3~0.6μs
   - 4次浮点乘法 + 3次加法：约7个时钟周期 ≈ 0.04μs
   - PLL的sin/cos：查表法约0.5μs
   - 总计约1~1.5μs，远小于50μs控制周期

   **exp()优化：** 由于$\gamma T_s$通常很小（0.01~0.5），可用一阶近似：
   $$e^{-\gamma T_s} \approx 1 - \gamma T_s + \frac{(\gamma T_s)^2}{2}$$
   误差在$\gamma T_s = 0.25$时仅0.8%，完全可接受。这样避免了exp()函数调用，计算时间降至0.2μs以内。

   更优方案：预计算$\gamma$对应的$e^{-\gamma T_s}$和$\frac{1-e^{-\gamma T_s}}{\gamma}$两个系数，在γ变化时更新，观测器更新时仅做乘加运算。

4. Whan-FOC LESO的数值稳定性：

   Simulink生成的LESO代码使用固定步长0.0001s（10kHz）。如果将控制频率提高到20kHz（$T_s = 50\mu s$）：
   
   - LESO的积分步长减半，数值精度提高（欧拉法的截断误差$\propto T_s$）
   - 稳定性改善：$\gamma T_s$减半，离稳定边界更远
   - 但Simulink生成的代码中系数是硬编码的（如`0.0001F`），直接改频率会导致系数不匹配
   - 需要在Simulink中重新设置步长并重新生成代码，而非简单修改采样周期
   
   **结论：** 频率提高对稳定性有利，但Simulink自动生成代码的硬编码系数需要重新生成。

### 题目5：零速闭环启动策略设计
**问题：** 某IPMSM参数：$R_s = 0.3\Omega$，$L_d = 0.8mH$，$L_q = 1.2mH$，$\psi_f = 0.025Wb$，极对数$p = 4$，额定转速3000rpm。要求设计基于非线性磁链观测器的零速闭环启动策略。
1. 设计γ自适应律的参数（$\gamma_{max}$, $\gamma_{min}$, $\omega_{low}$, $\omega_{high}$），并给出设计依据。
2. 设计PLL参数（$K_p$, $K_i$），使PLL带宽约为30Hz，阻尼比0.707。
3. 零速时如何建立初始角度？请给出完整的启动状态机流程（从上电到闭环运行）。
4. 如果电机带载启动（负载转矩为额定转矩的30%），启动策略需要做哪些调整？
5. 从零速加速到额定转速的过程中，观测器经历了哪几个阶段？每个阶段的主要误差源是什么？

**参考答案：**

1. γ自适应律参数设计：

   额定电角速度：$\omega_{e,rated} = 2\pi \times \frac{3000}{60} \times 4 = 1257 \text{ rad/s}$

   - $\gamma_{max}$：要求在0.5秒内抑制漂移，$\gamma_{max} \geq 2/0.5 = 4$。考虑电流模型在零速的可靠性，取$\gamma_{max} = 2000$（约3个电周期的收敛时间@10Hz电频率）
   - $\gamma_{min}$：高速时尽量接近纯积分，取$\gamma_{min} = 5$（保留微弱抗漂移能力）
   - $\omega_{low}$：电流模型可信的速度上限，取10%额定电角速度 = 126 rad/s
   - $\omega_{high}$：电压模型可信的速度下限，取20%额定电角速度 = 251 rad/s

2. PLL参数设计：

   自然频率：$\omega_n = 2\pi \times 30 = 188.5 \text{ rad/s}$
   
   阻尼比：$\zeta = 0.707$
   
   PLL误差增益：$K_{err} = \psi_f = 0.025$
   
   $$K_p = \frac{2\zeta\omega_n}{K_{err}} = \frac{2 \times 0.707 \times 188.5}{0.025} = 10668$$
   
   $$K_i = \frac{\omega_n^2}{K_{err}} = \frac{188.5^2}{0.025} = 1420890$$
   
   **注意：** 上述$K_i$值过大，实际工程中需根据速度环带宽和噪声水平适当降低。典型取$K_p = 2000 \sim 5000$，$K_i = 50000 \sim 200000$，通过实验微调。

3. 零速启动状态机：

   ```text
   状态1：预定位（ALIGN）
   ├── 给定Id = 50%额定电流，Iq = 0
   ├── 角度强制为0°（d轴对齐A相）
   ├── 持续时间：200ms（确保转子稳定到位）
   └── 同时初始化观测器：γ = γ_max，ψα = Ld·Id + ψf，ψβ = 0
   
   状态2：零速闭环建立（ZERO_SPEED_LOCK）
   ├── 切换到FOC闭环，角度来源=观测器
   ├── γ = γ_max（电流模型主导）
   ├── PLL以预定位角度为初始值
   ├── 检验：|ψfα·sin(θ) - ψfβ·cos(θ)| < ε 持续50ms
   └── 通过→状态3；超时5s→故障
   
   状态3：低速加速（LOW_SPEED_RAMP）
   ├── 速度给定斜坡增加
   ├── γ随速度自适应减小
   ├── 速度达到ω_low→状态4
   └── 若角度误差>15°持续100ms→回退状态1
   
   状态4：正常运行（RUNNING）
   ├── 全速域非线性磁链观测器
   ├── γ按自适应律调节
   └── 常规保护监控
   ```

4. 带载启动调整：

   - **预定位电流增大：** Id从50%额定提高到80~100%额定，确保负载转矩下转子不滑移
   - **零速闭环建立阶段增加Iq：** 预定位时不仅给定Id，还需根据负载估算给定小量Iq以产生保持力矩
   - **加速斜坡减缓：** 带载时加速度受限于电磁转矩裕量，斜坡速率降低
   - **增加失步检测：** 监测观测器角度与开环角度的偏差，超过阈值时回退到开环
   - **考虑HFI辅助：** 若负载较大，零速时仅靠电流模型可能不够稳定，可叠加HFI提高角度精度

5. 加速过程的阶段分析：

   | 阶段 | 速度范围 | γ值 | 主导模型 | 主要误差源 |
   |------|---------|-----|---------|-----------|
   | 零速锁定 | 0 | γ_max | 电流模型 | Ld/Lq参数误差、ψf误差 |
   | 低速过渡 | 0~ω_low | γ_max→递减 | 电流模型→混合 | γ切换瞬态、Rs温度漂移 |
   | 中速混合 | ω_low~ω_high | 递减 | 混合 | 电压模型与电流模型不一致 |
   | 高速运行 | >ω_high | γ_min | 电压模型（积分） | Rs温度漂移、死区电压误差 |

   **最关键阶段是低速过渡区**：γ从最大值开始减小，观测器从电流模型主导切换到电压模型主导。如果γ减小过快，电压模型尚未足够精确（反电动势仍较小），角度可能出现跳变。解决方案：确保过渡区足够宽（ω_high/ω_low ≥ 2），γ变化率限制。
