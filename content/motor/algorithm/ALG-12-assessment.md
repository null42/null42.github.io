## 一、概念理解题（）

### 题目1：速度环PI参数设计的对称最优法原理
**问题：** 对称最优法（Symmetrical Optimum, SO）是速度环PI参数设计的经典方法。请说明：
1. 对称最优法的基本原理是什么？为什么叫"对称最优"？
2. 对称最优法与零极点对消法（电流环设计方法）有什么本质区别？
3. 对称最优法设计的速度环开环传递函数有什么特征？相位裕度是多少？

**参考答案：**
1. **对称最优法原理：** 速度环的被控对象包含电流环（近似为一阶惯性环节 $1/(T_i s + 1)$）和机械惯性（积分环节 $1/J s$），开环传递函数为：
   $$G_{ol}(s) = K_{p,spd} \frac{T_{i,spd} s + 1}{T_{i,spd} s} \cdot \frac{1}{T_i s + 1} \cdot \frac{1}{J s}$$
   对称最优法通过选择PI零点 $\omega_z = 1/T_{i,spd}$，使开环对数幅频特性以 $-20\text{dB/dec}$ 的斜率穿过穿越频率 $\omega_c$，且穿越频率恰好位于PI零点和电流环极点的几何中点：
   $$\omega_c = \sqrt{\omega_z \cdot \omega_p} = \sqrt{\frac{1}{T_{i,spd}} \cdot \frac{1}{T_i}}$$
   "对称最优"的含义：穿越频率在对数坐标轴上对称地位于零点和极点之间，使系统在给定阻尼下获得最大带宽。

   对称最优法的PI参数公式：
   $$T_{i,spd} = a^2 T_i$$
   $$K_{p,spd} = \frac{J}{a T_i}$$
   其中 $a$ 为设计参数（典型值 $a = 2$），$T_i$ 为电流环等效时间常数，$J$ 为转动惯量。

2. **与零极点对消法的本质区别：**
   - **零极点对消法：** 用PI零点对消被控对象极点（$K_i/K_p = R_s/L_s$），将高阶系统降为一阶，设计简单但对参数敏感（对消失效时性能恶化）
   - **对称最优法：** 不对消极点，而是通过零点配置使开环频率特性对称，兼顾带宽和稳定性。适用于被控对象含积分环节（如速度环），零极点对消法无法直接应用
   - 零极点对消法适用于电流环（对象为一阶惯性），对称最优法适用于速度环（对象含积分+惯性）

3. **开环传递函数特征：**
   - 在穿越频率附近，幅频特性以 $-20\text{dB/dec}$ 穿越零分贝线，保证稳定性
   - 当 $a = 2$ 时，相位裕度 $\gamma = \arctan(a) - \arctan(1/a) = \arctan(2) - \arctan(0.5) = 63.4° - 26.6° = 36.8°$
   - 该相位裕度偏小，实际工程中常取 $a = 2 \sim 4$，$a = 3$ 时相位裕度约46°，更为稳健
   - 闭环阶跃响应有约43%的超调（$a = 2$ 时），可通过给定滤波器（前馈滤波）抑制超调

## 二、计算分析题（）

### 题目2：负载转矩观测器（扰动观测器）的设计原理
**问题：** 负载转矩观测器（Disturbance Observer, DOB）可以显著提高速度环的抗扰动性能。请分析：
1. 负载转矩观测器的基本原理是什么？它如何估计未知的负载转矩？
2. 降阶观测器和全阶观测器有什么区别？各自优缺点是什么？
3. 某系统参数：$J = 0.005\text{kg·m}^2$，$B = 0.01\text{N·m·s/rad}$，速度环控制周期 $T_s = 1\text{ms}$。请设计一个简单的负载转矩降阶观测器，给出离散域方程和观测器增益选取原则。

**参考答案：**
1. **负载转矩观测器原理：** 机械运动方程为：
   $$J\dot{\omega} = T_e - T_L - B\omega$$
   其中 $T_e$ 为电磁转矩（已知），$T_L$ 为负载转矩（未知），$\omega$ 为转速（可测量）。

   假设负载转矩变化缓慢（$\dot{T}_L \approx 0$），将 $T_L$ 扩展为状态变量，系统增广为：
   $$\dot{\omega} = -\frac{B}{J}\omega + \frac{1}{J}T_e - \frac{1}{J}T_L$$
   $$\dot{T}_L = 0$$

   观测器通过构建 $\omega$ 的观测模型，利用观测误差（$\hat{\omega} - \omega$）的反馈来修正 $T_L$ 的估计值。当观测器收敛后，$\hat{T}_L$ 即为负载转矩的估计值。

2. **降阶观测器 vs 全阶观测器：**

   | 维度 | 降阶观测器 | 全阶观测器 |
   |------|-----------|-----------|
   | 状态变量 | 仅估计 $T_L$（$\omega$ 直接测量） | 同时估计 $\omega$ 和 $T_L$ |
   | 阶数 | 1阶 | 2阶 |
   | 计算量 | 小 | 较大 |
   | 抗噪声 | 较差（直接使用测量速度的微分） | 较好（通过模型滤波） |
   | 精度 | 速度测量噪声大时精度差 | 可以滤除速度测量噪声 |
   | 适用场景 | 编码器精度高、速度噪声小 | 霍尔传感器或低速采样，速度噪声大 |

3. **降阶观测器设计：**

   连续域观测器方程：
   $$\dot{\hat{T}}_L = L_{obs}(\dot{\omega} + \frac{B}{J}\omega - \frac{1}{J}T_e + \frac{1}{J}\hat{T}_L)$$
   其中 $L_{obs}$ 为观测器增益。利用机械方程替换 $\dot{\omega}$：
   $$\dot{\hat{T}}_L = \frac{L_{obs}}{J}(\hat{T}_L - T_L)$$
   误差方程：$\dot{e} = \frac{L_{obs}}{J} e$，要求 $L_{obs} < 0$ 保证收敛。

   离散化（一阶欧拉法，$T_s = 1\text{ms}$）：
   ```c
   // 观测器更新（每个速度环周期执行）
   omega_err = omega_meas - omega_model;  // 速度观测误差
   Tl_est += L_obs * omega_err * Ts;       // 更新负载转矩估计
   omega_model += (Te - B*omega_model - Tl_est) / J * Ts;  // 更新模型速度
   ```

   **增益选取原则：**
   - 观测器极点 $p_{obs} = L_{obs}/J$，应比速度环带宽快3~5倍，但比电流环带宽慢
   - 若速度环带宽50Hz（$\omega_{spd} = 314\text{rad/s}$），观测器极点取 $\omega_{obs} = 1000 \sim 1500\text{rad/s}$
   - $L_{obs} = J \times \omega_{obs} = 0.005 \times 1200 = -6.0$（负值保证收敛）
   - 观测器极点不能过大，否则速度测量噪声被放大，$\hat{T}_L$ 高频振荡

## 三、工程实践题（）

### 题目3：速度环带宽与电流环带宽的约束关系（10:3:1法则）
**问题：** 串级控制系统中，内环带宽必须远高于外环带宽，这是保证系统稳定性和解耦性的基本要求。电机控制中常引用"10:3:1法则"。请分析：
1. "10:3:1法则"的具体含义是什么？三个数字分别代表什么？
2. 为什么外环带宽必须远低于内环带宽？如果速度环带宽接近电流环带宽会怎样？
3. 某伺服系统要求速度环带宽200Hz，请按照10:3:1法则设计电流环和位置环带宽，并计算各环路的PI参数约束。

**参考答案：**
1. **"10:3:1法则"含义：** 在位置-速度-电流三环串级控制中，各环路带宽之比约为10:3:1，即：
   - 电流环带宽 : 速度环带宽 : 位置环带宽 = 10 : 3 : 1
   - 例如：电流环1000Hz，速度环300Hz，位置环100Hz

   该法则确保内环对外环指令的响应足够快，外环看到的内环近似为比例环节（无动态延迟），从而实现各环路的近似解耦设计和独立整定。

2. **外环带宽必须远低于内环带宽的原因：**
   串级控制的前提是内环的动态响应远快于外环，这样外环设计时可以将内环近似为比例环节（增益为1），忽略其动态特性。如果速度环带宽接近电流环带宽：
   - **内环动态不可忽略：** 速度环设计时不能将电流环简化为比例环节，必须考虑电流环的相位滞后，导致速度环设计复杂化
   - **环路耦合：** 速度环和电流环的动态特性相互影响，可能出现共振峰，系统不稳定
   - **相位裕度下降：** 电流环在速度环穿越频率处贡献的相位滞后增大，速度环相位裕度降低
   - **振荡风险：** 两个带宽接近的环路可能产生拍频振荡，频率约为两个带宽之差

   定量分析：如果速度环穿越频率 $\omega_{c,spd}$ 处电流环的相位滞后为 $\phi_i$，则速度环的相位裕度减少 $\phi_i$。当 $\omega_{c,spd} = 0.3 \omega_{c,cur}$ 时，电流环相位滞后约 $\arctan(0.3) \approx 16.7°$，可接受；当 $\omega_{c,spd} = 0.8 \omega_{c,cur}$ 时，相位滞后约 $\arctan(0.8) \approx 38.7°$，严重影响稳定性。

3. **按10:3:1法则设计：**
   速度环带宽200Hz → 电流环带宽 $\approx 200 \times 10/3 \approx 667\text{Hz}$ → 位置环带宽 $\approx 200 \times 1/3 \approx 67\text{Hz}$

   **电流环PI参数约束：**
   - 电流环带宽 $\omega_{c,cur} = 2\pi \times 667 = 4189\text{rad/s}$
   - 零极点对消法：$K_p = L_s \cdot \omega_{c,cur}$，$K_i = R_s \cdot \omega_{c,cur}$
   - 要求：电流环控制周期 $\leq 1/(10 \times f_{c,cur}) = 1/6670 \approx 150\mu\text{s}$，即PWM频率 $\geq 6.67\text{kHz}$

   **速度环PI参数约束：**
   - 速度环带宽 $\omega_{c,spd} = 2\pi \times 200 = 1257\text{rad/s}$
   - 对称最优法：$T_{i,spd} = a^2 / \omega_{c,cur}$，$K_{p,spd} = J \cdot \omega_{c,spd} / a$
   - 取 $a = 3$：$T_{i,spd} = 9 / 4189 = 2.15\text{ms}$，$K_{p,spd} = J \times 1257 / 3 = 419J$
   - 要求：速度环控制周期 $\leq 1/(10 \times f_{c,spd}) = 0.5\text{ms}$

   **位置环参数约束：**
   - 位置环带宽 $\omega_{c,pos} = 2\pi \times 67 = 421\text{rad/s}$
   - 位置环通常为P控制（无积分），$K_{p,pos} = \omega_{c,pos}$
   - 要求：位置环控制周期 $\leq 1/(10 \times f_{c,pos}) = 1.5\text{ms}$

   **工程注意事项：**
   - 10:3:1是经验法则，实际比例可根据系统特性调整（如4:2:1或15:5:1）
   - 电流环带宽受PWM频率和采样延迟限制，不是可以无限提高的
   - 速度环带宽受机械共振频率限制，超过共振频率的1/3可能激发机械振荡
   - 位置环带宽受速度环带宽和机械刚性约束
