## 第1题：V模型与测试层级

**题目：** 在V模型中，系统设计阶段对应右侧的哪个验证层级？

A. 单元测试

B. 集成测试

C. 系统测试

D. 验收测试

**正确答案：** C

**详细解析：**

V模型的核心原则是**每一层设计都有对应的验证层**，形成对称关系：

| 左侧（设计） | 右侧（验证） | 对应关系 |
|-------------|-------------|---------|
| 需求分析 | 验收测试 | 验证需求是否满足 |
| 系统设计 | 系统测试 | 验证系统级设计是否正确实现 |
| 详细设计 | 集成测试 | 验证模块接口和数据流 |
| 编码实现 | 单元测试 | 验证代码逻辑正确性 |

系统设计定义了系统的整体架构、模块划分和接口规范，系统测试验证这些系统级设计是否正确实现。因此系统设计对应系统测试。

**选项A错误**：单元测试对应编码实现。**选项B错误**：集成测试对应详细设计。**选项D错误**：验收测试对应需求分析。

## 第2题：HIL测试的核心价值

**题目：** 以下哪个问题是HIL测试能发现而软件仿真（MIL/SIL）无法发现的？

A. PI控制器比例增益设置过大导致振荡

B. SVPWM扇区判断逻辑错误

C. 中断优先级配置错误导致控制周期抖动

D. 坐标变换公式推导错误

**正确答案：** C

**详细解析：**

**HIL vs 软件仿真的本质区别：**

| 维度 | 软件仿真(MIL/SIL) | HIL测试 |
|------|-------------------|---------|
| 控制器 | 仿真模型 | 真实硬件 |
| 执行时间 | 非实时 | 严格实时 |
| 中断行为 | 仿真调度 | 真实中断优先级和嵌套 |
| I/O信号 | 仿真数值 | 真实电气信号 |

**各选项分析：**

- **选项A**：PI增益过大导致振荡——这是算法逻辑问题，软件仿真完全可以发现
- **选项B**：SVPWM扇区判断错误——这是算法逻辑问题，软件仿真完全可以发现
- **选项C**：中断优先级配置错误导致控制周期抖动——**这是HIL才能发现的问题！** 软件仿真中没有真实的中断系统，中断响应是"即时"的，不存在优先级冲突和嵌套延迟。只有HIL中运行真实固件、真实中断时，才能暴露此类问题
- **选项D**：坐标变换公式错误——这是算法逻辑问题，软件仿真完全可以发现

**结论**：HIL的核心价值在于暴露**与真实硬件、实时执行、中断系统、I/O电气特性相关的问题**，而非算法逻辑问题。算法逻辑问题应在更底层的仿真中解决。

## 第3题：测试金字塔原则

**题目：** 根据测试金字塔原则，以下哪种测试策略最不合理？

A. 大量单元测试 + 适量集成测试 + 少量HIL测试 + 极少实车测试

B. 少量单元测试 + 少量集成测试 + 大量HIL测试 + 大量实车测试

C. 大量单元测试 + 大量集成测试 + 适量HIL测试 + 少量实车测试

D. 适量单元测试 + 大量集成测试 + 适量HIL测试 + 适量实车测试

**正确答案：** B

**详细解析：**

**测试金字塔原则**：底层测试越多，问题发现越早，修复成本越低。

```text
          /\
         /  \        实车测试（少量，高成本）
        /────\
       /      \      HIL测试（适量，中等成本）
      /────────\
     /          \    集成测试（较多，低成本）
    /────────────\
   /              \  单元测试（大量，极低成本）
  /────────────────\
```

**修复成本的指数增长规律**：
- 单元测试发现Bug：修复成本 = 1
- 集成测试发现Bug：修复成本 = 10
- HIL测试发现Bug：修复成本 = 100
- 实车测试发现Bug：修复成本 = 1000
- 客户现场发现Bug：修复成本 = 10000

**选项B的问题**：少量单元测试+少量集成测试意味着大量算法逻辑问题没有被底层测试拦截，而是被推到HIL和实车测试阶段才发现。此时修复成本极高，且HIL和实车测试的执行速度慢、周期长，严重拖慢开发进度。这就是典型的"倒金字塔"——头重脚轻，基础不牢。

**选项A最合理**：大量单元测试确保算法逻辑正确，适量集成测试确保接口正确，少量HIL和实车测试验证系统级行为。

## 第4题：HIL故障注入测试设计

**题目：** 在HIL测试中注入"电流采样断线"故障，以下哪个预期结果最合理？

A. 控制器立即检测到故障，1ms内关闭PWM，电机自由停车

B. 控制器检测到故障后，逐步降低电流指令至零，电机平稳减速

C. 控制器检测到故障，3ms内关闭PWM，进入安全状态，电机自由停车

D. 控制器无法检测到故障，电机继续运行

**正确答案：** C

**详细解析：**

**电流采样断线的故障特征**：
- ADC采样值变为0或满量程（取决于断线位置和ADC输入电路设计）
- 三相电流之和偏离零点（基尔霍夫电流定律不满足）
- PI积分器快速饱和（采样值为0时，误差持续增大）

**合理的故障响应策略**：

1. **检测时间**：3ms内检测到故障。这需要：
   - 硬件比较器：1μs级响应
   - 软件合理性检查：三相电流之和偏离零点超过阈值，连续3个采样周期确认
   - 不能太慢（如15ms），否则PI积分器已饱和，电机可能输出最大转矩

2. **响应动作**：关闭PWM，电机自由停车。这是功能安全的标准要求——检测到危险故障后，必须进入安全状态。自由停车是最安全的停车方式（不施加任何转矩）。

3. **安全状态**：关闭PWM后，控制器进入安全状态，禁止重新启动，直到故障清除且人工复位。

**各选项分析**：

- **选项A**：1ms响应时间过短——软件检测通常需要多个采样周期确认（防止误报），3ms是更合理的指标
- **选项B**：逐步降低电流指令是错误策略——电流采样已断线，无法准确控制电流，继续运行是危险的
- **选项C**：3ms检测+关闭PWM+安全状态，是合理的故障响应策略
- **选项D**：无法检测是不可接受的——这是严重的安全隐患

## 第5题：EMC传导发射超标分析

**题目：** 某电机控制器传导发射在开关频率的倍频处超标，以下哪种整改措施最有效？

A. 增大直流母线电容容量

B. 在电源输入端增加共模电感

C. 增加IGBT栅极电阻

D. 更换更高分辨率的ADC

**正确答案：** C

**详细解析：**

**传导发射在开关频率倍频处超标的根因**：

开关频率的倍频处出现超标尖峰，说明噪声源是PWM开关动作本身。每次开关动作产生高dv/dt和di/dt，其频谱在开关频率及其倍频处有明显的能量集中。

**各选项分析**：

- **选项A**：增大直流母线电容容量可以降低母线电压纹波，但对开关频率倍频处的传导发射改善有限。因为传导发射的主要路径是开关噪声通过寄生参数耦合到电源线，而非母线纹波。

- **选项B**：共模电感对共模噪声有效，但开关频率倍频处的噪声可能同时包含共模和差模成分。而且共模电感主要对低频段有效，对高频倍频的抑制效果有限。

- **选项C**：增加IGBT栅极电阻→降低开关速度→降低dv/dt和di/dt→从源头减少开关噪声能量。这是最直接、最有效的措施。代价是开关损耗增大，需要在EMC和效率之间权衡。

- **选项D**：ADC分辨率与传导发射无关，这是采样精度问题而非EMC问题。

**EMC整改的优先级原则**：源头抑制 > 传播路径 > 接收端。增加栅极电阻属于源头抑制，是最优先的策略。

## 第6题：型式试验温升测试

**题目：** 某PMSM电机控制器额定负载运行至热稳定后，IGBT结温达到118°C，NTC测得散热器温度为85°C。IGBT的结-壳热阻为0.5°C/W，壳-散热器热阻为0.3°C/W，IGBT功耗为40W。以下判断正确的是？

A. IGBT结温计算值与实测值一致，散热设计合理

B. IGBT结温计算值与实测值不一致，可能存在接触不良

C. IGBT结温超过F级绝缘限值，不合格

D. 数据不足，无法判断

**正确答案：** B

**详细解析：**

**理论计算IGBT结温**：

$$T_j = T_{heatsink} + R_{th,c-h} \times P_{IGBT} + R_{th,j-c} \times P_{IGBT}$$

$$T_j = 85 + 0.3 \times 40 + 0.5 \times 40 = 85 + 12 + 20 = 117°C$$

**实测值**：118°C

**分析**：理论计算值117°C与实测值118°C相差1°C，看似一致。但需要注意——NTC测量的是散热器上某一点的温度，而计算中使用的散热器温度应该是IGBT正下方的散热器温度。如果NTC安装位置距离IGBT较远，实际IGBT下方的散热器温度会更高。

**更关键的问题**：让我们从另一个角度验证——如果散热器温度85°C是准确的，那么：

$$T_j - T_{heatsink} = 118 - 85 = 33°C$$

$$R_{th,total} \times P_{IGBT} = (0.5 + 0.3) \times 40 = 32°C$$

差值1°C在测量误差范围内，看似合理。但实际工程中，如果导热硅脂涂抹不均匀或散热器接触不紧密，壳-散热器热阻会远大于标称值0.3°C/W。此时实测结温会显著高于计算值。

**选项B最合理**：虽然差值仅1°C，但在工程实践中，热阻参数的离散性较大。如果实测值持续高于计算值，应检查散热器与IGBT的接触质量——导热硅脂厚度、散热器平整度、安装螺钉扭矩等。

**选项C错误**：F级绝缘限值155°C，118°C远低于此限值。IGBT结温限值通常为150°C或175°C（取决于器件型号），118°C也在安全范围内。

## 第7题：回归测试策略

**题目：** 开发者修改了FOC算法中的Park变换函数，以下回归测试范围最合理的是？

A. 仅运行Park变换函数的单元测试

B. 运行Park变换的单元测试 + 坐标变换模块的集成测试

C. 运行完整FOC算法的集成测试 + HIL关键用例

D. 运行完整测试套件（单元+集成+HIL+台架）

**正确答案：** C

**详细解析：**

**Park变换的影响范围分析**：

Park变换是FOC算法的核心模块，其输出直接影响d-q轴电流环的反馈值。修改Park变换函数可能影响：
- 电流环闭环性能（d-q轴电流反馈值变化）
- 解耦补偿精度（前馈项依赖角度）
- 弱磁算法（d轴电流反馈变化）
- 保护策略（过流判断依赖电流采样值）

**各选项分析**：

- **选项A**：仅测Park变换函数本身——不够！Park变换的单元测试只能验证数学公式的正确性，无法验证其在整个FOC系统中的行为。例如，Park变换的输入角度来源（编码器/观测器）是否正确、输出是否被正确使用，这些都需要集成测试来验证。

- **选项B**：Park变换单元测试+坐标变换模块集成测试——仍然不够！坐标变换模块（Clarke+Park+逆Park）的集成测试只能验证变换链路的正确性，无法验证Park变换修改对电流环、速度环等下游模块的影响。

- **选项C**：完整FOC算法的集成测试+HIL关键用例——**最合理！** 集成测试验证FOC算法各模块的协同工作，HIL关键用例验证实时约束下的系统行为。这覆盖了Park变换修改可能影响的所有关键路径。

- **选项D**：完整测试套件——过于保守！Park变换是一个纯数学函数的修改，不涉及硬件接口、通信协议或安全机制，不需要运行台架测试。完整测试套件的执行周期太长，会严重影响开发效率。

**回归测试的"最小充分"原则**：回归测试范围应覆盖修改可能影响的所有模块，但不应过度扩展到无关模块。对于核心算法模块的修改，集成测试+HIL关键用例是"最小充分"的范围。

## 第8题：EMC预测试方案

**题目：** 某电机控制器传导发射超标，但暂无EMC暗室可用。以下哪种预测试方法可以最有效地定位噪声是共模还是差模？

A. 使用示波器直接测量电源线电压波形

B. 使用电流探头分别测量每根电源线的电流，然后计算共模和差模分量

C. 在电源线上串联电阻，测量压降

D. 更换不同长度的电源线，观察噪声变化

**正确答案：** B

**详细解析：**

**共模噪声与差模噪声的区别**：

- **差模噪声**：噪声电流在火线和零线之间流动，方向相反
- **共模噪声**：噪声电流在火线/零线与地线之间流动，方向相同

**分离共模和差模的方法**：

使用两个相同的电流探头分别夹在火线（L）和零线（N）上：

$$I_{CM} = \frac{I_L + I_N}{2}$$

$$I_{DM} = \frac{I_L - I_N}{2}$$

通过示波器的数学运算功能，可以实时显示共模和差模电流的频谱，从而判断超标频点的噪声类型。

**各选项分析**：

- **选项A**：示波器测量电压波形只能看到总噪声，无法区分共模和差模
- **选项B**：正确方法——电流探头分别测量后计算共模/差模分量
- **选项C**：串联电阻会改变电路阻抗，影响噪声分布，测量结果不准确
- **选项D**：更换电源线长度会改变辐射特性，但对传导发射的影响不明确，无法有效区分共模/差模

**定位噪声类型的意义**：
- 共模噪声超标→增加共模电感、Y电容、改善接地
- 差模噪声超标→增加X电容、差模电感
- 混合噪声→两种措施都需要

## 第9题：HIL测试用例设计——SMO低速失锁

**题目：** 参考案例1（HIL测试发现SMO低速失锁），以下哪个HIL测试用例最能有效暴露SMO低速失锁问题？

A. 电机从0rpm加速至额定转速，观察加速过程是否平稳

B. 电机在额定转速稳态运行，观察角度估计误差

C. 电机从额定转速缓慢减速至极低速（如50rpm），观察角度估计值是否连续平滑

D. 电机在50rpm稳态运行，观察电流波形是否正弦

**正确答案：** C

**详细解析：**

**SMO低速失锁的故障机制**：

SMO（滑模观测器）依赖反EMF来估计转子位置。反EMF幅值与转速成正比：$E \propto \omega$。当转速降至极低时，反EMF幅值极小，被采样噪声淹没，SMO的信噪比不足，锁相环失锁，导致角度估计值跳变。

**各选项分析**：

- **选项A**：加速过程——从0rpm加速时，SMO在低速阶段可能也有问题，但加速过程短暂，可能来不及观察到失锁现象。而且启动阶段通常使用开环或HFI，不依赖SMO。

- **选项B**：额定转速稳态——额定转速下反EMF充足，SMO工作正常，无法暴露低速失锁问题。

- **选项C**：**从额定转速缓慢减速至极低速**——这是最有效的测试用例！缓慢减速确保SMO在低速区域停留足够长的时间，使失锁现象充分暴露。减速过程中可以观察角度估计值是否连续平滑——如果出现跳变，说明SMO失锁。

- **选项D**：50rpm稳态——虽然也能测试低速性能，但缺少了从高速到低速的过渡过程。SMO失锁往往发生在速度穿越某个阈值时（如PLL带宽与反EMF幅值不再匹配的临界点），稳态测试可能无法捕捉到这个过渡过程。

**测试用例设计原则**：对于参数敏感型算法（如SMO、PLL），测试用例应覆盖参数变化的**过渡过程**，而不仅是稳态工作点。过渡过程往往是算法最脆弱的时刻。

## 第10题：综合题——测试策略规划

**题目：** 某PMSM电机控制器项目进入测试阶段，已知以下信息：
- 电流环带宽2000Hz，采样频率10kHz
- SMO+PLL无感方案，低速切换HFI
- 目标应用：电动两轮车
- 需通过CE认证

以下测试规划最合理的是？

A. 先做EMC测试→再做HIL测试→最后做型式试验

B. 先做单元测试→集成测试→HIL测试→台架测试→EMC预测试→型式试验→CE认证测试

C. 直接做CE认证测试，不通过再整改

D. 先做台架测试→再做HIL测试→最后做EMC测试

**正确答案：** B

**详细解析：**

**测试规划的核心原则**：
1. **从底层到顶层**：单元→集成→系统→验收
2. **从低成本到高成本**：仿真→HIL→台架→认证
3. **问题早发现早修复**：在低成本阶段解决问题

**各选项分析**：

- **选项A**：先做EMC测试是错误的——EMC测试应在功能验证通过后进行。如果基本功能都不正常，做EMC测试毫无意义。而且EMC整改可能需要修改硬件和软件，如果后续HIL测试又发现新问题，可能需要重新做EMC测试。

- **选项B**：**最合理的规划！**
  1. 单元测试：验证PI、坐标变换、SVPWM、SMO、HFI等模块的算法逻辑
  2. 集成测试：验证FOC算法各模块的协同工作
  3. HIL测试：验证实时约束下的系统行为，重点测试SMO/HFI切换、故障注入
  4. 台架测试：验证真实电机负载下的性能指标
  5. EMC预测试：在正式认证前定位和解决EMC问题，降低认证风险
  6. 型式试验：验证产品在规定条件下的性能和安全
  7. CE认证测试：正式认证

- **选项C**：直接做CE认证测试风险极高——如果测试不通过，整改成本巨大，且可能需要重新设计硬件。EMC预测试可以在正式认证前发现和解决问题。

- **选项D**：台架测试在HIL测试之前是错误的——台架测试成本高、风险大（可能损坏硬件），应先在HIL上验证基本功能和安全机制后再上台架。

**特别关注点**：
- 电流环带宽2000Hz、采样频率10kHz→带宽/采样率比=1/5，延迟裕度紧张，HIL测试中需重点验证电流环稳定性
- SMO+HFI方案→HIL测试中需重点验证低速切换过程的平滑性
- 电动两轮车应用→需关注防水（IP67）、振动、温升等型式试验项目

## 评分标准

| 答对题数 | 等级 | 评价 |
|---------|------|------|
| 9~10 | A | 深刻理解系统测试与验证方法论，具备独立规划测试策略和设计测试用例的能力 |
| 7~8 | B | 掌握主要测试层级和方法，HIL用例设计和EMC整改能力需加强 |

| <5 | D | 需要系统学习测试验证方法论，建议从V模型和测试金字塔原则开始 |
