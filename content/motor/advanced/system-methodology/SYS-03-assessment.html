第3题：PFC电压环带宽约束 ​

题目： 单相Boost PFC的电压环带宽为什么必须远低于2倍工频（100Hz或120Hz）？以下解释最准确的是？

A. 电压环响应太慢，无法跟踪100Hz信号

B. 如果电压环带宽高于2倍工频，电流参考会含有2倍工频分量，导致输入电流畸变，降低功率因数

第5题：过零畸变 ​

题目： 单相Boost PFC在输入电压过零附近电流波形出现"缺口"，即电流跟踪不上正弦参考。以下原因中，哪个不是导致过零畸变的原因？

A. 占空比在过零处接近1，受最大占空比限制而饱和

B. 轻载时电感电流在过零处进入断续模式（DCM），平均电流与占空比关系变为非线性

C. 电流环PI参数过大导致过零处振荡

D. 快恢复二极管的反向恢复电荷在过零处导致额外电流

正确答案： C

详细解析：

过零畸变是Boost PFC的固有问题，有四个主要成因：

1. 占空比饱和（选项A）： 过零处vin≈0v_{in} \approx 0vin​≈0，稳态占空比D=1−vin/Vdc→1D = 1 - v_{in}/V_{dc} \to 1D=1−vin​/Vdc​→1。但实际最大占空比受限（通常Dmax<0.95D_{max} < 0.95Dmax​<0.95，需要最小关断时间给ADC采样），控制器输出饱和，无法提供足够的占空比使电流跟踪参考。

2. DCM模式（选项B）： 轻载时电感电流在过零附近进入断续模式。DCM下平均电流与占空比的关系为：

Iavg,DCM=Vdc⋅D2⋅Ts2LI_{avg,DCM} = \frac{V_{dc} \cdot D^2 \cdot T_s}{2L}Iavg,DCM​=2LVdc​⋅D2⋅Ts​​

而CCM下为线性关系Iavg,CCM∝DI_{avg,CCM} \propto DIavg,CCM​∝D。PI控制器基于CCM模型设计，在DCM区域输出不正确。

3. 二极管反向恢复（选项D）： 快恢复二极管在过零处（电流从正变负的瞬间）反向恢复电荷QrrQ_{rr}Qrr​导致额外电流尖峰，干扰电流采样。

选项C为什么不是过零畸变的原因： PI参数过大会导致整个周期的振荡（不仅在过零处），且振荡频率接近电流环带宽。过零畸变是过零处特有的现象，与PI参数大小无关——即使PI参数很小，过零处仍然会有畸变，因为根因是占空比饱和和DCM模式，而非控制器增益。

第6题：交错并联PFC ​

第7题：Totem-pole PFC ​

题目： Totem-pole PFC必须使用GaN或SiC器件，而不能使用普通Si MOSFET，根本原因是？

A. GaN的导通电阻更低

B. Si MOSFET的体二极管具有较大的反向恢复电荷QrrQ_{rr}Qrr​，在高速桥臂换流时产生巨大的反向恢复电流

C. GaN的耐压更高

D. Si MOSFET开关速度太慢

正确答案： B

详细解析：

Totem-pole PFC的工作原理：

高速桥臂（S1/S2）在高频切换，当S1关断、S2开通时，电流从S1的体二极管转移到S2。如果使用Si MOSFET，其体二极管的反向恢复电荷QrrQ_{rr}Qrr​可达数百nC到μC\mu CμC级别。

反向恢复的问题：

Esw,loss=12Coss⋅Vds2+Qrr⋅VdsE_{sw,loss} = \frac{1}{2} C_{oss} \cdot V_{ds}^2 + Q_{rr} \cdot V_{ds}Esw,loss​=21​Coss​⋅Vds2​+Qrr​⋅Vds​

其中：

  • Esw,lossE_{sw,loss}Esw,loss​：单次开关损耗能量 (J)
  • CossC_{oss}Coss​：MOSFET输出电容 (F)
  • VdsV_{ds}Vds​：漏源极电压 (V)
  • QrrQ_{rr}Qrr​：体二极管反向恢复电荷 (C)

反向恢复电流在S2开通瞬间流过S2，产生巨大的开关损耗和严重的EMI问题。在65kHz以上开关频率下，Si MOSFET的QrrQ_{rr}Qrr​问题使得Totem-pole PFC不可行。

GaN HEMT的优势：

  • 零反向恢复电荷： Qrr≈0Q_{rr} \approx 0Qrr​≈0，因为GaN没有体二极管（是横向器件，电流双向流动）
  • 极低CossC_{oss}Coss​： 开关损耗低
  • 高dv/dt能力： 可达100V/ns

选项A不准确： GaN的导通电阻不一定比同规格Si MOSFET低，且导通电阻不是Totem-pole必须用GaN的原因。选项C不准确：GaN耐压不一定比Si高。选项D不完全：Si MOSFET开关速度不是根本问题，反向恢复才是。

第8题：PFC与FOC联合开发——中断优先级 ​

题目： PFC+电机控制共用一个MCU，PFC开关频率100kHz，电机开关频率16.7kHz。以下中断优先级设计最合理的是？

A. 电机PWM中断 > PFC PWM中断 > 通信中断

B. PFC PWM中断 > 电机PWM中断 > 通信中断

C. 通信中断 > PFC PWM中断 > 电机PWM中断

D. PFC和电机使用相同优先级，轮流执行

正确答案： B

详细解析：

中断优先级设计原则：

  1. 频率最高的控制环优先级最高 —— PFC 100kHz > 电机 16.7kHz
  2. 安全关键的保护优先级最高 —— 过流硬件保护（通常不由软件中断处理）
  3. 非实时任务优先级最低 —— 通信、显示

为什么PFC优先级更高：

  • PFC开关频率100kHz意味着每个PWM周期仅10us，中断延迟必须极小
  • 如果PFC中断被电机中断抢占，PFC电流环的执行延迟增大，可能导致电流跟踪误差增大
  • 电机的16.7kHz周期约60us，即使被PFC中断抢占（PFC ISR约3~5us），仍有足够时间完成计算

推荐的中断优先级设计：

优先级中断源执行内容频率
最高PFC PWM中断PFC电流环100kHz
高电机PWM中断FOC电流环16.7kHz
中电机速度环速度PI1~10kHz
低PFC电压环电压PI1~10kHz
最低通信/显示UI/协议100~1000Hz

关键约束： 两个ADC的采样时刻不能重叠。如果PFC和电机的ADC触发时刻冲突，需要调整PWM相位偏移，确保采样时刻错开。

第9题：从电控转PFC——知识迁移 ​

题目： 一位FOC电机控制工程师转做PFC开发，以下哪项知识可以直接复用（无需修改）？

A. 电流环PI控制器的代码实现

B. SVPWM生成模块

C. Park变换模块

D. 编码器速度计算模块

正确答案： A

详细解析：

70%可直接复用的知识：

知识模块可否复用理由
PI控制器代码完全复用PFC和FOC的PI控制器在数学上完全相同：误差计算→比例项→积分项→抗饱和→输出限幅
PWM配置高度复用中心对齐模式、ADC触发相同，但PFC频率更高
ADC采样+DMA完全复用采样框架相同，只是通道不同
保护逻辑框架框架复用OVP/OCP/UVP逻辑相同，阈值不同
SVPWM不能复用PFC是单相单管，不需要SVPWM（三相空间矢量调制）
Park变换不能复用PFC没有dq旋转坐标系，不需要Park变换
编码器速度计算不能复用PFC不需要编码器，需要的是电网PLL

PI控制器复用的代码示例：

c
/* 以下代码在PFC和FOC中完全相同 */
float PI_Execute(PI_Controller_t *pi, float ref, float fdb)
{
    float err = ref - fdb;
    float p_out = pi->kp * err;
    pi->integral += pi->ki * err * pi->ts;
    pi->integral = CLAMP(pi->integral, pi->out_min, pi->out_max);
    float out = p_out + pi->integral;
    out = CLAMP(out, pi->out_min, pi->out_max);
    return out;
}

PFC调用：duty = PI_Execute(&pfc_pi_current, i_ref, i_L); FOC调用：v_d = PI_Execute(&foc_pi_id, i_d_ref, i_d);

第10题：综合分析——PFC+电机联合系统 ​

题目： 工业变频器系统中，前端Totem-pole PFC + 后端电机逆变器构成AC→DC→AC完整能量链。当电机从电动模式切换到制动模式时，以下关于PFC行为的描述正确的是？

A. PFC继续工作在整流模式，制动能量通过制动电阻消耗

B. PFC检测到母线电压升高后切换到逆变模式，将制动能量回馈电网

C. PFC关闭，制动能量充入母线电容

D. 电机制动时PFC不受影响

正确答案： B

详细解析：

能量流分析：

  • 电动模式： 电网 → PFC(AC→DC) → 母线电容 → 逆变器(DC→AC) → 电机
  • 制动模式： 电机 → 逆变器(AC→DC) → 母线电容 → PFC(DC→AC) → 电网

Totem-pole PFC的双向能力：

传统Boost PFC只能实现AC→DC（整流），制动能量只能通过制动电阻消耗。Totem-pole PFC天然支持双向能量流——只需改变电流参考的极性：

c
if (power_direction == FORWARD) {
    i_ref = i_voltage_loop_output * |v_in| / v_rms_sq;  /* 整流模式 */
} else {
    i_ref = -i_voltage_loop_output * |v_in| / v_rms_sq; /* 逆变模式 */
}

母线电压控制逻辑：

  1. 电动模式：PFC电压环维持VdcV_{dc}Vdc​在设定值
  2. 制动模式：电机回馈能量导致VdcV_{dc}Vdc​升高
  3. 当VdcV_{dc}Vdc​超过上限阈值时，PFC切换到逆变模式，将多余能量回馈电网
  4. 当VdcV_{dc}Vdc​回到正常范围时，PFC切回整流模式

这就是"主动前端(AFE)"的概念： Totem-pole PFC作为主动前端，不仅实现功率因数校正，还实现了能量的双向流动，消除了制动电阻，提高了系统效率。

其他选项的问题：

  • 选项A： 使用制动电阻是传统方案，浪费制动能量，效率低。
  • 选项C： 母线电容容量有限，无法吸收大量制动能量，电压会持续升高触发过压保护。
  • 选项D： 电机制动时母线电压升高，PFC必须响应，否则会触发过压保护。
