# PMI-03: 家电变频专题

**副标题：从空调到洗衣机——成本敏感型PFC+FOC集成方案的设计实战**

**难度：** 

---

## 1.  核心摘要  

**一句话讲清楚**：家电变频的核心挑战是在极低成本约束下实现PFC+FOC的单芯片集成——用一颗STM32F103/GD32F303同时跑PFC电流环(50~100kHz)和FOC电流环(10~20kHz)，ADC通道复用、中断优先级竞争、母线电容最小化、无传感器启动、IEC 61000-3-2认证——每一项都是成本与性能的极限博弈。

**认知挂钩**：很多工程师以为"家电变频就是工业变频的缩小版，照抄方案降成本就行"，**但家电有工业变频没有的三大约束：成本压到极致（BOM <$8）、噪声敏感（压缩机不能吵到用户）、认证强制（IEC 61000-3-2不过不能上市）！** 工业变频器可以加AFE、用大电容、独立MCU，家电不行——必须用最少的元器件、最小的电容、最便宜的单芯片，同时满足PF>0.99、THD<5%、噪声<40dB。这是完全不同的设计哲学。

**家电变频 vs 工业变频的核心差异：**

| 维度 | 家电变频 | 工业变频 |
|------|---------|---------|
| 成本目标 | BOM <$8 | BOM >$50 |
| PFC方案 | 单芯片集成 | 独立PFC控制器或AFE |
| 母线电容 | 最小化（成本+体积） | 充裕（性能优先） |
| 传感器 | 无传感器/单电阻 | 编码器/霍尔 |
| 噪声要求 | < 40dB(A) | 无严格要求 |
| 认证 | IEC 61000-3-2强制 | 部分需要 |
| 开发周期 | 3~6个月 | 12~24个月 |

## 2.  问题引入  

### 工程师的真实困惑

**场景1：单芯片ADC不够用**
```text
工程师A:"用GD32F303做空调变频板，
PFC需要3路ADC（电感电流+输入电压+输出电压），
FOC需要3路ADC（2相电流+母线电压），
加上NTC温度和用户接口，至少需要10路ADC...
但GD32F303只有3个ADC，16个外部通道，
怎么分配采样时序？"
问题现象:
- PFC电流采样和FOC电流采样冲突
- ADC采样率不够，电流环带宽受限
- 采样噪声大，电机抖动
```

**场景2：压缩机启动困难**
```text
工程师B:"空调压缩机启动转矩大，
无传感器FOC在低速时角度估算不准，
经常启动失败或反转...
加了高频注入又太吵，用户投诉..."
问题现象:
- 压缩机启动失败率>5%
- 启动时有明显振动和噪声
- 高频注入噪声可被人耳听到
```

**场景3：EMC认证过不了**
```text
工程师C:"PFC+FOC方案EMC测试，
传导EMI在150kHz~500kHz超标5dB...
增加EMI滤波器后成本超了，
减少Y电容后漏电流合格但EMI又超标..."
问题现象:
- 传导EMI在PFC开关频率附近超标
- 辐射EMI在逆变器开关频率附近超标
- Y电容受漏电流3.5mA限制，不能无限增加
```

### 核心问题

- ADC不够 → PFC和FOC的ADC通道复用与采样时序设计
- 启动困难 → 压缩机大启动转矩+无传感器低速观测
- EMC超标 → PFC与逆变器EMI的协同抑制与Y电容约束

### 学习目标

读完本模块，你将能够：

 **理解家电变频架构** - 空调/冰箱/洗衣机/风扇的典型方案差异
 **掌握压缩机驱动特点** - 变负载、大启动转矩、噪声敏感
 **设计单芯片PFC+FOC方案** - ADC复用、中断优先级、资源分配
 **优化成本** - 无传感器方案、单电阻采样、减少母线电容
 **通过认证** - IEC 61000-3-2、EMC、安全认证要点

## 3.  直观理解  

### 类比1：家电变频就像"经济型轿车"

```text
工业变频 = 豪华SUV
  - 预算充足，性能优先
  - 独立PFC控制器 + 独立电机控制器
  - 大电容、编码器、AFE
  - 成本不是问题

家电变频 = 经济型轿车
  - 预算紧张，成本优先
  - 单芯片搞定PFC+电机
  - 最小电容、无传感器、制动电阻
  - 每一分钱都要省

设计哲学完全不同：
  工业变频：性能不够加硬件
  家电变频：性能不够优化算法
```

### 类比2：ADC复用就像"一条电话线多人共用"

```text
10路ADC需求 vs 3个ADC物理单元

就像10个人要打电话，但只有3条电话线

解决方案：
  1. 分时复用：3条线轮流给10个人用（ADC通道切换）
  2. 优先级：紧急电话优先（PFC电流采样优先级最高）
  3. 降频：不紧急的少打几次（温度采样1Hz就够了）
  4. 共享：母线电压PFC和FOC都要用，采一次共享
```

## 4.  技术原理  

### 4.1 家电变频架构

#### 4.1.1 空调变频架构

空调是家电中功率最大、技术难度最高的变频应用：

```text
  220VAC ──► EMI滤波 ──► 整流桥 ──► PFC(Boost) ──► 母线电容 ──► 逆变器 ──► 压缩机
              │                              │                        │
         L_CM+L_DM                       400VDC                   FOC控制
         C_X+C_Y                       470~680μF               无传感器
```

**空调变频关键参数：**

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 功率范围 | 1~5 kW | 1HP~3HP |
| PFC拓扑 | Boost PFC（单相） | 成本最低 |
| 母线电压 | 390~400V | PFC输出 |
| 母线电容 | 470~680μF | 电解电容 |
| 电机类型 | BLDC/PMSM压缩机 | 内置永磁体 |
| 控制方式 | 无传感器FOC | 压缩机封闭，无法安装编码器 |
| 开关频率 | PFC: 50~65kHz, 电机: 10~16kHz | |
| 认证要求 | IEC 61000-3-2 Class A/D | 强制 |

#### 4.1.2 冰箱变频架构

冰箱功率较小，但要求极低噪声：

```text
  220VAC ──► EMI滤波 ──► 整流桥 ──► PFC(Boost) ──► 母线电容 ──► 逆变器 ──► 压缩机
              │                              │                        │
         简化EMI                        390VDC                   FOC/方波
         小体积                       220~330μF               无传感器
```

**冰箱变频特殊要求：**
- 功率小（100~500W），PFC可以简化
- 噪声要求极严格（< 35dB(A)，夜间运行）
- 压缩机启停频繁（每天数十次）
- 成本极低（BOM < $5）

#### 4.1.3 洗衣机变频架构

洗衣机有独特的制动需求（脱水结束需要快速减速）：

```text
  220VAC ──► EMI滤波 ──► 整流桥 ──► PFC(Boost) ──► 母线电容 ──► 逆变器 ──► BLDC电机
              │                              │              │           │
         标准EMI                        390VDC        制动斩波器    FOC控制
                                       330~470μF      +制动电阻    无/有传感器
```

**洗衣机变频特殊要求：**
- 需要正反转（洗涤模式）
- 脱水时高速运行（800~1400rpm）
- 脱水结束需要快速制动→制动能量管理
- 负载变化大（空桶vs满载）
- 电机通常外置，可安装霍尔传感器

#### 4.1.4 风扇变频架构

风扇是最简单的家电变频应用：

```text
  220VAC ──► 整流桥 ──► 母线电容 ──► 逆变器 ──► BLDC电机
              │           │              │           │
           无PFC!      310VDC        单电阻采样   方波/SPWM
                      47~100μF                   无传感器
```

**风扇变频特殊要求：**
- 功率极小（20~100W），通常不需要PFC
- 成本极致压缩（BOM < $2）
- 单电阻采样或无电流采样
- 方波控制或简单SPWM即可
- 无需IEC 61000-3-2认证（< 75W豁免）

### 4.2 压缩机驱动特点

#### 4.2.1 变负载特性

压缩机负载随运行工况剧烈变化：

```text
  转矩
    │        ╱╲  高压比工况
    │       ╱  ╲
    │      ╱    ╲
    │     ╱      ╲  正常工况
    │    ╱        ╲
    │   ╱          ╲
    │  ╱            ╲  低压比工况
    │ ╱              ╲
    │╱                ╲
    └──────────────────── 转速
    0   1000  2000  3000  4000  rpm
```

**负载变化因素：**

| 因素 | 影响 | 典型变化范围 |
|------|------|------------|
| 制冷剂压力 | 转矩随压力比增大 | 1:3 |
| 环境温度 | 高温时负载增大 | 1:2 |
| 转速 | 转矩近似线性增加 | 1:4 |
| 启动 | 启动转矩是额定的2~3倍 | 2~3x |

**对控制的影响：**
- PI参数需要在宽负载范围内稳定→需要增益调度或鲁棒设计
- 负载突变时速度环不能过冲→压缩机过冲可能导致液击
- 低速大转矩启动→无传感器观测器精度下降

#### 4.2.2 启动转矩大

压缩机启动面临三大挑战：

**1. 静摩擦力矩大**

压缩机停机后制冷剂可能液化并流回压缩机，导致启动时需要克服液态制冷剂的阻力：

$$
T_{start} = T_{friction} + T_{gas} + T_{liquid} \approx (2 \sim 3) \times T_{rated}
$$

**2. 无传感器低速启动困难**

无传感器FOC在低速（< 5Hz）时反电动势极小，观测器信噪比极低：

$$
e_{back} = \omega_e \cdot \psi_f \propto \omega_e
$$

当$\omega_e \to 0$时，$e_{back} \to 0$，滑模观测器/磁链观测器无法工作。

**3. 启动策略选择**

| 启动策略 | 原理 | 优点 | 缺点 | 适用场景 |
|---------|------|------|------|---------|
| 开环V/f启动 | 固定V/f比开环运行 | 简单 | 可能失步、反转 | 低成本方案 |
| I-f启动 | 电流幅值+频率开环 | 比V/f更稳定 | 切换到闭环有冲击 | 主流方案 |
| 高频注入 | 注入高频信号检测位置 | 真正的零速启动 | 噪声大 | 不适合家电 |
| 转子定位+I-f | 先定位再I-f启动 | 避免反转 | 定位时间增加 | 推荐方案 |

**推荐方案：转子定位 + I-f启动 + 平滑切换到FOC**

```text
  阶段1: 转子定位（0.5~1秒）
    - 注入d轴直流电流，将转子拉到已知位置
    - 电流约50%额定值，避免过大冲击

  阶段2: I-f开环启动（1~3秒）
    - 电流幅值恒定，频率从0缓慢上升
    - 频率斜坡率根据负载调整
    - 保持电压角超前电流角（保证电动转矩）

  阶段3: 切换到FOC闭环（转速>10%额定）
    - 观测器精度足够时切换
    - 切换瞬间角度和电流必须连续
    - 使用渐变因子平滑过渡

  阶段4: FOC正常运行
    - 速度环+电流环双环控制
    - 根据负载调整速度环PI参数
```

#### 4.2.3 噪声敏感

家电压缩机的噪声限制极为严格：

| 噪声源 | 频率范围 | 产生原因 | 抑制方法 |
|--------|---------|---------|---------|
| 电磁噪声 | f_sw及其谐波 | 电流纹波导致定子振动 | 提高开关频率/随机PWM |
| 机械噪声 | 1~5kHz | 转矩脉动导致转子振动 | 降低转矩脉动 |
| 气流噪声 | 宽带 | 制冷剂流动 | 压缩机设计优化 |
| PFC噪声 | f_sw,PFC | 电感振动 | 浸漆电感/固定方式 |

**随机PWM技术：** 通过随机化开关周期或零向量分配，将EMI噪声能量从离散谱线分散到连续谱，降低可听噪声：

$$
T_{sw}(k) = T_{sw,avg} \cdot (1 + \delta \cdot r(k))
$$

其中$r(k)$为[-1, 1]均匀分布随机数，$\delta$为随机化幅度（0.05~0.15）。

### 4.3 单芯片PFC+FOC方案详解

#### 4.3.1 STM32F103/GD32F303方案

STM32F103和GD32F303是家电变频最主流的MCU选择：

**资源清单：**

| 资源 | STM32F103RCT6 | GD32F303RCT6 | PFC+FOC需求 |
|------|--------------|-------------|------------|
| 内核 | Cortex-M3 72MHz | Cortex-M4F 108MHz | - |
| ADC | 3×12-bit, 1Msps | 3×12-bit, 2.4Msps | 3个ADC单元 |
| ADC通道 | 16ch(ADC1)+16ch(ADC2) | 16ch×3 | ≥10ch |
| 定时器 | TIM1(高级)+TIM2-4 | TIM0(高级)+TIM1-4 | 2个高级定时器 |
| PWM通道 | 4ch(TIM1)+9ch | 4ch(TIM0)+12ch | PFC:1ch+FOC:6ch |
| DMA | 2单元,7ch | 2单元,8ch | ≥2ch |
| Flash | 256KB | 256KB | ≥128KB |
| RAM | 48KB | 32KB | ≥16KB |

**关键问题：STM32F103RCT6有TIM1和TIM8两个高级定时器，但TIM8的DMA请求通道与TIM1不同，需软件协调两个定时器的触发时序。**

**解决方案：**

| 方案 | PFC定时器 | FOC定时器 | 可行性 |
|------|----------|----------|--------|
| 方案A | TIM1(CH1) | TIM1(CH2-4) |  同一定时器，频率必须相同或整数倍 |
| 方案B | TIM1(CH1) | 通用定时器+软件 |  灵活但FOC PWM精度降低 |
| 方案C | 换用GD32F303(有TIM0+TIM1) | - |  推荐方案 |

**GD32F303双高级定时器方案（推荐）：**

```text
TIM0 (高级定时器): FOC PWM
  - CH0/CH1/CH2: 三相PWM (U/V/W)
  - CH3: 制动斩波器PWM
  - 中心对齐模式, f_sw = 16kHz
  - ADC1由TIM0触发

TIM1 (高级定时器): PFC PWM
  - CH0: PFC MOSFET驱动
  - 中心对齐模式, f_sw = 65kHz
  - ADC2由TIM1触发
```

#### 4.3.2 PFC中断与FOC中断优先级

**中断优先级设计原则：**

1. PFC电流环频率最高（65kHz），执行时间最短，优先级最高
2. FOC电流环频率次高（16kHz），可被PFC中断抢占
3. 速度环和PFC电压环频率低，优先级最低

**NVIC优先级配置：**

| 优先级 | 中断源 | 执行内容 | 频率 | 执行时间 |
|--------|--------|---------|------|---------|
| 0（最高） | TIM1_UP | PFC电流环 | 65kHz | 3~5μs |
| 1 | TIM0_UP | FOC电流环 | 16kHz | 8~12μs |
| 2 | TIM0_UP(降频) | 速度环+PFC电压环 | 1kHz | 5~10μs |
| 3 | DMA/UART | 通信 | 100Hz | 2~5μs |

**中断嵌套时序：**

```text
时间轴 (μs):
0    5    10   15   20   25   30   35   40   45   50   55   60
│    │    │    │    │    │    │    │    │    │    │    │    │
│PFC │    │PFC │    │PFC │    │PFC │    │PFC │    │PFC │    │
│ 3μs│    │ 3μs│    │ 3μs│    │ 3μs│    │ 3μs│    │ 3μs│    │
│    │FOC │    │    │    │FOC │    │    │    │FOC │    │    │
│    │12μs│    │    │    │12μs│    │    │    │12μs│    │    │

PFC中断每15.4μs一次(65kHz)
FOC中断每62.5μs一次(16kHz)
PFC中断可以抢占FOC中断
```

**最恶劣情况分析：** FOC中断执行期间被PFC中断抢占，FOC总执行时间 = FOC自身时间 + PFC抢占时间：

$$
t_{FOC,max} = t_{FOC} + n_{preempt} \times t_{PFC}
$$

其中$n_{preempt}$为FOC执行期间被PFC抢占的次数：

$$
n_{preempt} = \lceil \frac{t_{FOC}}{T_{PFC}} \rceil = \lceil \frac{12}{15.4} \rceil = 1
$$

$$
t_{FOC,max} = 12 + 1 \times 3 = 15 \text{ μs} < T_{FOC} = 62.5 \text{ μs} 
$$

CPU占用率：

$$
CPU_{load} = \frac{t_{PFC}}{T_{PFC}} + \frac{t_{FOC}}{T_{FOC}} = \frac{3}{15.4} + \frac{12}{62.5} = 19.5\% + 19.2\% = 38.7\%
$$

剩余61.3%的CPU时间可用于速度环、PFC电压环、通信等任务，余量充足。

#### 4.3.3 ADC资源分配

**ADC通道分配方案（GD32F303）：**

| ADC单元 | 通道 | 采样信号 | 采样率 | 触发源 |
|---------|------|---------|--------|--------|
| ADC0 | CH0 | FOC相电流A (Ia) | 16kHz | TIM0 TRGO |
| ADC0 | CH1 | FOC相电流B (Ib) | 16kHz | TIM0 TRGO |
| ADC0 | CH2 | 母线电压 (Vdc) | 16kHz | TIM0 TRGO |
| ADC1 | CH0 | PFC电感电流 (IL) | 65kHz | TIM1 TRGO |
| ADC1 | CH1 | PFC输入电压 (Vin) | 65kHz | TIM1 TRGO |
| ADC1 | CH2 | PFC输出电压 (Vdc) | 65kHz | TIM1 TRGO |
| ADC2 | CH0 | 散热器NTC温度 | 10Hz | 软件触发 |
| ADC2 | CH1 | 环境NTC温度 | 10Hz | 软件触发 |
| ADC2 | CH2 | 用户电位器 | 100Hz | 软件触发 |

**关键设计：母线电压(Vdc)由ADC0和ADC1各采一路，PFC和FOC各自使用，避免跨ADC共享数据的延迟。**

**ADC采样时序：**

```text
TIM0 (FOC, 16kHz, T=62.5μs):
  ┌──────────────────────┐
  │         PWM          │
  ┘                      └──────
       ↑ ADC0触发
       Ia, Ib, Vdc 采样（3个通道顺序采样，约3μs）

TIM1 (PFC, 65kHz, T=15.4μs):
  ┌──────┐
  │ PWM  │
  ┘      └──────────────
     ↑ ADC1触发
     IL, Vin, Vdc 采样（3个通道顺序采样，约1.5μs）
```

**ADC采样冲突避免：**

ADC0和ADC1是独立的ADC单元，可以并行采样，互不干扰。但需要注意：
- 两个ADC不能同时访问同一个通道（硬件限制）
- Vdc信号需要两路独立的采样电路（分压电阻+滤波电容）
- 或者使用ADC注入组（inject group）实现紧急采样

### 4.4 成本优化

#### 4.4.1 无传感器方案

无传感器FOC省去了编码器/霍尔传感器，是家电变频的标配：

| 方案 | 省去器件 | 节省成本 | 适用转速范围 |
|------|---------|---------|------------|
| 滑模观测器(SMO) | 编码器 | $2~5 | > 10% 额定转速 |
| 磁链观测器 | 编码器 | $2~5 | > 5% 额定转速 |
| 高频注入 | 编码器 | $2~5 | 0~10% 额定转速 |
| 反电动势过零 | 霍尔+编码器 | $3~8 | > 5% 额定转速（方波控制） |

**家电主流方案：** I-f启动 + 滑模观测器/磁链观测器FOC，成本节省$2~5/台。

#### 4.4.2 单电阻采样+PFC的ADC复用

单电阻采样（Single-Shunt）只使用母线直流母线上的一个电流采样电阻，通过PWM重构三相电流：

**传统三电阻方案 vs 单电阻方案：**

| 对比维度 | 三电阻采样 | 单电阻采样 |
|---------|-----------|-----------|
| 电流传感器 | 3个运放+3个ADC通道 | 1个运放+1个ADC通道 |
| BOM成本 | $0.6~1.0 | $0.2~0.3 |
| 采样精度 | 高（直接测量） | 中（需要重构） |
| 最小脉宽限制 | 无 | 有（< 2μs的PWM脉宽无法采样） |
| 算法复杂度 | 低 | 高（PWM移相+电流重构） |
| 适用场景 | 高性能伺服 | 家电变频 |

**单电阻采样与PFC的ADC复用挑战：**

单电阻采样需要在每个PWM周期内采样2~3次（重构三相电流），加上PFC的采样需求，ADC时序极为紧张：

```text
一个FOC PWM周期内(62.5μs)的ADC采样时序：

  ┌─┐         ┌──────┐         ┌──────┐
  │ │         │      │         │      │
  ┘ └─────────┘      └─────────┘      └──
  ↑  ↑              ↑              ↑
  │  采样1           采样2          采样3
  │  (Ibus, Ia重构)  (Ibus, Ib重构) (PFC: IL, Vin)
  │
  PFC采样(65kHz周期内)
```

**解决方案：**
1. PFC采样在FOC PWM的零向量期间插入，避免与FOC电流采样冲突
2. 降低PFC采样率到32.5kHz（FOC每2个周期采样1次PFC），释放ADC时间
3. 使用ADC注入组实现PFC紧急采样（过流保护）

#### 4.4.3 减少母线电容

母线电容是BOM成本的大头（电解电容占$0.5~1.5），减少电容容值可以显著降低成本：

**电容容值与成本的关系：**

| 容值 | 规格 | 单价 | 数量 | 总成本 |
|------|------|------|------|--------|
| 680μF | 450V/680μF | $1.20 | 1 | $1.20 |
| 470μF | 450V/470μF | $0.90 | 1 | $0.90 |
| 330μF | 450V/330μF | $0.70 | 1 | $0.70 |
| 220μF | 450V/220μF | $0.50 | 2 | $1.00 |

**减少电容的代价：**

$$
\Delta V_{dc} = \frac{P_{out}}{2\omega \cdot C_{bus} \cdot V_{dc}}
$$

| 容值 | 纹波电压 | 纹波比 | 评价 |
|------|---------|--------|------|
| 680μF | 11.7V | 2.9% | 充裕 |
| 470μF | 16.9V | 4.2% | 可接受 |
| 330μF | 24.1V | 6.0% | 偏大，需要母线电压前馈补偿 |
| 220μF | 36.2V | 9.1% | 过大，电机转矩脉动明显 |

**减少电容的补偿措施：**

1. **母线电压前馈补偿**：在逆变器控制中补偿母线纹波对输出电压的影响

$$
V_{ref,comp} = V_{ref} \times \frac{V_{dc,rated}}{V_{dc,actual}}
$$

2. **PFC电压环带宽优化**：在保证THD的前提下尽量提高电压环带宽，减小纹波

3. **增大PFC电感**：更大的电感→更小的电流纹波→更小的电容纹波电流→可以用更小的电容

4. **使用薄膜电容替代部分电解电容**：薄膜电容ESR更低，高频性能更好，但容值/价格比差

### 4.5 认证要求

#### 4.5.1 IEC 61000-3-2 谐波电流限制

IEC 61000-3-2是家电变频必须通过的认证，规定了输入电流的各次谐波限值：

**Class A限值（>75W的家电）：**

| 谐波次数 | 电流限值(A) |
|---------|------------|
| 3 | 2.30 |
| 5 | 1.14 |
| 7 | 0.77 |
| 9 | 0.40 |
| 11 | 0.33 |
| 13 | 0.21 |
| 15~39 | 2.25/n |

**Class D限值（<600W的特定设备，按mA/W计）：**

| 谐波次数 | 限值(mA/W) |
|---------|-----------|
| 3 | 3.4 |
| 5 | 1.9 |
| 7 | 1.0 |
| 9 | 0.5 |
| 11 | 0.35 |
| 13 | 0.296 |

**通过认证的关键：**

1. PFC满载PF > 0.99，THD < 5%
2. 过零畸变必须控制在合理范围内
3. 轻载（25%、50%）也需要满足要求
4. 电网电压波动（±10%）下仍需满足

#### 4.5.2 EMC认证

**传导EMI（EN 55032 / CISPR 32）：**

| 频段 | Class B (家用) | Class A (商用) |
|------|---------------|---------------|
| 150kHz~500kHz | 56~46 dBμV | 73 dBμV |
| 500kHz~5MHz | 46 dBμV | 73 dBμV |
| 5MHz~30MHz | 50 dBμV | 73 dBμV |

**辐射EMI（EN 55032）：**

| 频段 | Class B (10m) | Class A (10m) |
|------|--------------|--------------|
| 30MHz~230MHz | 30 dBμV/m | 40 dBμV/m |
| 230MHz~1GHz | 37 dBμV/m | 47 dBμV/m |

**EMC设计要点：**

1. PFC开关频率选择避开AM广播频段（535kHz~1605kHz）
2. EMI滤波器的共模电感需要覆盖PFC和逆变器两个频段
3. Y电容总容量受漏电流限制（< 3.5mA for Class I设备）
4. PCB布局：PFC和逆变器的高频回路面积最小化
5. 变压器/电感采用屏蔽结构，减少辐射

#### 4.5.3 安全认证

| 认证 | 标准 | 关键要求 |
|------|------|---------|
| 电气安全 | IEC 62368-1 / GB 4943 | 绝缘耐压、漏电流、接地 |
| 电磁兼容 | IEC 61000-3-2 / GB 17625.1 | 谐波电流限值 |
| 电磁兼容 | IEC 61000-3-3 / GB 17625.2 | 电压波动和闪烁 |
| 浪涌抗扰 | IEC 61000-4-5 | 1~4kV浪涌 |
| ESD抗扰 | IEC 61000-4-2 | 接触放电±4kV, 空气放电±8kV |
| 快速瞬变 | IEC 61000-4-4 | ±1kV (信号线), ±2kV (电源线) |

**安全认证常见失败点：**

1. Y电容漏电流超标→减小Y电容→EMI可能超标→需要优化EMI滤波器
2. 浪涌测试损坏PFC MOSFET→增加TVS管或压敏电阻(MOV)
3. 电压暂降时PFC失控→增加输入电压检测和软重启逻辑
4. ESD打火导致MCU复位→增加TVS和RC滤波

## 5.  交叉视角  

### 5.1 与PMI-01的交叉

PMI-01讲了PFC+电机的系统架构和母线电容设计，本模块从家电成本约束角度重新审视这些设计——在家电场景下，母线电容不是"够不够"的问题，而是"能不能再省一点"的问题。

### 5.2 与PMI-02的交叉

PMI-02讲了PFC与电机控制的协同设计，本模块从家电场景出发，将协同设计原则应用到具体的单芯片方案中——ADC复用、中断优先级、制动斩波器都是PMI-02理论的工程实践。

### 5.3 与ALG-07的交叉

ALG-07（无传感器观测器）详细讲解了滑模观测器和高频注入的原理，本模块从家电压缩机启动角度应用了这些技术。

### 5.4 与ALG-02的交叉

ALG-02（电流采样时序）详细讲解了PWM同步采样的原理，本模块从单电阻采样+PFC的ADC复用角度应用了这些技术。
