# PMI-01: PFC与电机控制系统架构

**副标题：从AC插座到电机轴——完整功率链路的系统级设计**

**难度：** ★★★★☆

---

## 1. 📌 核心摘要 ★★★★☆ 🔰📚

**一句话讲清楚**：PFC与电机控制系统架构的核心是"AC→EMI滤波→整流→PFC(Boost)→母线电容→逆变器→电机"这条完整功率链路，其中PFC前级和逆变器后级通过母线电容耦合——母线电容既要吸收PFC输出的2倍工频纹波，又要承受逆变器抽取的PWM纹波电流，两者的叠加效应决定了电容的选型和寿命。

**认知挂钩**：很多工程师把PFC和电机逆变器当作两个独立模块分别设计，**但它们共享同一条母线、同一个MCU、同一块PCB——母线电容上的纹波电流是PFC纹波和逆变器纹波的矢量和，而不是简单相加！** 选错电容容值或ESR，轻则母线电压纹波超标导致电机转矩脉动，重则电容过热爆浆。这不是"1+1=2"的加法题，而是"1+1=1.4~2.2"的矢量叠加题。

**与PP-04的关系**：PP-04讲的是PFC本身的原理和设计，本模块讲的是PFC嵌入电机驱动系统后的架构级问题——PFC不再是一个孤立的AC→DC变换器，而是整个功率链路的一环。

## 2. 🤔 问题引入 ★★★★☆ 🔰

### 工程师的真实困惑

**场景1：母线电容频繁损坏**
```text
工程师A:"空调变频板上的450V电解电容用了半年就鼓包，
拆开看ESR已经增大3倍...
计算纹波电流时只考虑了PFC输出纹波，
没算逆变器抽取的纹波电流..."
问题现象:
- 电解电容顶部鼓包，漏液
- 母线电压纹波从10V增大到40V
- 电机低速运行时出现明显抖动
```

**场景2：PFC和逆变器互相干扰**
```text
工程师B:"PFC开启后电机电流THD从3%恶化到8%，
示波器看母线电压有明显的100Hz波动..."
问题现象:
- 母线电压叠加了100Hz纹波（PFC输出2倍工频分量）
- 逆变器将100Hz纹波调制到电机电流
- 电机产生6倍工频(300Hz)转矩脉动
```

**场景3：单芯片方案ADC资源不够**
```text
工程师C:"用STM32F103做PFC+FOC，ADC通道不够用...
PFC需要3路（电感电流+输入电压+输出电压），
FOC需要3路（2相电流+母线电压），
加上温度和用户接口，总共需要10路以上..."
问题现象:
- ADC采样时序冲突
- PFC电流采样被FOC中断打断
- 电流环带宽受限于采样率
```

### 核心问题

- 母线电容损坏 → PFC纹波电流与逆变器纹波电流的叠加效应被忽视
- 电机电流恶化 → 母线电压纹波通过逆变器耦合到电机侧
- ADC资源不够 → PFC和FOC的采样需求未在架构层面统筹规划

### 学习目标

读完本模块，你将能够：

✅ **绘制完整功率链路** - 从AC输入到电机输出的每一级变换
✅ **选择PFC拓扑** - 根据功率等级和应用场景选择最优拓扑
✅ **设计母线电容** - 计算PFC纹波与逆变器纹波的叠加
✅ **评估单芯片集成方案** - ST/TI/Infineon主流方案对比
✅ **理解PFC与电机系统的耦合机制** - 母线电容是关键耦合点

## 3. 💡 直观理解 ★★★★☆ 🔰💡

### 类比1：功率链路就像"自来水系统"

```text
AC电网 = 水厂（水源，压力波动）
  │
EMI滤波 = 减压阀（过滤压力脉动）
  │
整流桥 = 单向阀（只允许正向水流）
  │
PFC = 恒压泵（把水压提升并稳定到400V）
  │
母线电容 = 蓄水池（缓冲供需不平衡）
  │          ↑ PFC往里注水（有100Hz波动）
  │          ↓ 逆变器往外抽水（有PWM频率波动）
  │
逆变器 = 变频水泵（按需调节流量和频率）
  │
电机 = 用水设备（负载变化大）
```

**关键洞察**：蓄水池（母线电容）同时承受两个方向的波动——PFC注入的100Hz低频波动和逆变器抽取的高频PWM波动。如果蓄水池太小，水位（母线电压）就会剧烈波动，影响下游设备（电机）的运行质量。

### 类比2：母线电容纹波叠加就像"两个方向的浪"

```text
PFC注入的纹波（100Hz正弦）：
  ∿∿∿∿∿∿∿∿∿∿∿∿  (缓慢的大波浪)

逆变器抽取的纹波（PWM频率）：
  ⚡⚡⚡⚡⚡⚡⚡⚡⚡⚡  (快速的小脉冲)

叠加后：
  ∿∿∿∿∿∿∿∿∿∿∿∿  +  ⚡⚡⚡⚡⚡⚡⚡⚡⚡⚡
  = 大波浪上叠加了快速抖动

电容的有效值纹波电流 = √(I²_pfc + I²_inv + 2·I_pfc·I_inv·cosφ)
  不是简单的 I_pfc + I_inv ！
```

## 4. 🔬 技术原理 ★★★★☆ 📚

### 4.1 完整功率链路

从AC插座到电机轴的完整功率变换链路：

```text
  AC电网          EMI滤波        整流桥        PFC(Boost)      母线电容       逆变器        电机
  220V/50Hz    L_CM+L_DM+C    4×二极管     MOSFET+L+D     C_bulk+C_film   6×IGBT/MOSFET  PMSM/BLDC
     │             │             │             │               │              │            │
     ▼             ▼             ▼             ▼               ▼              ▼            ▼
  正弦交流 ──► 抑制EMI ──► 脉动直流 ──► 400V稳定直流 ──► 纹波滤波 ──► PWM调制的交流 ──► 旋转磁场
              (传导/辐射)   (100Hz脉动)   (PF→1)        (低频+高频)    (FOC/SVPWM)    (电磁转矩)
```

**各级功能与关键参数：**

| 功率级 | 功能 | 输入 | 输出 | 关键参数 | 效率 |
|--------|------|------|------|---------|------|
| EMI滤波 | 抑制传导EMI，满足EN 55032 | 220VAC | 220VAC（滤波后） | CM/DM插入损耗 | ~99.9% |
| 整流桥 | AC→DC（不可控） | 220VAC | 310VDC（脉动） | 反向耐压>600V | ~98% |
| PFC(Boost) | 功率因数校正+升压 | 310VDC（脉动） | 400VDC（稳定） | PF>0.99, THD<5% | ~97% |
| 母线电容 | 储能+纹波滤波 | 400VDC（含纹波） | 400VDC（更纯净） | 纹波<5% | N/A |
| 逆变器 | DC→AC（可控） | 400VDC | PWM交流 | 开关频率10~20kHz | ~96% |
| 电机 | 电能→机械能 | PWM交流 | 转矩+转速 | 效率>90% | ~90% |

**系统总效率估算：**

$$
\eta_{total} = \eta_{EMI} \times \eta_{rect} \times \eta_{PFC} \times \eta_{inv} \times \eta_{motor}
$$

$$
\eta_{total} \approx 0.999 \times 0.98 \times 0.97 \times 0.96 \times 0.90 \approx 0.82
$$

典型家电变频系统总效率约80%~85%。

### 4.2 PFC拓扑选择对比

不同功率等级和应用场景需要不同的PFC拓扑：

#### 4.2.1 传统Boost PFC

```text
         L (Boost电感)     D (快恢复二极管)
  Vac ───┤├──────┬─────────►|──────┬─── Vdc (+)
         │      │ S1(MOSFET)│     │
         │      └────┤├─────┘    C (输出电容)
         │                         │
  N  ─────────────────────────────┴─── Vdc (-)
```

**适用场景：** < 2kW，家电变频，成本敏感

| 优点 | 缺点 |
|------|------|
| 电路简单，BOM少 | 整流桥2×二极管压降，导通损耗大 |
| 控制成熟，方案多 | 效率上限~97% |
| 成本最低 | 不支持双向能量流 |

#### 4.2.2 无桥PFC（Bridgeless PFC）

```text
         L (Boost电感)
  Vac ───┤├──────┬──────────────┬─── Vdc (+)
         │      │              │
         │    S1(MOSFET)     D1(快恢复)
         │      │              │
         │      ├──────────────┤
         │      │              │
         │    S2(MOSFET)     D2(快恢复)
         │      │              │
  N  ────┴──────┴──────────────┴─── Vdc (-)
```

**适用场景：** 1~5kW，对效率有要求

| 优点 | 缺点 |
|------|------|
| 消除整流桥，效率提升1~2% | EMI更差（高频回路不固定） |
| 导通路径只有1×MOSFET+1×二极管 | 电流采样复杂（需要两个传感器或切换） |
| 成本适中 | 控制逻辑比传统Boost复杂 |

#### 4.2.3 图腾柱PFC（Totem-Pole PFC）

```text
         L (Boost电感)
  Vac ───┤├──────┬──────────────┬─── Vdc (+)
         │      │              │
         │    S1(GaN/SiC)    S3(GaN/SiC)
         │      │  (高速桥臂)  │
         │      ├──────┬───────┤
         │      │      │       │
         │    S2(GaN/SiC)    S4(GaN/SiC)
         │      │  (低速桥臂)  │
         │      │              │
  N  ────┴──────┴──────────────┴─── Vdc (-)
```

**适用场景：** > 3kW，高效率需求，双向能量流

| 优点 | 缺点 |
|------|------|
| 效率最高（~99%） | 必须使用GaN/SiC，成本高 |
| 支持双向能量流（AFE） | 控制最复杂（换流逻辑+PLL） |
| 无整流桥损耗 | EMI设计挑战大 |
| GaN零Qrr，过零畸变小 | 驱动电路设计要求高 |

**为什么必须用GaN/SiC？** 传统Si MOSFET的体二极管有较大的反向恢复电荷$Q_{rr}$（数百nC），在高速桥臂换流时会产生巨大的反向恢复电流，导致开关损耗急剧增加甚至器件损坏。GaN HEMT的$Q_{rr} \approx 0$，从根本上解决了这个问题。

#### 4.2.4 交错并联PFC（Interleaved PFC）

```text
  Vac ───┬── L1 ── S1 ── D1 ──┬─── Vdc (+)
         │                     │
         ├── L2 ── S2 ── D2 ──┤    C
         │                     │
  N  ────┴─────────────────────┴─── Vdc (-)
```

**适用场景：** 2~5kW，需要降低输入纹波和EMI

| 优点 | 缺点 |
|------|------|
| 输入电流纹波降低50%+ | BOM翻倍（2套电感+开关管） |
| 热分布更均匀 | 需要2路独立电流采样 |
| EMI滤波器可以更小 | 均流控制增加复杂度 |
| 纹波频率翻倍（2×fsw） | 成本增加30~50% |

#### 4.2.5 拓扑选择决策矩阵

| 功率等级 | 效率要求 | 成本敏感度 | 双向需求 | 推荐拓扑 |
|---------|---------|-----------|---------|---------|
| < 1kW | 一般 | 高 | 无 | 传统Boost PFC |
| 1~3kW | 一般 | 高 | 无 | 传统Boost PFC |
| 1~3kW | 高 | 中 | 无 | 无桥PFC / 2相交错PFC |
| 3~10kW | 高 | 中 | 无 | 2相交错PFC / 无桥PFC |
| 3~10kW | 极高 | 低 | 有 | 图腾柱PFC (GaN) |
| > 10kW | 高 | 低 | 有 | 三相Vienna / 三相AFE |
| > 20kW | 高 | 低 | 有 | 三相有源前端(AFE) |

### 4.3 母线电容设计：PFC纹波与逆变器纹波的叠加

母线电容是PFC前级和逆变器后级的关键耦合点，其设计必须同时考虑两侧的纹波电流需求。

#### 4.3.1 PFC侧纹波电流

PFC输出电流包含2倍工频纹波（100Hz/120Hz），这是因为PFC输入功率是脉动的：

$$
P_{in}(t) = V_{in,peak} \sin(\omega t) \cdot I_{in,peak} \sin(\omega t) = \frac{V_{in,peak} I_{in,peak}}{2} (1 - \cos(2\omega t))
$$

其中$-\cos(2\omega t)$项就是2倍工频脉动分量。PFC输出的2倍工频纹波电流有效值：

$$
I_{C,pfc,rms} = \frac{P_{out}}{V_{dc}} \cdot \frac{1}{\sqrt{2}} \cdot \sqrt{1 - \frac{8}{3\pi} \cdot \frac{V_{in,peak}}{V_{dc}}}
$$

简化估算（$V_{dc} \gg V_{in,peak}$时）：

$$
I_{C,pfc,rms} \approx \frac{P_{out}}{\sqrt{2} \cdot V_{dc}}
$$

**PFC纹波电压（2倍工频）：**

$$
\Delta V_{dc,pfc} = \frac{P_{out}}{2\omega \cdot C_{bus} \cdot V_{dc}}
$$

其中$\omega = 2\pi \times 50 = 314$ rad/s。

#### 4.3.2 逆变器侧纹波电流

逆变器从母线电容抽取的电流包含开关频率及其倍频的纹波分量。三相逆变器输入电流的纹波有效值近似为：

$$
I_{C,inv,rms} \approx I_{phase,rms} \cdot \sqrt{2M \cdot \left(\frac{\sqrt{3}}{4\pi} + \frac{\sqrt{3}M}{\pi}\right)}
$$

其中$M$为调制比（0~1），简化估算：

$$
I_{C,inv,rms} \approx 0.5 \cdot I_{phase,rms}
$$

**经验值：** 逆变器纹波电流约为相电流有效值的30%~60%，取决于调制方式和功率因数。

#### 4.3.3 纹波电流叠加计算

母线电容承受的总纹波电流是PFC侧和逆变器侧纹波的矢量和：

$$
I_{C,total,rms} = \sqrt{I_{C,pfc,rms}^2 + I_{C,inv,rms}^2 + 2 \cdot I_{C,pfc,rms} \cdot I_{C,inv,rms} \cdot \cos\varphi}
$$

其中$\varphi$为PFC纹波与逆变器纹波之间的相位差。

**关键点：** $\cos\varphi$的值取决于电机运行频率与电网频率的关系，通常在-0.5~0.5之间变化。最恶劣情况下（$\cos\varphi = 1$）：

$$
I_{C,total,rms,max} = I_{C,pfc,rms} + I_{C,inv,rms}
$$

最乐观情况下（$\cos\varphi = -1$）：

$$
I_{C,total,rms,min} = |I_{C,pfc,rms} - I_{C,inv,rms}|
$$

**工程安全做法：** 按$I_{C,total,rms} = \sqrt{I_{C,pfc,rms}^2 + I_{C,inv,rms}^2}$计算（假设不相关），再留10~20%余量。

#### 4.3.4 母线电容选型计算示例

**设计条件：**
- 输出功率：$P_{out} = 2$ kW
- 母线电压：$V_{dc} = 400$ V
- 电网频率：50 Hz
- 电机相电流有效值：$I_{phase,rms} = 4$ A
- 允许母线纹波：$\Delta V_{dc} \leq 10$ V

**Step 1：PFC侧纹波电流**

$$
I_{C,pfc,rms} \approx \frac{2000}{\sqrt{2} \times 400} = 3.54 \text{ A}
$$

**Step 2：逆变器侧纹波电流**

$$
I_{C,inv,rms} \approx 0.5 \times 4 = 2.0 \text{ A}
$$

**Step 3：总纹波电流**

$$
I_{C,total,rms} = \sqrt{3.54^2 + 2.0^2} = \sqrt{12.53 + 4.0} = \sqrt{16.53} = 4.07 \text{ A}
$$

加20%余量：$I_{C,total,rms,design} = 4.07 \times 1.2 = 4.88$ A

**Step 4：电容容值（满足纹波电压要求）**

$$
C_{bus} \geq \frac{P_{out}}{2\omega \cdot V_{dc} \cdot \Delta V_{dc}} = \frac{2000}{2 \times 314 \times 400 \times 10} = 796 \text{ μF}
$$

**Step 5：电容纹波电流校验**

选择2颗450V/470μF电解电容并联：
- 单颗纹波电流额定：3.5 A（105°C, 120Hz）
- 并联总纹波电流额定：7.0 A
- 设计需求：4.88 A
- 余量：$7.0 / 4.88 = 1.43$ ✅

**Step 6：高频去耦**

在逆变器输入端并联薄膜电容（1~10μF），吸收高频PWM纹波，降低ESR对高频纹波的影响。

| 电容类型 | 规格 | 数量 | 作用 |
|---------|------|------|------|
| 电解电容 | 450V/470μF, 3.5A纹波 | 2 | 储能+低频纹波滤波 |
| 薄膜电容 | 630V/4.7μF, 低ESR | 1 | 高频纹波去耦 |
| 陶瓷电容 | 500V/0.1μF | 2 | MHz级噪声去耦 |

### 4.4 单芯片集成方案

PFC+电机控制在同一MCU上实现是家电变频的主流方案，以下是三大MCU厂商的集成方案对比：

#### 4.4.1 ST STNRG系列

**代表芯片：** STNRG388A（数字PFC+电机控制器）

| 特性 | 参数 |
|------|------|
| 内核 | ARM Cortex-M0+ |
| PFC通道 | 1~2相交错Boost PFC |
| 电机通道 | 3相PWM（FOC/六步换相） |
| ADC | 12-bit, 1Msps, 多通道 |
| PWM分辨率 | 8-bit（PFC）+ 12-bit（电机） |
| 通信 | UART, I2C |
| 封装 | TSSOP38 |

**优势：** 专用PFC硬件加速器，自动完成电流参考生成和乘法运算，减轻CPU负担。

**劣势：** 内核性能有限（M0+），不适合复杂观测器算法。

**典型应用：** 空调变频压缩机（1~3kW）

#### 4.4.2 TI C2000系列

**代表芯片：** TMS320F280049C

| 特性 | 参数 |
|------|------|
| 内核 | C28x（32位定点DSP） |
| 主频 | 100 MHz |
| PWM | ePWM × 16通道（高精度） |
| ADC | 12-bit, 3.45Msps, 多通道 |
| CLA | 控制律加速器（独立内核） |
| DMA | 6通道 |
| 通信 | CAN, UART, SPI, I2C |

**优势：** CLA可以独立执行一个控制环（如PFC电流环），主核执行另一个（如FOC），真正并行处理。PWM精度高，ADC速度快。

**典型应用：** 工业变频器、伺服驱动（5~20kW）

## 5. 🔗 交叉视角 ★★★★☆ 🔄

### 5.1 与PP-04的交叉说明

PP-04（PFC功率因数校正）详细讲解了PFC本身的原理：Boost PFC工作原理、双环控制结构、过零畸变、THD优化等。本模块（PMI-01）的视角不同——不是"PFC怎么设计"，而是"PFC嵌入电机系统后怎么设计"。

| 维度 | PP-04视角 | PMI-01视角 |
|------|----------|-----------|
| PFC输出 | 关注PF和THD | 关注母线纹波对电机的影响 |
| 母线电容 | 仅考虑PFC侧纹波 | PFC+逆变器纹波叠加 |
| 控制环 | PFC独立双环 | PFC环与电机环的带宽协调 |
| EMI | PFC自身的传导EMI | PFC与逆变器EMI的频谱叠加 |
| 保护 | PFC过压/过流 | PFC保护与电机保护的阈值配合 |
| MCU | PFC独立MCU | PFC+电机共用MCU的资源分配 |

### 5.2 与SYS-03的交叉说明

SYS-03（PFC vs 电机控制方法论）从控制理论角度对比了PFC和FOC的相似性。本模块从系统架构角度补充了SYS-03未涉及的硬件层面问题。

### 5.3 与PP-07的交叉说明

PP-07（功率变换与电机驱动）从功率变换角度讨论了AC→DC→AC的完整链路。本模块在此基础上深入PFC与母线电容的耦合设计。

## 6. 🏭 工程案例 ★★★☆☆ 🔧

### 案例1：2kW空调变频板母线电容设计

**系统参数：**
- 输入：220VAC/50Hz
- PFC输出：400VDC
- 电机：1.5kW BLDC压缩机
- 调制方式：SVPWM，fsw = 16kHz

**设计过程：**

1. PFC侧纹波电流：$I_{C,pfc} = 2000/(\sqrt{2} \times 400) = 3.54$ A
2. 逆变器侧纹波电流：$I_{C,inv} \approx 0.5 \times 3.5 = 1.75$ A（相电流3.5A）
3. 总纹波电流：$I_{C,total} = \sqrt{3.54^2 + 1.75^2} = 3.95$ A
4. 选择2×450V/330μF电解电容（单颗纹波3.0A），总纹波额定6.0A
5. 余量：$6.0/3.95 = 1.52$ ✅
6. 母线纹波电压：$\Delta V = 2000/(2 \times 314 \times 400 \times 660 \times 10^{-6}) = 12$ V（3%，可接受）

**实际测量结果：**
- 满载母线纹波：10Vpp（100Hz）+ 2Vpp（16kHz），总计12Vpp
- 电容表面温度：72°C（环境40°C），在安全范围内
- PF = 0.995, THD = 4.2%

### 案例2：3kW工业变频器PFC拓扑选择

**需求：**
- 三相380V输入
- 输出3kW驱动异步电机
- 要求效率>96%，PF>0.98
- 不需要能量回馈

**选择过程：**

三相输入排除了单相Boost PFC。候选方案：
1. 三相Vienna整流器（三电平PFC）——效率高，但控制复杂
2. 三相不控整流+DC/DC Boost PFC——简单，但PF较差
3. 三相有源前端(AFE)——性能最好，但成本最高

**最终选择：** 三相Vienna整流器，因为效率高（>97%）、PF好（>0.99）、成本适中（不需要6个IGBT），且不需要双向能量流。
