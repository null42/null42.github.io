# MC-01 模块测验
### 第1题 [中等] - dq电压方程 ★★
**问题:** 写出稳态下PMSM的dq电压方程 ud=Rs·id - ωe·Lq·iq 和 uq=Rs·iq + ωe·(Ld·id+ψpm)，并解释每一项的物理含义。
**参考答案:**
- Rs·id / Rs·iq：定子电阻上的压降，与电流同相，产生铜耗
- ωe·Lq·iq（d轴）：q轴电流通过旋转磁场在d轴绕组中感应的反电动势分量，本质是运动反电动势
- ωe·Ld·id（q轴）：d轴电流通过旋转磁场在q轴绕组中感应的反电动势分量
- ωe·ψpm（q轴）：永磁体磁场旋转在q轴绕组中切割产生的反电动势，是PMSM反电动势的主要来源
- 负号的物理意义：d轴方程中 -ωe·Lq·iq 表示q轴磁链旋转在d轴产生的感应电压方向与id参考方向相反

### 第2题 [较难] - 磁阻 vs 永磁转矩 ★★★
**问题:** 永磁转矩和磁阻转矩的本质区别。为什么SPMSM(Ld≈Lq)没有磁阻转矩？给出转矩方程 Te=1.5·pp·[ψpm·iq + (Ld-Lq)·id·iq]。
**参考答案:**
- 永磁转矩 = 1.5·pp·ψpm·iq：由定子电流iq与永磁体磁场ψpm相互作用产生，与id无关，是"磁场×电流"的经典力
- 磁阻转矩 = 1.5·pp·(Ld-Lq)·id·iq：由d/q轴磁路不对称（凸极效应）产生，本质是转子趋向于使磁阻最小位置运动的力。不需要永磁体，IPMSM/SynRM都利用此转矩
- SPMSM表贴式永磁同步电机：永磁体贴在转子表面，d轴和q轴磁路几乎对称（磁路都经过永磁体），所以Ld≈Lq，(Ld-Lq)≈0，磁阻转矩为零
- 工程意义：SPMSM只能靠ψpm·iq产生转矩，控制简单；IPMSM可以利用磁阻转矩实现MTPA，在相同电流幅值下输出更大转矩

### 第3题 [中等] - ωe vs ωm ★★
**问题:** 电角速度ωe和机械角速度ωm的关系。极对数pp=4时，机械转速3000rpm对应的电频率是多少？
**参考答案:**
- 关系式：ωe = pp · ωm，即电角速度等于极对数乘以机械角速度
- 计算过程：
  - 机械角速度 ωm = 3000 × 2π/60 = 100π rad/s
  - 电角速度 ωe = 4 × 100π = 400π rad/s
  - 电频率 fe = ωe/(2π) = 400π/(2π) = 200 Hz
- 物理直觉：一对极对应一个完整的电周期。pp=4意味着转子转一圈经历4个电周期，所以电频率是机械频率的4倍
- 对FOC的意义：电流环带宽需要远大于电频率（通常10倍以上）。200Hz电频率意味着电流环带宽至少需要2kHz，通常取5-10kHz

### 第4题 [较难] - 坐标系定义 ★★★
**问题:** αβ静止坐标系和dq旋转坐标系的定义。Clark变换将三相abc映射到αβ，Park变换将αβ旋转到dq——这两个变换的物理直觉是什么？
**参考答案:**
- αβ静止坐标系：α轴固定对齐a相绕组轴线，β轴超前α轴90°电角度。这是一个固定在定子上的坐标系，三相电流在该坐标系中表示为两个正交分量(iα, iβ)，形成一个在空间旋转的电流矢量
- dq旋转坐标系：d轴对齐转子磁极方向（永磁体N极），q轴超前d轴90°电角度。这是一个随转子同步旋转的坐标系
- Clark变换的物理直觉：三相电流虽然时间上相位差120°，但它们在空间上产生的是一个旋转磁场矢量。Clark将三相关节降维到两相αβ，等价于"用一个等效的两相绕组替代三相绕组，使其产生的磁场完全相同"
- Park变换的物理直觉：站在旋转的转子上看定子电流。在abc和αβ中，电流是交流量（正弦变化）；Park变换将这个旋转到转子上观察，使电流变为直流量(id和iq为常数)。这样就能用简单的PI控制器来控制交流电机的转矩，这就是FOC的核心思想
- 整体意义：abc→αβ→dq是将"三相时变交流系统"转化为"两相直流系统"的过程，使复杂的交流电机控制简化为类似直流电机的控制
