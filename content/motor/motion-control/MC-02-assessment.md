# MC-02 模块测验
### 第1题 [较难] - 幅值不变 vs 功率不变 ★★★
**问题:** 为什么FOC中通常用幅值不变Clarke变换(系数2/3)而不是功率不变(系数√(2/3))？两者的3/2变换矩阵有什么区别？
**参考答案:**
- 幅值不变Clarke（系数2/3）：变换后iα的幅值等于原始三相电流的峰值。矩阵为 (2/3)·[[1, -1/2, -1/2], [0, √3/2, -√3/2]]
- 功率不变Clarke（系数√(2/3)）：变换后功率 uα·iα + uβ·iβ = 三相瞬时功率。矩阵为 √(2/3)·[[1, -1/2, -1/2], [0, √3/2, -√3/2]]
- 两者唯一区别是系数不同：2/3 vs √(2/3)，变换矩阵的形状完全一致
- 选择幅值不变的原因：
  1. 物理直观：变换后的电流/电压幅值直接等于相电流/相电压峰值，方便与电机额定参数对照
  2. 调试便利：示波器观测iα波形可以直接读出相电流峰值，不需要额外换算
  3. 与Park变换配套使用：幅值不变的Clark+Park组合，dq分量幅值也等于相电流峰值，id=0控制时id_ref直接等于0，无需标幺化换算
- 功率不变的优点：在功率计算、能量守恒分析中更自然。但在FOC工程中，工程师更关心电流幅值是否超限，所以幅值不变更实用
- 注意：不管选哪种，正反变换必须一致——正变换用2/3，逆变换也要用对应的系数，否则幅值失真

### 第2题 [中等] - Park角度约定 ★★
**问题:** Park变换中角度θ是d轴与α轴的夹角还是q轴与α轴的夹角？这个角度定义如何影响id/iq的物理含义？
**参考答案:**
- 在lxfoc及大多数FOC实现中，θ定义为d轴与α轴的夹角（电角度）
- 此时Park变换矩阵为：[[cosθ, sinθ], [-sinθ, cosθ]]
- 物理含义：
  - id：电流矢量在d轴（磁极方向）上的投影，代表励磁分量
  - iq：电流矢量在q轴（超前d轴90°方向）上的投影，代表转矩分量
- 角度约定错误的后果：如果误用q轴与α轴夹角，则id和iq的物理意义互换，id变成转矩分量、iq变成励磁分量。此时id_ref=0控制会消除转矩分量，电机无法出力
- 工程调试提示：可以通过空载实验验证——如果id_ref=0时电机正常运行且电流很小，说明角度约定正确；如果电机振动或不转，说明id/iq反了，角度偏移了90°

### 第3题 [中等] - Clarke矩阵 ★★
**问题:** 写出幅值不变Clarke的3→2变换矩阵（含ia,ib,ic→iα,iβ），并验证当ia+ib+ic=0时零序分量为0。
**参考答案:**
- 幅值不变Clarke 3→2变换矩阵：
  ```
  | iα |       2   |  1    -1/2   -1/2 | | ia |
  | iβ |  =  --- · |  0    √3/2  -√3/2 | | ib |
  ```                     3                            | ic |
- 零序分量公式：i0 = (1/3)(ia + ib + ic)
- 验证：当ia+ib+ic=0（三相三线制无中线，基尔霍夫电流定律保证），i0 = (1/3)·0 = 0
- 详细展开：
  - iα = (2/3)(ia - ib/2 - ic/2) = (2/3)(ia - (ib+ic)/2) = (2/3)(ia - (-ia)/2) = (2/3)(3ia/2) = ia
  - 特殊情形验证：ia=1, ib=-0.5, ic=-0.5（三相对称），则 iα = (2/3)(1+0.25+0.25) = (2/3)(1.5) = 1，iβ = (2/3)(0 - √3/2·(-0.5) + √3/2·(-0.5)) = (2/3)(0) = 0
  - 结果：iα=1, iβ=0，即电流矢量恰好沿α轴方向，与预期一致

### 第4题 [较难] - 逆Park使用 ★★★
**问题:** iPark除用于SVPWM外，还有哪些用途（如死区补偿电流极性判断）？
**参考答案:**
- **SVPWM电压指令生成**：将dq电压指令(Vd, Vq)变换回αβ静止坐标系(Vα, Vβ)，再送入SVPWM模块生成PWM占空比
- **死区补偿电流极性判断**：死区效应导致实际输出电压与指令电压偏差，补偿方向取决于电流极性。通过iPark将dq电流变换回αβ或abc，判断各相电流正负，决定死区补偿电压的符号（加还是减）
- **前馈解耦电压计算**：交叉耦合补偿项（如-ωe·Lq·Iq, ωe·(Ld·Id+ψpm)）在dq域计算后，需要通过iPark映射到αβ域才能叠加到SVPWM输入
- **观测器反馈坐标变换**：滑模观测器或磁链观测器在αβ域工作，估计出的反电动势需要通过iPark（或等价运算）转换到dq域进行角度和速度计算
- **谐波注入**：在dq域叠加高次谐波电压（用于降低转矩脉动或噪声），叠加后的总电压指令需要通过iPark变换到αβ域送入调制器
- **弱磁控制电压限制**：弱磁时在dq域计算电压极限圆，将电压限幅结果通过iPark变回αβ，确保最终输出不超出母线电压能力
