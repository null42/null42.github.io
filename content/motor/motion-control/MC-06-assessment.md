# MC-06 模块测验 — 电流环设计

### 第1题 [较难] - PI零极点对消 ★★★

**问题:** 电流环PI设计中 Ki/Kp = Rs/Ld 的依据是零极点对消。解释这一设计方法——PI的零点 -1/Ti 对消了RL负载的极点 -Rs/Ld，结果是一阶系统。如果 Rs 或 Ld 不准确，对消失败会怎样？

**参考答案:**
PMSM电流环的被控对象是RL负载：传递函数 G(s) = 1/(Ld·s + Rs)，极点位于 s = -Rs/Ld。PI控制器传递函数为 Gpi(s) = Kp·(1 + 1/(Ti·s)) = Kp·(Ti·s + 1)/(Ti·s)，零点位于 s = -1/Ti。

令 1/Ti = Rs/Ld，即 Ki = Kp·Rs/Ld，PI的零点恰好对消RL极点，开环传递函数变为 Gopen(s) = Kp/(Ld·Ti·s) = Kp·Rs/(Ld²·s)，系统等效为一阶积分环节，相位裕度90°，稳定性最好。闭环时间常数 τ = Ld/(Kp·Rs)·(Ld/Rs) = Ld²/(Kp·Rs²)，通过调节 Kp 即可设定响应速度。

**对消失败的后果：**
- **Rs 偏大（实际电阻大于设定值）：** 极点更靠近原点，PI零点在极点左侧，对消不完全。等效二阶系统欠阻尼，电流响应出现超调和振荡。
- **Rs 偏小：** 极点在PI零点右侧，系统过阻尼，响应变慢，带宽下降。
- **Ld 偏大（实际电感大于设定值）：** 极点更远离原点，零点在极点右侧，产生残余极点，相位裕度下降，可能出现轻微振荡。
- **Ld 偏小：** 零点在极点左侧，过阻尼，带宽降低，响应速度下降。

工程中通常通过离线辨识获取准确的 Rs 和 Ld（电机参数自动辨识），并在运行中做温度补偿（Rs 随温度变化可达 ±50%）。Ld 受饱和影响也会变化，需根据 id 做查表补偿。

### 第2题 [中等] - 离散域Ki ★★

**问题:** Ki 连续域值 = Kp·Rs/Ld，离散化后 Ki_digital = Ki_cont·Ts。20kHz（PWM频率）和10kHz（电流环采样频率）两种采样频率，这个 Ts 应该取哪个值？为什么？

**参考答案:**
**Ts 应取 1/10kHz = 100μs（即电流环采样周期），而不是 1/20kHz = 50μs。**

原因：
- 电流环的执行频率是电流环采样频率（10kHz），PI调节器每 100μs 计算一次，输出新的占空比给PWM。因此离散化时的采样间隔 Ts 应等于 PI 的计算周期 = 100μs。
- PWM频率（20kHz）决定的是功率级的开关频率，每个PWM周期50μs。在中心对齐PWM模式下，一个电流环采样周期（100μs）包含两个PWM半周期，电流采样通常安排在PWM峰值处，每100μs更新一次PI输出。
- 如果用 Ts = 50μs 做离散化，则 Ki_digital 会偏小一半，导致实际积分作用比设计值弱，电流环带宽低于预期，响应变慢，稳态误差增大。

**总结：** 离散化时的 Ts 始终等于控制算法的执行周期（即电流环采样周期），而非PWM开关周期。

### 第3题 [较难] - Anti-windup的Kc ★★★

**问题:** 电流环 anti-windup 中的退饱和增益 Kc 应如何选择？Kc = 1/Ti（即 Ki/Kp 的比例）的含义是什么？

**参考答案:**
Anti-windup（退饱和/反积分饱和）用于防止PI积分器在输出饱和时继续累积（windup），导致退出饱和时产生严重超调。

**实现原理：** 当PI输出达到限幅（如电压限幅 Vmax），将饱和误差（PI输出 - 限幅值）乘以退饱和增益 Kc，反馈到积分器输入端，抵消多余的积分累积。

**Kc 的选择：**
- **Kc = 1/Ti = Ki/Kp = Rs/Ld：** 此时退饱和回路的传递函数为 Kc·Kp = Kp/Ti = Ki，与PI的积分通路增益匹配。退饱和时间常数等于PI的积分时间常数 Ti，即积分器以与正常积分相同的速率释放饱和累积量。这是工程上最常用的选择，退饱和速度适中。
- **Kc 过小：** 退饱和太慢，退出饱和时仍有大量残余积分量，导致超调和振荡。
- **Kc 过大：** 退饱和太快，积分器被过度反向充电，退出饱和瞬间产生反向超调（电流反向冲击），甚至引发极限环振荡。

**Kc = 1/Ti 的物理含义：** 饱和期间，退饱和反馈以 Ki·(u_sat - u_out)/Kp 的速率从积分器中抽出累积量，速率恰好等于正常积分时的累积速率，保证饱和退出时间约等于一个 Ti，既快速退饱和又不会产生反向冲击。

### 第4题 [中等] - 电流圆约束 ★★

**问题:** 在MTPA和弱磁控制中，电流矢量幅值受限于 Imax（逆变器/电机额定值）。为什么 id²+iq² ≤ Imax² 是圆形约束，而电压极限是椭圆形？两者的交点决定了什么工作区域？

**参考答案:**
**电流圆约束：** 逆变器最大输出电流和电机额定电流均限制了电流矢量的幅值，即 id² + iq² ≤ Imax²。这在 id-iq 平面上是以原点为圆心、Imax 为半径的圆。

**电压椭圆约束：** 电机端电压受直流母线限制：(Ld·ωe·id + ψpm·ωe)² + (Lq·ωe·iq)² ≤ (Vmax)²。整理后为：
(Ld·ωe)²·(id + ψpm/Ld)² + (Lq·ωe)²·iq² ≤ Vmax²

这是以 (-ψpm/Ld, 0) 为中心、长短轴分别与 id、iq 轴平行的椭圆。随转速 ωe 升高，椭圆缩小（因为电压需求随转速增大）。

**交点决定的工作区域：**
- 电流圆和电压椭圆的交集区域是电机可行工作域
- **低速区：** 电压椭圆很大（ωe小），电流圆是主要约束 → MTPA轨迹沿电流圆走
- **额定点：** MTPA曲线与电流圆的交点为额定工作点
- **高速弱磁区：** 电压椭圆缩小，与电流圆的交点决定最大输出转矩和最高转速。弱磁运行点沿电流圆移动（保持 id²+iq² = Imax²），同时满足电压椭圆约束（在椭圆边界上）
- **最大转矩/功率输出：** 两约束边界的交点即为该转速下的极限工作点
