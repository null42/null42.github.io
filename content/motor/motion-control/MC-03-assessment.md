# MC-03 模块测验
### 第1题 [中等] - 8个电压矢量 ★★
**问题:** 三相桥有8个开关组合。列出V0(000)到V7(111)，说明其中6个有效矢量与2个零矢量的区别。
**参考答案:**
- 8个开关组合（上桥臂状态ABC）：
  - V0(000)：三相下桥臂全导通 → 输出电压 = 0 → **零矢量**
  - V1(001)：C相上桥臂导通 → 对应空间角度 0°
  - V2(010)：B相上桥臂导通 → 对应空间角度 60°
  - V3(011)：B、C相上桥臂导通 → 对应空间角度 120°
  - V4(100)：A相上桥臂导通 → 对应空间角度 180°
  - V5(101)：A、C相上桥臂导通 → 对应空间角度 240°
  - V6(110)：A、B相上桥臂导通 → 对应空间角度 300°
  - V7(111)：三相上桥臂全导通 → 输出电压 = 0 → **零矢量**
- 有效矢量 vs 零矢量的区别：
  - 6个有效矢量（V1~V6）：在αβ平面上形成正六边形的6个顶点，幅值为 (2/3)·Vdc，相邻矢量间隔60°，能产生旋转磁场驱动电机
  - 2个零矢量（V0, V7）：在αβ平面上位于原点(0,0)，不产生任何磁场，但提供"空闲时间"用于调节PWM占空比和降低开关损耗
- 零矢量的作用：通过分配V0和V7的作用时间，可以调节有效矢量的等效作用时间比例，从而控制合成电压矢量的幅值。同时零矢量的合理分配影响共模电压和开关损耗

### 第2题 [较难] - 扇区号计算 ★★★
**问题:** 如何从Uα,Uβ判断当前属于哪个扇区？给出扇区计算公式（含3条判断线公式）。
**参考答案:**
- 3条判断线（六边形边界在αβ平面的投影）：
  - 线1：Uβ = 0（α轴）
  - 线2：Uβ = √3 · Uα（60°线）
  - 线3：Uβ = -√3 · Uα（120°线）
- 计算中间变量：
  ```
  A = Uβ
  B = (√3 · Uα - Uβ) / 2
  C = (-√3 · Uα - Uβ) / 2
  ```
- 符号判断：
  ```
  若 A > 0，则 X = 1，否则 X = 0
  若 B > 0，则 Y = 2，否则 Y = 0
  若 C > 0，则 Z = 4，否则 Z = 0
  ```
- 扇区号 N = X + Y + Z，查表映射：
  | N | 扇区 |
  |---|------|
  | 3 | I    |
  | 1 | II   |
  | 5 | III  |
  | 4 | IV   |
  | 6 | V    |
  | 2 | VI   |
- 物理直觉：3条判断线将αβ平面等分为6个60°扇区。A、B、C的符号组合唯一确定矢量落在哪个扇区，N值的编码方式使得查表即可得到扇区号

### 第3题 [中等] - 线性调制边界 ★★
**问题:** SVPWM线性调制范围可达多大（相对SPWM的1.0）？为什么SVPWM比SPWM的电压利用率高15.5%？
**参考答案:**
- SVPWM线性调制范围：合成电压矢量的最大幅值 = Vdc/√3 ≈ 0.577·Vdc（相电压峰值），对应的调制比 M = Vdc/(√3·Vdc/2) ... 通常用标幺值表示：
  - SPWM最大调制度 m = 1.0（相电压峰值 = Vdc/2）
  - SVPWM最大线性调制度 m = 2/√3 ≈ 1.155（相电压峰值 = Vdc/√3）
  - 电压利用率提升：(1.155 - 1.0) / 1.0 = 15.5%
- 原因分析：
  - SPWM是正弦波与三角载波比较，等效于在六边形内切圆上工作，但六边形的内切圆半径 = (2/3)·Vdc · cos(30°) = Vdc/√3... 实际上SPWM没有利用六边形角点附近的空间
  - SVPWM直接利用六边形顶点间的区域，合成矢量可以到达六边形内切圆的边界。六边形内切圆半径 = Vdc/√3，而SPWM等效的圆形半径 = Vdc/2
  - 比值：(Vdc/√3) / (Vdc/2) = 2/√3 ≈ 1.155
- 物理意义：SVPWM比SPWM多出的15.5%电压裕量在弱磁扩速时非常关键——同样的母线电压下，电机可以达到更高转速

### 第4题 [较难] - T1+T2>Ts的截断 ★★★
**问题:** 当T1+T2>Ts时超出线性调制范围，写出两种常见的截断策略（等比例缩放和Push-pull overmodulation）。
**参考答案:**
- **等比例缩放（Proportional Scaling）**：
  ```
  若 T1 + T2 > Ts：
      k = Ts / (T1 + T2)
      T1' = k · T1
      T2' = k · T2
  ```
  - 优点：保持电压矢量的方向不变（角度不变），仅缩小幅值。实现简单，过渡平滑
  - 缺点：输出矢量被限制在六边形内切圆上，六边形角点附近的电压能力未利用。谐波较大

- **Push-pull Overmodulation（六边形过调制）**：
  - 当矢量超出内切圆但未超出六边形时，不截断，而是将矢量投影到六边形边界上最近的边
  - 具体做法：保持扇区不变，让T1+T2=Ts，但允许T0=0（零矢量时间为0），合成矢量恰好落在六边形的边上
  - 当进一步超出六边形时，将矢量限制在六边形的顶点
  - 优点：充分利用六边形全部面积，电压利用率最大化
  - 缺点：超出内切圆区域后输出电压含低次谐波（5、7次），转矩脉动增大。过渡区域可能出现不连续跳变

- 工程选择：电动车驱动通常用等比例缩放（平滑性好）；工业主轴驱动追求极限输出时可Push-pull过调制
