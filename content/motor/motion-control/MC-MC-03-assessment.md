# 机械谐振抑制测验

### 第1题 [较难] - 反谐振与谐振频率的物理来源 ★★★

**问题:** 双惯量模型中反谐振频率和谐振频率的物理来源分别是什么？

**参考答案:** 双惯量模型将电机惯量Jm和负载惯量Jl通过有限刚度Ks的传动轴连接。反谐振频率ω_ar：来源于负载侧的谐振。当激励频率等于ω_ar时，负载侧产生共振，负载位移幅值很大，通过弹簧反作用于电机侧，恰好抵消了电机侧的激励，使得电机侧的响应（传递函数输出）出现"零点"——即反谐振频率是传递函数的零点。物理上表现为在该频率处电机端几乎不动，能量全部传递给了负载振动。谐振频率ω_r：来源于电机和负载作为整体在弹簧上的谐振。当Jm和Jl通过Ks耦合时，系统的等效惯量为Jm+Jl（两者同相运动），谐振频率 ω_r = √(Ks(1/Jm + 1/Jl)) = √(Ks(Jm+Jl)/(Jm·Jl))。谐振频率是传递函数的极点，在该频率处系统增益极大，任何小的激励都会产生大的响应。关系：ω_ar < ω_r，且 ω_ar²/ω_r² = Jl/(Jm+Jl)。

### 第2题 [困难] - 谐振比R对谐振严重程度的影响 ★★★★

**问题:** 谐振比R=Jl/Jm越大，谐振问题越严重还是越轻微？为什么？

**参考答案:** 谐振比R=Jl/Jm越大，谐振问题越严重。原因分析：（1）频率间距：反谐振频率ω_ar = √(Ks/Jl)，谐振频率ω_r = √(Ks(Jm+Jl)/(Jm·Jl))。当R增大（Jl增大），ω_ar降低，而ω_r = ω_ar·√(1+R)，ω_r相对ω_ar的比值增大，但两者之间的频率间距（以对数坐标看）变化不大。（2）谐振峰值高度：谐振峰值与反谐振谷值的增益比约为20log10(1+R) dB。R=1时约6dB，R=3时约12dB，R=10时约20.8dB。R越大，谐振峰值越高，系统在谐振频率处的增益越大，越容易不稳定。（3）相位突变：反谐振零点导致相位超前90°，谐振极点导致相位滞后90°，两者叠加产生180°的相位突变。R越大，谐振峰越尖锐，相位变化越剧烈，控制器的相位裕量在谐振频率附近急剧下降。（4）实际影响：大惯量比（如Jl/Jm>5）在工业中很常见（大负载小电机），是最难处理的谐振问题之一。

### 第3题 [困难] - 陷波滤波器参数确定 ★★★★

**问题:** 陷波滤波器的中心频率、深度和宽度分别如何确定？

**参考答案:** 陷波滤波器的传递函数 G_n(s) = (s² + 2ζ₁ω_n·s + ω_n²)/(s² + 2ζ₂ω_n·s + ω_n²)，三个关键参数：（1）中心频率ω_n：应设置为机械谐振频率ω_r。通过频响测试（如正弦扫频）或系统辨识获得。精确匹配至关重要——偏差5%以上效果急剧下降，因为谐振峰非常尖锐。实际中建议用在线辨识或自适应方法持续跟踪ω_r的变化。（2）深度（由ζ₁和ζ₂的比值决定）：深度 = 20log10(ζ₂/ζ₁) dB。ζ₁越小，陷波越深。深度应与谐振峰值匹配——过深会过度削弱谐振频率附近的增益，影响系统响应；过浅则无法充分抑制谐振。通常ζ₁取0.01~0.1，ζ₂取0.5~1.0。（3）宽度（由ζ₂决定）：ζ₂越大，陷波越宽。宽度选择需权衡：太窄只抑制单一频率，当谐振频率漂移时失效；太宽会削弱谐振频率附近的有用带宽。通常ζ₂取0.3~0.7。实际整定流程：先测谐振频率→设ω_n→从浅陷波开始（ζ₁=0.1）→逐步加深直到谐振抑制→检查闭环响应是否恶化。

### 第4题 [较难] - 低通滤波器替代陷波滤波器的场景 ★★★

**问题:** 什么情况下应该用低通滤波器而非陷波滤波器来抑制谐振？

**参考答案:** 应该用低通滤波器替代陷波滤波器的场景：（1）多个谐振频率密集分布——当系统存在多个相近的谐振频率（如柔性负载的多个模态），用多个陷波滤波器参数整定困难且相互干扰，低通滤波器可以一次性衰减所有高频谐振。（2）谐振频率不确定或漂移较大——当谐振频率随负载、温度、磨损等因素变化较大时，固定频率的陷波滤波器可能失效甚至恶化（陷波频率偏离谐振频率后，反而降低了该频率处的阻尼），低通滤波器对频率漂移的鲁棒性更好。（3）谐振频率远高于控制带宽——当谐振频率远高于位置环带宽时（如>5倍），低通滤波器可以在不影响控制性能的前提下衰减谐振，且实现更简单。（4）调试资源有限——低通滤波器只有一个截止频率参数需要整定，而陷波滤波器需要三个参数，在快速调试场景下低通更实用。低通滤波器的代价：会降低系统的相位裕量（在截止频率附近引入相位滞后），可能限制闭环带宽。
