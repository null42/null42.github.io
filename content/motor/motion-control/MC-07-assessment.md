# MC-07 模块测验 — 速度/位置环

### 第1题 [较难] - 级联带宽比 ★★★

**问题:** 三环串级控制的速度环、电流环带宽比通常为 1:5:50（位置:速度:电流）。如果速度环带宽过大会怎样？给出一个稳定性论证。

**参考答案:**
- **带宽比设计原则：** 串级控制中，内环必须比外环响应快足够多，使得外环设计时可以将内环近似为单位增益环节（即内环动态可忽略）。典型设计为相邻环带宽比 ≥ 5倍：位置环 10-50Hz，速度环 50-250Hz，电流环 500-2500Hz。

- **速度环带宽过大的稳定性问题：**

1. **内环近似失效：** 速度环带宽接近电流环带宽的 1/3 时，电流环的相移（包括数字延迟 1.5Ts、滤波器延迟）在速度环穿越频率处已不可忽略。速度环设计时假设电流环输出 = 参考值的前提不再成立，实际相位裕度比设计值小很多，系统趋于振荡甚至不稳定。

2. **机械谐振激励：** 实际传动链有弹性（联轴器、减速器），机械谐振频率通常为 100-500Hz。速度环带宽过高（如 >200Hz）可能激励谐振模态，产生明显的机械振动和噪声。

3. **噪声放大：** 速度信号来自编码器微分或观测器估计，含有高频噪声。速度环带宽越大，对该噪声的抑制越差，导致电流参考抖动，进一步引起转矩脉动和电流环不稳定。

- **稳定性论证（简化）：** 设电流环带宽 ωci，速度环带宽 ωcs。电流环在 ωci 处有 -90° 相移。若 ωcs = ωci/3，速度环穿越频率处电流环相移约 -30°，加上PI的 -90°，总相移约 -120°，相位裕度 60°（安全）。若 ωcs = ωci/1.5，穿越频率处电流环相移约 -60°，总相移约 -150°，相位裕度仅 30°（临界）。

### 第2题 [中等] - 速度斜坡 ★★

**问题:** 速度环参考信号为什么要经过斜坡（RAMP）处理？给定最大加速度 amax，将速度从 0 加速到 ωref 需要多少时间？

**参考答案:**
- **RAMP处理的原因：**
1. **限制加速度/力矩冲击：** 直接给定阶跃速度参考会导致速度误差突变为 ωref，PI输出饱和（输出最大电流限幅），等效于以最大转矩加速。虽然电流环有限幅保护，但加速度仍可能超过机械传动链承受能力，导致齿轮冲击、皮带打滑或联轴器损坏。
2. **保护机械系统：** 实际机械系统有最大允许加速度（由传动刚度、负载惯量、摩擦力等决定），RAMP确保加速度不超过此限值。
3. **改善动态品质：** 缓慢变化的参考使系统工作在线性区，减少超调和调节时间，速度跟踪更平滑。

- **加速时间计算：**
给定最大加速度 amax（单位：rad/s²），从 0 加速到 ωref（单位：rad/s）：

RAMP 以恒定加速度 amax 线性增加参考速度，加速时间 t = ωref / amax

例如：ωref = 300 rad/s（约2865 rpm），amax = 1000 rad/s²，则 t = 300/1000 = 0.3s。

RAMP 输出在达到 ωref 后保持恒定，速度环在此前始终以受控加速度跟踪。

### 第3题 [较难] - 加速度前馈 ★★★

**问题:** 在带大惯量负载时，电流环的 Iq_ref 需要补偿加速力矩 J·dω/dt / (1.5·pp·ψpm) 作为前馈。不做这个前馈的后果是什么？

**参考答案:**
- **运动方程：** Te - TL = J·dω/dt，其中 Te = 1.5·pp·ψpm·iq（表贴式PMSM，id=0时）。

- **加速度前馈的作用：** 在加速/减速过程中，电机需要额外提供加速力矩 J·dω/dt。前馈将此力矩对应的电流 Δiq_ff = J·dω/dt / (1.5·pp·ψpm) 直接叠加到速度环输出的 Iq_ref 中，使电机提前获得所需加速力矩。

- **不做前馈的后果：**

1. **速度跟踪误差大：** 加速力矩完全依赖速度环PI的积分作用逐步建立。对于大惯量负载（J大），需要长时间积分才能积累足够转矩，速度响应出现显著滞后（速度误差持续存在直到积分器输出足够）。

2. **加减速过程速度跌落/过冲：** 加速时实际速度低于参考（因为PI还没来得及输出足够电流），减速时实际速度高于参考（PI还没来得及减少电流）。速度误差随 J 和 dω/dt 增大而增大。

3. **速度环PI被迫增大增益：** 为了减小跟踪误差，只能提高速度环 Kp 和 Ki，但这会增加系统噪声敏感性，且可能激发机械谐振，与带宽约束矛盾。

4. **定位精度下降：** 在频繁加减速的定位应用中，累积的速度误差会转化为位置误差，影响定位精度和循环时间。

- **定量示例：** J = 0.01 kg·m²，dω/dt = 500 rad/s²，pp = 4，ψpm = 0.1 Wb，则 Δiq_ff = 0.01×500/(1.5×4×0.1) = 8.3A。若无前馈，速度环PI需要数秒才能通过积分积累出8.3A的指令，期间速度误差持续存在。

### 第4题 [中等] - 位置环Kp上限 ★★

**问题:** 位置环只有比例增益 Kp（没有积分），Kp 的上限受什么限制？如果 Kp 太大，机械传动链的刚度/间隙会如何响应？

**参考答案:**
- **位置环仅用P控制的原因：** 位置环不需要稳态误差为零（实际上速度环的积分已保证位置稳态无差），加入积分反而降低稳定性裕度。

- **Kp 上限的限制因素：**

1. **机械谐振频率：** Kp 决定了位置环带宽 ωbp = Kp（简化模型）。Kp 过大 → 位置环带宽超过机械传动链的谐振频率 → 激发扭转振动。对于柔性传动（皮带、长轴、减速器），谐振频率可能只有几十Hz，Kp 上限很低。

2. **间隙/齿隙（Backlash）：** 齿轮传动存在间隙。Kp 过大时，位置误差的微小变化会导致大的力矩输出，电机在间隙两侧来回切换，产生极限环振荡（limit cycle），表现为持续的抖动和噪声。

3. **速度环/电流环带宽约束：** 位置环输出是速度参考，必须经过速度环执行。Kp 过大导致速度参考变化过快，超出速度环的响应能力，产生相位滞后，降低稳定性裕度。

4. **编码器分辨率：** 位置环 Kp 过大时，编码器最小分辨率对应的位置误差被放大为显著的速度跳变，导致低速运行时转矩脉动加剧。

- **Kp 太大的响应：** 电机出现高频抖动（机械刚度不足时）或在齿轮间隙处来回撞击（间隙振荡），伴随明显的噪声和磨损。工程上通常通过机械刚度测试（敲击法或扫频法）确定谐振频率，将位置环带宽设定为谐振频率的 1/5~1/10。
