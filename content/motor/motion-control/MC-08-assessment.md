# MC-08 模块测验 — 无感观测器

### 第1题 [较难] - SMO切换增益H ★★★

**问题:** SMO中滑动面切换增益 H = H1·|e_i|，如果 H1 太小会失稳，太大会 chattering。给出 H1 的下界条件（需大于BEMF的最大变化率）。

**参考答案:**
滑模观测器(SMO)的电流估计误差动态方程为：
d(e_i)/dt = -Rs/Ld · e_i + (1/Ld)·(v_err - e_bemf) - H·sgn(e_i)

其中 e_bemf 为反电动势估计值，H 为切换增益。

- **滑动面到达条件（Lyapunov）：** 取 V = 0.5·e_i²，要求 dV/dt = e_i·d(e_i)/dt < 0，即：
e_i·(-Rs/Ld·e_i + (v_err - e_bemf)/Ld) - H·|e_i| < 0

忽略衰减项，充分条件为 H > |e_bemf|/Ld。由于 e_bemf = ωe·ψpm，其最大值为 ωe_max·ψpm，因此：
**H > ωe_max·ψpm / Ld**

即 H1 的下界：H1 > max(|de_bemf/dt|) / Ld，其中 de_bemf/dt 的最大值出现在最高电角速度和最大磁链时。

- **H1 太小的后果：** 不满足到达条件，滑动面无法建立，e_i 无法收敛到零，观测器发散，角度估计完全错误，电机失步。

- **H1 太大的后果：** 高频切换（chattering）严重，sgn 函数在零附近快速跳变，等效高频噪声注入电流环，导致：
- 转矩脉动增大
- 电流谐波增加
- BEMF估计中高频分量难以被LPF完全滤除，角度估计出现抖动
- 开关频率有限时，chattering可能超出LPF截止频率以外但仍影响采样精度

- **工程折中：** 通常引入边界层（sat函数替代sgn）或自适应增益（H 随 e_i 收敛后自动减小），在保证稳定性的同时抑制 chattering。

### 第2题 [较难] - BEMF LPF折中 ★★★

**问题:** 从BEMF提取角度前需LPF滤除高频chattering，LPF截止频率 fc 在低速和高速时应如何跟随？fc = 5~10 倍的基波频率 fe 的折中依据？

**参考答案:**
- **LPF的作用：** 滤除SMO切换产生的高频chattering（频率接近PWM开关频率及其谐波），保留BEMF基波分量用于角度提取。

- **截止频率 fc 与基波频率 fe 的关系：**

- **低速时（fe 小，如10-50Hz）：** BEMF幅值小（与转速成正比），信噪比低。若 fc 过高，BEMF中的噪声（电流采样噪声、chattering残余）占比大，角度估计抖动严重。但 fc 不能太低，否则LPF相移大，角度滞后严重。取 fc = 5~10·fe 可在滤噪和控制相移之间折中。

- **高速时（fe 大，如200-500Hz）：** BEMF幅值大，信噪比高。LPF相移 φ = arctan(fe/fc)，若 fc = 5·fe，相移 ≈ 11°；若 fc = 10·fe，相移 ≈ 5.7°。高速时chattering频率远高于基波，LPF滤波效果好。但 fc 太高会引入数字延迟问题（离散LPF稳定性）。

- **折中依据（fc = 5~10·fe）：**

| fc/fe 比 | LPF相移(基波处) | chattering衰减(fc/fs=1/10时) | 角度误差 |
|-----------|-----------------|-------------------------------|----------|
| 5         | ~11°            | ~20dB                         | 中等     |
| 10        | ~5.7°           | ~26dB                         | 较小     |

- **fc < 5·fe：** 相移过大，角度滞后导致 id/iq 解耦错误，控制性能恶化，需要相移补偿（增加复杂度）
- **fc > 10·fe：** chattering衰减不够，残余高频进入PLL，角度估计抖动
- **数字实现约束：** 离散一阶LPF的时间常数 τ = 1/(2πfc)，采样频率 fs 需满足 fs > 10·fc 以避免离散化不稳定。若 fs = 10kHz，fc_max = 1kHz，对应 fe_max = 100-200Hz（fc/fe = 5-10）。

因此 fc = 5~10·fe 是兼顾相移、滤波效果和数字实现可行性的经验折中。

### 第3题 [中等] - PLL带宽 ★★

**问题:** BEMF → PLL → 角度。PLL的PI带宽通常100-300Hz。为什么不能太大（受LPF相移约束）也不能太小（受动态跟踪约束）？

**参考答案:**
- **PLL结构：** BEMF的 eα/eβ 经 arctan 或正交归一化后得到角度估计误差 ε = θ_actual - θ_est，送入PI调节器输出角速度 ωest，积分得到角度 θest。

- **带宽不能太大的原因：**
- **LPF相移约束：** BEMF信号经过LPF后产生相移 φ(f)，PLL带宽 fp 处如果LPF相移过大（>30°），PLL的相位裕度严重降低，导致角度估计振荡甚至失稳。
- **噪声放大：** PLL带宽大 → 对BEMF中的噪声（chattering残余、电流谐波）响应更快，角度估计出现高频抖动。
- **稳定性约束：** PLL的穿越频率应远低于LPF截止频率（通常 fp < fc/3），否则LPF的额外相移使PLL不稳定。

- **带宽不能太小的原因：**
- **动态跟踪约束：** 电机加减速时，实际角度快速变化。PLL带宽 fp 决定了角度跟踪能力，跟踪误差约为 Δθ ≈ dω/dt / (2πfp)。若 fp = 50Hz，dω/dt = 1000 rad/s²，则 Δθ ≈ 3.2 rad（严重失步）。若 fp = 200Hz，Δθ ≈ 0.8 rad（可接受）。
- **启动/突变响应：** 电机启动或负载突变时，角度可能跳变。PLL带宽过低导致角度收敛时间过长（几个周期），期间FOC控制错误，可能产生反向转矩或过流。

- **典型设计：** fp = 100-300Hz，PLL穿越频率处的LPF相移 < 15°，角度跟踪误差 < 5° 电角度。

### 第4题 [较难] - EEMF vs SMO ★★★

**问题:** 对比反电动势观测器(EEMF)和滑模观测器(SMO)：结构、低速性能、参数鲁棒性，各自适用工况。

**参考答案:**

| 对比项 | EEMF观测器 | SMO |
|--------|-----------|-----|
| **结构** | 基于电机数学模型构建Luenberger型观测器，估计EEMF = eα+j·eβ，由EEMF的α-β分量比计算角度。线性系统，含状态反馈增益矩阵 | 非线性切换结构，sgn(sat)函数驱动电流估计误差到滑模面，从等效控制量中提取BEMF信息。本质是继电型非线性观测器 |
| **低速性能** | 低速时EEMF幅值极小（与转速成正比），信噪比急剧恶化。通常需要注入法(HFI)辅助启动，纯EEMF观测器在 <5%额定转速时不可用 | 低速时BEMF同样极小，但SMO的切换增益H可自适应调低，配合边界层技术，低速性能略优于EEMF。但同样无法在零速附近独立工作 |
| **参数鲁棒性** | 依赖Rs和Ld准确值构建观测模型。Rs随温度变化（铜线+0.4%/°C），Ld随电流饱和变化。参数偏差导致EEMF估计有误差，角度偏移。需要在线参数辨识辅助 | 对Rs/Ld的敏感度较低（滑模到达后系统对匹配不确定性具有鲁棒性），但对切换增益H和LPF设计敏感。参数鲁棒性总体优于EEMF |
| **角度质量** | 线性观测，输出平滑，角度估计连续性好，谐波含量低 | 本质非线性切换，chattering不可避免，LPF后仍有残余抖动，角度谐波较大 |
| **计算量** | 矩阵运算较多（4阶状态方程），但全为线性运算，DSP实现高效 | 结构简单（加减+sgn），但LPF和PLL计算量与EEMF相当 |
| **适用工况** | 中高速、对角度平滑度要求高的应用（如伺服、电动汽车高速区）| 中高速、参数变化大或低成本应用（家电、风机泵类），对角度质量要求不太严格 |
| **实现复杂度** | 较高（需调观测器增益、补偿系数）| 中等（主要调H1和LPF截止频率）|

- **总结：** 现代高性能无感FOC控制器常采用混合策略——低速用HFI注入，中高速切到EEMF或SMO，切换点通常在10-15%额定转速。选择EEMF还是SMO取决于应用场景对角度质量、成本、鲁棒性的优先级。
