# 梯形与S曲线速度规划测验

### 第1题 [中等] - 梯形规划相切换问题 ★★

**问题:** 梯形速度规划在相切换点存在什么问题？为什么S曲线能解决？

**参考答案:** 梯形速度规划在加速→匀速、匀速→减速的切换点处，加速度发生突变（从+a_max跳变到0，或从0跳变到-a_max），即加加速度(jerk)在理论上为无穷大。这会导致：（1）机械冲击和振动，激发结构共振；（2）电机电流突变，产生电磁噪声和力矩波动；（3）运动不够平滑，影响加工表面质量。S曲线通过在加速度变化段引入有限的jerk约束，使加速度连续变化而非阶跃跳变，从而消除加速度突变点，使力矩（电流）平滑过渡。代价是加速时间略长，但运动品质显著提升。

### 第2题 [较难] - 七段式S曲线阶段 ★★★

**问题:** 七段式S曲线的7个阶段分别是什么？哪些阶段可能退化为零？

**参考答案:** 七段式S曲线的7个阶段为：（1）加加速段（jerk > 0，加速度从0增加到a_max）；（2）匀加速段（jerk = 0，加速度保持a_max）；（3）减加速段（jerk < 0，加速度从a_max减小到0）；（4）匀速段（加速度=0，速度保持v_max）；（5）加减速段（jerk < 0，加速度从0减小到-a_max）；（6）匀减速段（jerk = 0，加速度保持-a_max）；（7）减减速段（jerk > 0，加速度从-a_max恢复到0）。可能退化为零的阶段：（2）和（6）——当加速距离不够达到a_max时退化为零，形成三角形加速度曲线；（4）——当总行程不够达到v_max时退化为零，形成无匀速段的S曲线。极端情况下（短行程），甚至（1）（3）或（5）（7）也可能合并，退化为更简单的曲线。

### 第3题 [困难] - S曲线加速时间计算 ★★★★

**问题:** 给定jerk=1000m/s³, a_max=10m/s², v_max=1m/s，计算从静止到v_max的加速时间。

**参考答案:** 首先判断是否能达到最大加速度：达到a_max所需时间 t_j = a_max / jerk = 10 / 1000 = 0.01s。在t_j内达到的速度增量 Δv_j = ½ × a_max × t_j = ½ × 10 × 0.01 = 0.05 m/s。阶段1和阶段3各贡献0.05 m/s，共0.1 m/s。剩余速度 v_remain = v_max - 0.1 = 0.9 m/s。匀加速段时间 t_a = v_remain / a_max = 0.9 / 10 = 0.09s。总加速时间 T_accel = t_j + t_a + t_j = 0.01 + 0.09 + 0.01 = 0.11s。验证：阶段1速度增量0.05，阶段2速度增量0.9，阶段3速度增量0.05，总计1.0 m/s = v_max，计算正确。

### 第4题 [较难] - S曲线代价与梯形适用场景 ★★★

**问题:** S曲线相比梯形曲线的主要代价是什么？何时可以接受梯形曲线？

**参考答案:** S曲线的主要代价：（1）加速/减速时间更长——相同约束下S曲线需要额外的jerk过渡时间，总运动时间增加约10%~30%；（2）计算复杂度更高——七段式需要判断多种退化情况，实时计算量更大；（3）参数整定更多——需要额外确定jerk参数。可以接受梯形曲线的场景：（1）对运动平滑性要求不高的点位运动（如物料搬运，只需到达目标位置即可）；（2）负载惯量远小于电机惯量，机械冲击影响小；（3）加速度本身很小，jerk过渡段可忽略不计；（4）实时计算资源极其有限的低端控制器；（5）调试初期快速验证逻辑，后续再切换为S曲线。
