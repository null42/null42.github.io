CT-09: 系统校正设计 ​

副标题：超前/滞后/陷波——用频率整形重塑电机控制动态难度： 专家级 适用对象： 电机控制工程师、伺服驱动开发者 前置知识： Bode图与频率响应、根轨迹分析、PID控制、复变函数

1. 核心摘要 ​

一句话： 系统校正（补偿）是通过在控制回路中串联超前、滞后、陷波等校正网络，对系统频率特性进行"外科手术式"整形——在需要的频段加增益/相位，在不需要的频段减增益——从而同时满足稳定性、响应速度和抗扰能力的要求。

认知挂钩： 如果说PID是"通用扳手"，那么串联校正器就是"专用手术刀"。PID调三个参数Kp/Ki/Kd，只能调整增益和积分/微分。但当系统有特定频段的谐振峰、或者相位滞后严重时，PID的"自由度"不够——这时需要专门的校正网络。

核心流程：

text
确定性能指标（相位裕度、带宽、稳态误差）
    ↓
分析原系统Bode图，找出不足
    ↓
选择校正器类型（超前/滞后/陷波）
    ↓
按设计步骤计算校正器参数
    ↓
验证校正后的Bode图/根轨迹/时域响应

三种校正器对比：

校正器作用适用场景副作用
超前校正增加相位裕度、提高带宽相位裕度不足、响应慢放大高频噪声
滞后校正减小稳态误差、压低高频增益稳态精度不够降低相位裕度（低频段）
陷波滤波器消除特定频率谐振机械谐振、电流谐波引入额外相位滞后

2. 问题引入 ​

场景1： 你的伺服驱动器电流环调试好了，带宽也够。但接上负载后，电机在某个转速（比如1200rpm）开始剧烈抖动——转速计显示 ±50rpm 的振荡。频谱分析仪显示振荡频率约 185Hz。排查发现传动轴系存在机械谐振模态，共振频率恰好 185Hz。降低速度环增益能缓解，但响应变慢了。

问题： 能否在"不牺牲响应速度"的前提下消除这个机械谐振？

场景2： 某台大惯量电机的速度环，稳态速度误差有 3rpm（给定1000rpm），这在一些精密应用中不可接受。增大 Ki 可以消除误差，但增大到一定程度后系统开始振荡。

问题： 如何在不引起振荡的前提下消除稳态误差？

答案都是"校正网络"： 场景1用陷波滤波器，场景2用滞后校正。

3. 直观理解 ​

3.1 校正器的频域直觉 ​

把Bode图想象成一块"橡皮泥"：

  • 超前校正 = 在中频段"推高"相位曲线 → 增加相位裕度 → 系统更稳定、响应更快
  • 滞后校正 = 在低频段"抬高"增益曲线 → 增加低频增益 → 减小稳态误差；同时"压低"高频段 → 不恶化稳定性
  • 陷波滤波器 = 在特定频率"挖一个坑" → 抑制该频率分量 → 消除谐振

3.2 传递函数形态 ​

超前校正：

Gc(s)=Kc⋅s+zs+p,z<pG_c(s) = K_c \cdot \frac{s + z}{s + p}, \quad z < pGc​(s)=Kc​⋅s+ps+z​,z<p
  • 零点z在极点p的左边 → 先"超前"增加相位，后增益回落

滞后校正：

Gc(s)=Kc⋅s+zs+p,z>pG_c(s) = K_c \cdot \frac{s + z}{s + p}, \quad z > pGc​(s)=Kc​⋅s+ps+z​,z>p
  • 极点p在零点z的左边 → 先"滞后"降低相位，但增加了低频增益

陷波滤波器：

Gc(s)=s2+2ζzωns+ωn2s2+2ζpωns+ωn2,ζz<ζpG_c(s) = \frac{s^2 + 2\zeta_z \omega_n s + \omega_n^2}{s^2 + 2\zeta_p \omega_n s + \omega_n^2}, \quad \zeta_z < \zeta_pGc​(s)=s2+2ζp​ωn​s+ωn2​s2+2ζz​ωn​s+ωn2​​,ζz​<ζp​
  • 在 ω=ωn 处增益骤降

3.3 电机控制的校正直觉 ​

电机问题校正对策
电流环超调大超前校正（增大相位裕度）
速度环稳态有差滞后校正（提升低频增益）
特定转速振动陷波滤波器（抑制谐振频率）
高频噪音放大滞后校正（压低高频增益）
动态响应慢 + 稳态有差滞后-超前复合校正

4.3 滞后-超前校正器（Lag-Lead Compensator） ​

结合两者优势：低频段提供滞后校正（提升稳态精度），高频段提供超前校正（改善动态）。

Gc(s)=Kc⋅(Tlags+1)(Tleads+1)(βTlags+1)(αTleads+1)G_c(s) = K_c \cdot \frac{(T_{lag}s + 1)(T_{lead}s + 1)}{(\beta T_{lag}s + 1)(\alpha T_{lead}s + 1)}Gc​(s)=Kc​⋅(βTlag​s+1)(αTlead​s+1)(Tlag​s+1)(Tlead​s+1)​

设计方法：先设计超前部分满足动态要求，再设计滞后部分满足稳态要求。

4.5 根轨迹设计法 ​

校正器还可以在根轨迹上设计：

超前校正 = 增加一个零点 + 一个更远的极点

  • 零点吸引根轨迹向左偏转 → 改善阻尼
  • 极点防止增益无限增大

滞后校正 = 增加一个靠近原点的零极点对（偶极子）

  • 偶极子几乎不改变根轨迹形态
  • 但提高稳态增益（零极点比）

5. 交叉视角：校正器与电机控制的桥梁 ​

5.1 电流环超前校正：提升相位裕度 ​

问题： 电流环在高带宽（>2kHz）设计时，数字延迟和滤波器延迟导致相位滞后严重，PI控制器可能无法满足相位裕度要求。

方案： 在PI控制器输出串联超前校正器

Gc(s)=Tleads+1αTleads+1G_c(s) = \frac{T_{lead}s + 1}{\alpha T_{lead}s + 1}Gc​(s)=αTlead​s+1Tlead​s+1​

参数设计：

  • 测量电流环开环在期望剪切频率处的相位
  • 计算需要补偿的相位 ϕneed\phi_{need}ϕneed​
  • 设计 α\alphaα 和 TleadT_{lead}Tlead​

实际效果： 某伺服驱动器电流环，带宽从 1.5kHz 提升到 2.8kHz，相位裕度保持 >45°。

5.2 速度环滞后校正：消除稳态误差 ​

问题： 纯比例速度控制存在稳态误差 ess=ωref/(1+Kv)e_{ss} = \omega_{ref} / (1+K_v)ess​=ωref​/(1+Kv​)。增大 Ksp 受限于稳定性。

方案： 在速度环串入滞后校正器

Glag(s)=Tlags+1βTlags+1,β>1G_{lag}(s) = \frac{T_{lag}s + 1}{\beta T_{lag}s + 1}, \quad \beta > 1Glag​(s)=βTlag​s+1Tlag​s+1​,β>1

低频增益提高 β 倍 → 稳态误差降为原来的 1/β。

注意： 滞后校正引入的极点-零点对在低频段，不影响中高频稳定性。但如果 β 过大，可能放大低频扰动（如负载转矩波动）。

5.3 陷波滤波器：机械谐振抑制 ​

问题背景： 伺服系统中，电机通过联轴器、丝杠等传动机构连接负载。整个轴系在特定频率下出现扭转谐振：

fres=12πKshaftJloadf_{res} = \frac{1}{2\pi}\sqrt{\frac{K_{shaft}}{J_{load}}}fres​=2π1​Jload​Kshaft​​​

当速度环带宽接近 f_res 时，电流环的转矩输出在谐振频率处被放大 → 机械振动 → 速度反馈振荡 → 控制系统正反馈 → 加剧振荡。

陷波滤波器解决方案：

  1. 频谱分析确定谐振频率 f_res
  2. 设计陷波滤波器，ω0=2πfres\omega_0 = 2\pi f_{res}ω0​=2πfres​
  3. 将陷波滤波器串联在速度环输出（转矩/电流给定之前）
  4. 验证陷波后开环Bode图：谐振峰消失，相位裕度恢复

工程实例：

  • 谐振频率：185 Hz
  • 陷波参数：ω0=1162\omega_0 = 1162ω0​=1162 rad/s, ζz=0.05\zeta_z = 0.05ζz​=0.05, ζp=0.5\zeta_p = 0.5ζp​=0.5 → 20dB 抑制
  • 结果：速度振荡消除，速度环带宽从 20Hz 恢复到 50Hz

5.4 多陷波：多个谐振模态 ​

大型伺服系统可能有多个谐振模态（如两质量系统有低频和高频两个谐振峰）。需串联多个陷波滤波器分别抑制。

FOC代码实现： 陷波滤波器通常实现为二阶IIR数字滤波器：

c
float notch_filter(notch_t *nf, float input) {
    float output = nf->b0 * input + nf->b1 * nf->x1 + nf->b2 * nf->x2
                   - nf->a1 * nf->y1 - nf->a2 * nf->y2;
    nf->x2 = nf->x1; nf->x1 = input;
    nf->y2 = nf->y1; nf->y1 = output;
    return output;
}

系数由双线性变换从 s 域映射到 z 域得到。

案例2：陷波滤波器抑制185Hz机械谐振 ​

系统： 750W伺服电机 + 滚珠丝杠，联轴器刚度有限 现象： 电机在1200rpm附近（对应185Hz的力矩脉动频率）出现剧烈振动 诊断： 速度反馈频谱分析显示185Hz处能量急剧放大

DSP离散化实现（Tustin变换）：

采样周期 Ts = 62.5μs (16kHz)

c
typedef struct {
    float b0, b1, b2, a1, a2;
    float x1, x2, y1, y2;
} notch_filter_t;

void notch_init(notch_filter_t *nf, float w0, float zeta_z, float zeta_p, float Ts) {
    float w0Ts = w0 * Ts;
    float den = 4.0f + 4.0f * zeta_p * w0Ts + w0Ts * w0Ts;
    nf->b0 = (4.0f + 4.0f * zeta_z * w0Ts + w0Ts * w0Ts) / den;
    nf->b1 = (2.0f * w0Ts * w0Ts - 8.0f) / den;
    nf->b2 = (4.0f - 4.0f * zeta_z * w0Ts + w0Ts * w0Ts) / den;
    nf->a1 = (2.0f * w0Ts * w0Ts - 8.0f) / den;
    nf->a2 = (4.0f - 4.0f * zeta_p * w0Ts + w0Ts * w0Ts) / den;
}

效果： 185Hz分量衰减33dB，速度振荡消失，同时速度环带宽从被迫降低的15Hz恢复到50Hz。

7. 实践练习 ​

练习1：超前校正器参数计算 ​

电流环原系统在 1000Hz 处幅值 0dB，相位 -155°（相位裕度 25°）。 设计超前校正器，使相位裕度提升到 50°，剪切频率维持1000Hz。

练习2：陷波滤波器调试 ​

在你的FOC平台上，用以下方法找到机械谐振频率：

  • 注入扫频信号（chirp signal）到电流给定
  • 用FFT分析速度反馈
  • 找到谐振峰频率 设计并实现陷波滤波器，观察抑制效果

练习3：滞后-超前复合校正 ​

针对速度环（给定传递函数），设计滞后-超前校正器：

  • 稳态速度误差 < 0.1%
  • 相位裕度 > 45°
  • 带宽 > 30Hz

8. 前沿拓展 ​

8.1 自适应陷波滤波器（ANF） ​

机械谐振频率可能随负载惯量、温度、磨损而变化。固定频率的陷波滤波器可能失效。

自适应陷波方案：

  • 在线FFT分析速度/电流频谱
  • 检测谐振峰频率
  • 自动调整陷波滤波器中心频率
  • 平滑过渡陷波参数

算法可以用梯度下降法或锁相环结构实时跟踪谐振频率。

8.2 鲁棒校正设计（H∞方法） ​

传统频域校正假设模型精确。实际电机参数存在不确定性。H∞校正通过求解优化问题，设计使系统在最差工况下仍保持稳定的校正器。

对于电机控制，可以将电机参数不确定性建模为乘性摄动，设计鲁棒校正器保证所有工况下相位裕度 >30°。

8.3 基于非线性校正的摩擦力补偿 ​

伺服系统低速运行时，摩擦力（Stribeck效应）导致速度爬行。传统线性校正器难以处理这种非线性。

方案： 在速度环PI输出叠加摩擦力前馈补偿项——基于速度的摩擦力模型（静摩擦+库仑摩擦+粘滞摩擦），实质是一种"非线性校正"。

8.4 分数阶校正器 ​

传统校正器是整数阶的（s的一阶零点/极点）。分数阶校正器（如 s0.5s^{0.5}s0.5）提供更灵活的频率整形能力，在特定应用中可能以更低阶数达到相同效果。

电机应用： 分数阶PI^λD^μ控制，相比传统PID，在电流环中可以获得更好的鲁棒性。
