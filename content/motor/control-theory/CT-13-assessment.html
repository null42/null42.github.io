题目4：LQR的相位裕度保证 ​

问题： LQR理论上保证至少60°相位裕度和无穷大幅值裕度（在输入端）。

  1. 这个性质是如何推导的？（简述证明思路）
  2. 在PMSM电流环LQR中，这一保证的实际意义是什么？
  3. 当存在数字延迟（一拍延迟）时，60°相位裕度保证还成立吗？

参考答案：

  1. 证明思路（回路传函法）： 输入端的回路传函 L(s)=K(sI−A)−1BL(s)=K(sI-A)^{-1}BL(s)=K(sI−A)−1B 可以证明 1+L(jω) 的Nyquist曲线不会进入以(-1,0)为圆心、半径为1的圆内。 这意味着：增益裕度=∞（Nyquist曲线不穿越负实轴），相位裕度≥60°。 证明用到Riccati方程的性质和Return Difference不等式。

  2. 实际意义：

    • 即使电机参数有一定误差（±30%），闭环仍稳定
    • K矩阵"自带鲁棒性"，不需要额外设计鲁棒控制器
    • 这解释了为什么LQR调参比极点配置更安全——选择"差"的Q/R只会降低性能，不会引起不稳定

  3. 不成立！ 数字延迟引入了e^(-Td·s)因子，改变了回路传函的相位特性。 对于Ls+Rs的一阶对象：

    • 无延迟：LQR保证60°+相位裕度
    • Ts=62.5μs (16kHz)：延迟在ω=10000rad/s处引入-36°相位→相位裕度剩余约24°
    • Ts=125μs (8kHz)：在ω=5000rad/s处引入-36°→相位裕度约24°

    对策： 在离散域直接求解DARE（离散LQR）→离散LQR在z平面保证类似性质。

题目5：LQG的分离原理 ​

问题： LQG=LQR+Kalman。分离原理说两者可独立设计。

  1. 写出LQG的完整闭环状态方程（含观测器误差的动态）
  2. 证明：闭环极点是LQR极点（A-BK的特征值）和Kalman极点（A-LC的特征值）的并集
  3. 分离原理成立的条件是什么？在电机控制中是否满足？

参考答案：

  1. 真实系统：x˙=Ax+Bu+w\dot{x}=Ax+Bu+wx˙=Ax+Bu+w 观测器：x^˙=Ax^+Bu+L(y−Cx^)\dot{\hat{x}}=A\hat{x}+Bu+L(y-C\hat{x})x^˙=Ax^+Bu+L(y−Cx^) 控制律：u=−Kx^u=-K\hat{x}u=−Kx^

    状态估计误差：e=x−x^e=x-\hat{x}e=x−x^, e˙=(A−LC)e+w−Lv\dot{e}=(A-LC)e+w-Lve˙=(A−LC)e+w−Lv 真实状态：x˙=Ax−BKx^+w=(A−BK)x+BKe+w\dot{x}=Ax-BK\hat{x}+w = (A-BK)x+BKe+wx˙=Ax−BKx^+w=(A−BK)x+BKe+w

  2. 闭环系统：

    [x˙e˙]=[A−BKBK0A−LC][xe]+[ww−Lv]\begin{bmatrix} \dot{\mathbf{x}} \\ \dot{\mathbf{e}} \end{bmatrix} = \begin{bmatrix} \mathbf{A-BK} & \mathbf{BK} \\ \mathbf{0} & \mathbf{A-LC} \end{bmatrix} \begin{bmatrix} \mathbf{x} \\ \mathbf{e} \end{bmatrix} + \begin{bmatrix} \mathbf{w} \\ \mathbf{w-Lv} \end{bmatrix}[x˙e˙​]=[A−BK0​BKA−LC​][xe​]+[ww−Lv​]

    特征值：det(sI-(A-BK))·det(sI-(A-LC))=0 → 极点=并集。

  3. 成立条件：

    • 系统线性（PMSM是线性的吗？→在工作点线性化后近似成立）
    • 无模型不确定性（实际中电机参数随时间/温度/磁饱和变化）
    • 噪声为高斯白噪声（实际中电流采样噪声近似满足）

    在电机控制中近似满足，分离原理提供了良好的设计指导，但需注意：

    • 参数变化时LQR和Kalman性能都退化，退化可能互相耦合
    • 为保证鲁棒性，通常观测器比LQR快5倍以上

题目7：DARE的迭代求解 ​

问题： 离散ARE（DARE）没有像连续ARE那样的闭式解。在DSP上需要数值迭代求解。

  1. 写出迭代求解DARE的算法伪代码（基于Riccati差分方程迭代）
  2. 迭代初值P₀如何选择？
  3. 在16kHz控制频率下，能否每个周期重新求解DARE？（计算量分析）

参考答案：

  1. 迭代算法（Kleinman法或直接迭代）：

    text
    P = Q  // 初值
for iter = 1 to max_iter:
    P_prev = P
    K = (R + B'*P*B) \ (B'*P*A)
    P = A'*P*A - A'*P*B*K + Q
    if norm(P - P_prev) < tol:
        break
K_final = (R + B'*P*B) \ (B'*P*A)

  2. P₀的选择：

    • P₀=Q（最简单，保证收敛到稳定解）
    • P₀=I（单位阵，对等权初始猜测）
    • P₀=0（从零开始，保守但收敛）

  3. 计算量：

    • 每次迭代：矩阵乘法4×4×4 ≈ 64次浮点乘法 + 矩阵求逆（2×2）≈6次乘法
    • 通常需10~20次迭代收敛 → 约1000~2000次浮点乘法
    • Cortex-M4 @168MHz: ~6~12μs
    • 16kHz周期62.5μs → 占用率10~19%

    不建议每周期求解DARE！ 应在参数变化时求解（如每100ms），平时查表或使用固定K。

题目8：有限时域LQR用于位置伺服 ​

问题： 点对点位置伺服（如转台从0°转到90°）可以用有限时域LQR。

  1. 与无限时域LQR的区别是什么？
  2. 写出有限时域LQR的迭代Riccati差分方程
  3. 在电机位置伺服中，何时使用有限时域LQR优于无限时域？

参考答案：

  1. 区别：

    • 无限时域：K是常数，P由ARE解出，适用于调节问题（保持状态在原点附近）
    • 有限时域：K是时变的（K₀, K₁, ..., K_{N-1}），P由Riccati差分方程反向递推，适用于跟踪问题（从起点到终点有确定的时间要求）

  2. 反向递推（从N到0）： P_N = P_f（终端权重矩阵） for k = N-1, N-2, ..., 0: Kk=(R+B′Pk+1B)−1(B′Pk+1A)K_k = (R + B'P_{k+1}B)^{-1}(B'P_{k+1}A)Kk​=(R+B′Pk+1​B)−1(B′Pk+1​A)Pk=Q+A′Pk+1A−A′Pk+1B(R+B′Pk+1B)−1B′Pk+1AP_k = Q + A'P_{k+1}A - A'P_{k+1}B(R+B'P_{k+1}B)^{-1}B'P_{k+1}APk​=Q+A′Pk+1​A−A′Pk+1​B(R+B′Pk+1​B)−1B′Pk+1​A

  3. 适用场景：

    • 转台快速定位（0→90°，100ms内完成）
    • 有限时域可设计"先加速后减速"的最优轨迹
    • 终端权重P_f可惩罚终端位置误差（保证精确停在90°）

    无限时域LQR更适合：

    • 持续跟踪（如速度控制、恒速运行）
    • 调节问题（保持位置不变）

    实用方案： 在线计算有限时域LQR的时变增益序列{K₀,...,K_{N-1}}，离线存储在FLASH中，执行时按时间步查表使用。

题目9：LQR与MPC的平滑切换 ​

问题： 设计一个LQR→MPC的混合控制策略：

  1. 正常工况使用LQR（计算量小）
  2. 当状态接近约束边界时（电压/电流即将饱和），切换到MPC
  3. 写出切换条件和切换时的bumpless transfer方案

参考答案： 1-2. 混合策略架构：

text
if (|u_lqr| < 0.8*Vmax && |x| < 0.9*Imax):
    u = -K_lqr * x  // 正常工况，快速LQR
else:
    u = solve_mpc(x, constraints)  // 临近约束，带约束MPC

  1. Bumpless transfer： 从LQR切换到MPC：

    • MPC的初始解 u₀ 设为当前LQR输出 → 热启动QP求解器
    • 第一个MPC控制周期用LQR的输出作为参考轨迹

    从MPC切换回LQR：

    • 不直接切，而是线性插值过渡5个周期：
    text
    for i = 0 to 4:
    alpha = i/4.0
    u = (1-alpha)*u_mpc + alpha*u_lqr

    更精细的方案：始终运行MPC（1步预测≈LQR的退化形式），根据约束状态调整预测步长N。

    • 无约束时：N=0 → 退化为LQR
    • 约束激活时：N=3~5 → 完整MPC

题目10：Q和R的自动调参策略 ​

问题： 为LQR电流环设计基于性能指标的自动调参策略：

  1. 定义性能指标：超调量PO、调节时间ts、电压峰值Vpeak
  2. 如果PO>5%，应如何调整Q和R？
  3. 写出自动调参的迭代伪代码

参考答案：

  1. 性能采集（从阶跃响应）：

    • PO = (i_peak - i_ref)/i_ref × 100%
    • ts = 电流进入±2%稳态带的时间
    • Vpeak = max(|ud|, |uq|) in transient

  2. 调整规则：

    • PO>5%：q过大/r过小→系统过于激进→①增大r（降低控制能量）或②降低q 建议：r_new = r_old × 1.5（保守调整）
    • ts>目标值：q过小→响应太慢→增大q 建议：q_new = q_old × 2.0
    • Vpeak>0.9×Vmax：接近饱和→增大r 建议：r_new = r_old × 2.0

  3. 自动调参伪代码：

    python
    def auto_tune_lqr(A, B, Q_init, R_init, target_ts, target_PO, Vmax):
    Q, R = Q_init, R_init
    for epoch in range(10):
        K = solve_are(A, B, Q, R)
        y = run_step_response(K)  // 硬件在环测试
        PO = measure_overshoot(y)
        ts = measure_settling_time(y)
        Vpeak = measure_voltage_peak()
        
        if PO > target_PO * 1.2:
            R *= 1.5
        elif ts > target_ts * 1.2:
            Q *= 2.0  // for iq channel
        elif Vpeak > 0.9 * Vmax:
            R *= 2.0
        else:
            break  // 满足要求
    return Q, R, K

    注意： 在实际电机上自动调参需要注意安全——每次迭代前应验证K不会导致不稳定（先在小信号/低电压下测试）。
