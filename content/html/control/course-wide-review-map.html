一、知识链：21 章各自解决什么问题

信号坐标与系统语言

1–2 章：定义信号、系统、因果性、稳定性、冲激响应与卷积。核心产物是“给定输入能写出输出；给定实验能判断系统性质”。

交付检查：先说清连续/离散、时间单位、初始条件和信号支撑，再计算。

频谱与系统选择性

3–7 章：用傅里叶级数、CTFT、DTFT、时间频率特性和采样，把系统记忆变成对频率的选择。核心产物是频谱、带宽、相位、群时延和混叠预算。

交付检查：频域结论要回到变换约定、频率单位、幅值因子和边界假设。

变换域与反馈接口

8–11 章：通信链路、拉普拉斯、Z 变换和线性反馈把信号处理接到控制环路。核心产物是传递函数、ROC、差分方程、灵敏度和闭环路径。

交付检查：不能只看外部传递函数；要检查内部稳定、延迟、噪声和实现时序。

经典控制器设计

理论 1–6：从建模、PID、频率响应、Nyquist、裕度到环路整形。核心产物是“指标 → 结构 → 参数 → 裕度 → 时域验证”的闭环证据。

交付检查：控制器必须带有对象、约束、采样和验收指标。

状态空间与现代控制

理论 7–9：状态反馈、观测器和 LQR 处理内部状态、多变量耦合与代价权衡。核心产物是可控/可观性证明、闭环极点、Riccati 方程和估计误差。

交付检查：先证明资格条件，再设计；不可测、不可控、饱和和参考跟踪不能事后补救。

数字部署与验收

理论 10：采样保持、离散化、差分实现、计算延迟、量化、限幅和故障保护。核心产物是可运行代码对应的离散模型与可复现测试记录。

交付检查：连续域稳定不等于数字实现稳定；必须检查单位圆极点、延迟、峰值和异常恢复。

二、章节接口：学完一章必须留下什么

1 → 2：能否把任意输入拆成基本信号，并说明系统如何作用于每一部分？
2 → 3：能否从 h(t) 或差分方程得到系统对指数和正弦的响应？
3 → 4 → 5：能否区分周期线谱、连续频谱密度和离散时间频谱的周期性？
5 → 7：能否说明采样为何复制频谱、何时混叠，以及采样频率如何影响控制带宽？
7 → 9 → 10：能否从连续模型进入拉普拉斯域，再得到带初始条件、ROC 和延迟的 Z 域实现？
11 → 理论 1：能否写出参考、扰动、测量噪声到输出的全部反馈路径？
理论 1–6 → 7–9：频域与状态空间指标是否对同一闭环给出一致判断？
理论 7–9 → 10：设计能否在有限字长、有限采样周期和有限执行器幅值下运行？

三、从课件推导到控制器的统一工作流

  1. 定坐标：写明连续/离散、单位、采样周期、正负号、初始条件和测量位置。
  2. 建模型：从物理守恒得到微分或差分方程，再选择传递函数或状态空间，并记录忽略的动态。
  3. 识别结构：找极点、零点、延迟、共振、积分器、不可控/不可观模态和饱和位置。
  4. 选指标：分别规定稳态误差、带宽、超调、PM/GM、噪声、输入峰值和故障响应。
  5. 设计并推导：每个参数都写出它改变的对象特征，不能只给最终数值。
  6. 多域验收：极点、频率响应、时域、采样延迟、量化和饱和至少各验一次。
  7. 记录失败模式：说明指标不达标时优先改哪个结构，为什么不能直接加倍增益。
模型假设 → 数学表示 → 设计动作 → 约束检查 → 仿真/实验 → 失败诊断

四、最终能力验收

层级必须能独立完成证据
A 基础定义信号、系统、变换域、稳定性和反馈路径用自己的符号重写并检查单位
B 推导从卷积、变换、特征方程、Riccati 或差分关系推出结论写出假设、中间步骤、结论和适用范围
C 设计从性能指标选择 PID、补偿器、状态反馈、观测器或 LQR参数表、极点/裕度、时域和约束验收
D 交付把控制器落到采样、延迟、量化、限幅和故障保护离散方程、伪代码、测试向量和诊断顺序

使用方式：听课时打开伴随讲义；章节结束后打开对应复盘。若接口卡答不出，回到带该公式或结论的课件页，而不是继续向后堆章节。
