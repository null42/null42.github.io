第二章：线性时不变系统

复盘目标不是再次逐页听课，而是把“冲激分解—卷积—系统性质—方程实现—广义函数”压缩成一套能自行推导、计算、判别和实现的工作系统。

返回第二章课件伴随讲义

一、概念地图

第二章只有一条总主线：任意输入可分解为移位冲激；LTI 对每个移位冲激的响应都是移位冲激响应；线性叠加把这些响应重新组合为卷积。其余内容都从这条主线生长出来。

  1. 表示层：离散信号写成 Σx[k]δ[n−k]，连续信号写成 ∫x(τ)δ(t−τ)dτ。
  2. 系统层：单位冲激响应 h 是初始松弛 LTI 系统的完整输入输出描述。
  3. 运算层：输出是 x*h；交换、分配、结合律分别支撑换序、并联和级联。
  4. 性质层：无记忆、可逆、因果、BIBO 稳定、阶跃响应均可改写为 h 的条件。
  5. 实现层：差分/微分方程通过延迟器或积分器变成状态化框图；初始条件就是存储单元的初值。
  6. 严格化层：δ、δ′ 和重复积分属于广义函数/分配层级，必须通过积分、卷积或测试函数作用理解。

一句话总览：卷积回答“给定输入会输出什么”，冲激响应条件回答“这个系统具有什么性质”，方程框图回答“它如何运行”，广义函数回答“理想冲激与微分积分为何能合法进入这套语言”。

二、核心定义

1. LTI 与初始松弛

线性要求 T{a x₁+b x₂}=aT{x₁}+bT{x₂}；时不变要求输入移位只造成同量输出移位。对由差分/微分方程描述的动态系统，只有固定初始状态，尤其是初始松弛/零状态条件下，输入输出算子才由单一 h 完整描述。若初始状态非零，总输出还含零输入响应。

2. 单位冲激响应

离散 h[n]=T{δ[n]}，连续 h(t)=T{δ(t)}。它不是“系统对所有输入的某种例子”，而是能生成所有零状态响应的核。实验脉冲只能近似 δ，测得输出通常是有限脉冲与 h 的卷积。

3. 卷积

离散：y[n]=(x*h)[n]=Σₖ x[k]h[n−k]
连续：y(t)=(x*h)(t)=∫₋∞⁺∞x(τ)h(t−τ)dτ

卷积中的 k 或 τ 是哑变量；n 或 t 是输出观察时刻。求和/积分范围不是背出来的，而是由两个因子支集的交集确定。

4. 无记忆、因果、可逆

无记忆 ⇔ h=Kδ
因果 ⇔ h[n]=0(n<0) 或 h(t)=0(t<0)
可逆 ⇔ 存在 h_inv 使 h*h_inv=δ

数学可逆不保证逆系统因果、稳定或实时可实现。纯延迟可由时间超前形式逆转，但这种逆需要未来数据。

5. BIBO 稳定

离散 LTI 稳定 ⇔ Σₙ|h[n]|<∞
连续 LTI 稳定 ⇔ ∫|h(t)|dt<∞

BIBO 稳定约束的是绝对总权重，而不是有符号面积。∫h=0 允许正负抵消，不能推出稳定；理想微分器 h=δ′ 不是 BIBO 稳定。

6. 阶跃响应

令 s=T{u}。离散有 s[n]=Σₖ₌₋∞ⁿh[k]、h[n]=s[n]−s[n−1]；连续有 s(t)=∫₋∞ᵗh(τ)dτ、h=ds/dt，分段跳变处必须包含冲激项。

7. 递归、IIR 与状态

递归指当前输出依赖过去输出；IIR 指冲激响应无限长；状态是为预测未来必须保存的最小过去信息。三者相关但不等价：一阶稳定递归可产生无限衰减尾巴，却只需保存一个状态。

8. 广义函数

δ 由 ⟨δ,φ⟩=φ(0) 定义；δ′ 由 ⟨δ′,φ⟩=−φ′(0) 定义。它们的“图像”只是记忆辅助，合法运算必须放在分配作用、积分或卷积中。

三、重要推导

推导链 1｜离散冲激分解到卷积和

筛选性质给出 x[n]=Σₖx[k]δ[n−k]。对系统 T 作用：

T{x[n]}=T{Σₖx[k]δ[n−k]}

线性允许把加权和移到系统外：y[n]=Σₖx[k]T{δ[n−k]}；时不变把移位冲激的响应改写为移位 h：T{δ[n−k]}=h[n−k]。故 y[n]=Σₖx[k]h[n−k]。推导中每一步都有唯一来源：分解靠冲激，拆和靠线性，响应移位靠时不变。

推导链 2｜连续窄脉冲到卷积积分

把 x 划分为宽度 Δ 的小区间，以面积为 1 的窄脉冲近似：

x_Δ(t)=Σₖx(kΔ)δ_Δ(t−kΔ)Δ

Δ 因子不可丢，它把脉冲幅值变成黎曼和的面积权重。令 Δ→0 得 x(t)=∫x(τ)δ(t−τ)dτ；再重复离散推导中的线性与时不变步骤，得到连续卷积积分。

推导链 3｜图解卷积的四步法

  1. 固定其中一个信号，通常写 h(τ)。
  2. 把另一个信号反转为 x(−τ)。
  3. 移位为 x(t−τ)，t 是滑动参数。
  4. 求两个支集交集，在交集上相乘并对 τ 积分。

最常见错误不是积分本身，而是没有先解支集不等式。右边信号通常给下界，左边信号通常给上界；边界切换决定输出分段。

推导链 4｜卷积代数与系统互联

交换律来自变量代换，允许 x*h=h*x；分配律来自积分/求和线性，说明并联系统冲激响应相加；结合律说明级联系统冲激响应卷积：

并联：h_eq=h₁+h₂；级联：h_eq=h₁*h₂

结合律只改变括号，交换律才改变次序。级联换序只对满足卷积条件的零状态标量 LTI 系统成立，不能无条件推广到饱和、非零状态、时变或 MIMO 非交换结构。

推导链 5｜因果条件

若系统因果，当前输出不能依赖未来输入。离散卷积中未来输入对应 k>n，此时 h[n−k] 的自变量为负；要让所有未来样本系数都为零，必须 h[m]=0,m<0。连续情形同理。反过来，如果 h 在负时间为零，卷积自动只保留过去和当前输入，因此条件充要。

推导链 6｜BIBO 稳定充分性与必要性

若 |x|≤M，离散：

|y[n]|≤Σₖ|x[k]||h[n−k]|≤MΣₘ|h[m]|

连续同理得到 |y(t)|≤M∫|h(τ)|dτ，故绝对可和/可积是充分条件。必要性不能只说“显然”：若绝对和发散，可针对某一输出时刻选择有界输入，使输入符号/相位与 h 匹配，消除抵消，让输出等于越来越大的绝对和；因此稳定必要求绝对和有限。

推导链 7｜阶跃响应与冲激响应互换

因为 u[n]=Σₖ₌₋∞ⁿδ[k]，线性系统输出也相应累加：s[n]=Σₖ₌₋∞ⁿh[k]。对 s 作一阶差分即可恢复 h。连续中 u′=δ，由卷积微分性质得 s′=h。实验上阶跃比理想冲激更易产生，但数值微分会放大噪声，应先拟合或平滑再求导。

推导链 8｜一阶差分方程的 h、极点和状态

对 y[n]−r y[n−1]=b x[n]，初始松弛且输入 δ 时：

h[0]=b，h[1]=br，…，h[n]=brⁿu[n]

它是 IIR；稳定条件 |r|<1。定义状态 q[n]=y[n−1]，则 y[n]=r q[n]+b x[n]、q[n+1]=y[n]。单位延迟器就是状态存储，初值 q[0] 决定零输入响应。

推导链 9｜连续方程为何用积分器实现

对 ẏ+ay=bx，不应解成含理想微分器的 y 表达式，而应写成 ẏ=bx−ay，再用积分器得到 y。有限初值解为：

y(t)=e^{-a(t−t₀)}y(t₀)+b∫ₜ₀ᵗe^{-a(t−τ)}x(τ)dτ

第一项是零输入响应，第二项是零状态响应。积分器输出是状态；上电、模式切换、积分饱和都在管理该状态。

推导链 10｜冲激导数与重复积分

δ′ 通过 ⟨δ′,φ⟩=−φ′(0) 定义，并满足 x*δ′=x′。单位面积矩形的导数是两个相邻冲激之差除以 Δ，其弱极限正是 δ′。另一方向，∫δ=u、u*u=t u，一般有：

u^{*m}(t)=t^{m−1}u(t)/(m−1)!

微分阶数在级联中相加，积分次数也在级联中相加；但积分与微分的互逆必须附带边界和初始条件。

五、易错点

  • 把卷积当普通乘法：卷积包含翻转、移位和全域叠加，不能逐点相乘。
  • 求和指标与输出指标混淆：k、τ 可改名，n、t 不能被积分掉。
  • 先积分后找范围：支集交集决定分段，范围错了，后续代数再熟也无效。
  • 认为有限冲激响应就是无记忆：只有支集缩到 0 点的 Kδ 才无记忆。
  • 认为因果系统必稳定：h[n]=2ⁿu[n] 因果但不稳定；e^t u(−t) 非因果但稳定。
  • 认为可逆就可实时实现：延迟的形式逆是超前，非因果。
  • 用 ∫h 代替 ∫|h|：正负抵消会掩盖无限绝对增益；理想微分器是典型反例。
  • 把 IIR 等同于不稳定：(1/2)ⁿu[n] 无限长但绝对可和。
  • 忽略初始条件：差分/微分方程描述动态规律，初值决定具体轨迹；非零初值不能只靠 x*h 表示。
  • 框图反馈符号读反：必须先把方程整理成当前输出/最高阶导数等于其余项。
  • 软件更新状态顺序错误：先覆盖状态会把上一拍变量变成当前变量，改变系统。
  • 用理想微分器处理噪声：高频增益无界；实际 D 必须滤波和限带。
  • 把 δ(0)=∞ 当严格定义：δ 是分配，核心是筛选作用；普通点值运算没有意义。
  • 认为 δ′ 零面积所以是零：它对常数作用为零，但对斜率作用非零。
  • 认为积分与微分完全互逆：积分会引入常数/状态，边界条件不可省略。

六、综合例题

例1｜离散一阶系统的全链条分析

系统 y[n]−0.6y[n−1]=2x[n]，初始松弛。

  1. 冲激响应：h[n]=2(0.6)ⁿu[n]。
  2. 因果：h 在 n<0 为零。
  3. 稳定：绝对和 2/(1−0.6)=5。
  4. 阶跃响应：s[n]=2Σₖ₌₀ⁿ0.6ᵏ=5(1−0.6^{n+1})u[n]。
  5. 状态实现：q[n]=y[n−1]，y=0.6q+2x，q⁺=y。
  6. 非零初值：若 y[−1]=y₋₁，额外零输入响应为 0.6^{n+1}y₋₁。

这一个例子同时贯通 h、IIR、稳定、阶跃响应、状态与初始条件。

例2｜连续一阶对象与阶跃实验

ẏ+2y=3x，初始松弛。冲激响应 h=3e^{-2t}u(t)，稳定且因果；单位阶跃响应：

s(t)=∫₀ᵗ3e^{-2τ}dτ=(3/2)(1−e^{-2t})u(t)

终值 3/2 是直流增益，指数速度由极点 −2 决定。若实验只测得 s，可在平滑后求导恢复 h。积分器框图为 ẏ=3x−2y，积分器初值就是 y(0)。

例3｜稳定系统的逆为什么可能不稳定

取 FIR h[n]=δ[n]−2δ[n−1]。它绝对和为 3，因果稳定。求因果逆令 h*h_inv=δ，得到递推 h_inv[n]−2h_inv[n−1]=δ[n]，故 h_inv[n]=2ⁿu[n]，绝对和发散。原系统信息上可逆，但因果逆不稳定；这是数字控制中不能任意精确抵消非最小相位零点的时域原型。

例4｜有限脉冲辨识不是“直接测 h”

设输入矩形脉冲宽 Δ、面积 1，则幅值 1/Δ。实际输出 y=p_Δ*h。若 Δ 与对象最快时间常数相比很小，y 近似 h；若不小，y 是平滑后的 h。减小 Δ 会提高峰值并增加执行器饱和、采样不足和噪声风险，因此要在时间分辨率与可实现幅值之间折中，并记录真实输入后做模型拟合。

例5｜理想微分器的双重警告

h=δ′ 的总面积为 0，但对输入 x(t)=sin(ωt) 输出 ωcos(ωt)，增益随 ω 无界。这同时说明：有符号面积不能判稳定；δ′ 必须在广义函数意义下使用；实际微分器必须带宽限制。

七、控制连接

1. 系统辨识

冲激响应是非参数模型；阶跃响应是其累积形式。有限脉冲、PRBS、扫频等实验都在不同意义上激发系统动态。真实对象存在噪声、非线性、漂移和初始状态，必须先确认 LTI 近似有效，再谈卷积模型。

2. 数字控制器实现

离散控制律最终都要化为差分方程或状态更新。单位延迟对应寄存器；系数乘法对应乘法器；求和点对应累加器。实现时还要考虑量化、溢出、采样抖动、执行顺序和状态初始化。

3. 极点、记忆与性能

一阶 IIR 尾项 rⁿ 的衰减速度由 |r| 决定。|r| 接近 1 时记忆长、收敛慢、对偏置和量化更敏感；超过 1 时状态增长。后续 z 域会把 r 识别为极点，时域绝对可和条件转化为极点在单位圆内。

4. 积分与微分

积分器提供低频增益、消除稳态误差，但引入状态和饱和；微分器提供预测性相位，但放大高频噪声。PID 的工程本质不是三个理想算子相加，而是带状态管理、限幅、滤波与采样实现的动态系统。

5. 延迟与可逆性

计算延迟和采样保持会在冲激响应中表现为移位，在频域中表现为相位滞后。延迟的数学逆需要超前，因此不能靠因果稳定控制器完全消除。模型预测、Smith 预估和前馈补偿是在模型条件下管理延迟，而不是违反因果性。

6. 通向频域与现代控制

下一步傅里叶与拉普拉斯/z 变换会把卷积化为乘法，把 h 映射为频率响应或传递函数；状态空间则把延迟器/积分器输出组织成状态向量。系统辨识、最优控制、MPC 和数据驱动控制虽然方法不同，但都依赖本章建立的输入输出、状态、因果和稳定观念。

八、多种系统表征互换

真正掌握本章，不是只会从 x 和 h 算 y，而是能在同一系统的多种表征之间往返。每种表征突出不同问题：冲激响应适合卷积与性质判别；阶跃响应适合实验观测；差分/微分方程适合描述动态约束；框图适合检查可实现结构；状态变量适合保存记忆并处理初值。

1. h → s

离散对 h 累加，连续对 h 积分。由 s 的终值可读直流增益，由初始延迟可读纯延迟，由指数包络可估主导极点。若 h 含冲激，s 会出现跳变；若 h 含普通衰减项，s 会出现连续过渡。

2. s → h

离散一阶差分，连续求导。实际数据必须先处理偏置、漂移和噪声；“先拟合模型再解析求导”通常比直接对测量序列差分稳健。若 s 在某时刻跳变量为 A，则 h 在该时刻包含权重 A 的冲激。

3. 方程 → h

把输入设为单位冲激并施加初始松弛，逐点递推或求解微分方程。也可先求齐次模态，再由冲激时刻的跳跃/初值条件定系数。检查 h 的支集判断因果，检查绝对和/积分判断稳定。

4. 方程 → 框图

离散时先解出当前 y，所有过去样本用延迟器产生；连续时先解出最高阶导数，使用积分器链而不是理想微分器。每个延迟器或积分器输出都是候选状态。框图完成后沿信号方向重新列方程，是最可靠的符号复核。

5. 框图 → 状态更新

列出所有存储单元输出组成状态向量 q。先用当前 q 与输入计算输出和新状态，再统一写回存储单元。这个顺序直接对应数字控制器中“读取—计算—限幅—状态修正—写回”的一个采样周期。

6. 状态与初始条件

零状态卷积只覆盖输入造成的响应；非零状态必须额外传播。控制器无扰切换的核心，是让切换前后的输出一致，并反求积分器/延迟器应持有的状态。若状态初始化错误，即使方程和参数完全正确，也会出现启动冲击。

互换训练建议：任取一个一阶离散系统和一个一阶连续系统，依次写出方程、h、s、稳定性、框图、状态更新与非零初值响应。若任何一步只能靠背公式而不能从上一表征推出，就回到对应课件页重新推导。

最小完整算例

对 y[n]-0.8y[n-1]=x[n]，零状态冲激响应为 h[n]=0.8^n u[n]；极点 0.8 在单位圆内，阶跃稳态增益为 1/(1-0.8)=5。

失败诊断：有限时长实验得到的是截断且含噪的响应，不等于完整 h；若逆系统把稳定零点变成单位圆外极点，‘可逆’也不等于‘稳定可实现’。
