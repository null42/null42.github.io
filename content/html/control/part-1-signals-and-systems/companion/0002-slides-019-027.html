SLIDE 019 · 周期反例

课件第 19 页｜两段都以 2π 重复，整体为什么仍不周期？

查看本页高清预览
x(t)={ cos t，t<0；　sin t，t≥0 }

[课件]负半轴余弦和正半轴正弦各自都以 2π 重复，但页面指出原点处存在一个只出现一次的不连续点，所以整体信号不是周期信号。

读图顺序：不要先数峰间距。先把整幅函数平移候选周期，特别检查分段边界、跳变点和定义规则是否也完全重复。

用定义直接否定候选周期 2π：
  1. 页面定义在零点取右段，因此 x(0)=sin0=0；
  2. −2π<0，故 x(−2π)=cos(−2π)=1；
  3. 若 2π 是周期，应对全部 t 有 x(t)=x(t+2π)；取 t=−2π 就要求 x(−2π)=x(0)；
  4. 实际 1≠0，所以 2π 不是整个分段信号的周期。

[必要补充]更强的论证是：若存在任意正周期 T，那么原点的跳变结构必须在 ±T,±2T,... 处重复；但除原点外，两侧分别是光滑的正弦/余弦，不存在同样跳变。因此不存在任何正周期。

易错点：“每一段都是周期函数”不推出“拼起来仍周期”。周期是整个定义域上的全局平移不变性。
即时检查
  1. 只检查远离原点的两个峰，为什么可能误判？
  2. 如果把右段改成 cos t 且零点定义一致，整体会怎样？
SLIDE 020 · 连续多分量公共周期

课件第 20 页｜cos2t+sin3t 的周期不是简单相加

查看本页高清预览

[课件]页面提出例题：判断 x(t)=cos2t+sin3t 是否周期，若周期则求周期。

公共周期整数方程：
  1. cos2t 平移 T 后不变要求 2T=2πk₁，即 T=πk₁；
  2. sin3t 平移 T 后不变要求 3T=2πk₂，即 T=2πk₂/3；
  3. 同一个 T 必须同时满足，故 πk₁=2πk₂/3，化为 3k₁=2k₂；
  4. 最小正整数解为 k₁=2,k₂=3；
  5. 所以基本周期 T₀=2π。

[必要补充]单独分量的基本周期是 T₁=π、T₂=2π/3。所谓“最小公倍数”不能直接套整数算法，而应找能同时写成 k₁T₁=k₂T₂ 的最小正实数。

[控制连接]若参考信号同时含 2 rad/s 与 3 rad/s 两个分量，整体模式每 2π 秒重复。若频率比是无理数，则不会存在有限公共周期，得到准周期信号。

易错点：不能把周期相加成 π+2π/3，也不能把角频率相加后取倒数。必须让每个相位增量分别成为 2π 的整数倍。
即时检查
  1. cos2t+sin4t 的基本周期是什么？
  2. cos t+sin(√2t) 为什么没有公共周期？
SLIDE 021 · 连续周期综合例题

课件第 21 页｜常相位不改周期，脉冲列靠索引换元证明

查看本页高清预览

例 3-1：x(t)=ej(πt+1)

  1. 拆成 ejejπt，前者只是恒定复系数；
  2. 周期条件 ejπT=1；
  3. πT=2πk，所以 T=2k；
  4. 最小正值取 k=1，得到 T₀=2。

[页面演进]页面旁注强调：给周期信号做时间平移或增加常相位，不会改变其周期。真正控制周期的是随 t 累积的相位斜率。

例 3-2：x(t)=Σn∈ℤe−(t−3n)²

验证 T=3：

x(t+3)=Σ e−(t+3−3n)²=Σ e−[t−3(n−1)]²。令 m=n−1。当 n 遍历全部整数时，m 仍遍历全部整数，所以 x(t+3)=Σm∈ℤe−(t−3m)²=x(t)。

[必要补充]“改变求和范围”并不是删项，而是对无限整数索引重新命名。脉冲中心位于 ...,−6,−3,0,3,6,...，相邻间距为 3，图形直觉和代数换元相互验证基本周期 3。

易错点：证明 T=3 是周期后还要确认没有更小正周期。这里每个高斯峰的中心集合本身最小平移间距为 3，所以基本周期是 3。
即时检查
  1. ej(4t−7) 的基本周期是多少？
  2. 若脉冲中心改成 5n+1，周期与平移量分别扮演什么角色？
SLIDE 022 · 离散周期正式定义

课件第 22 页｜离散周期的核心约束：N 必须是正整数

查看本页高清预览
x[n]=x[n+mN]，n∈ℤ，m∈ℤ；等价核心 x[n]=x[n+N]

[课件]若存在正整数 N 使所有整数索引处的值在移动 N 个样本后不变，则为离散周期信号。满足条件的最小正整数称基本周期 N₀。图中三样本模式重复，故 N₀=3。

读图顺序：先选择连续的一整组样本模式，再沿索引轴移动 N，逐点比较所有幅值和次序。不要只找两个相同高度的孤立样值。

结论理由
N 必须是正整数序列只在整数索引处定义，平移后仍须落在整数网格
若 N 是周期，2N、3N…也是周期重复应用一次周期平移
基本周期是最小正整数周期排除更小整数平移

[控制连接]若采样周期是 T_s，N 个样本的周期对应物理时间 NT_s。同一个离散基本周期在不同采样率下代表不同真实时间长度。

易错点：连续信号可有 0.5 s 周期；离散序列不能有“0.5 个样本”的普通周期。分数延时属于另一类系统问题。
即时检查
  1. 若 N=6 是周期，N=3 是否一定是周期？
  2. 为什么图中基本周期是 3，而不是 6？
SLIDE 023 · 离散周期判定例题

课件第 23 页｜不是看 ω₀ 是否有理，而是看 ω₀/(2π)

查看本页高清预览

例 1：x[n]=cos(8πn/7+2)

  1. 平移 N 后相位增加 8πN/7；
  2. 余弦完全重合要求 8πN/7=2πm；
  3. 化简为 4N/7=m，即 N=7m/4；
  4. N 必须是正整数，最小可取 m=4，得到 N₀=7。

例 2：x[n]=ej(n/8+π)

  1. x[n+N]/x[n]=ejN/8；常相位 π 抵消；
  2. 周期要求 ejN/8=1，即 N/8=2πm；
  3. 所以 N=16πm；
  4. m=0 只给 N=0，不是正周期；任意非零整数 m 使 N 含无理数 π，不可能是整数；
  5. 所以该序列非周期。

[必要补充]一般地，ejω₀n 周期当且仅当 ω₀/(2π)∈ℚ。若化成最简分数 p/q，基本周期为 q。余弦可能因对称性出现等价相位，但本页例题按完整相位增量即可得到最小周期。

[控制连接]连续 60 Hz 信号以 1000 Hz 采样后，归一化频率为 60/1000=3/50，序列要经过 50 个样本才完全重复。这比“每周期约 16.67 个样本”更严格。

易错点：ω₀=1/8 是有理数，但 ω₀/(2π)=1/(16π) 不是有理数，所以序列非周期。
即时检查
  1. ejπn/3 的基本周期是多少？
  2. cos(3πn/4) 为什么基本周期是 8？
SLIDE 024 · 1.2.3 偶信号与奇信号

课件第 24 页｜把第 6 页的分类速览升级为正式定义

查看本页高清预览

偶信号

x(−t)=x(t)
x[−n]=x[n]

时间反转后不变，几何上关于纵轴对称。

奇信号

x(−t)=−x(t)
x[−n]=−x[n]

时间反转后幅值相反，几何上关于原点对称。

[课件]页面给出连续和离散形式，并指出奇信号在 t=0 或 n=0 时取值必须为 0。

零点条件：

对奇信号代入零点：x(0)=−x(−0)=−x(0)，所以 2x(0)=0，即 x(0)=0。离散序列同理。

[必要补充]判断奇偶前应检查定义域是否关于零对称。零信号同时满足奇、偶两个定义；除零信号外，一个信号不可能同时既奇又偶。

易错点：“左右形状相似”不够。偶信号左右同号，奇信号左右反号；横坐标反转和幅值取负要分别检查。
即时检查
  1. t²+t⁴ 是什么奇偶性？
  2. t+t² 为什么既非奇也非偶？
SLIDE 025 · 任意信号的奇偶分解

课件第 25 页｜不是“有些信号能分”，而是任意信号都能唯一分

查看本页高清预览
xₒ(t)=½[x(t)−x(−t)]　　xₑ(t)=½[x(t)+x(−t)]

[课件]页面给出奇部、偶部公式，并通过相加展开证明 x(t)=xₒ(t)+xₑ(t)。例 1 要求先画 x(−t)，再逐点做和与差。

三步完整证明：
  1. 验证奇部：xₒ(−t)=½[x(−t)−x(t)]=−xₒ(t)；
  2. 验证偶部：xₑ(−t)=½[x(−t)+x(t)]=xₑ(t)；
  3. 验证重构：xₒ+xₑ=½[x−x_r]+½[x+x_r]=x，其中 x_r=x(−t)。

[必要补充]分解是唯一的。若 x=e₁+o₁=e₂+o₂，则 e₁−e₂=−(o₁−o₂)。左边是偶信号，右边是奇信号；一个信号若同时奇偶，只能为零，因此 e₁=e₂、o₁=o₂。

[拔高]算子 Pₑx=[x(t)+x(−t)]/2 与 Pₒx=[x(t)−x(−t)]/2 可看作投影：重复投影不会再改变结果，并且 Pₑ+Pₒ=I。

易错点：两个公式都必须除以 2。若不除以 2，相加会得到 2x(t)。
即时检查
  1. 若 x 本来就是偶信号，公式给出的奇部是什么？
  2. 为什么唯一性证明依赖“同时奇偶只能为零”？
SLIDE 026 · 四幅图的页面演进

课件第 26 页｜从单侧波形看到奇部和偶部如何共同重构

查看本页高清预览

读图顺序：(a) 原信号只在正半轴；(b) 时间反转只在负半轴；(c) 做差后负半轴取负、正半轴取正；(d) 做和后左右同号。每一步幅值都要乘 1/2。

[页面演进]第 25 页给代数公式，本页用四幅波形显示公式如何逐点工作。原信号在正半轴出现时，奇部与偶部在正半轴各贡献一半；在负半轴，它们大小相同、符号相反，重构时刚好相消为零。

逐点重构检查：
  • 正半轴：x(−t)=0，所以 xₑ=x/2、xₒ=x/2，相加为 x；
  • 负半轴：x(t)=0，所以 xₑ=x(−t)/2、xₒ=−x(−t)/2，相加为 0；
  • 零点：奇部必为 0，偶部保留原零点值。

[控制连接]对一组围绕某基准时刻对称采集的数据，偶部保留镜像相同成分，奇部保留镜像反号成分。它可用于分离偏置、对称响应与方向相关响应，但实际应用前必须明确对称中心。

易错点：奇部图在负半轴不是简单复制，而是反号复制；偶部图才是同号镜像。
即时检查
  1. 只在负半轴有信号时，奇偶分解会怎样？
  2. 若对称中心不是 t=0，应先做什么变换？
SLIDE 027 · 奇偶性质

课件第 27 页｜双边和抵消与能量正交

查看本页高清预览

性质 1：奇序列的双边和为零

若 x[−n]=−x[n]，且双边和存在，则

Σn=−∞∞x[n]=x[0]+Σn=1∞{x[n]+x[−n]}=0+Σ0=0

零点为 0，正负索引成对抵消。

[必要补充]“双边和存在”不能省略。若级数不绝对收敛，任意重排可能改变结果；至少应使用课件展示的对称求和方式。

性质 2：实信号的奇偶分量能量相加

令 x=xₑ+xₒ，则

Σx²=Σxₑ²+Σxₒ²+2Σxₑxₒ

xₑ[n]xₒ[n] 是奇序列，因为偶×奇=奇；在对称求和且收敛条件下，其双边和为 0。因此

Σx²=Σxₑ²+Σxₒ²

[课件]页面特别圈出“这项为奇函数所以等于 0”。正确理解是交叉项的总和为零，不是每个 n 上的乘积都为零。

[拔高]用内积写为 ⟨xₑ,xₒ⟩=0，说明偶子空间与奇子空间正交。复信号的能量应使用共轭内积 Σxₑ[n]xₒ*[n]。

易错点：例如 xₑ[n]=1、xₒ[n]=n 时，乘积 n 在多数点不为零；但正负 n 的对称和抵消。
即时检查
  1. 偶序列与奇序列的乘积是什么奇偶性？
  2. “交叉项求和为零”和“交叉项逐点为零”有什么区别？
页段深化 · 两种整数结构与一个正交分解

一、把第 19–27 页连成三条可复用方法

1. 连续多频率周期：求公共时间 T

对 x(t)=Σ A_k cos(ω_kt+φ_k)，整体周期 T 必须使每个非零分量都完成整数圈：

ω_kT=2πm_k，m_k∈ℤ

两个非零频率存在公共周期的必要条件是 ω₁/ω₂=m₁/m₂∈ℚ。若频率比无理，两个相位不会在有限时间同时复位。

2. 离散复指数周期：求整数步数 N

e^{jω₀(n+N)}=e^{jω₀n} ⇔ ω₀N=2πm

这里未知量 N 本身必须是正整数。因此判据成为 ω₀/(2π)∈ℚ。若最简分数为 p/q，则最小 N 通常是 q。连续情形求“多久以后相位转整圈”，离散情形还要求这个时间恰好对应整数个索引步。

对象周期变量存在条件
e^{jω₀t}正实数 T任意 ω₀≠0，T₀=2π/|ω₀|
e^{jω₀n}正整数 Nω₀/(2π) 为有理数

3. 奇偶分解是唯一投影，能量按正交方向相加

投影：

Pₑx=(x+Rx)/2

Pₒx=(x−Rx)/2

其中 R 是时间反转算子。可验证 Pₑ²=Pₑ、Pₒ²=Pₒ、PₑPₒ=0。

能量：

||x||²=||xₑ+xₒ||²

=||xₑ||²+||xₒ||²+2⟨xₑ,xₒ⟩

奇偶正交使最后一项为 0。

[控制连接]如果采样数据围绕事件中心同时含有对称响应和方向相关响应，可用奇偶分解分离。若中心选错，原本的偶成分会泄漏到奇部，因此“对称中心”本身也是建模参数。
