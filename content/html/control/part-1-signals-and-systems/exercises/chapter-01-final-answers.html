  2. 频率比5/14，周期14。
  3. delta(4t+8)=delta(t+2)/4。
  4. x_e=(x+x反转)/2，x_o=(x-x反转)/2。

  2. delta(2t-4)=delta(t-2)/2，结果3/2。
  3. delta(t)-delta(t-3)。
  4. 有记忆、不可逆（一般无法唯一恢复首值）、因果、稳定、时不变、线性。

  3. y(t)=t x(t)。
  4. 累加器 y[n]=Σ_{k=-∞}^{n}x[k]。

  2. 微分增益随频率上升，放大高频噪声。

  4. 阶跃检验突变跟踪与稳态误差；斜坡检验持续变化参考的跟踪能力和系统型别。

第一章逐题完整推导

A 级｜定义与直接计算

  1. 连续复指数周期。令 e^{j3(t+T)}=e^{j3t}，得到 3T=2πk。最小正整数取 k=1，故 T₀=2π/3 s。代回可见指数因子增加 e^{j2π}=1。
  2. 离散余弦周期。要求 (5π/7)N=2πm，即 5N=14m。由于 5 与 14 互素，最小正整数为 N₀=14。离散周期必须是整数，不能写成 14/5。
  3. 冲激尺度。δ(4t+8)=δ[4(t+2)]=δ(t+2)/|4|。绝对值来自变量替换的雅可比；若系数为负，尺度仍取正。
  4. 奇偶分解。x_e(t)=[x(t)+x(-t)]/2，x_o(t)=[x(t)-x(-t)]/2。相加恢复 x，分别代入 -t 可验证偶、奇性质。

B 级｜组合计算与系统性质

  1. 公共周期。12=2²·3，18=2·3²，最小公倍数为 36。36 是公共周期；和信号的基本周期仍需代回检查，可能是 36 的因子。
  2. 冲激积分。δ(2t-4)=δ(t-2)/2，所以 ∫(t+1)δ(2t-4)dt=(2+1)/2=3/2。先缩放再筛选可避免遗漏二分之一。
  3. 矩形窗导数。d[u(t)-u(t-3)]/dt=δ(t)-δ(t-3)。上升沿产生正冲激，下降沿产生负冲激；冲激面积等于跃变量。
  4. y[n]=x[n]+x[n-1]。它线性、时不变、因果且 BIBO 稳定；依赖过去样本所以有记忆。有限记录一般无法唯一恢复边界前的输入，因此不能直接宣称稳定可逆。

C 级｜证明与反例

  1. 周期条件。e^{jω₀(n+N)}=e^{jω₀n} 当且仅当 ω₀N=2πm，即 ω₀/(2π)=m/N∈Q。反之若该比值为 p/q，取 N=q 即得周期。
  2. 单位模但非周期。x[n]=e^{jn} 的模恒为 1，但 1/(2π) 不是有理数，因此不存在整数周期。
  3. 线性但时变。y(t)=t x(t) 满足叠加性；对移位输入输出为 t x(t-t₀)，原输出移位为 (t-t₀)x(t-t₀)，两者不同。
  4. 因果但不稳定。累加器 y[n]=Σ_{k=-∞}^{n}x[k] 只使用现在和过去输入；对有界输入 u[n]，输出随 n 增长，故不满足 BIBO 稳定。

D 级｜向控制系统迁移

  1. 混叠。450 Hz 以 600 Hz 采样得到离散频率 1.5π，减去 2π 得 -0.5π，实余弦表现为 150 Hz。抗混叠必须在采样前完成。
  2. 微分器噪声。H(jω)=jω，高频增益无限增长；实际 D 控制必须加入低通滚降并考虑量化差分。
  3. 单位样本响应。x[n]=Σ_kx[k]δ[n-k]，由线性与时不变性得到 y[n]=Σ_kx[k]h[n-k]，即卷积和。
  4. 阶跃与斜坡。阶跃暴露上升时间、超调、稳态误差和饱和；斜坡进一步暴露系统型别、速度误差、速率限制和持续跟踪能力。两者都要记录控制输入。

整章诊断：依次检查连续/离散坐标、频率单位、时间变换方向、冲激尺度、初始条件和反例是否真正满足题设。

第一章接口与诊断｜答案验收层

本章复核样例：对 x(t)=cos(4t)+sin(6t) 先求分量周期 π/2、π/3，再取最小公共周期 T=π；若改成 cos(πn/3)，必须改用整数样本周期 N=6。

常见错误为什么错：把采样序列当成连续信号、允许离散周期为非整数、忽略冲激的单位和尺度，会让后续采样与数字控制从定义处开始出错。
