拉普拉斯、传递函数与框图代数

A 级答案

  1. F(s)=integral_0^infinity e^{-st}f(t)dt。指定零状态输入输出通道的传递函数为冲激响应的拉普拉斯变换 G(s)=L{g(t)}=Y/U。
  2. 真分式：分母阶数不低于分子；严格真：分母阶数更高；非真：分子阶数更高，通常意味着理想微分等不可直接实现的高频行为。
  3. 单边变换导数含初值，例如 L{x_dot}=sX-x(0^-)。传递函数定义只保留输入引起的零状态响应，故推导 Y/U 时必须令初值为零。
  4. 先求输入变换 U，再按指定通道求 Y=GU，最后做反拉普拉斯得到 y(t)，同时检查初值、因果性和收敛。

B 级答案

  1. 区域 0≤tau≤t<infinity 交换为 0≤tau<infinity,t≥tau；令 z=t-tau，内层产生 e^{-tau s}F_2(s)，外层剩 F_1(s)，故结果为乘积。
  2. 由课件方程得 U/R=(s+4)/(s^2+3)、Y/U=(1+2s)/(s^2+s)，相乘即 Y/R=(1+2s)(s+4)/[(s^2+s)(s^2+3)]。
  3. Js^2Gamma=W-(K+sD)Gamma，故 Gamma/W=1/(Js^2+Ds+K)。归一化后 omega_n=sqrt(K/J)、zeta=D/(2sqrt(JK))。
  4. x=G_4(G_2z-H_2x)+G_5(G_3z-H_2x)，所以 x/z=(G_4G_2+G_5G_3)/(1+G_4H_2+G_5H_2)。令 Q=G_6x/z，再由 z=G_1[R-(H_3+H_4)Y] 得 Y/R=QG_1/[1+Q(H_3+H_4)]。

C 级答案

  1. 非零初值会在变换后产生额外项，例如二阶方程含 sx(0)+x_dot(0)；输出等于零状态受迫响应加零输入自然响应，不能只用 GU。
  2. 若不稳定极点在外部通道中与零点精确消去，Y/R 可能看似稳定，但内部状态仍按不稳定模态增长；模型误差还会破坏精确消去。
  3. 自检包括：每条线命名；未标求和符号按课件约定；令反馈块为零检查并联前向；令某支路为零检查退化；核对单位；随机赋数值后用线性方程组与公式比较。
  4. Q 形式保留内部回路来源，适合设计、解释和局部验证；完全展开便于统一求根和数值代入，但长式容易掩盖结构。两者应并存。

D 级答案

  1. 先从电气和机械能量平衡写微分方程，明确电压、负载转矩等输入与电流、速度等输出；逐方程零初值变换，建立每个节点通道，再按真实传感与控制连接画框图。
  2. 给所有内部信号组成向量 x，写 x=A(s)x+B(s)r，解 x=[I-A(s)]^{-1}B(s)r；选择输出矩阵即可一次得到所有外部到内部/输出的传递通道。
  3. 用 K_d s/(1+s/omega_f) 替代理想 K_d s。低于 omega_f 近似微分，高频增益限制为 K_d omega_f，但会加入极点与相位变化，需重新检查裕度。
  4. 同一输入下：解析分式检查极点模态与稳态；状态空间数值仿真加入非零初值和执行器；实验检查未建模动态。比较时统一单位、采样、初值、输入与传感滤波，并用残差定位差异来源。
