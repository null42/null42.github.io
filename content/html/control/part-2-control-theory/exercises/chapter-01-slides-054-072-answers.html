拉普拉斯与框图综合习题

A 级答案

  1. 核心模式：时间延迟对应 e^{-sT}；乘 e^{at} 对应 F(s-a)；时间微分对应 s 乘法并附初值；时间积分对应除 s；多项式 t^n↔n!/s^{n+1}；共轭复极点对应指数包络三角函数。
  2. f(t-T)u(t-T)↔e^{-sT}F(s) 是事件晚发生；e^{at}f(t)↔F(s-a) 是幅值随时间指数加权。前者在 s 域乘指数，后者移动极点。
  3. 简单极点用 A/(s-p)；不可约二阶用 (As+B)/(s^2+as+b)；n 重极点必须含 A_1/(s-p)+...+A_n/(s-p)^n。
  4. 变量放在分支点、内环接口和输出前，使每条方程短且一条线只有一个名称；优先先闭合局部内环，再处理外环。

B 级答案

  1. 问题1：U=[1-e^-2s-e^-4s+e^-6s]/s^2，Y=GU。问题2各结果为 1/s+5/s^2、2/s^3+2/s^2+1/s、4s/(s^2+36)、2/s^3+3/[(s+2)^2+9]。问题3按正文各页部分分式。问题4与5结果见下两项。
  2. 第68页：H=2/(s+3)+(-2s-10)/(s^2+8s+25)，故 h=2e^-3t-2e^-4t cos3t-(2/3)e^-4t sin3t。
  3. 第69页 (s+3)/[(s+1)(s+2)^2]=2/(s+1)-2/(s+2)-1/(s+2)^2，故 f=2e^-t-2e^-2t-t e^-2t。
  4. 问题4：Y/R=G1G2(1+K1)/(1+G2K1)，令 K1=0 得 G1G2。问题5令 H2=H3=0 后，课件长式应退化为由 G1、G2、G3 构成的无内反馈网络，且所有内部变量方程保持一致。

C 级答案

  1. 先由执行器速度/加速度约束确定梯形上升、平台和下降时间，再选择二阶带宽不显著快于命令拐角频率，并仿真峰值输出与控制量；必要时把斜率突变进一步圆滑。
  2. 主导性取决于 |c_i e^{p_i t}|，所以极点靠近虚轴但残值很小的模态未必主导目标输出；不同输入输出通道残值也不同。
  3. 重复极点产生 t^{k}e^{pt}，对参数微小变化会分裂为邻近极点，残值可能很大，数值和模型误差敏感性通常高于良好分离的简单极点。
  4. 先手工设正确模板和假设，再用 CAS 做 apart、inverse Laplace 和随机数值代入；最后用初终值、重新拉普拉斯和时域仿真验证，不能把软件输出当作模型定义。

D 级答案

  1. 把期望轨迹参数化为分段恒加速度或 S 曲线，约束 |r_dot|≤v_max、|r_ddot|≤a_max，必要时再限 jerk；输出不仅要连续，还应使控制器所需阶次导数有限。
  2. 自动流程：多项式长除→分母因式/实二阶分组→按重数生成模板→解线性系数→反变换→正变换回代→随机 s 点残差→初终值检查。
  3. 问题5写 x3=G3(Y+H3x3)、x1=G1(R-x3)、x2=G2(x1+H2x2)、Y=x1+x2，组成四元线性方程。矩阵求逆不仅给 Y/R，也给 x1/R、x2/R、x3/R。
  4. 取对象含不稳定模态 1/(s-1)，外部传递中用零点 s-1 精确消去，可得到看似稳定常数通道；但内部状态仍按 e^t 增长。任何微小失配都会重新暴露不稳定极点。
