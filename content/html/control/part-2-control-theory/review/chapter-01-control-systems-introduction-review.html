理论一：从物理对象到闭环极点

本复盘不按页码重讲，而把课件中的四旋翼、框图、LTI、卷积、拉普拉斯、传递函数、极点模态和变换习题重构成一条控制设计主线：先明确想改变什么，再写出对象和信号关系，随后建立可运算模型，最后把性能要求翻译成闭环动力学。

一、概念地图：控制设计是一条闭合推理链

1. 任务层
参考、扰动、输出、约束、性能指标
2. 物理层
力/力矩、惯量、阻尼、执行器与传感器
3. 结构层
前馈、反馈、求和点、分支点、内部回路
4. 表示层
微分方程、冲激响应、传递函数、极点与模态
5. 设计层
改变特征方程，分配速度、阻尼和稳态能力
6. 实现层
采样、延迟、饱和、噪声、验证与故障模式

初学者最容易把第 4 层误当成控制理论全部：会算拉普拉斯、会化框图，却不知道为什么这样建模。真正的闭环能力是：任何一个公式都能回答“哪个物理量进入了哪里、改变哪个极点、代价是什么、实现时会怎样失真”。

二、一页总纲：本章必须贯通的七个问题

1. 控制器究竟在做什么？ 它依据可获得的信息决定执行器输入，使整个闭环在参考、扰动和约束下满足目标。控制器不是孤立模块，评价对象永远是闭环。

2. 为什么先讲四旋翼？ 因为它把“物理自由度—执行器—控制分配—多个反馈环”集中在同一对象中。四个旋翼转速平方经过分配矩阵形成总推力与滚转、俯仰、偏航力矩。

3. 框图怎样避免靠口诀化简？ 给每个节点命名，按箭头写代数或算子方程，再逐步消元。标准负反馈中 L=KG，S=1/(1+L)，T=L/(1+L)，并有 S+T=1。

4. LTI 为什么重要？ 线性允许缩放与叠加，时不变允许把一次冲激响应平移到任意时刻。于是任意输入可分解为移位冲激，输出必为 y=x*h。

5. 传递函数从哪里来？ 在零初始条件下，卷积经拉普拉斯变换成为乘法，H(s)=Y(s)/X(s)=L{h(t)}。它描述输入输出通道，不等于系统全部内部状态。

6. 极点为什么支配响应？ 部分分式把有理函数拆成若干模态。极点 p_i 对应 e^{p_i t}；实部决定衰减/增长，虚部决定振荡，重复极点引入 t^k e^{pt}。

7. 怎样从分析走向设计？ 先把指标翻译为目标闭环极点或特征多项式，再求控制参数；随后检查控制量、扰动通道、内部稳定、模型误差，最终才进入采样和数字部署。

三、控制目标与物理角色：先定义问题，再写控制器

一个可设计的控制问题至少包含六项：参考 r、被控输出 y、可操纵输入 u、可测信号 y_m、扰动 d、约束集合。若只说“让系统稳定”，仍需追问稳定哪个平衡点、允许多大控制输入、是否要跟踪、是否有噪声和延迟。

角色问题常见错误
Plant 对象 G输入怎样通过物理定律产生输出？把执行器、传感器或保持器漏在对象之外
Controller 控制器 K根据误差/状态怎样生成命令？只看 K 的公式，不看闭环效果
Reference 参考 r希望系统达到什么轨迹？用不可实现的跳变命令激发饱和
Measurement 测量真实可得到什么信息？默认所有状态无噪声、无延迟可测
Disturbance 扰动 d从对象输入端还是输出端进入？混淆扰动注入点，得到错误抑制通道
Constraint 约束输入、速度、加速度、状态边界是什么？线性设计有效但实际执行器长期饱和

反馈的本质不是“发现误差就乘一个增益”，而是用误差信息持续重塑对象的动力学。前馈根据已知模型提前抵消确定项，例如悬停重力；反馈处理未知初值、参数偏差和扰动。二者职责不同，应组合而非互相替代。

四、四旋翼：从旋翼作用到虚拟控制通道

旋翼 i 的推力和反扭矩通常在工作区近似为 f_i=k_f omega_i²、tau_i=k_m sigma_i omega_i²，其中 sigma_i=±1 表示旋向。把 q=[omega_1²,omega_2²,omega_3²,omega_4²]^T 作为执行器变量，可写成

v = [F_z, tau_phi, tau_theta, tau_psi]^T = B q

B 是控制分配矩阵：第一行把四个推力相加，滚转和俯仰行按旋翼相对质心的力臂给出正负号，偏航行按旋向给出反扭矩符号。上层姿态/高度控制器并不直接“控制四个电机”，而是先产生四个虚拟通道 v，再解 q=B^{-1}v 或受约束分配问题。

控制分配不是纯代数。 若求得某个 q_i<0，或 omega_i 超过上限，说明理想虚拟力矩不可实现。此时直接截断电机命令会改变各通道耦合，应使用带上下界、优先级和失效约束的分配器，并把饱和信息反馈给上层防积分饱和逻辑。

从偏航物理方程看到 PD 的来源

忽略耦合并在悬停附近线性化，偏航角 gamma 可近似满足

J gamma¨ + D gamma˙ = tau_c + tau_d

若控制律 tau_c=K_p(r-gamma)-K_d gamma˙，则

J gamma¨ + (D+K_d) gamma˙ + K_p gamma = K_p r + tau_d

比例项等效为“恢复弹簧”，把偏离参考的角度拉回；微分项等效为“附加阻尼”，耗散运动趋势。闭环特征多项式 Js²+(D+K_d)s+K_p 直接告诉我们：K_p 主要设定固有频率，K_d 主要设定阻尼，但二者又通过归一化参数共同决定实际极点。

五、框图、节点方程与四个基本闭环函数

框图是信号方程图，不是元件连接图。求和点定义代数关系，分支点复制同一信号，方块定义算子关系。可靠方法永远是：给关键节点命名，沿箭头写方程，最后消元；不要在复杂图上凭视觉套“串联、并联、反馈”口诀。

标准负反馈 e=r-y_m，u=Ke，y=Gu+d_o，y_m=y+n。令环路增益 L=KG，可得：

S=1/(1+L),   T=L/(1+L),   KS=K/(1+L),   GS=G/(1+L)
通道闭环关系解释
r → yT互补灵敏度，决定跟踪和高频噪声传递
d_o → yS输出扰动抑制
n → y−T测量噪声经反馈进入输出
r → uKS参考引起的控制努力
输入扰动 d_i → yGS对象输入端扰动通道

S+T=1 是结构恒等式，不是设计偏好。某一频率让 |S| 很小，通常意味着 |T| 接近 1；不能在所有频率同时让跟踪、抑扰、噪声隔离和鲁棒性都无限好。后续环路整形就是在频率轴上安排这种不可避免的折中。

符号检查： 若负反馈推导得到 1−KG，应立即回到求和点；但正反馈局部环确实可能产生 1−GH。分母符号必须由节点方程决定，不能由记忆决定。

六、LTI 假设：为什么能把复杂响应分而治之

线性包含齐次性和可加性：T{a x_1+b x_2}=aT{x_1}+bT{x_2}。时不变性要求若 y(t)=T{x(t)}，则 T{x(t-tau)}=y(t-tau)。因果性则要求时刻 t 的输出不依赖未来输入。三者是不同性质，不能互相推出。

真实控制对象常只在某个平衡点附近近似 LTI。线性化的逻辑是对非线性状态方程 xdot=f(x,u) 在 (x_0,u_0) 处作一阶展开：

delta xdot = A delta x + B delta u,   delta y = C delta x + D delta u

因此“LTI 模型有效”隐含三个条件：工作点明确、偏差足够小、参数在考察时段内近似不变。四旋翼大角度机动、电机饱和、气动系数变化都会破坏这些条件。线性理论不是错误，而是必须连同适用域一起使用。

判断系统是否时不变时，要对系统算子整体做延迟测试。例如 y(t)=x(2t) 是线性但时变；y(t)=x(t)² 是时不变但非线性；y(t)=x(t-1) 是线性、时不变且因果。

七、冲激响应与卷积：从基函数响应重建任意输出

连续信号可用冲激筛选性质写成 x(t)=∫x(tau)delta(t-tau)dtau。对 LTI 系统，单位冲激 delta(t) 的响应定义为 h(t)。时不变性给出 delta(t-tau) 的响应 h(t-tau)，线性再允许按 x(tau) 缩放并叠加：

y(t)=∫ x(tau) h(t-tau) dtau = (x*h)(t)

这条证明中每一步都有责任：冲激展开来自信号表示；移位响应来自时不变；缩放与积分叠加来自线性。少一个条件，卷积结论就不成立。因果 LTI 系统有 h(t)=0（t<0）；BIBO 稳定要求 ∫|h(t)|dt<∞。

卷积同时提供两种观察角度：固定 t 时翻转平移 h(t-tau) 与 x(tau) 求重叠面积；或把每个时刻的输入看作激发一个缩放、延迟的冲激响应。前者便于计算，后者更接近物理因果解释。

控制连接： h(t) 描述某个输入输出通道的全部零状态动态，但不能自动暴露内部不可控/不可观模态。仅凭外部冲激响应判断“系统内部一定稳定”可能被极零抵消欺骗。

八、拉普拉斯与传递函数：把卷积变成代数

对因果信号，单边拉普拉斯 X(s)=∫_0^-^∞x(t)e^{-st}dt。卷积定理给出 L{x*h}=X(s)H(s)，于是零初始条件下

H(s)=Y(s)/X(s)=L{h(t)}

“零初始条件”不能省略。以一阶系统 ydot+a y=b u 为例，单边变换得到 sY-y(0^-)+aY=bU；只有 y(0^-)=0 时才有 Y/U=b/(s+a)。非零初值形成独立的自然响应，不应被误塞进传递函数。

有限维常系数微分方程通常给出有理传递函数 H(s)=N(s)/D(s)。严格真有理表示输出不直接依赖输入的高阶导数；分子次数等于分母次数可能存在直接通道；分子高于分母通常意味着理想微分等非严格真有理行为，实现时需额外滚降。

三种模型必须能往返

表示最擅长回答局限
微分方程物理参数、初始条件、能量关系复杂互联时计算繁琐
冲激响应/卷积任意输入的零状态响应常为无限长函数，不够紧凑
传递函数串并联、反馈、极点零点、频域分析只描述指定输入输出通道，隐藏内部实现

正确学习顺序不是把传递函数当作起点，而是从物理方程确认通道，再在零初值下变换，最后用极限、单位和时域行为反向检查。

九、极点、模态与稳定性：从分母读出时间尺度

若 Y(s) 是有理函数，部分分式可写成 Σ_i Σ_k c_ik/(s-p_i)^k。逆变换后得到 c_ik t^{k-1}e^{p_i t}/(k-1)!。因此：

  • Re(p)<0：模态指数衰减；越靠左通常越快。
  • Re(p)=0：简单虚轴极点产生持续振荡或常值；重复虚轴极点会增长。
  • Re(p)>0：模态指数增长，不稳定。
  • Im(p)≠0：产生振荡，频率由虚部决定。
  • 重复极点：多出时间多项式因子，瞬态可能显著放大。

“主导极点”不能只看谁最靠近虚轴，还要看该通道的残值。极点很慢但残值近零时，输出中未必明显；精确极零抵消虽能使外部通道看不到某模态，却对参数误差极敏感，也可能隐藏内部不稳定。

标准二阶分母 s²+2 zeta omega_n s+omega_n² 的极点为 −zeta omega_n ± j omega_n sqrt(1−zeta²)。omega_n 决定总体时间尺度，zeta 决定振荡与超调趋势。对 Js²+(D+K_d)s+K_p，匹配系数得到

K_p=J omega_n²,   K_d=2 zeta omega_n J-D

这就是从“希望多快、多振荡”到控制器参数的第一条完整设计公式。若算出 K_d<0，说明对象本身阻尼已高于目标，或目标参数选择与控制结构不匹配，不能机械接受结果。

十、正逆变换与复杂框图：计算必须服务于结构理解

1. 正变换：先把信号写成标准构件

多项式直接展开，三角乘指数使用 s→s−a 的指数移位，分段信号用移位阶跃或斜坡。梯形参考可由四个移位斜坡叠加构造；这种表达不仅便于拉普拉斯计算，也揭示参考整形如何限制速度与加速度。

2. 逆变换：先识别极点类型

  • 简单实极点：A/(s-p)，可用遮盖法求残值。
  • 共轭复极点：保留不可约二阶配方，或用共轭残值合成为实衰减正弦。
  • 重复极点：A_1/(s-p)+...+A_m/(s-p)^m，每个幂次都不能漏。
  • 非真分式：先做多项式长除，直接项可能对应冲激及其导数。

3. 复杂框图：先内部、后外部，但不牺牲内部稳定

为内部节点 x_1,x_2,... 写线性方程，可统一成 (I-A)x=Br。输出 y=Cx+Dr，于是 y/r=C(I-A)^{-1}B+D。这个矩阵视角是节点消元的系统化版本，也为后续状态空间和信号流图打基础。

保留局部分母往往比完全展开更有价值，因为 1−G_iH_i 或 1+G_iH_i 直接显示某个内环的稳定风险。总传递函数有限不等于每个内部信号有限；控制设计必须检查内部稳定。

通用验算链：
  1. 单位与相对阶次是否合理；
  2. 令某增益为零，是否退化到正确结构；
  3. s→0 与 s→∞ 的极限是否符合物理；
  4. 极点与时域模式是否一致；
  5. 随机赋值后，节点方程数值解是否与化简式一致。

十一、综合例题：从偏航指标独立设计 PD 闭环

问题。 悬停附近偏航动力学为 J gamma¨+D gamma˙=tau_c+tau_d。已知 J=0.02 kg·m²、D=0.04 N·m·s/rad。希望小角度闭环近似二阶，阻尼比 zeta=0.8，2% 调节时间不超过 0.5 s，并采用 tau_c=K_p(r-gamma)-K_d gamma˙。

步骤一：把时域指标翻译成极点参数

标准近似 t_s≈4/(zeta omega_n)。取边界 omega_n=4/(0.8×0.5)=10 rad/s。目标分母为 s²+16s+100，对应极点 −8±j6。

步骤二：匹配闭环特征多项式

闭环分母 Js²+(D+K_d)s+K_p。除以 J 后与目标分母比较：

K_p=J omega_n²=2 N·m/rad
K_d=2 zeta omega_n J-D=0.28 N·m·s/rad

步骤三：分别写跟踪、扰动与控制量通道

Gamma/R = K_p/[Js²+(D+K_d)s+K_p]
Gamma/Tau_d = 1/[Js²+(D+K_d)s+K_p]
Tau_c/R = K_p(Js²+Ds)/[Js²+(D+K_d)s+K_p]

第一式说明常值角度参考的稳态增益为 1；第二式在 s=0 时为 1/K_p，说明纯 PD 对常值外扰存在静差；第三式用于评估执行器峰值。只看 Gamma/R 会漏掉抗扰与控制努力这两个关键问题。

步骤四：做物理与实现检查

  1. 若参考瞬间跳变，比例项立即要求 K_p Delta r 的力矩，必须与电机偏航力矩上限比较。
  2. 角速度测量噪声会被 K_d 放大，实际微分需滤波或直接使用陀螺仪带宽受控的角速度。
  3. 控制分配器必须把 tau_c 转成四个非负、限幅的 omega_i²。
  4. 参数 J、D 变化后极点会移动，应做范围仿真而非只验证名义模型。
  5. 数字实现时把采样、计算延迟、ZOH 与微分滤波纳入闭环，再重新检查极点和裕度。

进一步设计。 若要消除常值偏航扰动的静差，需要积分作用或扰动观测/前馈估计；但积分会增加状态、相位滞后和饱和风险。这自然引向后续稳态误差、根轨迹、频域设计与数字控制内容。

十二、易错点与失败模式：知道何时不能继续算

错误为什么错修正动作
把控制器当成闭环K 稳定不代表 KG/(1+KG) 满足目标始终写出完整闭环通道和特征方程
忽略扰动注入点输入扰动与输出扰动对应 GS、S，不相同先在框图上标注物理位置再列方程
把传递函数用于非零初值Y/X 定义只描述零状态通道把初始条件响应单独计算后叠加
只凭输出传递函数判内部稳定不稳定模态可能被极零抵消隐藏检查内部节点或最小实现
只看极点不看残值模态可见程度由残值共同决定做部分分式并比较时域贡献
重复极点漏项会漏掉 t^k e^{pt} 模态按每个幂次完整列部分分式
把微分当作理想器件高频噪声被无限放大加入有限带宽滤波并计入相位
分配后直接截断电机破坏虚拟通道方向和闭环假设采用约束控制分配与饱和管理

十三、控制器设计迁移检查表：从连续推导走向数字实现

  • 面对新对象，能先定义控制目标和信号角色，再由物理定律写微分方程。
