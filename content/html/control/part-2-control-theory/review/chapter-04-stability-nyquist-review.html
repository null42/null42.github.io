理论四：把“看 Nyquist 图”还原为闭环根计数

复盘目标不是背一句“不要包围 −1”，而是能从稳定定义和闭环方程出发，独立处理开环不稳定、原点积分器、动态控制器和内部极零抵消。

返回课件伴随讲义 · 独立完整答案

一、三遍复习路线

  1. 第一遍：只抓证明链。闭环特征方程 → 特征函数零点 → 辐角原理 → P/N/Z → 稳定要求 Z=0。
  2. 第二遍：逐个复算课件例题。先不看结论写出 P，再读方向和 N，最后用直接求根或 Routh 交叉验证。
  3. 第三遍：迁移到设计。加入控制器零极点、纯延迟、采样计算延迟和不确定性，说明怎样保留离 −1 的安全距离。
离开门槛：给你一条带箭头的 Nyquist 曲线和开环模型，你必须能写出完整判定记录，而不是只说“看起来稳定”。

二、概念地图：所有箭头最后都回到闭环极点

分析对象

环路函数 L=KG 与特征函数 F=1+L。前者便于测量和作图，后者的零点就是闭环极点。

计数对象

P 数开环 L 的 RHP 极点，N 数对 −1 的有向净包围，Z 数闭环 RHP 极点。

特殊边界

虚轴极点、原点积分器和曲线穿过 −1 时，标准轮廓必须变形，等号对应临界稳定。

工程目标

不仅要求 Z=0，还要远离 −1，并验证控制量、噪声、延迟、参数漂移与未建模动态。

三、先把“稳定”说完整

概念问题本章判据常见误解
BIBO 稳定任意有界输入是否产生有界输出因果 LTI：冲激响应绝对可积；最小有理系统全部极点在 LHP一次阶跃没发散就算证明
渐近稳定零输入内部运动是否衰减到零有限维连续系统全部内部模态在 LHP虚轴极点只是“慢一点”
内部稳定全部外部输入到全部内部信号是否稳定闭环互联无隐藏不稳定模态只检查 Y/R
鲁棒稳定模型变化后是否仍稳定Nyquist 曲线在不确定性下仍保持正确包围且不碰 −1名义 Z=0 就结束
BIBO 条件的关键推导
  1. 由卷积 y(t)=∫g(τ)u(t−τ)dτ 开始。
  2. 若输入有界，存在 C 使 |u(t)|≤C。
  3. 应用三角不等式，把未知输入压缩成统一上界。
  4. 若 ∫|g(τ)|dτ<∞，则输出被常数 C∫|g| 统一限制。
|y(t)| ≤ ∫|g(τ)||u(t−τ)|dτ ≤ C∫|g(τ)|dτ

反例：积分器 G=1/s 对有界阶跃产生无界斜坡。它说明“没有 RHP 极点”还不够，虚轴极点也会破坏 BIBO 稳定。

四、闭环特征方程与内部稳定

L(s)=K(s)G(s)
T(s)=Y/R=L/(1+L)，S(s)=1/(1+L)，S+T=1
1+L(s)=0 ⇔ L(s)=−1

若 K=S/R、G=B/A，闭环分母为 A(s)R(s)+B(s)S(s)。反馈使对象和控制器重新耦合，闭环极点通常既不是对象极点，也不是控制器极点。

为什么单一 Y/R 不够
  1. 在参考、输入扰动和测量噪声处分别设置独立输入。
  2. 把误差、控制量、对象输入和输出全部列为待检查内部信号。
  3. 求闭环传递矩阵；各元素通常共享 1+L，但分子不同。
  4. 若某一元素发生 RHP 极零抵消，其他元素或初始状态仍可能暴露该模态。
危险做法：把 (s−1) 在某个外部通道中约掉，然后宣布系统稳定。真实器件的微小失配会让隐藏的 e^t 模态重新出现。

五、辐角原理怎样变成 Nyquist 判据

设复函数 H(s)=∏(s−zᵢ)/∏(s−pᵢ)。观察点沿闭合轮廓走一周，每个内部零点让 H 的总辐角增加一周，每个内部极点让总辐角减少一周；轮廓外零极点的净贡献为零。

H(C) 对原点的有向净包围 = Z − P

控制中令 H=1+L。H 曲线包围原点，等价于 L 曲线包围 −1；H 在 RHP 的零点就是闭环 RHP 极点。因此可用开环频响完成闭环根计数。

本课件的符号约定
  1. Nyquist 轮廓围住右半平面，并按课件规定方向行进。
  2. P：L 在 RHP 的极点数，按重数计。
  3. N：L(C) 对 −1 的有向净包围数；课件采用 Z=N+P。
  4. 闭环稳定要求 Z=0，故所需 N 由 P 决定。
其他教材可能把逆时针定义为正并写成 Z=P−N。公式外观可以不同，但轮廓方向、N 的正号和最终计数必须整套一致。

六、不会出错的 Nyquist 判定算法

  1. 写环路。明确负反馈符号，写出完整 L(s)=K(s)G(s)，不要漏掉传感器、延迟或控制器滤波。
  2. 先数 P。在画图前确定 L 的 RHP 极点数；虚轴极点不计入 P，但要改变轮廓。
  3. 处理边界。检查原点积分器、其他虚轴极点、非严格真有理项与纯延迟。
  4. 画完整曲线。标注 ω 方向，用共轭对称补齐负频率，并补上无穷远弧或小圆弧映射。
  5. 数 N。按本课件约定统计 −1 的有向净包围，不以“是否穿过负实轴”代替包围。
  6. 算 Z。使用 Z=N+P；只有 Z=0 且曲线不穿过 −1 才是严格稳定。
  7. 交叉验证。低阶系统用直接求根或 Routh；最后再检查裕度、控制量和不确定性。

建议使用固定判定记录表：在草稿纸上依次写“反馈符号、L(s)、RHP 极点 P、虚轴极点、正频率起点、ω→∞ 终点、共轭镜像、特殊连接弧、N 的正方向、净包围 N、Z、临界参数、复核方法”。只要其中一项空白，就暂时不要给出稳定结论。这个记录表尤其能防止把正频率局部曲线误当完整 Nyquist 轮廓。

若参数 K 连续变化，N 只能在曲线穿过 −1 时改变。可先解 Im L(jω)=0 找负实轴候选频率，再由 K|G(jω)|=1 求临界 K，并检查穿越方向。这样得到的是精确稳定边界，而不是从低分辨率图上估读。

七、三个课件算例串起来

例 1：开环稳定

G=1/(s+1)²、K=1。P=0、N=0，所以 Z=0。直接求根得 s=−1±j。

要点：不包围 −1 只有在 P=0 时才直接意味着稳定。

例 2：两个 RHP 极点

G=0.4(s+0.9)/(s²−0.9s+0.6)，P=2。K=1 时 N=0、Z=2；课件给出稳定区 K>2.3，此时 N=−2。

要点：反馈稳定化要求非零包围，降低增益并不一定更安全。

例 3：一个 RHP 极点

G=1.5/(s−1)，闭环极点 1−1.5K，故稳定要求 K>2/3。K=1 时 N=−1、P=1、Z=0；K=1/2 时 Z=1。

要点：Nyquist 与直接求根必须给出同一结论。

参数扫描技巧

对正实常数 K，画 G 绕 −1/K 等价于画 KG 绕 −1；动态控制器必须整体并入 L，不能把 −1/K(s) 当固定点。

八、积分器为何必须画小圆弧

若 L(s)=B(s)/[s^qA(s)]，虚轴轮廓会经过 s=0 的极点。应在右半平面用半径 r 的小半圆绕开，并令 r→0。

s=re^{jθ} ⇒ L(s)≈γr^{−q}e^{−jqθ}，γ=B(0)/A(0)
  • r 趋于零时，映射半径趋于无穷大。
  • 相角变化被 q 倍放大；q>1 时可能形成多重无穷远半圆。
  • γ 的符号会额外旋转 180°。
  • 该弧可能贡献包围数，因此不能从最终图中删除。

课件例题：G=1/[s(s+1)²] 的闭环特征式为 s³+2s²+s+K。Nyquist 与 Routh 都得到严格稳定区 0<K<2。

九、从稳定判据迁移到数字控制设计

工程因素Nyquist 上的表现验收动作
比例增益变化近似径向缩放曲线扫描稳定区与最小 −1 距离
超前/滞后或 PI同时改变幅值和相位，重塑整条曲线使用完整 K(s)G(s)，不能只移动临界点
纯延迟与计算延迟幅值近似不变，相位随频率持续下降把 e^{−sT} 或离散延迟显式纳入环路
采样与保持增加相位滞后并改变高频模型在离散域单位圆或等效频响上重新验证
模型不确定性Nyquist 曲线形成一族可能轨迹要求所有轨迹保持正确包围且不触碰 −1
饱和与限幅线性 Nyquist 不再完整描述闭环加入抗积分饱和与非线性时域测试

稳定设计的最终交付不是一张图，而是一份证据链：名义 P/N/Z 正确、参数最坏情况仍稳定、裕度满足要求、控制量不饱和、噪声不过度放大、采样和计算延迟已计入。

十、连续 Nyquist 怎样迁移到离散系统

连续系统稳定区域是开左半平面，Nyquist 轮廓包围开右半平面；离散系统稳定区域是单位圆内部，因此要统计闭环特征函数在单位圆外的零点。离散频率响应沿 z=e^{jΩ} 的单位圆取得，Ω 只需遍历一个 2π 周期。

连续：Re(s)<0；离散：|z|<1
z=e^{sT}：左半平面映到单位圆内部，虚轴映到单位圆
离散闭环特征方程仍为 1+L(z)=0
部署时不能遗漏的变化
  1. 先由连续对象和零阶保持得到脉冲传递函数，而不是只把 s 替换为差分算子。
  2. 把一拍或多拍计算延迟写成 z^{-d}；它在单位圆上贡献相位 −dΩ。
  3. 使用离散控制器的真实系数、滤波器和采样周期形成 L(z)。
  4. 数单位圆外开环极点与对 −1 的包围，再检查闭环根是否全部位于单位圆内。
  5. 最后在量化、饱和和采样抖动下复验，因为这些因素不属于线性 Nyquist 模型。

关键直觉：连续域中“增加一点延迟”会旋转 Nyquist 曲线；离散域中的整数拍延迟同样只改单位圆频响相位，但相位下降与归一化频率 Ω 成正比。采样越慢，同一物理频率对应的 Ω 越大，留给控制器的相位预算越少。

真正熟练的表现不是画图更快，而是遇到非标准对象时能立即识别哪条快捷规则失效，并退回特征方程、轮廓和根计数。

本章整体优化：理论四接口与诊断

主线：Nyquist 判据的本质是围绕 -1 的净绕数与开环 RHP 极点数共同决定闭环 RHP 极点数；图形直觉必须还原为根计数。

最小完整算例

先列开环 RHP 极点数 P，再沿统一方向计算绕数 N，按所采用的符号约定得到 Z；只有 Z=0 才能宣称闭环无 RHP 极点。

失败诊断：遇到原点积分器、虚轴极点或轨迹穿越 -1，不能套普通图形口诀；必须处理小圆弧、边界稳定和参数扰动后的实际闭环。

稳定判据的比较与选择

方法直接信息主要边界
Routh多项式 RHP 根数与参数区间不直接显示频率裕度；延迟需近似
根轨迹增益变化下闭环极点路径多参数和纯延迟处理不自然
Nyquist由开环频率轨迹计算闭环 RHP 根数必须统一绕行方向并处理虚轴极点
Bode 裕度交越附近的相对稳定性和带宽多交越、开环不稳定时不能替代完整 Nyquist

选择顺序不是“哪张图更熟”，而是先看模型形式和问题：参数多项式用 Routh，单增益极点移动用根轨迹，延迟和开环不稳定用 Nyquist，工程裕度整形用 Bode，并以闭环极点或 Nyquist 作最终确认。

十二、A–D 综合测试

A 级｜概念与符号

  1. 从单位负反馈节点方程推导 Y/R=L/(1+L) 和特征方程。
  2. 区分 BIBO、渐近、内部和鲁棒稳定。
  3. 在本课件约定下解释 P、N、Z，并写出稳定条件。

B 级｜标准计算

  1. 对 G=1/(s+1)²、K=1 完成 Nyquist 与直接求根双重判定。
  2. 若对象 Nyquist 在负实轴交于 −0.25，求临界正增益并说明等号状态。
  3. 推导 G=1.5/(s−1) 的稳定增益区，并写出 K=1/2 与 K=1 的 P/N/Z。

C 级｜边界与反例

  1. 构造外部 Y/R 看似稳定、内部仍含 RHP 模态的抵消例子。
  2. 推导 q 阶积分器小圆弧的幅值和角度映射。
  3. 解释为何动态 PI 控制器不能用固定 −1/K 点代替完整环路曲线。

D 级｜设计与部署

  1. 为含一个 RHP 极点、一个积分器和纯延迟的对象写完整 Nyquist 判定方案。
  2. 把连续控制器部署为数字控制器时，列出采样、保持、计算延迟、量化和饱和的稳定性复验步骤。
  3. 设计一份实验扫频安全方案，使开环不稳定对象也能获得环路频响而不失控。
