理论二：从控制器结构到可部署闭环

本复盘不按课件页码重述，而是把 PID、二阶暂态、根轨迹、输入约束、数字算法、前馈和串级控制重构成一条真正可用于设计的路线：先辨识对象与指标，再选择结构、配置极点、检查约束，最后把连续设计迁移成可验证的软件。

一、概念地图：控制器不是三个旋钮

模型
对象、工作点、阶次、延迟与零点

如果只记住“P加快、I消差、D减振”，你仍然无法设计新对象。真正要问的是：哪一个通道需要怎样的低频增益？哪一个特征方程系数要改变？输入限幅后内部状态是否仍与实际执行器一致？

二、一页总纲：十步设计闭环

  1. 明确物理输入/输出、参考、扰动和传感器方向。
  2. 在工作点附近建立对象模型，标出积分、延迟、零点和约束。
  3. 分别写跟踪、扰动、噪声和控制量通道。
  4. 用稳态指标判断是否需要积分或前馈。
  5. 用超调/调节时间选二阶目标 ζ、ωn 和极点区域。
  6. 选择 P/PI/PD/PID、根轨迹、极点配置或复合结构。
  7. 逐项匹配闭环分母，并核验实际极点、零点与高阶动态。
  8. 加入输入饱和、滤波、延迟和 anti-windup 再仿真。
  9. 离散化，明确位置式/增量式算法及采样事件顺序。
  10. 用 SIL、HIL、实机和故障测试闭合证据链。

每一步都要有“失败回退”：指标不可行就改指标，参数不可实现就改结构，仿真失配就改模型或降低带宽。

三、P、I、D 的统一理解：它们改变什么

P：直接按当前误差施加作用，提高环路低频增益和响应力度，但不能消除有负载/对象积分不足时的常值误差，过大可能降低阻尼。

I：引入原点极点，使稳定线性闭环对常值参考/扰动实现零稳态误差。它也引入相位滞后、慢模态和 windup 风险；只有在闭环稳定且执行器可实现时，“积分消差”才成立。

D：利用误差变化趋势提供预测和阻尼，通常增加相位超前、降低振荡；但放大采样噪声，并在参考端微分产生 kick，因此常对测量量微分并加滤波。

C(s)=Kp(1+1/(Ti s)+Td s)=Kp+Ki/s+Kd s，Ki=Kp/Ti，Kd=KpTd

参数化不同不等于控制器不同；必须展开传递函数并确认零点、滤波和实现顺序。

四、二阶系统：把时间指标翻译成极点

T(s)=ωn²/(s²+2ζωn s+ωn²)，p=-ζωn±jωn√(1−ζ²)

ζ决定阻尼与极点射线，ωn决定时间尺度。欠阻尼单位阶跃中：

  • ωd=ωn√(1−ζ²)，峰值时间 Tp=π/ωd；
  • Mp=exp(−ζπ/√(1−ζ²))，常用 2% 调节时间 Ts≈4/(ζωn)；
  • 极点的实部 −ζωn 控制包络衰减，虚部控制振荡频率。

设计顺序是先由允许超调求 ζ，再由调节时间求 ωn，最后检查极点区域是否与采样率、未建模极点、执行器带宽相容。任何显著零点、纯延迟、饱和或高阶残值都会使标准公式只剩近似意义。

五、从目标极点到控制器：模型匹配与根轨迹

对 G(s)=1/[s(s+a)] 的 PD 控制器 D(s)=Kp+Kd s，闭环分母为 s²+(a+Kd)s+Kp。与目标 s²+2ζωn s+ωn² 匹配得到 Kp=ωn²、Kd=2ζωn−a。一般对象则需从特征方程、根轨迹角度/幅值条件或状态空间极点配置求解。

高阶系统的二阶设计依赖主导极点近似：非主导极点足够快且残值不大时，主导极点决定尾部；但必须回到真实对象检查首峰、零点、延迟、控制量和参数偏差。

六、约束与 anti-windup：把执行器纳入控制器模型

实际执行器收到的是 u=sat(v)，而不是 PID 未限幅输出 v。若饱和时仍更新积分器 Ī=Ki e，积分状态会继续积累；解除饱和后，过大的积分储能会造成严重过冲和长时间恢复。

Ī=Ki e+Kaw(u−v)

反算项用执行器实际拒绝的控制量修正积分状态；条件积分则在会加重饱和的方向暂停积分。Kaw是约束下的时间尺度，不应脱离输入能力和采样周期单独选。

七、数字 PID：连续结构的状态机化

位置式直接计算绝对控制量：

v[k]=Kp e[k]+KiTsΣe[i]+Kd(e[k]−e[k−1])/Ts

增量式由相邻位置式相减：

Δu[k]=Kp(e[k]−e[k−1])+KiTs e[k]+Kd(e[k]−2e[k−1]+e[k−2])/Ts

数字实现必须明确采样、滤波、状态更新、限幅、anti-windup 和 PWM/DAC 更新的时序；ADC 的离散样本不自动意味着对象输入有零阶保持，物理接口决定重构模型。

八、前馈与串级：用结构利用可获得的信息

若对象为 Y=GuU+GdD，可测扰动的理想前馈为 Ff=−Gd/Gu；工程实现必须检查逆模型的稳定性、因果性、延迟和噪声放大，并常用低频/带宽受限近似逆。前馈负责可预测部分，反馈负责模型误差和未测扰动。

串级把主变量外环和快速中间变量内环分开。内环闭合后，外环看到的是等效对象；内环带宽通常以外环的 4–10 倍作为起始设计范围，再根据延迟、噪声和执行器能力修正。

九、综合设计案例：电机速度/位置双环

  1. 建立电气、机械和传感器模型，区分电压、电流、速度、位置与负载扰动。
  2. 先闭合电流内环，使其足够快并限制电压/电流；再把内环等效模型交给速度外环。
  3. 由超调与调节时间选择外环 ζ、ωn，匹配 P/PD/PI 参数，检查扰动稳态误差。
  4. 对可测负载使用低频前馈，避免积分器长期储能；加入饱和和反算 anti-windup。
  5. 离散化并测试采样抖动、量化、计算延迟、反向阶跃和故障恢复，最后比较实测曲线与模型残差。

这个案例体现理论二的核心：控制器不是从 PID 表格直接取出，而是从对象、指标、结构和实现约束共同决定。

十、最容易失分的十个判断

  1. 未检查稳定就使用终值定理。
  2. 把对象传递函数、闭环传递函数和扰动通道混为一谈。
  3. 把二阶极点公式用于有强零点/延迟/饱和的波形。
  4. 只调 Kp，不检查阻尼与控制量。
  5. 把积分消差当成非线性饱和下仍然成立。
  6. 把微分滤波当成可有可无。
  7. 把根轨迹当作任意极点配置工具。
  8. 以为增量式 PID 天然拥有积分消差。
  9. 把 ADC 样本自动当成 ZOH 输入。
  10. 只验证参考阶跃，不验证扰动、噪声、限幅和故障。

主线：PID 不是三个独立旋钮：P 改变刚度与带宽，I 改变低频型别和稳态误差，D 提供相位超前但放大测量噪声。

最小完整算例

以 G(s)=1/[s(s+1)] 为例，加入 PI 后要先展开闭环特征多项式，再由目标极点和阶跃指标核对 K_p、K_i，而不是只套单环节经验公式。

失败诊断：饱和时积分器继续积累误差会 windup；离散 D 项直接差分测量会放大噪声。实现必须说明采样、微分滤波、限幅和 anti-windup。

十一、章末 A–D 综合测试

闭卷完成后再打开独立答案。每道题都要求写假设、单位、稳定前提和验证方式。

A 级｜概念骨架

  1. 分别说明 P、I、D 的动力学作用及各自主要代价。
  2. 写出标准二阶极点与 Mp、Tp、Ts 的关系。
  3. 解释 u、v、I 在饱和 PID 中的区别。
  4. 说明前馈与串级各自需要什么额外信息。

B 级｜独立推导

  1. 由单位阶跃响应 Mp=10%、Tp=0.6s 求 ζ、ωn 和目标极点。
  2. 对 G=1/[s(s+3)] 推导 PD 参数匹配目标 ζ=0.7、ωn=5。
  3. 从位置式 PID 推导增量式 PID，并指出保存状态。
  4. 推导扰动前馈 Fd=−Gd/Gu 及其 DC 近似。

C 级｜综合分析

  1. 解释一个四阶闭环为何可能近似二阶，以及怎样用残差否定该近似。
  2. 某 PI 控制器在输入限幅后长时间过冲，写出 windup 的状态方程和两种修正。
  3. 分析测量噪声、参考阶跃和采样延迟分别如何影响 D 项。
  4. 判断一个前馈逆模型是否可部署，列出稳定、因果和噪声检查。

D 级｜自主设计

  1. 为含可测负载扰动的电机速度系统设计“电流内环—速度外环—扰动前馈—数字 anti-windup”方案。
  2. 给出从规格到代码到 HIL 的验收矩阵，至少包含跟踪、扰动、噪声、限幅、采样和故障。
  3. 若目标极点区域与执行器带宽不相交，提出三种不依赖盲目增益增大的改进路线。
