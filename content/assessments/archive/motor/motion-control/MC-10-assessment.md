# MC-10 模块测验
### 第1题 [中等] - Rs 温度漂移 ★★
**问题:** 铜绕组的电阻温度系数约为 0.39%/°C，从 25°C 升温到 125°C 时 Rs 增幅约 40%。请问：(1) Rs 变化对 FOC 系统的哪个模块影响最大？(2) 为什么 Rs 变化对电流环本身的影响相对较小？

**参考答案:**
(1) Rs 变化影响最大的是**无感观测器**（特别是基于反电动势/磁链模型的观测器）。反电动势观测器 EEMF 依赖定子电阻Rs 来从电压方程中反推反电动势：ê = u − Rs·i − Ls·di/dt。Rs 偏差直接导致反电动势估计误差，进而导致转子角度和转速估计偏差。在低速运行时，反电动势本身很小，Rs 偏差占比更大，观测器性能急剧恶化。此外，参数辨识模块中基于 Rs 的在线辨识也会因温度变化而需要持续跟踪。

(2) 对电流环本身影响较小的原因：电流环 PI 控制器的核心功能是跟踪电流指令，其闭环带宽远高于 Rs 变化引入的低频扰动。电流环的前馈解耦项（ωe·Ls·iq、ωe·Ls·id）和反电动势前馈（ωe·ψpm）才是电压方程中影响电流环精度的主要项，Rs·id 在高速运行时相对反电动势前馈很小（例如 Rs=0.1Ω、id=10A → Rs·id=1V，而反电动势在 3000rpm 时可能达 30V+）。即使 Rs 变化 40%，在 PI 闭环的积分作用下，稳态电流跟踪误差几乎不受影响。

### 第2题 [较难] - ψpm 退磁导致前馈误差 ★★★
**问题:** 永磁体磁链 ψpm 的温度系数约为 −0.12%/°C。考虑一台 48V 母线、4 极对、额定 3000rpm 的电机，ψpm 从 0.1Wb 衰减到 0.088Wb（对应约 100°C 温升）。(1) 请计算额定转速下反电动势前馈的误差电压。(2) 该误差占母线电压的百分比是多少？(3) 这对电流环性能有什么实际影响？

**参考答案:**
(1) 额定电角频率 ωe = 2π·n·pp/60 = 2π·3000·4/60 ≈ 1257 rad/s。
- 正常 ψpm 下的反电动势幅值：E_normal = ωe·ψpm = 1257 × 0.1 = 125.7V（peak，dq 坐标系中的 q 轴反电动势）
- 退磁后：E_degraded = 1257 × 0.088 = 110.6V
- 前馈误差电压：ΔE = 125.7 − 110.6 = 15.1V ≈ **15V**

(2) 母线电压 48V，线电压峰值 = 48V，相电压峰值 = 48/√3 ≈ 27.7V。误差 15V 占可用相电压的比例：15/27.7 ≈ **54%**。即使按线电压母线计算 15/48 ≈ **31%**。这是一个巨大的前馈误差。

(3) 实际影响：前馈解耦中的反电动势补偿项 ωe·ψpm 偏大 15V，导致 q 轴电压指令偏大。PI 控制器需要额外消耗积分量来抵消这 15V 的多余前馈，表现为：
- q 轴电流超调或稳态误差增大
- 在高速运行时可能触发电压饱和（电压极限被错误前馈占满）
- 电流环有效带宽下降，动态响应变慢
- 严重时导致失步或过流保护

解决方案：引入 ψpm 在线辨识（通过电压方程反推），或设计足够鲁棒的电流环（降低前馈权重、提高 PI 增益裕度）。

### 第3题 [中等] - Ld/Lq 饱和特性 ★★
**问题:** Ld 和 Lq 随电流增大而饱和下降，变化幅度可达 10%~50%。请问：(1) 单点辨识（仅在一个电流值下辨识 Ld/Lq）与多电流点辨识（在多个电流值下建立 Ld(id,iq) 查找表）对 MTPA 控制精度的影响有何区别？(2) 为什么饱和对 MTPA 的影响比对 id=0 控制的影响更大？

**参考答案:**
(1) 单点辨识的问题：MTPA 最优电流角依赖 Ld−Lq 的差值。如果在额定电流 Is_rated 下辨识得到 Ld=2mH、Lq=5mH，但实际在 0.5·Is_rated 时 Ld=3mH、Lq=7mH（饱和程度不同），则 MTPA 计算的 id 偏离真正的最优值，转矩损失可达 3%~8%。多电流点辨识建立 Ld(id,iq) 的二维查找表，在每个工作点使用准确的电感值，MTPA 精度显著提升，转矩损失可控制在 1% 以内。

(2) id=0 控制不依赖 Ld/Lq（因为 Ld≈Lq 或根本不利用磁阻转矩），电感饱和只影响电流环的前馈解耦精度——而前馈误差可被 PI 闭环纠正。但 MTPA 的 id 分配直接由 Ld−Lq 决定，这是一个**开环**计算——如果 Ld/Lq 不准，id 就分配错了，PI 无法纠正（PI 只跟踪 id/iq 指令，不管指令是否最优）。因此饱和对 MTPA 的影响是本质的、不可被闭环补偿的。

### 第4题 [较难] - 惯量 J 辨识 ★★★
**问题:** 加减速法辨识惯量的基本原理是 J = Te_ref / (dω/dt)。实际操作中需要：空载运行得到机械惯量 Jm，带载运行得到总惯量 Jtotal = Jm + Jload，两者相减得到负载惯量 Jload。请问：(1) 为什么必须分空载和带载两个状态分别辨识，而不能只用一次辨识就得到 Jload？(2) 在实际操作中，加减速过程中的 Te_ref 如何准确获取？有哪些误差源需要补偿？

**参考答案:**
(1) 一次辨识只能得到总惯量 Jtotal = Jm + Jload。由于 Jm 和 Jload 是两个独立未知量，单一方程无法求解两个未知数。必须至少做两次实验（两个不同的 J 配置），建立两个方程：
- 空载：Jm = Te_ref_empty / (dω/dt)_empty
- 带载：Jm + Jload = Te_ref_loaded / (dω/dt)_loaded
- 两式相减得 Jload。

如果只做带载一次实验，Jm 未知就无法分离出 Jload。有些方案用已知的 Jm（电机铭牌或设计值）来跳过空载实验，但实际 Jm 可能因耦合机构、轴承摩擦力矩等因素偏离铭牌值。

(2) Te_ref 的准确获取及误差源：
- **Te_ref 获取**：Te_ref = 1.5·pp·ψpm·iq_ref（假设 id=0 或已知 id 补偿），需要精确的 ψpm 值。
- **摩擦扭矩**：库仑摩擦和粘滞摩擦在加速和减速过程中方向不同，导致加减速曲线不对称。补偿方法：取加速和减速的平均值，或单独辨识摩擦模型后扣除。
- **齿槽转矩**：周期性扰动，在低速时影响大。可通过多周期平均消除。
- **电气延迟**：电流环跟踪延迟导致 Te 实际值与 Te_ref 有相位差。需确保电流环带宽足够高（>10 倍 dω/dt 对应频率）。
- **转速微分噪声**：dω/dt 由转速微分得到，需要低通滤波，但滤波引入延迟。可用最小二乘拟合直线段代替逐点微分。
