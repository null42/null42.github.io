# MC-09 模块测验
### 第1题 [中等] - 磁阻转矩 ★★
**问题:** IPMSM 中为什么负 id 产生正磁阻转矩？给定转矩方程 Te = 1.5·pp·[ψpm·iq + (Ld−Lq)·id·iq]，当 Ld < Lq、id < 0、iq > 0 时，请说明 (Ld−Lq)·id·iq 为何为正值。

**参考答案:** IPMSM 中永磁体位于转子内部，q 轴磁路主要经过铁芯，磁阻小、电感大；d 轴磁路经过永磁体（μr≈1），磁阻大、电感小，因此 Ld < Lq。代入转矩方程的磁阻分量 (Ld−Lq)·id·iq：由于 Ld−Lq < 0、id < 0（去磁方向），负负得正，再乘以 iq > 0，结果为正。这意味着负的 d 轴电流利用凸极效应产生额外的正向转矩，相当于在相同 iq 下提升了转矩密度。这也是 IPMSM 相比 SPMSM 转矩密度更高的根本原因。

### 第2题 [较难] - MTPA 电流角 ★★★
**问题:** 对于给定定子电流幅值 Is = √(id² + iq²)，MTPA 最优 id 的解析解为 id = ψpm/(2·(Lq−Ld)) − √(ψpm²/(4·(Lq−Ld)²) + Is²/2)。请解释：(1) 该公式如何由对 Te 关于 id 求偏导并令 ∂Te/∂id = 0 推导得出？(2) 为什么随着 Is 增大，最优电流角 β（id 相对于 Is 的夹角）变得更负（即 id 向更深的去磁方向偏移）？

**参考答案:**
(1) 将 iq = √(Is² − id²) 代入转矩方程 Te(id)，对 id 求导并令 ∂Te/∂id = 0，整理后得到关于 id 的一元二次方程，求解取物理上有意义的根（负值）即得到该公式。核心在于磁阻转矩分量与永磁体转矩分量对 id 的灵敏度不同——id 减小既增大磁阻转矩又减小永磁体转矩，最优值在两者边际贡献相等处。
(2) Is 增大时，磁阻转矩项 (Ld−Lq)·id·iq 的权重相对增大（因为 id·iq 乘积项随电流增大而二次增长），为了最大化磁阻转矩的贡献，需要更深的负 id。从公式看，根号内 Is²/2 项随 Is 增大占主导，id 趋近于 −Is/√2，即 β 趋近于 −45°（电流矢量更多偏向 d 轴负方向）。物理含义：大电流时凸极效应更显著，用更多电流产生磁阻转矩比全部用于 q 轴更高效。

### 第3题 [中等] - SPMSM 的 id=0 策略 ★★
**问题:** 为什么 SPMSM（Ld ≈ Lq）的最优电流分配就是 id = 0？在弱磁区域 id = 0 有什么副作用？

**参考答案:** 当 Ld ≈ Lq 时，(Ld−Lq) ≈ 0，转矩方程退化为 Te = 1.5·pp·ψpm·iq，磁阻转矩分量消失。此时给定 Is 下最大化 Te 等价于最大化 iq，而 iq = √(Is² − id²)，所以 id = 0 时 iq 最大、转矩最大。id = 0 在 MTPA 意义上是最优的。

副作用：弱磁区域需要注入负 id 来抵消反电动势以扩展转速范围，id = 0 无法实现弱磁。因此在基速以上，SPMSM 必须牺牲部分转矩（从 id=0 切换到 id<0），电流利用率下降。此外，id=0 策略在弱磁区电压利用率不如 IPMSM——因为 IPMSM 可以同时利用磁阻转矩和弱磁效应，而 SPMSM 两者只能二选一。

### 第4题 [较难] - 弱磁区域 MTPA 到 MTPV 的过渡 ★★★
**问题:** 电压极限椭圆随 ωe 增大而缩小，弱磁区 id 分配从 MTPA 过渡到 MTPV（最大转矩电压比）。请解释：(1) MTPA 轨迹与电压极限椭圆的交点如何确定弱磁起始点？(2) MTPV 曲线的物理含义是什么？(3) 从 MTPA 到 MTPV 的过渡逻辑是什么——在什么条件下切换、为什么需要切换？

**参考答案:**
(1) MTPA 曲线在 id-iq 平面上是一条从原点出发的轨迹。电压极限椭圆 (ud² + uq²) ≤ (Udc/√3)² 的圆心在原点附近，长短轴分别反比于 Ld·ωe 和 Lq·ωe，随 ωe 增大而收缩。当 MTPA 轨迹首次触及电压椭圆时的电流和转速即为弱磁起始点（基速）。超过此转速，MTPA 要求的电压超出母线限制。

(2) MTPV 的物理含义：在电压极限椭圆上，寻找使转矩 Te 最大的工作点。不同于 MTPA 在电流圆上最优化，MTPV 在电压椭圆上最优化。MTPV 曲线的特征是电流矢量沿电压椭圆移动，id 持续变负、iq 逐步减小。在极高速时 MTPV 趋近于 id = −ψpm/Ld（纯弱磁、iq→0）。

(3) 过渡逻辑：在基速以下，MTPA 轨迹完全位于电压椭圆内部，电压约束不起作用，运行在 MTPA 曲线。达到基速后，MTPA 曲线跑出电压椭圆，此时必须在电压椭圆上运行。切换条件：当 MTPA 所需电压 > 电压极限时自动切换到 MTPV。MTPV 在电压椭圆上最大化转矩，相比纯弱磁（id 只增大到刚好满足电压约束、iq 任意分配）更高效，因为它在满足电压约束的同时最大化了输出转矩。
