# MC-11 模块测验
### 第1题 [较难] - 单电阻电流重构 ★★★
**问题:** 单电阻采样方案在扇区边界和低调制深度时面临采样窗口不足的问题。请描述 lxfoc 的单电阻电流重构策略的核心思路（参考 `sampling/lxfoc_sampling_oneshunt.c`）：(1) 单电阻采样的基本原理是什么——如何从一个采样电阻还原两相电流？(2) 在哪些区域会出现"不可观测区"？(3) lxfoc 采用了什么策略来解决这些问题？

**参考答案:**
(1) **基本原理**：单电阻串联在母线负极（或下桥臂公共端），测量的是每个 PWM 周期中"导通相"的合成电流。七段式 SVPWM 的一个开关周期内有 7 个开关状态（含两个零矢量），不同时段不同相的电流流过母线电阻。通过在同一个 PWM 周期内不同时刻采样两次，得到两个不同开关状态对应的电流值，利用基尔霍夫电流定律（ia + ib + ic = 0）联立求解出两相电流。

(2) **不可观测区**：当两个有效矢量的作用时间都很短（接近零矢量区域，即扇区边界）或某个矢量作用时间为零（低调制深度、矢量接近六边形顶点）时，两个采样窗口时间不足（需要 ≥ ADC 采样保持时间 + 开关瞬态稳定时间 ≈ 1~2μs），无法在该周期内完成两次有效采样。此时重构失败。

(3) **lxfoc 的解决策略**（参考 `lxfoc_sampling_oneshunt.c`）：
- **最小脉宽注入**：当某个矢量作用时间小于最小阈值时，主动微调占空比（注入扰动）以创造足够的采样窗口。这种"伪占空比"在一个周期内修正，对电机运行影响极小。
- **采样时刻选择**：利用 PWM 计数器在中心对齐模式下的两个匹配点（上升沿和下降沿），分别在两个有效矢量时段进行采样。
- **扇区边界切换策略**：在不可观测区内使用前一周期的有效电流值进行保持，或通过观测器预测补充。
- **噪声抑制**：在开关瞬态后延迟固定时间（消隐时间）再触发 ADC，避免开关振铃干扰采样值。

### 第2题 [中等] - 最小脉宽限制 ★★
**问题:** 假设 ADC 采样保持时间 200ns + 转换时间 400ns，加上安全余量后最小可用脉宽约 1μs。在 20kHz PWM 频率（Ts = 50μs）下：(1) 计算最大和最小可用占空比。(2) 当占空比超出可用范围时（即某个相的导通时间 < 1μs），会发生什么现象？(3) 对电流波形有什么实际影响？

**参考答案:**
(1) PWM 周期 Ts = 50μs，最小脉宽 Tmin = 1μs：
- 最小可用占空比 = Tmin / Ts = 1/50 = **2%**
- 最大可用占空比 = (Ts − Tmin) / Ts = 49/50 = **98%**
即可用占空比范围为 2% ~ 98%。

(2) 当某相占空比 < 2% 或 > 98% 时：
- ADC 在该相导通期间的采样窗口不足 1μs，采样值可能落在开关瞬态的振铃区间内
- 对于单电阻方案：无法区分相邻两个矢量的电流，电流重构失败
- 对于三电阻方案：电流虽可采样，但该相电流极小，信噪比极差

(3) 对电流波形的实际影响：
- **削波失真**：在正弦波过零附近（占空比接近 0% 或 100%），实际采样的电流值包含大量噪声和开关尖峰，等效于电流波形在过零处被"削平"
- **低次谐波**：削波引入 5 次、7 次等低次谐波，导致转矩脉动
- **电流环振荡**：噪声采样值被 PI 控制器放大，可能引起电流环高频振荡
- 解决思路：注入最小占空比钳位（clamp）或零序偏移，确保任何一相占空比始终在 2%~98% 范围内。

### 第3题 [较难] - PWM 中点采样 ★★★
**问题:** 七段式对称 PWM 的中点对应 V0 零矢量（000 状态）的中央时刻。请解释：(1) 为什么在 PWM 中点时刻采样电流的信噪比最高？(2) 与在有效矢量时刻采样相比，中点采样有哪些优势？(3) 中点采样的缺点是什么？在什么场景下可能不适用？

**参考答案:**
(1) **信噪比最高的原因**：
- 零矢量（000）时三个下桥臂同时导通，所有相的电流都通过下桥臂续流，没有开关动作
- 中点时刻远离任何开关跳变沿（距离最近的开关沿有 TON/2 或 TOFF/2 的时间），开关振铃已完全衰减
- 电流处于自由续流状态，di/dt ≈ 0，电流值最稳定
- 没有 MOSFET/IGBT 的 dv/dt 耦合噪声通过寄生电容注入采样电路

(2) **相比有效矢量时刻采样的优势**：
- 有效矢量时刻（如 100、110 状态）有桥臂在开关过程中，存在开关噪声叠加在采样信号上
- 有效矢量时刻电流正在变化（受电压驱动，di/dt ≠ 0），采样时刻的微小偏差会导致采样值偏差
- 中点采样不需要额外的消隐时间（blanking time），等效可用采样窗口更大

(3) **缺点和限制场景**：
- **单电阻方案**：中点（000 状态）时母线电流为零（三相电流都走下桥臂，不流过母线电阻），无法采样。单电阻方案必须在有效矢量时段采样。
- **动态响应延迟**：中点采样意味着在一个 PWM 周期中间才获取电流值，等效采样延迟为 0.5Ts（相比周期起始采样），对电流环带宽有轻微影响。
- **过调制/六步模式**：零矢量消失时没有"中点"可采，必须切换到有效矢量采样策略。

### 第4题 [中等] - 双更新模式 ★★
**问题:** 双更新（double-update）模式将 FOC 的计算延迟从 1Ts 降至约 0.5Ts。请解释：(1) 单更新与双更新的区别是什么？(2) 为什么延迟减小对电流环带宽至关重要？(3) 双更新模式的硬件要求是什么？

**参考答案:**
(1) **区别**：
- **单更新（single-update）**：每个 PWM 周期只在中点（或起点）触发一次 ADC 采样和 FOC 计算，新 PWM 占空比在下一个周期生效。延迟 = 1 个完整 PWM 周期（1Ts）。
- **双更新（double-update）**：每个 PWM 周期在中心和两端各触发一次——中心采样+计算，更新占空比；两端再采样+计算，再更新占空比。相当于半个 PWM 周期就更新一次，延迟降至 0.5Ts。

(2) **对带宽的意义**：
- 数字控制中，采样-计算-更新的总延迟是限制带宽的核心因素。延迟引入的相位滞后 = ω·Td（Td 为总延迟）
- 单更新 Td ≈ 1.5Ts（采样延迟 0.5Ts + 计算延迟 ≈ 0.5Ts + PWM 锁存延迟 0.5Ts），可用带宽 ≈ fs/10 ~ fs/6
- 双更新 Td ≈ 0.75Ts，可用带宽可提升至 ≈ fs/5 ~ fs/3
- 例如 fs = 20kHz：单更新带宽 ~2~3.3kHz，双更新 ~4~6.7kHz。带宽翻倍意味着更快的动态响应和更好的电流波形质量。

(3) **硬件要求**：
- MCU 的 ADC 需支持**双触发**：在 PWM 计数器中心（匹配点）和两端（溢出/归零）都能触发 ADC 转换
- PWM 定时器需要支持**中心对齐 + 双更新**模式（如 STM32 的 Center-Aligned Mode with Shadow Register Update on both edges）
- FOC 计算时间必须 < 0.5Ts（即 < 25μs @20kHz），否则来不及在下半个周期生效
- 需要更精密的时序设计，避免 ADC 触发与 PWM 更新的竞争条件
