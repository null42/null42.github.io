## 一、概念理解题（）

### 题目1：死区补偿的工程深化方法（vs ALG-04的基础补偿）
- **问题：** ALG-04介绍了基于电流极性的基础死区补偿方法，但工程实践中存在诸多问题需要深化处理。请分析：
1. 基础极性补偿方法在工程中有哪些具体问题？（至少列举3个）
2. 什么是"电流极性模糊区"？如何定义和处理？
3. 请对比以下三种工程深化方法的原理和优缺点：基于电压模型的补偿、扰动观测器补偿、重复控制补偿。

- **参考答案：**
1. **基础极性补偿方法的工程问题：**
   - **电流过零判断不稳定：** 电流在过零点附近受噪声影响，极性频繁翻转，补偿量在正负之间跳变，导致电流在零点附近振荡加剧
   - **补偿量不精确：** 简化模型仅考虑死区时间，忽略开关延迟差异（$T_{on} \neq T_{off}$）、器件压降、温度漂移等因素，实际补偿量与需求不匹配
   - **离散化效应：** 电流极性在一个控制周期内可能变化，但补偿量按周期更新，导致补偿滞后
   - **零电流钳位区无法处理：** 电流被钳位在零附近时，极性判断失效，补偿方向错误
   - **动态响应差：** 电流极性突变时（如转矩反转），补偿量切换滞后，产生瞬态电流冲击

2. **电流极性模糊区：** 当电流幅值小于某个阈值 $I_{th}$ 时，电流极性不可靠（噪声和量化误差占主导），该区域称为极性模糊区。

   **定义方法：**
   - 固定阈值法：$I_{th} = k \times I_{noise,rms}$（$k = 3 \sim 5$），$I_{noise,rms}$ 为电流噪声有效值
   - 自适应阈值：$I_{th}$ 随运行工况（转速、负载）动态调整

   **处理方法：**
   - **线性过渡法：** 在模糊区内，补偿量从正值线性过渡到负值：
     $$\Delta V_{comp} = V_{dt} \cdot \frac{i}{I_{th}} \quad (|i| < I_{th})$$
   - **保持上一拍极性：** 在模糊区内保持上一次的补偿方向不变，避免频繁切换
   - **基于电压角度判断：** 在模糊区内不依赖电流极性，而是根据参考电压矢量角度推算电流极性（稳态时电流滞后电压约功率因数角）

3. **三种工程深化方法对比：**

   | 维度 | 基于电压模型 | 扰动观测器 | 重复控制 |
   |------|------------|-----------|---------|
   | 原理 | 根据参考电压和电流方向计算精确补偿量，考虑开关延迟和压降 | 将死区视为未知扰动，通过观测器在线估计并补偿 | 利用死区误差的周期性，通过迭代学习逐周期消除 |
   | 优点 | 物理意义清晰，补偿精确（模型准确时） | 不依赖精确模型，自适应性强 | 可消除任意周期性误差，无需极性判断 |
   | 缺点 | 需要精确的器件参数（$T_{on}$、$T_{off}$、$V_d$等），参数漂移时失效 | 观测器带宽有限，动态响应慢 | 收敛需要多个基波周期，仅对周期性误差有效 |
   | 计算量 | 小 | 中等 | 中等（需存储历史周期数据） |
   | 适用场景 | 参数已知的标准化产品 | 参数变化大的应用 | 稳态运行、对THD要求高的应用 |

## 二、计算分析题（）

### 题目2：抗齿槽转矩补偿的原理
- **问题：** 齿槽转矩（Cogging Torque）是PMSM固有的转矩脉动源，由永磁体与定子齿槽的磁阻变化引起。请分析：
1. 齿槽转矩的产生机理是什么？其频率特征如何？
2. 抗齿槽转矩补偿的基本原理是什么？如何获取补偿表？
3. 某PMSM有12个定子槽、10个转子极（极对数5），请计算齿槽转矩的基波频率（每转波动次数），并设计一个基于查表法的补偿方案。

- **参考答案：**
1. **齿槽转矩产生机理：** 永磁体产生的磁通倾向于通过磁阻最小的路径（定子齿），当转子旋转时，永磁体与定子齿的相对位置不断变化，磁路磁阻周期性变化，导致磁共能随转子位置变化，产生齿槽转矩：
   $$T_{cog} = -\frac{\partial W_{mc}}{\partial \theta_m}$$
   齿槽转矩与电流无关，即使电机不通电，手动旋转转子也能感受到周期性的"卡顿"感。

   **频率特征：** 齿槽转矩是转子机械位置的周期函数，基波频率为：
   $$N_{cog} = \text{LCM}(N_s, 2p) / p$$
   其中 $N_s$ 为定子槽数，$p$ 为极对数，LCM为最小公倍数。齿槽转矩每转波动 $N_{cog} \times p$ 次。

2. **抗齿槽转矩补偿原理：** 在q轴电流指令上叠加一个与转子位置相关的补偿电流 $i_{q,comp}(\theta)$，使补偿电流产生的电磁转矩恰好抵消齿槽转矩：
   $$T_{comp} = K_t \cdot i_{q,comp}(\theta) = -T_{cog}(\theta)$$
   因此：$i_{q,comp}(\theta) = -T_{cog}(\theta) / K_t$

   **获取补偿表的方法：**
   - **离线测量法：** 在电机不通电时，用测力计或转矩传感器缓慢旋转转子，记录各位置的齿槽转矩，生成 $\theta \to i_{q,comp}$ 查找表
   - **在线自学习法：** 在速度闭环运行时，检测速度纹波（齿槽转矩导致），通过迭代算法逐步建立补偿表
   - **电流注入法：** 在d轴注入高频电流，检测q轴响应中的位置相关分量，辨识齿槽转矩
   - **有限元计算：** 利用电机有限元模型预先计算齿槽转矩波形

3. **齿槽转矩频率计算：**
   $N_s = 12$，$2p = 10$，$\text{LCM}(12, 10) = 60$
   每转齿槽转矩波动次数：$N_{cog} = 60 / 5 = 12$ 次/转
   齿槽转矩基波频率：$f_{cog} = 12 \times n / 60$（$n$ 为转速rpm）
   在1000rpm时：$f_{cog} = 12 \times 1000/60 = 200\text{Hz}$

   **基于查表法的补偿方案：**
   - **建表：** 将一个电周期（$360°/p = 72°$机械角度）等分为 $N_{table}$ 个区间（如 $N_{table} = 360$），每个区间存储一个补偿电流值
   - **查表：** 根据当前转子机械位置 $\theta_m$，计算表索引 $idx = (\theta_m \times N_{table} / 72°) \mod N_{table}$，读取 $i_{q,comp}[idx]$
   - **插值：** 为避免补偿量阶跃，对相邻表项进行线性插值
   - **在线更新：** 运行中检测速度纹波，用梯度下降法更新补偿表：
     $$i_{q,comp}[idx]_{k+1} = i_{q,comp}[idx]_k - \mu \cdot \Delta\omega[idx]_k$$
     其中 $\mu$ 为学习率，$\Delta\omega$ 为速度纹波在对应位置的采样值
   - **补偿叠加：** $i_q^{ref} = i_q^{spd} + i_{q,comp}(\theta_m)$

## 三、工程实践题（）

### 题目3：角度延迟补偿与转速纹波补偿的协同设计
- **问题：** 在无感FOC中，观测器估算角度存在延迟，导致d轴和q轴交叉耦合，产生转矩脉动和转速纹波。同时，齿槽转矩等周期性扰动也产生转速纹波。两种补偿需要协同设计。请分析：
1. 角度延迟的来源和定量影响是什么？如何补偿？
2. 角度延迟补偿和齿槽转矩补偿在什么情况下会相互干扰？
3. 请设计一个协同补偿框架，同时处理角度延迟和周期性转矩扰动，说明各模块的功能和接口。

- **参考答案：**
1. **角度延迟的来源：**
   - **观测器延迟：** SMO/磁链观测器的低通滤波器引入相位滞后，$\Delta\theta_{obs} \approx -\arctan(\omega_e / \omega_{LPF})$
   - **计算延迟：** 一拍延迟（$T_s$）等效角度延迟 $\Delta\theta_{calc} = \omega_e T_s$
   - **PLL延迟：** 锁相环带宽有限，跟踪角度滞后 $\Delta\theta_{PLL} \approx \omega_e / \omega_{PLL}$
   - 总角度延迟：$\Delta\theta_{total} = \Delta\theta_{obs} + \Delta\theta_{calc} + \Delta\theta_{PLL}$

   **定量影响：** 角度延迟 $\Delta\theta$ 导致Park变换角度偏差，产生：
   - d轴电流误差：$\Delta i_d \approx i_q \sin\Delta\theta \approx i_q \Delta\theta$（q轴电流泄漏到d轴）
   - q轴电流误差：$\Delta i_q \approx -i_d \sin\Delta\theta \approx -i_d \Delta\theta$
   - 转矩脉动：$\Delta T_e = 1.5p[\psi_f \Delta i_q + (L_d - L_q)(i_d \Delta i_q + i_q \Delta i_d)]$

   **补偿方法：**
   - **前馈补偿：** $\theta_{comp} = \theta_{est} + \omega_e T_{delay}$，其中 $T_{delay}$ 为总延迟时间
   - **角度预测：** $\theta_{pred}(k+1) = \theta_{est}(k) + \omega_e T_s + \frac{1}{2}\dot{\omega}_e T_s^2$
   - **Smith预估器：** 在观测器中引入延迟补偿环节

2. **两种补偿相互干扰的情况：**
   - **频率重叠：** 角度延迟产生的转矩脉动频率为基波频率（1次），齿槽转矩脉动频率为 $N_{cog}$ 次。当 $N_{cog} = 1$ 时（极少见），两者频率重叠，无法分离
   - **更常见的情况：** 角度延迟补偿改变dq轴定向精度，影响齿槽转矩补偿的注入效果。如果角度延迟未完全补偿，齿槽转矩补偿注入的 $i_{q,comp}$ 实际上部分注入了d轴，降低补偿效果
   - **耦合路径：** 角度误差 → dq轴交叉耦合 → 转矩脉动 → 速度纹波 → 齿槽补偿表学习偏差 → 补偿效果下降
   - 反过来，齿槽补偿注入的q轴电流如果含有d轴泄漏分量，会改变d轴磁链，影响观测器精度

3. **协同补偿框架：**

   ```text
   ┌─────────────────────────────────────────────────────┐
   │                   协同补偿框架                        │
   │                                                     │
   │  ┌───────────┐    ┌──────────────┐                  │
   │  │ 观测器     │───→│ 角度延迟补偿  │───→ θ_comp      │
   │  │ (SMO/PLL) │    │ θ + ωe·Tdelay│      │          │
   │  └───────────┘    └──────────────┘      │          │
   │       ↓                                  ↓          │
   │  ┌───────────┐    ┌──────────────┐  ┌────────┐     │
   │  │ ωe估计    │───→│ 转速纹波分离  │  │ Park   │     │
   │  │           │    │              │  │ 变换   │     │
   │  └───────────┘    │ ┌──────────┐ │  └────────┘     │
   │                    │ │1次分量   │─┤→ 角度延迟修正   │
   │                    │ │(角度延迟)│ │                 │
   │                    │ └──────────┘ │                 │
   │                    │ ┌──────────┐ │                 │
   │                    │ │Ncog次分量│─┤→ 齿槽补偿表     │
   │                    │ │(齿槽转矩)│ │  更新           │
   │                    │ └──────────┘ │                 │
   │                    └──────────────┘                 │
   │                                                     │
   │  ┌───────────┐    ┌──────────────┐                  │
   │  │ 齿槽补偿表 │───→│ iq_comp注入  │───→ iq_ref      │
   │  │ (在线更新) │    │              │                  │
   │  └───────────┘    └──────────────┘                  │
   └─────────────────────────────────────────────────────┘
   ```

   **各模块功能：**
   - **角度延迟补偿：** 前馈补偿观测器+计算+PLL的总延迟，输出修正后的角度 $\theta_{comp}$
   - **转速纹波分离：** 对速度纹波进行带通滤波，分离1次分量（角度延迟残余）和 $N_{cog}$ 次分量（齿槽转矩），避免两种补偿相互干扰
   - **1次分量反馈：** 用1次速度纹波微调角度延迟补偿量（自适应修正 $T_{delay}$）
   - **齿槽补偿表：** 用 $N_{cog}$ 次速度纹波在线更新补偿表，仅响应齿槽频率的扰动
   - **补偿注入：** 将齿槽补偿电流叠加到q轴电流指令，使用修正后的角度进行Park变换

   **关键设计要点：**
   - 角度延迟补偿优先级高于齿槽补偿，必须先消除角度延迟，再进行齿槽补偿
   - 转速纹波分离的带通滤波器带宽要足够窄，避免频率混叠
   - 齿槽补偿表的学习率应小于角度延迟补偿的收敛速度，防止两者竞争
   - 在加减速过程中，暂时冻结齿槽补偿表更新（速度变化导致频率偏移，学习不准确）
