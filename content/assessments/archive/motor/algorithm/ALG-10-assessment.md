## 一、概念理解题（）

### 题目1：线性调制区与过调制区的分界线（调制比m=1）的物理意义
- **问题：** SVPWM的线性调制范围上限为 $m = 1$（对应相电压幅值 $U_{ph} = U_{dc}/\sqrt{3}$），超过此值进入过调制区。请说明：
1. 调制比 $m = 1$ 的物理意义是什么？为什么这是线性调制的极限？
2. 线性调制区、过调制区和六阶梯波模式对应的调制比范围分别是多少？
3. 过调制区为什么能输出比线性调制更高的电压？代价是什么？

- **参考答案：**
1. **$m = 1$ 的物理意义：** 调制比定义为参考电压矢量幅值与六阶梯波基波幅值之比 $m = V_{ref} / (2U_{dc}/\pi)$，或等价定义为相电压幅值与 $U_{dc}/\sqrt{3}$ 之比。当 $m = 1$ 时，参考电压矢量的轨迹恰好内切于SVPWM六边形（由6个有效矢量顶点构成的正六边形），这是不发生波形失真（即参考电压矢量轨迹为正圆）的最大值。

   **为什么是线性调制极限：** 当 $m \leq 1$ 时，参考电压矢量轨迹完全在六边形内部，SVPWM可以通过相邻两个有效矢量的线性组合精确合成任意方向的参考矢量，输出电压与参考电压成线性关系。当 $m > 1$ 时，参考矢量轨迹超出六边形，部分区域无法用线性组合精确合成，必须采用非线性处理（如保持角度不变、截断幅值），输出电压与参考电压不再成线性关系。

2. **调制比范围：**
   - 线性调制区：$0 \leq m \leq 1$，输出电压正弦，THD最低
   - 过调制区：$1 < m \leq \pi/(2\sqrt{3}) \approx 0.907 \times \pi/\sqrt{3}$（不同定义下约为 $1 < m \leq 1.15$ 或 $m_{max} = 2/\sqrt{3} \approx 1.155$），输出电压波形开始畸变
   - 六阶梯波模式：$m = m_{max} = 2/\sqrt{3} \approx 1.155$（或按另一种定义 $m = \pi/3 \approx 1.047$），逆变器仅输出6个有效矢量依次切换，相电压为阶梯波

   注：不同文献对调制比定义不同，常见的有 $m = V_{ref} / (U_{dc}/\sqrt{3})$（此时 $m_{max} = 2/\sqrt{3}$）和 $m = V_{ref} / (2U_{dc}/\pi)$（此时 $m_{max} = \pi/3$）。

3. **过调制能输出更高电压的原因：** 在线性调制区，参考矢量轨迹限制在六边形内切圆内，6个扇区的零矢量时间均大于零。过调制时，参考矢量超出内切圆，在某些扇区零矢量时间为零，全部时间分配给有效矢量，等效于增大了输出电压的基波分量。

   **代价：**
   - 输出电压波形畸变，不再是纯正弦波，含有5、7、11、13次等低次谐波
   - 电流THD增大，转矩脉动加剧
   - 电压与调制比的关系变为非线性，控制增益变化
   - 过渡到六阶梯波时，电压不可连续调节

## 二、计算分析题（）

### 题目2：过调制对电流谐波和转矩脉动的影响
- **问题：** 某PMSM在过调制区域运行，请分析：
1. 过调制引起的电压谐波主要有哪些次数？为什么会出现这些特定次数的谐波？
2. 电压谐波如何转化为电流谐波和转矩脉动？频率关系是什么？
3. 某SPMSM参数：$R_s = 0.2\Omega$，$L_s = 0.5\text{mH}$，基波频率 $f_1 = 200\text{Hz}$。在过调制区，5次电压谐波幅值为基波的15%。请计算5次电流谐波幅值，并估算由此引起的转矩脉动幅值占基波转矩的比例。

- **参考答案：**
1. **过调制电压谐波次数：** SVPWM过调制产生的电压谐波主要是5次、7次、11次、13次等，即 $6k \pm 1$ 次（$k = 1, 2, 3, \ldots$）。原因：
   - 过调制使相电压波形从正弦波趋向阶梯波，阶梯波的傅里叶级数仅含 $6k \pm 1$ 次谐波（三相无零序，3的倍数次谐波被抵消）
   - 5次和7次谐波幅值最大，随次数增加迅速衰减
   - 在六阶梯波极限下，相电压的傅里叶级数为 $v = \frac{2U_{dc}}{\pi} \sum_{k=1}^{\infty} \frac{1}{6k \pm 1} \sin((6k \pm 1)\omega t)$

2. **电压谐波到电流谐波的转化：** 电流谐波幅值取决于阻抗：
   $$I_n = \frac{V_n}{\sqrt{R_s^2 + (n\omega_e L_s)^2}} \approx \frac{V_n}{n\omega_e L_s}$$（高频时电感主导）
   5次电流谐波频率为 $5f_1$，7次为 $7f_1$。

   **电流谐波到转矩脉动：** 转矩 $T_e = \frac{3}{2}p\psi_f i_q$，电流谐波在dq轴上表现为脉动。5次和7次ABC谐波在dq轴上均表现为6次脉动（$5\omega_e$ 和 $7\omega_e$ 在dq坐标系下分别为 $-6\omega_e$ 和 $+6\omega_e$），因此转矩脉动频率为 $6f_1$。

3. **5次电流谐波计算：**
   5次谐波角频率：$\omega_5 = 5 \times 2\pi \times 200 = 6283\text{rad/s}$
   5次阻抗：$Z_5 = \sqrt{R_s^2 + (5\omega_e L_s)^2} = \sqrt{0.04 + (6283 \times 0.0005)^2} = \sqrt{0.04 + 9.87} \approx 3.14\Omega$
   假设基波电压幅值 $V_1$，5次电压谐波 $V_5 = 0.15 V_1$
   5次电流谐波与基波电流之比：$I_5/I_1 = (V_5/V_1) \times (Z_1/Z_5) = 0.15 \times (Z_1/3.14)$
   基波阻抗：$Z_1 = \sqrt{0.04 + (1256.6 \times 0.0005)^2} = \sqrt{0.04 + 0.395} \approx 0.656\Omega$
   $I_5/I_1 = 0.15 \times 0.656/3.14 = 0.15 \times 0.209 = 0.0314$，即5次电流谐波约为基波的3.14%

   **转矩脉动估算：** 5次和7次电流谐波在dq轴上叠加产生6次转矩脉动。粗略估算，转矩脉动幅值约为电流谐波幅值的2倍（5次和7次共同贡献），即约6.3%的基波转矩。实际值取决于调制比和具体波形，过调制越深，脉动越大。

## 三、工程实践题（）

### 题目3：六阶梯波模式与SVPWM模式切换时的平滑过渡策略
- **问题：** 在全速度范围控制中，电机从线性调制区加速到六阶梯波模式，需要经过过调制区的平滑过渡。请分析：
1. 从线性调制到六阶梯波的模式切换过程中，如果不做平滑处理会出现什么问题？
2. 常用的过调制过渡策略有哪些？请简述最小相位误差法和电压谐波注入法的基本思路。
3. 某系统需要在 $m = 0.9 \sim 1.155$ 之间实现平滑过渡。请设计一个基于调制比分段的过渡策略，说明每个区域的处理方法。

- **参考答案：**
1. **不做平滑处理的问题：**
   - **电压跳变：** 从线性调制突然切换到过调制处理方式，输出电压基波幅值可能发生跳变，导致电流冲击
   - **相位突变：** 过调制处理改变了电压矢量的角度-幅值关系，切换点处电压矢量方向突变，导致电流波形畸变
   - **转矩脉动突变：** 从低THD的线性调制突然进入高THD的过调制，转矩脉动急剧增大，机械系统冲击
   - **控制环路不稳定：** 电流环PI参数按线性调制设计，过调制区的非线性增益变化可能导致环路失稳

2. **常用过渡策略：**

   **最小相位误差法（Minimum Phase Error, MPE）：**
   - 核心思路：当参考矢量超出六边形时，保持参考矢量角度不变，将幅值截断到六边形边界
   - 处理方式：$V_{out} = \min(V_{ref}, V_{hex}(\theta))$，其中 $V_{hex}(\theta)$ 是六边形边界在该角度处的半径
   - 优点：实现简单，角度连续无跳变
   - 缺点：幅值截断导致电压谐波，且截断程度随调制比增大而加剧

   **电压谐波注入法：**
   - 核心思路：在基波参考电压中注入特定谐波（主要是3次谐波），使参考矢量轨迹从圆形变为接近六边形的形状，从而在不超出六边形的前提下增大基波输出
   - 注入3次谐波后：$v_a = m \cdot \sin(\theta) + k_3 \cdot \sin(3\theta)$，$k_3$ 根据调制比动态调整
   - 优点：过渡平滑，THD可控
   - 缺点：需要精确计算注入量，计算复杂度较高

3. **基于调制比分段的过渡策略设计：**

   | 区域 | 调制比范围 | 处理方法 |
   |------|-----------|---------|
   | 线性调制区 | $0 \leq m \leq 0.9$ | 标准SVPWM，无特殊处理 |
   | 过渡区I | $0.9 < m \leq 1.0$ | 注入3次谐波，逐步增大 $k_3$，使参考轨迹从圆逐渐变形 |
   | 过渡区II | $1.0 < m \leq 1.1$ | 最小相位误差法，幅值截断+角度保持，截断量逐渐增大 |
   | 过渡区III | $1.1 < m < 1.155$ | 逐步减少零矢量时间，增加有效矢量持续时间，逼近六阶梯波 |
   | 六阶梯波区 | $m = 1.155$ | 纯六阶梯波，仅6个有效矢量依次切换 |

   **关键设计要点：**
   - 每个区域的边界应设置滞回宽度（如 $\pm 0.02$），防止在边界处频繁切换
   - 过渡区内的参数（$k_3$、截断系数等）应随调制比连续变化，避免阶跃
   - 电流环PI参数在过调制区需要适当降低增益（因为电压增益非线性增大），防止振荡
   - 切换到六阶梯波时，电流环失去对电流波形的精确控制能力，应切换为转矩/功率开环控制
