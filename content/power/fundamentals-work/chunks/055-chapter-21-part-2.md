# 第21章 脉宽调制整流器（第2部分）

## 21.3 电流波形的控制（续）

![源页 p.886](../assets/page-snapshots/chapter-21/page-886.png)

图21.20 升压整流器的电流编程控制

电感电流纹波引入附加偏差。两种机制在电感电流较小（交流线路波形过零附近）时最为显著。

电流编程升压变换器的静态输入特性（即平均输入电流对输入电压）为

$$\langle i_g(t) \rangle_{T_s} = \begin{cases} \dfrac{v_g(t)\, L\, i_{2c}^2(t)\, f_s\, V}{2(V - v_g(t))(v_g(t) + m_a L)^2} & \text{DCM} \\[6pt] i_c(t) - \left( 1 - \dfrac{v_g(t)}{V} \right)\left( m_a + \dfrac{v_g(t)}{2 L} \right) T_s & \text{CCM} \end{cases} \tag{21.60}$$

变换器在连续导通模式下运行的条件为

$$\langle i_g(t) \rangle_{T_s} > \frac{T_s\, V}{2 L}\, \frac{v_g(t)}{V}\left( 1 - \frac{v_g(t)}{V} \right) \tag{21.61}$$

用控制电流 $i_c(t)$ 表示，CCM 运行条件为

$$i_c(t) > \frac{T_s\, V}{L}\left( \frac{m_a L}{V} + \frac{v_g(t)}{V} \right)\left( 1 - \frac{v_g(t)}{V} \right) \tag{21.62}$$

传统电流编程整流器控制方案中，控制电流 $i_c(t)$ 简单地与交流输入电压成正比：

$$i_c(t) = \frac{v_g(t)}{R_e} \tag{21.63}$$

![源页 p.887](../assets/page-snapshots/chapter-21/page-887.png)

其中 $R_e$ 是若平均输入电流严格跟随参考电流 $i_c(t)$ 时将得到的仿真电阻。式(21.60)至(21.63)给出的静态输入特性绘于图21.21。平均输入电流 $\langle i_g(t) \rangle_{T_s}$ 作为外加输入电压 $v_g(t)$ 的函数，对若干仿真电阻 $R_e$ 值绘制。CCM-DCM 边界附近区域示出。曲线按固定人工斜坡斜率

$$m_a = \frac{V}{2 L} \tag{21.64}$$

绘制。这是在所有静态工作点稳定升压电流编程控制器的最小人工斜坡值。将 $m_a$ 降到此值以下会导致低 $v_g(t)/V$ 处 CCM 工作点不稳定。

图21.21 电流编程升压变换器的静态输入特性，采用式(21.64)的最小稳定人工斜坡

为实现电阻仿真，期望静态输入特性为线性且过原点。由图21.21可见并非如此：CCM 下曲线相当线性，但接近 CCM-DCM 边界时呈现显著曲率。所得平均电流波形总结于图21.22。

### 21.3.3 临界导通模式与滞环控制

低谐波整流器以及直流-直流变换器和直流-交流逆变器中有时采用的另一控制方案是滞环控制。滞环控制器不在固定开关频率和占空比下工作，而是按需开关晶体管以将波形保持在给定范围内。滞环控制的一个特例称为临界导通模式控制，在若干商用 IC 中实现，在数百瓦以下的低谐波整流器中流行[262–264]。

一个示例是图21.23(a)的正弦，其中升压变换器输入电流被控制为跟随带 $\pm 10\%$ 容差的正弦参考。晶体管导通时电感电流增大，关断时减小。故此滞环控制器在输入电流低于参考的 90% 时开通晶体管，在输入电流超过参考的 110% 时关断晶体管。滞环控制器实现简单。但缺点是开关频率可变且抗噪性降低。

滞环控制的另一示例是图21.23(b)的波形。下限选为零，上限为参考输入的两倍。此控制器在连续和断续导通模式之间的边界运行升压变换器。产生相同波形的替代控制方案简单地以恒定导通时间操作晶体管：电感电流到达零时开通晶体管，在长度 $t_{on}$ 的固定间隔后关断。所得电感电流波形的峰值直接取决于外加输入电压，平均值

![源页 p.889](../assets/page-snapshots/chapter-21/page-889.png)

图21.23 两个滞环控制升压变换器的输入电流波形：(a) $\pm 10\%$ 调节带，(b) 临界导通模式运行（$\pm 100\%$ 调节带）

为其峰值的一半。无论哪种控制方法，变换器都自然表现出无损耗电阻或理想整流器行为。仿真电阻为

$$R_e = \frac{2 L}{t_{on}} \tag{21.65}$$

此方案的优点是电感尺寸小、控制 IC 成本低。缺点是峰值电流增大、开关频率可变和需附加输入 EMI 滤波。

典型临界导通模式控制器如图21.24所示。零电流检测器检测 $i_g(t)$（电感电流）何时为零；这通常通过监测电感两端电压实现。零电流检测器置位锁存器，开通晶体管并启动开关周期。晶体管电流也被监测，并与正比于外加输入电压 $v_g(t)$ 的正弦参考 $v_r(t)$ 比较。当检测电流等于参考时，锁存器复位，晶体管关断。

由于开关频率可变且可能在宽范围内变化，须仔细设计变换器功率级。对给定功率 $P$，所需晶体管导通时间 $t_{on}$ 可通过合并式(21.17)和(21.65)并解 $t_{on}$ 求得：

$$t_{on} = \frac{4 L P}{V_M^2} \tag{21.66}$$

图21.24 临界导通模式的典型实现

![源页 p.890](../assets/page-snapshots/chapter-21/page-890.png)

对图21.24的电感 $L$ 应用伏秒平衡原理得

$$v_g\, t_{on} + (v_g - V)\, t_{off} = 0 \tag{21.67}$$

故晶体管关断时间为

$$t_{off} = t_{on}\, \frac{v_g}{V - v_g} \tag{21.68}$$

开关周期 $T_s$ 为

$$T_s = t_{off} + t_{on} \tag{21.69}$$

将式(21.66)和(21.68)代入式(21.69)得

$$T_s = \frac{4 L P}{V_M^2}\, \frac{1}{1 - \dfrac{v_g(t)}{V}} \tag{21.70}$$

将式(21.11)代入式(21.70)得开关频率表达式：

$$f_s = \frac{1}{T_s} = \frac{V_M^2}{4 L P}\left( 1 - \frac{V_M}{V} |\sin(\omega t)| \right) \tag{21.71}$$

$\sin(\omega t)$ 等于零时出现最大开关频率：

$$f_{s,max} = \frac{V_M^2}{4 L P} \tag{21.72}$$

正弦峰值处出现最小开关频率：

$$f_{s,min} = \frac{V_M^2}{4 L P}\left( 1 - \frac{V_M}{V} \right) \tag{21.73}$$

![源页 p.891](../assets/page-snapshots/chapter-21/page-891.png)

式(21.72)和(21.73)可用于选择电感 $L$ 和输出电压 $V$，使开关频率在可接受范围内变化。

### 21.3.4 非线性载波控制

非线性载波控制器（NLC）能够在 CCM 下工作的升压及其他变换器中实现输入电阻仿真。控制器实现简单，无需检测输入电压或输入电流，也无需电流环路误差放大器。升压非线性载波电荷控制器本质稳定，不受电流编程控制器中需加人工斜坡的稳定性问题困扰。

图21.25给出了带非线性载波电荷控制的 CCM 升压整流器系统，波形如图21.26。此方法的理由如下。控制晶体管开关电流 $i_s(t)$ 是理想的。此脉动电流比连续变换器输入电流容易检测——可用简单电流互感器，如图21.25。进一步，控制此电流的积分（即电荷）有两个原因：(1) 波形积分改善抗噪性；(2) 波形积分与其平均值直接相关，

$$\langle i_s(t) \rangle_{T_s} = \frac{1}{T_s} \int_t^{t+T_s} i_s(\tau)\, d\tau \tag{21.74}$$

图21.25 升压变换器的非线性载波电荷控制

![源页 p.892](../assets/page-snapshots/chapter-21/page-892.png)

图21.26 图21.25 NLC 控制器升压整流器的晶体管电流 $i_s(t)$、抛物线载波电压 $v_c(t)$ 和积分器电压 $v_i(t)$ 波形

在固定频率系统中，$T_s$ 为常数，一个开关周期内的积分与平均值成正比。故只需在开关电流积分等于参考时关断晶体管，即可使平均开关电流与参考信号成正比。在图21.25控制器中，开关电流 $i_s(t)$ 由变压器匝比 $n$ 缩放，然后由电容 $C_i$ 积分，使

$$v_i(t) = \frac{1}{C_i} \int_0^{d T_s} \frac{i_s(\tau)}{n}\, d\tau \quad \text{对于}\; 0 < t < d T_s \tag{21.75}$$

积分器电压 $v_i(t)$ 在每个开关周期末复位为零，下一开关周期开始时重新积分。故在晶体管关断时刻，电压 $v_i(d T_s)$ 与平均开关电流成正比：

$$v_i(d T_s) = \frac{\langle i_s \rangle_{T_s}}{n C_i f_s} \quad \text{对于区间}\; 0 < t < T_s \tag{21.76}$$

应如何控制平均开关电流？为实现输入电阻仿真，期望

$$\langle i_g(t) \rangle_{T_s} = \frac{\langle v_g(t) \rangle_{T_s}}{R_e(v_{control})} \tag{21.77}$$

进一步期望避免检测 $i_g(t)$ 或 $v_g(t)$。与其他方案一样，我们将检测直流输出电压 $\langle v(t) \rangle_{T_s}$ 以构建平衡平均输入和输出功率的低带宽反馈环路。故让我们确定式(21.77)蕴含的 $\langle i_s(t) \rangle_{T_s}$ 与 $\langle v(t) \rangle_{T_s}$ 之间的关系。假设升压变换器工作于连续导通模式，则可写

$$\langle i_s(t) \rangle_{T_s} = d(t)\, \langle i_g(t) \rangle_{T_s} \tag{21.78}$$

$$\langle v_g(t) \rangle_{T_s} = d'(t)\, \langle v(t) \rangle_{T_s} \tag{21.79}$$

![源页 p.893](../assets/page-snapshots/chapter-21/page-893.png)

将式(21.78)和(21.79)代入式(21.77)得

$$\langle i_s(t) \rangle_{T_s} = \frac{d(t)\,(1 - d(t))\, \langle v(t) \rangle_{T_s}}{R_e(v_{control})} \tag{21.80}$$

图21.25控制器实现了此方程。

图21.25的非线性载波发生器产生抛物线波形 $v_c(t)$，由下式给出

$$v_c(t) = v_{control}\left( \frac{t}{T_s} \right)\left( 1 - \frac{t}{T_s} \right) \quad \text{对于}\; 0 \le t \le T_s \tag{21.81}$$

$$v_c(t + T_s) = v_c(t)$$

此波形如图21.26。注意式(21.81)类似于式(21.80)，$d(t)$ 换成 $(t/T_s)$。控制器在 $t = d T_s$（积分器电压 $v_i(t)$ 等于载波波形 $v_c(t)$ 时）关断晶体管。故

$$v_i(d T_s) = v_c(d T_s) = v_{control}(t)\, d(t)\,(1 - d(t)) \tag{21.82}$$

代入式(21.76)得

$$\frac{\langle i_s(t) \rangle_{T_s}}{n C_i f_s} = v_{control}(t)\, d(t)\,(1 - d(t)) \tag{21.83}$$

此式与式(21.80)形式相同。比较式(21.80)和(21.83)可知仿真电阻 $R_e$ 为

$$R_e(v_{control}) = \frac{d(t)(1 - d(t))\, \langle v(t) \rangle_{T_s}}{\langle i_s(t) \rangle_{T_s}} = \frac{\langle v(t) \rangle_{T_s}}{n C_i f_s\, v_{control}(t)} \tag{21.84}$$

若直流输出电压和控制电压的交流变化可忽略，则 $R_e$ 基本恒定，交流线路电流将呈现低谐波失真。故无需检测输入电压或输入电流，仅通过检测开关电流即可在 CCM 升压变换器中实现输入电阻仿真。

生成抛物线载波波形的一种简单方法使用两个积分器，如图21.27。缓慢变化的控制电压 $v_{control}(t)$ 被积分，得到峰值幅值与 $v_{control}(t)$ 成正比的斜坡波形 $v_r(t)$。去除该波形的直流分量，然后再次积分。第二积分器输出为抛物线载波 $v_c(t)$，如图21.26和式(21.81)所示。两个积分器在每开关周期末由时钟发生器复位为零。抛物线载波的幅值因而仿真电阻可通过改变 $v_{control}(t)$ 控制。

式(21.78)和(21.79)仅在变换器工作于连续导通模式时成立。因此变换器工作于 DCM 时交流线路电流波形失真。由于这发生在交流线路电压过零附近，故产生交越失真。但谐波失真不如电流编程方案严重，采用 NLC 控制方法构建通用输入整流器是可行的。总谐波失真的分析和绘制见文献[267]。

非线性载波控制可应用于电流编程升压整流器，以及基于升降压、SEPIC、Ćuk 等拓扑的其他整流器，采用积分电荷控制或峰值电流编程控制[267, 268]。这些情形须采用不同载波波形。文献[269]描述了一种检测交流输入电压 $v_g(t)$ 而非开关电流 $i_s(t)$ 的非线性载波控制器。

## 21.4 含理想整流器的单相变换器系统

PWM 整流器系统中的一个附加问题是从交流线路汲取的功率、传递到直流负载的功率以及大容量储能电容中储存的能量的控制。

### 21.4.1 储能

通常期望变换器系统的直流输出电压可高精度调节。实践中，用高增益宽带宽反馈环路即可轻易实现。得到良好调节的直流输出电压 $v(t) = V$，含可忽略的交流变化。对给定恒定负载特性，负载电流 $I$ 和瞬时负载功率 $p_{load}(t) = P_{load}$ 也恒定：

$$p_{load}(t) = v(t)\, i(t) = V I \tag{21.85}$$

但单相理想整流器的瞬时输入功率 $p_{ac}(t)$ 不恒定：

$$p_{ac}(t) = v_g(t)\, i_g(t) \tag{21.86}$$

若 $v_g(t)$ 由式(21.11)给出，且 $i_g(t)$ 遵循式(21.1)，则瞬时输入功率为

$$p_{ac}(t) = \frac{V_M^2}{R_e} \sin^2(\omega t) = \frac{V_M^2}{2 R_e}\left( 1 - \cos(2\omega t) \right) \tag{21.87}$$

随时间变化。交流输入电压过零处瞬时输入功率为零。式(21.85)和(21.87)如图21.28(a)所示。注意所需瞬时负载功率 $p_{load}(t)$ 不等于所需瞬时整流器输入功率 $p_{ac}(t)$。整流器系统内某元件须提供或消耗这两个瞬时功率之差。

![源页 p.895](../assets/page-snapshots/chapter-21/page-895.png)

图21.28 单相理想整流器系统的波形：(a) 脉动交流输入功率 $p_{in}(t)$ 和恒定直流负载功率 $P_{load}$；(b) 储能电容电压 $v_C(t)$

由于理想整流器不消耗或产生功率，也不含显著内部储能，故须向系统加入低频储能元件如电解电容。瞬时输入与负载功率之差流过此电容。

含储能元件的整流器系统波形可通过求解整流器能量方程确定[275, 276]。若储能电容 $C$ 是唯一能显著低频储能的系统元件，则流入电容的功率 $p_C(t)$ 等于瞬时输入与输出功率之差：

$$p_C(t) = \frac{d E_C(t)}{dt} = \frac{d\left( \frac{1}{2} C v_C^2(t) \right)}{dt} = p_{ac}(t) - p_{load}(t) \tag{21.88}$$

其中 $C$ 是电容值，$v_C(t)$ 是电容电压，$E_C(t)$ 是电容储能。故如图21.28(b)所示，当 $p_{ac}(t) > p_{load}(t)$ 时能量流入电容，$v_C(t)$ 升高；反之 $v_C(t)$ 降低。故须允许电容电压 $v_C(t)$ 按需升降以储存和释放所需能量。稳态下 $p_{ac}(t)$ 和 $p_{load}(t)$ 的平均值必须相等，使一个交流线路周期内电容储能无净变化。

系统配置能够(1)宽带宽控制交流线路电流波形以实现单位功率因数，(2)内部低频储能，(3)宽带宽调节直流输出电压。也可将这些功能集成到单个变换器中，只要维持输入、输出和电容电压所需的低频独立性[277]。

储能电容还使系统可在瞬时输入和输出功率不同的其他情况下工作。例如，通常要求交流线路电压短时失效期间输出电压保持调节。保持时间是 $v_{ac}(t)$ 变为零后输出电压 $v(t)$ 保持调节的持续时间。典型要求是系统在丢失一个完整交流线路周期（即 50 Hz 系统中 20 ms）期间继续向负载供电。保持时间内负载功率完全由储能电容供给。电容值应选得使保持时间结束时电容电压 $v_C(t)$ 超过直流-直流变换器产生所需负载电压所需的最小值。

储能功能可由电容以外的元件（如电感）执行。但电感因重量和成本高而是差选。例如，100 μF 100 V 电解电容和 100 μH 100 A 电感各可储 1 J 能量。但电容尺寸、重量、成本均小得多。

储能电容引入的一个问题是系统启动暂态期间的大浪涌电流。电容电压 $v_C(t)$ 初始为零；需大量电荷和能量将其升到平衡值。升压变换器无法限制此浪涌电流幅值：即使 $d(t) = 0$，只要变换器输出电压低于输入电压，大电流就流过升压变换器二极管到电容。需附加电路限制升压变换器浪涌电流。具有升降压型变换比的变换器本质上能控制浪涌电流。此优点以附加开关应力为代价。

也可设计理想整流器在世界任何地方接入公用电力系统时正确工作。通用输入整流器可在低至日本部分地区 100 V、高至西澳大利亚 260 V 的额定交流方均根电压幅值下工作，交流线路频率为 50 Hz 或 60 Hz。无论交流输入电压如何，通用输入整流器产生恒定额定直流输出电压 $V_C$。

$$i_{ac}(t) = \frac{p_{ac}(t)}{v_{ac}(t)} = \frac{p_{load}(t)}{v_{ac}(t)} = \frac{P_{load}}{V_M \sin(\omega t)} \tag{21.89}$$

储能电容电压纹波可通过积分式(21.88)求得。在 $p_{ac}(t)$ 平均值等于 $P_{load}$ 的稳态条件下，积分式(21.88)得

$$E_C(t) = \frac{1}{2} C v_C^2(t) = E_C(0) + \int_0^t \left( -P_{load} \cos(2\omega t) \right) dt \tag{21.90}$$

其中 $\omega$ 是交流线路频率。求积分得

$$E_C(t) = E_C(0) - \frac{P_{load} \sin(2\omega t)}{2\omega} \tag{21.91}$$

因此电容电压波形为

$$v_C(t) = \sqrt{\frac{2 E_C(t)}{C}} = \sqrt{v_C^2(0) - \frac{P_{load}}{\omega C} \sin(2\omega t)} \tag{21.92}$$

可验证此波形的方均根值为 $V_{C,rms} = v_C(0)$。故式(21.92)可写为

$$v_C(t) = V_{C,rms} \sqrt{1 - \frac{P_{load}}{\omega C V_{C,rms}^2} \sin(2\omega t)} \tag{21.93}$$

此波形绘于图21.28(b)。$\sin(2\omega t)$ 等于 1 和 -1 时分别出现电容电压最小和最大值。因此峰-峰电容电压纹波为

$$2 \Delta v_C = V_{C,rms}\left[ \sqrt{1 + \frac{P_{load}}{\omega C V_{C,rms}^2}} - \sqrt{1 - \frac{P_{load}}{\omega C V_{C,rms}^2}} \right] \approx \frac{P_{load}}{\omega C V_{C,rms}} \tag{21.94}$$

近似在 $P_{load}/(\omega C V_{C,rms}^2)$ 足够小于 1 时有效，此条件在交流电压纹波足够小于 $V_{C,rms}$ 时满足。

### 21.4.2 外环低带宽控制系统的建模

如上所述，按需改变仿真电阻以平衡平均交流输入和直流负载功率的外环低带宽控制器是所有近理想整流器系统共有的。为设计此控制器，可用无损耗电阻（LFR）模型对整流器建模。对 LFR 进行扰动和线性化得到预测相关小信号传递函数的小信号等效电路。本节推导此模型[245, 276, 278]。

期望整流器输出电压对负载功率、交流线路电压和元件特性的变化稳定。故需要电压反馈环路。如21.4.1节讨论，此环路不能试图去除交流线路频率二次谐波 $2\omega$ 处的电容电压纹波，因为这样做要求 $R_e(t)$ 在二次谐波频率处显著变化。这会向交流线路电流波形引入显著失真、相移和功率因数退化。因此此环路在 $2\omega$ 处须有足够小增益，故带宽必须低。因此，为设计低带宽外控制环路，无需对系统高频行为建模。可假设任何内宽带宽控制器在低频下理想工作，使图21.33(a)的理想整流器模型充分代表低频系统行为。

本节推导的小信号模型正确预测任何可建模为无损耗电阻的整流器系统的控制-输出传递函数和输出阻抗。模型忽略高频开关纹波的复杂效应，对控制频率足够低于交流线路频率的变化有效。电阻和直流-直流变换器/稳压器负载均处理。

PWM 整流器波形方均根值和平均值的计算可能相当繁琐，这可能妨碍功率级元件的有效设计。本节开发若干近似，允许为功率级电流的方均根值和平均值写出相对简单的解析表达式，并比较变换器方案[255, 279]。升压整流器的晶体管方均根电流被发现相当低。

晶体管电流的方均根值定义为

$$I_{Q,rms} = \sqrt{\frac{1}{T_{ac}} \int_0^{T_{ac}} i_Q^2(t)\, dt} \tag{21.110}$$

其中 $T_{ac}$ 是交流线路波形周期。积分可表示为一个交流线路周期内所有开关周期上积分之和：

$$I_{Q,rms} = \sqrt{\frac{1}{T_{ac}} \sum_{n=1}^{T_{ac}/T_s} \left( \frac{1}{T_s} \int_{(n-1)T_s}^{n T_s} i_Q^2(t)\, dt \right)} \tag{21.111}$$

![源页 p.905](../assets/page-snapshots/chapter-21/page-905.png)

当 $T_s$ 远小于 $T_{ac}$ 时，上式积分可近似。该近似相当于取 $T_s \to 0$ 的极限，如下：

$$I_{Q,rms} = \sqrt{\frac{1}{T_{ac}} \lim_{T_s \to 0} \sum_{n=1}^{T_{ac}/T_s} \left( \frac{1}{T_s} \int_{(n-1)T_s}^{n T_s} i_Q^2(\tau)\, d\tau \right)} = \sqrt{\frac{1}{T_{ac}} \int_0^{T_{ac}} \frac{1}{T_s} \int_t^{t+T_s} i_Q^2(\tau)\, d\tau\, dt} \tag{21.112}$$

即先在一个开关周期内对 $i_Q^2(t)$ 求平均，再对所得结果在交流线路周期上求平均：
$$I_{Q,rms} = \sqrt{\langle \langle i_Q^2(t) \rangle_{T_s} \rangle_{T_{ac}}}$$

因此 $i_Q^2(t)$ 先在一个开关周期内求平均。所得结果再在交流线路周期上求平均，最后对结果开方。

### 21.5.1 升压整流器示例

对升压整流器，晶体管电流 $i_Q(t)$ 在晶体管导通时等于输入电流，在晶体管关断时为零。因此，$i_Q^2(t)$ 在一个开关周期上的平均为

$$\langle i_Q^2 \rangle_{T_s} = \frac{1}{T_s} \int_t^{t+T_s} i_Q^2(t)\, dt \tag{21.113}$$

$$= d(t)\, i_{ac}^2(t)$$

若输入电压为

$$v_{ac}(t) = V_M |\sin\omega t| \tag{21.114}$$

则输入电流为

$$i_{ac}(t) = \frac{V_M}{R_e} |\sin\omega t| \tag{21.115}$$

其中 $R_e$ 为仿真电阻。在恒定输出电压 $V$ 下，晶体管占空比须满足关系

$$\frac{V}{v_{ac}(t)} = \frac{1}{1 - d(t)} \tag{21.116}$$

此处假设变换器动态快于交流线路频率。将式 (21.114) 代入式 (21.116) 并解出 $d(t)$ 得

$$d(t) = 1 - \frac{V_M}{V} |\sin\omega t| \tag{21.117}$$
