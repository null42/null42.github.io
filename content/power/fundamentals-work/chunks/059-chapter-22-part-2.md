## 22.3 软开关（续）

![源页 p.951](../assets/page-snapshots/chapter-22/page-951.png)

图22.26 串联谐振变换器低于谐振在 $k = 1$ CCM 下工作时晶体管 $Q_1$ 的电压和电流波形

电压基波分量 $v_{s1}(t)$，如图22.25。因此电流波形 $i_s(t)$ 的过零发生在电压 $v_s(t)$ 过零之前。

对半周期 $0 < t < T_s/2$，开关电压 $v_s$ 等于 $+V_g$。对 $0 < t < t_\beta$，电流 $i_s(t)$ 为正，晶体管 $Q_1$ 和 $Q_4$ 导通。$i_s(t)$ 为负时（区间 $t_\beta < t < T_s/2$）二极管 $D_1$ 和 $D_4$ 导通。$T_s/2 < t < T_s$ 期间情况对称。

由于 $i_{s1}(t)$ 超前 $v_{s1}(t)$，晶体管先于各自反并联二极管导通。注意，在 $D_1$ 导通区间 $t_\beta < t < T_s/2$ 的任意时刻，晶体管 $Q_1$ 都可关断而不产生开关损耗。电路自然地使晶体管关断过渡无损，可容忍较长关断开关时间。

一般而言，谐振槽对开关呈现有效电容负载、使开关电流过零发生在开关电压过零之前时，可出现零电流开关。桥式配置中，零电流开关的特征是半桥导通顺序 $Q_1$–$D_1$–$Q_2$–$D_2$，即晶体管在各自反并联二极管导通时关断。若需要，每当零电流开关性质出现在关断过渡时，可用自然换流晶闸管替代晶体管。

图22.26中晶体管开通过渡类似于 PWM 开关：硬开关且非无损。$Q_1$ 开通过渡期间，二极管 $D_2$ 须关断。晶体管电流和电压均不为零，$Q_1$ 经历高瞬时功率耗散周期，产生开关损耗。与 PWM 情形一样，$D_2$ 的反向恢复电流流过 $Q_1$。此电流尖峰可能是开关损耗的最大分量。此外，$Q_1$ 和 $Q_2$ 的漏-源电容及 $D_1$ 耗尽层电容存储的能量在 $Q_1$ 开通时丢失。这些开通过渡开关损耗机制是零电流开关方案的主要缺点。

### 22.3.2 全桥高于谐振工作：零电压开关

串联谐振变换器高于谐振工作时，可出现零电压开关现象，电路使晶体管电压在控制器开通晶体管之前降为零。经小幅电路修改，晶体管关断过渡也可在零电压下发生。此过程可显著降低基于 MOSFET 和二极管的变换器的开关损耗。

对图22.24的全桥电路，开关输出电压 $v_s(t)$ 及其基波分量 $v_{s1}(t)$ 以及近似正弦的槽电流波形 $i_s(t)$ 如图22.27。高于槽谐振频率时，槽网络 $Z_i(s)$ 的输入阻抗由槽电感阻抗主导。故槽对桥呈现有效电感负载，开关电流 $i_s(t)$ 滞后于开关电压基波分量 $v_{s1}(t)$，如图22.27。因此电压波形 $v_s(t)$ 的过零发生在电流波形 $i_s(t)$ 之前。

对半周期 $0 < t < T_s/2$，开关电压 $v_s(t)$ 等于 $+V_g$。对 $0 < t < t_\alpha$，电流 $i_s(t)$ 为负，二极管 $D_1$ 和 $D_4$ 导通。$i_s(t)$ 为正时（区间 $t_\alpha < t < T_s/2$）晶体管 $Q_1$ 和 $Q_4$ 导通。$T_s/2 < t < T_s$ 期间波形

![源页 p.953](../assets/page-snapshots/chapter-22/page-953.png)

对称。由于 $v_s(t)$ 过零超前 $i_s(t)$ 过零，晶体管在各自反并联二极管之后导通。注意，在 $D_1$ 导通区间 $0 < t < t_\alpha$ 的任意时刻，晶体管 $Q_1$ 都可开通而不产生开关损耗。电路自然地使晶体管开通过渡无损，可容忍较长开通开关时间。一个特别重要的含义是避免了反并联二极管反向恢复相关的开关损耗。可用较慢二极管（如 MOSFET 体二极管）实现 $D_1$ 至 $D_4$。此外，$Q_1$ 至 $Q_4$ 和 $D_1$ 至 $D_4$ 的输出电容不导致开关损耗。

一般而言，谐振槽对开关呈现有效电感负载、使开关电压过零发生在开关电流过零之前时，可出现零电压开关。桥式配置中，零电压开关的特征是半桥导通顺序 $D_1$–$Q_1$–$D_2$–$Q_2$，即晶体管在各自反并联二极管导通时开通。由于整个开通过渡期间晶体管电压为零，开通时开关损耗（由慢开通时间或任何器件电容储能引起）不发生。

图22.28中晶体管关断过渡类似于 PWM 开关。采用 IGBT 或其他少数载流子器件的变换器中，关断过渡可能产生显著开关损耗。电流拖尾现象使 $Q_1$ 经历高瞬时功率耗散周期，产生开关损耗。

为辅助晶体管关断过程，可在桥的各臂引入小电容 $C_{leg}$，如图22.29所示。采用 MOSFET 的变换器中，器件输出电容足以实现此目的，无需外部分立电容。栅极驱动信号中还引入延迟，使四晶体管全部关断有一个短换流区间。在正常 $Q_1$、$D_1$、$Q_2$、$D_2$ 导通区间，臂电容与半导体开关并联，对变换器工作无影响。但这些电容在晶体管关断时引入换流区间。$Q_1$ 关断时，槽电流 $i_s(T_s/2)$ 流过开关电容 $C_{leg}$ 而非 $Q_1$，$Q_1$ 和 $C_{leg}$ 上的电压升高。最终 $Q_1$ 上的电压达到 $V_g$；二极管 $D_2$ 随后正向偏置。若 MOSFET 关断时间足够快，则 MOSFET 在漏极电压显著升到零以上之前完全关断，产生可忽略的关断开关损耗。器件电容（即 $C_{leg}$）中存储的能量转移到槽电感。半导体器件电容或存储电荷均不导致开关损耗这一事实是零电压开关的主要优点，也是其使用的最常见动机。MOSFET 变换器通常可仅用内部漏-源电容以此方式工作。但 IGBT 等其他器件通常需要大量外部电容以降低 IGBT 关断过渡期间的损耗。

零电压开关的附加优点是降低器件电容相关的 EMI。传统 PWM 变换器以及（在某种程度上）零电流开关变换器中，开通和/或关断过渡期间半导体器件电容的快速充放电产生显著高频振铃和电流尖峰。

所有半导体器件零电压开关的变换器波形中振铃明显缺席；这些变换器本质上不产生此类 EMI。

## 22.4 谐振变换器的负载依赖性质

前几章研究的 CCM PWM 变换器的性质在很大程度上不受负载电流影响。因此这些变换器具有若干常被视为理所当然的 desirable 性质。晶体管电流与负载电流成正比；故轻载时导通损耗小，导致良好的轻载效率。此外输出阻抗低，故直流输出电压不显著依赖负载 $i$–$v$ 特性（至少在 CCM 中）。不幸的是，这些良好性质不一定为谐振变换器所共有。谐振变换器设计的核心重要性在于选择谐振槽拓扑和元件值，使轻载时晶体管导通损耗最小，使宽负载电流范围内（最好所有预期负载，但至少在满载和中间功率）获得零电压开关，并使变换器动态范围与负载 $i$–$v$ 特性兼容。本节讨论这些设计问题。

循环槽电流引起的导通损耗是谐振变换器设计中公认的问题。这些电流独立于或仅弱依赖于负载电流，导致轻载效率低。图22.30中，开关电流 $i_s(s)$ 等于 $v_s(s)/Z_i(s)$。若希望开关电流跟踪负载电流，则在开关频率处 $\|Z_i\|$ 应由负载电阻 $R$ 主导或至少受其强烈影响。不幸的是，这通常与零电压开关要求（$Z_i$ 由槽电感主导）不一致。

![源页 p.955](../assets/page-snapshots/chapter-22/page-955.png)

图22.30 谐振逆变器模型

为设计具有良好性质的谐振变换器，工程师须洞察负载电阻 $R$ 如何影响槽输入阻抗和输出电压。

本节将逆变器输出特性、零电压开关边界和晶体管电流对负载电阻的依赖与负载开路或短路极端条件下槽网络的性质联系起来。无阻尼槽网络响应易于绘制，可快速获得优化槽网络设计所需的洞察。

### 22.4.1 逆变器输出特性

首先研究逆变器输出电压幅值 $\|v\|$ 如何依赖负载电流幅值 $\|i\|$。考虑图22.30的谐振逆变器系统。令 $H_\infty(s)$ 为槽网络的开路（$R \to \infty$）传递函数：

$$H_\infty(s) = \left. \frac{v(s)}{v_{s1}(s)} \right|_{R \to \infty} \tag{22.33}$$

令 $Z_{o0}(s)$ 为源 $v_{s1}(s)$ 短路时确定的输出阻抗。则可用图22.31的戴维南等效电路建模槽网络输出端口。用分压公式求解得

$$v(s) = H_\infty(s)\, v_{s1}(s)\, \frac{R}{R + Z_{o0}(s)} \tag{22.34}$$

给定角开关频率 $\omega_s = 2\pi f_s$，令 $s = j\omega_s$ 得表示交流输出电压幅值和相位的相量：

$$v(j\omega_s) = H_\infty(j\omega_s)\, v_{s1}(j\omega_s)\, \frac{R}{R + Z_{o0}(j\omega_s)} \tag{22.35}$$

图22.31 建模槽网络输出端口的戴维南等效电路

幅值可由下式求得

$$\|v(j\omega_s)\|^2 = v(j\omega_s)\, v^*(j\omega_s) \tag{22.36}$$

其中 $v^*(j\omega_s)$ 是 $v(j\omega_s)$ 的复共轭。将式(22.35)代入式(22.36)得

![源页 p.956](../assets/page-snapshots/chapter-22/page-956.png)

$$\|v(j\omega_s)\|^2 = \frac{\|H_\infty(j\omega_s)\|^2\, \|v_{s1}(j\omega_s)\|^2\, R^2}{(R + Z_{o0}(j\omega_s))(R + Z_{o0}(j\omega_s))^*} = \frac{\|H_\infty(j\omega_s)\|^2\, \|v_{s1}(j\omega_s)\|^2\, R^2}{(R + Z_{o0}(j\omega_s))(R + Z_{o0}(j\omega_s))^*} \tag{22.37}$$

假设槽网络仅含纯电抗元件，即槽网络内任何损耗或其他电阻元件影响可忽略，则此结果可进一步化简。则输出阻抗 $Z_{o0}(j\omega_s)$ 及槽网络所有其他驱动点阻抗均为纯虚量。这意味着复共轭 $Z_{o0}^*(j\omega_s)$ 为

$$Z_{o0}^*(j\omega_s) = -Z_{o0}(j\omega_s) \tag{22.38}$$

将式(22.38)代入式(22.37)并化简得

$$\|v(j\omega_s)\|^2 = \frac{\|H_\infty(j\omega_s)\|^2\, \|v_s(j\omega_s)\|^2}{1 + \dfrac{\|Z_{o0}(j\omega_s)\|^2}{R^2}} \tag{22.39}$$

且

$$R = \frac{\|v(j\omega_s)\|}{\|i(j\omega_s)\|} \tag{22.40}$$

将式(22.40)代入式(22.39)并重排得

$$\|v(j\omega_s)\|^2 + \|i(j\omega_s)\|^2\, \|Z_{o0}(j\omega_s)\|^2 = \|H_\infty(j\omega_s)\|^2\, \|v_s(j\omega_s)\|^2 \tag{22.41}$$

故给定频率下，逆变器输出特性（即 $\|v(j\omega_s)\|$ 与 $\|i(j\omega_s)\|$ 的关系）是椭圆形的。式(22.41)可进一步重排为

$$\frac{\|v(j\omega_s)\|^2}{V_{oc}^2} + \frac{\|i(j\omega_s)\|^2}{I_{sc}^2} = 1 \tag{22.42}$$

其中开路电压 $V_{oc}$ 和短路电流 $I_{sc}$ 为

$$V_{oc} = \|H_\infty(j\omega_s)\|\, \|v_s(j\omega_s)\|$$

$$I_{sc} = \frac{\|H_\infty(j\omega_s)\|\, \|v_s(j\omega_s)\|}{\|Z_{o0}(j\omega_s)\|} = \frac{V_{oc}}{\|Z_{o0}(j\omega_s)\|} \tag{22.43}$$

![源页 p.957](../assets/page-snapshots/chapter-22/page-957.png)

图22.32 谐振逆变器的椭圆形输出特性。还示出了电阻匹配负载

这些逆变器输出特性如图22.32。此特性描述给定开关频率下交流输出电压幅值如何随电路加载变化。平衡输出电压由此椭圆特性与负载 $i$–$v$ 特性的交点给定。例如，图22.32还给出了 $R = \|Z_{o0}(j\omega_s)\|$ 的特殊情形下斜率 $1/R$ 的电阻负载线叠加。此 $R$ 值对应匹配负载工作，此时变换器输出功率最大。可证工作点为

$$\|v(j\omega_s)\|^2 = \frac{V_{oc}}{\sqrt{2}}$$

$$\|i(j\omega_s)\|^2 = \frac{I_{sc}}{\sqrt{2}} \tag{22.44}$$

注意图22.32也可应用于谐振直流-直流变换器的输出 $i$–$v$ 特性，因为输出整流器此时用有效电阻负载 $R_e$ 加载槽。

### 22.4.2 晶体管电流对负载的依赖

晶体管须导通出现在槽网络输入端口的电流 $i_s(t)$。此电流由槽网络输入阻抗 $Z_i(j\omega_s)$ 确定：

$$i_{s1}(j\omega_s) = \frac{v_{s1}(j\omega_s)}{Z_i(j\omega_s)} \tag{22.45}$$

图22.33 槽网络，并联谐振变换器示例：(a) 槽电路，(b) $R \to 0$ 和 $R \to \infty$ 极限下输入阻抗幅值 $\|Z_i\|$ 的波特图

![源页 p.958](../assets/page-snapshots/chapter-22/page-958.png)

如前所述，获得良好轻载效率要求 $\|Z_i(j\omega_s)\|$ 随负载电阻 $R$ 增大而增大。为理解 $\|Z_i(j\omega_s)\|$ 如何依赖 $R$，让我们画出开路（$R \to \infty$）和短路（$R \to 0$）负载极端情形下的 $\|Z_i(j\omega_s)\|$：

$$Z_{i0}(j\omega_s) = \left. Z_i(j\omega_s) \right|_{R \to 0}$$

$$Z_{i\infty}(j\omega_s) = \left. Z_i(j\omega_s) \right|_{R \to \infty} \tag{22.46}$$

例如，考虑图22.19、22.20、22.21、22.22、22.23的并联谐振变换器。$\|Z_{i0}(j\omega_s)\|$ 和 $\|Z_{i\infty}(j\omega_s)\|$ 阻抗的波特图如图22.33构造。$Z_{i0}(s)$ 在负载 $R$ 短路时求得，等于电感阻抗 $sL$。$Z_{i\infty}(s)$ 在负载 $R$ 开路时求得，由串联组合 $(sL + 1/(sC))$ 给出。

图22.33可见阻抗幅值 $\|Z_{i0}(j\omega_s)\|$ 和 $\|Z_{i\infty}(j\omega_s)\|$ 在频率 $f_m$ 处相交。若选开关频率使 $f_s < f_m$，则 $\|Z_{i\infty}(j\omega_s)\| > \|Z_{i0}(j\omega_s)\|$。变换器则表现出 desirable 特性：空载开关电流幅值 $\|v_s(j\omega_s)\|/\|Z_{i\infty}(j\omega_s)\|$ 小于短路条件下开关电流 $\|v_s(j\omega_s)\|/\|Z_{i0}(j\omega_s)\|$。事实上短路开关电流受槽电感阻抗限制，而空载开关电流主要由槽电容阻抗决定。

若选开关频率使 $f_s > f_m$，则 $\|Z_{i\infty}(j\omega_s)\| < \|Z_{i0}(j\omega_s)\|$。空载开关电流幅值则大于负载短路时开关电流！负载电流减小或去除时，晶体管将继续导通大电流并产生高导通损耗。这导致轻载效率差。可结论为，为在并联谐振变换器中获得良好轻载效率，应选 $f_s$ 充分小于 $f_m$。不幸的是，这要求低于谐振工作，导致输出电压动态范围减小和失去零电压开关性质的倾向。串联、并联和 LCC 槽电路的输入阻抗如图22.34所示。

一个遗留问题是 $\|Z_i(j\omega_s)\|$ 在开路和短路之间的中间负载值下如何表现。答案由以下定理22.1给出：$\|Z_i(j\omega_s)\|$ 随 $R$ 单调变化，故由 $\|Z_{i0}(j\omega_s)\|$ 和 $\|Z_{i\infty}(j\omega_s)\|$ 界定。因此极限情形 $\|Z_{i0}(j\omega_s)\|$ 和 $\|Z_{i\infty}(j\omega_s)\|$ 的波特图提供对所有 $R$ 的 $\|Z_i\|$ 行为的正确定性理解。定理对无损耗槽网络有效。

**定理 22.1** 若槽网络为纯电抗，则其输入阻抗 $\|Z_i\|$ 是负载电阻 $R$ 的单调函数。

此定理用 Middlebrook 额外元件定理（见第16章）证明。槽网络输入阻抗 $Z_i(s)$ 可表示为负载电阻 $R$ 和槽网络驱动点阻抗的函数：

$$Z_i(s) = Z_{i0}(s)\, \frac{\left( 1 + \dfrac{R}{Z_{o0}(s)} \right)}{\left( 1 + \dfrac{R}{Z_{o\infty}(s)} \right)} = Z_{i\infty}(s)\, \frac{\left( 1 + \dfrac{Z_{o0}(s)}{R} \right)}{\left( 1 + \dfrac{Z_{o\infty}(s)}{R} \right)} \tag{22.47}$$

$$\|Z_i\|^2 = Z_i\, Z_i^* = \frac{Z_{i0}(s)\, Z_{i0}^*(s)\left( 1 + \dfrac{R}{Z_{o0}(s)} \right)\left( 1 + \dfrac{R}{Z_{o0}^*(s)} \right)}{\left( 1 + \dfrac{R}{Z_{o\infty}(s)} \right)\left( 1 + \dfrac{R}{Z_{o\infty}^*(s)} \right)} = \|Z_{i0}\|^2\, \frac{\left( 1 + \dfrac{R^2}{\|Z_{o0}\|^2} \right)}{\left( 1 + \dfrac{R^2}{\|Z_{o\infty}\|^2} \right)} \tag{22.48}$$

其中 $Z_i^*$ 是 $Z_i$ 的复共轭。

接下来对式(22.48)关于 $R$ 求导：

$$\frac{d\, \|Z_i\|^2}{dR} = \frac{2 R\, \|Z_{i0}\|^2\left( \dfrac{1}{\|Z_{o0}\|^2} - \dfrac{1}{\|Z_{o\infty}\|^2} \right)}{\left( 1 + \dfrac{R^2}{\|Z_{o\infty}\|^2} \right)^2} \tag{22.49}$$

导数的根在 (i) $R = 0$、(ii) $R = \infty$ 以及特殊情况 (iii) $\|Z_{i0}\| = \|Z_{i\infty}\|$。由于导数在其他情况下非零，谐振网络输入阻抗 $\|Z_i\|$ 在 $0 < R < \infty$ 范围内是 $R$ 的单调函数。特殊情况 (iii) 中 $\|Z_i\|$ 与 $R$ 无关。因此定理22.1得证。

### 22.4.3 ZVS/ZCS 边界对负载电阻的依赖

还需确定 ZVS 与 ZCS 边界处的临界负载电阻 $R = R_{crit}$。此边界也可表示为 $Z_{i0}$ 和 $Z_{i\infty}$ 的函数。如22.3节讨论，零电压开关发生在开关电流 $i_s(t)$ 滞后于开关电压 $v_s(t)$ 时。零电流开关发生在 $i_s(t)$ 超前 $v_s(t)$ 时。此定义忽略半导体输出电容影响，故给出近似 ZVS/ZCS 边界。开关电流与开关电压之间的相位再次由槽网络输入阻抗确定：

$$i_{s1}(j\omega_s) = \frac{v_{s1}(j\omega_s)}{Z_i(j\omega_s)} \tag{22.53}$$

故 $Z_i(j\omega_s)$ 为感性时发生零电压开关，$Z_i(j\omega_s)$ 为容性时发生零电流开关，ZVS/ZCS 边界发生在 $Z_i(j\omega_s)$ 相位为零处。

再次考虑短路和开路负载的极限情形。LCC 逆变器示例的 $Z_{i0}(j\omega_s)$ 和 $Z_{i\infty}(j\omega_s)$ 波特图如图22.37。这些极限情形中，输入阻抗 $Z_i$ 仅由电抗槽元件组成，$Z_{i0}(j\omega_s)$ 和 $Z_{i\infty}(j\omega_s)$ 是相位为 $-90°$ 或 $+90°$ 的纯虚量。$f_s < f_0$ 时，$Z_{i0}(j\omega_s)$ 和 $Z_{i\infty}(j\omega_s)$ 均由槽电容主导；故 $Z_i(j\omega_s)$ 相位为 $-90°$。故短路和开路条件下均获得零电流开关。$f_s > f_\infty$ 时，$Z_{i0}(j\omega_s)$ 和 $Z_{i\infty}(j\omega_s)$ 均由槽电感主导；故 $Z_i(j\omega_s)$ 相位为 $+90°$。短路和开路负载下均获得零电压开关。$f_0 < f_s < f_\infty$ 时，$Z_{i0}(j\omega_s)$ 由槽电感主导而 $Z_{i\infty}(j\omega_s)$ 由槽电容主导。这意味着短路条件下获得零电压开关，开路条件下获得零电压开关。此情形下，必有某临界负载电阻值 $R = R_{crit}$ 代表 ZVS 与 ZCS 的边界，使 $Z_i(j\omega_s)$ 相位等于 $0°$。

图22.37 用输入阻抗 $Z_{i0}$ 和 $Z_{i\infty}$ 确定 ZCS/ZVS 边界，LCC 示例

![源页 p.963](../assets/page-snapshots/chapter-22/page-963.png)

非零有限 $R$ 时 $Z_i(j\omega_s)$ 的行为可从上述极限情形外推。以下定理22.2表明：

1. 若开路负载和短路负载均发生零电流开关（即 $Z_{i0}(j\omega_s)$ 和 $Z_{i\infty}(j\omega_s)$ 相位均为 $+90°$），则对所有负载发生零电流开关。

2. 若开路负载和短路负载均发生零电压开关（即 $Z_{i0}(j\omega_s)$ 和 $Z_{i\infty}(j\omega_s)$ 相位均为 $-90°$），则对所有负载发生零电压开关。

3. 若开路负载发生零电压开关、短路负载发生零电流开关（即 $Z_{i0}(j\omega_s)$ 相位为 $-90°$、$Z_{i\infty}(j\omega_s)$ 相位为 $+90°$），则 $R > R_{crit}$ 时发生零电压开关、$R < R_{crit}$ 时发生零电流开关，$R_{crit}$ 由式(22.54)给出。

4. 若开路负载发生零电流开关、短路负载发生零电压开关（即 $Z_{i0}(j\omega_s)$ 相位为 $+90°$、$Z_{i\infty}(j\omega_s)$ 相位为 $-90°$），则 $R > R_{crit}$ 时发生零电流开关、$R < R_{crit}$ 时发生零电压开关，$R_{crit}$ 由式(22.54)给出。

对 LCC 示例，可结论：$f_s < f_0$ 时对所有 $R$ 值发生零电流开关。$f_s > f_\infty$ 时对所有 $R$ 值发生零电压开关。$f_0 < f_s < f_\infty$ 时，ZVS 与 ZCS 的边界由式(22.54)给出。

**定理 22.2** 若槽网络为纯电抗，则零电流开关与零电压开关的边界发生在负载电阻 $R$ 等于临界值 $R_{crit}$ 时，$R_{crit}$ 为

$$R_{crit} = \|Z_{o0}\|\, \sqrt{\frac{-Z_{i\infty}}{Z_{i0}}} \tag{22.54}$$

此定理依赖于槽输入阻抗为容性时发生零电流开关、感性时发生零电压开关的假设。边界发生在 $Z_i(j\omega)$ 相位为零处。此定义在存在显著半导体输出电容时给出零电压开关的必要非充分条件。

结果通过求使式(22.47)中 $Z_i(j\omega)$ 虚部为零的 $R$ 值导出。由于假设槽网络理想无损耗，$Z_{o\infty}$、$Z_{o0}$、$Z_{i\infty}$ 实部必须为零。故

$$\text{Im}(Z_i(R_{crit})) = \text{Im}(Z_{i\infty})\, \text{Re}\left( \frac{1 + \dfrac{Z_{o0}}{R_{crit}}}{1 + \dfrac{Z_{o\infty}}{R_{crit}}} \right) = \text{Im}(Z_{i\infty})\left( 1 - \frac{Z_{o0}\, Z_{o\infty}}{R_{crit}^2} \right) \left/ \left( 1 + \frac{\|Z_{o\infty}\|^2}{R_{crit}^2} \right) \right. = 0 \tag{22.55}$$

![源页 p.964](../assets/page-snapshots/chapter-22/page-964.png)

其中 $\text{Im}(Z)$ 和 $\text{Re}(Z)$ 表示复量 $Z$ 的虚部和实部。式(22.55)的非平凡解为

$$1 = \frac{Z_{o0}\, Z_{o\infty}}{R_{crit}^2} \tag{22.56}$$

故

$$R_{crit} = \sqrt{Z_{o0}\, Z_{o\infty}} \tag{22.57}$$

利用互易恒等式

$$\frac{Z_{o0}}{Z_{o\infty}} = \frac{Z_{i0}}{Z_{i\infty}} \tag{22.58}$$

用式(22.58)从式(22.57)消去 $Z_{o\infty}$ 得

$$R_{crit} = \|Z_{o0}\|\, \sqrt{\frac{-Z_{i\infty}}{Z_{i0}}} \tag{22.59}$$

此即所需结果。$Z_{o0}$ 是逆变器输出阻抗，$R = \|Z_{o0}\|$ 对应最大输出功率的匹配负载工作。$Z_{i\infty}$ 和 $Z_{i0}$ 为纯虚，故式(22.59)除非 $Z_{i\infty}$ 和 $Z_{i0}$ 相位相反否则无实数解。如图22.37所示，若给定频率下 $Z_{i\infty}$ 和 $Z_{i0}$ 均为感性，则对所有负载发生零电压开关。$Z_{i\infty}$ 和 $Z_{i0}$ 均为容性时对所有负载发生零电流开关。因此定理22.2得证。

图22.38(a)说明了 LCC 逆变器 $R$ 从 0 变到 $\infty$ 时 $Z_i(j\omega)$ 的相位响应。图22.38(b)说明了 $R_{crit}$ 和匹配负载阻抗 $\|Z_{o0}\|$ 对频率的典型依赖。$f > f_\infty$ 时对所有负载发生零电压开关，$f < f_0$ 时对所有负载发生零电流开关。$f_0 < f < f_\infty$ 范围内，$Z_{i0}$ 感性而 $Z_{i\infty}$ 容性；故 $R < R_{crit}$ 时发生零电压开关、$R > R_{crit}$ 时发生零电流开关。频率 $f_m$ 处 $R_{crit} = \|Z_{o0}\|$，故 ZVS/ZCS 边界恰在匹配负载处遇到。通常期望在匹配负载处获得零电压开关，轻载时循环电流小效率好。显然这要求在 $f_0 < f < f_m$ 范围内工作。则在匹配负载和短路条件下获得零电压开关，但轻载时失去。选 $\|Z_{i0}\| \ll \|Z_{i\infty}\|$ 的元件值有利于使导致零电压开关的负载范围最大化。

### 22.4.4 另一示例

作为另一示例，考虑选择谐振槽元件以在给定开关频率下获得给定输出特性，并评估此选择对 $R_{crit}$ 的影响。期望在开关频率 $f_s = 100\,\text{kHz}$、输入电压 $V_g = 160\,\text{V}$ 下运行谐振逆变器。变换器应能产生开路峰值输出电压 $V_{oc} = 400\,\text{V}$，并在 25 W 下产生 150 Vrms 标称输出。期望选择实现此目标的谐振槽元件。

![源页 p.966](../assets/page-snapshots/chapter-22/page-966.png)

指标意味着变换器应具有开路传递函数

$$\|H_\infty(j\omega_s)\| = \frac{V_{oc}}{V_{s1}} = (400\,\text{V})\left( \frac{4}{\pi\, 160\,\text{V}} \right) = 1.96 \tag{22.60}$$

所需短路电流由式(22.42)解 $I_{sc}$ 求得：

$$I_{sc} = I\, \sqrt{1 - \left( \frac{V}{V_{oc}} \right)^2} \tag{22.61}$$

指标还意味着标称工作点处峰值电压和电流为

$$V = 150\sqrt{2} = 212\,\text{V}$$

$$I = \frac{P}{V_{rms}}\, \sqrt{2} = \frac{25\,\text{W}}{150\,\text{V}}\, \sqrt{2} = 0.236\,\text{A} \tag{22.62}$$

$$R_{nom} = \frac{V}{I} = 900\,\Omega$$

$$\|Z_{o0}(j\omega_s)\| = \frac{V_{oc}}{I_{sc}} = 1439\,\Omega$$

$$f_m = 100.6\,\text{kHz}$$

$$f_s = 100.0\,\text{kHz}$$

$$f_0 = 64\,\text{kHz} \tag{22.73}$$

负载短路时槽输入阻抗 $Z_{i0}$ 和负载开路时 $Z_{i\infty}$ 如图22.41。短路条件下槽谐振频率为

$$f_0 = \frac{1}{2\pi\sqrt{L_s C}} \tag{22.77}$$

开路条件下槽谐振频率为

$$f_\infty = \frac{1}{2\pi\sqrt{(L_s + L_p) C}} \tag{22.78}$$

每种情形下，槽输入阻抗 $Z_i$ 都是串联谐振电路，短路谐振频率高于开路谐振频率。槽输入阻抗 $\|Z_i\|$ 构造于图22.42。

低开关频率 $f_s < f_\infty$ 时，晶体管对所有负载零电流开关工作。高开关频率 $f_s > f_0$ 时，晶体管对所有负载零电压开关工作。中间频率范围 $f_\infty < f_s < f_0$ 内，晶体管轻载 $R > R_{crit}$ 时零电压开关工作、重载 $R < R_{crit}$ 时零电流开关工作。临界电阻 $R_{crit}$ 可证为

$$R_{crit} = \frac{R_{o0}}{n F}\, \sqrt{1 + n}\, \sqrt{\frac{1 - F^2}{1 + n}\, F^2 - 1} \tag{22.79}$$
