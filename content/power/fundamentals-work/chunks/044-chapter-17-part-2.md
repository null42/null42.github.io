# 第17章 输入滤波器设计（第2部分）

## 17.4 阻尼输入滤波器设计（续）

### 17.4.1 $R_f$-$C_b$ 并联阻尼（续）

![源页 p.698](../assets/page-snapshots/chapter-17/page-698.png)

图17.24 最优并联 $R_f$-$L_b$ 阻尼与无阻尼及若干次优设计的输出阻抗曲线比较。此例 $n = L_b/L = 0.516$

对此滤波器，定义量 $n$ 为阻塞电容 $C_b$ 与滤波电容 $C_f$ 之比：

$$n = \frac{C_b}{C_f} \tag{17.33}$$

最优设计中峰值滤波器输出阻抗出现在频率

$$f_m = \frac{f_f}{\sqrt{\dfrac{2}{2+n}}} \tag{17.34}$$

最优设计峰值输出阻抗值为

$$\|Z_o\|_{mm} = R_{0f}\sqrt{\frac{2}{(2+n)n}} \tag{17.35}$$

导致最优阻尼的阻尼电阻值由下式描述

$$Q_{opt} = \frac{R_f}{R_{0f}} = \sqrt{\frac{(2+n)(4+3n)}{2n^2(4+n)}} \tag{17.36}$$

上述方程允许选择阻尼值 $R_f$ 和 $C_b$。

例如让我们重新设计 17.3.2 节的阻尼网络，在最小化阻塞电容 $C_b$ 值的同时达到相同峰值输出阻抗 $\|Z_o(j\omega)\|_{mm} = 1\,\Omega$。由 17.3.2 节其他参数值为 $R_{0f} = 0.84\,\Omega$、$C_f = 470\,\mu\text{F}$、$L_f = 330\,\mu\text{H}$。先解式 (17.35) 求所需 $n$ 值：

![源页 p.699](../assets/page-snapshots/chapter-17/page-699.png)

图17.25 最优并联 $R_f$-$C_b$ 阻尼设计与 17.3.2 节次优设计及原始无阻尼滤波器输出阻抗比较

$$n = \frac{R_{0f}^2}{\|Z_o\|_{mm}^2}\left(1+\sqrt{1+\frac{4\|Z_o\|_{mm}^2}{R_{0f}^2}}\right) \tag{17.37}$$

用给定数值评估此式得 $n = 2.5$。故阻塞电容需值为 $nC_f = 1200\,\mu\text{F}$。这是 17.3.2 节所用值的四分之一。然后由式 (17.36) 求 $R_f$ 值得

$$R_f = R_{0f}\sqrt{\frac{(2+n)(4+3n)}{2n^2(4+n)}} = 0.67\,\Omega \tag{17.38}$$

此滤波器设计的输出阻抗与 17.3.1 节原始无阻尼滤波器及 17.3.2 节次优设计的输出阻抗比较如图17.25所示。可见最优阻尼滤波器确实在式 (17.34) 给出的略低峰值频率处达到所需 1 Ω 峰值输出阻抗。

$R_f$-$C_b$ 并联阻尼方法在直流-直流变换器中有重要应用。由于串联电阻与 $C_b$ 串联，$C_b$ 可用含显著等效串联电阻的电容类型如电解和钽电容实现。但在某些应用中，下一小节的 $R_f$-$L_b$ 方法可导致更小设计。此外，大阻塞电容值在有交流输入的应用中可能不理想。

### 17.4.2 $R_f$-$L_b$ 并联阻尼

图17.23b 给出阻尼电阻 $R_f$ 与电感 $L_f$ 并联的放置。电感 $L_b$ 使滤波器高频呈现双极点衰减特性。为允许 $R_f$ 阻尼滤波器，电感 $L_b$ 在滤波器谐振频率 $f_f$ 处阻抗幅值应充分小于 $R_f$。此阻尼网络优化见 [158]。

![源页 p.700](../assets/page-snapshots/chapter-17/page-700.png)

图17.26 图17.23b 并联 $R_f$-$L_b$ 电路最优设计步骤所得性能。最优峰值滤波器输出阻抗 $\|Z_o\|_{mm}$ 和滤波器高频增益增大对 $n = L_b/L_f$ 的关系

此方法中电感 $L_b$ 物理上可远小于 $L_f$。由于 $R_f$ 通常远大于 $L_f$ 直流电阻，基本无直流电流流过 $L_b$。此外 $R_f$ 可在滤波器谐振频率 $f_f$ 处实现为 $L_b$ 的等效串联电阻。故这是阻尼输入滤波器的非常简单、低成本方法。

此方法的缺点是滤波器高频衰减退化：滤波器传递函数高频渐近线从 $1/\omega^2 L_f C_f$ 增大到 $1/\omega^2(L_f\,\|\,L_b)C_f$。由于阻尼需要限制 $L_b$ 最大值，高频衰减的显著损失不可避免。为补偿须增大 $L_f$ 值。故阻尼与高频衰减退化之间存在折中，如图17.26所示。例如将高频衰减退化限制在 6 dB 导致最优峰值滤波器输出阻抗 $\|Z_o\|_{mm}$ 为原始特性阻抗 $R_{0f}$ 的 $\sqrt{6}$ 倍。附加阻尼导致高频衰减进一步退化。

最优阻尼设计（即给定 $L_b$ 选择下使峰值输出阻抗 $\|Z_o\|$ 最小的 $R_f$ 选择）由以下方程描述：

$$Q_{opt} = \frac{R_f}{R_{0f}} = \sqrt{\frac{n(3+4n)(1+2n)}{2(1+4n)}} \tag{17.39}$$

其中

$$n = \frac{L_b}{L_f} \tag{17.40}$$

峰值滤波器输出阻抗出现在频率

$$f_m = f_f\sqrt{\frac{1+2n}{2n}} \tag{17.41}$$

值为

$$\|Z_o\|_{mm} = R_{0f}\sqrt{2n(1+2n)} \tag{17.42}$$

滤波器高频渐近线衰减退化因子为

$$\frac{L_f}{L_f\,\|\,L_b} = 1+\frac{1}{n} \tag{17.43}$$

故给定转折频率 $f_f$、特性阻抗 $R_{0f}$ 的无阻尼 $L_f$-$C_f$ 滤波器和最大允许输出阻抗 $\|Z_o\|_{mm}$ 要求后，可解式 (17.42) 求所需 $n$ 值。然后确定 $L_b$ 和 $R_f$ 的数值。

### 17.4.3 $R_f$-$L_b$ 串联阻尼

图17.23c 给出阻尼电阻 $R_f$ 与电感 $L_f$ 串联的放置。电感 $L_b$ 提供直流旁路以避免 $R_f$ 中显著功耗。为允许 $R_f$ 阻尼滤波器，电感 $L_b$ 在滤波器谐振频率处阻抗幅值应充分大于 $R_f$。

虽然此电路理论上与 17.4.2 节并联阻尼 $R_f$-$L_b$ 情形等价，但实际设计中有若干差异。两个电感都须承载全部直流电流，故两者尺寸显著。滤波器高频衰减不受 $L_b$ 选择影响，高频渐近线与原始无阻尼滤波器相同。此滤波器设计的折中不涉及高频衰减；而是阻尼与旁路电感尺寸的问题。

可为情形导出与前几节类似的设计方程。最优峰值滤波器输出阻抗出现在频率

$$f_m = f_f\sqrt{\frac{2+n}{2(1+n)}} \tag{17.44}$$

值为

$$\|Z_o\|_{mm} = R_{0f}\sqrt{\frac{2(1+n)(2+n)}{n}} \tag{17.45}$$

导致最优阻尼的阻尼电阻值由下式描述

$$Q_{opt} = \frac{R_{0f}}{R_f} = \left(\frac{1+n}{n}\right)\sqrt{\frac{2(1+n)(4+n)}{(2+n)(4+3n)}} \tag{17.46}$$

此情形下峰值输出阻抗不能通过阻尼降到 $\sqrt{2}R_{0f}$ 以下。但可通过重新设计 $L_f$ 和 $C_f$ 减小 $R_{0f}$ 值进一步降低滤波器输出阻抗。

### 17.4.4 级联滤波节

多节 L-C 滤波级级联可用比单节 L-C 滤波器更小体积和重量达到给定高频衰减。多节滤波器增大的截止频率允许使用更小电感和电容值。通常需要阻尼每个 L-C 节，意味着每个节的阻尼应优化。不幸的是前几节结果限于单节滤波器。级联 L-C 节之间的相互作用可导致附加谐振和增大滤波器输出阻抗。

尽管如此，可设计级联滤波节使 L-C 节之间相互作用可忽略。在以下所述方法中，滤波器输出阻抗近似等于最后一节输出阻抗，避免了级间相互作用引起的谐振。虽然所得滤波器在任何意义上可能不"最优"，但可获得允许智能设计多节滤波器且每节经济阻尼的洞察。

![源页 p.702](../assets/page-snapshots/chapter-17/page-702.png)

图17.27 在现有滤波器输入端加入滤波节

考虑在现有滤波器输入端加入滤波节，如图17.27所示。设现有滤波器已正确设计满足式 (17.19) 输出阻抗设计准则：$Z_a(s) = 0$ 和 $\hat{v}_g(s) = 0$ 条件下 $\|Z_o\|$ 充分小。希望加入不显著增大 $\|Z_o\|$ 的阻尼滤波节。

可再次引用 16.1 节 Middlebrook 额外元件定理，表示加入滤波节如何修改 $Z_o(s)$：

$$Z_o(s) = \left(\left.Z_o(s)\right|_{Z_a(s)=0}\right)\frac{\left(1+\dfrac{Z_a(s)}{Z_{N1}(s)}\right)}{\left(1+\dfrac{Z_a(s)}{Z_{D1}(s)}\right)} \tag{17.47}$$

其中

$$Z_{N1}(s) = \left.Z_{i1}(s)\right|_{\hat{v}_{test}(s)\to\text{null} 0} \tag{17.48}$$

是现有滤波器输出端口短路时输入端口阻抗。注意此特定情形中置零 $\hat{v}_{test}(s)$ 与短路滤波器输出端口相同，因为短路电流流过 $\hat{i}_{test}$ 源。量

$$Z_{D1}(s) = \left.Z_{i1}(s)\right|_{\hat{i}_{test}(s)=0} \tag{17.49}$$

是现有滤波器输出端口开路时输入端口阻抗。故附加滤波节在以下条件满足时不显著改变 $Z_o$：

$$\|Z_a\| \ll \|Z_{N1}\| \quad \text{且} \quad \|Z_a\| \ll \|Z_{D1}\| \tag{17.50}$$

可解析或计算机仿真构造 $Z_{N1}$ 和 $Z_{D1}$ 波特图获得 $Z_a$ 限值。$\|Z_a\|$ 满足式 (17.50) 时校正因子 $(1+Z_a/Z_{N1})/(1+Z_a/Z_{D1})$ 近似为 1，修改后 $Z_o$ 近似等于原始 $Z_o$。

为满足设计准则 (17.50)，选 $Z_a$ 谐振频率不同于 $Z_{D1}$ 谐振频率有利。换句话说应错调谐滤波节。这最小化滤波节之间相互作用，可允许使用更小储能元件值。

### 17.4.5 示例：双节输入滤波器

作为示例，考虑使用每节 $R_f$-$L_b$ 并联阻尼的双节滤波器设计，如图17.28所示 [158]。希望达到 17.3.2 和17.4.1 节单节滤波器设计的相同衰减，并滤波图17.11 相同降压变换器示例的输入电流。这些滤波器在 250 kHz 处呈现 80 dB 衰减，满足式 (17.19) 设计不等式及图17.13 的 $\|Z_N\|$ 和 $\|Z_D\|$ 阻抗。故设计图17.28 滤波器在 250 kHz 处达到 80 dB 衰减。

![源页 p.703](../assets/page-snapshots/chapter-17/page-703.png)

图17.28 双节输入滤波器示例，每节采用 $R_f$-$L_b$ 并联阻尼

如上一节和下文所述，错调谐滤波节以减小滤波节之间相互作用有利。将发现滤波节 1 截止频率应选小于节 2 截止频率。结果节 1 衰减大于节 2。（稍任意地）设计从节 1 获得 45 dB 衰减，从节 2 获得 35 dB 衰减（总计为指定 80 dB）。还选每节 $n_1 = n_2 = n = L_b/L_f = 0.5$；如图17.26所示，此选择导致滤波谐振阻尼与高频滤波衰减退化之间的良好折中。式 (17.43) 和图17.26 预测 $R_f$-$L_b$ 阻尼网络将退化高频衰减因子 $(1+1/n) = 3$ 即 9.5 dB。故节 1 无阻尼谐振频率 $f_{f1}$ 应选为在 250 kHz 处产生 $45+9.5 = 54.5\text{ dB} \Rightarrow 533$ 衰减。由于节 1 高频呈双极点（−40 dB/十倍频程）滚降，$f_{f1}$ 应选为

$$f_{f1} = \frac{(250\text{ kHz})}{\sqrt{533}} = 10.8\text{ kHz} \tag{17.51}$$

注意此频率远高于降压变换器输出滤波器 1.6 kHz 谐振频率 $f_0$。故 $\|Z_o\|$ 可大到 3 Ω 仍远低于图17.13 的 $\|Z_N(j\omega)\|$ 和 $\|Z_D(j\omega)\|$ 图。

解式 (17.42) 求 $n = 0.5$ 时导致 3 Ω 峰值输出阻抗的所需节 1 特性阻抗得

$$R_{0f1} = \frac{\|Z_o\|_{mm}}{\sqrt{2n(1+2n)}} = \frac{3\,\Omega}{\sqrt{2(0.5)(1+2(0.5))}} = 2.12\,\Omega \tag{17.52}$$

故滤波电感和电容值为

$$L_1 = \frac{R_{0f1}}{2\pi f_{f1}} = 31.2\,\mu\text{H} \tag{17.53}$$

$$C_1 = \frac{1}{2\pi f_{f1} R_{0f1}} = 6.9\,\mu\text{F}$$

节 1 阻尼网络电感为

$$n_1 L_1 = 15.6\,\mu\text{H} \tag{17.54}$$

节 1 阻尼电阻由式 (17.39) 求得：

$$R_1 = Q_{opt}R_{0f1} = R_{0f1}\sqrt{\frac{n(3+4n)(1+2n)}{2(1+4n)}} = 1.9\,\Omega \tag{17.55}$$

峰值输出阻抗将出现在式 (17.41) 给出的频率 15.3 kHz 处。滤波节 1 的 $\|Z_{N1}(j\omega)\|$ 和 $\|Z_{D1}(j\omega)\|$ 现可解析构造或计算机仿真绘制。$\|Z_{N1}(j\omega)\|$ 是节 1 输出短路时节 1 输入阻抗 $Z_{i1}$，由 $sL_1$ 和 $(R_1+sn_1L_1)$ 支路并联组合给出。$\|Z_{D1}(j\omega)\|$ 是节 1 输出开路时节 1 输入阻抗 $Z_{i1}$，由 $Z_{N1}(s)$ 与电容阻抗 $1/sC_1$ 串联组合给出。图17.29 含用 SPICE 生成的滤波节 1 $\|Z_{N1}(j\omega)\|$ 和 $\|Z_{D1}(j\omega)\|$ 图。

![源页 p.705](../assets/page-snapshots/chapter-17/page-705.png)

图17.29 滤波节 1 的 $Z_{N1}$ 和 $Z_{D1}$ 波特图。还给出滤波节 2 输出阻抗 $Z_a$ 波特图

设计滤波节 2 的一种方法如下。为避免显著修改总滤波器输出阻抗 $Z_o$，节 2 输出阻抗 $\|Z_a(j\omega)\|$ 须充分小于 $\|Z_{N1}(j\omega)\|$ 和 $\|Z_{D1}(j\omega)\|$。由图17.29 可见对 $\|Z_{D1}(j\omega)\|$ 而言节 1 和 2 峰值频率重合时最难完成。节 2 峰值频率低于节 1 峰值频率时最难满足 $\|Z_{N1}(j\omega)\|$ 设计准则。故最佳选择是错调谐滤波节，节 1 谐振频率低于节 2 峰值频率。这意味着节 1 产生比节 2 更多高频衰减。为此我们选择节 1 达 45 dB 衰减、节 2 达 35 dB 衰减。

节 2 无阻尼谐振频率 $f_{f2}$ 应以与式 (17.51) 中节 1 相同方式选择。选 $n_2 = n = L_b/L_f = 0.5$；这再次意味着 $R_f$-$L_b$ 阻尼网络将退化高频衰减因子 $(1+1/n) = 3$ 即 9.5 dB。故节 2 无阻尼谐振频率 $f_{f2}$ 应选为在 250 kHz 处产生 $35+9.5 = 44.5\text{ dB} \Rightarrow 169$ 衰减。由于节 2 高频呈双极点滚降，$f_{f2}$ 应选为

$$f_{f2} = \frac{(250\text{ kHz})}{\sqrt{169}} = 19.25\text{ kHz} \tag{17.56}$$

节 2 输出阻抗将在式 (17.41) 给出的 27.2 kHz 处达峰。故节 1 和 2 峰值频率差约 2 倍。

![源页 p.706](../assets/page-snapshots/chapter-17/page-706.png)

图17.29 显示 27.2 kHz 处 $\|Z_{D1}(j\omega)\|$ 幅值约 3 dBΩ，$\|Z_{N1}(j\omega)\|$ 约 7 dBΩ。故设计节 2 峰值输出阻抗为 $0\text{ dBΩ} \Rightarrow 1\,\Omega$。解式 (17.42) 求所需节 2 特性阻抗得

$$R_{0f2} = \frac{\|Z_a\|_{mm}}{\sqrt{2n(1+2n)}} = \frac{1\,\Omega}{\sqrt{2(0.5)(1+2(0.5))}} = 0.71\,\Omega \tag{17.57}$$

故节 2 元件值为

$$L_2 = \frac{R_{0f2}}{2\pi f_{f2}} = 5.8\,\mu\text{H}$$

$$C_2 = \frac{1}{2\pi f_{f2} R_{0f2}} = 11.7\,\mu\text{F} \tag{17.58}$$

$$n_2 L_2 = 2.9\,\mu\text{H}$$

$$R_2 = Q_{opt}R_{0f2} = R_{0f2}\sqrt{\frac{n(3+4n)(1+2n)}{2(1+4n)}} = 0.65\,\Omega$$

所得 $Z_a$ 波特图叠加于图17.29。可见 $\|Z_a(j\omega)\|$ 在 15 kHz 和 27 kHz 峰值频率之间小于但非常接近 $\|Z_{D1}(j\omega)\|$。阻抗不等式 (17.50) 在 15 kHz 以下满足更好，高频满足非常好。

节 2 对 $\|Z_o(j\omega)\|$ 的影响在 40 kHz 以上非常小（此处不等式 (17.50) 非常好满足），低频影响中等偏小。有趣的是约 12 kHz 以上加入节 2 实际减小 $\|Z_o(j\omega)\|$。原因可从图16.8 看出：当 $\angle Z_a(j\omega)$ 和 $\angle Z_{D1}(j\omega)$ 相位差不太大（$\le 90°$）时，$1/(1+Z_a/Z_{D1})$ 项减小所得 $\|Z_o(j\omega)\|$ 的幅值。如图17.29 相位图所示确实如此。故允许 $\|Z_a(j\omega)\|$ 在 12 kHz 以上幅值与 $\|Z_{D1}(j\omega)\|$ 相似是可接受的设计选择。

## 17.5 稳定判据

前几节用 Middlebrook 额外元件定理获得加入输入滤波器如何改变变换器传递函数的洞察。17.2.3 节讨论的阻抗不等式给出如何整形滤波器输出阻抗使加入输入滤波器不显著改变变换器传递函数 $G_{vd}(s)$、$G_{vg}(s)$、$Z_{out}(s)$ 的洞察。故预期加入满足阻抗不等式的输入滤波器不改变设计良好的开关稳压器的稳定性。此意义上阻抗不等式可视为可能保守的设计准则。

17.2.3 节阻抗不等式本身不定义闭环系统稳定边界，因为这些不等式不依赖实际环路增益 $T(s)$。至今我们仅将额外元件定理应用于 $G_{vd}(s)$ 等开环传递函数。为确定含输入滤波器的闭环开关稳压器稳定性，需进一步研究变换器功率级传递函数的改变如何影响环路增益 $T(s)$ 的稳定性和相位裕度。

一种直接方法是绘制含式 (17.4) 修改 $G_{vd}(s)$ 的修改后环路增益，然后对结果应用常规稳定测试如相位裕度测试。也可绘制修改后 $G_{vg}(s)$ 和 $Z_{out}(s)$ 检查这些量是否继续满足设计目标。此方法在 17.5.1 节讨论。

第二种方法基于输入滤波器源阻抗 $Z_o(s)$ 与变换器闭环输入阻抗 $Z_i(s)$ 的比较 [151]。此方法用 $Z_o(s)$ 直接表示稳定边界。输入滤波器被 $Z_i(s)$ 加载导致分压项

$$\frac{Z_i}{Z_i+Z_o} \tag{17.59}$$

可含 RHP 极点，是稳定问题的起源。17.5.2 节含推导和示例。17.5.1 和17.5.2 节方法给出稳定边界的相同预测。

### 17.5.2 闭环输入阻抗

确定精确稳定边界的另一种有用方法基于闭环变换器输入阻抗 $Z_i(s)$ 对输入滤波器的加载。此加载导致分压项

$$\frac{Z_i(s)}{Z_i(s)+Z_o(s)} = \frac{1}{1+\dfrac{Z_o(s)}{Z_i(s)}} \tag{17.60}$$

向系统闭环传递函数引入新极点 [151]。这些新极点可能位于右半平面，这可视为加入输入滤波器使稳压器不稳定的机理。本节用额外元件定理导出输入滤波器如何将附加项 (17.60) 加到系统闭环传递函数；以闭环音频敏感度 $\hat{v}/\hat{v}_g$ 为例，但网络所有闭环传递函数含相同极点。其次用反馈定理求闭环输入阻抗 $Z_i(s)$ 表达式。最后通过将 $T_m(s) = Z_o(s)/Z_i(s)$ 视为可用奈奎斯特稳定定理和相位裕度测试等常规技巧确定稳定性的小环路增益来检验式 (17.60) 的稳定性。

![源页 p.714](../assets/page-snapshots/chapter-17/page-714.png)

图17.40 含输入滤波器的闭环变换器系统小信号模型

图17.40 给出由 CCM 开关变换器、其反馈系统和输入滤波器组成的系统小信号模型。输入滤波器输出端口用戴维南等效电路建模，含输出阻抗 $Z_o$。无载输入滤波器传递函数为 $H_i(s)$，施加到输入滤波器输入端口的电压为 $v_g$。变换器功率级用 7.4 节规范模型建模。补偿器和 PWM 传递函数合并为增益块 $A(s)$。

无输入滤波器情形 $Z_o(s) = 0$ 且 $H_i(s) = 1$。此条件下可用反馈定理以与 13.4 节类似方式求"原始"闭环传递函数。"原始"环路增益求得为

$$T(s) = A(s)e(s)MH_e(s)H(s) \tag{17.61}$$

"原始"音频敏感度为

$$G_{vg}(s) = \frac{MH_e(s)}{1+T(s)} \tag{17.62}$$

与式 (13.103) 一致。输入滤波器存在时额外元件定理预测音频敏感度变为

$$G'_{vg}(s) = H_i(s)G_{vg}(s)\frac{1}{1+\dfrac{Z_o}{Z_{Ng}}\cdot\frac{1}{1+\dfrac{Z_o}{Z_{Dg}}}} \tag{17.63}$$

![源页 p.715](../assets/page-snapshots/chapter-17/page-715.png)

图17.41 用额外元件定理求修改后 $G'_{vg}(s)$

图17.41 说明用额外元件定理求修改后音频敏感度 $G'_{vg}(s)$。戴维南阻抗 $Z_o(s)$ 视为额外元件，在 $Z_o$ 端口注入电流 $\hat{i}_t$。

阻抗 $Z_{Ng}$ 是 $\hat{i}_t$ 和 $\hat{v}_{in}$ 调整使输出电压 $\hat{v}$ 置零时注入端口看到的阻抗。参考变化 $\hat{v}_{ref}$ 也设为零：

$$Z_{Ng} = \left.\frac{\hat{v}_t}{\hat{i}_t}\right|_{\hat{v}\to\text{null} 0,\,\hat{v}_{ref}=0} \tag{17.64}$$

$\hat{v}$ 置零且 $\hat{v}_{ref}$ 设为零时占空比变化 $\hat{d}$ 也为零。故 $e(s)\hat{d}$ 和 $j(s)\hat{d}$ 源为零。此外 $\hat{v}$ 置零条件导致负载和 $C$、$L_e$ 元件中零电流变化，故变压器绕组两端无电压且无电流流过变压器绕组。故置零条件意味着 $\hat{i}_t = 0$ 且 $\hat{v}_t = -H_i\hat{v}_{in}$。因此 $Z_{Ng}$ 为

$$Z_{Ng} = \frac{-H_i\hat{v}_{in}}{0} = \infty \tag{17.65}$$

$Z_{Ng}$ 为开路，式 (17.63) 校正因子分子项等于 $(1+0) = 1$。

阻抗 $Z_{Dg}$ 是 $\hat{v}_{in}$ 和 $\hat{v}_{ref}$ 设为零时注入端口看到的阻抗：

$$Z_{Dg} = \left.\frac{\hat{v}_t}{\hat{i}_t}\right|_{\hat{v}_{in}=0,\,\hat{v}_{ref}=0} \tag{17.66}$$

量 $Z_{Dg}$ 即稳压器的闭环输入阻抗 $Z_i$。故式 (17.63) 中闭环音频敏感度为

$$G'_{vg}(s) = H_i(s)G_{vg}(s)\frac{1}{1+\dfrac{Z_o}{Z_i}} \tag{17.67}$$

类似分析可证修改后闭环输出阻抗含相同校正因子分母项 [151]。

加入输入滤波器如何导致稳定闭环稳压器不稳定（即闭环传递函数极点在复平面右半部分）？式 (17.67) 中量 $G_{vg}(s)$ 是原始稳压器的闭环音频敏感度；假定原始稳压器正确设计使 $G_{vg}(s)$ 稳定且不含右半平面极点。量 $H_i$ 是滤波器无载传递函数，假定也不含右半平面极点因为滤波器是无源网络。故唯一可能导致不稳定的项是分母校正因子项

$$\frac{1}{1+\dfrac{Z_o}{Z_i}} = \frac{1}{(1+T_m)} \tag{17.68}$$

式 (17.68) 中的项是加入输入滤波器引起潜在不稳定的起源。分母校正因子项取与闭环传递函数相同的数学形式，有效"小环路增益"为 $T_m = Z_o/Z_i$，$(1+T_m)$ 项可能含右半平面根。故可对 $T_m$ 应用奈奎斯特稳定判据或相位裕度测试等通常稳定测试。

**求闭环输入导纳 $Y_i = 1/Z_{Dg}$**

可如图17.42所示应用第13章反馈定理。测试源 $\hat{v}_t$ 注入小信号模型功率输入端口，测量变换器输入电流 $\hat{i}_t$。输入导纳是从 $\hat{v}_t$ 到 $\hat{i}_t$ 的传递函数：

$$Y_i = \frac{\hat{i}_t}{\hat{v}_t} \tag{17.69}$$

![源页 p.717](../assets/page-snapshots/chapter-17/page-717.png)

图17.42 用反馈定理求闭环输入导纳 $Y_i = 1/Z_{Dg}$

为确定闭环 $Y_i$，在求和节点后注入源 $\hat{v}_z$，用反馈定理将 $Y_i$ 表示为

$$Y_i = Y_{i\infty}\frac{T}{1+T} + Y_{i0}\frac{1}{1+T} \tag{17.70}$$

增益 $Y_{i\infty}$ 为

$$Y_{i\infty}(s) = \left.\frac{\hat{i}_t(s)}{\hat{v}_t(s)}\right|_{\hat{v}_{ref}=0,\,\hat{v}_y\to\text{null} 0} \tag{17.71}$$

环路参考变化 $\hat{v}_{ref}$ 设为零。测试源 $\hat{v}_t$ 存在下调整 $\hat{v}_z$ 置零 $\hat{v}_y$。图17.43 说明此条件下模型的求解。

参考 $\hat{v}_{ref}$ 设为零时置零 $\hat{v}_y$ 意味着输出电压 $\hat{v}$ 也置零。故负载电阻 $R$ 中电流置零。故有效滤波元件中电流置零，变压器二次侧必无电压。这意味着变压器一次侧无电压，$e(s)\hat{d}$ 源中无电流。故置零条件下测试电压必为 $\hat{v}_t = -e(s)\hat{d}$，测试电流必为 $\hat{i}_t = j(s)\hat{d}$。这导致结果

$$Y_{i\infty} = \frac{j(s)\hat{d}}{-e(s)\hat{d}} = -\frac{j(s)}{e(s)} \tag{17.72}$$

对降压变换器此表达式简化为

$$Y_{i\infty} = -\frac{M^2}{R} \tag{17.73}$$
