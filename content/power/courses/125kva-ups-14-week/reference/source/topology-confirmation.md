## 2. 系统基本信息

- 单个 UPS 功率模块额定容量为 125 kVA；
- 单模块包含整流、直流变换、分裂母线、中点平衡、逆变和控制部分；
- 目标 DSP 为 TMS320F28075；
- 本阶段只分析单个 125 kVA 模块内部拓扑，不分析机架级多模块并联。

## 3. 直流母线与中性线

统一定义：

- `P`：逆变侧正直流母线；
- `O`：直流母线中点；
- `M`：逆变侧负直流母线；
- `BAT+`：整流输出与电池正端；
- `BAT-`：整流输出与电池负端。

已经确认：

```text
O = mN = OutN
```

蓝色中性线与上下母线电容中点为实际电气连接。

`REC_12P` 和 `INV_12P` 均表示母线电容。图中整流区域和逆变区域竖着画出的两条母线在理想拓扑中属于同一电气节点，可以合并分析。

因此整流区域和逆变区域的同极性母线满足：

```text
P_REC = P_INV = P
O_REC = O_INV = O
M_REC = M_INV = M
```

不同位置的母线电容是物理上分散布置、电气上并联的电容组。参数设计时需要分别考虑母排阻抗和纹波电流分配，理想拓扑推导时可以合并为等效电容。

## 4. 两套维也纳整流器

图中上下两套整流单元均为标准三相维也纳整流器，并且交流侧和直流侧均并联。

第一套整流器：

```text
正直流端 = BAT+
双向开关公共端 = O
负直流端 = BAT-
```

第二套整流器：

```text
正直流端 = BAT+
双向开关公共端 = O
负直流端 = BAT-
```

因此：

```text
R1+ = R2+ = BAT+
R1O = R2O = O
R1- = R2- = BAT-
```

两套整流器分别具有独立的三相输入电感、功率器件和驱动信号。每相可以定义：

```text
i_gx = i_1x + i_2x
i_Δx = i_1x - i_2x
```

主电路能够确认两套整流器并联，但不能确认控制程序是否采用载波移相交错，也不能确认移相角是否为 180°。

此前关于“上下整流单元直流侧分别连接不同电池端，形成交叉耦合”的判断无效，不得继续使用。

## 5. 主动中点平衡电路

中点平衡电路确定为一个半桥和一个平衡电感：

```text
P ── 上管组 ── Xb ── 下管组 ── M
                 │
                 Lb
                 │
                 O
```

即：

```text
上管组上端接 P
上管组下端接 Xb
下管组上端接 Xb
下管组下端接 M
Xb 经 Lb 接 O
```

上管组和下管组中的每只功率管都有单独的驱动信号。课程必须区分独立驱动通道、同步门极命令、并联器件均流和单管故障退出。

## 6. 两套 T 型三电平逆变器

两套逆变器均为相同结构的 T 型三电平逆变器。

每相纵向主管连接：

```text
P ── 上主管 ── 相开关节点 X ── 下主管 ── M
```

横向辅管连接：

```text
O ── 辅助双向开关 ── X
```

逆变侧横向辅管公共端确定与中点 `O` 实际连接。

每相两只辅管的准确结构为：

- 反并联二极管背向；
- 共发射极连接；
- 两只器件组成一个主动双向开关。

原图中上半逆变器辅管画成二极管相向属于绘图错误。上下两套逆变器都必须按二极管背向、共发射极结构分析和建模。

两套逆变器各自经过独立三相输出电感后并联到公共 `U/V/W` 输出。主电路能够确认并联，但不能确认实际控制是否采用载波移相交错，也不能确认移相角是否为 180°。

此前关于“上下两套逆变器可能采用不同的共发射极和共集电极实现”的判断无效，不得继续使用。

## 7. 三开关双电感直流支路

目前只确认连接和二极管方向，不确认其正式名称、完整功率流和实际控制模式。

节点连接：

```text
BAT+ ── L+ ── XP ── SP ── P
                    │
                    S0
                    │
BAT- ── L- ── XN ── SM ── M
```

中管 `S0` 连接 `XP` 与 `XN`。

反并联二极管正向方向：

```text
DP：XP → P
D0：XN → XP
DM：M → XN
```

三个门极共有八种逻辑组合。`SP=S0=SM=1` 会建立 `P-SP-S0-SM-M` 的直通路径，属于明确禁止状态。

在获得控制代码、PWM波形或项目说明之前，课程中统一称为“三开关双电感直流支路”，不提前命名为充电器、双向升降压变换器或逆变母线主变换器。

## 8. 尚未确认事项

以下事项不能从主电路图直接得出，项目组前辈本次也未确认：

1. 两套维也纳整流器是否采用载波移相交错；
2. 两套 T 型逆变器是否采用载波移相交错；
3. 如果采用交错，实际移相角是否为 180°；
4. 三开关双电感直流支路的正式名称；
5. 该直流支路在市电、充电、电池放电和旁路模式下的准确功率流；
6. `SP、S0、SM` 的正常门极序列和调制方法；
7. 中点平衡电路中多只功率管是否同步开关、交错开关或支持部分器件退出；
8. 输入电压、输出电压、母线电压、电池电压、开关频率和额定支路电流。

这些内容后续通过控制代码、PWM配置、实测波形、器件网络名或进一步咨询确认。确认前，课程必须分别分析可能方案，不把其中一种写成产品事实。

## 9. 后续课程使用原则

- 标准维也纳整流器先按单机拓扑完整推导，再扩展到两机并联；
- 标准 T 型三电平逆变器统一采用二极管背向、共发射极辅管结构；
- 并联结构与交错控制分开讲解；
- 三开关双电感支路先按已知连接枚举状态，不提前绑定运行模式；
- 所有正式拓扑图以原图为依据，对原图错误进行显式修正并保留说明；
- 新资料与本文冲突时，先修订本文，再修改课程和仿真模型。
