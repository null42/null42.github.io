# MATLAB通用脚本

本目录包含功率不变Clarke/Park自检、PI离散化、PWM采样时序、参数集、无源器件设计和半导体损耗教学脚本。所有参数均为教学示例，不代表125 kVA产品规格。运行绘图脚本时，结果自动保存到`simulations/matlab/results/`并保持图窗打开。
