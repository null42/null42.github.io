# 中点平衡与直流支路

`balancer_control.slx`是平衡电感平均通道。`dc_branch_gate_matrix.m`只给出八组合安全分类：`SP=S0=SM=1`为直流母线直通，其余状态仍需电流方向和产品证据，不赋予充电或放电名称。
