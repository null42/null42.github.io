# T型模型

`ttype_state_table.m`只把P=`1000`、O=`0110`、N=`0001`作为教学允许状态，其余组合标记为禁止或未受控。`.slx`模型用于输出电感和差流平均通道，主管、辅管和二极管换流必须在PSIM规范中逐状态验证。
