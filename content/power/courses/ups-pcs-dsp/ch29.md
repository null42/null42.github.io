**本章要解决的问题：** 系统里所有控制（第14章的 dq、第24~27章的提取、第30章的切换）都需要一个可信的 θ 与 f。本章给出 SOGI 与 SRF-PLL 的完整设计与三个算例（带宽取舍、不平衡下的 2ω 纹波、频率跟踪速率），并给出代码与"失锁"防护。

### 29.1 两类 PLL 与它们的适用边界

| 结构 | 输入 | 强项 | 弱项 | 用在哪 |
| --- | --- | --- | --- | --- |
| SOGI-PLL（单相） | 单相电压 | 构造正交分量、天然滤 3/5 次 | 带宽与动态强耦合 | 单相机型（第13章） |
| SRF-PLL（三相） | 三相电压 | 简单、动态快 | 不平衡时 2ω 纹波进相位 | 三相（第14/26章） |
| DSOGI-PNSC / 解耦双 dq | 三相电压 | 不平衡/谐波下仍准 | 算力与调试量 | 不平衡度大或弱电网 |

### 29.2 算例 29-1：锁相环带宽的取舍（用数字说话）

```text
SRF-PLL 的环路可近似为二阶系统，PM / GM 取 45°~60° 时：
 Kp = 2ζωn，Ki = ωn²，取 ζ = 0.707

 ωn = 2π×20Hz（Pn = 20Hz）：
 Ki = (2π×20)² = 15,791 → Ki·Ts = 15,791×55.6e-6 = 0.878
 Kp = 2×0.707×125.66 = 177.7
 阶跃相位响应：约 2.5 个 ωn 周期 = 2.5/20 = 125ms 建立到 ±2%（实测口径：≤150ms）

 ωn = 2π×50Hz（更快）：
 Ki·Ts = 6.17，Kp = 444
 建立时间约 50ms 但对不平衡产生的 2ω（100Hz）纹波抑制变差（2ω 只比 ωn 高 1 倍）
 ωn = 2π×10Hz（更稳）：
 2ω 抑制更好，但建立 250ms 不满足"相位跳变恢复"要求

判据（本课程口径）：ωn = 20~30Hz（不平衡场合按 29-2 的 −20dB/dec 实算收紧到 20Hz）
 ① 相位阶跃 ±10° 后 ≤150ms 恢复（并入验收）
 ② 2ω 纹波在相位上的峰峰值 ≤0.5°（29.3 给出算式）
 ③ 频率斜坡（0.5~2Hz/s，验收表 A 组）下无稳态相位误差
```

### 29.3 算例 29-2：三相不平衡把 100Hz 纹波灌进 θ

```text
三相电压不平衡度 3%（负序 3% = 0.03×311 = 9.33V 峰值）：
 SRF-PLL 的 dq 变换对负序分量等于"反向旋转" → 在 dq 系里变成 2ω（100Hz）交流
 q 轴上的 2ω 纹波幅值 = 负序全幅 9.33V（等幅 Clarke 下 Park 只旋转不缩放，负序幅值不变）

 相位误差传递：θ_err(2ω) ≈ v_q(2ω) × |H(2ω)|/(311V/rad)
 PI 型 PLL 的高频段由 Kp 主导（−20dB/dec），不是二阶的 −40dB/dec：
 |H(2ω)| ≈ 2ζωn/ω（ω = 纹波角频率 2π×100）
 ωn = 20Hz → |H| = 2×0.707×20/100 = 0.283 → θ_err = 9.33×0.283/311 = 8.5e-3 rad = 0.49° （贴近 0.5° 门槛）
 ωn = 30Hz → |H| = 0.424 → θ_err = 0.72° 超门槛
 ωn = 50Hz → |H| = 0.707 → θ_err = 1.22° 

 → 按 −20dB/dec 实算，不平衡度 3% 时需 ωn ≤ 20Hz；现场不平衡度更大（弱电网）或不愿压低带宽时，
 改用解耦双 dq / DSOGI-PNSC（29.1 表格第 3 行），或对 v_q 加 100Hz 陷波/低通前馈

对控制的影响：θ 的 2ω 纹波会让 dq 电流指令出现 2ω 分量 → 三相电流不平衡 → 发热与保护误动
```

### 29.4 算例 29-3：频率跟踪速率与限幅（验收指标的落地）

```text
验收要求：频率跟踪速率 0.5~2 Hz/s（验收表 A 组）
 9kHz 控制中断（第7章 7-3 奇偶双拍口径）下每拍允许的最大频率变化 = 2/9000 = 0.222 mHz/拍

 实现：在 PLL 的角频率输出上加斜率限幅
 ω_new = clamp(ω_raw, ω_prev − Δω_max, ω_prev + Δω_max)
 Δω_max = 2π×0.222e-3 = 1.395e-3 rad/s（每拍）
 并在 f 越限（45~55Hz）时置标志交状态机（第34章）

 与"相位连续"的关系（第30章切换）：
 切换瞬间要求 θ 连续：θ_inv = θ_grid（同步判据：幅值差 ≤2%、相位差 ≤1°、频率差 ≤0.1Hz）
 PLL 的频率限幅保证了 θ 不会被"跟踪"突变拉走 → 切换时相位可预期
```

### 29.5 代码：SOGI + SRF-PLL（可编译）

```c
/* ---------- pll.c ---------- */
#define PLL_WN_HZ     20.0f                 /* 自然频率（29.2 口径） */
#define PLL_ZETA      0.707f
#define PLL_KP        (2.0f*PLL_ZETA*2.0f*3.14159265f*PLL_WN_HZ)      /* 177.7 */
#define PLL_KI_TS     (2.0f*3.14159265f*PLL_WN_HZ*2.0f*3.14159265f*PLL_WN_HZ*CTRL_TS) /* 0.878 */
#define PLL_DF_MAX    (6.2831853f*0.222e-3f)   /* rad/s 每拍，限速 2Hz/s（29-3，9kHz 控制中断口径） */
#define PLL_F_MIN     45.0f
#define PLL_F_MAX     55.0f

typedef struct {
 float theta, w, integ;
 float err_prev, theta_prev;
 uint16_t flags; /* PLL_F_LOCKED / PLL_F_RANGE / PLL_F_JUMP */
 uint8_t unlock_cnt;
} pll_t;
pll_t g_pll;

/* SOGI 正交信号发生器（单相用；三相用 abc→αβ 替代） */
static float g_sogi_x1, g_sogi_x2;
void sogi_step(float v, float w, float k, float *alpha, float *beta)
{
 const float x1_new = g_sogi_x1 + CTRL_TS * (k*(v - g_sogi_x1)*w - g_sogi_x2*w);
 const float x2_new = g_sogi_x2 + CTRL_TS * (x1_new * w);
 g_sogi_x1 = x1_new; g_sogi_x2 = x2_new;
 *alpha = g_sogi_x1; *beta = g_sogi_x2; /* β 滞后 α 90° */
}

/* 每拍调用：三相输入 → θ、ω */
void pll_step(const float vabc[3])
{
 /* ① 三相 → αβ（等幅约定，第14章同一函数库） */
 const float va = (2.0f*vabc[0] - vabc[1] - vabc[2]) / 3.0f;
 const float vb = (vabc[1] - vabc[2]) / 1.7320508f;

 /* ② 用当前 θ 旋转得 vq（相位误差信号） */
 const float s = sinf(g_pll.theta), c = cosf(g_pll.theta);
 const float vq = -va * s + vb * c; /* vq → 0 表示锁定 */

 /* ③ PI + 积分得 θ */
 g_pll.integ += PLL_KI_TS * vq;
 float w_raw = PLL_KP * vq + g_pll.integ;
 const float w_nom = 2.0f * 3.14159265f * 50.0f;

 /* ④ 频率限速（29-3）与限幅 */
 float w = w_nom + w_raw;
 if (w > g_pll.w + PLL_DF_MAX) w = g_pll.w + PLL_DF_MAX;
 if (w < g_pll.w - PLL_DF_MAX) w = g_pll.w - PLL_DF_MAX;
 const float f = w / 6.2831853f;
 if (f < PLL_F_MIN || f > PLL_F_MAX) g_pll.flags |= PLL_F_RANGE;
 else g_pll.flags &= (uint16_t)~PLL_F_RANGE;

 g_pll.w = w;
 g_pll.theta += w * CTRL_TS;
 if (g_pll.theta > 6.2831853f) g_pll.theta -= 6.2831853f;

 /* ⑤ 失锁判定：vq 长期过大（慢任务里累计） */
 g_pll.err_prev = vq;
}

/* 1ms 慢任务：失锁与相位跳变监视（不占 ISR） */
void task_pll_watchdog(void)
{
 if (fabsf(g_pll.err_prev) > 0.1f * 311.0f) { /* vq > 10% 峰值 */
 if (++g_pll.unlock_cnt > 20u) g_pll.flags |= PLL_F_JUMP;
 } else {
 g_pll.unlock_cnt = 0; g_pll.flags &= (uint16_t)~(PLL_F_JUMP);
 }
 if (g_pll.flags & (PLL_F_RANGE | PLL_F_JUMP)) g_prot.fault |= PROT_F_PLL;
}
```

### 29.6 上机核对（LAB4）

| 步骤 | 该看到什么 | 判据 |
| --- | --- | --- |
| 相位阶跃 ±10° | 恢复时间 | ≤150ms（29-1 预测 125ms） |
| 频率斜坡 2Hz/s | 稳态相位误差 | ≤1°（限速不产生稳态误差） |
| 不平衡 3% | θ 的 100Hz 纹波 | ≤0.5°（29-2 预测 0.49°，ωn=20Hz 时贴近门槛） |
| 谐波 5 次 5% | θ 抖动 | ≤0.3°（SRF-PLL 对 5 次有天然抑制） |
| 失锁注入（幅值骤降 50%） | PLL_F_JUMP 置位 | ≤20ms 内告警并交状态机 |

### 29.7 失败案例复盘：PLL 带宽设成 80Hz，不平衡工况下保护误动

> [!CAUTION]
> 现象：现场三相不平衡（约 4%）时，并机电流不平衡度超限报警，同时母线电压出现 100Hz 波动。定位路径：①观察 θ 的 100Hz 纹波（约 0.6°）→ ②核算 PLL 带宽（80Hz，远大于 29-2 按 −20dB/dec 实算的 20Hz 上限）→ ③降到 25Hz 后 θ 纹波降到 0.05°，报警消失。根因：把 PLL 带宽当成"越快越好"的性能指标，忽略了不平衡时负序分量在 dq 系里变成 2ω 纹波、带宽越高抑制越差。预防措施：①PLL 带宽按"不平衡度 × 2ω 抑制"取值（本课程 20Hz；平衡电网可放宽至 30Hz，但须按 29-2 的 −20dB/dec 实算复核）；②不平衡度 >3% 的场合改用解耦双 dq/DSOGI-PNSC；③把"θ 的 2ω 纹波 ≤0.5°"列入上机核对。

### 29.10 补充：双上下文锁相状态机（对照参考工程 Alg_Int_LockStatus / Alg_LockStatus）

参考工程把锁相判定拆成两个上下文：`Alg_Int_LockStatus`（中断内，每拍快判）与 `Alg_LockStatus`（非中断，慢判与决策）。原因很直接：中断里不能做复杂分支与多次确认，慢任务才能做"连续 N 次确认 + 记录 + 交状态机"。

```text
四态状态机（本课程口径）：
 状态 进入条件 动作
 UNLOCK 上电 / vq 超阈值连续 20 次（20ms） 转本振 50Hz，禁止切换与并网
 LOCKING vq 回落到 3% 峰值以下 跟踪但不上报"已锁定"
 LOCKED vq 持续低于 3% 峰值 100ms 允许切换/并网，输出频率可用
 HOLD LOCKED 下发生相位跳变或频率越限 保持输出、冻结切换、等待恢复或降级

快判（中断内，每拍，≤50 周期）：
 ① 读 vq（相位误差信号），与两个阈值比较（10% 与 3% 峰值 = 31.1V 与 9.3V）
 ② 越限计数 +1（饱和到上限），回落则清零或递减
 ③ 只置标志位，不做任何决策、不写日志
慢判（1ms 任务）：
 ① 依据快判计数与时间戳判定状态转移（阈值见上表）
 ② 状态变化时记事件码（UNLOCK / RE-LOCK / HOLD）与时间戳（与第36章黑匣子一致）
 ③ 与整机状态机（第34章）交互：HOLD/UNLOCK 期间禁止切换（第30章）、禁止并网（第38章）
 ④ 向上遥测：锁定状态、失锁累计时间、两路锁相差（第30章 30.10 的 PLL1/PLL2 判定）

诊断量（必须上报，用于现场定位）：
 vq 峰值与均值、越限计数、失锁次数与累计时长、最近一次失锁前后的 θ 与 f
判据：相位阶跃 30° 扰动下，UNLOCK 判定 ≤20ms；电网正常波动（±1Hz、THD 5%）下误判 0 次
```

> [!CAUTION]
> 失败案例复盘（把判定全放中断）：早期版本在 9kHz 中断里做完整的失锁判定（多次确认 + 日志写入），实测中断最坏时长从 2.6µs 跳到 11µs 且抖动大，触发过 ISP 超时告警。改为"中断只置标志 + 慢任务判定"后，中断恢复稳定，失锁判定时间仍满足 ≤20ms。结论：判定逻辑的"确认次数"越多，越应该放慢任务；中断里只做阈值比较与计数。
