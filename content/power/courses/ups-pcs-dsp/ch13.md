**本章要解决的问题：** 输出必须是**低畸变的正弦**（THDu ≤1%），而 LC 滤波器本身是个谐振器（空载 Q 可达 41）。本章用 2kW/220V 单相全桥（L = 1.5mH、C = 10µF、ubus = 400V）把五件事算到底：滤波器谐振、内环阻尼、准 PR 参数、谐波谐振器、以及代码实现。

### 13.1 拓扑与调制选择

```text
400V 母线 ──[单相全桥 4 管，单极性调制]──┐
                                        ├──[L = 1.5mH]──┬──► 负载 220V/2kW
                                        │               │
                                        └──────────────[C = 10µF]
调制：单极性 → 桥臂输出三电平（+400 / 0 / −400），等效纹波频率 2·fsw = 36kHz
     开关损耗比双极性低，滤波电感可小；代价是共模电压变化更复杂（第45章 EMC）
     调制比 m = 311/400 = 0.778（满载，留 22% 余量给跌落与死区，第6章）
```

### 13.2 设计流程（本章固定动作）

1. **需求**：220V/2kW，THDu ≤1%，动态瞬变 ≤±5%、恢复 ≤20ms（验收表 A 组）。
2. **滤波器**：定 L、C → 算 fr、Z0、满载/空载 Q（算例 13-1）。
3. **内环**：电感电流 P 控制，交越受 1.5Ts 限制（算例 13-2）。
4. **阻尼**：有源阻尼把空载 Q 压到 ≤0.8（算例 13-3）。
5. **外环**：准 PR（基波）+ 3/5/7 次谐振器（算例 13-4 / 13-5），校验 PM ≥45°。
6. **代码化**：谐振器系数、限幅、抗饱和写入 `param_table.h`。

### 13.3 算例 13-1：LC 滤波器——空载 Q = 41 是本章的起点

```text
滤波器：L = 1.5mH，C = 10µF
  谐振频率 f_r = 1/(2π√(LC)) = 1/(2π×1.2247e-4) = 1,300 Hz
  特征阻抗 Z0 = √(L/C) = √(150) = 12.25 Ω
  满载（2kW/220V）等效负载电阻 R = 220²/2000 = 24.2 Ω
     Q_满载 = R/Z0 = 24.2/12.25 = 1.98（谐振峰 5.9dB）
  空载（等效 500Ω 或仅剩绕组 0.3Ω）：
     Q_空载 = 500/12.25 = 40.8（谐振峰 32dB）  ← 无阻尼时必然振荡

判据：f_r 应落在 10·f_grid 与 fsw/2 之间 → 500Hz < 1300Hz < 8000Hz ✓
     但 Q_空载 必须靠阻尼解决（算例 13-3），不能靠"多带点负载"
```

### 13.4 算例 13-2：电流内环（P 控制，不用积分是为了不丢相位）

```text
内环对象（全桥 + 电感，m 为归一化调制量 −1~1）：
  i_L = m·u_bus/(sL)  →  |G_i(f)| = 400/(2π·f·1.5e-3)

取 fc_i = 1kHz（内环必须远低于 fsw/10 = 1.8kHz，把延迟留给外环）：
  |G_i(1kHz)| = 400/9.425 = 42.44 A/m  →  Kp_i = 1/42.44 = 0.02356 m/A
  （物理含义：1A 电流误差产生 42.4V 电压指令；满量程 m=±1 对应 ±42.4A 指令误差）
  相位：−90°(对象) − 30.0°(延迟 1.5Ts@1kHz) = −123.75° → PM = 56.3° ✓

为什么内环用纯 P：积分会再加 −90° 附近相位；内环不需要零稳态误差，
"零稳态误差"由外环的谐振器负责（算例 13-4）。
```

### 13.5 算例 13-3：有源阻尼——把空载 Q 从 41 压到 0.707

```text
目标：ζ = 0.707（Q = 0.707，谐振峰 −3dB，无峰值）
  等效虚拟阻尼电阻 R_d = Z0/(2ζ) = 12.25/(2×0.707) = 8.66 Ω
  校验：ζ = Z0/(2R_d) = 12.25/17.32 = 0.707 ✓
  → 空载 Q：40.8 → 0.707（谐振峰 32dB → −3dB）

实现（电容电流反馈等效电阻）：
  在调制量上减去 K_d·i_c，其中 K_d = R_d/u_bus = 8.66/400 = 0.02165 m/A
  物理意义：电容电流流过 R_d 产生的压降折算成调制量

代价检查：
  ① 需要额外一路电容电流采样（或由 i_L − i_o 重构）
  ② 阻尼电阻消耗的等效功率 = i_c,rms²·R_d：满载 50Hz 时 i_c,rms = 2π·50·10µ·220 = 0.691 A
     → 0.691² × 8.66 = 4.13 W（等效损耗，只发生在有源阻尼回路）→ 可接受
```

### 13.6 算例 13-4：准 PR 参数与基波稳态误差

```text
外环对象（内环已闭合 → 从 i_ref 到 v_out ≈ 1/(sC)）：
  |G_v(50Hz)| = 1/(2π×50×10e-6) = 318.3 V/A

准 PR：Gc(s) = Kp + 2Kr·ωc·s/(s² + 2ωc·s + ω0²)，ω0 = 2π×50
  在 ω0 处 |Gc| = Kp + Kr（谐振器峰值正好是 Kr）

取 Kp_v = 0.0314（把交越定在 500Hz 附近）：
  交越校验：|Gc·G_v| @500Hz = 0.0314×(1/(2π×500×10e-6)) × 内环 0.894 = 0.89，
            故实际交越 ≈455Hz，略低于名义值（后续相位链一律按 455Hz 计）
  相位：−90°(对象) − 26.6°(内环@500Hz) − 15.0°(延迟@500Hz) = −131.6° → PM = 48.4°（仅计基波通路）
  ⚠ 谐振器在交越处还有滞后分量，必须再扣：按 13.7 在实际交越 455Hz 处的完整链条
      −90°(对象) −24.4°(内环) −13.6°(延迟 1.5Ts=83.3µs) −5.6°(谐振器) = −133.6°
      → 最终 PM ≈ 46.4° ✓（与 13.11 验收单判据一致）

取 Kr_v = 0.6、ωc = 6.28 rad/s（半带宽 1Hz）：
  50Hz 环路增益 = (0.0314 + 0.6) × 318.3 = 200.9
  基波稳态误差 ≈ 1/(1+T) = 1/201.9 = 0.50%（电压有效值偏差 1.1V）
  ⚠ 为什么 ωc 只取 1Hz（而不是 10Hz）：谐振项在交越频率处的等效矢量是 2Kr·ωc/ω，
    ωc 越大这个滞后矢量越大、越吃相位裕度（算例 13-5 给出定量结论）。
    频率偏移由第29章的 PLL 自适应 ω0 来跟（谐振器中心始终钉在电网频率上），
    所以这里不需要靠"宽带宽"去容忍 ±5Hz。
```

### 13.7 算例 13-5：加 3/5/7 次谐振器——把死区谐波"按下去"

```text
不加谐振器时的谐波（来自第6章算例 6-5 的死区谐波，u_bus = 400V 口径）：
  3 次 1.33%、5 次 0.80%、7 次 0.57% → RSS = √(0.87²+0.52²+0.37²) = 1.65%  ← 超出 THDu ≤1%

取 Kr3 = 0.05、Kr5 = 0.03、Kr7 = 0.02（ωc_h = 6.28 rad/s，带宽 1Hz，与基波谐振器相同）：
  环路增益 = |Kp_v + Σ谐振器| × |1/(2π·f_h·C)| × 内环
   150Hz：|Gc| = 0.0849；|G_v| = 106.1 → 环路增益 8.91 → 1.33%/8.91 = 0.150%
   250Hz：|Gc| = 0.0626；|G_v| =  63.66 → 环路增益 3.87 → 0.80%/3.87 = 0.207%
   350Hz：|Gc| = 0.0521；|G_v| =  45.47 → 环路增益 2.23 → 0.57%/2.23 = 0.255%
  补偿后 RSS = √(0.098²+0.135²+0.166²) = 0.360%   ✓✓ 远优于 ≤1%

⚠ 谐振器的相位代价（必须算，否则 PM 是假的）：
  谐振器在远离中心频率处近似为 2Kr·ωc/(jω) —— 一个滞后 90° 的小矢量。
  本设计交越频率 455Hz 处：
    基波谐振器（Kr=0.6、ωc=6.28）：|矢量| = 2×0.6×6.28/(2π×455) = 2.64e-3
    3/5/7 次（Kr 合计 0.10、ωc 同为 6.28）：|矢量| = 2×0.10×6.28/(2π×455) = 0.44e-3
    合矢量 = 3.08e-3（滞后 90°），而基波通路只有 Kp = 0.0314：
    相位代价 = −atan(3.08e-3/0.0314) = −5.6°
  → 在 455Hz 处的开环相位 = −90°(对象) −24.4°(内环) −13.6°(延迟 1.5Ts=83.3µs) −5.6°(谐振器) = −133.6°
    PM = 46.4°（门槛 45°，实际以扫频为准；第21章的双更新可把它提到 55° 以上）

结论：THDu 指标靠"在谐波频率处堆增益"拿到，但 Kr 与 ωc 越大，交越处的相位代价越大。
      本设计 ωc = 1Hz 是"够用且不伤裕度"的取值——代价是必须靠 PLL 自适应中心频率
      （否则电网偏 1Hz 以上就会削弱基波增益）。
```

### 13.8 代码：谐振器组 + 内环 + 有源阻尼（可编译）

```c
/* ---------- param_table.h：常量来源（13.4~13.7） ---------- */
#define INV_FSW_HZ     18000.0f          // Hz，平台统一（18kHz 载波）
#define INV_TS         (1.0f/INV_FSW_HZ)           // s = 55.6µs
#define INV_L_H        1.5e-3f           // H，输出滤波电感（算例 13-1）
#define INV_C_F        10e-6f            // F，输出滤波电容（算例 13-1）
#define INV_UBUS_V     400.0f            // V，母线（第6章死区算例口径）
#define INV_VREF_RMS   220.0f            // V，输出设定
#define INV_KP_I       0.02356f          // m/A，内环 P（算例 13-2）
#define INV_KD_DAMP    0.02165f          // m/A，有源阻尼（算例 13-3）
#define INV_KP_V       0.0314f           // A/V，外环 Kp（算例 13-4）
#define INV_ILIM_A     18.0f             // A，电流指令上限 = 1.4×I_pk（I_pk = 12.86A，第0章 0.A）
#define INV_M_LIMIT    0.95f             // 调制量限幅（算例 13-1 的调制余量）
#define SQRT2_F        1.4142136f        // √2（第0章 0.3 符号表）

/* ---------- 谐振器（均为 b0 + b2·z⁻² / (1 + a1·z⁻¹ + a2·z⁻²)） ----------
   系数由 Tustin 得到（c = 2/Ts = 36000，ω0 = 2π·f_h）：
     D0 = c² + 2ωc·c + ω0²
     b0 = 2Kr·ωc·c/D0, b2 = −b0
     a1 = (−2c² + 2ω0²)/D0,  a2 = (c² − 2ωc·c + ω0²)/D0
   校核：直流增益 (b0+b2)/(1+a1+a2) = 0（谐振器不放大直流）✓
   极点半径 √a2：基波 0.99965、3/5/7 次 ≈0.99965 → 需 float 满精度或两积分器结构
------------------------------------------------------------------------- */
typedef struct { float b0, b2, a1, a2, s1, s2; } reso_t;

#define R1_B0  2.09244e-4f  /* 50Hz,  Kr=0.6,  ωc=6.28 (算例 13-4) */
#define R1_A1 (-1.9989980f)
#define R1_A2  0.9993025f
#define R3_B0  1.74264e-5f   /* 150Hz, Kr=0.05, ωc=6.28 (算例 13-5) */
#define R3_A1 (-1.9965642f)
#define R3_A2  0.9993029f
#define R5_B0  1.04430e-5f   /* 250Hz, Kr=0.03, ωc=6.28 */
#define R5_A1 (-1.9917055f)
#define R5_A2  0.9993038f
#define R7_B0  6.94942e-6f   /* 350Hz, Kr=0.02, ωc=6.28 */
#define R7_A1 (-1.9844395f)
#define R7_A2  0.9993051f

static reso_t r1 = { R1_B0, -R1_B0, R1_A1, R1_A2, 0, 0 };
static reso_t r3 = { R3_B0, -R3_B0, R3_A1, R3_A2, 0, 0 };
static reso_t r5 = { R5_B0, -R5_B0, R5_A1, R5_A2, 0, 0 };
static reso_t r7 = { R7_B0, -R7_B0, R7_A1, R7_A2, 0, 0 };

float reso_step(reso_t *r, float x)       // DF-II Transposed，每拍 5 乘 4 加
{
    const float y = r->b0 * x + r->s1;
    r->s1 = r->b2 * x - r->a1 * y + r->s2;
    r->s2 =            - r->a2 * y;
    return y;
}

/* 外环：准 PR = Kp·e + Σ(各次谐振器) */
float pr_step(float err)
{
    return INV_KP_V * err + reso_step(&r1, err) + reso_step(&r3, err)
                         + reso_step(&r5, err) + reso_step(&r7, err);
}

/* ---------- inv.c：逆变 ISR（18kHz，第4章五件事） ---------- */
void inv_isr(void)
{
    const float v_out = adc_to_volt(g_adc.raw_vout, &g_adc.cal_vout);
    const float i_l   = adc_to_amp (g_adc.raw_il,   &g_adc.cal_il);
    const float i_c   = adc_to_amp (g_adc.raw_ic,   &g_adc.cal_ic);   // 电容电流

    const float v_ref = INV_VREF_RMS * SQRT2_F * sinf(pll_get_theta());  // 瞬时给定

    /* ① 外环 PR：电压误差 → 电流指令（限幅，抗饱和由 limit_pr 处理） */
    float i_ref = pr_step(v_ref - v_out);
    i_ref = clampf(i_ref, -INV_ILIM_A, INV_ILIM_A);

    /* ② 内环 P + 有源阻尼：电流误差与电容电流 → 调制量 */
    float m = INV_KP_I * (i_ref - i_l) - INV_KD_DAMP * i_c;
    m = clampf(m, -INV_M_LIMIT, INV_M_LIMIT);

    pwm_set_unipolar(pwm_inv, m);            // 单极性调制写入（第8章状态表）
    adc_clear_soc_flag();
    Interrupt_clearACKGroup(ISR_INV);
}

/* 谐振器状态在模式切换时必须清零（否则切换瞬间的残留会冲击输出） */
void inv_ctrl_reset(void)
{
    r1.s1 = r1.s2 = r3.s1 = r3.s2 = r5.s1 = r5.s2 = r7.s1 = r7.s2 = 0.0f;
}
```

> [!TIP]
> 三个实现细节：①谐振器状态机必须可复位（第34章模式切换），残留状态会让切换瞬间输出畸变；②限幅要同时限制"电流指令"与"调制量"，且限幅后要冻结谐振器积分（否则等效于饱和）；③50Hz 谐振器的极点半径 0.99965，用定点实现时系数分辨率不足会导致谐振频率偏移——本课程统一用 float + 满精度，或改用两积分器结构。

### 13.10 失败案例复盘：空载才振荡——"实验室带载测试"漏掉的死角

> [!CAUTION]
> 现象：带 50% 负载测试一切正常（THDu 0.7%），现场空载（或只带一台风扇）时出现约 1.3kHz 的等幅振荡，输出 THDu 超过 8%。定位路径：①抓 1.3kHz 频率 = 算例 13-1 的 fr→ ②量空载 Q（谐振幅值法约 40）→ ③确认有源阻尼未启用（代码里电容电流采样通道未被校准，量程错误导致 Kd实际为 0）→ ④校准电容电流通道后 Q 降到 0.7，振荡消失。根因：无源阻尼依赖负载，空载时阻尼消失；有源阻尼代码"存在但未生效"（采样通道标定错误使 Kd乘了一个错误系数）。预防措施：①阻尼相关通道标定后必须做"断开-接通"对比实验（本课程列入 LAB3 固定项）；②测试矩阵必须包含空载、轻载、非线性负载、突加突卸四类；③把"fr处谐振幅值"纳入上机核对判据；④有源阻尼的系数 Kd与采样通道增益必须在同一份标定记录里追溯（附录 B）。

### 13.12 练习

1. **E1** 若把 C 从 10µF 增到 20µF：重算 fr、Z0、满载与空载 Q；说明这对阻尼与 THDu 各有什么影响。
2. **E2** 计算 Kp_v = 0.0314 时 5 次谐波（250Hz）处的环路增益（含 5 次谐振器），并把它与算例 13-5 的数对上；若不装 5 次谐振器，需要多大 Kp_v 才能达到同样抑制（并说明为什么这不现实）。
3. **E3** 用 13.8 的代码，补一个"谐振器状态限幅"（防止谐振器内部状态在故障时飞出），并说明为什么不能只限幅输出。（参考答案见 [练习参考答案](/posts/power/courses/ups-pcs-dsp/docs/answers/)）
