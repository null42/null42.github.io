**本章要解决的问题：** 模块化 UPS 的核心：N+1 冗余下的 均流 与 环流。三个算例给出环流来源、抑制手段与 环流度 的达标条件。

### 38.1 环流从哪来（一图说清）

```text
两台模块并联，各自输出阻抗 Z1、Z2，输出电压 V1、V2（同幅同频同相的理想情况）
  环流 i_H = (V1 − V2)/(Z1 + Z2)      ← 电压差是唯一来源
  电压差的三个分量：幅值差 ΔU、相位差 Δθ、谐波差 ΔU_h

  环流不流经负载 → 白占容量、增加损耗、引起不均流 → 模块间温度不一致 → 寿命差异
```

### 38.2 算例 38-1：环流有多大（三种不一致的贡献）

```text
取 Z1 + Z2 = 0.1Ω（含输出电缆与逆变输出阻抗），额定 76A

  ① 幅值差 2%（4.4V）：i_H = 4.4/0.1 = 44 A（58% 额定）✗✗ 严重
  ② 相位差 1°：ΔU = 2×311×sin0.5° = 5.43V → i_H = 54 A（71%）✗✗
  ③ 相位差 0.2°：ΔU = 1.09V → i_H = 10.9 A（14%）⚠ 仍需抑制
  ④ 5 次谐波幅值差 1%（3.1V）→ 5 次环流 = 3.1/|Z(5次)|：
     |Z(5次)| ≈ 5×0.1 = 0.5Ω（感性为主）→ i_H5 = 6.2 A（8%）⚠

  → 结论：仅靠"精度"不可能把环流压到 5% 以下；必须靠**均流控制 + 虚拟阻抗** 主动抑制
     目标：环流度 ≤5%（验收表 E 组），空载 ≤5%
```

### 38.3 算例 38-2：三种均流方案的精度与代价

| 方案 | 原理 | 环流度实测口径 | 代价 |
| --- | --- | --- | --- |
| 下垂（无通信） | P–f、Q–V 下垂（第33章） | 3%~5%（取决于 m、n 与线路阻抗） | 电压/频率随负载偏移（0.5%/0.25Hz） |
| 集中均流（主从） | 主模块下发电流指令 | 1%~2% | 通信中断会退化；主模块故障需切换 |
| 平均电流（CAN 广播） | 各模块广播电流，取平均做修正 | 1%~2% | 依赖通信周期（≤10ms） |
| 下垂 + 通信均流 | 下垂做基准、通信做修正（本课程推荐） | ≤2%（动态 ≤5%） | 实现复杂度 |

```text
通信均流的修正量计算（平均电流法）：
  i_avg = Σ i_k / N（各模块输出电流有效值）
  修正量 ΔV_k = K_sh·(i_avg − i_k)，K_sh 由虚拟阻抗决定：K_sh = Z_v（Ω）
  取 Z_v = 0.1Ω、i_avg − i_k = 4A → ΔV = 0.4V（0.13% 额定电压）→ 足够小的修正即可均流 ✓
  K_sh 的取值约束：太大 → 动态抢功（振荡）；太小 → 均流慢
    推荐 K_sh = 0.05~0.2Ω；通信周期 ≤10ms
  误差分析：CAN 传输 8 字节电流值（16bit 有效值，分辨率 0.01A）→ 量化误差可忽略
```

### 38.4 算例 38-3：N+1 冗余与"模块退出"的过渡

```text
4 模块各 50kW 并联带 150kW 负载（3 用 1 备）：
  每模块 50kW（额定）→ 无余量 → 若要求 N+1，负载 ≤150kW（即每模块 50kW 时已无冗余）
  正确配置：4 模块 × 50kW 带 100kW 负载（每模块 25kW，50% 负载率）→ 任一模块退出后
    剩余 3 模块承担 100kW = 每模块 33.3kW（67%）✓ 仍有余量

  退出过渡（模块故障 → 封波 → 断路器断开）：
    退出瞬间负载电流重新分配：缺口 = 退出模块的 25kW（总负载的 25%），
    剩余每模块从 25kW 增到 33.3kW（各补 33% 增量）
    电流环带宽 1kHz → 10ms 内完全可完成；电压跌落 ≤5%（验收表 A 组）
    电压跌落估算：ΔU = I_missing × Z_out,closed
      I_missing = 25kW/(3×220) = 37.9A（每相；33.3kW 是退出后剩余单模块的新负载，不是缺口）
      Z_out = 0.1Ω → ΔU = 3.79V = 1.7% ✓

  判据：任一模块退出时，剩余模块不超载（≤100% 额定）、输出电压跌落 ≤5%、恢复 ≤20ms
```

### 38.5 代码：均流环与环流抑制

```c
/* ---------- parallel.c ---------- */
#define PAR_N_MAX      8
#define PAR_KSH_OHM    0.10f        /* 均流修正系数（38-3） */
#define PAR_ILIM_A     83.6f        /* 单模块电流限幅 1.1×76A */
#define PAR_COMM_TO_MS 50u          /* 通信超时 → 退化到纯下垂 */

typedef struct { float i_rms; uint16_t valid_ms; uint8_t online; } par_mod_t;
static par_mod_t g_mod[PAR_N_MAX];
static uint8_t g_nmod;
static float g_share_corr;          /* 本模块的均流修正量（V） */

/* 10ms 任务：接收各模块电流并算修正量 */
void task_current_sharing(void)
{
    float sum = 0.0f; uint8_t n = 0;
    for (uint8_t k = 0; k < g_nmod; k++) {
        if (g_mod[k].online && g_mod[k].valid_ms < PAR_COMM_TO_MS) { sum += g_mod[k].i_rms; n++; }
    }
    if (n < 2u) { g_share_corr = 0.0f; return; }              /* 单模块或通信中断 → 不做修正 */

    const float i_avg = sum / (float)n;
    const float i_me  = inv_output_current_rms();
    float dv = PAR_KSH_OHM * (i_avg - i_me);                 /* 该修正多少电压 */
    dv = clampf(dv, -3.0f, 3.0f);                            /* 限幅：≤1% 额定电压 */
    g_share_corr = dv;
}

/* 在电压环给定上叠加修正（幅值微调），下垂提供频率/相位基准（第33章） */
float parallel_voltage_trim(void)
{
    if (g_state.comm_lost) return 0.0f;                      /* 通信丢失 → 纯下垂 */
    return g_share_corr;
}

/* 环流度计算（用于遥测与验收判定） */
float circulating_current_ratio(void)
{
    if (g_nmod < 2u) return 0.0f;
    float imax = 0.0f, imin = 1e9f;
    for (uint8_t k = 0; k < g_nmod; k++) {
        if (!g_mod[k].online) continue;
        if (g_mod[k].i_rms > imax) imax = g_mod[k].i_rms;
        if (g_mod[k].i_rms < imin) imin = g_mod[k].i_rms;
    }
    return 100.0f * (imax - imin) / 76.0f;                   /* 相对额定 */
}
```

### 38.7 失败案例复盘：只做下垂不做通信均流，空载环流 18%

> [!CAUTION]
> 现象：4 模块并联空载时环流度 18%，模块间温差 12℃，用户投诉"部分模块发烫"。定位路径：①测各模块电流（两极分化）→ ②核算（38-1：相位差 0.2° 就产生 14% 环流；实测相位差约 0.3°）→ ③确认只有下垂没有通信均流 → ④加入平均电流均流（K_sh = 0.1Ω）后环流度降到 2.5%。根因：下垂只能做"功率均分"的粗调（且空载时下垂量太小、无法区分），空载环流主要来自相位差，必须用通信均流/相位对齐来消除。预防措施：①空载环流必须单独测试并达标（≤5%）；②投入通信均流并做"通信中断退化"测试；③把"环流度"与"模块温度差 ≤5℃"一起纳入验收（第46章）。

### 38.10 补充：并机的三层结构——均流、载波同步、直流差流（对照参考工程）

本书 38.3 写的是第一层（均流环）。参考工程里还有两个对应方法：`Alg_Int_CarrierPowerCANSync`（载波与 CAN 功率同步）与 `App_Int_IlDcCirReg`（电感电流直流/环流调节）。三层各管一类电流，带宽差三个数量级，缺一层就会出现"均流指标达标但模块温度不一"的现象。

| 层 | 管什么电流 | 手段（参考工程 / 本书） | 带宽与周期 | 失效后果 |
| --- | --- | --- | --- | --- |
| ① 均流 | 基波与低频负载电流的分配 | `Alg_Int_CurrShareReg` / 本书 38.3（平均电流 + Ksh = 0.1Ω） | 10ms 级 | 模块间电流不平衡度 >5%，个别模块过载 |
| ② 载波同步 | 模块之间的**开关频率分量差流** | `Alg_Int_CarrierPowerCANSync` / 本书 38.10 | 每拍（硬件链） | 差流含低频拍频分量、EMI 变差、模块温度不一致 |
| ③ 直流差流 | 模块之间的**直流与超低频环流** | `App_Int_IlDcCirReg`（+ `App_Int_VinvDcReg`） | ≤1Hz 慢环 | 直流环流长期占容量：模块温升、变压器/电感偏磁、寿命差异 |

```text
② 载波同步（并机的第二层）
为什么需要：两台模块载波相位不同 → 它们的桥臂输出脉冲在时间上错开，
  差流里出现"拍频分量"（频率 = 相位差的等效频率），幅值受差流回路感抗限制但频率很低、感抗很小
  定量：两模块载波相位差 5°（18kHz 下 = 0.77µs）
    差流回路感抗（两套 LCL 的 L1+L1 = 1.6mH）在 18kHz 下 = 2π×18000×1.6m = 181Ω（高频部分被抑制）
    但相位差会在包络上形成低频分量：等效频率 ≈ Δφ/360×fsw（缓慢漂移时可达几十 Hz）
    该频段感抗仅 2π×50×1.6m = 0.5Ω → 5V 电压差即产生 10A 差流 ✗
落实手段（按可靠性排序）：
  a) 硬件同步链：主模块 SYNCOUT → 从模块 SYNCIN，从模块用 TBPHS 设相位（第11章同一机制）
  b) CAN 广播相位/功率信息做校对：参考工程即"载波 + CAN 功率同步"，
     用于①校正漂移②让各模块同时接受同一功率指令（避免指令不同步造成的瞬时差流）
  c) 相位读回校验：写入 TBPHS 后读回比较（第11章复盘的同一教训）
判据：模块间载波相位差 ≤1°（18kHz 下 0.15µs）；差流低频分量（<100Hz）<1% 额定

③ 直流差流调节
成因（三个，都与"两台不完全一样"有关）：
  a) 采样通道偏置不同：偏置差 0.147A（第28章 28-4 的 2 LSB 口径）× 两台 → 直流指令差
  b) 器件压降与占空比损失不同：每台死区/管压降不同 → 输出直流分量不同
  c) 中点电位不同（三电平并联时）：中点偏差通过 O 状态产生直流分量
抑制：在均流环之上再叠一个"直流分量环"——取各模块输出电流的滑动平均（≥1s），
  把"本机直流分量 − 系统平均直流分量"作为误差，用极慢积分（≤1Hz）修正指令
  参数：积分时间常数 1/(2π×0.2Hz) ≈ 0.8s；限幅 = 1% 额定电流（防止与均流环抢动作）
  ⚠ 带宽必须远低于基波（50Hz）与均流环（10ms 级），否则会把"负载不平衡"当成"直流偏差"去修
判据：各模块输出电流的直流分量差 ≤0.5% 额定；长时间（≥8h）不累积漂移
```

> [!CAUTION]
> 失败案例复盘（只做均流、不做载波同步与直流环流）：四模块并机，均流不平衡度 3.8%（达标），但运行 3 个月后两台模块的散热器温度比另两台高 9℃，且输出电感出现轻微偏磁噪声。核查：①差流频谱显示 40~80Hz 的包络分量（载波相位缓慢漂移所致）；②各模块输出电流的直流分量差 1.2%（超 0.5% 判据），来自采样偏置与死区差异。处理：加入载波同步（SYNC 链 + TBPHS 读回校验）与直流差流慢环后，温度差降到 3℃、偏磁噪声消失。结论：均流指标只考核"基波分配"，管不住"开关频率分量"与"直流分量"；并机的三层必须齐备。
