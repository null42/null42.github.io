**本章要解决的问题：** 要做谐波补偿，先得**把谐波从测量电流里"分出来"**。本章给出最经典的方法（瞬时无功 pq 与 ip-iq 法），三个算例分别算清"提取精度"、** 低通的真实代价（建立时间与泄漏）**，以及最容易出事的"变换系数约定"；另补两件配套工具：半周期 MAF（24.5）与单相 SOGI 正交构造（24.6）。

### 24.1 一次变换就分成"基波 + 谐波"

```text
三相瞬时量 → αβ（Clarke）→ pq 或 ip-iq → 低通取直流 → 反变换 = 基波 → 相减 = 谐波

ip-iq（用电压相位角 θ 与电流）：
 ① iαβ = T_αβ · iabc
 ② [ip; iq] = [ sinθ, −cosθ; cosθ, sinθ ]·[iα; iβ] ← 把基波旋转成直流
 ③ 低通（截止 10~20Hz）取出 ip、iq 的直流分量（= 基波有功/无功）
 ④ 反变换得到基波电流 i_fund；i_harm = i_measured − i_fund
```

> [!IMPORTANT]
> 为什么有效：平衡三相的基波在 dq 系里是直流，而 3/5/7 次谐波在 dq 系里变成 2ω/4ω/6ω 的交流（3 次变 2ω=100Hz、5 次变 6ω=300Hz…）。其中正序谐波（7=6k+1 次）在 dq 系转 +6ω，负序谐波（5=6k−1 次）转 −6ω，二者都落在 300Hz——第25章 MSRF 按序别建系时必须区分旋转方向。只要低通能滤掉这些交流，剩下的就是纯基波。提取频率 = 6ω（300Hz）是主要残余——它决定低通的设计。

### 24.2 算例 24-1：提取精度——低通带宽决定残余多少谐波

```text
测量电流含 5 次谐波 20%：ia = 107.5·sin(ωt) + 21.5·sin(5ωt)（峰值）
 ip 中：基波 → 直流；5 次 → 6ω（300Hz）交流，幅值按等幅 Clarke 约定为 21.5A（与相电流峰值同口径，24.4）
 用一阶低通滤 ip，低通在 300Hz 处的衰减 = fc/300（一阶近似）：

 fc 300Hz 衰减 残余 5 次进入"基波估计" 推算的谐波指令误差
 50Hz 1/6 = 0.167 21.5×0.167 = 3.59 A 相对 21.5A 偏 16.7%
 20Hz 0.0667 1.43 A 偏 6.7%
 10Hz 0.0333 0.72 A 偏 3.3%
 5Hz 0.0167 0.36 A 偏 1.7%

判据：谐波指令误差 ≤5%（否则补偿后仍有残余）→ fc ≤15Hz
取 fc = 10Hz：提取误差 3.3%（= 300Hz 分量的泄漏增益，与 24.3 ② 同口径）；
建立时间 3τ = 47.7ms（见 24.3）
```

### 24.3 算例 24-2：低通提取的真实代价——建立时间与泄漏（决定补偿效果）

```text
先纠正一个常见误解：基波在 dq 系里是直流，一阶低通对直流的增益 = 1、相移 = 0
 → 稳态下基波估计不存在"相位误差"。把低通在高频交流处的相移折算成"时延"、
 再换算出"250Hz 处几十度稳态相位误差"的推导不成立——
 那是把"被滤除的交流分量"的相移，误当成了"指令通道的时延"。

真正的代价有两项：
 ① 建立时间（动态）：一阶低通 t_s ≈ 3τ = 3/(2π·fc)
 fc = 10Hz（24.2 取值）→ 3/(2π×10) = 47.7ms：负载突变后基波估计约 48ms 才稳，
 期间"基波估计的误差"全部灌进谐波指令（假补偿）。
 即使把 fc 放宽到 300Hz，t_s 也只降到 3/(2π×300) ≈ 1.6ms——快不起来
 ② 幅值泄漏（稳态精度上限）：dq 系 300Hz（5/7 次）分量以 |H| = 1/√(1+(f/fc)²) 漏进基波估计
 fc = 10Hz：|H(300)| = 1/√(1+30²) = 0.033（滞后 88.1°）→ 谐波指令误差
 = |1 − 0.033∠−88.1°|：幅值偏差 ≈0.06%、相位 ≈1.9°（很小——泄漏不是稳态主害）
 fc = 300Hz：|H(300)| = 1/√2 = 0.707 → 70.7% 的 5 次漏进"基波"，提取失效
 → 泄漏随 fc 急剧恶化：这就是 24.2 表里 fc 不能随便放宽的另一半含义

③ 精度与动态互相牵制：fc ↓ → 泄漏小但建立慢；fc ↑ → 快但泄漏大
 → 补偿指令换提取方法：滑窗 DFT / MSRF（第25章）——谐波在自身 dq 系是直流，
 低通只影响建立时间，不产生稳态幅相误差

对策（按成本递增）：
 ① 只做遥测/计量：保持 fc = 10Hz，接受 ~48ms 建立（计量不需要快）
 ② 动态要求高：分段投切 fc（负载稳定后再降低），或对建立过程"冻结补偿输出"
 ③ 补偿指令：换提取方法（第25章），并用"建立时间"而非"时延"评价提取环节
```

### 24.4 算例 24-3：Clarke 的两种约定差 1.5 倍（事故高发点）

```text
等幅约定（本课程统一）：iα = (2ia − ib − ic)/3, iβ = (ib − ic)/√3
 平衡时 |iαβ| = I_m（相电流峰值）
等功率约定（部分文献/旧代码）：iα = √(2/3)·(ia − ib/2 − ic/2), iβ = (ib − ic)/√2
 平衡时 |iαβ| = √(3/2)·I_m = 1.2247·I_m

若两处混用（正变换用等幅、反变换用等功率）：
 基波估计幅值偏差 = 1.2247 倍 → 谐波指令 = i − i_fund 出现 22.5% 的"假基波"
 → 补偿电流白天补、晚上反补，THD 反而升高
验算：I_m = 107.5A，误差 = 0.2247×107.5 = 24.2A（= 额定电流的 22.5%）

识别方法（30 秒自查）：注入纯平衡正弦，观察 |iαβ| 是否等于相电流峰值：
 等于 I_m → 等幅；等于 1.2247·I_m → 等功率
```

### 24.5 配套工具Ⅰ：半周期 MAF（滑动平均滤波器）——直流/偶次提取与均值类保护

MAF 是"系数最简单"的滤波器：输出 = 最近 N 拍的算术平均。它的价值在零点分布——窗长取半周期（10ms）时，**100Hz 及其整数倍的增益精确为零**，正好用来提取/滤除单相系统里的 2ω（100Hz）功率脉动与偶次分量；计算量 O(1)，比同性能的 IIR 便宜得多。代价是群延迟 (N−1)Ts/2 与"满窗才准"的建立时间。

```text
频响（N 拍窗，Ts = 55.6µs）：
 |H(f)| = | sin(π·f·N·Ts) / (N·sin(π·f·Ts)) |，直流增益 = 1
 零点：f = k/(N·Ts) → 半周期窗（N·Ts = 10ms）对 100/200/300Hz… 增益 = 0
 群延迟 = (N−1)·Ts/2：N = 180 → 179×55.6µs/2 ≈ 5.0ms（全周期窗 N = 360 → ≈10ms）
 建立时间 = 窗长（新数据填满整个窗后输出才完全反映）

算例（手算）：N = 180（10ms / 55.6µs），看 150Hz 的剩余增益：
 |H(150)| = |sin(π×150×0.010)| / (180×sin(π×150×55.6e-6))
 = |sin(1.5π)| / (180×sin(0.02620))
 = 1 / (180×0.02619) = 1/4.715 = 0.212（−13.5dB）
 → 半周期窗对 50Hz 奇次（150/250Hz…）不是零点、只能压 ~13dB；
 要把奇次一并归零必须用全周期窗 N = 360（对 50Hz 全部整数倍为零，代价是延迟翻倍）

用途：单相逆变器/PFC 的 2ω（100Hz）纹波提取与抑制、母线二次纹波测量、均值类保护量
 （功率、电流平均值）；窗长必须随电网频率重算（与第25章 25.4 同一条纪律）
```

```c
/* ---------- maf.c：半周期滑动平均（O(1) 递推，窗长随电网频率重算） ---------- */
#define MAF_N_MAX  200                 /* 缓冲上限（覆盖 45Hz 以上：18000/(2×45)） */
typedef struct {
 float buf[MAF_N_MAX];
 float sum;
 uint16_t n, idx; /* n = fs/(2·f_grid)，由 PLL 频率决定 */
} maf_t;

void maf_init(maf_t *f, float fs_hz, float f_grid_hz)
{
 uint16_t n = (uint16_t)(fs_hz / (2.0f * f_grid_hz) + 0.5f); /* 半周期拍数 */
 if (n == 0u || n > MAF_N_MAX) n = MAF_N_MAX;
 f->n = n; f->idx = 0; f->sum = 0.0f;
 for (uint16_t k = 0; k < MAF_N_MAX; k++) f->buf[k] = 0.0f;
}

float maf_step(maf_t *f, float x)
{
 f->sum += x - f->buf[f->idx]; /* 加最新点、减最老点 */
 f->buf[f->idx] = x;
 f->idx = (uint16_t)((f->idx + 1u) % f->n);
 return f->sum / (float)f->n; /* 直流增益 1；100Hz 整数倍增益 = 0 */
}
```

### 24.6 配套工具Ⅱ：SOGI 正交信号构造——单相系统的"虚拟正交"

单相系统没有"三相减一相"的运气——要做 dq 变换或功率计算，必须先构造出正交分量。SOGI 用两个积分器构成带通，同时输出同相的 v′ 与正交的 qv′，是单相锁相与单相谐波提取的标准前端。

```text
传递函数（中心 ω0 = 2π×50，增益系数 k）：
 v′/v = k·ω0·s / (s² + k·ω0·s + ω0²) ← 带通，中心增益 1
 qv′/v = k·ω0² / (s² + k·ω0·s + ω0²) ← 低通，与 v′ 正交

稳态（ω = ω0）：v′/v = 1（等幅同相）、qv′/v = −j（等幅、滞后 90°）→ 正交对到手
建立时间 ≈ 3/(k·ω0)：k = 1.414 → 3/(1.414×314.2) = 6.8ms（本课程默认）
 k ↓ → 带宽 ∝ k 变窄（谐波抑制更好）但建立变慢：k = 0.7 → 13.6ms；k = 2 → 4.8ms
频率偏移 ±1Hz（电网 49Hz）：|v′/v| = 0.9996（幅值误差 0.04%）、正交角误差 ≈1.6°
 → SOGI 对小频偏天然鲁棒；大频偏需 PLL 回授中心频率（第29章）

算例（手算）：v = 311·sin(θ)，含 5 次谐波 4%：
 稳态 v′ = 311·sin(θ)（5 次被带通压到 |H(250)| ≈ 0.22 倍 → 残余 0.9%）
 qv′ = 311·cos(θ)：与 v′ 等幅、滞后恰 90° → 单相 dq/功率计算可直接使用
 k 从 1.414 改 0.7：建立时间 6.8ms → 13.6ms（≈翻倍），换来的滤波带宽减半
```

可视化与参数试验：见 规范与大纲/sim/interactive.html 模块③（SOGI 正交构造，可拖动 k 与频率偏移观察 qv′ 正交与建立过程）。**上机核对（并入 LAB4）：** 注入含 5 次谐波的正弦，李萨如图形（v′，qv′）应为圆；k 改 0.7 后建立时间应约翻倍。

### 24.7 代码：ip-iq 谐波提取

```c
/* ---------- ipiq.c ---------- */
#define IPIQ_LPF_FC   10.0f        /* Hz，低通截止（24.2 结论） */
static biquad_t g_ip_lpf, g_iq_lpf;

void ipiq_init(void) { disc_lpf1_init(&g_ip_lpf, IPIQ_LPF_FC); disc_lpf1_init(&g_iq_lpf, IPIQ_LPF_FC); }

/* 输入：三相电流（A）与电网相位 θ；输出：基波三相电流（A，等幅约定） */
void ipiq_extract(const float iabc[3], float th, float ifund[3])
{
 const float s = sinf(th), c = cosf(th);
 /* ① 等幅 Clarke（与第14章同一约定，禁止混用） */
 const float ia = (2.0f*iabc[0] - iabc[1] - iabc[2]) / 3.0f;
 const float ib = (iabc[1] - iabc[2]) / 1.7320508f;

 /* ② 旋转到 dq（基波变直流） */
 const float ip = ia * s - ib * c;
 const float iq = ia * c + ib * s;

 /* ③ 低通取直流 = 基波有功/无功分量 */
 const float ip_dc = biquad_step(&g_ip_lpf, ip);
 const float iq_dc = biquad_step(&g_iq_lpf, iq);

 /* ④ 反变换回三相（基波估计） */
 const float iaf = ip_dc * s + iq_dc * c;
 const float ibf = -ip_dc * c + iq_dc * s;
 ifund[0] = iaf;
 ifund[1] = -0.5f*iaf + 0.8660254f*ibf;
 ifund[2] = -0.5f*iaf - 0.8660254f*ibf;
}

/* 谐波电流 = 测量 − 基波估计；低通的代价是建立时间 3τ≈48ms 与幅值泄漏（24.3），不是固定时延 */
void ipiq_harmonic(const float iabc[3], float th, float iharm[3])
{
 float ifund[3];
 ipiq_extract(iabc, th, ifund);
 for (uint8_t k = 0; k < 3; k++) iharm[k] = iabc[k] - ifund[k];
}
```

### 24.9 失败案例复盘：约定混用，补偿越补越差

> [!CAUTION]
> 现象：有源滤波功能投入后，负载电流的 THD 从 25% 升到 28%，且波形出现"包络"。定位路径：①注入纯正弦测提取输出（不是 0，而是 22% 的"假基波"）→ ②核对正/反变换系数（正变换等幅、反变换等功率）→ ③统一为等幅后 THD 降到 6%。根因：Clarke 变换的两种系数约定混用，等效在指令里叠加了 22.5% 的错误基波。预防措施：①把变换写成唯一函数库（abc_to_dq/dq_to_abc），不在业务代码里手写系数；②上机核对固定做"纯正弦输入 → 输出应为 0"这一项；③在术语表注明本课程统一采用等幅约定（第14章口径）。
