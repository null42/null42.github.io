**本章要解决的问题：** 把第1章算出的需求（76A 采样、12 路 PWM、微秒级保护）翻译成**可核算的芯片资源清单**：通道够不够、周期够不够、内存够不够。本章给出四个核算算例（外设通道、算力周期、存储、采样率），一份** 拒绝猜测**的待核清单，以及一次真实的选型翻车复盘。

### 2.1 规格清单（已核实，出处见 2.6）

| 项目 | 规格 | 对控制设计的含义 |
| --- | --- | --- |
| CPU | C28x，120MHz，FPU + TMU，240 MIPS | 控制环直接用 `float`，三角/开方走硬件 |
| 协处理器 | CLA 120MHz，IEEE754 单精度 | 可把 PLL/SOGI 或保护扫描搬走，给主核腾周期 |
| 存储 | Flash 512KB（ECC）/ RAM 100KB（ECC） | 参数表 + 黑匣子 + 波形缓冲（见算例 2-3） |
| ePWM | 24 通道（176-PTP）/ 15 通道（100-PZP）★ | 三电平三相 12 路；两套交错需 24 路 |
| ADC | 3× 12bit SAR，通道 17（176-PTP）/ 14（100-PZP）★ | 三相同刻采样 + 母线 + 温度 |
| 比较器 | 最多 8× CMPSS（内置 DAC 阈值） | 硬件保护链起点（第36章） |
| 通信 | 2× CAN、3× SPI、3~4× UART、USB 2.0、EMIF、DMA 6 通道、97 GPIO（176-PTP）★ | BMS(CAN)、动环(UART)、DMA 搬采样 |
| 时钟 | 内部零引脚 10MHz 振荡器 ×2 + 片上晶振；窗口看门狗；丢失时钟检测 | 失时钟检测用于"跑飞自恢复"设计 |

★ 标注项随封装变化，采购与画板前必须按《TMS320F2807x Real-Time Microcontrollers datasheet (Rev. K)》核对。

### 2.2 算例 2-1：外设通道核算（选型第一关）

```text
对象：50kW 三相三电平 UPS（TNPC/NPC），四线制输出

① PWM 通道
 三相 × 每相 4 管 = 12 路主开关
 若采用"两套模块交错 180°"：12 × 2 = 24 路
 → 176-PTP 的 24 通道：刚好用满，无余量（需预留风扇/继电器等 GPIO 而非 PWM）
 → 100-PZP 的 15 通道：不够，直接排除该封装

② ADC 通道
 三相电流 3 + 输出三相电压 3 + 母线（P/O/M）3 + 电池电流/电压 2 + 散热器温度 2 = 13 路
 → 17 通道：余 4 路（可用作自检、冗余）；14 通道：余 1 路，偏紧

③ CMPSS（硬件保护）
 三相过流 3 + 母线过压 1 + 输出过压 1 + 电池过流 1 = 6 路
 → 8 路：余 2 路（留给母线欠压/风扇堵转等）

④ 定时器与通信
 1ms/10ms 慢任务定时 1~2 个；CAN 1（BMS）+ UART 1（上位机/动环）→ 资源充足
```

> [!IMPORTANT]
> 核算纪律：外设核算必须按"封装 → 通道 → 余量"三步写下来，而不是"应该够"。余量建议 ≥15%：本算例 ADC 余 4/17 = 23%（合格），PWM 余 0/24（不合格，需改为单套 12 路 + 交错由外部同步，或选更大封装）。

### 2.3 算例 2-2：算力周期核算（选型第二关）

```text
前提：载波 18kHz，控制中断周期 111.1µs（9kHz，奇偶双拍，每 2 载波中断一次）→ 120MHz 下 = 13,333 个 CPU 周期/拍

控制环各段周期预算（浮点、TMU 加速；数字为设计预算，实测后回填）：
 采样读取与换算（3 相电流 + 3 电压）............ 200
 保护扫描（阈值、锁存、故障码）................ 80
 PLL / SOGI（单相）........................... 400
 电流环（Clarke/Park + 2×PI + 解耦）........... 300
 电压环（2×PR 或 PI + 限幅）................... 250
 谐波补偿（5/7 次 PR 各支路）................... 500
 SVPWM（扇区判断 + 占空比计算）................. 250
 PWM 影子寄存器写入 + 中断三件套................ 40
 ────────────────────────────────────────────
 合计（平均）................................. 2020 → 15.2% 占用率
 最坏路径（限幅/故障分支/谐波全开）............. 2600 → 19.5% 占用率

判据：平均 ≤40%、最坏 ≤50%（余量留给故障路径与中断抖动）
```

| 余量不足时的三条正路 | 代价 |
| --- | --- |
| 把 PLL/SOGI 或保护扫描搬到 CLA | 需设计主核↔CLA 的共享变量交接协议（第37章） |
| 谐波补偿降次（只做 5/7 次，放弃 11/13 次） | THDu 预算变紧，需重新分配（第23章） |
| 降低载波频率（18kHz → 10kHz） | THDu 变差、滤波器变大，需重新核算全链路 |

### 2.4 算例 2-3：存储核算（选型第三关）

```text
RAM 需求（100KB 可用，带 ECC 的实际可用量以手册为准）：
 可调参数表：200 项 × 4B = 800 B（+ CRC16 表 8B）
 黑匣子日志：1000 条 × (时间戳4 + 码1 + 值2 + 状态2 + CRC1) = 10 KB
 波形环形缓冲：8 通道 × 512 点 × 4B = 16 KB
 控制中间量与状态机：≈ 2 KB
 通信收发缓冲：4 KB
 ─────────────────────────────
 合计 ≈ 33 KB → 占 100KB 的 33%，合格（余量留给后续功能）

Flash 需求（512KB）：
 代码 ≈ 60~120 KB；参数出厂默认值 + 标定系数 ≈ 8 KB（双备份 16KB）
 → 充足；双区安全（bootloader 升级）另占一个区（附录 B）
```

### 2.5 算例 2-4：采样率是否够（与第5章衔接）

```text
电流环带宽经验值：fc_i ≈ f_sw / 10 = 18kHz / 10 = 1.8 kHz
采样率（= 载波频率）18 kHz = 10 × fc_i

判据：采样率 ≥ 8~10 倍电流环带宽（低于此值，数字延迟与离散化误差会吃掉相位裕度）
验证：第0章 0.C 的 1.5Ts 延迟在 1.8kHz 处引入相位滞后
 θ = 360° × f · 1.5Ts = 360 × 1800 × 1.5 × 55.6e-6 = 54.0°
 → 这 54° 必须从相位预算里扣（PM 目标 45° 起，见第13章/LAB3）
```

> [!WARNING]
> 关键换算：1.5Ts 在 1.8kHz 处就是 54° 相位——这是"数字控制比模拟控制难"的核心原因。若把 fc_i 提高到 3kHz，滞后变为约 90°（360×3000×1.5×55.6e-6），几乎不可能达到 PM≥45°。所以电流环带宽不是想提多少就提多少，它被采样率与延迟锁死。

### 2.6 出处纪律与待核清单

引用芯片事实必须写明文档名与修订号：《TMS320F2807x Real-Time Microcontrollers datasheet (Rev. K)》《TMS320F2807x TRM (Rev. H)》《TMS320F2807x Silicon Errata (Rev. K)》。以下项目**本课程拒绝凭记忆写数字**：

| 待核项 | 猜错的后果 | 查哪里 |
| --- | --- | --- |
| eCAP 模块数量 | 测频/测相方案不可行（第7/29章） | datasheet 特性表 |
| ePIE 分组数、每向量字数、向量表基址 | ISR 应答写法错 → 丢中断（第4章） | TRM 中断章节 |
| ePWM AQCSFRC 位段编码 | 强制电平写反 → 保护失效（历史样片曾出错） | TRM ePWM 章节 + 实测 |
| ADC 采样保持电容 Ch、源阻抗上限 | ACQPS 取错 → 采样值系统性偏低（第5章） | datasheet ADC 电气特性 |
| ePWM↔GPIO 复用映射 | PCB 走线不可行、X-BAR 路由受限 | datasheet 引脚复用表 |
| 带 ECC 的 RAM 实际可用量与分区 | 波形缓冲/日志段放不下或与栈冲突 | TRM 存储章节 + 链接文件 |

### 2.7 浮点与定点：代码量差多少

```text
// 浮点（F28075 默认）：增量式 PI，可直接读
float pi_step(float e){
 integ += Ki * Ts * e; // Ts = 55.6e-6f // s，18kHz 载波
 float u = Kp * e + integ;
 if (u > UMAX) { u = UMAX; integ -= (u_raw_before - UMAX); } // 抗饱和
 return u;
}

// 定点（历史样片 F28035 的典型写法）：同样的功能，需要额外定标与饱和
_iq integ_q = _IQ(0.0);
_iq pi_step_q(_iq e){
 integ_q += _IQmpy(_IQ(Ki*Ts_iq), e); // 定标系数必须另行生成
 _iq u = _IQmpy(_IQ(Kp_iq), e) + integ_q;
 u = _IQsat(u, _IQ(UMAX), _IQ(UMIN)); // 溢出保护
 return u;
}
```

| 维度 | 浮点（本课默认） | 定点（IQmath，仅移植用） |
| --- | --- | --- |
| 可读性 | 公式即代码，便于评审 | 每个系数都要定标，评审成本高 |
| 溢出风险 | 需注意数值范围但不必逐点定标 | 必须逐点评估，错一处即溢出 |
| 上机验证 | 可与 Simulink/桌面 C 逐拍对比 | 需额外汇率换算，对拍更麻烦 |

### 2.8 平替台架：用 100MHz 器件跑低压实验要改什么

```text
算例 2-5：同一控制律换到 100MHz 器件（低压台架）
 TBPRD：EPWMCLK 60e6 / (2 × 18e3) = 1667 （F28075 实配值，第0章 0.B）
 Ts 不变（18kHz），但 1 拍周期数从 6,667 → 5,556，算力预算收紧 16.7%
 若台架用不同开关频率（如 20kHz）：Ts = 50µs，
 延迟相位 θ = 360 × fc_i × 1.5Ts 也要重算，环路增益必须重新整定
```

> [!IMPORTANT]
> 纪律：台架结论不能直接搬到目标板。外设数量、时钟频率、延迟拍数三项任一变，第0章 0.C/0.D 的模型参数就变，必须重算 TBPRD/ACQPS/延迟相位，并重新跑一遍 LAB2 的带宽与裕度判据。

### 2.10 失败案例复盘：封装选错导致改板

> [!CAUTION]
> 现象：首版样机选用 100 引脚封装做三相三电平，调试时发现 ePWM 通道不够，只能用软件模拟第 4 个开关的时序，结果死区不一致、上下管偶发直通。定位路径：①先怀疑驱动 → ②量门极波形发现死区不一致 → ③查配置代码发现只有 15 路 PWM 可用，第 16 路用 GPIO 软件翻转 → ④确认是外设数量不足，不是驱动问题。根因：选型时只看了"CPU 够快"，没做 2.2 的通道核算。预防措施：①选型评审必须提交"外设通道核算表"（封装 → 通道 → 余量 ≥15%）；②软件翻转时序不得用于任何桥臂开关；③在 references.html 登记该封装的关键差异。

### 2.13 补充：CLA 资源与触发源（参考工程实证）

参考工程把 θ 与采样数据处理交给 CLA（详见第37章 37.9）。平台侧要点：CLA 是独立协处理器，不经过 PIE、不响应普通外设中断，由 CLA 任务触发源启动（ePWM/ADC/软件）；它与 CPU 并行执行但共享 RAM，因此数据交换必须用共享区加握手。CLA 支持浮点，可访问 ADC 结果寄存器与 ePWM 比较寄存器，典型用途是每拍固定的坐标变换、SVPWM 计算与定系数滤波。
