**本章要解决的问题：** 把"谐波"从模糊概念变成可分解、可测量、可追责的三件事：**来源**（谁产生）、** 口径**（怎么算）、** 限值**（谁判合格）。三个算例分别给出死区/纹波/非线性负载的谐波量级、THD 三种口径的差异，以及 TDD 为什么比 THD 更适合并网判定。

### 23.1 四个谐波源与它们的"指纹"

| 来源 | 产生机制 | 次数特征 | 本课程量级/出处 |
| --- | --- | --- | --- |
| 死区与器件压降 | 每个开关周期损失一段伏秒 | 奇次为主（3/5/7…） | 1.33%/0.80%/0.57%（第6章算例 6-5，400V 母线、基波峰值 311V 口径） |
| 开关纹波 | PWM 载波与边带 | fsw 及其边带 | 由滤波器与采样对齐压制（第5/18章） |
| 非线性负载 | 整流+电容负载的电流尖峰 | 3/5/7/9…宽谱 | 峰值因数 2~3（规范要求 ≥3:1） |
| 电网背景谐波 | 上级电网已有畸变 | 随电网，通常 5/7 为主 | 2%（第14章算例 14-5 假设） |

> [!IMPORTANT]
> 追责顺序：输出 THDu 超标时，先分清是"自己产生的"（死区/纹波）还是"负载/电网灌进来的"。前者靠补偿器与调制改进（第25~28章），后者靠阻抗设计（输出阻抗要低）与前馈（第14章 14-5）。搞错方向会白调一个月。

### 23.2 算例 23-1：三种 THD 口径，同一波形能差 2 倍

```text
取一组实测谐波（相对基波幅值；基波峰值 311V 口径，与第6章算例 6-5 一致）：
  3 次 1.33%、5 次 0.80%、7 次 0.57%、9 次 0.21%

① THD（以基波为分母，最常用）：
   THD = √(1.33²+0.80²+0.57²+0.21²) = √(1.7689+0.64+0.3249+0.0441) = √2.7779 = 1.67%
   （仅 3/5/7 三项 RSS = √2.7338 = 1.65%，即死区谐波的口径）

② 若轻载运行、基波只有额定的 30%，但谐波绝对量不变：
   THD 会"虚高"到 1.67%/0.30 = 5.6%（因为分母变小）
   → 这就是纯 THD 口径在轻载时失真严重的原因

③ TDD（以最大需求电流为分母）：
   TDD = 谐波有效值/最大需求电流 → 轻载时数值不变（1.67%）
   → 并网判定用 TDD（IEEE 519），设备内部考核用 THD

④ 单次谐波限值（很多规范同时考核"总 + 单次"）：
   规范：5%/7%/10%（半载/额定/轻载，见验收表 A 组）
   本例 5 次 = 0.80% ✓ 远低于单次限值
```

> [!WARNING]
> 口径必须写在报告里："THD 是多少"这句话本身不完整——必须同时写分母是谁（基波/额定/最大需求）、测到几次（50 次还是 25 次）、带宽（是否含开关频率附近）。本课程统一：THDu 分母取基波、次数取 2~50 次、带宽 ≤2kHz 的分析窗。

### 23.3 算例 23-2：非线性负载下的 THDu 预算表

```text
目标：阻性负载 THDu ≤1%、非线性负载 ≤3%（验收表 A 组）
预算分配（把 1% 分给三个来源，留 30% 余量）：

  来源              贡献（阻性负载）    手段
  死区（3/5/7）      0.360%（补偿后）   第13章 3/5/7 次谐振器
  开关纹波残留       ≈0.1%              滤波器 + 采样对齐（第18章）
  电网背景灌入       0.05%（前馈后）    第14章 电网电压前馈
  ─────────────────────────────────────
  RSS 合计           √(0.360²+0.1²+0.05²) = √(0.1296+0.01+0.0025) = √0.1421 = 0.38%  ✓ 余量充足

  非线性负载（峰值因数 3:1，电流尖峰 27A）：
    电流尖峰导致输出瞬时跌落（取决于输出阻抗 Zout）
    要求 THDu ≤3%：在 5 次（250Hz）处 Zout·I_5 ≤ 3%×311V = 9.3V
    若 I_5 = 4A → 允许 |Zout(250Hz)| ≤ 9.3/4 = 2.33Ω
    第14章 5 次处环路增益 3.87（三相口径）；单相第13章 5 次环路增益 = 2.23
    → |Zout| = |Z_open|/(1+T)，|Z_open(250Hz)| = 1/(2π×250×10µ) = 63.7Ω
      → 闭环 |Zout| = 63.7/(1+2.23) = 19.7Ω ≫ 2.33Ω  ✗ 不达标
    → 结论：单相 2kW 在非线性负载下必须再加"负载电流前馈"或更高次谐振器（第26/28章）
```

### 23.4 算例 23-3：测量本身的误差有多大

```text
谐波分析仪表与 DSP 内部 FFT 的差异来源（本课程要求两套都对得上）：
  ① 频率分辨率：内部 FFT 用 10 周期（0.2s）窗 → 分辨率 5Hz
     50Hz 基波泄漏到 5 次以上的误差 ≈ −30dB 旁瓣 → 对 0.5% 量级谐波的读数影响 ≤0.02% ✓
  ② 采样不同步：若采样窗不是整数周期（如 10.02 周期），泄漏误差可达 −20dB → 0.5% 谐波读到 0.55%
     → 措施：用 PLL 相位做"整周期同步采样"（第29章接口）
  ③ 抗混叠不足：开关纹波混叠到低频（第18章算例 18-3 的 −7dB）→ 可能凭空造出 3/5 次
     → 措施：分析用数据先经 2kHz 低通（Tustin，第18章）
  ④ 量化：12bit ADC → 噪声底 0.0212A = 0.23% 额定
     对 0.2% 量级的谐波注：直接用 1 LSB 分辨，误差不可忽略
     → 措施：多次平均（N = 16 → 噪声降 4 倍 = 0.06%）或提高量程利用率

四舍五入：本课程规定内部谐波测量误差 ≤±0.05%（相对基波），否则不允许用于验收判定。
```

### 23.5 代码：整周期同步采样 + 谐波分解（可编译）

```c
/* ---------- harm.c：整周期同步采样的谐波分析（用于遥测与验收自检） ---------- */
#define HARM_N      256          /* 每周期采样点数（50Hz → 5.12kHz 等效采样窗） */
#define HARM_ORDER  50           /* 分析到 50 次（2.5kHz），与 23.1 口径一致 */

typedef struct {
    float re[HARM_ORDER + 1];
    float im[HARM_ORDER + 1];
    uint16_t n;                  /* 已填充点数 */
    float buf[HARM_N];
} harm_t;
static harm_t g_harm;

/* 由 PLL 相位触发：每 1/N 个工频周期采一次，实现整周期同步 */
void harm_push(float sample)
{
    g_harm.buf[g_harm.n] = sample;
    if (++g_harm.n >= HARM_N) g_harm.n = 0;      /* 环形填充 */
}

/* 计算 1~50 次：h=1 即基波，供 harm_report 做 THD 分母（DFT 只算关心的次数，比全 FFT 省算力） */
void harm_analyze(void)
{
    const float k2pi = 6.2831853f;
    for (uint8_t h = 1; h <= HARM_ORDER; h++) {
        float sr = 0.0f, si = 0.0f;
        for (uint16_t k = 0; k < HARM_N; k++) {
            const float th = k2pi * (float)h * (float)k / (float)HARM_N;
            sr += g_harm.buf[k] * cosf(th);
            si -= g_harm.buf[k] * sinf(th);
        }
        /* 幅值 = 2/N·√(re²+im²)（单边谱，幅值不变约定） */
        g_harm.re[h] = 2.0f * sr / (float)HARM_N;
        g_harm.im[h] = 2.0f * si / (float)HARM_N;
    }
}

/* THD（分母=基波幅值，取 re[1]/im[1]——harm_analyze 已从 h=1 起算；谐波求和 2~50 次） */
void harm_report(float *thd_pct, float *worst_pct, uint8_t *worst_order)
{
    float sum2 = 0.0f, worst = 0.0f; uint8_t wo = 0;
    const float fund = sqrtf(g_harm.re[1]*g_harm.re[1] + g_harm.im[1]*g_harm.im[1]);
    for (uint8_t h = 2; h <= HARM_ORDER; h++) {
        const float m = sqrtf(g_harm.re[h]*g_harm.re[h] + g_harm.im[h]*g_harm.im[h]);
        sum2 += m * m;
        if (m > worst) { worst = m; wo = h; }
    }
    *thd_pct    = 100.0f * sqrtf(sum2) / (fund + 1e-6f);
    *worst_pct  = 100.0f * worst / (fund + 1e-6f);
    *worst_order = wo;
}

/* 分析前必须低通（第18章）：fc = 2kHz，Tustin，防开关纹波混叠造出假谐波 */
static biquad_t g_harm_lpf;
void harm_init(void)
{
    disc_lpf1_init(&g_harm_lpf, 2000.0f);   /* 第20章 20.5 接口 */
}
```

### 23.6 上机核对（LAB3/LAB4）

| 步骤 | 该看到什么 | 判据 |
| --- | --- | --- |
| 与功率分析仪对比 | THDu 读数一致性 | 偏差 ≤±0.05%（23.4 口径） |
| 整周期同步开/关 | 关掉同步后 5 次读数变化 | 变化 ≤0.05%（证明同步有效） |
| 非线性负载（整流+容性） | THDu ≤3%，峰值因数 ≥3 | 验收表 A 组 |
| 轻载 THD 虚高验证 | 30% 负载时 THD 读数 | 能用 TDD 口径解释（23.2 ②③） |
| 分析前低通验证 | 低通开/关对 20~50 次读数的影响 | 关掉后出现"假谐波"即证实 |

### 23.7 失败案例复盘：把负载灌进来的谐波当成"自己产生"的

> [!CAUTION]
> 现象：现场 THDu 2.6%（非线性负载），团队按"死区谐波"方向改了两个月（加大谐振器、改死区补偿），THDu 几乎没变。定位路径：①断掉负载用电子负载（纯阻性）测 THDu = 0.4% → 说明逆变侧本身没问题 → ②带真实负载测，频谱显示 3/5/7 次与负载电流波形完全同步 → ③确认谐波来自负载电流在输出阻抗上的压降 → ④改用负载电流前馈（第28章）+ 提高 5/7 次谐振器增益（注意第22章相位代价）后降到 1.8%。根因：未先做"谐波归因"（自产 vs 灌入），把资源投在错误方向。预防措施：①任何谐波整改必须先做"阻性/非线性/空载"三组对照测试并记录频谱；②把 Zout（输出阻抗）曲线纳入设计交付物（第13章 LAB3 的 Zout 图）；③归因结论写进故障报告，作为后续改进的输入。
