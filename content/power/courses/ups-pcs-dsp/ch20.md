**本章要解决的问题：** 把连续域设计搬进 120MHz 的 `C28x`：Tustin 与预畸变到底差多少、后向欧拉该用在哪、浮点与定点的执行时间差、以及数值溢出与分辨率的边界。

### 20.1 三种离散化方法的分工（先给结论）

| 方法 | 映射 | 稳定性 | 用在哪 |
| --- | --- | --- | --- |
| Tustin（双线性） | s = (2/Ts)(z−1)/(z+1) | 左半平面→单位圆内（保稳定） | **控制器/补偿器（本课程默认）** |
| 后向欧拉 | s = (z−1)/(zTs) | 无条件稳定，相位偏保守 | 被控对象模型、简单平滑 |
| 前向欧拉 | s = (z−1)/Ts | 可能不稳定（极点可能出圆） | 仅在 Ts 远小于对象时间常数时可用 |
| 零阶保持（ZOH） | 精确匹配"保持一拍" | — | 被控对象离散化（仿真/对拍） |

> [!IMPORTANT]
> 为什么控制器必须用 Tustin：它保稳定、保频率轴形状（配合预畸变后频率点精确），且系数计算简单。后向欧拉会带来额外的相位滞后（等效"多算 0.5 拍"），前向欧拉则可能直接把数字环路推到不稳定（第18章算例 18-1 的 +72% 带宽误差就是它的"副作用"）。

### 20.2 算例 20-1：不预畸变，交越频率偏了 18%

```text
Tustin 把数字频率 ωd 映射成模拟频率 ωa = (2/Ts)·tan(ωd·Ts/2)。
反过来：设计在 ωc 的控制器，实际交越落在 tan(ωd·Ts/2) = ωc·Ts/2 解出的 ωd 处。
Ts = 55.6µs（18kHz）：

  fc = 1 kHz：ωc·Ts/2 = 6283×2.778e-5 = 0.17453
     ωd·Ts/2 = atan(0.17453) = 0.17279 → f_real = 0.17279×2/(2π×55.6e-6) ≈ 990 Hz
     误差 −1.0%  ✓ 可忽略
  fc = 5 kHz：ωc·Ts/2 = 31416×2.778e-5 = 0.87266
     ωd·Ts/2 = atan(0.87266) = 0.71750 → f_real ≈ 4,110 Hz
     误差 −17.8%  ✗ 必须预畸变

预畸变做法（把设计频率"改高"）：
  先算已畸变值 k = tan(ωc·Ts/2)，令预畸变设计频率 ωc' = (2/Ts)·k（> ωc）参与系数计算
  → 5kHz 时 k = tan(0.87266) = 1.1917、ωc' = (2/Ts)×1.1917 ≈ 42,900 rad/s（≠ ωc = 31,416！）
  用 ωc' 算出的系数经 Tustin 离散后，实际 −3dB 点精确落回 5kHz
  实际含义：预畸变是"让指定的 ωc 精确落在离散系统上"，对一阶/二阶环节即把 ωcTs/2 → tan(ωcTs/2)
  全链自洽校验（1kHz 一阶低通）：k = tan(0.17453) = 0.1765
    → b0 = k/(1+k) = 0.150、a1 = (k−1)/(k+1) = −0.700（20.8 的 disc_lpf1_init 即此公式）

谐振器同理（更敏感，因为频率必须精确）：
  7 次谐波 350Hz：ω0Ts/2 = 0.061087 → atan 后 ωd = 2196.4 rad/s → 349.6 Hz（偏 −0.4Hz）
  50Hz 基波：偏 −1.3 mHz（可忽略）
  → 谐波谐振器（≥7 次）必须预畸变；基波谐振器可省，但为统一风格建议一律预畸变
```

### 20.3 算例 20-2：浮点 vs 定点，执行时间差多少

```text
平台口径（第2章）：C28x @120MHz，单精度浮点含在 CPU 里（FPU），一个乘加约 1 周期
  18kHz 控制周期 = 120MHz/18kHz = 6,667 周期

PI 一次（2 乘 + 2 加 + 限幅判断）：
  浮点：约 8 周期 → 占 ISR 0.11%
  IQmath 定点（Q15，函数调用 + 定标）：约 25~30 周期 → 占 ISR 0.57%

4 个谐振器（每个 9 操作）：
  浮点：约 40 周期 → 0.53%
  IQmath：约 200 周期 → 2.7%

占比都不高，但差距是 3~5 倍；而浮点的开发效率与可读性优势更大（不用手算标度与溢出）。
第3章已核定：ISR 平均 2020 周期、最坏 2600 周期（占 15.2%/19.5%）——用浮点留出的余量足够。
结论：F28075 一律用 float；IQmath 只用于移植旧代码（第2章术语表口径）。
```

### 20.4 算例 20-3：数值分辨率与溢出的边界

```text
float32 相对精度 ε = 1.2e-7：
  积分器值 A 时的绝对分辨率 = A·ε
    A = 18.85（第11章算例 11-4 的无抗饱和累积值）→ 分辨率 2.3e-6，可忽略 ✓
    A = 1e6（参数错误/发散时的量级）→ 分辨率 0.119，与输出量 0.1 同量级 → 控制彻底失效 ✗
  → 结论：抗饱和不只是"防过冲"，也是"防精度崩塌"；积分器必须被限幅在合理量级内

溢出（定点专属但值得知道）：
  Q15 的 int16 积分器累积到 32768 会回绕成 −32768 → 输出反向跳变（比浮点发散更危险，且无告警）
  对策：定点实现必须用 int32 中间量 + 饱和加法（SATS 指令），并向保护逻辑上报"饱和"标志

量化噪声折算到输出（参考第18章）：
  12bit ADC（1 LSB = 0.806mV）经 11mV/A 的电流通道 → 1 LSB = 0.0733A
  在 1.8kHz 带宽内，量化噪声 RMS ≈ 0.0733/√12 = 0.0212A = 0.23% 额定（9.09A）→ 不构成瓶颈 ✓
```

### 20.5 定点实现：Q 格式、标幺与饱和（浮点平台也必须懂）

定点不是"把 float 换成 int"，而是重新设计一套数值系统：先定标幺基准消除物理量纲，再定 Q 格式分配位数，最后用饱和、舍入与拓宽中间量把误差与溢出关在笼子里。本平台有 FPU，所以正文代码走浮点，但这一节不能跳过——量产机型里有大量无 FPU 的定点 DSP，老代码移植、CLA 定点模式、外购模块接口都会遇到定标问题；而且标幺化、饱和、舍入这三条纪律在浮点系统里同样决定实现质量（第18章算例 18-2 的量化误差是同一件事）。

| Q 格式 | 存储类型 | 数值范围 | 分辨率 | 典型用途 |
| --- | --- | --- | --- | --- |
| Q15 | int16 | −1 ~ +0.99997 | 3.05e-5 | 归一化电压/电流指令、PWM 比较值 |
| Q12 | int16 | −8 ~ +7.9998 | 2.44e-4 | 内环中间量（需要一点动态范围） |
| Q1.14 / Q1.30 | int16 / int32 | −2 ~ +2 | 6.1e-5 / 9.31e-10 | 含符号扩展的滤波器状态 |
| Q30 | int32 | −2 ~ +2 | 9.31e-10 | 谐振器/陷波器系数（第18章 18-3 的结论） |
| int64 中间量 | int64 | — | — | Q30×Q30 相乘（积为 Q60，必须拓宽） |

#### 先标幺，再谈定标

```text
很多定点代码写乱，根因是"物理量直接定标"：电压 700V 想用 Q15 表示 → 只能表示到 1V，精度不够；
换成"每 LSB = 0.1V"又失去统一性。正确顺序是先标幺（标幺值），再定标。

  取单相 2kW 逆变（第13章）为基准：
    V_base = 311 V（相电压峰值）  I_base = 12.86 A（额定峰值）  Z_base = 24.2 Ω
  则：
    L = 1.5mH → ωL = 0.471 Ω → 0.0195 pu
    C = 10µF → 1/(ωC) = 318 Ω → 13.1 pu
    负载 24.2 Ω → 1.0 pu
  → 所有控制器系数都是"1 量级"的数，Q15 随便够；换 380V 机型只改标定系数，控制代码一行不动

  三相 50kW 系统同法：V_base = 311V、I_base = 107.5A、Z_base = 2.89 Ω
    LCL 的 ωL1 = 0.2513 Ω → 0.087 pu（第14章 14-3 的解耦系数 3.59e-4 就是它的标幺值）
```

### 20.6 定点代码：PI 与谐振器怎么写

```text
/* ---------- 定点 PI（Q15 输入输出、int32 累加，含饱和与抗饱和） ---------- */
typedef struct {
    int16_t kp_q15;        /* Kp 定标 Q15 */
    int16_t ki_ts_q15;     /* Ki·Ts 定标 Q15（第19章 19-2 的口径陷阱在定点里更致命） */
    int32_t integ_q15;     /* 积分状态用 int32 拓宽，避免 int16 回绕 */
    int16_t out_min, out_max;
} pi_fx_t;

/* 饱和加法：越界就停在边界，绝不回绕（int16 回绕会直接把输出反相） */
static inline int16_t sat16(int32_t x)
{
    if (x >  32767) return  32767;
    if (x < -32768) return -32768;
    return (int16_t)x;
}

/* 乘法定标：Q15 × Q15 = Q30 → 右移 15 位；用"加半个 LSB 再移位"实现舍入 */
static inline int32_t mul_q15(int16_t a, int16_t b)
{
    const int32_t p = (int32_t)a * (int32_t)b;          /* Q30 */
    return (p + (1 << 14)) >> 15;                      /* 舍入而非截断（见 20.7 算例②） */
}

int16_t pi_fx_step(pi_fx_t *p, int16_t err)
{
    /* ① 条件积分：输出已越限且误差同向 → 冻结（第11章 11-4 的定点版） */
    int32_t unsat = (int32_t)p->kp_q15 * err / 32768 + (p->integ_q15 >> 15);
    if (!(unsat > p->out_max && err > 0) && !(unsat < p->out_min && err < 0)) {
        p->integ_q15 += mul_q15(p->ki_ts_q15, err);       /* 积分累加（Q15） */
    }
    /* ② 输出限幅 */
    const int32_t out = (int32_t)p->kp_q15 * err / 32768 + (p->integ_q15 >> 15);
    if (out > p->out_max) return p->out_max;
    if (out < p->out_min) return p->out_min;
    return (int16_t)out;
}

/* ---------- 定点谐振器（系数 Q30，状态 int64 防溢出） ---------- */
typedef struct { int32_t b0_q30, b2_q30, a1_q30, a2_q30; int64_t s1, s2; } reso_fx_t;

int16_t reso_fx_step(reso_fx_t *r, int16_t x)
{
    /* y = b0·x + s1（Q30 × Q15 = Q45 → 右移 30 得 Q15） */
    const int64_t y = ((int64_t)r->b0_q30 * x >> 30) + (r->s1 >> 15);
    r->s1 = ((int64_t)r->b2_q30 * x >> 30) - ((int64_t)r->a1_q30 * (y << 15) >> 30) + r->s2;
    r->s2 = -(((int64_t)r->a2_q30 * (y << 15)) >> 30);
    return sat16(y);
}
```

> [!WARNING]
> 三处最容易被忽略的定点纪律：①中间量必须拓宽——Q30×Q30 是 Q60，用 int32 装一定溢出（现象：低频包络或间歇性跳变，很难查）；②舍入而非截断——截断带 −0.5 LSB 的系统性偏置，积分器长期累积会变成可测的直流分量（第28章 28-4 的直流抑制环就是它的防线）；③饱和加法而不是回绕——int16 回绕会把 +32767 变成 −32768，输出瞬间反相，后果是炸管而不是"性能下降"。

### 20.7 定点三个算例：位数怎么选

```text
算例①（精度）：第13章 50Hz 谐振器系数 a1 = −1.998998、a2 = 0.999302
  （ωc = 6.28 rad/s 即 1Hz 半带宽口径，与第13章算例 13-4 相同；第13章/第19章另有
    ωc = 31.4（5Hz）的演示对比口径，用途不同，系数不可混用）
  Q15 存储（分辨率 3.05e-5）：
    Δa1 = 3.05e-5 → Δcosθ0 = Δa1/(2r) = 1.53e-5 → δθ = 1.53e-5/0.017453 = 8.77e-4 rad
    频率偏移 Δf = δθ/(2πTs) = 8.77e-4/3.491e-4 = 2.5 Hz ← 50Hz 谐振器跑到 47.5 或 52.5Hz（第18章 18-3 已算过）
  Q30 存储：Δf = 2.5/32768 = 77 µHz ✓
  → 结论：基波/谐波谐振器必须 Q30；一阶平滑类滤波器 Q15 足够

算例②（舍入策略）：积分器每拍累加一个 Q15 小数
  截断（>>15，直接丢弃低位）：每拍平均偏 −0.5 LSB = −1.5e-5
    1kHz 控制频率下 1 秒累积 −1.5e-2 → 相当于积分器多了 0.015 的偏置（可观测为直流）
  舍入（(p + 16384) >> 15）：偏置 ≈0（误差 ±0.5 LSB 随机）
  → 结论：凡是"累加型"运算（积分、DFT、电能累积）一律舍入（第41章计量误差预算里的 0.02% 就靠它）

算例③（速度）：C28x @120MHz，单次 PI（2 乘 2 加 + 限幅）
  浮点（FPU）：约 8 周期
  定点（native int16/int32 乘加）：约 6 周期
  IQmath 库调用版：约 22 周期（含函数调用与定标管理）
  → 定点的速度优势只有 25%，而 IQmath 反而慢 3 倍
  → 本课程口径：有 FPU 就用浮点（第2章）；无 FPU 时才用定点，且优先用 native 整数运算而不是 IQmath
```

> [!CAUTION]
> 失败案例复盘（积分器定点溢出）：某定点机型在输入电压 +12% 时偶发"输出反相、母线过流"。波形显示每 20~40ms 出现一次单拍反向脉冲，符合 int16 积分器回绕特征（累积到 32767 后翻成 −32768）。根因是积分状态用 int16 且无饱和加法；改为 int32 状态并在输出处饱和后故障消失。定点系统的溢出不报警，它只是安静地把数换成另一个数，因此饱和与抗饱和必须做在最底层，不能指望上层限幅兜住。

### 20.8 代码：离散化工具与"编译期固定 Ts"

```c
/* ---------- disc.h：把 Ts 与常见离散化一次性写清，避免各处手算 ---------- */
#define CTRL_FSW_HZ   18000.0f
#define CTRL_TS       (1.0f/CTRL_FSW_HZ)         /* 55.6µs，平台统一 */
#define CTRL_TS_US    55.6f
#define CTRL_TD_1P5   (1.5f*CTRL_TS)             /* 83.3µs，1.5Ts 延迟链 */

/* Tustin 辅助：把连续频率折成预畸变后的 k = tan(ωcTs/2)，再算系数 */
static inline float tustin_k(float fc_hz) { return tanf(3.14159265f*fc_hz*CTRL_TS); }

/* 一阶低通（Tustin + 预畸变），fc 由 18 章设计给出 */
static void disc_lpf1_init(biquad_t *f, float fc_hz)
{
    const float k = tustin_k(fc_hz);
    f->b0 = k/(1.0f+k);  f->b1 = f->b0;  f->b2 = 0.0f;
    f->a1 = (k-1.0f)/(k+1.0f);            f->a2 = 0.0f;
    biquad_reset(f);
}

/* PI（Tustin）：离散后与"Kp + Ki·Ts 形式"等价的一次实现
   连续：Gc = Kp + Ki/s → Tustin：
     b0 = Kp + Ki·Ts/2,  b1 = −Kp + Ki·Ts/2  （对应的差分方程直接进代码）
   注意：本课程固件用"比例 + 增量积分"写法（11.7），两者数学等价、前者更好做抗饱和 */
static void disc_pi_init(ctrl_pi_t *p, float kp, float ki_1s)
{
    p->kp     = kp;
    p->ki_ts  = ki_1s * CTRL_TS;      /* 唯一允许进运算的口径（第19章 19.2） */
    p->ki_1s  = ki_1s;                /* 文档字段，不参与运算 */
}

/* 定点移植用（仅在旧代码场景）：Q15 饱和加法宏，避免回绕 */
#define Q15_SAT_ADD(a,b)  __builtin_sat_add(a,b)   /* 语义示意：实际用 SATS/饱和指令 */

/* ---------- 上电自检：Ts 相关常量是否与平台口径一致 ---------- */
uint8_t disc_selfcheck(void)
{
    if (fabsf(CTRL_TS*CTRL_FSW_HZ - 1.0f) > 1e-4f) return 1u;  /* Ts 与 fsw 不一致 */
    if (fabsf(1.0f/CTRL_TS - 18000.0f) > 0.5f)     return 2u;  /* 折算与平台不符 */
    return 0u;
}
```

### 20.10 失败案例复盘：5kHz 交越"设计对、实测偏两成"

> [!CAUTION]
> 现象：某 DC-DC 环路设计交越 5kHz，实测扫频只有 4.1kHz（−18%），相位裕度比预期好很多，动态却偏慢。定位路径：①核对模型与系数（手算无误）→ ②怀疑离散化（按算例 20-1 计算 Tustin 频率畸变 −17.8%，与实测 −18% 吻合）→ ③加预畸变后实测 4.95kHz。根因：Ts/fc 比值不够小（18kHz 采样、5kHz 交越 = 3.6 倍），Tustin 的频率轴压缩不可忽略。预防措施：①交越频率与采样频率之比尽量 ≥10（本课程统一 18kHz 载波 / ≤1.8kHz 交越）；②若必须高比值，一律用预畸变并把折算写进设计文档；③上机核对必须包含"实测交越频率"这一项（本课程列为 LAB1 判据）。
