**本章要解决的问题：** 合闸瞬间母线电容相当于短路：冲击电流能到几 kA。本章用三个算例算清冲击电流、预充电阻与接触器的选型、以及"预偏置"（输出已有电压时的软启动）。

### 35.1 不预充会怎样（先算再设计）

```text
母线电容 28.6mF（第1章口径），回路电阻（线缆 + 电感 DCR）0.05Ω
 合闸瞬间冲击电流 I_pk = V/R = 700/0.05 = 14,000 A （上级断路器 63A 立即跳闸）
 即使电阻 0.2Ω 也有 3,500A 
 充电时间常数 τ = R·C = 0.05×28.6e-3 = 1.43 ms（能量几乎瞬间灌入）
 峰值能量 = ½CV² = 0.5×28.6e-3×700² = 7,007 J（相当于 7kJ 在毫秒级释放）
 → 上级断路器、接触器触点、电容都承受不了

结论：任何 ≥1mF 的母线都必须预充；预充电阻必须能把冲击电流限制到
 "断路器额定值的 2~3 倍且持续时间 <100ms"
```

### 35.2 算例 35-1：预充电阻与时间

```text
目标：冲击电流 ≤100A（上级 63A 断路器不跳）
 R_pre ≥ V/I = 700/100 = 7 Ω → 取 10Ω（留余量）

充电过程（RC，C = 28.6mF，R = 10Ω）：
 τ = R·C = 10×28.6e-3 = 0.286 s
 充到 95% 需 3τ = 0.86 s；充到 99% 需 4.6τ = 1.32 s
 实际取"充到 90%（2.3τ = 0.66s）即由主接触器旁路"，剩余由主回路完成

电阻功率校核（关键，最易漏）：
 预充过程中电阻消耗的总能量 = ½CV² = 7,007 J（与充电速度无关，全部转化为热）
 若要求在 0.86s 内完成，平均功率 = 7007/0.86 = 8,148 W
 → 不能选普通电阻：必须选"脉冲耐受型"（如铝壳绕线 100W 但允许 8kW×1s 的短时冲击）
 或直接按"能量"选型：W = ½CV² = 7.0 kJ 的单次能量能力，并规定"两次预充间隔 ≥30s"

校核公式（写进设计说明）：E_once = ½·C·V² = 7.0 kJ；P_avg = E/τ_charge；T_间隔 ≥ 5×(E/P_rated)
```

### 35.3 算例 35-2：预充电流与三相输入的差异

```text
三相 380V 输入（线电压峰值 537V）经不控整流 → 母线 700V？不成立：
 不控整流的三相母线电压 = 537V（整流后峰值），要得到 700V 必须用 Boost PFC（第12章）
 → 预充分两级：
 ① 交流侧预充（经预充电阻 + 整流桥）把母线充到 537V：
 I_pk = 537/10 = 53.7A ≤100A；τ = 10×28.6e-3 = 0.286s，3τ = 0.86s
 ② 主接触器旁路后启动 Boost，把母线升到 700V（Boost 自身软启动，占空比斜坡）
 升压过程从 537V 到 700V 的能量差 = ½C(700² − 537²) = 0.5×28.6e-3×(490000−288369) = 2,884 J
 → 由 PFC 在 50ms 内提供 → 平均功率 57.7kW（瞬时）→ PFC 必须限制占空比上升率
 实测做法：d_max 从 0 以 500/s 的速率爬升 → 0.3s 到额定
 判据：预充阶段母线电流 ≤100A；升压阶段 ≤1.5 倍额定输入电流
```

### 35.4 算例 35-3：预偏置——输出侧已有电压时的软启动

```text
场景：模块化 UPS 中某模块重新投入，输出母线上已有 220V（其他模块在供电）
 若直接投入本模块的逆变：本模块输出 0V，与母线 220V 之间通过输出阻抗 Z_out = 0.1Ω
 → 冲击电流 = 220/0.1 = 2,200A （远超额定的 1.4 倍峰值）

 处理（"预偏置"三步）：
 ① 检测输出母线电压（幅值/相位）
 ② 本模块逆变先"跟随"该电压（把 v_ref 设为测得的母线电压，进入受控电流源模式）
 ③ 当输出电流 <5% 额定且相位差 ≤1° 时，切换为电压源模式并合闸输出接触器
 时间预算：跟随建立 50ms + 判定 3 个周期 60ms ≈ 0.1s

 判据：投入瞬间冲击电流 ≤1.2 倍额定峰值；投入后 20ms 内电流分配到位（第38章均流）
```

### 35.5 代码：预充与软启动时序

```c
/* ---------- softstart.c ---------- */
#define SS_RPRE_OHM     10.0f         /* 预充电阻（35-2） */
#define SS_VBUS_READY_V 630.0f        /* 预充完成阈值（537V 的 90% + 余量） */
#define SS_TMAX_MS      5000u         /* 预充超时（超过即告警并断开） */
#define SS_D_RATE       500.0f        /* 占空比爬升率（1/s，35-3） */
#define SS_PREBIAS_DV   2.0f          /* 预偏置相位/幅值判定容差（%） */

typedef enum { SS_IDLE = 0, SS_PRECHARGE, SS_BYPASS_RELAY, SS_BOOST_RAMP, SS_ONLINE, SS_TIMEOUT } ss_state_t;

void task_softstart(void)
{
 static ss_state_t s = SS_IDLE;
 static uint16_t t_ms = 0;
 const float vbus = adc_to_volt(g_adc.raw_vbus, &g_adc.cal_vbus);

 switch (s) {
 case SS_IDLE:
 if (g_cmd.start) { precharge_relay_on(); s = SS_PRECHARGE; t_ms = 0; }
 break;

 case SS_PRECHARGE: /* ① 经预充电阻充电 */
 if (vbus >= SS_VBUS_READY_V) { main_relay_on(); s = SS_BYPASS_RELAY; t_ms = 0; }
 else if (++t_ms > SS_TMAX_MS) { s = SS_TIMEOUT; precharge_relay_off(); }
 break;

 case SS_BYPASS_RELAY: /* ② 接触器旁路电阻 */
 if (++t_ms > 50u) { precharge_relay_off(); s = SS_BOOST_RAMP; t_ms = 0; }
 break;

 case SS_BOOST_RAMP: { /* ③ PFC 占空比斜坡升压 */
 static float d = 0.0f;
 d += SS_D_RATE * 0.001f; /* 每 1ms 加 0.0005 */
 if (d > 0.8f) d = 0.8f;
 pfc_set_duty_limit(d); /* 限幅而非直接给占空比 */
 if (fabsf(vbus - PFC_VDC_REF) < 0.02f * PFC_VDC_REF && ++t_ms > 100u) {
 pfc_release_limit(); s = SS_ONLINE;
 }
 break;
 }
 case SS_TIMEOUT:
 g_prot.fault |= PROT_F_PRECHARGE_TIMEOUT; /* 预充超时：母线充不上来 */
 break;
 default: break;
 }
 g_status.ss_state = (uint8_t)s;
}

/* 预偏置投入（35-4）：输出母线已有电压时的"跟随 → 合闸" */
void task_prebias(void)
{
 if (!g_cmd.online_req) return;
 if (!prebias_v_match(SS_PREBIAS_DV)) { inv_follow_mode_enable(); return; } /* 先跟随 */
 if (inv_output_current_pu() < 0.05f && pll_phase_diff_deg() < 1.0f) {
 inv_voltage_mode_enable();
 output_contactor_on();
 log_fault_event(EV_PREBIAS_DONE, 0u);
 }
}
```

### 35.7 失败案例复盘：预充电阻按功率选型，第二次上电就烧断

> [!CAUTION]
> 现象：样机第一次上电正常，断电后 5s 内再次上电，预充电阻冒烟开路，母线没充上电。定位路径：①量电阻（开路）→ ②核算能量（E = ½CV² = 7 kJ，而选的是 100W 普通绕线电阻，单次脉冲耐受能量仅约 400 J）→ ③查"两次预充间隔要求"（按 E/P_rated = 7007/100 = 70s，未在软件里做间隔限制）。根因：预充电阻按"平均功率"选型，忽略了"单次脉冲能量"这个主导参数；软件也没有做最小间隔限制。预防措施：①预充电阻按 E = ½CV² 选型（脉冲能量耐受），并注明允许的最小间隔；②软件加"预充最小间隔"计时（本例 ≥30s）与"预充次数统计"；③把"连续上电"写入测试用例（LAB5）。

### 35.10 补充：模块热插拔的五步时序（含参考代码对照）

预充与预偏置解决"这台机器自己怎么上电"，热插拔解决"系统运行中把一台模块并进来"。两者共用同一批动作（预充、同步、缓慢并入），但热插拔多了"识别"与"核查"两步，且**任何一步失败都必须干净退出**——运行中并入失败的代价是母线短路或两台模块互相灌电流。

```text
五步时序（本课程口径，顺序不可交换）：

① 插入检测（50ms）
 用长短针配合：长针先接通 ID/通信地，短针后接通功率回路 → 保证"先识别、后上电"
 ID 电阻或 EEPROM 给出模块地址（与第38章均流地址一致）

② 读取模块信息（200ms）
 读地址、参数版本、标定系数 CRC、固件版本（第37章 37-4）
 判据：与本机版本兼容（不兼容直接拒绝并报事件码），标定系数 CRC 通过

③ 预充与同步（900ms）
 经预充电阻把模块内母线充到与本机母线差 ≤5%
 （第35章 35-2：10Ω/28.6mF，τ = 0.286s；预算 900ms = 3.15τ → 充到 95.7%，差 4.3% ≤5%；
 若只给 800ms 则仅 2.8τ/93.9%，差 6.1% 不达标——预算必须按 3τ 校核）
 同时把本模块的参考相位与系统同步（第29章相位靠齐、第30章三同步判据：幅值 ≤2%、相位 ≤1°、频率 ≤0.1Hz）

④ 相序与相位核查（200ms）
 三相相序（正序/负序）、相序与另一台模块一致、输出相位差 ≤1°
 注入测试：先给很小的电压指令，量环流；环流 >10% 额定即判定不一致，退出

⑤ 缓慢并入并参与均流（100ms）
 电流指令斜坡限速 ≤10%/ms（并入瞬间的冲击由斜坡而非环路承担）
 并入后 20ms 内进入均流环（第38章 K_sh = 0.1Ω）

时间预算合计 ≈ 1.45s（不含人工插拔动作）
阻断条件：任一步失败 → 断开输出继电器、置事件码、等待重新插入（不允许"重试并入"）
```

```text
并入冲击的定量（为什么必须限速）：
 并入瞬间电压差 ΔV 与回路阻抗 Z_loop 决定冲击
 ΔV = 2V（预充后的残余差）、Z_loop = 0.1Ω → 冲击 20A（26% 额定）——可接受
 ΔV = 10V（未做预充）→ 冲击 100A（132% 额定）→ 触发保护并可能损坏接触器
 斜坡限速的作用：把"并入"从"阶跃"变成"斜坡"，
 电流指令限速 10%/ms → 达到额定需要 10ms → 期间环流由差流阻尼与均流环吸收
判据：并入瞬间冲击 ≤1.2 倍额定峰值；并入后 20ms 内各模块电流不平衡度 ≤5%
```
