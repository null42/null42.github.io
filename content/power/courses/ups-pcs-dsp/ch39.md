**本章要解决的问题：** 把效率从"指标"变成"可设计、可测量、可收益"的三步账：损耗分解（算给谁看）、ECO 模式 的收益与风险、休眠轮换 的策略。

### 39.1 效率指标与损耗分解（50kW 口径）

```text
验收要求：效率 ≥95.5%（半载）/ ≥96.5%（额定）（验收表 B 组）
 额定 50kW、效率 96.5% → 总损耗 = 50000×(1/0.965 − 1) = 1,814 W

 损耗分解（典型分布，供改进排序用）：
 通态损耗（通态损耗） 620 W（34%）← 轻载时占主体
 开关损耗 480 W（26%）← 与频率成正比（第31章五段式可省 1/3）
 磁性元件（铜损+铁损） 380 W（21%）
 控制/驱动/风扇/采样 334 W（19%）← 与负载几乎无关 → 轻载效率的主因
 → 改进优先级：轻载看"固定损耗"（控制+风扇+驱动），满载看"通态+开关"

 说明：本表是工程典型分布，用于量级判断与改进排序；精确值须逐器件按手册积分（附录 C）。
```

### 39.2 算例 39-1：ECO 模式的年收益（用数字说服客户）

```text
在线模式效率 96.5%，旁路（ECO）模式效率 99.5%（少了 AC-DC-AC 两次变换的损耗）
 50kW 负载：在线损耗 1,814 W；ECO 损耗 = 50000×(1/0.995 − 1) = 251 W
 省 = 1,814 − 251 = 1,563 W
 年节省电量 = 1.563 kW × 8,760 h = 13,692 kWh（按 0.8 元/kWh ≈ 1.1 万元/年）

 代价（必须一起算）：
 ① 市电异常时需切回逆变：切换时间 ≤1ms（第30章），期间负载暴露于电网扰动
 ② ECO 下谐波/闪变抑制能力下降（负载面对的是未经净化的市电）
 ③ 切换动作增加（电网质量差的现场可能频繁切换）→ 影响寿命与可靠性
 判据：ECO 模式 ≥99%（额定）、≥98.5%（半载）、≥97.5%（轻载）（验收表 B 组）
```

### 39.3 算例 39-2：增强 ECO 的代价（仍做谐波治理）

```text
增强 ECO（增强 ECO）：负载走旁路，但 PFC/变流器仍工作以做输入谐波与 PF 治理
 要求：输入 PF ≥0.98、电流谐波 <5%（验收表 A 组）
 损耗重新分配：
 负载支路（旁路）损耗 = 50kW×0.5% = 250 W（SCR + 滤波器）
 PFC 只处理"谐波与无功"（约 15% 容量）：损耗 = 7.5kW×4% = 300 W
 合计 550 W → 效率 = 50000/(50000+550) = 98.9% 仍优于在线模式
 与 ECO 的差别：多花 300 W，换来"输入电能质量达标 + 无缝切换"
 → 选择依据：客户是否考核输入指标（数据中心通常考核，所以要增强 ECO）
```

> [!TIP]
> 超级 ECO ＝ 动态在线跟踪：超级 ECO 下逆变器仍在线运行但不带负载，其输出相位/幅值动态跟踪旁路（市电）电压，因此随时可直接带载，转移时间近 0。它与增强 ECO 的本质差别：增强 ECO 的逆变器处于待机休眠（静态开关不动作），切换前需先建同步，转移为毫秒级。| 项目 | 增强 ECO | 超级 ECO || --- | --- | --- || 逆变器状态 | 待机休眠（静态开关不动作） | 在线空载运行，相位/幅值持续跟踪旁路 || 输入 PF / 谐波 | PF ≥0.98、THDi <5%（PFC 仍工作，39.3） | 同增强 ECO（PFC 仍工作） || 转移时间 | 毫秒级（先同步、再切换） | 近 0（已持续跟踪，可直接带载） || 适用工况 | 考核输入电能质量、可接受毫秒级转移的现场 | 对转移时间极敏感、又要省电的现场 || 主要风险 | 切换瞬间负载暴露于市电扰动；SCR 动作寿命（39.7） | 逆变器空载运行仍有损耗；跟踪失锁必须立即转双变换在线 |术语落点：VFI（电压频率独立，双变换始终在线）见第 1/34 章；在线扩容（模块化 UPS 热插拔增减模块）见第 38 章并机。

### 39.4 算例 39-3：休眠轮换的收益与寿命均衡

```text
4 模块 × 50kW 带 25kW 负载（每模块 12.5% 负载率，效率约 90%）：
 总损耗 = 4 × (12.5kW×(1/0.90 − 1)) = 4 × 1,389 = 5,556 W
 休眠 2 个模块，剩 2 个各带 25%（效率 94%）：
 总损耗 = 2 × (25kW×(1/0.94 − 1)) = 2 × 1,596 = 3,192 W
 另外休眠模块自身待机损耗 ≈ 2×30 W = 60 W（待机是成本项，须从收益中扣除）
 → 省 = 5,556 − 3,192 − 60 = 2,304 W（比 ECO 的 1,563 W 还多）

 轮换策略（寿命均衡）：
 每小时轮换一次（4 模块 → 每模块每天运行 12h）→ 风扇与电解电容寿命按"运行小时数"摊平
 轮换时的负载转移：先启动备用模块（同步 → 均流 → 再休眠另一个），转移过程 ≤100ms
 判据：单模块负载率不超过 80%；轮换期间输出电压跌落 ≤5%
 限制：不能休眠到只剩 1 个模块（失去冗余）；休眠后剩余容量必须满足 N+1
```

### 39.5 代码：ECO 决策与休眠轮换

```c
/* ---------- eco.c ---------- */
#define ECO_LOAD_TH      0.40f       /* 负载率低于 40% 才允许休眠（39.4 休眠算例） */
#define ECO_SLEEP_MIN_N  2u          /* 至少保留 2 个模块在线（N+1 冗余） */
#define ECO_ROTATE_MS    3600000u    /* 每小时轮换一次 */
#define ECO_SWITCH_RATE  2.0f        /* 允许的切换次数/小时上限（电网质量差时退出） */

typedef struct { uint32_t run_ms; uint8_t sleeping; uint8_t rotate_due; } eco_mod_t;
static eco_mod_t g_eco[PAR_N_MAX];
static uint8_t g_eco_enable;

/* 1s 任务：休眠与轮换决策 */
void task_eco_decide(void)
{
 if (!g_eco_enable) return;

 const float load = sys_load_ratio(); /* 0~1 */
 const uint8_t n_on = par_online_count();

 /* ① 电网质量差 → 退出 ECO（避免频繁切换） */
 if (grid_switch_count_per_hour() > ECO_SWITCH_RATE || g_grid.quality_bad) {
 eco_exit(); return;
 }

 /* ② 轻载 → 休眠（保留 N+1 模块） */
 const uint8_t n_need = (uint8_t)(load / 0.8f + 1.0f) + 1u; /* 单模块 ≤80% + 1 冗余 */
 if (load < ECO_LOAD_TH && n_on > n_need && n_on > ECO_SLEEP_MIN_N) {
 eco_sleep_one(); /* 先唤醒备用、均流后休眠一个 */
 }

 /* ③ 轮换：运行时间最长的优先休眠 */
 for (uint8_t k = 0; k < g_nmod; k++) {
 if (g_eco[k].sleeping) continue;
 g_eco[k].run_ms += 1000u;
 if (g_eco[k].run_ms > ECO_ROTATE_MS) g_eco[k].rotate_due = 1u;
 }
 eco_rotate_process(); /* 同步→均流→休眠，≤100ms */
}

/* 休眠/唤醒的顺序（关键：绝不能先休眠后建压） */
void eco_sleep_one(void)
{
 if (!eco_pick_spare()) return; /* ① 找 standby 模块 */
 par_start_module(eco_pick_spare()); /* ② 启动并同步（第30章判据） */
 if (par_current_shared_ok()) { /* ③ 均流建立 */
 const uint8_t victim = eco_pick_longest_run(); /* ④ 选运行最久的模块休眠 */
 par_stop_module(victim); /* 封波 → 断输出接触器 */
 g_eco[victim].sleeping = 1u;
 }
}
```

### 39.7 失败案例复盘：为省电频繁进出 ECO，SCR 与风扇提前失效

> [!CAUTION]
> 现象：某机房（电网电压波动大）投运 14 个月后 SCR 模块与风扇批量故障，故障日志显示 ECO 切换次数日均 300 次以上。定位路径：①读日志（ECO 进出记录）→ ②核算（每次切换 SCR 承受一次电流冲击，机械/热循环累积）→ ③确认"电网波动 + 无切换次数限制"是根因 → ④加入"切换次数/小时上限"与"电网质量判据"后，切换降到日均 3 次。根因：把 ECO 当成"永远省电"的模式，忽略了切换带来的寿命消耗与负载暴露风险。预防措施：①ECO 必须带"电网质量判据"与"切换频次限制"（39-5 的ECO_SWITCH_RATE）；②把 ECO 切换次数、SCR 动作次数纳入遥测与寿命统计（第41/46章）；③现场调试时用日志确认切换率符合预期再交付。
