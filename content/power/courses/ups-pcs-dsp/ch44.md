**本章要解决的问题：** 并网变流器在电网断电后若继续给局部负载供电，就形成孤岛——对检修人员是致命风险。三个算例：被动检测的盲区、主动法的扰动代价、检测时限与 IEEE 1547 要求。

### 44.1 检测方法矩阵

| 类型 | 方法 | 检测时间 | 盲区（NDZ） | 对电能质量影响 |
| --- | --- | --- | --- | --- |
| 被动 | 过/欠压、过/欠频 | 10ms~2s | 大（功率匹配时失效） | 无 |
| 被动 | 电压相位跳变、谐波突变 | 20~100ms | 中 | 无 |
| 主动 | 主动移频（AFD）/无功扰动 | ≤2s（典型 0.3~1s） | 小 | THDi 略升 |
| 主动 | 阻抗测量（注入谐波） | ≤1s | 很小 | 注入谐波需控制 |

### 44.2 算例 44-1：被动法的盲区有多大

```text
孤岛发生瞬间：负载功率与变流器输出功率匹配程度决定电压/频率变化
 设电网断开瞬间本地负载 = 变流器输出（ΔP = 0，ΔQ = 0）：
 电压与频率都不变 → 过/欠压、过/欠频完全失效（盲区 100%）

 量化盲区（近似）：
 功率不平衡 ΔP/P = 20% → 电压变化 ≈ 20%×Z_grid/R_load 耦合量级 → 过压/欠压可测
 功率不平衡 <5% → 电压变化 <2% → 落在 ±10% 阈值内 → **检测不到**
 → 结论：纯被动法在"功率匹配"工况下必然失效（这是标准要求必须有主动法的原因）

 本课程口径：被动 + 主动双路，任一触发即退出（≤2s，IEEE 1547 要求）
```

### 44.3 算例 44-2：主动移频（AFD）的扰动代价

```text
AFD 原理：在频率指令上加一个小正反馈（每周期偏移 Δf = k_f·(f_meas − f_nom)）
 孤岛时频率逐步漂移 → 触发过/欠频保护（0.3~1s）
 并网时电网"钉住"频率，扰动表现为频率跟踪误差

 参数：k_f = 0.02（每周期偏移 2% 的频差），Δf_max = 0.5Hz
 并网时的频率抖动：稳态下 f_meas ≈ f_grid，扰动 ≈ k_f×(PLL 频率误差) ≈ 0.02×0.01Hz = 0.2mHz 可忽略
 孤岛时的漂移速度：每周期（20ms）频率变化 2%×当前偏移 → 呈指数增长
 从 0.01Hz 漂到 0.5Hz（触发阈值）：0.5 = 0.01×1.02^n → n = ln50/ln1.02 = 197 周期 = 3.9s 太慢
 → 提高 k_f 到 0.05：n = ln50/ln1.05 = 80 周期 = 1.6s 仍满足 ≤2s
 但并网时频率抖动 = 0.05×0.01 = 0.5mHz（仍可忽略）
 → 结论：k_f = 0.05 是"检测速度 vs 电能质量"的好折中；更大（0.1）会在弱电网下引起频率振荡

 与 LVRT 的冲突（第33章）：电网跌压期间若把频率扰动加大，可能误判孤岛而脱网 
 → 规则：LVRT 期间暂停主动法（只保留被动法），跌压结束后恢复
```

### 44.4 算例 44-3：检测时限与保护配合

```text
IEEE 1547 要求：孤岛发生后 ≤2s 内停止输出（本课程按 ≤1s 设计，留余量）
 时间预算：
 被动检测（电压/频率越限）：≤200ms
 主动法（AFD 漂移）：≤1.6s（k_f = 0.05 时）
 断路器/接触器动作：≤20ms
 → 最坏路径 1.6 + 0.02 = 1.62s；若要求 ≤1s：提高 k_f 到 0.1 时
 n = ln50/ln1.1 ≈ 41 周期 = 0.82s ≤ 1s 已满足时限；
 保持 k_f = 0.05（1.6s）时才需要加阻抗测量法

 与"防误动"的平衡：
 误动的代价：无故障时脱网 → 负载失电（对 UPS 而言是严重事故）
 → 三级确认：被动越限（快速）→ 主动漂移（持续）→ 电网电压/电流相关性判据
 判据：误动率 ≤1 次/年（按现场电网扰动统计），漏检率（盲区）≤5%（功率匹配 ±5% 内）
```

### 44.5 代码：双路检测与退出

```c
/* ---------- island.c ---------- */
#define ISL_KF            0.05f       /* AFD 正反馈系数（44-3） */
#define ISL_DF_MAX_HZ     0.5f        /* 频率扰动上限 */
#define ISL_V_HI_PU       1.10f       /* 过压阈值（IEEE 1547 的 110%） */
#define ISL_V_LO_PU       0.88f
#define ISL_F_HI_HZ       50.5f       /* 过频阈值（50Hz 系统，df = f − 50） */
#define ISL_F_LO_HZ       49.3f       /* 欠频阈值；60Hz 系统另行定义（60.5/59.3） */
#define ISL_T_MAX_MS      1000u       /* 本课程设计时限 ≤1s */
#define ISL_NDZ_LOCK      0.05f       /* 功率匹配 ±5% 时盲区标志（触发阻抗法） */

static uint32_t g_isl_start_ms;
static uint8_t g_isl_active;

/* 每拍（或每工频周期）调用：被动 + 主动 */
void island_detect_step(float v_pu, float f_hz)
{
 /* ① 被动：幅值/频率越限 */
 if (v_pu > ISL_V_HI_PU || v_pu < ISL_V_LO_PU ||
 f_hz > ISL_F_HI_HZ || f_hz < ISL_F_LO_HZ) {
 island_trip("passive");
 return;
 }

 /* ② 主动：AFD 频率扰动（LVRT 期间暂停，第33章） */
 if (g_mode != GM_LVRT) {
 const float df = ISL_KF * (f_hz - 50.0f); /* 正反馈 */
 pll_add_freq_offset(clampf(df, -ISL_DF_MAX_HZ, ISL_DF_MAX_HZ));
 }

 /* ③ 盲区补偿：功率匹配时切阻抗测量法（注入小幅 5 次谐波看阻抗变化） */
 const float dp = fabsf(p_measured() - p_local_est()) / fmaxf(p_local_est(), 1.0f);
 if (dp < ISL_NDZ_LOCK) island_impedance_probe_enable();
}

/* 退出流程：先停输出再分闸（避免带载分断，第43章同理） */
void island_trip(const char *why)
{
 if (g_isl_active) return;
 g_isl_active = 1u; g_isl_start_ms = g_ms_tick;
 inv_output_disable(); /* ① 停输出 */
 grid_breaker_open(); /* ② 分闸 */
 log_fault_event(EV_ISLAND, (uint16_t)(why[0])); /* ③ 记录（含时间戳） */
 g_status.island_time_ms = g_ms_tick - g_isl_start_ms;
}

/* 时限自检：超过 1s 未完成退出 → 二级告警 */
void task_island_watchdog(void)
{
 if (g_isl_active && (g_ms_tick - g_isl_start_ms) > ISL_T_MAX_MS) {
 g_prot.fault |= PROT_F_ISLAND_SLOW;
 }
}
```

### 44.6 上机核对（LAB5）

| 步骤 | 该看到什么 | 判据 |
| --- | --- | --- |
| 功率匹配（ΔP ≤5%）孤岛 | 检测时间 | ≤1s（44-4 预算） |
| 功率不匹配（ΔP ≥20%）孤岛 | 被动法检测时间 | ≤200ms |

| 弱电网（SCR 小） | 是否误判 | 不误动（k_f 不过大） |
| LVRT 期间 | 主动法是否暂停 | 暂停，只保留被动法 |
| 退出过程 | 电流波形 | 先降流后分闸，无带载分断 |

### 44.7 失败案例复盘：主动法增益过大，弱电网下频繁误脱网

> [!CAUTION]
> 现象：某现场（弱电网）每天脱网 3~5 次，报"孤岛保护动作"；同一设备在实验室从不误动。定位路径：①取现场波形（频率出现 ±0.08Hz 的缓慢摆动）→ ②核算 AFD（k_f = 0.15，增益偏大，与弱电网的低频阻抗形成正反馈）→ ③降到 0.05 并加"三级确认"后误动归零，同时孤岛检测仍在 1.6s 内完成（满足 IEEE 1547 ≤2s；功率匹配工况由阻抗法补齐 ≤1s 设计目标）。根因：主动法增益按"最快检测"整定，忽略弱电网下的稳定裕度（第14章 SCR 概念）。预防措施：①k_f 按"最小 SCR"工况校核（本课程统一 0.05）；②加三级确认与"连续 N 次越限"去抖；③上机核对必须包含弱电网/长电缆工况；④保留"检测时间 vs 误动率"的现场统计并要求上报（第41章）。
