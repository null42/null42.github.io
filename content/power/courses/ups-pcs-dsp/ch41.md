**本章要解决的问题：** 遥测不是"把变量发上去"：它要有**量级可信、时间可追、误差可算**。三个算例：计量精度预算、时间对齐与同步采样、黑匣子的事件记录设计。

### 41.1 遥测清单与精度要求

| 类别 | 量 | 精度要求 | 主要误差源 |
| --- | --- | --- | --- |
| 计量（对外） | 输出电压/电流/功率/电能/PF | ±0.5%（0.5 级） | 标定精度、采样同步、谐波 |
| 监视（对内） | 母线/电池/温度/THDu | ±2% | 量程选择、温度漂移 |
| 诊断 | ISR 时长、通信统计、告警计数 | ±1 个计数 | 统计口径 |

### 41.2 算例 41-1：0.5 级计量的误差预算（RSS）

```text
目标：功率计量 ±0.5%（联合误差）
  分项（各自 1σ）：
    ADC 增益/参考精度        0.10%
    两点标定残差             0.15%（第9章 9-4）
    采样不同步（电压/电流相差 0.2°） 0.35% ← 主导项！（按 PF=1 假设；PF<1 时误差按 cosφ 加权放大，ΔP/P ≈ tanφ·Δθ，见 41.7 与 E1）
    互感器/分流器温度漂移     0.10%
    计算截断（定点/单精度）   0.02%
  RSS = √(0.10²+0.15²+0.35²+0.10²+0.02²) = √(0.01+0.0225+0.1225+0.01+0.0004) = 0.407% ✓

  → 结论：**采样同步是 0.5 级计量的决定性因素**。
    若把电压/电流采样相位差从 0.2° 降到 0.05°（同步触发），该项误差降到 0.087%
    → RSS 降到 0.22%（达到 0.2 级）
  → 这就是第5章"同一 SOC 触发多通道"的意义
```

### 41.3 算例 41-2：时间对齐与电能累积

```text
电能累积：E += P·Δt。若 P 的采样周期抖动 1%（Δt 用理论值而非实测），
  长时间累积误差 = 1%（不可接受；0.5 级要求 ≤0.5%）
  → 用定时器计数（实测 Δt = 计数值/时钟频率），误差 ≤0.001% ✓
  → 或直接对 P 求和（配合同步采样，能量 = Σ(P·Ts)，Ts 由硬件定时器保证）

  时间戳精度：SOE 要求 ≤10ms
    1ms 任务里取 g_ms_tick → 分辨率 1ms ✓；与上位机时钟同步用 NTP/SNTP（偏差 ≤100ms，
    但事件内部排序只用本机 tick，避免时钟跳变污染顺序）
```

### 41.4 算例 41-3：黑匣子的容量与保存策略

```text
黑匣子内容：故障码 + 时间戳 + 关键变量快照 + 故障前后各 20 拍波形
  单条记录：8 B 头 + 32 B 变量 + 40 拍×6 通道×2 B = 8+32+480 = 520 B
  环形缓冲 64 条 = 33 KB（RAM 与 Flash 都可承受）
  掉电保存：故障发生时立即写 Flash（单次擦写 ~10ms，需在故障后 100ms 内完成）

  写 Flash 的纪律（关键）：
    ① 不在 ISR 里写 Flash（擦写时间不可控，会挤掉控制周期）
    ② 由 10ms 任务触发，写期间关闭不相关中断
    ③ Flash 擦写寿命 ~10 万次 → 统计并限制（配合第46章寿命模型）
  判据：故障后 100ms 内记录落盘；连续 1,000 次故障记录无丢失
```

### 41.5 代码：遥测量与事件记录

```c
/* ---------- telemetry.c ---------- */
#define TELEM_SOE_LEN   64
#define TELEM_SNAP_PRE  20                 /* 故障前拍数 */
#define TELEM_SNAP_POST 20

typedef struct {
    uint32_t ms; uint16_t code; uint16_t mode;
    float v_out, i_out, v_bus, temp, thdu, debt_ah;
} soe_t;

static soe_t g_soe[TELEM_SOE_LEN];
static uint16_t g_soe_w;

/* 计量量：由"同步采样 + 实测 Δt"计算，保证 0.5 级 */
float meter_power_w(void)
{
    static float energy_j = 0.0f;
    const float v = adc_to_volt(g_adc.raw_vout, &g_adc.cal_vout);
    const float i = adc_to_amp (g_adc.raw_iout, &g_adc.cal_iout);
    const float p = v * i;                                  /* 瞬时功率 */
    energy_j += p * CTRL_TS;                                /* Δt 由定时器口径保证（41-3） */
    return lpf1_step(&g_p_lpf, p);                          /* 上报用平均功率 */
}

/* 事件记录：故障码 + 快照（在 10ms 任务里落盘，不进 ISR） */
void soe_push(uint16_t code)
{
    soe_t *s = &g_soe[g_soe_w];
    s->ms = g_ms_tick;  s->code = code;  s->mode = (uint16_t)g_fsm.st;
    s->v_out = inv_v_rms();  s->i_out = inv_output_current_rms();
    s->v_bus = adc_to_volt(g_adc.raw_vbus, &g_adc.cal_vbus);
    s->temp = temp_hs_c();   s->thdu = g_harm_thd;
    g_soe_w = (uint16_t)((g_soe_w + 1u) % TELEM_SOE_LEN);
    g_flash.pending = 1u;                                   /* 交给 10ms 任务写 Flash */
}

/* 关键量快照的"哨兵校验"：上位机可判断数据是否被截断 */
uint8_t soe_read(uint16_t idx, soe_t *out)
{
    if (idx >= TELEM_SOE_LEN) return 1u;
    *out = g_soe[idx];
    return 0u;
}
```

### 41.7 失败案例复盘：计量误差 1.8%，根因是电压电流采样不同步

> [!CAUTION]
> 现象：客户用 0.2 级标准表比对，发现功率计量偏高 1.8%，多次标定无法消除。定位路径：①核对标定（无问题）→ ②测电压/电流通道相位（相差 1.0°，因两者由不同 SOC 触发、ACQPS 不同）→ ③改为同一 SOC 顺序触发后相位差 0.05°，误差降到 0.35%。根因：两通道采样时刻不一致 → 在功率因数低于 1 时产生系统性的功率误差（ΔP/P ≈ tanφ·Δθ）。预防措施：①计量通道必须同源同步触发；②标定报告必须包含"通道相位差"测量值；③把"与标准表比对"列入出厂 ATE（附录 B）。
