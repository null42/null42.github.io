**本章要解决的问题：**50kW/380V 三相并网/并机变流器的电流环怎么整定——同时满足 **THDi ≤3%**（谐波 ≤5%）、不平衡度 ≤3%、相位差 ≤1°（见 [整机验收指标表](/posts/power/courses/ups-pcs-dsp/docs/acceptance/)）。五个算例覆盖滤波器谐振、有源阻尼、dq 解耦、延迟收益与电网电压前馈，并给出 dq 电流环代码。

### 14.1 拓扑与坐标系选择

```text
700V 母线 ──[三相全桥 6 管]──[L1 = 800µH]──┬──[L2 = 200µH]──► 电网/负载 380V 50kW
 │
 [Cf = 10µF]
电流额定：I_rms = 50000/(√3×380) = 75.97 ≈ 76 A（第0章 0.A 的跨章一致值）
```

| 坐标系 | 适合 | 控制器 | 代价 |
| --- | --- | --- | --- |
| abc（自然系） | 故障诊断、单相独立控制、不平衡处理 | 3 个独立 PR | 计算量大，参数难统一 |
| αβ（静止两相） | PR/谐振控制、单相/三相通用 | PR 谐振器组 | 需处理正交分量 |
| dq（同步旋转） | 三相平衡工况、并机均流、功率控制 | PI（基波变直流） | 基波变直流的同时把不平衡变成 2ω 纹波 |

> [!IMPORTANT]
> 本课程的选择：三相平衡、并网/并机场合用 dq + PI（本章）；三相不平衡与单相用 αβ + PR（第13/32章）。αβ / dq不是"哪个更好"，而是"哪个把问题变成直流"。不平衡度 3% 的要求意味着负序分量不能忽略（第32章的零序/负序处理）。

### 14.2 算例 14-1：LCL 参数与谐振频率（三条判据一起看）

```text
L1 = 800µH（逆变侧）、L2 = 200µH（网侧）、Cf = 10µF
 谐振频率 f_res = (1/2π)·√((L1+L2)/(L1·L2·Cf))
 L1·L2·Cf = 8e-4 × 2e-4 × 1e-5 = 1.6e-12
 (L1+L2) = 1.0e-3
 → (1/2π)·√(1.0e-3/1.6e-12) = (1/2π)·√(6.25e8) = 25,000/6.2832 = 3,979 Hz ≈ 3.98 kHz
 等效特征阻抗 Z0 = √(L_eq/Cf)，L_eq = L1∥L2 = (8e-4×2e-4)/1e-3 = 1.6e-4 H
 Z0 = √(1.6e-4/1e-5) = √16 = 4.00 Ω

三条判据：
 ① 10·f_grid = 500 Hz < f_res = 3,979 Hz （避免低次谐波放大）
 ② f_res < fsw/2 = 8,000 Hz （避免开关谐波落在谐振外）
 ③ 电流环交越 fc_i < f_res/2 = 1,990 Hz（有阻尼时才可放宽到该线）
```

### 14.3 算例 14-2：有源阻尼（虚拟电阻）设计

```text
目标：ζ = 0.707（谐振峰 0dB 以下，不留尖峰）
 所需虚拟电阻 R_d = 2ζ·Z0 = 2×0.707×4.00 = 5.66 Ω

实现：调制量上减去 K_d·i_cf（电容电流反馈）
 等效关系：K_d·Kmod = R_d → K_d = R_d/Kmod = 5.66/350 = 1.62e-2 (1/A)（Kmod = u_bus/2 = 350V，平台口径）
 校验：ζ = R_d/(2Z0) = 5.66/8.00 = 0.707 

与"真电阻"比较（为什么用有源阻尼）：
 真电阻 R_d = 5.66Ω 在 50Hz 的电流：i_cf = 2π·50·10µ × 220 = 0.691 A（相电压 220V 口径）
 损耗 = 0.691² × 5.66 × 3 相 = 8.1 W，且随负载/谐波升高
 有源阻尼的代价是"电流环在谐振频率处的增益要求更高 + 噪声放大"，不产生真实损耗
```

### 14.4 算例 14-3：dq 电流环 PI + 解耦（含 1.5Ts 延迟账）

```text
对象（dq 下 L1 上的电流，m 为归一化调制量）：i_d = m_d·(u_bus/2)/(sL1)，Kmod = u_bus/2 = 350V
 |G_i(1kHz)| = 350/(2π×1000×8e-4) = 350/5.027 = 69.6 A/m
 → Kp_i = 1/69.6 = 1.44e-2 m/A（精确 1.436e-2；等价于 Kp = ω_c·L1 = 5.03 V/A 折算到调制量）

取 fc_i = 1.0 kHz（受 f_res/2 = 1.99kHz 与 1.5Ts 双重限制）：
 |Gc| 需 1.44e-2，零点取 100Hz
 Ki_i = 1.436e-2 × 2π×100 = 9.02 (m/(A·s)) → 离散 Ki·Ts = 9.02×55.6e-6 = 5.02e-4
 相位校验：−90°(对象) − 5.71°(零点) − 30.0°(延迟 1.5Ts@1kHz) = −125.7° → PM = 54.3° 

解耦（dq 交叉耦合项 ωL1·i_q、ωL1·i_d）：
 ωL1 = 2π×50×8e-4 = 0.2513 V/A → 归一化 0.2513/350 = 7.18e-4 m/A
 不加解耦的后果：d/q 相互干扰，负载突变时 i_d 与 i_q 互相"打摆"，动态变差
```

### 14.5 算例 14-4：把 1.5Ts 降成 1Ts 值多少相位

```text
方案 A：1.5Ts（ZOH 0.5Ts + 计算 1.0Ts）= 83.3µs → 1kHz 处 30.0°
方案 B：1Ts（单更新 + 立即装载，计算延迟压缩到 0）= 55.6µs → 1kHz 处 20.0°
 → PM 从 54.3° 提升到 61.8°（+11.3°）

这 11.3° 能换成什么：
 ① 同样的 PM 下把 fc_i 从 1.0kHz 提到约 1.3kHz（带宽 +30%）
 ② 保留 1.0kHz 但获得更大的参数漂移容忍度（电感饱和、温度变化、弱电网）
结论：第4章"ISR 时间纪律"与第5章"采样对齐"不是洁癖，它直接换控制带宽。
```

### 14.6 算例 14-5：电网电压前馈与 THDi

```text
背景：电网电压本身有畸变。设 5 次谐波 2%（相对 380V 有效值）= 7.6 V
 5 次处 L1 的阻抗：ω5·L1 = 2π×250×8e-4 = 1.2566 Ω
 由电网谐波"推"进 L1 的谐波电流 = 7.6/1.2566 = 6.05 A

① 无前馈时靠环路抑制：
 环路增益 T(250Hz) = Kp_i × |G_i(250Hz)| = 1.436e-2 × 350/(2π×250×8e-4)
 = 1.436e-2 × 278.5 = 4.00
 闭环后谐波电流 = 6.05/(1+4.00) = 1.21 A → 1.21/76 = 1.6%
 达标但已占了 ≤3% 的一半预算；若电网畸变到 4%，就到了 3.2% 

② 加电网电压前馈（把电网谐波直接抵消在指令上）：
 残余只取决于前馈通道精度（含采样标定误差）：设 0.5%
 → 残余 5 次 = 2% × 0.5% = 0.01%（可忽略）
 代价：需要三路电网电压采样且必须与电流通道同步标定（附录 B）
```

> [!WARNING]
> 注意前馈的边界：前馈"抵消"的是测到的电压谐波。若采样通道本身有相位误差（第9章的滤波相位），前馈会在高频段"帮倒忙"。因此前馈通道的相位一致性必须与电流通道一起标定并记录。

### 14.7 代码：dq 电流环 + 解耦 + 前馈 + 阻尼（可编译）

```c
/* ---------- param_table.h：常量来源（14.2~14.6） ---------- */
#define G3_FSW_HZ    18000.0f           // Hz，平台统一
#define G3_TS        (1.0f/G3_FSW_HZ)   // s = 55.6µs
#define G3_L1_H      800e-6f            // H，逆变侧电感（算例 14-1）
#define G3_L2_H      200e-6f            // H，网侧电感（算例 14-1）
#define G3_CF_F      10e-6f             // F，滤波电容（算例 14-1）
#define G3_UBUS_V    700.0f             // V，母线（第8章）
#define G3_INV_UBUS  (2.0f/G3_UBUS_V)   // 1/V，调制量归一化（V→m，Kmod = Vdc/2 = 350V）
#define G3_W_L1      0.2513f            // V/A，ωL1 @50Hz（算例 14-3 解耦系数，归一化后 7.18e-4 m/A）
#define G3_KP_I      1.44e-2f           // m/A，电流环 Kp（算例 14-3）
#define G3_KI_I_TS   5.02e-4f           // m/(A·拍)，Ki·Ts（算例 14-3）
#define G3_KD_DAMP   1.62e-2f           // m/A，有源阻尼（算例 14-2）
#define G3_ILIM_A    110.0f             // A，电流指令上限（1.45×76A，保护矩阵）

/* ---------- dq 变换（幅值不变约定；θ=0 时 d 轴与 α 轴重合） ---------- */
void abc_to_dq(float ia, float ib, float ic, float th, float *id, float *iq)
{
 const float s = sinf(th), c = cosf(th);
 const float ialpha = (2.0f*ia - ib - ic) / 3.0f; /* 等幅 Clarke：平衡时 = ia */
 const float ibeta = (ib - ic) / 1.7320508f; /* 1/√3 */
 *id = ialpha * c + ibeta * s;
 *iq = -ialpha * s + ibeta * c;
}
void dq_to_abc(float md, float mq, float th, float *ma, float *mb, float *mc)
{
 const float s = sinf(th), c = cosf(th);
 const float malpha = md * c - mq * s;
 const float mbeta = md * s + mq * c;
 *ma = malpha;
 *mb = -0.5f*malpha + 0.8660254f*mbeta; /* √3/2 */
 *mc = -0.5f*malpha - 0.8660254f*mbeta;
}

/* ---------- g3.c：三相电流环 ISR（18kHz，第4章五件事） ---------- */
static ctrl_pi_t pi_d = { G3_KP_I, G3_KI_I_TS, -1.0f, 1.0f, 0.0f, 0.0f, 20.0f };
static ctrl_pi_t pi_q = { G3_KP_I, G3_KI_I_TS, -1.0f, 1.0f, 0.0f, 0.0f, 20.0f };

void g3_current_isr(void)
{
 const float th = pll_get_theta(); // 电网角度（第29章）
 float id, iq;
 abc_to_dq(adc_to_amp(g_adc.raw_ia, &g_adc.cal_ia),
 adc_to_amp(g_adc.raw_ib, &g_adc.cal_ib),
 adc_to_amp(g_adc.raw_ic, &g_adc.cal_ic), th, &id, &iq);

 float id_ref, iq_ref;
 power_ref_to_dq(&id_ref, &iq_ref); // 由功率/电压环给出（第28章）

 /* ① PI + ② 交叉解耦（算例 14-3） + ③ 电网电压前馈（算例 14-6） */
 float vd = ctrl_pi_step(&pi_d, id_ref - id) - G3_W_L1 * iq * G3_INV_UBUS;
 float vq = ctrl_pi_step(&pi_q, iq_ref - iq) + G3_W_L1 * id * G3_INV_UBUS;
 vd += g3_get_vff_d(); vq += g3_get_vff_q(); // 前馈通道（含标定）

 /* ④ 有源阻尼：电容电流反馈（算例 14-2），在 abc 系注入以避免坐标变换误差 */
 const float icf_a = adc_to_amp(g_adc.raw_icfa, &g_adc.cal_icf);
 const float icf_b = adc_to_amp(g_adc.raw_icfb, &g_adc.cal_icf);
 const float icf_c = -icf_a - icf_b; // 第三相由基尔霍夫定律重构

 float ma, mb, mc;
 dq_to_abc(vd, vq, th, &ma, &mb, &mc);
 ma -= G3_KD_DAMP * icf_a; mb -= G3_KD_DAMP * icf_b; mc -= G3_KD_DAMP * icf_c;

 pwm_set_svpwm(pwm_g3, ma, mb, mc); // 第31章 SVPWM
 adc_clear_soc_flag();
 Interrupt_clearACKGroup(ISR_G3);
}
```

> [!TIP]
> 代码要点：①解耦项用的是测量电流而不是指令（抗饱和时更稳）；②有源阻尼在 abc 系注入，避免"dq 变换把谐振频率搬移"带来的相位误差；③第三相由基尔霍夫定律重构，省一路采样但要与保护逻辑一致（第36章）；④所有限幅与抗饱和统一由ctrl_pi_t处理（第11章），不在业务代码里散写。

### 14.9 失败案例复盘：弱电网把谐振频率"拉低"，整定表失效

> [!CAUTION]
> 现象：实验室（强电网）并网运行稳定，THDi 1.8%；现场（SCR较小的弱电网）出现 3.1kHz 附近的持续振荡，THDi 升到 7%，且随并机台数增加而恶化。定位路径：①测振荡频率 3.1kHz（不是设计值 3.98kHz）→ ②按网侧电感追加 Lg= 200µH 重算：L2′ = 400µH → fres= (1/2π)√((L1+L2′)/(L1L2′Cf)) = 19,365/6.2832 = 3,082 Hz，与实测吻合 → ③发现电流环交越 1.0kHz 与下移后的 fres距离变小（比值从 3.98 降到 3.08），阻尼的相位代价放大 → ④把有源阻尼增益按"最小 SCR"重算并加入电网阻抗在线估计后恢复。根因：整定用的是"无穷大母线"假设，未考虑电网阻抗使 fres下移；且多机并机等效降低了 SCR。预防措施：①设计必须在"最小 SCR 工况"下复算 fres与阻尼（写入设计说明）；②并机台数变化时重新标定或使用自适应阻尼；③现场调试用扫频确认实际 fres；④把"并机台数 / 电网阻抗"列为影响稳定性的环境变量（第28章）。

### 14.11 练习

1. **E1** 若 Cf 从 10µF 减到 5µF：重算 fres、Z0、所需 Rd 与 Kd；说明"减小 Cf 为什么可能让电流环更容易整定"，以及它的代价（滤波效果）。
