**本章要解决的问题：** 把控制量变成波形：**频率**（时基怎么算）、** 死区**（防直通要多大、代价多少、怎么补）、** 更新时机**（影子装载）、** 生成方式**（正弦表与相位累加器）。给出五个算例与六个"示波器检查项"，全部可手算/实测复核。

### 6.1 算例 6-1：TBPRD、周期与占空比分辨率

```text
增减（对称）模式下：  f_sw = f_clk / (2 · TBPRD)

F28075 @120MHz、载波 18kHz：
  TBPRD = EPWMCLK / (2 × f_sw) = 60e6 / (2 × 18e3) = 1667
  中断周期 T_sw = 1/18k = 55.6 µs        （= 6,667 个 CPU 周期，与第2/4章一致）

占空比最小步进 = 1 / (2·TBPRD) = 1/3,334 = 0.0300%
  → 若需要更细的等效分辨率（如减小死区补偿的量化台阶），使用 HRPWM
    （哪些通道支持以《F2807x datasheet》/《F2807x TRM》为准）
```

> [!WARNING]
> 最常见的一处算错：把 TBPRD 写成 fclk/fsw（少一个 2）。18kHz 会变成 36kHz：开关损耗翻倍、死区占比翻倍、THDu 变化——现象是"一上电就比预期热得多"。

### 6.2 算例 6-2：死区时间怎么定

```text
按器件数据手册的极值计算，不凭经验：
  t_dead ≥ t_off(max) + t_delay(开关延迟差) + t_margin + t_safety

  例（示例值，实际按所用器件手册代入）：
    t_off(max) = 2.0 µs（含拖尾）
    t_delay    = 0.3 µs（开通延迟差，按 t_on(min) = 0.3 µs 计）
    t_margin   = 0.5 µs（驱动离散性 + 温度）
    t_safety   = 0.2 µs（设计余量）
  → t_dead ≥ 2.0 + 0.3 + 0.5 + 0.2 = 3.0 µs

死区占周期比例： 3µs / 55.6µs = 5.40%       ← 这个比例后面要用于补偿与谐波预算
```

| 死区取值 | 好处 | 坏处 |
| --- | --- | --- |
| 偏大 | 绝不直通 | 基波损失、低次谐波增大、轻载效率差 |
| 偏小 | 波形好、效率高 | 器件分散/高温拖尾变长 → 直通炸管 |
| 随载/温调整（第39章） | 兼顾效率与安全 | 需两套阈值与在线切换，必须做失效保护 |

> [!WARNING]
> 死区只能由 ePWM 死区子模块硬件产生，不能用软件延时。软件延时受中断抖动影响，最坏情况失效；硬件死区在 CPU 跑飞时依然有效。

### 6.3 算例 6-3：死区补偿量（前馈怎么写）

```text
死区造成的"丢失伏秒"等效为占空比偏差：
  Δd = t_dead / T_sw = 3µs / 55.6µs = 5.40%
  等效输出电压偏差（母线 400V）： ΔV = Δd × 400V = 21.6 V

补偿方法（按电流方向前馈）：
  d_cmd = d_pid + sign(i_L) × Δd × K_comp     // K_comp 通常取 0.8~1.0，实测微调
  → 电流方向为正时补 +Δd，为负时补 −Δd

注意：电流过零附近 sign() 抖动会引起输出抖动 → 用带死区的过零判断或平滑过渡
```

> [!IMPORTANT]
> 为什么必须有这一段：死区电压偏差 21.6V，占基波峰值 311V 的 6.9%（分母为基波峰值），不补会直接反映为"输出偏低 + 低次谐波偏大"，是 THDu 预算里最先被吃掉的部分。

### 6.4 死区谐波的定量预算

| 谐波次数 | 占基波峰值 | 口径 |
| --- | --- | --- |
| 3 次 | 1.33% | 按基波峰值 311V 计（与第23章、第36章统一，见 audit-v1 F3） |
| 5 次 | 0.80% |  |
| 7 次 | 0.57% |  |

```text
三者方和根： √(1.33² + 0.80² + 0.57²) = √(1.7689 + 0.64 + 0.3249) = √2.7338 ≈ 1.65%
→ 死区在"THDu ≤3%（非线性负载）"的预算里占 1.65 个百分点
→ 剩余裕量 = 3 − 1.65 = 1.35 个百分点，留给采样误差、调制非线性与负载谐波
```

> [!TIP]
> 口径纪律：说谐波百分比必须同时给分母（基波峰值 or 有效值）与工况（空载/阻性/非线性）。混用会让同一台机器出现两套"合格"数据——这正是 audit-v1 F3 记录的历史缺陷。

### 6.5 算例 6-4：SPWM 生成与频率分辨率

```text
// 相位累加器 + 正弦查表（单相全桥单极性 SPWM 的核心）
#define TAB_N   1024                       // 正弦表长度（2 的幂）
static uint32_t phase;                     // 32 位相位累加器
static const float SIN_TAB[TAB_N] = { ... };

// 每个载波周期执行一次（f_sw = 18kHz）
phase += phase_step;                       // 50Hz 时：phase_step = f_out·2^32/f_sw
                                           //        = 50 × 4294967296 / 18000 ≈ 1.193e7
float s = SIN_TAB[(phase >> 22) & (TAB_N - 1)];   // 取高 10 位做表索引

float m = v_ctrl / VDC_HALF;                       // 调制度：线性区 |m| ≤ 1
if (m >  1.0f) m =  1.0f;                          // 限幅（过调制见 6.6）
if (m < -1.0f) m = -1.0f;
s = s * m;

uint16_t duty_a = (uint16_t)((0.5f + 0.5f * s) * (float)TBPRD);
EPWM_setCmpA(EPWM_A, duty_a);              // 写影子寄存器，周期边界生效
```

```text
频率分辨率（相位累加器方式）：
  Δf = f_sw / 2^32 = 18000 / 4.295e9 = 4.19 µHz    ← 远超工频精度需求
  表分辨率：1024 点 → 相位量化 0.35°，对应幅值误差 < sin(0.18°) ≈ 0.3%（可接受；
  若要更低，用线性插值或 12bit 表）
```

### 6.6 调制方式与等效开关频率

| 调制方式 | 桥臂电压 | 输出纹波频率 | 适用 |
| --- | --- | --- | --- |
| 双极性 | ±Vdc 翻转 | fsw = 18kHz | 简单；共模应力大 |
| 单极性（推荐） | 0 / ±Vdc | 2fsw = 36kHz | 谐波更小、滤波器更小 |
| 三电平 PD 载波 | ±Vdc/2、0 | fsw | 第15/31章 |

```text
算例 6-5：单极性 SPWM 的滤波器尺寸收益
  纹波频率从 18kHz 提到 36kHz（即 2f_sw），同样纹波幅值要求下
  所需 LC 乘积按 f² 缩小 → 4 倍
  例：由 1.5mH × 10µF（fr = 1.30kHz）可缩到 fr ≈ 2.6kHz 的滤波器
```

> [!WARNING]
> 线性区边界是硬约束：|m|≤1 时输出基波与调制波成正比；进入过调制后基波不再线性增长而 THD 激增（波形族见第0章 0.E③）。这就是母线取 380~400V 的工程理由：220V 市电峰值 311V，必须留出调制裕量才永远碰不到限幅。

### 6.7 载波相位与多模块交错

```text
N 个模块交错 360°/N：
  TBPHS_i = (i × 2 × TBPRD) / N                 // 增减模式按半周期折算
  N = 2、TBPRD = 1667 → TBPHS = 0 / 1667        // 两模块反相

两相交错的纹波抵消（与第11章的电流纹波一致）：
  D = 0.5 时理论完全抵消；偏离时残余 ∝ |2D − 1|
  例：D = 0.4 → |2×0.4 − 1| = 0.2 → 残余为单相纹波的 20%
```

> [!TIP]
> 交错与环流的耦合：交错能压纹波，但模块间相位/幅值不一致会产生环流。工程顺序是先保证相位同步精度，再谈交错收益（第38章）。

### 6.8 跳闸区（TZ）与硬件保护联动

| 要点 | 做法 | 注意 |
| --- | --- | --- |
| 一次性跳闸 vs 逐周期限流 | 短路/失控用一次性（锁存）；逐周期限流用比较事件限占空比 | 选错会"故障后自动恢复、反复冲击" |
| 强制电平 | 用 AQCSFRC 类寄存器强制安全电平 | 位段编码须按《F2807x TRM》核对（历史样片曾写反） |
| 验证 | 断开软件路径注入越限信号 | 判据 <1µs（LAB5） |

### 6.9 上机核对：六个示波器检查项

| # | 测什么 | 该看到什么 | 判据 |
| --- | --- | --- | --- |
| 1 | 桥臂电压周期 | 18kHz（55.6µs）方波 | ±1%（±180Hz） |
| 2 | 上下管门极波形 | 互补、留死区、无交叠 | 实测死区 ≥3µs 且 ≤3.6µs |
| 3 | 母线电流 | 无直通尖峰（低压上电时看） | 尖峰 <额定 1.5 倍 |
| 4 | 占空比变化沿 | 只在周期边界变化，无半周期截断 | 与影子装载设置一致 |
| 5 | 极性自检 | 给定 +50% 时输出直流分量方向正确 | 低压开环 + 限流电源 |
| 6 | 死区补偿效果 | 投入补偿后输出直流分量趋零、低次谐波下降 | THDu 改善可测 |

### 6.10 失败案例复盘：TBPRD 少乘 2，整机发热翻倍

> [!CAUTION]
> 现象：首台样机上电后 5 分钟内散热器温度明显高于仿真预期，效率只有 92%。定位路径：①测桥臂频率（36kHz，是设定的 2 倍）→ ②查 TBPRD 计算（写成 fclk/fsw= 3,334）→ ③改回 1,667 后频率 18kHz、效率回到 95.5% 附近 → ④复核死区占比与 THDu（都随之改善）。根因：增减模式频率公式少乘 2，导致开关频率翻倍：开关损耗翻倍、死区占周期比例翻倍、LC 纹波频率也变。预防措施：①频率公式写成带单位的推导（fsw= fclk/(2·TBPRD)），不接受口算记忆；②上电第一件事是测频率（6.9 检查项 1）；③把 TBPRD 与周期数的换算写进参数表注释（18kHz ↔ 1,667 ↔ 6,667 周期）。
