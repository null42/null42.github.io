**本章要解决的问题：** 把 dq 电流环的输出变成六个门极信号：SVPWM 的扇区判定与作用时间（三个算例）、七段式/五段式的取舍、以及 αβ / dq 解耦误差对电流环的实际影响。

### 31.1 SVPWM 的三步与母线利用率

```text
① 由 vα、vβ 判定扇区（六个 60° 扇区）
② 由扇区选两个相邻有效矢量 + 零矢量，算作用时间
③ 按七段式（对称）或五段式排布到比较寄存器

线性区上限：|v_ref| ≤ Vdc/√3 = 700/1.732 = 404 V（与第15章零序注入的结论一致）
```

### 31.2 算例 31-1：作用时间计算与校验（全流程）

```text
条件：Vdc = 700V、Ts = 55.6µs、参考矢量 |v*| = 380V、角度 θ = 20°（落在扇区 I）
 扇区 I 的两个有效矢量：V1（100，α 轴）、V2（110，60°）
 解方程：T1 = Ts·|v*|/(Vdc/√3)·sin(60°−θ_s)/sin60°... 实用简化式：
 T1 = √3·Ts·|v*|/Vdc · sin(60° − θ)
 T2 = √3·Ts·|v*|/Vdc · sin(θ)
 T0 = Ts − T1 − T2
 代入：√3×55.6e-6×380/700 = 1.7321×55.6e-6×0.5429 = 5.228e-5 = 52.28 µs
 T1 = 52.28 × sin40° = 52.28×0.6428 = 33.60 µs
 T2 = 52.28 × sin20° = 52.28×0.3420 = 17.88 µs
 T0 = 55.6 − 33.60 − 17.88 = 4.12 µs
 校验：T0 = 4.12µs < 2×死区（2×2.2 = 4.4µs） 已不满足 → 必须限制 |v*|（见 31.3）
 占空比：Ta = T0/4 = 1.03µs → 比较值 = 1.03/55.6×1667 = 31（TBPRD = 1667，第0章口径）
```

### 31.3 算例 31-2：最小脉宽限制与"母线利用率"的真实上限

```text
上例 T0 = 4.12µs 已低于 2 倍死区 4.4µs → 母线若再降到 680V，T0 会进一步缩到 2.6µs 
 （680V 时：T1+T2 = 52.28×(700/680)×0.9848 = 53.0µs → T0 = 55.6 − 53.0 = 2.6µs）
 → 必须设置"最小零矢量时间"约束：T0 ≥ 6µs（含死区 4.4µs + 余量）
 → 反算允许的最大 |v*|：
 T1+T2 ≤ Ts − 6µs = 49.6µs；上例 T1+T2 = 52.28×(sin40°+sin20°) = 51.48µs（随 |v*| 线性缩放）
 → 51.48×(|v*|/380) ≤ 49.6 → |v*| ≤ 366V（θ=20° 附近）
 这个限制比 Vdc/√3 = 404V 更严 → **真实可用调制比 = 366/404 = 0.91**（受最小脉宽约束）
 对应输出能力：相电压峰值 366V（可输出 259V 有效值相电压） 仍满足 380V 线电压（220V 相）需求

设计含义：高调制比工况（重载 + 母线跌落）时，要么降低开关频率（Ts 变大、T0 变大），
 要么接受 THD 上升（最小脉宽处的波形畸变）。
```

### 31.4 算例 31-3：七段式 vs 五段式（损耗与 THD 的取舍）

```text
七段式（每个周期 6 次开关动作/相）：
 波形对称、THD 低（谐波集中在 2fsw 与边带）、共模电压变化 3 次/周期
五段式（4 次开关动作/相）：
 开关损耗降低 33%（(6−4)/6），但低次谐波增大、共模电压模式不同

定量（18kHz、器件 E_on+E_off = 0.9 mJ@700V/76A）：
 七段式：每相 6 次 × 0.9 mJ × 18000 = 97.2 W/相（仅开关损耗，含开通+关断）
 五段式：4/6 × 97.2 = 64.8 W/相 → 三相省 97.2 W
 代价：THDu 从 0.4% 升到约 0.7%（经验量级，需实测确认）
判据：THDu 余量充足（≤1% 目标，实际 0.26%）时可换五段式省损耗；否则保持七段式
```

### 31.5 算例 31-4：解耦误差能有多大

```text
dq 解耦项：vd = vd_pi − ωL·iq；vq = vq_pi + ωL·id
 第14章：ωL = 0.2513 V/A（50Hz、L = 800µH）→ 归一化 3.59e-4 m/A

 若解耦系数误差 10%（电感容差）：
 id = iq = 76A（额定）时，残余交叉耦合 = 0.1×0.2513×76 = 1.91V
 对电流环的影响：相当于注入一个 1.91V 的扰动，被环路抑制 → 残差 = 1.91/(1+T)
 T(50Hz) 在电流环 ≈ 4 → 残差 0.38V = 0.054% 额定 → 可忽略 
 若"忘记解耦"（误差 100%）：
 残余 = 19.1V → 残差 3.8V = 0.54%；且动态时会与 q 轴指令相互干扰
 → 现象：突加负载时 id/iq 互相"打摆"，恢复时间变长 2~3 倍
判据：解耦系数误差 ≤20%（对应电感容差）；无解耦时动态指标不达标
```

### 31.6 代码：SVPWM + 解耦

```c
/* ---------- svpwm.c ---------- */
#define SVPWM_TBPRD    1667        /* 18kHz 增减计数（第0章 0.B） */
#define SVPWM_T0_MIN   6.0e-6f     /* 最小零矢量时间（31-3） */
#define SVPWM_TDEAD    2.2e-6f     /* 死区（第6章） */

typedef struct { float ta, tb, tc; uint8_t sector; float t0; } svpwm_t;

void svpwm_calc(float valpha, float vbeta, float vdc, float ts, svpwm_t *o)
{
 /* ① 扇区判定：用三相参考的符号（等幅 Clarke 反变换） */
 const float va = valpha;
 const float vb = -0.5f*valpha + 0.8660254f*vbeta;
 const float vc = -0.5f*valpha - 0.8660254f*vbeta;
 uint8_t sec;
 if (va > 0.0f && vb <= 0.0f) sec = 1;
 else if (vb > 0.0f && vc <= 0.0f) sec = 3;
 else if (vc > 0.0f && va <= 0.0f) sec = 5;
 else if (va > 0.0f && vb > 0.0f) sec = 2;
 else if (vb > 0.0f && vc > 0.0f) sec = 6;
 else sec = 4;

 /* ② 作用时间（用 min-max 注入的等价形式，数值更稳） */
 const float k = 1.7320508f * ts / vdc; /* √3·Ts/Vdc */
 float t1 = k * (valpha*0.8660254f - vbeta*0.5f);
 float t2 = k * vbeta;
 float t0 = ts - fabsf(t1) - fabsf(t2);

 /* ③ 最小零矢量约束：不够就等比压缩有效矢量（过调制压缩，保证 ta 非负） */
 if (t0 < SVPWM_T0_MIN) {
 const float scale = (ts - SVPWM_T0_MIN) / (ts - t0); /* 压缩因子 <1 */
 t1 *= scale; t2 *= scale; /* 过调制时压缩有效矢量时间，使 T0 回到下限 */
 t0 = SVPWM_T0_MIN;
 }
 o->t0 = t0; /* 记录：t0 被钳到下限即"调制饱和"诊断量 */
 o->sector = sec;

 /* ④ 三段比较值（七段式对称排布，Ta 为最小） */
 const float ta = (ts - t0 - fabsf(t1) - fabsf(t2))*0.5f; /* 简化示意，实际按扇区展开 */
 o->ta = ta; o->tb = ta + fabsf(t1); o->tc = ta + fabsf(t1) + fabsf(t2);
}

void svpwm_apply(const svpwm_t *o)
{
 pwm_set_cmp(pwm_g3, 0, (uint16_t)(o->ta/CTRL_TS*(float)SVPWM_TBPRD));
 pwm_set_cmp(pwm_g3, 1, (uint16_t)(o->tb/CTRL_TS*(float)SVPWM_TBPRD));
 pwm_set_cmp(pwm_g3, 2, (uint16_t)(o->tc/CTRL_TS*(float)SVPWM_TBPRD));
}

/* ⑤ 解耦（第14章 14-3） */
void decouple(float id, float iq, float *vd, float *vq)
{
 const float wl = G3_W_L1 * G3_INV_UBUS; /* 归一化到调制量 */
 *vd -= wl * iq;
 *vq += wl * id;
}
```

### 31.8 失败案例复盘：扇区边界判定错误导致每周期一次畸变

> [!CAUTION]
> 现象：输出电流在 50Hz 波形上每周期出现一次尖刺，THDu 1.8%（正常应 0.4%）。定位路径：①看尖刺位置（固定在某个相位）→ ②对应扇区切换点（60° 整数倍附近）→ ③检查扇区判定的边界条件（用了 `=` 与浮点比较，边界处出现"扇区跳 2"）→ ④改为带容差的判定后消失。根因：浮点比较在扇区边界抖动，导致相邻两拍使用不相邻的矢量组合，产生电压跳变。预防措施：①扇区判定必须用带容差/滞回的比较（或改用 min-max 注入的直接算法，天然无扇区跳变）；②上机核对固定做"逐扇区验证"；③把"扇区是否连续变化（±1）"做成运行期诊断量。

### 31.11 补充：把 SVPWM 放到 CLA，以及 HRPWM 在调制里的作用

参考工程把 θ 与采样数据处理交给 CLA（第37章 37.9），CPU 只取回结果做决策：扇区判定、作用时间计算与比较值写入属于周期性、无分支、可预测的计算，适合放 CLA；而限幅策略、最小脉宽约束（31-3）与故障注入判断留 CPU。HRPWM（第3章 3.10）在调制里的作用是提高边沿分辨率：普通 PWM 在 1667 计数下的占空比分辨率约 11 位，HRPWM 可到 21 位量级，对过零附近的小占空比与并机相位微调有实际意义。

> [!IMPORTANT]
> 补充（对照 逆变侧28075CLA内容.cpp）：参考工程的 SVPWM 与谐波补偿都在 CLA 侧实现（Dat_CLA_SPWM()、Alg_CLA_VinvHarmCmpn()），且Dat_CLA_SPWM()内部就包含直流分量补偿；CLA 侧的具体约定（执行顺序、共享区、清标志、标度写法）见第37章 37.11。本节 31.11 讲"哪些进 CLA"，37.11 讲"进去以后怎么写"。

### 31.12 补充：三电平 PD 载波 SPWM 与 NTV 60° 整数法（衔接第15/32章）

三电平（NPC，第15章建模）的矢量平面有 19 个基本矢量：6 个 60° 大扇区，每个大扇区再分 4 个小三角形（内 1、中 1、外 2）。调制有两条等价的路：PD（Phase Disposition）载波 SPWM——两个同相三角载波层叠后与正弦参考比较，线性区它与 NTV-SVPWM 等效（等价于自动注入零序，母线利用率同为 Vdc/√3 = 404V）；NTV（最近三矢量）60° 整数法则把参考矢量换算成整数坐标，直接给出"最近三矢量 + 作用时间"。工程上常"PD 载波出波、NTV 做校验与中点平衡分配"。

```text
60° 斜坐标变换（基本矢量以小矢量幅值 Vdc/3 为单位）：
 g = (Vα − Vβ/√3)/(Vdc/3)，h = 2√3·Vβ/Vdc
 Vref = (Vdc/3)·(g + h·e^j60°)；大扇区号 = floor(θ/60°)+1
 小三角形判定（大扇区 I）：
 g ≥ 0、h ≥ 0 且 g+h ≤ 1 → 内三角（顶点 (0,0)/(1,0)/(0,1)，含零矢量）
 g ≤ 1、h ≤ 1 且 g+h ≥ 1 → 中三角（顶点 (1,0)/(0,1)/(1,1)，含中矢量）
 其余 → 两个外三角（含大矢量）

算例 31-5：Vdc = 700V、|Vref| = 400V、θ = 30°（Ts = 55.6µs）
 m = |Vref|/(Vdc/√3) = 400/404.15 = 0.99（贴近线性区上限）
 Vα = 400·cos30° = 346.4V，Vβ = 400·sin30° = 200.0V
 g = (346.4 − 200/1.732)/(700/3) = (346.4 − 115.5)/233.3 = 0.990
 h = 2×1.732×200/700 = 0.990（θ=30° 在 60° 角平分线上，g=h 可作对称性校验）
 扇区：大扇区 I；g、h ∈ (0,1) 且 g+h = 1.98 ≥ 1 → 中三角
 作用时间：t(1,0) = (1−h)·Ts = 0.0103×55.6 = 0.57µs
 t(0,1) = (1−g)·Ts = 0.57µs
 t(1,1) = (g+h−1)·Ts = 0.979×55.6 = 54.5µs（校验：0.57+0.57+54.5 = 55.6）
 冗余选择：t(1,0) 对应小矢量对 [POO]/[ONN]，t(0,1) 对应 [PPO]/[NON]——
 正/负小矢量的中点电流反号，用时间分配因子 α（0~1）做中点平衡（第32章 32.10）；
 本例 t1+t2 仅 1.1µs → 高调制比时中点平衡"授权"最弱，这是判据必须留裕量的原因
```
