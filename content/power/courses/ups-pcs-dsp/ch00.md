### 0.1 数学自检清单：一共只需要这五样

1. **复数与 jω**：电感阻抗写作 jωL——频率越高阻碍越大；电容相反。所有"幅频/相频"讨论都建立在它上面。
2. **拉氏变换的一句话本质**：把微分变乘法——d/dt 记作 s。于是微分方程变成代数方程，比值就是传递函数。
3. **一阶系统** τ·dy/dt + y = x：阶跃后到 63% 用时 = τ；带宽近似 fc ≈ 1/(2πτ)。第18章的滤波器全是它的变装。
4. **二阶标准形** ωn（自然频率）与 ζ（阻尼比）：ζ<1 时阶跃振荡，谐振峰高约 1/(2ζ)。第10~16章每个对象都是它或它的三阶亲戚。
5. **Bode 图与相位裕度 PM**：开环增益降到 0dB 的频率处，看相位距 −180° 还差多少度。**45° 及格、60° 优秀**——直观理解：负反馈信号绕环路一圈回来时，若相位差半圈还幅度够大，就会自己喂自己振荡。

> [!IMPORTANT]
> 自检方法：能向同事口述以上五条的"电源语境版"，即可直接进入第1章；哪条卡住，先花半小时补那一条，不必整学期重修控制理论。

### 0.2 标幺化（pu）：五分钟入门，全书通用货币

动机：5kW 和 500kW 的机器，电流差两个数量级，但"负载率 80%"是同一句话。标幺化就是把物理量除以基准值，让所有设计公式跨功率复用。

```text
基准四件套（任选两个，其余派生）：
  S_base = 额定容量        V_base = 额定相电压(或线电压，全书统一注明)
  I_base = S_base / (√3 · V_ll)      Z_base = V_base² / S_base

例：50kW / 380V 系统 → I_base = 50k/(√3×380) ≈ 76A
    Z_base = U_LL²/S_N = 380²/50k ≈ 2.89Ω（相阻抗基值按线电压平方口径，含√3约定，与 U_ph²/S_ph 等价）
    实测电流 40A → 0.53 pu；电感 300 µH（0.3 mH）→ X_L = 2π×50×0.3mH ≈ 0.094Ω → 0.094/2.89 ≈ 0.033 pu
```

使用纪律：**每张表、每段代码注明当前 pu 的基值口径**——基值不同，同一个"0.5pu"含义天差地别。

### 0.A 电学基础：从欧姆定律到三相功率（新手专用）

如果你从未学过电路或已忘光，本节给你**刚好够用** 的电学底子——读完即可理解第1~7章的全部内容。更深的理论会在用到时再讲。

#### ① 欧姆定律与功率（直流入门）

```text
欧姆定律：V = I × R          （电压=电流×电阻）
功率：    P = V × I = I² × R = V²/R

例：12V 电池接 2Ω 电阻：
    I = 12/2 = 6A
    P = 12×6 = 72W（电阻发热消耗的功率）
```

#### ② 交流电：为什么有"有效值"

```text
市电是正弦波：v(t) = √2 × V_rms × sin(2π·50·t)
              ↑峰值        ↑有效值(220Vrms 就是它)

峰值 = √2 × 有效值 ≈ 1.414 × V_rms
220V 市电的峰值 = 311V ← 这就是为什么母线要充到 380~400V

有效值的物理意义：与同阻值直流产生相同热量的等效值。
V_rms = V_peak / √2
```

#### ③ 相位与功率因数：电压和电流不一定同步

```text
纯电阻负载：电流与电压同相位 → PF=1，全部是有功功率
纯电感负载：电流滞后电压 90° → PF=0，能量在电源↔电感间来回搬运
实际负载：  介于两者之间 → PF = cosφ

有功功率 P = V_rms × I_rms × cosφ  （真正做功的部分，单位 W）
无功功率 Q = V_rms × I_rms × sinφ  （来回搬运不做事，单位 var）
视在功率 S = V_rms × I_rms          （总容量，单位 VA）

PF = P/S —— 越低说明电网被"浪费"的容量越多，这就是 PFC 存在的理由。
```

#### ④ 阻抗：把电阻概念推广到交流

```text
电阻：R（不随频率变化）
感抗：X_L = ωL = 2πfL     （频率越高阻碍越大）
容抗：X_C = 1/(ωC)        （频率越高阻碍越小）

合成阻抗 Z = R + jX       （j 是虚数单位，表示 90° 相位旋转）
|Z| = √(R² + X²)

LC 谐振：当 X_L = X_C 时阻抗最小（串联）或最大（并联）
  ω_r = 1/√(LC)          ← 第10~16章反复出现的公式就是它
```

#### ⑤ 三相制：为什么用三相

```text
三相 = 三路幅值相同、相位互差 120° 的正弦波
  va = Vm·sin(ωt)
  vb = Vm·sin(ωt − 120°)
  vc = Vm·sin(ωt − 240°)

优点：
  ① 三相功率瞬时值恒定（单相以 2×工频脉动）→ 电机/变压器受力平滑
  ② 三根线传输三倍功率（相比三个独立单相）
  ③ 对称三相负荷的中线电流为零 → 省一根线

线电压 = √3 × 相电压（如相 220V → 线 380V）
```

#### ⑥ 半导体开关：为什么能"变"电压

```text
MOSFET/IGBT = 电子开关：导通≈短路(压降极低)，关断=断路
通过高速开关(18kHz~100kHz)+占空比控制，把直流"切"成不同宽度的脉冲，
再经 LC 滤波还原为所需的平均电压——这就是所有 DC-DC 和逆变器的本质。

Buck 降压：V_out = D × Vin      (D 为占空比 0~1)
Boost 升压：V_out = Vin/(1−D)

开关频率越高 → 滤波器越小 → 体积越小；但开关损耗越大 → 需要折中。
```

### 0.C Z变换与离散化速成（连续→数字的翻译官）

数字控制器只能跑差分方程，而电源拓扑天然是微分方程。**Z变换是把 s 域传递函数 G(s) 翻译成 z 域 G(z) 的唯一标准桥梁**。本节只给你落地要用的三种离散化方法与一张决策表。

#### ① Z变换的一句话本质

```text
x[k] —Z→ X(z) = Σ x[k] z^{-k}
时移性质：x[k-1] —Z→ z^{-1} X(z)    ← 这一条支撑起所有差分方程实现
延迟算子：z^{-1} 代表"推迟一个采样周期"
```

把连续积分器 1/s 离散化，本质就是把 ∫ 变成 Σ。三种主流近似对应三种求和方式：

#### ② 三大离散化方法对照表（全书通用，背下来）

| 方法 | s 域替换规则 | 频域特性 | 稳定性 | 相位误差 | 典型适用场景 |
| --- | --- | --- | --- | --- | --- |
| **双线性变换 (Tustin)** | s = (2/Ts) · (z-1)/(z+1) | 频率轴完美映射：ω = (2/Ts) tan(ω_d Ts/2) | s平面左半平面 → z平面单位圆内 ** 无条件保稳** | 频率畸变：高频压缩，需预畸变 | ** 首选：PI/PR/各类补偿网络**，带宽 < fsw/10 时极准 |
| 前向欧拉 | s = (z-1)/Ts | 低频近似，高频相位超前（乐观） | 有条件稳定，极点可能跑出单位圆 | 高频相位偏乐观，裕度虚高 | 仅用于**极低带宽**（fc < fsw/50）的简单积分环节 |
| 后向欧拉 | s = (z-1)/(z·Ts) | 低频近似，高频相位滞后（悲观） | 无条件保稳 | 高频相位偏保守，裕度偏低 | 植物模型离散化（如 1/s → Ts·z/(z-1)），**带延迟的受控对象** 首选 |

#### ③ 关键公式速查（直接抄进代码）

```text
// 1. 连续 PI：G(s) = Kp + Ki/s
//    Tustin 离散化（预畸变 ωc）：
//    s = (2/Ts)*(z-1)/(z+1)  →  G(z) = Kp + Ki*Ts/2 * (z+1)/(z-1)
//    差分方程（增量式，抗饱和（anti-windup）最稳）：
//    u[k] = u[k-1] + Kp*(e[k]-e[k-1]) + Ki*Ts/2*(e[k]+e[k-1])

// 2. 连续积分器 1/s（植物模型用后向欧拉更实在）：
//    后向欧拉：G(z) = Ts * z / (z-1)
//    差分：y[k] = y[k-1] + Ts * x[k]        ← 这才是"上一拍输出 + 本拍输入×Ts"

// 3. 一阶低通 ωc/(s+ωc) — Tustin：
//    a = ωc*Ts/2;  G(z) = a*(z+1) / ((1+a)z + (1-a))
//    差分：y[k] = ((1-a)/(1+a))*y[k-1] + (a/(1+a))*(x[k]+x[k-1])

// 4. 二阶谐振/陷波（准 PR 核心）— Tustin + 预畸变：
//    目标谐振频率 ωr → 预畸变 Ω = (2/Ts)*tan(ωr*Ts/2)
//    s² + 2ζΩs + Ω²  代入 s=(2/Ts)*(z-1)/(z+1) 展开得标准二阶差分
```

#### ④ 频率预畸变：为什么要做、怎么做

双线性变换把连续频率 ω 压缩到离散频率 ω_d：`ω = (2/Ts) tan(ω_d Ts/2)`。反推：若想离散控制器在 **ωc 处穿越**，连续设计时必须把角频率"拉大"到：

```text
ωc_prewarp = (2/Ts) * tan(ωc * Ts / 2)

例：Ts=55.6 µs（18kHz 载波；F28075 @120MHz，EPWMCLK=60MHz 增减模式 TBPRD=1667），目标 fc=1.8kHz（ωc=2π×1800≈11310 rad/s）
    预畸变系数 k = tan(ωc·Ts/2) = tan(11310×55.6e-6/2) ≈ tan(0.3142) ≈ 0.3249
    ωc_prewarp = 2k/Ts ≈ 2×0.3249/55.6e-6 ≈ 1.17e4 rad/s（≈1.86kHz）
    → 不预畸变时离散穿越约 1.74kHz（频率轴压缩约 3%），相位裕度评估偏差 1~3°
```

> [!IMPORTANT]
> 平台口径（已按主参考代码重定标，全书统一）：EPWMCLK = 60MHz（= SYSCLKOUT/2，与参考工程TBPRD = 1667→ 载波 18kHz 自洽）→ Ts= 55.6 µs；控制中断为INT on CTR_ZERO且INTPRD = ET_2ND→每 2 个载波周期中断一次（控制周期 111.1 µs）；死区KDeadTime3usCnst= 3 µs；ADC 用ADCA/ADCB/ADCD 三组并行、ACQPS = 12、由 ePWM2 SOCA 触发、采样率预算 2.733 MSPS；使能 HRPWM；θ 与采样数据处理分担给 CLA。数值来源：参考代码索引第 0 节（UPS-PCS课程\部分参考代码\）。

> [!IMPORTANT]
> 纪律：全书凡涉及 Tustin 离散化的控制器设计（第18、19、22、26、27章），必须预畸变穿越频率/谐振频率。植物模型离散化（第10、11、13、14章）用后向欧拉，不预畸变。

### 0.D 小信号建模三步走（从电路图到传递函数）

无论 Buck、Boost、逆变器、PFC、LCL，小信号建模的**标准动作只有三步**。掌握这套流程，后面第10~16章所有推导你都能自己复现。

#### 步骤 1：写大信号状态方程（时域）

```text
// 以 Buck 为例，状态变量选 iL、vC
diL/dt = (D·Vin - vC) / L
dvC/dt = (iL - vC/R) / C
// D 为占空比（控制输入），Vin 视为恒定扰动输入
```

> [!TIP]
> 多拓扑通用技巧：用状态空间平均法 (SSA)。把开关周期内导通/关断两段拓扑分别写状态方程，按占空比加权平均。第10章有完整族谱表。

#### 步骤 2：平衡点计算（直流工况）

```text
令导数为零解稳态值（大写字母）：
0 = (D·Vin - Vc) / L    →  Vc = D·Vin
0 = (IL - Vc/R) / C     →  IL = Vc/R = D·Vin/R
// 这一步给后续线性化提供偏移量
```

#### 步骤 3：扰动线性化 → 拉氏域传递函数

```text
引入小信号扰动（帽子变量，下文用 ^ 表示）：iL = IL + iL^, vC = Vc + vC^, d = D + d^
代入大信号方程，忽略二阶小量（如 d^·vC^），得线性时域微分方程：
L·diL^/dt = Vin·d^ − vC^
C·dvC^/dt = iL^ − vC^/R

拉氏变换（零初始条件），消除 iL^ 得控制-输出传递函数：
Gvd(s) = vC^(s)/d^(s) = Vin / (LC s² + (L/R)s + 1)
     = Vin / (1 + s/(ω_r·Q) + s²/ω_r²)
     其中 ω_r = 1/√(LC), Q = R√(C/L)

// 同理得输入-输出传递函数（抗扰度分析用）：
Gvg(s) = vC^(s)/Vin^(s) = D / (1 + s/(ω_r·Q) + s²/ω_r²)
```

#### ⑤ 离散化进数字控制器

得到 Gvd(s) 后：

- **植物模型**（仿真/辨识/前馈用）：用** 后向欧拉**或 ZOH 精确离散化（MATLAB `c2d(G,Ts,'zoh')`）——保真度优先
- **控制器设计**（PI/PR/补偿网络）：用**Tustin + 预畸变**——相位裕度准
- **数字延迟补偿**：第10章建立的 1.5Ts 延迟模型 `z^{-1.5}` 串联在植物模型后，再做环路整形

> [!WARNING]
> 避坑清单： ① 别把大信号方程直接代 s 当传递函数——必须先线性化； ② 状态变量选错（如 Buck 选 vC/iL 而非 vC/D）会导致阶数错误； ③ 忽略 ESR/寄生电阻会让 Q 算偏、谐振峰虚高（第10章实测对比）； ④ 三相 dq 建模时，先在 abc 写大信号，再做 Park 变换线性化，别直接在 dq 写——容易漏掉 ωL 耦合项（第14章演示）。

### 0.E 主流拓扑在不同工况下的理论波形图谱

不需要记波形，要会**从拓扑+工况推波形**。下面是全书反复引用的"波形速查卡"，建议打印贴工位。

#### ① Buck / 同步整流 Buck（第11、12、13章）

| 工况 | 电感电流 iL | 开关管 Vds / 电流 | 关键判据 |
| --- | --- | --- | --- |
| CCM（连续电流） | 三角波，平均值=Iout，纹波 ΔI = (Vin-Vout)D·Ts/L | 上管：导通时 iL，关断时 0；下管：互补。Vds 上管=Vin，下管≈0 | ΔI < 2·Iout |
| DCM（不连续电流） | 三角波回零平底，出现"死区"，峰值更高 | 下管电流反向被二极管/同步管钳位，需强制关断防反向 | ΔI ≥ 2·Iout；边界 Kcrit = 2L/(R·Ts) |
| 轻载/空载 | 脉冲群模式（PFML/跳频）或强制 CCM | 上管极窄脉冲（最小导通时间限制），下管长导通 | 最小占空比 Dmin = Ton_min/Ts |
| 过载/短路 | 电流斜率受限，逐周期限流切入（峰值电流模式） | 上管导通时间被钳位，频率可能折半（跳频保护） | 斜率补偿 ≥ 0.5×下降沿斜率 |

#### ② Boost / PFC 整流器（第12章）

| 工况 | 电感电流 iL（输入电流） | 二极管/同步管电流 | 输出电容电流 ic |
| --- | --- | --- | --- |
