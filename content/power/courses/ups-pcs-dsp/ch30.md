**本章要解决的问题：** 把"切换"做成可验收的动作：静态开关怎么触发、无扰转移的三同步判据取多少、以及 切换时间 指标怎么落地。

### 30.1 三种通路的切换矩阵

| 切换 | 时间要求 | 机制 | 关键动作 |
| --- | --- | --- | --- |
| 市电 ↔ 电池（在线模式内） | 0ms | 母线电压由整流/DC-DC 接力，负载侧无感 | DC-DC 快速接管母线（第16章） |
| 旁路 ↔ 逆变 | ≤1ms | SCR 过零自然换流 | 预触发 + 三同步（30.2） |
| 逆变 → 维护旁路 | 不停电 | 人工操作 + 电气互锁 | 顺序互锁、防误操作 |
| 模块级（集中旁路） | ≤1ms | 整机旁路通道 | 模块与旁路控制器协同（第38章） |

### 30.2 算例 30-1：三同步判据的定量依据（冲击电流说了算）

```text
先合后分（make-before-break）：切换时两条通路短暂并联 → 冲击电流 = ΔV/Z_loop
  旁路通路与逆变通路之间的环路阻抗 Z_loop ≈ 0.3Ω（变压器漏抗 + 线缆 + SCR 导通压降折算）

  相位差 Δθ 引起的电压差：ΔV = 2·V_pk·sin(Δθ/2)
    1° → 2×311×sin0.5° = 5.43 V → 冲击 5.43/0.3 = 18.1 A（24% 额定）
    2° → 10.9 V → 36.2 A（48%）✗ 已接近保护阈值
    5° → 27.1 V → 90.4 A（119%）✗ 必跳保护
  幅值差 2% → ΔV = 0.02×311 = 6.2 V → 20.7 A（27%）
  频率差 0.1Hz → 相位以 0.1×360 = 36°/s 漂移 → 必须"在相位窗内立即动作"（窗口 ≤1° → 28ms 机会窗）

→ 判据（本课程口径）：|Δθ| ≤1°、|ΔV| ≤2%、|Δf| ≤0.1Hz，三条同时满足且持续 ≥3 个工频周期才允许转移
  （更严的场合可取 0.5°/1%/0.05Hz，代价是等待时间变长）
```

### 30.3 算例 30-2：为什么 ≤1ms 必须靠"预触发"

```text
SCR 只能在过零时自然关断、在过零附近触发导通：
  若在任意时刻发触发号，要等到下一个电压过零点才导通 → 最坏等待 10ms（半周期）✗ 远超 1ms

预触发方案（可行）：
  用 PLL 相位预测下一个过零点，在过零前 T_pre 发出触发号
  T_pre 取 0.9ms（覆盖触发脉冲宽度与器件开通延迟）
  预测误差来源：频率误差 0.1Hz → 0.9ms 内相位误差 = 0.1×360×0.9e-3 = 0.032° → 时间误差 1.8µs ✓ 可忽略

  切换时间预算：
    检测（电流/电压越限）0.1ms + 决策 0.05ms + 预触发剩余等待 (T_pre) 0.9ms + SCR 开通 (µs 级)
    → 合计 ≈ 1.05ms ≈ 指标 ≤1ms（边界）；把 T_pre 降到 0.7ms 可留出余量
  反向（旁路 → 逆变）：逆变必须已同步跟踪、且 SCR 需等电流过零自然关断（≤10ms 是关断时间，不是负载中断时间）
    → 逆变先带载、旁路电流过零后自然退出 → 负载"无感"（这才是 ≤1ms 的含义）
```

### 30.4 算例 30-3：切换瞬间的相位跳变与冲击（与第29章联动）

```text
反例：以"逆变内部参考"作为同步判据（而不是电网 PLL）
  逆变 θ 与电网 θ 相差 3°（PLL 未校准）→ 判据误判为"已同步" → 转移冲击 27V/0.3Ω = 90A → 跳保护

正例：判据统一取自 PLL（第29章）的电网相位，逆变通过调节自身相位去"追上"电网
  每次追赶步长 ≤0.2°（避免相位突变引起负载扰动）
  → 追赶 3° 需 15 拍 × (1/18000) ≈ 0.83ms（理论下限）；实际按"每工频周期调 0.2°"→ 15 个周期 = 0.3s
  判据满足后立即可转移（机会窗 28ms 足够）

PLL 相位跳变 的防护：相位连续性检查（每拍 |Δθ| ≤ 期望值 + 容差），超限则暂停切换并告警
```

### 30.5 代码：切换状态机与预触发

```c
/* ---------- transfer.c ---------- */
#define TR_DTH_MAX_DEG   1.0f      /* 相位差判据（30-2） */
#define TR_DV_MAX_PCT    2.0f      /* 幅值差判据 */
#define TR_DF_MAX_HZ     0.1f      /* 频率差判据 */
#define TR_HOLD_CYCLES   3u        /* 需连续满足的工频周期数 */
#define TR_PRE_MS        0.7f      /* 过零预触发提前量（30-3） */

typedef enum { TR_IDLE = 0, TR_SYNCING, TR_ARMED, TR_TRANSFER, TR_DONE, TR_ABORT } tr_state_t;

/* 1ms 慢任务里跑：同步判据 + 状态推进（不在 ISR 里做决策） */
void task_transfer(void)
{
    static tr_state_t st = TR_IDLE;
    static uint16_t hold_ms = 0;

    const float dth = pll_phase_diff_deg();      /* 逆变相位 − 电网相位（度） */
    const float dvu = 100.0f*(inv_v_rms() - grid_v_rms())/grid_v_rms();
    const float df  = inv_f_hz() - pll_f_hz();

    switch (st) {
    case TR_IDLE:
        if (g_cmd.transfer_req) { st = TR_SYNCING; hold_ms = 0; inv_phase_align_start(); }
        break;
    case TR_SYNCING:                              /* 逆变逐步追赶电网相位 */
        inv_phase_align_step(0.2f);               /* 每次 ≤0.2° */
        if (fabsf(dth) <= TR_DTH_MAX_DEG && fabsf(dvu) <= TR_DV_MAX_PCT &&
            fabsf(df) <= TR_DF_MAX_HZ) {
            if (++hold_ms >= TR_HOLD_CYCLES*20u) st = TR_ARMED;   /* 3 个周期 = 60ms */
        } else { hold_ms = 0; }
        break;
    case TR_ARMED:                                /* 等待过零预触发窗口 */
        if (scr_pre_trigger_ready(TR_PRE_MS)) { scr_trigger(pwm_bypass); st = TR_TRANSFER; }
        if (fabsf(dth) > 2.0f*TR_DTH_MAX_DEG) { st = TR_SYNCING; hold_ms = 0; }  /* 条件破坏 → 退回 */
        break;
    case TR_TRANSFER:
        if (scr_conducting(pwm_bypass)) { inv_output_reduce(); st = TR_DONE; }   /* 先合后分 */
        break;
    case TR_DONE:
        g_status.mode = MODE_BYPASS;  st = TR_IDLE;
        break;
    default: break;
    }
    g_status.tr_state = (uint8_t)st;
}
```

### 30.7 失败案例复盘：同步判据取错相位源，切换瞬间跳机

> [!CAUTION]
> 现象：逆变切旁路时偶发过流跳机（约 1/10 次），负载短时中断（达 10ms）。定位路径：①录波看切换瞬间（冲击电流 95A）→ ②核对判据数据来源（用的是逆变内部参考相位，而非电网 PLL）→ ③两者相差 3°（PLL 未参与校准）→ ④统一用 PLL 相位并加"相位连续性检查"后，100 次切换无异常。根因：判据与实际并联点电压不同源；内部参考与电网相位存在未校准的固定偏差。预防措施：①同步判据的相位必须取自电网 PLL，且与旁路电压采样同源标定（附录 B）；②加"相位连续性检查"，防止PLL 相位跳变被误判为同步；③切换类功能必须做 100 次循环试验（本课程列入 LAB5）。

### 30.10 补充：双锁相分工与旁路电压异常快检（对照参考工程）

参考工程有两个锁相方法（`Alg_Int_PhaseLock1` / `Alg_Int_PhaseLock2`）与一个快速检查（`Alg_Int_bBpVoltAbnormalFastChk`）。前者说明"相位基准不止一个"，后者说明"切换判据之前先要有否决条件"。

#### ① 双锁相分工

| 锁相 | 相位来源 | 用途 | 带宽/速度 | 异常处理 |
| --- | --- | --- | --- | --- |
| PLL1 | 电网 / 旁路电压（第29章 SRF-PLL 或 `ups\pll.c` 的跟旁路模式） | 提供切换判据与并网相位基准；决定"往哪个相位靠齐" | 20~30Hz（第29章 29-2） | 失锁 → 冻结切换、转本振（50Hz 自振） |
| PLL2 | 逆变输出 / 反馈电压 | 监视逆变实际输出相位；并机时用于模块间相位一致性与差流判断 | 可更慢（10~20Hz，只做监视与慢校正） | 与 PLL1 差超限 → 否决切换并告警 |

```text
为什么必须分开：
  ① 切换判据要求"逆变相位追上电网相位"——若用输出相位去追自己，判据自洽（永远满足）
     → 必须一个基准（电网）、一个被调对象（逆变输出），两者独立测量
  ② 并机时每台模块的"电网相位"可能来自各自采样，必须用同一个（PLL1）做公共基准，
     否则模块间相位基准不同 → 相位差直接变成差流（第38章 38.10 第②层）
  ③ 故障降级不同：PLL1 失锁 → 不能切换（可能电网异常）；PLL2 异常 → 不能并机（可能本机异常）
诊断量（建议上报）：两路锁相的相位差、频率差、各自锁定状态、失锁累计时间（第41章遥测）
判据：正常运行时 |θ_PLL1 − θ_PLL2| ≤1°，|f1 − f2| ≤0.05Hz；超限 10ms 即告警
```

#### ② 旁路电压异常快检（切换前的否决条件）

```text
三同步判据（30.2）是"允许切换"的条件；快检是"即使满足三同步也禁止切换"的条件。
  两者关系：先过快检（否决），再看三同步（允许），最后才动作
检查项与阈值（本课程口径，可按现场收紧）：
  ① 幅值突变：|ΔV| > 10%（1 个工频周期内）→ 旁路可能正在跌压/恢复过程，禁止切换
  ② 相位跳变：|Δθ| > 5°（相对上一周期外推值）→ 电网有扰动，切换会带来冲击（第30章 30-4）
  ③ 频率越限：f 超出 45~55Hz 或 df/dt > 2Hz/s（与第29章限速同口径）
  ④ 畸变超限：旁路电压 THD > 10% → 切换后负载直接面对畸变电网
  ⑤ 缺相/单相跌落：任一相低于 80% 额定 → 三相不平衡切换（第32章）
时间预算：快检在 9kHz 控制中断或 1ms 任务内完成（≤1ms），而三同步判定需 3 个工频周期（60ms）
  → 快检的意义：在 60ms 等待窗内若电网恶化，立即取消本次切换，避免"按旧判据切到坏电网"
实现要点：
  ① 阈值必须来自测量值，不能与三同步判据共用同一个状态量（否则一起失效）
  ② 否决后要记录事件码（含五项检查的明细），便于现场回溯（第36章黑匣子）
  ③ 快检只在"准备切换"的窗口内使能，正常运行不参与（避免误报刷屏）
判据：人为注入单项异常（如幅值 12% 突变）时，30-2 的三同步判据仍满足，但快检必须否决切换
```

> [!CAUTION]
> 失败案例复盘（按旧判据切到坏电网）：现场记录显示一次"旁路↔逆变"切换发生在市电正在恢复的过程中：三同步判据在 60ms 等待窗内采集到的是"恢复中的相位与幅值"（恰好落在窗口内），切换后负载经历一次 15% 的电压冲击。加入快检（幅值突变 >10%、相位跳变 >5° 即否决）后，同类工况下切换被取消并等待 2s 重判。结论：判据是"允许条件"，必须有独立的"否决条件"；两者共用状态量等于没有快检。
