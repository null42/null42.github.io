**本章要解决的问题：** 把一个物理量"准确地、及时地、三相同时地"变成数字。给出五个可手算的算例：分压电阻设计、误差预算 RSS、ACQPS 两口径、抗混叠滤波器的相位代价、双向电流调理增益；并解释为什么"采样时刻对齐载波"比"加滤波器"更能保证精度。（注意：SOC 在第42章指荷电状态 State of Charge，与本章 Start-of-Conversion 撞名。）

### 5.1 算例 5-1：母线电压分压电阻怎么选

```text
目标：母线 400V 映射到 ADC 满量程 3.3V（留 10% 余量 → 目标 3.0V 对应 400V）

取 R1 = 1 MΩ、R2 = 8.2 kΩ（分压点接 ADC）：
 分压比 = (R1 + R2)/R2 = 1008.2/8.2 = 122.9
 400V 时 ADC 端电压 = 400 / 122.9 = 3.25 V ← 已接近 3.3V，余量仅 1.5%（偏紧）
 建议改 R2 = 7.5kΩ：比 = 1007.5/7.5 = 134.3 → 400V → 2.98 V（余量 9.7%）

电阻功耗：P = V²/R_total = 400² / 1.0075e6 = 0.159 W
 → 单只 1MΩ 需 ≥0.5W 规格（或串联 2 只 0.25W），否则长期工作温漂大
```

> [!IMPORTANT]
> 设计顺序：①定"满量程对应多少物理量"（留 10% 余量）→ ②算分压比 → ③选标准阻值并回代校验余量 → ④算功耗选封装 → ⑤把分压比写进标定系数（附录 B）。这五步做完，增益误差才有可标定的基础。

### 5.2 算例 5-2：误差预算（RSS 合成）

```text
各误差项（以母线电压测量为例）：
 ① 分压电阻容差：两只 1% 电阻最坏叠加 ≈ 2% 增益误差
 ② 运放/ADC 偏置失调：折算 5mV / 3000mV 量程 ≈ 0.17%
 ③ 量化误差：12bit → ±0.5 LSB = ±1/8192 ≈ 0.012%
 ④ 参考电压误差：以手册为准（未核实时按 0.1% 占位并标注）

方和根（RSS，各项独立时）：
 √(2² + 0.17² + 0.012² + 0.1²) = √(4 + 0.029 + 0.0001 + 0.01) ≈ 2.01%

判据与对策：
 未标定：±2.0% → 直接决定"稳压精度 <±1%"能否达标（不能！）
 标定后：增益误差可压到 ≤0.2%（两点标定，附录 B）→ 满足 ±1%
```

> [!WARNING]
> 这条推理链很重要：未标定的 2% 增益误差已经吃光"稳压精度 ±1%"的全部预算。所以量产必须做标定，而"标定流程"属于交付物（附录 B），不是可选优化。

### 5.3 算例 5-3：ACQPS 需要多少（两个口径）

```text
采样保持等效为一阶 RC：τ = R_s · C_h，要求充电误差 < 半 LSB（12bit）

严格口径（0.5 LSB）： t = τ · ln(2^13) = 9.01 τ
宽松口径（0.1%）： t = τ · ln(1000) = 6.91 τ

例：R_s = 10kΩ、C_h = 5pF（C_h 以 datasheet 为准，此处仅代入示范）
 τ = 50 ns
 严格：t = 450 ns → 120MHz 下 54 个周期 → ACQPS ≥ 53
 宽松：t = 345 ns → 42 个周期 → ACQPS ≥ 41

工程取法：取更严者并留 20% 余量 → ACQPS ≈ 64
更省事的做法：加一级运放缓冲，把 R_s 从 10kΩ 降到 100Ω → τ 降 100 倍，
 ACQPS 可降到个位数，把采样预算让给"多通道轮询"
```

| 做法 | ACQPS | 代价 |
| --- | --- | --- |
| 直接分压进 ADC（R_s 大） | 大（几十个周期） | 采样窗挤占通道轮询时间 |
| 加运放缓冲（R_s 小） | 小 | 多一颗运放与供电 |
| 加大 ACQPS | — | 直接减少每周期可采通道数 |

### 5.4 算例 5-4：抗混叠滤波器的相位代价

```text
单极点 RC 滤波器在电流环带宽 fc = 1.8kHz 处的相位滞后：θ = atan(fc / f_p)

 f_p = 8 kHz → θ = atan(1.8/8) = 12.7° （18kHz 开关纹波衰减 −10log(1+(18/8)²) ≈ −7.8dB）
 f_p = 4 kHz → θ = atan(1.8/4) = 24.2° （衰减约 −13.3dB）
 f_p = 1.8 kHz → θ = atan(1) = 45.0° （直接吃掉一半相位裕度）
```

> [!IMPORTANT]
> 结论：抗混叠不能靠把极点压得很低——那会用自己的相位换纹波抑制。本课程的做法是：极点放在 f_sw/2 附近（18kHz 采样 → 8kHz），把 12.7° 相位预算记入第13章的裕度账；真正解决纹波混叠靠"采样时刻对齐载波纹波中心"（5.5），因为对三角纹波而言，对齐采样取到的就是平均值，混叠分量本身被抵消。

### 5.5 SOC 触发与载波对齐：为什么这样采到的是平均电流

```text
电感电流是三角波，三角波的"中点"= 周期平均值：

 iL 波形（纹波）与载波相位的关系
 ╱╲ ╱╲ ← 载波峰（计数器顶端）= iL 纹波谷
 ╱ ╲ ╱ ╲
 ╱ ╲╱ ╲ ← 载波谷（计数器零）= iL 纹波峰
 ──────────────────────►
 在这两点触发 ADC SOC，一次就读到平均电流
```

| 触发方式 | 读到什么 | 后果 |
| --- | --- | --- |
| 载波峰/谷硬件触发（推荐） | 平均电流 | 与模型一致，环路设计可直接用 |
| 固定延时后触发 | 平均值 + 随占空比变化的偏差 | 等效增益随工况漂移 → 某些工况电流环发抖 |
| 软件在 ISR 里启动 | 平均值 + 抖动误差 | 抖动 1µs → 0.267A 误差（第4章算例 4-3） |

> [!WARNING]
> 纪律：SOC 触发源一律用 ePWM 硬件事件；采样时刻必须与载波对齐，并在设计文档里写明"采的是峰还是谷"。这条纪律同时是第0章 0.C 中 1.5Ts 延迟模型成立的前提。

### 5.6 算例 5-5：双向电流调理的偏置与增益

```text
对象：±150A 双向电流（放电为正、充电为负）

方案：分流器/霍尔输出经运放调理，偏置到 ADC 中点 1.65V：
 正满量程（+150A）→ 3.30V，负满量程（−150A）→ 0.00V
 增益 = 1.65V / 150A = 11 mV/A
 分辨率 = 3.3V / 4096 / 0.011 V/A = 0.0733 A/LSB （12bit 量化步进）

判据：
 量化噪声 0.073A / 9.1A（2kW 系统额定）≈ 0.8% → 可接受（配合过采样更低）
 零偏必须软件校准：零电流时读数应稳定在 1.65V ±5mV（0.15% FS）
```

| 方案 | 优点 | 代价 |
| --- | --- | --- |
| 分流器 + 隔离放大器 | 精度高、带宽宽 | 需隔离供电；共模与自热要处理 |
| 霍尔采样 | 天然隔离、量程宽 | 零漂与带宽不如分流器 |
| 开尔文采样（分流器必须） | 消除引线压降误差 | PCB 需单独走取样线 |

### 5.7 校准与过采样

```text
// 零偏在线校准（待机时执行，写进参数表）
#define CAL_N 256
float ia_off_sum = 0;
for (int k = 0; k < CAL_N; k++) ia_off_sum += ADC_readPhaseA();
ia_offset = ia_off_sum / CAL_N; // 每个通道一个偏置系数
```

| 手段 | 能解决 | 不能解决 |
| --- | --- | --- |
| 零偏在线校准 | 运放失调、缓慢温漂 | 增益误差、动态误差 |
| 两点标定（附录 B） | 增益 + 偏置 | 时变误差 |
| 过采样平均（M 次） | 随机噪声（每 4 倍降 1bit 量化噪声） | 系统偏差；且引入 (M−1)/2 拍延迟 |

> [!WARNING]
> 过采样不能用在电流环反馈：M=8 时平均延迟 ≈3.5 拍；18kHz 下 3.5×55.6µs ≈ 194.6µs 的等效额外延迟，在 1.8kHz 处等于 126° 相位（360×1800×194.6e-6）——直接把环路推入不稳定。过采样只用于遥测与保护（第41/36章）。

### 5.8 三相同刻采样

```text
i_N = −(i_a + i_b + i_c) // 四线制的零序/中线电流，不需额外通道
```

| 方案 | 适用 | 限制 |
| --- | --- | --- |
| 3 路传感器 + 3 ADC 同触发（推荐） | 四线制、不平衡负载必备 | 占 3 个 ADC 与 3 路调理 |
| 2 路传感器 + 第三相重构 | 成本敏感、三线制 | 占空比接近 0/100% 时有效采样窗不足 → 重构失效，必须避开或限幅 |

> [!IMPORTANT]
> 为什么四线制倾向三路独立采样：重构法必须占用"采样窗落在低侧管导通期间"，而四线制单相满载时占空比会走到极端，重构失效区正好落在最需要精度的工况上。

### 5.9 上机核对（LAB0/LAB2）

| 步骤 | 该看到什么 | 判据 |
| --- | --- | --- |
| 已知电压逐通道比对 | 各通道读数一致，误差 <0.5% FS | 分压比回代校验 |
| 零电流偏置检查 | 读数稳定在 1.65V±5mV | 1 分钟内漂移 <2mV |
| 采样时刻与载波 | 同屏：载波峰（谷）处出现采样触发沿 | 偏差 <2% 周期 |
| ACQPS 建立检查 | 示波器探采样保持节点，窗口内建立完成 | 无可见"未到顶" |
| 纹波混叠检查 | 电流反馈在稳态下抖动 <0.2% FS | 超过则检查采样时刻 |

### 5.10 失败案例复盘：采样窗不足导致"电流环只在某些工况发抖"

> [!CAUTION]
> 现象：电流环在轻载、高占空比工况下持续高频抖动，重载正常。定位路径：①看 Graph 电流反馈（含高频噪声）→ ②换到直流测试（噪声消失，说明不是调理噪声）→ ③查采样时刻（发现在高占空比时采样点已落在开关沿附近）→ ④核算 ACQPS（按 0.1% 口径取值，但 R_s 在高温下变大，实际未建立完成）。根因：ACQPS 取宽松口径且未留余量；高温使源阻抗上升，建立时间不够，读数系统性偏低且随温度漂移。预防措施：①ACQPS 按 0.5 LSB 严格口径 + 20% 余量；②高温试验（40℃ 满载）必测采样精度；③优先降低 R_s（加缓冲），而不是加大采样窗。

### 5.13 补充：三组 ADC 并行与采样率预算（参考工程实证）

```text
参考工程用 ADCA + ADCB + ADCD 三组（未用 ADCC），全部 SOC 由 ePWM2 SOCA 触发（TRIGSEL = 7）：
 ADCA 通道分配示例：CHSEL 5 = Vouta/VBPA/Ibal/Vnpgnd/VINDC_A（复用）、4 = Vinva、3 = Iinva、2 = Ila1、15 = Ila2
 ACQPS = 12 → 采样窗 13 个 SYSCLK；转换时间 10.3 个 ADCCLK（ADCCLK = SYSCLK/3 = 40MHz）
采样率预算（工程注释里的算法）：
 单通道周期 = 13/120MHz + 10.3/40MHz = 108.3ns + 257.5ns = 365.8ns
 单组 ADC 等效采样率 = 1/365.8ns = 2.733 MSPS
 校验：必须不超过器件上限 3.1 MSPS 
为什么需要三组并行：18kHz 载波、每拍要采 10 路以上（三相电压/电流、中点、平衡支路、温度、模块 ID）
 单组顺序采 12 路 = 12×365.8ns = 4.39µs（占 55.6µs 周期的 7.9%，且各通道采样时刻不齐）
 三组并行后每组 4~5 路 → 窗口缩短、各通道时刻更接近（计量与相位一致性更好，第41章）
纪律：①多组 ADC 必须由同一触发源同拍启动；②不同 ADC 的采样时刻差要计入计量误差预算（第41章 41-2 的 0.35% 主导项）；③ACQPS 不能随意加大，它直接决定采样率上限
```
