**本章要解决的问题：** 把"选什么补偿器"变成可复算的流程：①零极点抵消法（穿越频率由你定、PM 自动到手）；②谐振控制器组的**相位代价公式**（解释第13章为什么 ωc 只能取 1Hz）；③PR 环路为什么把 PM / GM 门槛放宽到 40°。

### 22.1 补偿器选型表（先看对象有什么极点）

| 对象特征 | 选什么 | 为什么 | 章 |
| --- | --- | --- | --- |
| 单极点（L/R、RloadC） | PI（零点抵消该极点） | 抵消后剩纯积分，PM 可接近 90° | 22-1 |
| 纯积分（1/(sL)、1/(sC)） | PI（零点放在 fc/10） | 无极点可消，零点只补低频增益 | 11~14 |
| 高 Q 双极点（LC 谐振） | 先加阻尼（有源/无源），再选 PI | 平坦增益的 PI 无法把谐振峰压到 0dB 以下 | 11-1 / 13-3 |
| 含 RHP 零点（Boost/反激） | PI + 交越 ≤ fRHPZ/3 | RHP 零点无法抵消 | 12-2 |
| 需要跟踪正弦量 | PR / 准 PR（+谐波谐振器组） | 在指定频率堆增益实现零稳态误差 | 13 / 22-2 |

### 22.2 算例 22-1：零极点抵消法（一步算出 Kp、Ki）

```text
对象：Gp(s) = K/(1 + s/ωp)，取 K = 100、ωp = 2π×160 = 1005 rad/s（160Hz 的 RC/RC 型极点）
PI：Gc(s) = Kp(s + ωp)/s （把零点正好放在对象极点上）

抵消后开环：T(s) = Kp·K·ωp/s → 纯积分器（−20dB/dec，相位 −90°）
交越频率 ωc 处 |T| = 1：
 Kp = ωc/(K·ωp)

取 fc = 500Hz（18kHz 平台的保守选择）：
 Kp = 3141.6/(100×1005) = 0.03126
 Ki = Kp·ωp = 0.03126×1005 = 31.42 (1/s) → Ki·Ts = 31.42×55.6e-6 = 1.75e-3
 相位校验：−90°(积分) − 15.0°(延迟 1.5Ts@500Hz) = −106.9° → PM = 73.1° 
 GM：高频段还有一个 −20dB/dec 的余量，实测 ≥15dB 

对照（零点放在 fc/10 = 50Hz，不抵消极点）：
 Kp 由 |Gc(500Hz)|·|Gp(500Hz)| = 1 解出：
 |Gp(500)| = 100/√(1+(500/160)²) = 30.2；|Gc(500)| = Kp·√(1+(50/500)²) = 1.005Kp
 → Kp = 1/(30.2×1.005) = 0.03295；Ki = 0.03295×2π×50 = 10.35 (1/s) → Ki·Ts = 5.75e-4
 相位：−72.3°(未抵消的对象极点) − 5.7°(零点) − 15.0°(延迟) = −94.9° → PM = 85.1°（更宽裕）
 但低频增益差 3 倍：10Hz 处 |Gc| = 0.501（抵消法） vs 0.168（不抵消）
 → 结论：抵消法的价值是"让 −20dB/dec 从 ωp 一直延伸到 0dB"，把低频增益做到最大；
 代价是交越处的相位只剩"90° − 延迟"。若对象有两个以上极点（LC 谐振、级联 RC），
 不抵消会让相位在交越处跌破 −180°，此时抵消法从"优化"变成"必须"。
```

### 22.3 算例 22-2：谐振控制器组的相位代价公式（本章核心）

```text
单个谐振项：Gr(s) = 2Kr·ωc·s/(s² + 2ωc·s + ω0²)
在远离中心频率（ω ≫ ω0）处：Gr(jω) ≈ 2Kr·ωc/(jω) → 幅值 2Krωc/ω，相位 −90°
→ 每个谐振器在交越频率 fc 处贡献一个"滞后 90° 的小矢量"，幅值为 2Kr·ωc/(2πfc)

合矢量 IΣ = Σ_h 2Kr_h·ωc_h/(2π·fc)
相位代价 Δφ = −atan(IΣ/Kp) ← 直接从 Kp 与合矢量算出来，不需要仿真

用第13章的四个谐振器验算（fc = 455Hz）：
 ωc = 6.28（1Hz 半带宽），Kr = 0.6 / 0.05 / 0.03 / 0.02
 IΣ = 2×6.28×(0.6+0.05+0.03+0.02)/(2π×455) = 2×6.28×0.70/2858.8 = 3.077e-3
 Δφ = −atan(3.077e-3/0.0314) = −5.6° （与第13章算例 13-5 一致）

反过来做设计：给定允许的相位代价 Δφ_allow，反解 ωc 上限
 要求 Δφ ≤ 10°（即 IΣ ≤ 0.176×Kp = 0.00553）：
 ωc ≤ 0.00553×2π×455/(2×0.70) = 11.3 rad/s（半带宽 1.8Hz）
 若把 Kr 之和放大到 2.8（极端追求谐波指标）：
 ωc ≤ 0.00553×2π×455/(2×2.8) = 2.82 rad/s（半带宽 0.45Hz）→ 必须频率自适应
 若把 ωc 放宽到 31.4（10Hz，想抗 ±5Hz 频偏）：
 IΣ = 2×31.4×0.70/2858.8 = 0.01538 → Δφ = −26.1° → PM 只剩约 20° 
 ← 这就是第13章把 ωc 从 31.4 改到 6.28 的定量依据
```

> [!IMPORTANT]
> 本课程的设计规则（可直接背）：谐振器合矢量 IΣ≤ 0.2×Kp（相位代价 ≤11.3°）。若电网频率偏移超出谐振器半带宽，用 PLL 自适应中心频率（第29章），而不是加大 ωc——加大 ωc 是拿相位裕度换频率容忍度，非常不划算（本例 1→10Hz 要付出 20°）。

### 22.4 算例 22-3：PR 环路的 PM 门槛为什么是 40°

```text
PI 环路要求 PM ≥45° 的理由：谐振/延迟等不确定性会让相位裕度在批量生产中漂移（第17章敏感度）
PR 环路的差别：
 ① 谐振器带来的相位滞后是"窄带"的：只在中心频率附近的 IΣ 矢量在交越处生效，
 而其幅值随频率下降（∝1/ω），频率偏移时滞后更快消失
 ② 基波通路的 Kp 决定了"宽带"行为的鲁棒性，仍按 45° 口径设计
 ③ 谐波谐振器只影响指定频率，不会造成全频段振荡

定量对照（第13章 + 第17章敏感度）：
 Kp 通路（宽带）：PM = 48.4°（455Hz 处按 Kp×|O| 计算）
 含谐振器：PM = 46.4°（谐振器代价 Δφ = 5.6°，与 22.3 公式一致）
 最坏组合（L +20%、延迟 2.5Ts）：
 内环等效带宽 1kHz→833Hz → 内环在 455Hz 的滞后 24.4°→28.6°（+4.2°）
 延迟 +1 拍 = 360°×455×55.6e-6 = +9.1°
 → PM = 46.4 − 4.2 − 9.1 = 33.1°：跌破 40° 门槛，贴着 22.6 的 ≥30° 底线
 → 结论：PR 环路把门槛定为 40°（本课程口径），并用"最坏组合复算"作为真正的守门人：
 名义 46.4° 对 40° 门槛只有 6.4° 富余，一组参数漂移就能吃光；
 单相逆变器在 18kHz 平台上"含谐振器"的 PM 落在 40~50° 属正常区间
```

### 22.5 代码：设计脚本接口（Phase Cost 计算器）

```c
/* ---------- reso_phase_cost.c：把 22.3 的公式做成可调用函数（上位机/脚本同款） ---------- */
typedef struct { float kr; float wc; } reso_spec_t; /* 每个谐振器的 Kr 与 ωc */

/* 交越频率处的谐振器合矢量与相位代价（度） */
float reso_phase_cost(const reso_spec_t *rs, uint8_t n, float kp, float fc_hz)
{
 const float w = 2.0f * 3.14159265f * fc_hz;
 float isum = 0.0f;
 for (uint8_t k = 0; k < n; k++) {
 isum += 2.0f * rs[k].kr * rs[k].wc / w; /* 2Kr·ωc/ω */
 }
 return atanf(isum / kp) * 180.0f / 3.14159265f; /* 返回正数=代价大小(度) */
}

/* 设计期断言：把 22.3 的规则做成可执行判据 */
uint8_t reso_design_check(void)
{
 /* 第13章的设计：Kp=0.0314、fc=455Hz、Kr/ωc 如下 */
 static const reso_spec_t RS[4] = {
 { 0.6f, 6.2832f }, /* 50Hz */
 { 0.05f, 6.2832f }, /* 150Hz */
 { 0.03f, 6.2832f }, /* 250Hz */
 { 0.02f, 6.2832f }, /* 350Hz */
 };
 const float cost = reso_phase_cost(RS, 4, INV_KP_V, 455.0f);
 if (cost > 11.3f) return 1u; /* 超过设计规则 0.2×Kp 对应值 */
 return 0u;
}

/* 若电网频率偏移超出半带宽，改用自适应 ω0（第29章接口），而不是放大 ωc */
void reso_set_center(float f_grid_hz)
{
 /* 由 f_grid 重算各次 b0/a1/a2（系数公式见第13章 13.8），并写入谐振器组 */
 reso_retune_all(f_grid_hz);
}
```

### 22.7 失败案例复盘：为压 THDu 把 Kr 放大 5 倍，THDu 反而更差

> [!CAUTION]
> 现象：为把 THDu 从 1.2% 压到 0.5%，把 Kr3/5/7 各放大 5 倍，结果 THDu 升到 1.8%，输出波形出现低频"呼吸"。定位路径：①扫频测 PM（从 46.4° 掉到约 22°）→ ②用 22.3 的公式手算：若只放大 Kr3/5/7，IΣ 从 3.08e-3 增到 4.83e-3 → 代价 5.6°→8.8°，解释不了 22° → ③复核代码发现 Kr 表被整体 ×5（基波 Kr=0.6 也被放大到 3.0）→ IΣ = 1.54e-2、代价 26° → 与实测 PM≈20° 吻合 → ④恢复 Kr、只按需放大 3/5/7 并用reso_phase_cost()复核。根因：把"谐波抑制"当成"堆增益"的单调问题，忽略谐振器在交越处的相位代价；且"放大 3/5/7"的操作实际把基波谐振器一并放大，代价被放大近 3 倍。预防措施：①Kr 只按"够用"取值（本例 5%/3%/2% 已把 RSS 压到 0.360%，本来就无需放大）；②改 Kr 后必须用reso_phase_cost()复核并重跑扫频；③把"谐振器合矢量 ≤0.2Kp"写进设计评审检查表；④THDu 不达标时优先查测量（采样对齐、第12章复盘）而不是加 Kr。
