**本章要解决的问题：** 让输入电流"长得像"输入电压——同时满足 PF ≥0.99、电流谐波 ≤5%（见 [整机验收指标表](/posts/power/courses/ups-pcs-dsp/docs/acceptance/)）。难点不在"能不能控"，而在**两个带宽上限**：内环被 RHP 零点与 1.5Ts 延迟压住，外环被 2ω 母线纹波压住。本章用 2kW/220V→700V 的算例把四个算例算到底，并给出可直接编译的双环 + 陷波代码。

### 12.1 拓扑与指标映射

```text
AC 220V ──[EMI]──[整流桥]──[L = 3.74mH]──┬──[S 高频管]──┐
                                        │              │  母线 700V（第8章）
                                        └──[D]──────────┴──[C = 1000µF]──► 逆变器
```

| 指标（验收表 A 组） | 由谁决定 | 本章算例 |
| --- | --- | --- |
| PF ≥0.99 / 0.97 / 0.94（半载/额定/轻载） | 电流环带宽 + 采样时刻对齐 + 相位补偿 | 12-2 / 12-3 |
| 输入电流谐波 ≤5% / ≤7% / ≤10% | 外环带宽（2ω 纹波 → 3 次谐波）+ 过零畸变 | 12-4 |
| 母线电压稳定（瞬变 ≤±5%、恢复 ≤20ms） | 外环 + 功率前馈 | 12-3 / 12-5 |
| 保持时间 20ms（第1章算例 1-2） | 母线电容 1000µF | 12-5 校核 |

### 12.2 算例 12-1：电感选型（把开关频率与体积的账算清楚）

```text
条件：Pin = 2kW，Vin,rms = 220V，Vo = 700V（第8章母线），fsw = 18kHz（平台统一）
  I_rms = 2000/220 = 9.09 A      I_pk = 9.09×√2 = 12.86 A

峰值点的占空比（Boost）：D = 1 − Vin,pk/Vo = 1 − 311/700 = 0.5557
取电流纹波比 ΔI/I_pk = 20% → ΔI = 2.57 A
  L = Vin,pk·D/(ΔI·fsw) = 311×0.5557/(2.57×18000) = 172.8/46260 = 3.74 mH

对比 65kHz（若允许提高开关频率）：
  L = 172.8/(2.57×65000) = 1.03 mH   ← 电感体积降到 1/4，代价是开关损耗与 EMI
判据：ΔI/I_pk ≤30%（纹波过大→电流环增益波动、过零畸变）；同时校核磁芯不饱和
```

### 12.3 算例 12-2：电流内环（两个带宽上限取最小）

```text
内环对象（平均电流模式，母线刚性假设：母线电容足够大且外环足够慢，内环设计时 v̂≈0）
  Gid(s) ≈ Vo/(sL) = 700/(s×3.74e-3)

上限 1：fsw/10 = 1.8 kHz
上限 2：RHP 零点 f_RHPZ = D′²R/(2πL)，D′ = 311/700 = 0.4443，R = 700²/2000 = 245Ω
        f_RHPZ = 0.4443²×245/(2π×3.74e-3) = 48.36/0.023499 = 2,058 Hz → /3 = 686 Hz
上限 3：1.5Ts 延迟（换算成"吃掉 45° 相位"的频率：360°·f·83.3µs = 45° → f = 1333 Hz）
→ 取最小并留余量：fc_i = 650 Hz

  |Gid(650Hz)| = 700/(2π×650×3.74e-3) = 700/15.28 = 45.8 A/duty
  需 |Gc_i| = 1/45.8 = 0.02183 → Kp_i = 0.02172 duty/A（零点取 65Hz）
  Ki_i = Kp_i·2π×65 = 8.87 (1/s) → 离散 Ki·Ts = 8.87×55.6e-6 = 4.93e-4

校验：PM = 180 − (90 + 5.71（零点）+ 19.5（延迟@650Hz）) = 64.8° ✓
      GM：在 1.8kHz 处 |G_ol| = 0.0217×16.55 = 0.359 → −8.9 dB ✓（≥6dB）
```

> [!WARNING]
> 为什么 18kHz 平台的 PFC 电流环只有 650Hz：RHP 零点在 2.06kHz，1.5Ts延迟在 650Hz 就已吃掉 19.5°。这就是"低开关频率 + 大电感"的两重代价。若改用 65kHz（L = 1.03mH，fRHPZ= 7.47kHz），fci可提到 2.5kHz 量级——提高开关频率在这里买到的是实打实的带宽。

### 12.4 算例 12-3：电压外环（用功率平衡模型，避开 2ω 陷阱）

```text
外环对象（功率平衡法：内环已让输入电流跟随指令，外环看到的是功率注入母线）
  C dV/dt = (Pin − Pload)/V    →   v̂ = (V_rms·î_ref)/(s·C·V)
  即对象 = V_rms/(s·C·V) = 220/(s×1000e-6×700) = 220/(s×0.70)

设计目标 fc_v = 10 Hz（上限来自 2ω = 100Hz 纹波，见算例 12-4）
  |obj(10Hz)| = 220/(2π×10×0.70) = 220/43.98 = 5.003 V/A
  需 |Gc_v| = 1/5.003 = 0.1999 → Kp_v = 0.2000 A/V（零点取 2Hz）
  Ki_v = 0.2000×2π×2 = 2.513 (1/s) → 离散 Ki·Ts = 2.513×55.6e-6 = 1.40e-4

母线电容校核（保持时间 20ms，母线最低允许 600V）：
  C = 2·P·t/(V² − Vmin²) = 2×2000×0.02/(700² − 600²) = 80/(130000) = 615 µF
  实际取 1000µF → 保持时间 32.5ms ✓（留足老化与降额余量，第46章）
```

### 12.5 算例 12-4：2ω 纹波如何变成 3 次谐波（外环带宽的真正上限）

```text
单相 PFC 母线必然有 2ω（100Hz）纹波：设母线纹波 10V(峰峰) → 幅值 ΔV = 5V
电压环在 100Hz 的增益（零点 2Hz 以上近似平坦）≈ Kp_v = 0.2000 A/V
  电流指令幅值纹波 ΔI_ref = Kp_v × ΔV = 0.2000 × 5 = 1.00 A

幅值调制产生边带（标准结论）：
  i_in = (I + ΔI_ref·cos2ωt)·cosωt = I·cosωt + (ΔI_ref/2)[cos3ωt + cosωt]
  → 3 次谐波幅值 = ΔI_ref/2 = 0.50 A → 有效值 0.354 A
  → 相对基波：0.354/9.09 = 3.9%   ✓ 满足 ≤5%

若采用 fc_v = 15Hz（Kp_v = 0.294）：
  3 次谐波 = (0.294×5/2)/1.414 = 0.520 A(rms) → 5.7%  ✗ 超出 ≤5%
```

> [!IMPORTANT]
> 这就是"PFC 电压环只能做到 10~20Hz"的算术原因：外环增益越高，母线 2ω 纹波越容易被搬进电流指令，变成 3 次谐波。带宽与谐波指标直接对冲。想两者兼得只有两条路：①加 2ω 陷波器（代码见 12.6）；②用"母线电压滑动平均"或"波纹补偿"把 2ω 分量从反馈里先剔掉。

### 12.6 代码：双环 + 2ω 陷波 + 前馈（可编译）

```c
/* ---------- param_table.h：常量来源（12.2~12.5） ---------- */
#define PFC_FSW_HZ      18000.0f        // Hz，平台统一（第0章 0.B）
#define PFC_TS          (1.0f/PFC_FSW_HZ)          // s = 55.6µs
#define PFC_L_H         3.74e-3f         // H，电感（算例 12-1）
#define PFC_C_F         1000e-6f        // F，母线电容（算例 12-3）
#define PFC_VDC_REF     700.0f          // V，母线设定（第8章）
#define PFC_VIN_RMS     220.0f          // V，额定输入（第0章 0.A）
#define PFC_KI_KP       0.0217f         // duty/A，内环 Kp（算例 12-2）
#define PFC_KI_KI_TS    4.93e-4f        // duty/(A·拍)，Ki·Ts（算例 12-2）
#define PFC_KV_KP       0.2000f         // A/V，外环 Kp（算例 12-3）
#define PFC_KV_KI_TS    1.40e-4f        // A/(V·拍)，Ki·Ts（算例 12-3）
#define PFC_ILIM_A      12.9f           // A，电流指令上限 = 1.0×I_pk（12.2）

/* ---------- 2ω 陷波器（中心 100Hz，与算例 12-4 配套） ----------
   H(s) = (s² + ω0²)/(s² + ω0·s/Q + ω0²)，ω0 = 2π×100，Q 取 3（带宽 33Hz）
   Tustin + 预畸变：k = tan(ω0·Ts/2) = tan(π×100×Ts) = tan(0.017453) = 0.017455，Ts = 1/18kHz
   令 D0 = 1 + k² + k/Q = 1 + 3.0468e-4 + 5.8184e-3 = 1.0061230
     b0 = (1+k²)/D0 = 0.99422        b1 = 2(k²−1)/D0 = −1.98722   b2 = b0
     a1 = 2(k²−1)/D0 = −1.98722      a2 = (1+k²−k/Q)/D0 = 0.98843
   旁证：b1 = −2·b0·cos(ω0·Ts) = −2×0.99422×cos(0.034907) = −1.98722 ✓
   校核：直流增益 (b0+b1+b2)/(1+a1+a2) = 1.0000 ✓；Nyquist 处亦为 1.0000 ✓
-------------------------------------------------------------------------- */
#define NOTCH_B0  0.99422f
#define NOTCH_B1 (-1.98722f)
#define NOTCH_B2  0.99422f
#define NOTCH_A1 (-1.98722f)
#define NOTCH_A2  0.98843f

static float nz1, nz2;
float notch2w_step(float x)              // DF-II Transposed，输入母线电压
{
    const float y = NOTCH_B0 * x + nz1;
    nz1 = NOTCH_B1 * x - NOTCH_A1 * y + nz2;
    nz2 = NOTCH_B2 * x - NOTCH_A2 * y;
    return y;
}

/* ---------- pfc.c ---------- */
static ctrl_pi_t pi_i = { PFC_KI_KP, PFC_KI_KI_TS, 0.0f, 0.98f, 0.0f, 0.0f, 20.0f };
static ctrl_pi_t pi_v = { PFC_KV_KP, PFC_KV_KI_TS, 0.0f, PFC_ILIM_A, 0.0f, 0.0f, 5.0f };

/* PFC 电流环 ISR：18kHz，与 PWM 载波同步（第4章五件事） */
void pfc_isr(void)
{
    const float v_bus  = adc_to_volt(g_adc.raw_vbus, &g_adc.cal_vbus);
    const float vin_ins= adc_to_volt(g_adc.raw_vin,  &g_adc.cal_vin);   // 瞬时输入电压
    const float i_l    = adc_to_amp (g_adc.raw_il,   &g_adc.cal_il);   // 电感电流（中点采样）

    /* ① 电流指令 = 外环输出（幅值） × 单位正弦（来自第7章捕获/PLL 的相位） */
    const float v_avg = notch2w_step(v_bus);                 // 先剔掉 2ω，避免搬进指令
    const float i_amp = ctrl_pi_step(&pi_v, PFC_VDC_REF - v_avg);
    const float s_th  = sinf(pll_get_theta());               // 与输入电压同相
    const float i_ref = i_amp * s_th;

    /* ② 内环 → 占空比，加输入电压前馈（减少积分器负担，加速过零附近响应） */
    const float d_ff   = 1.0f - vin_ins / v_bus;             // Boost 稳态占空比前馈
    const float d_cmd  = ctrl_pi_step(&pi_i, i_ref - i_l) + d_ff;

    pwm_set_duty(pwm_boost, d_cmd);
    adc_clear_soc_flag();
    Interrupt_clearACKGroup(ISR_PFC);                        // 应答 PIE 组
}
```

> [!TIP]
> 三个细节决定成败：①电流采样必须在开关管导通中点（第5章 5.5），采到的是平均电流；采在开关沿上会采到纹波峰/谷，过零点附近直接失控。②陷波器只用于外环反馈，绝不放进内环（会引入相位）。③前馈d_ff让积分器只负责修正误差，过零附近（Vin→0）动态才能跟上。

### 12.8 失败案例复盘：过零畸变——采样时刻比补偿器更关键

> [!CAUTION]
> 现象：PF 只有 0.96，THDi 8.5%；示波器上看输入电流在过零附近有约 1ms 的"平顶"。软件上怎么调 Kp/Ki 都无改善。定位路径：①看采样时刻（ADC 触发点固定在计数器零点，即开关管关断时刻）→ ②此时电感电流处于纹波谷值，不是平均值 → ③过零附近纹波占比相对更大（I_pk 小），误差最大 → ④把触发点移到开关管导通中点（计数峰对齐）后 THDi 降到 3.2%。根因：用了"错误时刻的瞬时值"当平均电流，误差随负载/相位变化；这属于共模误差，闭环增益再高也修不掉。预防措施：①采样时刻按第5章 5.5 的规则对齐并写入设计说明；②上机核对必须包含"过零附近波形"这一项；③当发现"调增益无效的畸变"时，优先怀疑测量而不是控制；④把采样对齐列入 LAB2 的固定检查项。
