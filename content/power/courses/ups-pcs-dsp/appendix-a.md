本附录回答三个问题：**该按哪些标准做**、** 试验怎么测**、** 现场最常见的不符合项是什么**。数值口径统一取自 [整机验收指标表](/posts/power/courses/ups-pcs-dsp/docs/acceptance/)（其来源为中国移动模块化 UPS 技术规范书 V2）。

### A.1 标准清单与适用关系

| 标准 | 管什么 | 本课程对应指标/章节 |
| --- | --- | --- |
| GB 7260.1 | UPS 安全：绝缘、耐压、漏电流、接地 | 绝缘 >2MΩ、耐压 2000VAC/1min、漏电流 ≤3.5mA、接地 ≤0.1Ω（第45章） |
| GB/T 14549 | 公用电网谐波限值 | 输入谐波 ≤5%/7%/10%（第12/23章） |
| YD/T 983 | EMC 限值与测量方法 | 传导/辐射发射与抗扰（第45章） |
| YD/T 2165 | 模块化 UPS 产品要求 | 整机验收 A~G 组全部指标（第48章 48-4） |
| GB/T 34120 | 储能变流器功能与性能 | PCS 的 PQ/VF/LVRT 与保护（第33章） |
| IEEE 1547 | 并网互联、孤岛、穿越 | 孤岛 ≤2s（第44章）、LVRT（第33章） |
| IEEE 519 | 并网电流谐波（TDD 口径） | TDD 与分母口径（第23章 23-2） |

### A.2 关键试验的测法与判据（工程师视角）

```text
① 绝缘电阻（>2MΩ）：
 500V 或 1000V 兆欧表，测"相线—地""母线—地"；测量前断开 SPD 与 Y 电容（否则读数被拉低）
 读数稳定后 60s 取值；环境湿度 >80% 时需记录并注明

② 耐压（2000VAC/1min）：
 从 0 升到试验电压用 ≥5s，保持 1min，降压用 ≥5s（避免冲击）
 泄漏电流监视（通常 ≤5mA/回路）；**测试时必须断开所有半导体与电容**
 试验后必须复测绝缘与功能（高压可能损伤器件）

③ 漏电流（≤3.5mA）：
 按 YD/T 983 的测量网络（模拟人体阻抗），在 1.06 倍额定电压下测
 与第45章 45-2 的"共模位移电流"预算对拍（本课程预测 2.67mA）

④ 接地连续性（≤0.1Ω）：
 25A 以上试验电流，测机壳接地点到接地排的压降并折算电阻

⑤ 谐波与 PF：
 稳态 10 个周波窗；三组负载（半载/额定/轻载）分别记录（口径见第23章 23-1）
```

### A.3 认证流程与"提前介入"清单

| 阶段 | 动作 | 返工代价 |
| --- | --- | --- |
| 设计阶段（必须做） | 漏电流预算（45-2）、EMI 滤波衰减（45-3）、爬电距离/电气间隙核查、SPD 选型 | 1× |
| 样机阶段 | 预测试（自有设备近似测）、关键器件证书齐全（电容/继电器/风扇/线材） | 10× |
| 送检阶段 | 正式送第三方实验室；准备图纸、BOM、说明书、铭牌 | 100× |
| 量产后 | 一致性核查（关键件变更必须重新评估）、年度抽查 | — |

### A.4 现场最常见的 5 个不符合项（本书复盘的汇总）

> [!CAUTION]
> ① 漏电流超标（第45章复盘）：根因是器件对散热器寄生电容，软件无法修 → 必须改绝缘材料/结构。② 传导发射 150~500kHz 超标：根因多为共模滤波谐振频率过高（45-3 要求 ≤18kHz）或 Y 电容布置不当。③ 耐压试验后功能异常：试验时未断开半导体/电容，或升压过快 → 必须写进试验作业指导书。④ 爬电距离不足（三电平分裂母线 350V 段）：PCB 未按电压分段核查 → 设计阶段用"电压—间距表"逐段签核。⑤ 铭牌/说明书参数与实测不符：常见于"效率只取最优值"（第39/48章要求给出全负载段曲线）。预防措施：把以上 5 条做成《认证自查表》，送检前逐条签核；每条的定量依据都在本书对应章节。

### A.5 认证相关参数的可追溯要求

| 参数 | 设计值来源 | 必须保留的记录 |
| --- | --- | --- |
| 绝缘/耐压/漏电流/接地 | GB 7260.1 + 验收表 G 组 | 型式试验报告 + 每台出厂测试值 |
| 谐波/PF/THDu | GB/T 14549 + 验收表 A 组 | 三组负载的实测频谱 |
| EMC | YD/T 983 | 传导/辐射/抗扰报告 + 关键件变更记录 |
| 孤岛/LVRT | IEEE 1547 / GB/T 34120 | 检测时限与曲线实测 |
| 标识与说明书 | 各产品标准 | 铭牌、参数表、安装维护说明（含"先停机再分闸"，第43章） |

> [!IMPORTANT]
> 一句话总结：安规与认证不是"最后一道关"，而是从第一天就写进设计的数字。本书把每条指标都给了设计依据与算例——照着算，认证就能一次通过。

### A.6 练习

1. **E1** 用第45章 45-2 的方法估算你手上设备的漏电流，判断能否满足 ≤3.5mA，并给出两条整改措施。
2. **E2** 写一份"耐压试验作业指导书"（含需断开的器件、升压速率、判据、试验后复测项），并说明每一步的物理原因。
3. **E3** 把所在项目的铭牌参数与 [验收指标表](/posts/power/courses/ups-pcs-dsp/docs/acceptance/) 逐条对照，找出缺项与口径不一致处（这份对照表就是送检前的自查表）。（参考答案见 [练习参考答案](/posts/power/courses/ups-pcs-dsp/docs/answers/)）
