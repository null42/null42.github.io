**本章要解决的问题：** 拿到一个变换器，怎么得到一张能用来设计控制器的幅相曲线？本章给出**一条固定流水线**（状态空间平均 → 平衡点 → 线性化 → 离散化 → 延迟链 → 数值验证），三个算例（Buck 的 f0/Q、延迟的相位代价、扫频时间预算），以及 MATLAB 对拍脚本和 C 侧二阶模型的配套代码。

### 10.1 五步流水线（固定动作，不要跳步）

| 步 | 做什么 | 产出 | 常见漏项 |
| --- | --- | --- | --- |
| 1 | 列导通/关断两态方程，按占空比平均 | 状态空间平均 模型 | 忽略寄生电阻 → 低频增益虚高 |
| 2 | 令导数为零解平衡点 | D、IL、Vo 的关系（校核工作点） | 不校核，模型与实物工况不符 |
| 3 | 加小信号扰动、忽略二次项 | 控制到输出传函 Gvd(s) | 把大信号关系当小信号传函用 |
| 4 | 离散化（Tustin + 预畸变）+ 延迟链 | Gvd(z) | 只做 c2d，漏掉 ZOH 与计算延迟 |
| 5 | 数值扰动扫频与解析式对拍 | 幅相曲线 + 偏差报告 | 扫频幅值过大，测出来是非线性区 |

### 10.2 算例 10-1：Buck 的谐振频率与 Q（LAB1 基准）

```text
参数：Vin = 48V，Vout = 12V，L = 4.7µH，C = 10µF，fsw = 200kHz，负载 3A

工作点：D = Vout/Vin = 12/48 = 0.25，负载电阻 R = 12/3 = 4Ω

SSA 结果（控制到输出）：
 Gvd(s) = Vin / (1 + s/(Q·ω0) + (s/ω0)²)

 f0 = 1/(2π√(LC)) = 1/(2π√(4.7e-6 × 10e-6)) = 1/(2π × 6.855e-6) = 23,215 Hz ≈ 23.2 kHz
 Q = R·√(C/L) = 4 × √(10/4.7) = 4 × 1.4588 = 5.835
 谐振峰 = 20·log10(Q) = 20·log10(5.835) = 15.3 dB
 直流增益 = Vin = 48V（= 20·log10(48) = 33.6 dB）

电容 ESR 零点：ESR = 20mΩ → fz = 1/(2π×20m×10µ) = 796 kHz（远高于 fsw/2=100kHz，可忽略）
```

> [!WARNING]
> Q = 5.84 意味着什么：开环在 23.2kHz 有 15.3dB 的尖峰，且相位在该点附近骤降 180°。若不加补偿直接闭环、且交越频率落在尖峰附近，系统必然振荡。这就是为什么 Buck 电流/电压环的交越要远低于f0（常见取 f0/5 以下）——LAB1 的判据就是实测谐振点与 23.2kHz 的偏差在 ±5% 内。

### 10.3 算例 10-2：延迟链的相位代价（本课程的核心账）

```text
数字控制共有的总延迟（不要漏）：
 ① ZOH（零阶保持）：等效 0.5·Ts
 ② 采样到占空比生效的计算延迟：1.0·Ts（第4章：中断→更新比较值）
 → 合计 1.5·Ts

UPS 场景（fsw = 18kHz，Ts = 55.6µs）：
 总延迟 = 1.5 × 55.6µs = 83.3 µs
 在 1.8kHz 处相位滞后 = 360° × 1800 × 83.3e-6 = 54.0° ← 关键数字

Buck 场景（fsw = 200kHz，Ts = 5µs）：
 总延迟 = 7.5 µs
 在 1.8kHz 处 = 360° × 1800 × 7.5e-6 = 4.9° ← 差 11.1 倍

结论：开关频率越低，延迟的相位代价线性放大。UPS 侧 18kHz 下 54° 几乎吃掉
 全部相位裕度预算，因此必须"先减延迟（对齐采样/单更新），再谈补偿器"。
```

> [!IMPORTANT]
> 这条账是本课程反复使用的主线：第5章（对齐采样减少脉动）、第4章（ISR 时间纪律）、第11~14 章（各变换器的补偿器设计）都围绕"1.5Ts 能降到多少"展开。把 54° 记在脑子里，任何"带宽能不能再高一点"的问题都先扣这 54°。

### 10.4 算例 10-3：数值扰动扫频的时间预算与扰动幅值

```text
扫频设置：200Hz ~ 20kHz，30 个对数分布点，每点记录 20 个周期
 总时长 ≈ Σ(20 / f_k) 
 几何级数求和：r = 100^(1/29) = 1.1715
 Σ 1/f_k = (1/200) · (1 − r^-30)/(1 − r^-1) = 0.005 × 0.9913/0.1464 = 0.0339 s
 总时长 = 20 × 0.0339 = 0.68 s ≈ 0.7 s（低频点主导）
 → 留出稳定时间后按 50 周期/点：约 1.7 s，单次实验完全可接受

扰动幅值选取（1% 原则）：
 Buck：D = 0.25 → 扰动幅值取 0.002（相对 0.8%）
 判据：输出交流分量 ≤1%（不进入限幅/饱和），且 FFT 或相敏检波可分辨
 过大的后果：测到的是非线性区的"平均"特性，相位尤其不可信
```

### 10.5 三种建模手段的分工

| 手段 | 给出 | 用它做什么 | 章节 |
| --- | --- | --- | --- |
| SSA 解析式 | 连续传函（含零极点显式表达） | 设计补偿器、看趋势、灵敏度分析 | 10 / 11~14 |
| 离散化 + 延迟 | G(z)，含 1.5Ts 与频率预畸变 | 数字控制器设计与系数计算 | 10 / 13 |
| 数值扰动扫频 | 实测幅相（可含限幅、饱和等非线性） | 验证与对拍，找出模型与对象的偏差 | 10 / LAB1 |
| 阻抗比判据 | 级联系统的稳定裕度 | 多级变换器级联（PFC+DC-DC）稳定性 | 22 |

### 10.6 MATLAB 对拍脚本（放 `规范与大纲/sim/`，名 lab1_buck_freqresp.m）

```text
% lab1_buck_freqresp.m — Buck 开环扫频：数值扰动 vs 解析式
Ts = 5e-6; fsw = 1/Ts; % 200kHz，与算例 10-1 一致
L = 4.7e-6; C = 10e-6; Vin = 48; D = 0.25; R = 4;
f0 = 1/(2*pi*sqrt(L*C)); % 23,215 Hz
Q = R*sqrt(C/L); % 5.835

f = logspace(log10(200), log10(20000), 30); % 算例 10-3: 30 点
mag = zeros(size(f)); ph = zeros(size(f));
for k = 1:numel(f)
 n = round(20/f(k)/Ts); % 20 个周期（算例 10-3）
 t = (0:n-1)*Ts;
 d = D + 0.002*sin(2*pi*f(k)*t); % 扰动幅值 0.002（1% 原则）
 v = sim_buck(d, t, L, C, R, Vin); % 与固件同结构的被控对象模型
 % 相敏检波（比 FFT 更抗泄漏）：与注入频率做互相关
 I = sum(v.*sin(2*pi*f(k)*t)); Qr = sum(v.*cos(2*pi*f(k)*t));
 ph(k) = atan2(Qr, I) * 180/pi;
 mag(k) = 2*sqrt(I^2 + Qr^2) / n; % 幅值（V）
end

% 解析式对照（算例 10-1）
H = Vin ./ (1 + 1i*f/(Q*f0) - (f/f0).^2);
semilogx(f, 20*log10(mag), 'o', f, 20*log10(abs(H)), '-');
% 判据：谐振点处偏差 ≤5%（LAB1 验收线）
```

### 10.7 C 侧实现：把二阶模型写成可运行的 biquad

```c
/* ---------- Tustin + 预畸变得到 Buck 双极点模型（fs=200kHz, f0=23.215kHz, Q=5.835） ----------
 K = tan(ω0·Ts/2) = tan(2π×23215×2.5e-6) = 0.3819
 D0 = K² + K/Q + 1 = 0.14585 + 0.06545 + 1 = 1.2113
 b0 = b2 = K²/D0 = 0.12041
 b1 = 2K²/D0 = 0.24083
 a1 = (2K² − 2)/D0 = −1.41027
 a2 = (K² − K/Q + 1)/D0 = 0.89193
 校核：b0+b1+b2 = 0.48165，1+a1+a2 = 0.48166（舍入内一致）
------------------------------------------------------------------------- */
#define BQ_B0  0.12041f
#define BQ_B1  0.24083f
#define BQ_B2  0.12041f
#define BQ_A1 (-1.41027f)
#define BQ_A2  0.89193f

static float w1, w2; // DF-II Transposed 状态

float biquad_step(float x) // 输入归一化占空比扰动，输出归一化电压扰动
{
 const float y = BQ_B0 * x + w1;
 w1 = BQ_B1 * x - BQ_A1 * y + w2; // 注意 a1 符号：y = Σb·x − a1·y[n-1] − a2·y[n-2]
 w2 = BQ_B2 * x - BQ_A2 * y;
 return y;
}

/* 上电时复位状态，避免残留值造成首拍冲击 */
void biquad_reset(void) { w1 = 0.0f; w2 = 0.0f; }
```

> [!TIP]
> 为什么在 C 里也要建模型：①固件里做"模型对拍"（控制输出与实际对象比对）可做传感器无故障时的解析冗余校验；②无硬件时可用它跑闭环仿真（HIL 前的最小验证）；③补偿器上下电切换时的状态复位逻辑必须与模型一致，否则会出现首拍冲击。

### 10.8 上机核对（LAB1/LAB2）

| 步骤 | 该看到什么 | 判据 |
| --- | --- | --- |
| Buck 开环扫频 | 幅频在 23.2kHz 出现尖峰 | 谐振点偏差 ≤5%（LAB1 验收线） |
| 尖峰高度 | 比低频增益高 15.3dB | ±2dB（受寄生与探针影响） |

### 10.9 失败案例复盘：漏掉延迟，带宽"算得出来、跑不起来"

> [!CAUTION]
> 现象：设计文档给出 2kHz 交越、PM = 50°，实测一上电就等幅振荡（约 1.9kHz）。定位路径：①复核解析模型（没算错）→ ②用示波器测"指令到占空比生效"的延迟（发现是 2.5Ts，而不是设计假设的 1Ts）→ ③把延迟按 10.3 的方式折算补进模型（1.8kHz 处 54° → 2.5Ts 时 90°）→ ④重设交越到 1.2kHz 后稳定。根因：设计时按"理想瞬时更新"估算相位裕度，忽略了 ZOH(0.5Ts) + 双缓冲/影子寄存器带来的额外一拍。预防措施：①延迟链必须逐项列出并实测（LAB0 用 GPIO 打点）；②裕度表里必须显式写出"延迟相位"这一行；③补偿器设计前先做延迟标定，再谈带宽；④任何"带宽提高一倍"的方案，先扣除多出来的延迟相位再评估。
