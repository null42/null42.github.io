**本章要解决的问题：**EMC 是"设计出来的，不是测出来的"。本章给出四类干扰源—路径—受体表，以及三个可手算的算例：共模电流路径、开关谐波包络与滤波衰减需求、SPD 选型。YD/T 983 是限值依据。

### 45.1 干扰的三要素与对策（先看表，再算数）

| 要素 | 本机来源 | 对策 | 量化依据 |
| --- | --- | --- | --- |
| 源 | 开关 dv/dt（第8章 3.5V/ns）、di/dt（500A/µs） | 软开关、降低 di/dt、吸收电路、五段式 | 45-2 |
| 路径（传导） | 共模经 Y 电容与地、差模经输入线 | EMI 滤波器、Y 电容、共模电感 | 45-3 |
| 路径（辐射） | 长回路天线效应（di/dt 回路） | 缩小回路面积、叠层母排、屏蔽 | 45-4 |
| 受体 | 自身采样通道、通信、外部设备 | 屏蔽、滤波、隔离、单点接地 | 第9章 9-6 |

### 45.2 算例 45-1：共模电流的估算

```text
共模电流主要由 dv/dt 经寄生电容流入地：
  i_cm = C_par · dv/dt，C_par = 器件对散热器的寄生电容（含绝缘垫）
  单管 C_par = 150 pF（含垫片与安装），dv/dt = 3.5 V/ns（三电平 350V/100ns）
  每次开关的位移电流峰值 = 150e-12 × 3.5e9 = 0.525 A
  18kHz 下，每相每周期 2 次开关（含互补管）→ 等效 RMS：
    单脉冲电荷 Q = C·ΔV = 150e-12×350 = 52.5 nC，每周期 2 次 → I_avg = 52.5e-9×2×18000 = 1.89 mA
    三相合计 ≈ 5.7 mA  ← 与验收表 G 组"漏电流 ≤3.5mA"**直接冲突** ✗

  → 必须同时做三件事：
    ① 减小 C_par：用低介电常数垫片（150pF → 80pF）、增大垫片厚度、整块金属基板焊接替代垫片
       重算：80pF 时三相合计 = 5.7×80/150 = 3.02 mA ✓（≤3.5mA，余量 14%；②再降至 ≈2.2mA）
    ② 提高 dv/dt 上升时间（加大 Rg）：3.5 → 2.5V/ns → 再降 28%
    ③ 共模滤波（Y 电容）：在 150kHz~1MHz 内提供额外衰减
  判据：整机漏电流 ≤3.5mA（验收表 G 组）——**这条指标本质上由寄生电容决定**
```

### 45.3 算例 45-2：EMI 滤波器衰减需求（传导发射）

```text
限值（YD/T 983 类）：150kHz~500kHz 准峰值 79dBµV（对应 8.9 mV）
  实测源（未滤波）：假设 150kHz 处共模噪声 300 mV（由 45-2 的位移电流在 LISN 上形成）
  需要衰减 = 20·log10(300/8.9) = 30.6 dB，留 6dB 余量 → 需要 37 dB

  二阶共模 LC 滤波器（L、C 各贡献 −20dB/dec，合计 −40dB/dec）的 150kHz 衰减 ≈ 40·log10(f/f_c)：
    需要 37dB → (f/f_c)² = 10^(37/20) = 70.8 → f/f_c = 8.4 → f_c = 150/8.4 = 17.9 kHz
    → 共模电感 + Y 电容的谐振频率必须 ≤18kHz
  反算元件（按 C_y = 4.7nF×2、L_cm 未知）：
    f_c = 1/(2π√(L·C)) → 18,000 = 1/(2π√(L×9.4e-9)) → √(L×9.4e-9) = 8.84e-6 → L×9.4e-9 = 7.8e-11
    → L = 8.3 mH（共模电感，双线并绕）
  校验漏电流：4.7nF 在 220V/50Hz 的泄漏电流 = 2π×50×4.7e-9×220 = 0.32 mA ✓ 远小于 3.5mA 限值
```

### 45.4 算例 45-3：SPD 与浪涌能量

```text
规范（YD/T 983 类）典型试验等级：1.2/50µs 电压波 + 8/20µs 电流波，共模 2kV/1kA
  SPD 能量 = ∫u·i dt ≈ 0.5×U_peak×I_peak×t_pulse（三角形近似）
    = 0.5×2000×1000×20e-6 = 20 J（单次）
  → 选 SPD 时看"标称放电电流 In ≥5kA、最大能量 ≥40J（20J×2 余量）"
  与器件耐压的关系：SPD 残压必须 ≤器件耐压的 80%
    线路侧 2kV 涌入、SPD 残压 700V → 母线电容与整流器件承受 700V ✓（耐压 1200V 的 58%）

  SPD 布置三原则：
    ① 尽可能靠近入口（引线电感每 1µH 在 1kA/µs 下产生 1000V 附加电压）→ 引线 ≤0.5m
    ② 分级：入口 SPD（大能量）+ 板级 TVS（低残压）
    ③ SPD 失效短路会引发火灾 → 必须带热脱扣与状态触点（纳入遥测，第41章）
```

### 45.5 代码：EMC 相关的"可观测项"

```c
/* ---------- emc.c：把 EMC 相关量做成可观测、可告警（EMC 无法靠软件修，但必须靠软件监视） ---------- */
#define EMC_FAN_SPD_FAULT   (1u<<0)     /* SPD 状态触点（45-4 ③） */
#define EMC_LEAK_ALARM_MA   3.0f         /* 漏电流告警阈值（限值 3.5mA 的 85%） */
#define EMC_GROUND_OHM_MAX  0.1f         /* 接地电阻限值（验收表 G 组） */

/* 1s 任务：EMC 相关监测（漏电流、接地、SPD、Y 电容健康） */
void task_emc_monitor(void)
{
    const float i_leak = leak_current_rms_ma();
    if (i_leak > EMC_LEAK_ALARM_MA) g_prot.fault |= PROT_F_LEAK;

    if (spd_status_contact() == 0u) g_prot.warn |= EMC_FAN_SPD_FAULT;   /* SPD 已动作/失效 */

    /* Y 电容老化/失效检测：正常时共模电流 RMS 有稳定范围，突变即告警 */
    const float i_cm = common_mode_current_rms_ma();
    if (i_cm > 1.5f * g_emc.cm_baseline || i_cm < 0.5f * g_emc.cm_baseline) {
        g_prot.warn |= PROT_F_CM_ANOMALY;                 /* 可能是 Y 电容或寄生电容变化 */
    }

    /* 接地电阻（可选测量通道）：>0.1Ω 告警（验收表 G 组） */
    if (ground_resistance_ohm() > EMC_GROUND_OHM_MAX) g_prot.warn |= PROT_F_GROUND;
}
```

### 45.7 失败案例复盘：漏电流超标 4.2mA，整改从"改软件"变成"改垫片"

> [!CAUTION]
> 现象：整机漏电流 4.2mA（限值 3.5mA），EMC 试验一次不通过。定位路径：①按 45-2 算共模位移电流（三相 5.7mA）→ ②确认主导项是器件对散热器的寄生电容（150pF/管）→ ③换低介电常数垫片并加厚（降到 80pF）→ ④漏电流 3.0mA ✓，同时传导发射在 150~500kHz 也改善 4dB（附带收益）。根因：漏电流指标由机械/结构与器件安装的寄生参数决定，软件无法改善；之前把"漏电流大"当成采样问题排查方向错了。预防措施：①漏电流预算在设计阶段就按 45-2 算清（含三相管数）；②垫片/绝缘材料选型进入 BOM 评审；③把"共模电流基线"纳入遥测（45-5），可发现 Y 电容老化；④EMC 整改必须先做"源-路径-受体"归因，再动手。
