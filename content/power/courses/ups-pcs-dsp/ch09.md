**本章要解决的问题：** 把现场的高压大电流变成 ADC 能吃的 0~3.3V 信号，并且**不引入无法标定的误差**。给出三个算例（Sallen-Key 正确算法与常见错误对照、软件滤波的相位代价、两点标定），配套标定与滤波的可编译代码，以及 PCB 五规则。

### 9.1 从现场到 ADC 的链路

```text
母线电压 700V ──[分压 R1/R2]──[缓冲运放]──[RC/Sallen-Key 抗混叠]──► ADC
相电流 ±150A ──[分流器/霍尔]──[隔离放大器]──[偏置到 1.65V]──[抗混叠]──► ADC
母线/散热器温度 ──[NTC 分压 + 低通]──────────────────────────────► ADC
```

| 环节 | 设计要点 | 典型陷阱 | 章 |
| --- | --- | --- | --- |
| 分压/衰减 | 留 10% 量程余量；算功耗与电阻温漂 | 余量为零，母线略高就削顶 | 5 |
| 隔离 | 隔离放大器 或 霍尔采样 | 隔离供电未做，共模干扰直接进 ADC | 9 |
| 抗混叠滤波 | 极点放 fsw/2 附近（相位代价见 5.4） | 用错公式把截止频率算高 41% | 9 |
| 偏置 | 双向电流偏到中点 1.65V | 偏置由分压得到 → 随电源波动漂移 | 5 |
| 标定 | 两点标定写入参数表（附录 B） | 只做零偏不做增益 → 残留 2% 误差 | 9 / 附录 B |

### 9.2 算例 9-1：Sallen-Key 截止频率的正确算法（附常见错误）

```text
单位增益 Sallen-Key 低通（R1、R2 串在信号路，C1 从中间节点到输出，C2 从同相端到地）：

  fc = 1 / (2π · √(R1·R2·C1·C2))
  Q  = √(R1·R2·C1·C2) / ( C2 · (R1 + R2) )

设计目标：fc ≈ 11.25kHz、Q = 0.707（巴特沃斯，无峰值）
取 R1 = R2 = 10kΩ、C2 = 1nF、C1 = 2nF：
  √(R1R2C1C2) = √(10e3 × 10e3 × 2e-9 × 1e-9) = √(2e-10) = 1.4142e-5
  fc = 1/(2π × 1.4142e-5) = 11,254 Hz ✓
  Q  = 1.4142e-5 / (1e-9 × 20e3) = 0.707 ✓        （C1 = 2·C2 恰好给出巴特沃斯）

【常见错误】直接套一阶公式 fc = 1/(2πRC)（取 R=10k、C=1nF）：
  fc' = 1/(2π × 10e3 × 1e-9) = 15,915 Hz
  误差 = 15,915 / 11,254 = 1.414 倍（正好差 √2）
  → 设计者以为"抗混叠到 15.9kHz 够用"，实际截止在 11.25kHz，
    18kHz 开关纹波衰减少、相位多 11°（见第5章 5.4），
    电流环会莫名少掉一截相位裕度
```

> [!IMPORTANT]
> 记法：只要 R1=R2、C1=C2，fc = 1/(2πRC) 恰好成立（此时 Q=0.5，不是巴特沃斯）；一旦为了 Q 而取 C1=2C2，fc 就变成 1/(2π·√(2)·RC) ——√2 这个因子就是本算例的错误来源。

### 9.3 算例 9-2：软件滤波不是免费的（相位代价）

```text
一阶低通差分实现（与模拟一阶等效）：
  连续：H(s) = 1/(1 + s/ωc)，  ωc = 2π·fc
  离散：a = Ts / (τ + Ts)，    τ = 1/ωc
        y[k] = y[k-1] + a·(x[k] − y[k-1])

取 fc = 2kHz、Ts = 55.6µs（18kHz）：
  τ = 1/(2π×2000) = 79.6 µs
  a = 55.6 / (79.6 + 55.6) = 0.411

在电流环带宽 1.8kHz 处的相位滞后：
  θ = atan(1.8 / 2.0) = 42.0°      ← 相当于吃掉大半的相位裕度预算
```

> [!WARNING]
> 结论：软件滤波和硬件滤波一样要记相位账。电流环反馈路径上不要随意加低通；需要抑制噪声时优先：①改善采样时刻对齐（第5章）→ ②加大 ACQPS/降低源阻抗 → ③过采样（仅遥测/保护）→ ④万不得已才在反馈路径加重滤波，并把相位代价写进裕度表。

### 9.4 算例 9-3：两点标定把 2% 误差压到 0.2%

```text
电流通道（0~100A，对应 ADC 码 2048~3412，与第5章算例 5-5 的 11mV/A 一致）：
  点 1：通 0A    → 读数 raw1 = 2048
  点 2：通 100A  → 读数 raw2 = 3412

  增益 k = (Y2 − Y1) / (raw2 − raw1) = (100 − 0) / (3412 − 2048) = 0.0733 A/LSB
  偏置 off = raw1 − Y1/k = 2048 − 0 = 2048

标定后残差来源（RSS）：线性度 ±0.1%、重复性 ±0.05%、参考电压漂移 ±0.1%
  → √(0.1² + 0.05² + 0.1²) ≈ 0.15%   （远优于未标定的 2%）
```

```c
/* ---------- param_table.h ---------- */
typedef struct { float k; float off; } cal_t;     // y = k·(raw − off)
#define CAL_IA_DEFAULT { 0.0733f, 2048.0f }       // A/LSB、LSB；第9章算例 9-3
#define CAL_IB_DEFAULT { 0.0733f, 2048.0f }
#define CAL_IC_DEFAULT { 0.0733f, 2048.0f }
#define CAL_VBUS_DEFAULT { 0.1954f, 0.0f }        // V/LSB：分压比 a=3.3/800（母线 800V↔ADC 满量程 4096 LSB）
                                                  // 设计值 k=(3.3/4096)/a=800/4096=0.1953；0.1954 为两点标定实测
                                                  // 校核：700V↔3582 LSB（ADC 引脚 2.89V，量程余量 12.5%，符合 9.1 规则 1）

/* ---------- adc.c ---------- */
static inline float adc_to_amp(uint16_t raw, const cal_t *c)
{
    return c->k * ((float)raw - c->off);           // 一次乘加，ISR 友好
}

/* 标定值从参数表加载（第3章 3.6 / 附录 B） */
void adc_load_cal(void)
{
    cal_t c;
    if (param_get(PARAM_CAL_IA, &c, sizeof(c)) != PARAM_OK) c = (cal_t)CAL_IA_DEFAULT;
    g_adc.cal_ia = c;                              // 加载失败回退出厂默认值
}
```

> [!TIP]
> 为什么标定必须"两点"：只测零点只能修偏置；增益误差来自电阻容差与运放增益（第5章算例 5-2 的 2%），必须用第二个已知点解出斜率。标定系数存 Flash 双备份（第3章 3.6），并纳入 CRC 校验。

### 9.5 软件一阶低通与"死区时间"式保护滤波

```text
/* 用于遥测量（温度、母线电压）的低通，不用于电流环反馈 */
float lpf1_step(float x, float *y, float a)
{
    *y += a * (x - *y);            // 等价 y = a·x + (1−a)·y，少一次乘法
    return *y;
}

/* 用于保护的"连续 N 次越限才动作"去抖（比低通更可控） */
#define OCP_N 3                      // 连续 3 拍越限才认定（3×55.6µs = 166.8µs）
uint8_t ocp_debounce(float i, float lim, uint8_t *cnt)
{
    if (i > lim) { if (++(*cnt) >= OCP_N) return 1; }
    else         { *cnt = 0; }
    return 0;
}
```

> [!IMPORTANT]
> 保护去抖优于低通：低通会延迟真实故障的判定并引入相位；"连续 N 拍认定"不改变幅值，只滤掉单拍尖峰，判定延迟 = N×Ts（本例 166.8µs），完全可控。第36章的保护矩阵统一用这种方式。

### 9.6 PCB 五规则（采样相关）

| # | 规则 | 违反后果 |
| --- | --- | --- |
| 1 | 分流器用 开尔文采样：取样线单独从焊盘内侧引出 | 引线压降进误差，且随温度变化 |
| 2 | 模拟地与数字地单点连接，模拟区远离功率回路 | 开关噪声直接进 ADC，读数抖动 |
| 3 | RC/Sallen-Key 就近 ADC 引脚放置 | 滤波形同虚设，噪声在走线上耦合 |
| 4 | 功率回路面积最小（叠层母排/紧贴布局） | 关断尖峰升高（第8章 8.6） |
| 5 | 差分采样走等长、成对布线；单端采样短线加地线包络 | 共模转差模，读数随负载变化 |

### 9.8 失败案例复盘：Sallen-Key 公式用错，抗混叠实际失效

> [!CAUTION]
> 现象：电流采样在高调制比工况下出现规律性抖动，Graph 上看到与开关频率同源的干扰。定位路径：①扫频测调理通道（实测 −3dB 在 11.2kHz，而设计文档写 15.9kHz）→ ②核对计算公式（发现取了 C1=2C2 却仍用 1/(2πRC)）→ ③按 9.2 的正确公式重算并调整 C1/C2 → ④抖动明显下降。根因：滤波器实际截止频率比设计值低 √2 倍，导致在电流环带宽附近多出 11° 相位滞后，同时 18kHz 纹波抑制也不符合预期。预防措施：①滤波器设计文档必须写"公式 + 元件值 + 计算过程"，不能只写结果；②扫频实测纳入 LAB 判据；③把该算例写进评审清单（本课程已将 Sallen-Key 错误算法列入 audit-v1 的历史缺陷）。
