**本章要解决的问题：** 把第10章的 Gvd(s) 变成一组能写进固件的数字。本章用第10章的 Buck 参数走完整条路：先证明"单电压环 + 纯积分"为什么被 Q=5.84 卡住（算例 11-1），再加电流内环把对象"降阶"（算例 11-2、11-3），最后处理积分饱和（算例 11-4），并给出可编译的双环代码。

### 11.1 三种基本 DC-DC 的模型对照

| 拓扑 | 直流增益 Gvd(0) | 极点 | 右半平面零点 | 控制难点 |
| --- | --- | --- | --- | --- |
| Buck | Vin | LC 双极点（Q 可很高） | 无（含 ESR 零点，左半平面） | 谐振峰，相位在 f0 附近骤降 |
| Boost | Vin/D′ | LC 双极点（Q 可很高） | 有，fRHPZ = D′²R/(2πL) | RHP 零点导致"增益涨、相位降"，带宽上限 |
| Buck-Boost/反激 | Vin·D/(1−D)² | RHP 零点 与双极点 | 有，且更低 | 带宽最受限，需按 fRHPZ/3 定交越 |

> [!IMPORTANT]
> 一条通用纪律：交越频率必须同时满足三条上限——①≤fsw/10；②谐振点时增益 <0dB（见算例 11-1 的规则）；③有 RHP 零点时 ≤fRHPZ/3。三条取最小。

### 11.2 设计流程（本章固定动作）

1. **需求**：输出电压/电流、动态指标（第0章 0.C 与 [验收指标表](/posts/power/courses/ups-pcs-dsp/docs/acceptance/)：瞬变 ≤±5%、恢复 ≤20ms）、开关频率与延迟。
2. **算对象**：由 SSA 得 Gvd(s)，记下直流增益、极点频率、Q、RHP 零点（第10章）。
3. **定拓扑结构**：单环 or 双环（本课程 DC-DC/PFC/逆变统一用双环）。
4. **定交越与零极点布局**：按 11.1 的三条上限取 fc；PI 零点取 fc/10；校验 PM/GM。
5. **换算成代码常量**：Kp、Ki·Ts（离散形式），写进 `param_table.h` 并注明来源。
6. **判据**：PM ≥45°、GM ≥6dB；阶跃响应超调与恢复时间达标。

### 11.3 算例 11-1：单电压环为什么被 Q 卡住（"不可能三角"）

```text
对象（第10章算例 10-1）：Vin = 48V，L = 4.7µH，C = 10µF，R = 4Ω，fsw = 200kHz（Ts = 5µs）
  f0 = 23.2kHz，Q = 5.84，直流增益 48（33.6dB）
  谐振点幅值 |Gvd(f0)| = 48 × Q = 280（48.9dB）

先按"教科书写法"取 fc = fsw/10 = 20kHz，用纯积分补偿器 Gc = Ki/s：
  |Gvd(20kHz)| = 48/|1 − (20/23.2)² + j(20/23.2)/5.84| = 48/0.2969 = 161.7
  需 |Gc(20kHz)| = 1/161.7 = 6.18e-3  →  Ki = 6.18e-3 × 2π × 20000 = 776.6 (1/s)
  在 f0 处 |Gc(f0)| = 776.6/(2π×23215) = 5.325e-3
  |G_ol(f0)| = 5.325e-3 × 280 = 1.49  →  +3.5 dB  ← 增益裕量为负，系统不稳定

推导规则（纯积分补偿器）：
  交越处 |Gc(fc)|·|Gvd(fc)| = 1 且 fc ≪ f0 时 |Gvd(fc)| ≈ Vin
  → |Gc(f)| ≈ 1/(Vin·f/fc)（积分器按 −20dB/dec 衰减）
  在 f0 处 |G_ol(f0)| = |Gc(f0)|·Vin·Q = (fc/f0)·Q
  要求 < 1 并留 6dB 余量 → fc < f0/(2Q) = 23215/(2×5.84) = 1,988 Hz

取 fc = 2kHz：
  |Gvd(2kHz)| = 48.38 → 需 |Gc(2k)| = 0.02067 → Ki = 0.02067×2π×2000 = 259.7 (1/s)
  离散：Ki·Ts = 259.7 × 5e-6 = 1.30e-3
  校验：|G_ol(f0)| = (259.7/(2π×23215))×280 = 0.4986 → −6.0 dB  → GM = 6.0 dB ✓
  相位：−90°(积分) − 0.85°(对象@2kHz) − 5.4°(延迟 1.5Ts) = −96.25° → PM = 83.8° ✓
```

> [!WARNING]
> 结论：单电压环纯积分能把 Q=5.84 压住，但代价是交越只有 fsw/100（2kHz），抗负载扰动慢。规则fc ≤ f0/(2Q)请记住——它说明"高 Q 谐振"与"高带宽"在单环里是互斥的。

### 11.4 算例 11-2：电流内环把对象降阶

```text
加电感电流内环后，内环对象（平均电流模式，电流环输出=占空比）近似为 1/(sL)。

设计步骤：
  ① 取 fc_i = fsw/20 = 10kHz（因 1.5Ts 延迟在此处已占 27°，见第10章算例 10-2）
  ② |1/(jωL)| @10kHz = 1/(2π×10000×4.7e-6) = 3.386 → 需 |Gc_i(10k)| = 0.2953
  ③ PI 零点取 fc/10 = 1kHz：|Gc_i(10k)| = Kp·√(1+(1/10)²) = 1.005·Kp
     → Kp_i = 0.2953/1.005 = 0.2938
  ④ Ki_i = Kp_i·2π×1000 = 1846 (1/s) → 离散 Ki·Ts = 1846×5e-6 = 9.23e-3
  ⑤ 校验相位：−90°(对象) − 5.71°(零点) − 27°(延迟) = −122.7° → PM = 57.3° ✓（GM 由 L 与延迟决定，≥10dB）
```

### 11.5 算例 11-3：电压外环（内环闭环近似为一阶）

```text
内环闭环等效：T_i(s) ≈ 1/(1 + s/ω_ci)，ω_ci = 2π×10kHz
外环对象 ≈ [1/(sC)] × T_i(s)

  ① 取 fc_v = 2kHz（远低于内环 10kHz，两者不打架）
  ② |1/(jωC)| @2kHz = 1/(2π×2000×10e-6) = 7.958 → 需 |Gc_v| = 0.12566
  ③ 零点取 200Hz：Kp_v = 0.12566/1.005 = 0.1250
  ④ Ki_v = 0.1250×2π×200 = 157.1 (1/s) → 离散 Ki·Ts = 157.1×5e-6 = 7.86e-4
  ⑤ 相位：−90°(电容) − 11.31°(内环@2k) − 5.4°(延迟) = −106.7° → PM = 73.3° ✓

对比算例 11-1：同样是 2kHz 交越，双环的 GM/PM 都更宽裕，
且负载扰动先被 10kHz 的电流内环吸收 —— 电压跌落更大程度被抑制。
```

| 指标 | 单电压环（11-1） | 双环（11-2 + 11-3） |
| --- | --- | --- |
| 电压环交越 | 2kHz | 2kHz（内环 10kHz） |
| PM / GM | 83.8° / 6.0dB | 73.3° / 内环 ≥10dB |
| 谐振点处理 | 靠把 fc 压到 f0/(2Q) | 被内环"包"在里面，外环看不到 |
| 负载扰动 | 直接冲击输出 | 先由内环吸走 |
| 成本 | 1 个采样 + 1 个 PI | 2 个采样 + 2 个 PI + 限幅逻辑 |

### 11.6 算例 11-4：积分饱和能让启动慢 100 倍

```text
启动瞬间：V_ref = 12V，V_out = 0V → 误差 e = 12V
  电压环积分器累积速率 = Ki_v · e = 157.1 × 12 = 1885 A/s
  电流指令限幅 I_max = 5A（保护电感与器件）
  → 若无抗饱和：积分器在 5/1885 = 2.65 ms 就冲到限幅，但会继续累积

设饱和持续 10ms（负载/母线建立时间）：
  超限量 = 1885 × 0.010 = 18.85 A（积分器内部值）
  退出饱和需要把多出的 18.85 − 5 = 13.85 A 消掉：
    若反向误差只有 0.2V，则需时间 t = 13.85/(157.1×0.2) = 0.441 s  ← 完全不可接受

对策（两种，都用代码实现）：
  ① 条件积分（clamping）：输出越限时冻结积分
  ② 反算（back-calculation）：把 (sat_out − out) 乘 1/Tt 反馈回积分器
  判据：启动到稳态的时间 ≤ 20ms（验收表 A 组"动态恢复 ≤20ms"）
```

### 11.7 双环 PI 代码（含抗饱和，可直接编译）

```c
/* ---------- param_table.h：常量来源全部标注（算法来自 11.4/11.5） ---------- */
#define DC_FSW_HZ       200000.0f      // Hz，开关频率（第10章算例 10-1）
#define DC_TS_S         (1.0f/DC_FSW_HZ)   // s，Ts = 5µs
#define DC_L_H          4.7e-6f        // H，电感（第10章算例 10-1）
#define DC_C_F          10e-6f         // F，电容（同上）
#define DC_VOUT_REF     12.0f          // V，输出设定
#define DC_ILIM_A       5.0f           // A，电流指令上限（保护矩阵，第36章）

/* 电流内环：fc_i = 10kHz，零点 1kHz（算例 11-2） */
#define DC_KI_KP        0.2938f        // V/A，Kp_i = 0.2938
#define DC_KI_KI_TS     9.23e-3f       // V/(A·拍)，Ki_i·Ts = 1846/200000
/* 电压外环：fc_v = 2kHz，零点 200Hz（算例 11-3） */
#define DC_KV_KP        0.1250f        // A/V，Kp_v
#define DC_KV_KI_TS     7.86e-4f       // A/(V·拍)，Ki_v·Ts = 157.1/200000

/* ---------- ctrl_pi.h ---------- */
typedef struct {
    float kp, ki_ts;        // 比例增益、积分增益（已乘 Ts）
    float out_min, out_max; // 输出限幅
    float integ;            // 积分器状态（无抗饱和时极易饱和，见算例 11-4）
    float out;              // 上一次输出（供 back-calculation 用）
    float kt;               // 反算系数 1/Tt
} ctrl_pi_t;

/* ---------- ctrl_pi.c ---------- */
float ctrl_pi_step(ctrl_pi_t *p, float err)
{
    /* ① 条件积分：用积分更新前的输出预估越限，且误差还在"往越限方向"推 → 冻结积分 */
    const float out_pre = p->kp * err + p->integ;
    const uint8_t sat_hi = (out_pre > p->out_max) && (err > 0.0f);
    const uint8_t sat_lo = (out_pre < p->out_min) && (err < 0.0f);
    if (!sat_hi && !sat_lo) {
        p->integ += p->ki_ts * err;
    }

    /* ② 输出限幅（未限幅输出必须在积分更新之后重算） */
    const float out_unsat = p->kp * err + p->integ;
    float out = out_unsat;
    if (out > p->out_max) out = p->out_max;
    if (out < p->out_min) out = p->out_min;

    /* ③ 反算（back-calculation）：integ += kt·(out − out_unsat)
       未饱和时两项相等、积分器不动 → 等效 Ki 增益不被 kt 污染，
       退饱和时间与算例 11-4 的手算一致；饱和时按 1/Tt 把超限部分退回积分器 */
    p->integ += p->kt * (out - out_unsat);

    p->out = out;
    return out;
}

void ctrl_pi_reset(ctrl_pi_t *p, float preload)   // 上下电/模式切换时调用（第34章）
{
    p->integ = preload;    p->out = preload;
}

/* ---------- dc_dc.c：ISR 里的调用顺序（第4章"五件事"） ---------- */
static ctrl_pi_t pi_i = { DC_KI_KP, DC_KI_KI_TS, -1.0f, 1.0f, 0.0f, 0.0f, 10.0f };  // 输出=占空比
static ctrl_pi_t pi_v = { DC_KV_KP, DC_KV_KI_TS, -DC_ILIM_A, DC_ILIM_A, 0.0f, 0.0f, 20.0f };

void dc_dc_isr(void)                     // 200kHz 控制中断，已在第4章预算内
{
    const float v_out = adc_to_volt(g_adc.raw_vout, &g_adc.cal_vout);   // 第9章 9.4
    const float i_l   = adc_to_amp (g_adc.raw_il,   &g_adc.cal_il);

    const float i_ref = ctrl_pi_step(&pi_v, DC_VOUT_REF - v_out);        // 外环：V → I 指令
    const float d_cmd = ctrl_pi_step(&pi_i, i_ref - i_l);               // 内环：I → 占空比

    pwm_set_duty(pwm_buck, d_cmd);       // 写入比较值（第3章）
    adc_clear_soc_flag();                // 清标志
    EPWM_clearTripFlag();                // 若有 TZ 触发
    Interrupt_clearACKGroup(ISR_DC_DC);  // 应答 PIE
}
```

> [!TIP]
> 代码纪律对照 v2.2：①常量全部来自算例，带单位与出处；②_isr结尾、只做第4章五件事，重活（如温漂自检、故障上报）放 1ms 慢任务；③PI 的结构体把限幅与抗饱和当成"补偿器的一部分"，而不是散落在业务代码里；④模式切换必须调用ctrl_pi_reset()预置积分器，否则首拍冲击（第34章）。

### 11.8 交错并联：把纹波"错"掉（多相 Buck / 交错 PFC 的通用技术）

交错并联是同一台设备内部把 N 个功率单元并联、但把 PWM 相位错开 360°/N 的技术。它的目的有三个：把器件电流与热摊到 N 个便宜器件上、用纹波抵消换取更小的滤波器、用等效 2N·fsw 的纹波频率换取更小的磁件与电容。它不提高开关频率，但改变纹波的频率与幅值分布。

```text
相位差 = 360°/N（两相 180°、三相 120°、四相 90°、六相 60°）
各相开关频率相同，只是导通时刻错开；输出端并联、输入端共享

交错到底能"错"掉多少纹波——两相交错的严格推导（Buck，D ≤ 0.5）：
  单相电感电流峰峰      ΔI_1 = D(1−D)·Vin·T/L
  两相之和（180°）      ΔI_2 = D·T·(1−2D)·Vin/L
  纹波之比 = ΔI_2/ΔI_1 = (1 − 2D)/(1 − D)

  代入数值（Vin=12V、Vo=3V、L=1µH、fsw=500kHz、单相 ΔI_1 = 4.5A）：
    D = 0.50 → 比值 0     （理论完全抵消，实测受相位抖动限制）
    D = 0.25 → 比值 0.667 → 3.0 A
    D = 0.20 → 比值 0.75  → 3.4 A
    D = 0.10 → 比值 0.889 → 4.0 A（几乎没抵消）
  推广到 N 相：**N·D 为整数时抵消最好**（两相 D=0.5、三相 D=1/3 或 2/3、四相 D=1/4/2/4/3/4）
  → 设计纪律：稳态占空比尽量落在 N·D = 整数附近，工程上取 0.3~0.7 区间内最靠近的那个点

  这就是"交错并联"最容易被误解的地方：它不是"相数越多纹波越小"，
  而是"相数 × 占空比"的配合问题。两相在 D=0.25 时只降 1/3，三相在 D=1/3 时几乎全消。
```

### 11.9 交错并联的三个工程要点（采样、投切、差流）

```text
① 相位配置：靠 ePWM 同步链，别靠软件延时
   主相 ePWM 输出 SYNCOUT → 从相 SYNCIN，从相用 TBPHS 设相位偏移
   软件延时产生的抖动会让交错"时好时坏"——现场表现为"纹波忽大忽小、EMI 测试重复性差"

② ADC 采样点必须避开所有相的开关时刻
   单相时采样点在载波峰/谷；N 相交错后，其他相正在开关（第5章 5-5 的对齐规则被破坏）
   做法（按代价排序）：
     a) 采样时刻表：把采样点放在"所有相都不动作"的时间窗内（N 越大窗口越窄）
     b) 每相各自在自己的窗口采样（需要多组 SOC 与缓冲，代价是 RAM 与 ISR 时间）
     c) 用高带宽电流传感器 + 数字平均（补救手段，相位对齐仍要做）
   判据：采样时刻与最近一次开关沿的间隔 ≥ 1µs（避开振铃），否则电流反馈里会混入开关噪声

③ 差流与投切（这部分与第38章的模块并联不同，别混）
   总流 i_Σ = i_1 + i_2（供给负载），差流 i_Δ = (i_1 − i_2)/2（在两相之间循环）
   差流回路的"电源"是两相之间的电压差（相位抖动、占空比差异、器件压差）
     ΔV = 5V 时、回路阻抗 0.05Ω → i_Δ = 100A（夸张吗？不夸张——这就是为什么相位抖动不能靠软件补）
   抑制手段：
     a) 载波相位由硬件同步（上面①）
     b) 每相电流独立采样 + 相间均流环（可以理解为"每相对自己的电流负责"）
     c) 耦合电感：把两相绕在同一磁芯上（反相耦合），差流看到的电感变大 → 自然抑制
        例：L_self = 10µH、耦合系数 k = 0.8 → 差流看到的等效电感 = L(1+k) = 18µH（差流纹波降到 56%）
   轻载相数投切（phase shedding，第39章效率优化的手段）：
     负载 < 30% 时关掉 1~N−1 相 → 剩余相回到高效率区；投切顺序必须"先加相再减相"，
     且投切瞬间的电流重新分配要在 ≤2ms 内完成（否则输出跌落）
```

> [!CAUTION]
> 失败案例复盘（交错相位丢失）：四相 Buck 纹波"忽大忽小"，电流波形一会儿整齐一会儿紊乱。查了两天布局无果，最终定位到相移寄存器TBPHS只在初始化时写过一次，而跳周期/突发模式会把相位寄存器复位——相位漂移后交错失效。处理：把交错相位当作"运行期状态"管理，在每相投切、模式切换、故障恢复后重新写入并读回校验。

**交错并联与模块并联的分工（别混）：** 交错（本节）是*同一台设备内部*的多个功率单元错相工作，解决的是"纹波、器件电流、热"；模块并联（第38章）是*多台设备*之间的均流与环流，解决的是"容量与冗余"。两者的数学工具也不同：交错看**差流 iΔ**（不含负载的那部分），并机看** 环流度**（相对额定电流的比值）。

### 11.10 交错并联的代码：相位配置、差流监视、相数投切

```c
/* ---------- interleave.c：N 相交错的相位管理（以 DC-DC 电池侧 4 相为例） ---------- */
#define IL_N            4u           /* 相数（11-8：稳态 D 要与 N 配合选） */
#define IL_PHASE_TICKS  (TBPRD/IL_N) /* 每相相位偏移（增减计数，TBPRD = 1667 → 417） */
#define IL_IDIFF_LIM_A  8.0f         /* 差流告警阈值（10% 额定相电流） */
#define IL_SHED_LOAD    0.30f        /* 相数投切阈值（30% 负载） */
#define IL_REDIST_MS    2u           /* 投切后电流重分配允许时间 */

/* 上电与每次投切后都必须重写相位（现场坑，见 11-9 的复盘） */
void interleave_set_phase(void)
{
    for (uint8_t k = 0; k < IL_N; k++) {
        epwm_set_phase(pwm_dc, k, (uint16_t)(k * IL_PHASE_TICKS));   /* TBPHS */
        epwm_set_sync_chain(pwm_dc, k);                              /* SYNCOUT → 下一相 SYNCIN */
    }
    EPWM_syncAllSyncIn(pwm_dc);                                      /* 强制一次同步 */
    for (uint8_t k = 0; k < IL_N; k++) {                             /* 读回校验 */
        if (epwm_get_phase(pwm_dc, k) != (uint16_t)(k * IL_PHASE_TICKS)) {
            g_prot.fault |= PROT_F_IL_PHASE;                         /* 相位没写进去 */
        }
    }
}

/* 10ms 任务：相间均流 + 差流监视 + 相数投切 */
void task_interleave(void)
{
    float i_ph[IL_N], i_sum = 0.0f, i_max = 0.0f, i_min = 1e9f;
    for (uint8_t k = 0; k < IL_N; k++) {
        i_ph[k] = dc_phase_current_a(k);
        i_sum += i_ph[k];
        if (i_ph[k] > i_max) i_max = i_ph[k];
        if (i_ph[k] < i_min) i_min = i_ph[k];
    }
    const float i_avg = i_sum / (float)IL_N;
    const float i_diff = 0.5f * (i_max - i_min);          /* 差流（最坏两相之差的一半） */

    if (i_diff > IL_IDIFF_LIM_A * (i_avg / (i_avg + 1.0f))) {   /* 差流随负载缩放，避免轻载误报 */
        g_prot.warn |= PROT_W_IL_DIFF;
        interleave_set_phase();                            /* 相位漂了就重写（最常见的原因） */
    }

    /* 相间均流：把偏差折算成该相占空比微调（±2%，避免影响总输出） */
    for (uint8_t k = 0; k < IL_N; k++) {
        const float d = clampf(0.02f * (i_avg - i_ph[k]) / (i_avg + 1.0f), -0.02f, 0.02f);
        dc_phase_duty_trim(k, d);
    }

    /* 相数投切（第39章 phase shedding）：先加相后减相，投切后重分配时间有上限 */
    const float load = i_avg / DC_PHASE_RATED_A;
    if (load < IL_SHED_LOAD && dc_phase_active_count() > 1u) {
        dc_phase_disable(dc_phase_pick_worst());            /* 关掉效率最差的一相 */
        interleave_set_phase();                             /* 相数变了，相位角也要重算 */
        g_il.redist_deadline_ms = g_ms_tick + IL_REDIST_MS;
    } else if (load > 0.45f && dc_phase_active_count() < IL_N) {
        dc_phase_enable(dc_phase_pick_idle());              /* 先加相 */
        interleave_set_phase();
        g_il.redist_deadline_ms = g_ms_tick + IL_REDIST_MS;
    }
    if (g_il.redist_deadline_ms != 0u && g_ms_tick > g_il.redist_deadline_ms) {
        g_il.redist_deadline_ms = 0u;
        if (i_diff > 2.0f * IL_IDIFF_LIM_A) g_prot.fault |= PROT_F_IL_REDIST;   /* 重分配超时 */
    }
}
```

### 11.12 失败案例复盘：没有抗饱和，甩载时母线被顶飞

> [!CAUTION]
> 现象：满载切到 10% 负载时，输出电压上冲到 14.5V（+21%），远超 ±5% 要求，约 0.4s 后才恢复。定位路径：①记录电压环输出（长时间贴在限幅值 +5A）→ ②确认内环本身没问题（电流快速跟随）→ ③检查积分器（发现饱和期间仍在累积）→ ④对照算例 11-4 计算退饱和时间 0.44s，与实测吻合 → ⑤加条件积分 + 反算后，恢复到 12ms。根因：限幅只加在输出端，积分器状态不受限；一旦负载突变，超出的积分量需要极长时间才能消退。预防措施：①所有 PI 必须带条件积分或反算（本课程统一封装）；②限幅值必须来自保护矩阵并写进参数表；③上机核对必须包含"启动"与"甩载"两个方向；④整定评审时必须手算一次"退饱和时间"（0.44s 这种量级是肉眼可见的故障，不能只靠试）。
