**本章要解决的问题：**UPS 的"后备时间显示准不准"直接决定客户能不能安心停电检修。三个算例：安时积分 + OCV 修正、内阻法估 SOH、以及温度对可用容量的影响。

> [!TIP]
> 术语提示：SOC 在第5章指 ADC 的 Start-of-Conversion（转换启动），本章指荷电状态（State of Charge）。

### 42.1 三种方法的适用与互补

| 方法 | 原理 | 精度 | 局限 |
| --- | --- | --- | --- |
| 安时积分（库仑计数） | SOC = SOC0 + ∫i dt/(C·η)（i 充电为正） | ±3%（短期） | 长期漂移（电流偏置累积） |
| OCV 查表 | 静置后开路电压 → SOC 表 | ±5% | 需静置 ≥2h；不适合在线 |
| 内阻法（SOH） | R = ΔV/ΔI，随老化上升 | SOH ±5% | 受温度与 SOC 影响 |
| 融合（本课程推荐） | 安时积分 + 静置时 OCV 重置 + EKF | ±2% | 算力与标定工作量 |

### 42.2 算例 42-1：安时积分的漂移与修正

```text
电池组：384V/100Ah（38.4 kWh），放电电流 139A（第0章跨章一致值）
 采样电流偏置误差 0.147A（第28章 2 LSB 口径）：
 放电 1h 的累积误差 = 0.147×3600 = 529 As = 0.147 Ah = 0.147% 容量
 连续放电 4h → 0.59% 容量误差 → 对应后台时间显示偏差 ≈ 1.4 min（按 100Ah/139A = 43min 折算）
 → 单次放电内可接受；但若长期不修正，每次充放电循环都累积 → 每月可漂移数十 %

修正策略（三条一起）：
 ① 每次充满后重置 SOC = 100%（充电终止判据：电流 < 0.02C 且电压达均充值）
 ② 每 30 天静置 ≥2h 时用 OCV 校正（修正系数限幅 ±5%）
 ③ 电流通道零点每次上电自动校零（充电机断开时采 100 拍平均）
 判据：SOC 显示误差 ≤±3%（对实际放电试验）
```

### 42.3 算例 42-2：SOH 估算（内阻法）与"该换电池了"

```text
新电池内阻（384V/100Ah 铅酸或磷酸铁锂，按 100Ah 单体串并折算）：R0 ≈ 25 mΩ
 判据（统一映射：SOH = R0/R_now × 100%，与 42.5 代码一致）：
 例：内阻升至 1.2 倍（30 mΩ）→ SOH = 25/30 ≈ 83%；升至 1.5 倍（37.5 mΩ）→ SOH = 25/37.5 ≈ 67%
 阈值：SOH <80%（内阻 >31.25 mΩ）→ 报警；SOH ≈67%（内阻 1.5 倍）→ 建议更换

 测量方法（在线，不打断供电）：在"电池放电切换"瞬间测：
 ΔV/ΔI = (V1 − V2)/(I2 − I1)，取 20 次平均
 置信度：ΔI 需 ≥0.3C（30A），否则噪声主导：ΔI = 30A、R = 25 mΩ → ΔV = 0.75V 可测
 温度修正（内阻随温度变化）：R(25℃) = R(T)·[1 + α(T − 25)]，α ≈ −0.02/℃（低温内阻升高）

 容量核对（更直接的方法，与内阻法 SOH 互相印证）：做一次"后备时间试验"（annual test）
 实测放电电流 139A、到终止电压用时 T 分钟 → 实际容量 = 139×T/60 Ah
 容量比 = 实际容量/标称 100Ah，应与 SOH = R0/R_now 大体一致（偏差 >10% 时以实测容量为准）

 MTBF/寿命口径（验收表：模块 ≥5×10⁵h）不包含电池 → 电池寿命单独管
```

### 42.4 算例 42-3：温度对可用容量的影响与 SOC 限值

```text
磷酸铁锂在 0℃ 可用容量约 80%、−10℃ 约 65%、40℃ 约 100%（但循环寿命下降）
 设计温度范围 0~40℃（机房）→ 后备时间必须在"最坏温度"下校核：
 设计目标 30min（按 25℃）→ 在 0℃ 下变成 24min 
 → 两条路：①容量按"最坏温度 + 老化（SOH 80%，对应内阻升至 1.25 倍）"选型：
 需要容量 = 需求容量/(0.8×0.8) = 需求/0.64
 （0.8 温度折减 × 0.8 SOH）→ 30min 目标需选 47min 的容量
 ②低温时降额运行（限制放电电流）→ 延长放电时间至目标值

 判据：在 0℃ 与 SOH = 80% 的"最坏组合"下，实测后备时间 ≥ 标称值 ×0.9
```

### 42.5 代码：SOC/SOH 估算

```c
/* ---------- battery.c ---------- */
#define BATT_CAP_AH      100.0f       /* Ah，标称容量 */
#define BATT_C_RATE_MAX  0.2f         /* 最大充电电流 0.2C */
#define BATT_SOC_OCV_MIN 5.0f         /* OCV 校正幅度限幅（%） */
#define BATT_R0_MOHM     25.0f        /* 新电池内阻（42-3） */
#define BATT_T_ALPHA     (-0.02f)     /* 内阻温度系数（1/℃） */

static float g_soc = 100.0f, g_soh = 100.0f, g_r_now = BATT_R0_MOHM;

/* 安时积分（每 10ms 调一次；i 充电为正） */
void batt_coulomb_step(float i_a, float temp_c)
{
 static float drift_buf = 0.0f;
 const float dt_h = 0.010f / 3600.0f;
 float i_eff = i_a;
 if (i_a > 0.0f) i_eff = i_a / 0.98f; /* 充电效率 98% */
 g_soc += i_eff * dt_h / BATT_CAP_AH * 100.0f; /* i_eff 充电为正、放电为负 → 充电时 SOC 上升 */
 g_soc = clampf(g_soc, 0.0f, 100.0f);

 /* 温度对可用容量的修正（42-4）：仅用于"后备时间"显示，不改变 SOC 定义 */
 g_temp_factor = 1.0f;
 if (temp_c < 0.0f) g_temp_factor = 0.80f;
 else if (temp_c < 25.0f) g_temp_factor = 0.90f;
}

/* 充满判据 → 重置 SOC（42-2 ①） */
void batt_check_full(float i_a, float v_batt)
{
 if (i_a < 0.02f*BATT_CAP_AH && v_batt > batt_equalize_voltage()) {
 g_soc = 100.0f; g_full_cnt++;
 }
}

/* 静置 OCV 校正（42-2 ②）：仅在"长期静置 + 无充放电"时使用 */
void batt_ocv_correct(float v_ocv)
{
 if (!batt_idle_over_2h()) return;
 const float soc_ocv = soc_from_ocv_table(v_ocv, batt_temp_c());
 float delta = soc_ocv - g_soc;
 delta = clampf(delta, -BATT_SOC_OCV_MIN, BATT_SOC_OCV_MIN);
 g_soc += delta; /* 限幅修正，避免被坏数据带偏 */
}

/* 内阻法 SOH（42-3）：在放电切换瞬间采样，20 次平均 */
void batt_soh_update(float dv, float di, float temp_c)
{
 if (fabsf(di) < 30.0f) return; /* ΔI 不足则不更新 */
 const float r_meas = fabsf(dv/di) * 1000.0f; /* mΩ */
 const float r_25 = r_meas / (1.0f + BATT_T_ALPHA*(temp_c - 25.0f));
 g_r_now = 0.9f*g_r_now + 0.1f*r_25; /* 一阶平滑 */
 g_soh = 100.0f * BATT_R0_MOHM / g_r_now; /* SOH = R0/R_now×100%：1.2 倍→83%、1.5 倍→67%（42-3） */
 g_soh = clampf(g_soh, 0.0f, 110.0f);
}
```

### 42.6 上机核对（LAB5）

| 步骤 | 该看到什么 | 判据 |
| --- | --- | --- |
| SOC 对比（放电试验） | 显示 SOC 与实际放电量 | 误差 ≤±3%（42-2） |
| 长时间浮充后 | 充电时 SOC 上升、浮充时 SOC 稳定 | 充满重置后 = 100%、无漂移 |
| 内阻测量 | 放电切换瞬间 ΔV/ΔI | 与实验室测值偏差 ≤10% |
| 温度折减显示 | 0℃ 下后备时间估算 | ≥ 标称 ×0.9（42-4） |
| 电池老化模拟 | 串入 20 mΩ 模拟老化 | R = 25+20 = 45 mΩ → SOH = 25/45 ≈ 56%（<80% 报警） |

### 42.7 失败案例复盘：SOC 长期漂移，停电时后备时间只有标称的一半

> [!CAUTION]
> 现象：客户按 SOC 显示 85% 时停电，实际 12 分钟就报电池欠压（标称 30min）。定位路径：①做放电试验（实际容量只有 55Ah，SOH ≈ 55%）→ ②查代码（既没做"充满重置"，也没做 OCV 校正，SOC 长期只靠安时积分）→ ③现场数据（每天充放电 1 次，累积漂移 + 无 SOH 监控）→ ④加充满重置 + OCV 校正 + SOH 监控后，显示与实测吻合。根因：纯安时积分必然漂移；且没有 SOH 监控，客户完全不知道电池已经老化。预防措施：①SOC 必须"充满重置 + 静置校正"双修正；②SOH 必须在线估算并进入告警（<80% 报警，内阻升至 1.5 倍即 SOH ≈67% 建议更换）；③后备时间显示必须按"最坏温度 + 当前 SOH"折算（42-4）；④每年做一次放电试验并记录（附录 B）。
