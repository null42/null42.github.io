## 📐 课程设计理念

本页面阐述《UPS与PCS数字控制：DSP算法从入门到精通》的核心设计哲学、教学架构决策与工程落地导向。所有章节编排、内容深度、代码风格均源于此处的第一性原则。

---

## 一、 核心定位：**工程师的第一手手册**

不是教科书的补充，而是让工程师"拿来即用、遇事可查、推导可验"的实战参考。

| 维度 | 传统教材 | 本课程 |
| --- | --- | --- |
| 读者画像 | 学生/科研 | 量产项目工程师、转行嵌入式开发 |
| 起点 | 小信号建模、控制理论 | 第0章：欧姆定律→三相功率→符号表（零门槛） |
| 建模深度 | 公式推导为主 | SSA五步法→数值扰动→大信号→阻抗法，全链路可追溯 |
| 离散化 | 双线性变换一句带过 | 三种方法对照表+预畸变纪律+量化验证清单 |
| 代码落地 | 伪代码/片段 | 寄存器级ISR、float+TMU、CLA分工、Graph环形缓冲调试 |
| 调试视角 | 理论裕度 | 示波器波形图谱、死区谐波预算、死机排查口诀 |
| 质量门槛 | 无/主观 | 七维度门槛制（D1-D7）+ 强制自动化校验（V1-V4） |

## 二、 三大设计支柱

### 1. 认知负荷最小化——先用后学，分层展开

- **第0章**：30分钟补齐电学/数学/工具底子，建立全书符号表与口径对照
- **先用后学牌**：第14章用dq→第29章才系统讲解，但第14章显式标注"见第29章深度解析"
- **概念复现间隔**：关键概念（如Q值、PLL、死区）全书≥3次间隔重复
- **动手收口点**：连续理论章≤3章，必有LAB/验收清单/仿真脚本闭环

### 2. 工程可追溯性——每个数字都有出处，每行代码可验证

- **建模追溯总表**（第10.9节）：拓扑→建模章→环路章→整定例，一张表全链路可查
- **参数标度链**：从物理参数→标幺值→IQ格式→寄存器值，全程量纲可核
- **勘误公开透明**：audit-v1.html 记录4类实质性错误修正过程
- **引用可双向循迹**：正文[Ref: P5] → [references.html](/posts/power/courses/ups-pcs-dsp/docs/references/) 锚点，交叉引用零断链

### 3. 量产级鲁棒性——把坑踩在文档里，不留给现场

#### 典型"坑"已在文档显式标注

| 坑类型 | 文档位置 | 对策 |
| --- | --- | --- |
| 平台口径变更：F28035 → F28075 | 第2.2节选型附表 + audit-v1 | 原版照抄网传的 F28035 外设数量（8 个 ePWM 等）已作废；本版按《F2807x datasheet (Rev. K)》列出真实配置：24 ePWM 通道 @176-PTP、3×12bit ADC、最多 8×CMPSS |
| Buck谐振峰分贝换算错(8.7dB→4.4倍) | 第10章/LAB1 + audit-v1 | 公式推导+MATLAB验证，强制预畸变 |
| SCR误算4.7→94 | 第14章+audit-v1 F2 | 公式S_sc/P_n手算复核，弱电网灵敏度表量化 |
| 死区百分比基准不统一 | 第13/23/28章+audit-v1 F3 | 统一按311V峰值：1.33%/0.80%/0.57% |
| AQCSFRC强制电平编码反了 | 第36章+E.1核验记录 | TI E2E论坛核实：0x0005=强制低，代码已修正 |
| 仿真无延迟→带宽虚高 | 第10.4节+LAB全系列 | 强制ZOH+1.5Ts延迟，c2d后margin自动含延迟 |

### 关键顺序原则

- **先单相后三相**：单相全桥(Ch13)建立PR/死区/谐波认知 → 三相LCL(Ch14)复用认知仅加dq解耦
- **先稳态后暂态**：小信号建模(Ch10) → 大信号/软启动/模式切换/整机状态机(Ch33-35)
- **先稳态后谐波**：基波环路稳定(Ch13-14) → 谐波提取/补偿(Ch23-28)
- **先整流后逆变**：PFC(Ch12)建立电流环认知 → 逆变(Ch13)复用仅换调制波

## 四、 代码与工程规范

#### F28075 浮点与 CLA 规范

- 主控 TMS320F28075：120MHz C28x + FPU + TMU，默认全程 float，不再手写定点；sinf/cosf/atan2f/sqrtf 由 TMU 硬件加速
- IQmath 定点仅在移植旧代码或极限省周期时使用（默认 IQ24），且积分器必须饱和限幅，增量式 PI 最稳
- CLA 与主核并行跑确定性子任务（单相 PLL/SOGI、保护扫描、采样预处理），主核只做环路与状态机；共享变量用 volatile + 双缓冲交接，避免读写撕裂

#### ISR 纪律

- ISR 只干：采样→保护扫描→控制算法→PWM更新→PIEACK
- 除法/三角函数/printf/大循环 **严禁进 ISR**，丢 1ms 任务队列
- 共享变量 **必须 volatile**，Graph环形缓冲观测波形

#### 工程模板结构

```c
ups_ctrl/
├── source/
│ ├── main.c // 初始化序列 + 主循环(低优先级)
│ ├── isr.c // 控制中断：电流环/电压环/PWM更新
│ ├── task.c // 1ms/10ms 慢速任务队列
│ ├── protect.c // 保护状态机 + 故障日志(黑匣子)
│ └── comm.c // Modbus/CAN 协议栈
├── include/
│ ├── param_table.h // 所有可调参数集中定义(+CRC)
│ └── global.h // 共享变量(注意 volatile)
└── cmd/
 ├── ram_lnk.cmd // RAM 调试
 └── flash_lnk.cmd // Flash 烧录
```
