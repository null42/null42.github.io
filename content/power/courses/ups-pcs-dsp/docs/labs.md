## 实验指导书 LAB0~LAB5：把纸面算例变成波形

配套 `sim/` 目录下的 MATLAB 脚本（脚本清单与状态见 `sim/index.html`，当前为待补）。总纪律（第0章/第3章）：仿真必含 ZOH+一拍延迟；硬件只上低压台架；每完成一 lab 归档"波形+参数版本"。

### LAB0 环境与安全（0.5 天）

1. 安装 MATLAB + Control System Toolbox；运行 `sim/lab1_buck_freqresp.m`（脚本待补，状态见 sim/index.html；补齐前可用第0章 0.C 手算流程替代），确认打印 fn≈23.2kHz。
2. 硬件台架清单：**TMS320F28075** 目标板（在用逆变侧 28075 板卡 / F2807x controlCARD；低价平替 F280049C LaunchPad，但外设数量差异须按第2章附表核对）、24V→12V 降压评估板(≤3A)、限流直流电源、双通道示波器+高压差分探头(后期)、电子负载。
3. 安全三句：限流起步；测功率级用隔离通道；断电验放后才能接线。

> [!WARNING]
> 判据：lab1 两张 Bode 图能口头解释"峰在哪、延迟改了什么"，才允许进入 LAB2。进阶（大信号首练）：改用开关级模型跑一次带限流的软启动斜坡，对照第35章预充电流公式——这就是"大信号模型"的第一次实操。

### LAB1 Buck 对象辨识与 SSA 验证（1 天｜对应第10章）

1. 按教材 10.2 五步手算 Gvd/Gid，列出 fn/Q。
2. 运行 lab1 脚本，核对打印值与手算一致（±1%）。
3. Simulink 进阶：搭开关级模型（MOSFET+二极管），在占空比上注入 1% 正弦，用脚本"单频相关解调"扫 200Hz~20kHz，把实测点叠到解析 Bode 上。
4. **验收问答**：高频段实测低于解析曲线的原因？（答：未计入的 ESR 零点方向相反——ESR 使幅频抬升；若实测更低，查是否漏了死区伏秒损失。）

### LAB2 第一个闭环：Buck 电压环 PI（2 天｜第11/17章）

1. 运行 `lab2_buck_pi.m`（待补）：按**第11章算例 11-2 / 11-3** 复现双环整定——电流内环 fci=10kHz / PM 57.3°（Kpi=0.2938、Ki·Ts=9.23e-3），电压外环 fcv=2kHz / PM 73.3°（Kpv=0.1250、Ki·Ts=7.86e-4）；输出含延迟的 PM/GM 与 3A 负载阶跃跌落；并复现** 算例 11-4** 的退饱和时间（无抗饱和 0.44s vs 有抗饱和 ≤20ms）。同时做对照实验：单电压环纯积分时 fc 上限只能取 f0/(2Q)=2kHz（算例 11-1）。
2. 把 Kp 手动 ±50%，记录 PM 与阶跃跌落的变化趋势表（至少 5 组）。
3. 硬件迁移：F28075 目标板 + 功率板，母线 12V，闭环带 1A 负载；用 Graph 抓阶跃。

| 项目 | 仿真预期 | 硬件合格线 |
| --- | --- | --- |
| PM | 45°~70°（设计判据 ≥45°） | 扫频复核 ≥40°（硬件口径，两值有意不同） |
| 3A 阶跃跌落 | 脚本打印值 ±20% | <5%×Vout |
| 恢复时间 | <1ms | <2ms |

> [!TIP]
> 常见坑：传感标度忘折算（Kp 差 3 倍量级先查这里）；Ki 含 Ts 与否口径混用；Graph 缓冲区没开实时模式。

### LAB3 单相逆变 PR 双环（3 天｜第13章，本课重头戏）

1. 运行 `lab3_inv_pr.m`（待补）：按**第13章算例** 复现——内环 Kpi=0.02356 → fci=1kHz / PM 56.3°；有源阻尼 Kd=0.02165 → 空载 Q 从 41 降到 0.707（算例 13-3）；外环 PR（Kpv=0.0314、Krv=0.6、ωc=31.4）→ 50Hz 环路增益 200.9、基波误差 0.5%（算例 13-4）；3/5/7 次谐振器（Kr=0.05/0.03/0.02、ωc=1Hz）把死区谐波 RSS 从 1.65% 压到 0.360%，**同时** 交出 −5.6° 的交越相位代价（最终 PM 46.4°，算例 13-5）。这是"谐振器在谐波频率处堆增益"机制的程序化证据。
2. 看 Zout 图：闭环红曲线在 50Hz 的深谷 vs 开环蓝线；解释为什么空载 THDu 反而可能更差（谷外频率仅被 Kpv 通路压制）。
3. 加非线性负载仿真：桥式整流+RL+C 负载，记录 THDu 基线 → 投入负载前馈 → 再投 5/7 次 PR（按 26 章设计例）→ 最后投 RC（27 章参数）。每步存图，体验八步案例的前五步。
4. 硬件迁移（可选，母线 60V 低压版逆变器）：重复步骤 3 的前两步。

### LAB4 SOGI + 单相 PLL（1 天｜第24/29章）

1. 运行 `lab4_sogi_pll.m`（待补；补齐前可先用交互仿真·dq与SOGI 模块在浏览器观察正交构造与 2ω 纹波）：确认正交输出 Lissajous 为圆、末段频率均值偏差 <0.02Hz。
2. 修改激励加入 100Hz 幅值调制（模拟不平衡单相场景），观察 vq 纹波频率应为 2×工频。
3. 把 SOGI 的 ω 改成阶跃突变（模拟不守纪律的自适应），复现"振铃"，再改成斜坡更新对比——亲眼看一遍第24章两条纪律的意义。

### LAB5 保护时序与黑匣子（半实物，2 天｜第36章）

1. F28075 目标板：配置 **CMPSS→X-BAR→ePWM TZ** 链路，用 CMPSS 内置 DAC（阈值可在线改写）设限；示波器测"电流越限→PWM 消失"延迟，目标 <1 µs 且** 不经软件**。
2. 软件路径对照：写 AQCSFRC=0x0005 强制低，验证与 TZ 行为差异（影子装载时机）。
3. 实现故障环形缓冲（时间戳4B+码1B+值2B+状态2B+CRC1B），人为触发三次 OCP，读出日志核对顺序。
4. I²t 反时限：注入 110% 电流验证 60s 动作点（加速时钟 ×60 做快速测试）。

> [!WARNING]
> 交付物归档模板（每个 LAB 一份）：目的｜参数版本号｜关键波形截图｜margin 或判据数值｜异常与解释｜下一步。半年后回看，这些档案就是你的私人教科书。
