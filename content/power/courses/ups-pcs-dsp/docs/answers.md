### 第0章

**0-A** 五问：①220V 是有效值，峰值 = √2×220 ≈ 311V，母线必须高于峰值才留得出调制裕量；②PF=0.8 表示视在功率里约 20% 是来回搬运、不做功的无功，电网容量被占用；③LC 在 ω_r = 1/√(LC) 处谐振（串联阻抗最小 / 并联阻抗最大）；④三相四线制只在负载不对称或含 3 次及倍数谐波时 N 线才有电流；⑤Buck 用 50% 占空比把 24V 切成平均 12V 的脉冲，再经 LC 滤波得到 12V。

**0-B** 数学自检：五条清单能口述"电源语境版"即过；卡住的那条先花半小时补，不必整学期重修控制理论（00.html 0.1）。

**0-C** 两套调制增益：单相全桥 Kpwm = Vdc（第13章）；三相桥 Kmod = Vdc/2（第14/25章）。差 2 倍是调制定义不同，套公式前先确认口径（00.html 0.3）。

### 第1章

**E1** 正常：市电→EMI→PFC→母线→逆变→LC→负载，同时母线经双向DC/DC以浮充电压给电池小电流充电。断电：PFC 输入侧失能，电池→Boost/DAB 升压接管母线（电压被闭环维持在原值），逆变与输出侧完全无感——这就是"双变换在线"的字面意义。

**E2** 在线式：连续正弦无缺口（逆变一直在跑）；后备式：出现 2~10ms 的平台/零区并伴随相位跳变，之后恢复。用单次触发抓下降沿即可对比。

**E3** 任答三：准PR谐振控制、重复控制全谱抑制、HRPWM 皮秒移相、数字锁相环、反时限保护曲线、黑匣子日志、多机下垂均流。

### 第2章

**E1** 55.6 µs×120MHz=6,667 周期；占用率 2200/13,333≈16.5%——处于健康区间（判据：留给故障路径与中断抖动的余量 ≥50%）。

**E2** 回绕成大负数；对策：①累加前 _IQsat 饱和 ②降格式到 IQ16/IQ20 ③把积分器拆为"主限幅+增量小步"结构。

**E3** 两电平三相桥=3 个模块（每模块 A/B 一对互补）。NPC 若采用"外侧管互补对+钳位管联动"的门极逻辑可仍用 3 模块外接逻辑，独立四管控制则需 6 模块——先查 TRM 再定架构。

### 第3章

**E1** 无 volatile 时编译器可能把共享变量缓存进寄存器、或跨访问重排序优化，主循环永远读到旧值。

**E2** 上电→ADC 短接测零漂(存offset)→单路PWM示波器验极性→强制 TZ 验证封锁路径→读回自检结果写日志，任一项失败进安全态。

**E3** 探头地线环路感应(换短弹簧复测)、采样点落在开关沿(改SOC相位)、量化/混叠(降带宽看是否消失)。

### 第4章

**E1** 一次性应答所有组：正在挂起的其他组中断被错误放行/丢失配对，破坏嵌套语义；正确做法只 ACK 本组。

**E2** 状态{释放,消抖,按下计时,长按已触发}；1ms 节拍计数，释放沿判时长：<300ms 短击、≥1s 长按触发一次并锁存至释放。

**E3** 平均 800cy=6.7 µs 安全；最坏 2600cy=21.7 µs，占控制中断周期 111.1 µs（9kHz 双拍，13333 计数）的 19.5%（若按 18kHz 载波周期 6667 计数口径则约 39%——引用时注明分母口径），余量充裕；但抖动会污染采样时刻一致性，仍需拆分任务或提优先级保障。

### 第5章

**E1** τ=R_s·C_hold=10k×5pF=50ns；到 0.1% 需 ln1000≈6.9τ≈345ns → 所需 SYSCLK 周期数 ≈345/8.33≈41.4（F28075 @120MHz）→ ACQPS = 周期数−1，取 ≥41（60MHz 旧样片为 ≥20）。

**E2** 开关共模尖峰相对谷/峰时刻极性相反，成对平均后互相抵消；画图时把尖峰画在载波沿上即一目了然。

**E3** 可参照物：内部 VREFLO/VREFHI、已知精密分压点、任一稳定电池/基准通道——定期比对增益系数漂移趋势。

### 第6章

**E1** 相位累加器 24~32 位：step=f_target·2^N/fsw；N=24 时分辨率 18k/16.7M≈1.08mHz ✅。

**E2** 两相纹波反相叠加，D=0.5 完全抵消（理想零）；偏离时残余∝|2D−1|，再叠加死区差异引入的共模分量。

**E3** 平顶=交越区伏秒缺失；对策：按电流极性的死区伏秒补偿注入、最小脉宽限制、驱动加强缩短等效 Δt。

### 第7章

**E1** 三次谐波使合成波形过零点斜率改变：ADC 找过零产生随谐波相位变化的固定偏移（量级 ∝U₃/3U₁ 弧度）；迟滞比较器整形后表现为定时抖动，迟滞窗可压制部分抖动但偏移仍在。

**E2** 连续计数器：越限置 pending，持续 200 个周期确认→置欠/过频故障并锁存；恢复需回到窗口内持续 N 秒（双向迟滞）。

**E3** θ 直接清零=输出相位阶跃=电压瞬时跳变=负载电流冲击；限速斜坡让相位在若干毫秒内滑回，环路无感。

### 第8章

**E1** 峰值 169.7V；m=0.82 → Vdc≥207V → 取 230~250V 母线档（兼顾电解耐压规格与 60Hz 变压器系列）。

**E2** 末期每节约 10.5V×16=168V；P=10kW/η0.94 → I_bat≈63A（这就是低压电池方案电流恐惧的来源）。

**E3** 每管恒承 Vbus/2=450V → 650V 器件裕量 1.44 倍 ✅；这正是三电平能用中压管的根因。

### 第9章

**E1** 方和根：√(0.1²+0.02²+0.15²+0.16²)%≈0.24% → 整机标 ±0.3% 合理（校准后可标 ±0.15%）。

**E2** X7R 容值随直流偏压近线性下滑，额定电压处可达 −40%~−55% → fc 随信号幅度漂移，滤波名存实亡。

**E3** ①开尔文断开(满载才显现)②差分臂不对称(共模转差模,随开关同步)③分流电阻温升(慢漂移)。鉴别：空载对照/换通道交叉验证/加热试验。

### 第10章

**E1** 令 d^=0，输入项走 D·Vin^（注意是 D 不是 1！），消元得 **Gin(s)=D/(LCs²+(L/R)s+1)**，直流增益 = D ✅ 与稳态 Vout=D·Vin 自洽。

**E2** fc=2kHz、1.5×55.6 µs=83.3 µs → 延迟相位 360×2000×83.3e-6≈60°；若 PM 仅剩 30°：①加电容电流反馈削峰回收相位 ②降 fc 或减小 Ts。

**E3** LLC 的能量搬运节奏由谐振腔自身决定，不存在"占空比→平均电压"的单值映射；DCM 边界附近平均电流对 d 出现平方律依赖，一阶展开失效。

### 第11章

**E1** 结果 M=2/(1+√(1+4K/D²))，K=2Lfsw/R。轻载(K→0)任意 D 下 M→1（远高于 CCM 的 D）——解释了轻载电压泵升现象。

**E2** 每相 ΔI=Vin·D/(L·fsw)=200×0.5/(250 µH×50k)=8A；两相交错 D=0.5 时总纹波理想为零（残余来自失配与寄生）。

**E3** 突卸瞬间 i_ref 阶跃向下但电流环有限斜率 → 电池仍灌入功率 → 母线泵升直至 OVP；风险点标注在 iL 过零附近（方向切换）与 V_bus 峰值。

### 第12章

**E1** 链条：80Hz 处环路增益放大 100Hz 母线纹波 → |I|* 被 100Hz 调制 → 相乘产生 50±100Hz 分量 → 输入电流出现 **3 次(150Hz)与直流注入**，THDi/PF 双双恶化。

**E2** C≥2Pt/(Vn²−Vmin²)=2×5000×0.02/(160000−115600)≈4.5mF（约为 10ms 方案的 5.3 倍）——替代方案：保持期允许降压运行抬高 V_min。

**E3** 要点：过零窗检测(Vinst<阈值)→冻结前馈/提高比例→窗宽自适应；副作用声明（过零区 THD 局部恶化需实测验收）。

### 第13章

**E1** Kpi=0.030：Gi 所需=1/(0.03×400)=0.0833；两轮试凑得实际穿越≈2.79kHz，总相位≈−177° → **PM≈3~10°，不可用**——再次印证峰推穿越机制。

**E2** fr=1/(2π√(1.5m×10 µF))≈1.30kHz、Q=R√(C/L)=2.16、fz=657Hz 不变。fr 跌到名义 fc=1.2k 正上方 → 威胁严重；对策：fc 降至 ≤430Hz 或立即上有源阻尼。

**E3** 空载 Gi(s)=Cs/(LCs²+1)，增益峰恰在 fr 处趋于无穷（分母最小）；有限 R 时分子零点使峰值频率略低于 fr 并随负载减轻向 fr 收敛——题面"略低于"的说法仅在带载时成立。

### 第14章

**E1** Cf 并 Rp：icf 支路导纳=sCf+1/Rp，同框架推得 σ=1/(2RpCf)；与 Kc/2L1 联立 → Rp=L1/(Kc·Cf)=3.6e-4/(5.29×1e-5)≈6.8Ω ✅。

**E2** 阈值要求 fr'≥3×2.5k=7.5kHz＞强电网基准 7.02kHz——** 连 Lg=0 都不满足**：提带宽直接摧毁弱电网耐受，必须靠阻尼而不是蛮干。

**E3** 有效相位滞后 Δφ=ω·τ_d，注入矢量从纯实轴旋转出虚部分量：等效 Rd'=Rd·cosΔφ 且新增虚拟电抗 Rd·sinΔφ；7kHz 处 5° 滞后影响小，但频率越高越要警惕由"阻尼"翻转为"激励"。

### 第15章

**E1** d/dφ[φ(π−φ)]=π−2φ=0 → φ=π/2，代入得 Pmax=nV1V2/(8fsLk)。

**E2** 机理：轻载下单位周期的电荷转移少，固有不对称(损耗/采样)占比放大 → 净漂移速率不降反升。对策：主动注入小幅方波平衡电流+增大 Cmid+均压电阻兜底。

**E3** 表=输入(电压档×负载档)×输出(Kp,Ki,Kr 三元组)+切换迟滞带；插值用双线性，切换点参数做 50ms 渐变。

### 第17章

**E1** Ku=4d/(πa)=4×0.5/(π×1.2)=0.53；Tu=0.9ms；T-L：Kp=0.44Ku≈0.233，Ti=2.2Tu≈1.98ms → Ki≈118/s。

**E2** λ=2ms：Kp=8/(0.8×2.2)=4.55，Ti=min(8,8.8)=8ms → Ki=569/s；对比 λ=0.8ms 版本：穿越更低、PM 更厚、抗噪更强但阶跃恢复更慢——按现场噪声选档。

**E3** 【要点】须包含：触发源定义、冻结条件清单（软启/保护/模式切换）、恢复策略、以及"参数渐变 50~100ms"的平滑实现描述。

### 第18章

**E1** acc+=(I²−In²)Δt：110%/60s → K=(484−400)×60=5040 A²·s（In=20A）；验证 150%：t=5040/(900−400)=10.1s ✅ 反比关系符合反时限直觉。

**E2** TZSEL.OSHT6=1;TZCTL.TZA/TZB=FORCE_LO;EALLOW 下 TZFRC.OST=1；恢复流程：排除故障→TZCLR.OST=1→软启状态机。

**E3** 双页+递增序号+CRC：写备用页→校验→置有效标志；上电读两页取"序号大且 CRC 过"者，另一页标记待擦除。

### 第19章

**E1** 增量式饱和发生在 u 本身，下一拍从限幅值出发修正——天然无"积分仓库"需要消化，故无退饱和迟滞。

**E2** 增益比=1/√(1+(Δ/ωc)²)：Δ=2π×0.5，ωc=31.4 → 0.995（−0.04dB）；ωc=125.7 → 0.9998。结论：** 基波支路对 ±0.5Hz 天然免疫**；真正敏感的是高次分支（13 次失配 6.5Hz/ωc=5Hz 时跌 4dB）——ωc 应按最高次分支的失配预算选取。

**E3** 电流环噪声通过 D 通路的微分放大被无限放大，且电流环带宽高、D 的相位超前在此频段无收益；温度对象时间常数大、噪声低，D 的预判价值才显现。

### 第20章

**E1** ω_d=(2/T)atan(ω_aT/2)：ω_aT/2=0.982rad → ω_d=32000×0.7757=24.82krad/s=3950Hz，偏差 **≈21%** ——高频特征必须预畸变。

**E2** 微分低通：D 项带一阶低通：D(s)=Kd·s/(1+s/ω_N)，离散化后 y[k]=(2τf−Ts)/(2τf+Ts)·y[k−1] + (2Kd/(2τf+Ts))·(e[k]−e[k−1])，其中 τf=1/ω_N；给结构即可，N=ω_N/ω_c 取 8~20。

**E3** 新旧参数各自算 u 后线性插值：u=u_old+(u_new−u_old)·n/50（50 拍过渡），期间禁用依赖参数突变的功能（如抗饱和重置）。

### 第21~22章

21 章练习答案要点：Kpi=ωcL/Kmod 代入得数值；打架振荡频率出现在两环带宽之间的"无人区"；失效检测用"外环误差持续>阈值∧内环输出未饱和"组合判定。<br>
22 章 Type III 例：z₁≈300Hz、z₂≈900Hz 包夹 fr=900Hz——正确布置 z₁=fr/3、z₂=fr，p₁=ESR 零点(若有)、p₂=3~5×fc；最大提升角出现在 z-p 几何中心附近，用 margin 复核收口。本质差异：DC-DC 对象是"宽幅平坦+单峰"，逆变器对象是"正弦跟踪+周期扰动谱"，工具自然分流。

### 第23~28章（谐波篇）

**22-E1** 全部乘 0.4（按基波峰值 311V 口径）：3次0.53%/5次0.32%/7次0.23%，RSS≈0.66% —— 线性指标可裸奔，非线性预算仍建议保留 PR/RC 余量。

**22-E2** 死区误差电压不变而基波下降 → 各次含有率(分母 U1)上升；叠加轻载阻尼变小使 LC 峰更尖放大残余扰动 → 双重推高。

**22-E3** 【要点】流程：看频谱分布(奇次集中=死区/负载类)→空载对比(消失=电流相关源)→改 fsw 观察谱线移动(定位开关相关源)。

**23-E1** MAF 传函 sin(NωTs/2)/(N·sin(ωTs/2))，分子零点在 ω=k·2π/(N·Ts)=k·基波角频率 → 半窗(T/2)时零点在 2k×50Hz，恰好吞掉 6k 次纹波。

**23-E2** 代入 s=jω0：D 分子=j kω0²，分母=j kω0² → |D|=1 与 k 无关 ✅。

**23-E3** I_h,rms=√Σ_{h≥2}I_h²（分母为额定或基波，注明口径）；THDi 同式但分母=I1——轻载时 THDi 虚高而 I_h,rms 不变。

**24-E1** X(n)−X(n−1) 展开后利用 x(n)−x(n−N) 合并同类项即得递推式（教材正文已给，练习补全过程）。

**24-E2** 每基波周期栅格滑差=fs/f0−N=18000/50.5−360≈−3.56 采样 → h=13 相位滑差=2π×13×3.56/360≈0.81rad≈46°/周期——一个窗内完全失真，定量证明必做自适应（N=Fsw/f0=360，18kHz/50Hz 口径）。

**24-E3** Park(+5θ)：cos(5θ) sin(5θ) 查表；MAF 窗 T/2；反 Park(−5θ)；伪代码 6 行内完成。

**25-E1** a=(1+sin12°)/(1−sin12°)=1.525；τ=1/(2π·350·√a)=368 µs；wz=432Hz、wp=659Hz（中心 350Hz 处输出恰 12°）。

**25-E2** 三因排查：①该次对象幅值估计错(扫频核实) ②相位失配超 ±90%(看 cos 符号) ③邻次谐振器互拉(临时旁路邻次观察)。

**25-E3** 高次失配预算=2π·h·Δf_max·Td 与 ωc 关系表；结论：ωc≥(2~3)×h·Δf_max 对应角频率方可忽略失配。

**26-E1** Δθ_h=2π·h·(fs/f0−N)/N 每基波周期累积；f0=50.3Hz（Δf=+0.6%）、h=13、N=360 → 每周期≈28°——数个周期即完全失配。

**26-E2** 需 m·ωTs≈160° → ωTs=12.38° → m=13；D=|0.95−0.5∠0.9°|=0.45 ✅ 达标。

### 第32章（三相四线制 · 不平衡 · 零序与中点平衡）

**E1** 四线制与三线制的差别全在零序通路：三线制零序电流无处可去，不平衡负载只表现为负序；四线制零序经中线流回，i_N=-(i_a+i_b+i_c)，因此必须单独抑制零序并平衡分裂母线上下电容电压。

**E2** 单相满载是最坏工况：某一相电流为额定而另两相为零，负序与零序同时出现，要求电压不平衡度 ≤3%、相位差 ≤1°；电流峰值系数按 ≥3:1 设计限幅。

**E3** 中点平衡可用电荷积分环或载波偏移实现；判据是上下电容电压偏差持续 <5%Vdc，且在负载突变与非线性负载下不发散。

### 第34章（整机模式状态机与能量流协同）

**E1** 【要点】模式矩阵至少覆盖：市电正常（逆变供电）、电池放电、旁路、ECO、故障与恢复、维护旁路；每行需写清"进入条件 / 控制使能次序 / 参考来源（市电相位或自产）/ 退出条件"。

**E2** 市电↔电池切换要求 0ms：母线电压由双向 DC-DC 闭环维持，整流侧失能后母线不跌落，故负载无感；这是"在线式"的字面含义。

**E3** 恢复必须软启：从故障恢复到闭环需重走预充与参考斜坡，否则冲击电流与动态瞬变（要求 ≤±5%、恢复 ≤20ms）会超标。

### 第37章（固件架构与实时任务调度）

**E1** 快慢分层：控制 ISR 只做"采样→保护扫描→控制算法→PWM 更新→中断应答"；1ms/10ms 慢任务（遥测、通信、参数保存）放主循环或定时任务队列，严禁在 ISR 内做除法、三角函数、printf 与大循环。

**E2** ISR 占用率判据 ≤50%：120MHz 下 18kHz 载波周期 6,667 周期，控制环实测最坏 2600 周期约占 19.5%，余量留给故障路径与中断抖动。

**E3** 参数表集中定义 + CRC 校验，掉电保存需考虑写入触发策略（变化即写 vs 定时写）与 Flash 寿命；恢复默认值必须走同一校验路径。
