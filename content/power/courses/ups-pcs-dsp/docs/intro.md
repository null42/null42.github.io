双变换在线式 UPS 与储能变流器 PCS 的 DSP 控制开发全路线 · 第0章 + 48 章 + 附录 A~C 体系 · 教学样片 TMS320F28075

### 🧭 开始前准备（零基础必读）

- **前置知识底线**：电路基础（基尔霍夫定律、LC 阻抗、有效值/峰值）、基础微积分与复数（能看懂传递函数记号）、C 语言（指针/结构体/中断概念）。控制理论** 不需要**提前学——第0章 0.1 有"数学自检五问"，卡哪条补哪条即可。
- **软件环境**：Code Composer Studio（CCS，建议 12.x 及以上）+ C2000 编译器；MATLAB + Control System Toolbox 仅为 LAB0~LAB4 可选项——补齐前可用浏览器交互仿真替代观察波形。
- **硬件投入（可选）**：LAB2 起才需要实机，低压台架预算约 200~500 元（F280049C LaunchPad 平替 + 降压评估板 + 示波器）；纯软件学习 0 成本跑通 LAB0~LAB4。
- **使用方法**：①先读[第0章](/posts/power/courses/ups-pcs-dsp/ch00/)并完成 0.1 自检 → ②按[岗位课表](/posts/power/courses/ups-pcs-dsp/docs/paths/)选一条轨道 → ③每章末做 E 题，对[参考答案](/posts/power/courses/ups-pcs-dsp/docs/answers/)（注意"答案不唯一"声明）→ ④动手环节按[实验指导书](/posts/power/courses/ups-pcs-dsp/docs/labs/)逐项打勾 → ⑤术语卡壳即查[术语表](/posts/power/courses/ups-pcs-dsp/docs/glossary/)，整机指标以[验收单](/posts/power/courses/ups-pcs-dsp/docs/acceptance/)为准。

### 👥 适合人群

- **UPS/电源研发工程师** —— 从模拟控制或单片机方案转向 C2000 数字平台
- **储能/逆变器工程师** —— 系统掌握并网、离网、锁相、保护的全栈实现
- **电力电子/电气专业学生** —— 打通"建模→补偿→离散化→寄存器"的完整链路
- **嵌入式工程师转行电力电子** —— 从 GPIO/PWM 外设到环路调试的实战地图

### 🎯 学完你能做什么

- 独立完成单相在线式 UPS 的采样、SPWM、双环、旁路切换软件开发
- 完成三相 PCS 的 SVPWM/dq 控制、PQ 并网、VF 离网与 LVRT 策略设计
- 搭建硬件快速保护路径（比较器→TZ）并正确编写软件关断逻辑
- 设计 PLL、准 PR 谐振控制器，处理谐波治理与弱电网适应性问题
- 建立并联均流/下垂控制、SOC 估算、Modbus/CAN 监控等系统级功能
