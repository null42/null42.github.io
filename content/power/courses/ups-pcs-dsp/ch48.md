### 48.2 算例 48-1：从指令到输出的全链路核算（把每一环的数连起来）

```text
目标：验证"负载阶跃 0→100%"时输出跌落 ≤5%、恢复 ≤20ms（验收表 A 组）

① 电流环动态（内环 1kHz）：阶跃响应时间 ≈ 2.5/(2π×1000) = 0.4 ms
② 电压环动态（外环 455Hz）：≈ 2.5/(2π×455) = 0.87 ms
③ 前馈支路（负载电流前馈，第28章）：前馈量在 1 拍（55.6µs）内生效
   → 主通道是前馈，环路只补残差 → 实际恢复时间 ≈ 0.5ms + 前馈误差修正
④ 母线支撑（28.6mF，瞬时缺额 50kW）：
   跌落 = ΔP·t/(V·C) = 50000×0.5e-3/(700×28.6e-3) = 25/20.02 = 1.25 V（0.18%）✓
⑤ 采样与延迟：1.5Ts = 83.3µs 已含在①内

  全链路预测：输出跌落 ≈ 前馈残差（前馈精度 1% → 1%）+ 母线跌落 0.18% + 环路残差 ≈ 1.3%
  → 满足 ≤5% ✓ 且恢复时间 <1ms（远优于 20ms）
  实测偏差主要来自前馈精度与采样标定 → 把"前馈通道标定"作为首查项
```

### 48.3 算例 48-2：整机效率链核算（与第39章对接）

```text
在线双变换模式（50kW 负载）：
  整流/PFC 效率 98.5% × DC-DC 99.0% × 逆变 98.5% × 滤波/输出 99.5%
  = 0.985×0.99×0.985×0.995 = 95.6%  ✓ 与第0章口径一致，满足 ≥95.5%（半载）
  额定点（96.5%）靠更大负载下固定损耗被摊薄：固定损耗 334W 在 50kW 时占 0.67%
    η = 1/(1 + 0.0067 + 0.034) ≈ 96.2%
  ⚠ 96.2% 未达 96.5% 合同线 → 不判"达标"，列入整改项（散热/磁件优化后复测）；
    正式验收的负载点与限值口径以 acceptance.html 为准

  ECO 模式（旁路）：99.5% → 年省电量 13,692 kWh（第39章 39-2）
  增强 ECO：98.9%（第39章 39-3）

  → 三条效率数字必须都能在测试台上复现；不能只报"最高效率点"
```

### 48.5 代码：整机初始化顺序（上电检查单的代码化）

```c
/* ---------- boot.c：上电初始化与自检顺序（顺序不可换） ---------- */
void system_boot(void)
{
    /* ① 基础：时钟与看门狗（第2/3章） */
    sys_clock_init();  wdt_init();  gpio_safe_all();

    /* ② 安全：先把所有门极封到安全电平，再初始化任何外设（第8章） */
    pwm_force_safe_level_all();
    if (!tz_selftest())            sys_fault_fatal(FATAL_TZ);      /* TZ 通路自检（第36章） */

    /* ③ 参数：双备份读取 + CRC + 范围校验（第37章） */
    if (param_load_checked() != 0u) sys_fault_fatal(FATAL_PARAM);

    /* ④ 采样：标定系数加载 + 零点自校（第9章、附录 B） */
    adc_cal_load();  adc_zero_calibrate();

    /* ⑤ 控制：滤波器/谐振器初始化并复位状态（第13/18章） */
    filter_init();  harmon_init();

    /* ⑥ 通信：先起接收、再起发送（第40章） */
    can_init();  comm_start();
    if (adc_selftest(ADC_SELF_CH) != 0u) sys_fault_fatal(FATAL_ADC);

    /* ⑦ 预充与软启动交给状态机（第34/35章） */
    g_fsm.st = SYS_PRECHARGE;
    log_fault_event(EV_BOOT_DONE, 0u);
}

/* 上电自检清单（与 LAB0~LAB5 的固定项一一对应） */
static const sys_check_t BOOT_CHECKLIST[] = {
    { "TZ 通路",     tz_selftest },
    { "参数 CRC",    param_crc_ok },
    { "ADC 自检",    adc_selftest_ok },
    { "PLL 锁定",    pll_locked },
    { "谐波计量",    harm_selftest },
    { "通信链路",    comm_link_ok },
    { "中点平衡",    tl_balance_dir_ok },     /* 第15章：方向验证 */
    { "直流抑制",    dc_reject_baseline_ok },
};
```

### 48.7 失败案例复盘：项目"一次投运成功"的真实时间线（反面教材）

> [!CAUTION]
> 现象：某 50kW PCS 项目计划 3 个月交付，实际 7 个月，主要返工集中在三处。时间线（复盘）：①第 1 个月完成硬件与开环 —— 正常；②第 2 个月发现 THDu 1.8%（原因：为压谐波把 Kr 放大 5 倍，PM 掉到 22°，见第22章复盘）—— 返工 3 周；③第 3 个月并机空载环流 18%（只做下垂没做通信均流，见第38章复盘）—— 返工 2 周；④第 4 个月整机漏电流 4.2mA（寄生电容未按 45-2 预算）—— 返工 1.5 周。根因：三处返工都源于"跳过前置计算、直接调参"——而这三条（谐振器相位代价、空载环流、漏电流预算）都能在设计阶段用手算发现。预防措施：①把本书的"可手算核对项"做成《设计评审检查表》（谐振器 IΣ、空载环流、漏电流预算、延迟链、抗饱和退饱和时间、中点平衡方向）；②每项都要有"数字 + 出处"；③评审不通过不允许进入调试阶段。本课程的全部算例就是这张检查表。

### 48.9 练习（结课大作业）

1. **E1** 选一台现成的 UPS/PCS 铭牌参数，按 48-2 的口径反算其母线电容、滤波电感与开关频率，并判断其设计取舍（提示：从保持时间与 THDu 反推）。
2. **E2** 把自己的课程实验数据整理成 48-4 格式的验收对照表（12 行），每行给出"设计值—实测值—偏差—原因"。
3. **E3** 写一份 2 页的《设计评审检查表》，把本书所有"手算核对项"列出（至少 20 项），每项含判据与出处章节；这份表就是本课程的最终交付物。（参考答案见 [练习参考答案](/posts/power/courses/ups-pcs-dsp/docs/answers/)）

> [!TIP]
> 课程结束语：UPS/PCS 的 DSP 控制没有"黑魔法"——所有现场事故都能追溯到"某一笔账没算或算错"（延迟、损失、寄生、裕度、能量、寿命）。把这本书里的数字都自己算一遍，你会比大多数做过 5 年项目的人更可靠。
