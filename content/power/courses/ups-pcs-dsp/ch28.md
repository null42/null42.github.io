### 28.2 算例 28-1：负载电流前馈——直接压低输出阻抗

```text
第23章遗留问题：单相 2kW 在 5 次（250Hz）处闭环 |Zout| = 19.7Ω，要求 ≤2.33Ω
  靠环路增益做不到（需要 T 从 2.23 提到 26.4 → 相位代价不可接受）

负载电流前馈：把测到的负载电流 i_o 按 1:1 前馈到电流指令（内环）
  闭环输出阻抗 = Z_open/(1 + T) − Z_ff
  其中 Z_ff 由前馈通道精度决定：前馈增益精确到 1 时，等效"负阻抗"抵消 1/(1+T) 项
  实际 Zout ≈ Z_open/(1+T) × (前馈误差) + Z_open/(1+T_feedforward_loop)

  数值：前馈增益误差 1% → |Zout(250Hz)| ≈ 19.7Ω × 0.01 + 前馈环残余 ≈ 0.2 + 0.5 = 0.7Ω ✓✓
  → 从 19.7Ω 降到 0.7Ω，5 次谐波压降 = 0.7×4A = 2.8V = 0.9% × 311V ✓ 达标

前馈的三条纪律（与 21-3 相同，但更容易翻车）：
  ① 极性必须验证：反了就是正反馈（现象：THDu 从 1% 猛升到 5% 以上）
  ② 前馈系数用"测量增益×标定系数"算出，并从参数表读取（附录 B）
  ③ 前馈量必须限幅（负载短路时前馈会给出巨大指令）
```

### 28.3 算例 28-2：虚拟阻抗——均流与限流的"软件电阻"

```text
① 并联均流（第38章预演）：模块间电压差 ΔV = 2V 时，若输出阻抗 0.1Ω，环流 = 20A（26% 额定）
   加虚拟阻抗 Zv = 0.5Ω（虚拟）后，等效电压差不变但"阻抗"增大到 0.6Ω → 环流 = 3.3A（4.4%）
   → 满足"环流度 <5%"（验收表 E 组）
   代价：负载调整率变差：额定 76A 时虚拟压降 = 0.5×76 = 38V（17.3%）
   → 折中：Zv = 0.1~0.2Ω，配合通信均流（第38章）

② 限流（故障电流限制）：虚拟阻抗在过流时增大（自适应虚拟阻抗）
   例：正常 Zv = 0.2Ω；故障时 Zv = 2Ω → 短路电流限制到 380/2 = 190A（2.5 倍额定），
       避免触发上级断路器（规范要求故障清除时间与限流配合，第44章）
   → 这比"直接封锁门极"更平滑，且保留故障电流供保护判据使用
```

### 28.4 算例 28-3：直流分量抑制（防变压器饱和）

```text
来源与量级：
  ① ADC 偏置误差 2 LSB（1.61mV）→ 电压通道分压比 121.2 → 折算 0.195V 输出直流 = 0.088% ✓
  ② 电流通道偏置误差 2 LSB（0.147A）→ 通过电流环影响输出电压直流分量：
     电流偏置 0.147A 流过 24.2Ω 负载 → 3.56V = 1.6% ✗ 超标（要求 ≤0.5%）
  ③ 调制不对称（上下管死区不等）：不对称 0.1µs → 每周期伏秒误差 = 400V×0.1µs = 40V·µs = 4.0e-5 V·s
     → 平均直流 = 4.0e-5×18000 = 0.72V = 0.33%（仅在 1 个方向；18kHz 载波口径）
  三者合计（最坏同向）= 0.088+1.6+0.33 = 2.02% ✗ 必须抑制

抑制方法（在电压环里加"直流谐振器"，即 ω0 = 0 的谐振器，等价于额外的纯积分）：
  直流环增益 = Kr0（如 1.0）→ 直流误差压到 1/(1+T_dc)
  T_dc 由纯积分提供：T_dc → ∞（理想）→ 唯一限制是 ADC 偏置漂移与积分器精度
  实测目标：输出直流 ≤0.5%（即 1.1V），并纳入保护（>2% 时告警）

  ⚠ 直流抑制环的带宽必须很低（≤1Hz），否则会与 50Hz 基波谐振器"打架"
```

### 28.5 代码：前馈 + 虚拟阻抗 + 直流抑制

```c
/* ---------- harm_adv.c：28.2~28.4 三项功能的合并实现 ---------- */
#define HA_FF_GAIN     1.00f        /* 负载电流前馈系数（标定后写入，附录 B） */
#define HA_FF_LIM_A    110.0f       /* 前馈限幅 = 1.45×76A */
#define HA_ZV_NORM     0.20f        /* 正常虚拟阻抗（Ω，28.3） */
#define HA_ZV_FAULT    2.00f        /* 故障虚拟阻抗 */
#define HA_DC_KI_TS    1.26e-4f     /* 直流抑制积分增益（Ki = 2.0 (1/s) × Ts） */
#define HA_DC_LIM_V    1.1f         /* 直流抑制输出限幅（0.5%×220V） */

static ctrl_pi_t g_dc_pi = { 0.0f, HA_DC_KI_TS, -HA_DC_LIM_V, HA_DC_LIM_V, 0.0f, 0.0f, 5.0f };
static float g_io_dc;                 /* 输出电流直流分量估计（用于诊断） */

/* ① 负载电流前馈：直接叠加到电流指令上 */
float ha_feedforward(float io)
{
    return clampf(HA_FF_GAIN * io, -HA_FF_LIM_A, HA_FF_LIM_A);
}

/* ② 虚拟阻抗：等效额外压降（均流用），故障时自动加大 */
float ha_virtual_drop(float io, uint8_t fault)
{
    float zv = HA_ZV_NORM;
    if (fault != 0u) zv = HA_ZV_FAULT;     /* 故障时切换到限流用的虚拟阻抗 */
    return zv * io;
}

/* ③ 直流抑制：对输出电压的直流分量做积分修正（带宽 ≤1Hz） */
float ha_dc_reject(float v_out, float v_ref_dc)
{
    g_io_dc = lpf1_step_slow(v_out);              /* 慢速平均，1Hz 量级 */
    return ctrl_pi_step(&g_dc_pi, v_ref_dc - g_io_dc);
}

/* 合并到逆变控制（在 inv_isr 内、限幅之前） */
void ha_apply(float io, float v_out, float *i_ref_cmd)
{
    if (!harm_comp_enable()) return;              /* 第26章：过载/故障退出 */
    *i_ref_cmd += ha_feedforward(io);             /* 前馈（极性与增益已标定） */
    *i_ref_cmd += ha_dc_reject(v_out, 0.0f);      /* 直流修正 */
}
```

### 28.7 失败案例复盘：负载电流前馈极性接反，谐波"越补越大"

> [!CAUTION]
> 现象：投入负载电流前馈后，THDu 从 0.32% 猛升到 2.6%，输出电压波形出现明显畸变。定位路径：①对比投入前后频谱（各次谐波同比例放大）→ ②检查前馈通道符号（电流互感器方向反了）→ ③改正极性后 THDu 降到 0.15%（与 28-1 预测一致）。根因：前馈极性错误 → 从"补偿"变成"正反馈"；前馈是开环补偿，极性错误不会被环路自动纠正。预防措施：①前馈投入必须做"极性验证实验"（本课程列入 LAB3 固定项）；②前馈系数带符号写入参数表，并在标定报告里记录方向；③前馈量必须限幅，限制极性错误时的破坏范围；④把"THDu 变化方向"作为前馈投入的合格判据（必须下降）。

### 28.10 补充：直流分量的三层抑制与变压器补偿（对照参考工程）

参考工程把直流分量问题拆成三个方法：`App_Int_VinvDcReg`（输出电压直流环）、`App_Int_IlDcCirReg`（电感电流直流/环流环）、`Alg_Int_TransformerAndDcCmp`（变压器与直流分量补偿）。本书 28-4 只给了第一层的方案，本节补齐三层。

| 层 | 抑制对象 | 带宽 | 限幅 | 解决什么 |
| --- | --- | --- | --- | --- |
| ① 电压层 `VinvDcReg` | 输出电压的直流分量 | ≤1Hz | 1.1V（0.5% 额定） | ADC 偏置与调制不对称造成的输出直流 |
| ② 电流层 `IlDcCirReg` | 电感/支路电流的直流分量 | ≤0.5Hz | 1% 额定 | 模块间直流环流、电感偏磁（不改变输出电压，电压层管不到） |
| ③ 变压器层 `TransformerAndDcCmp` | 变压器（隔离/输出变压器）的伏秒不平衡 | ≤0.2Hz | 0.5% 调制量 | 偏磁累积：原边电流直流分量增大、励磁电流饱和、噪声与温升 |

```text
为什么必须分层：三层的"被测量"不同，互不替代
  电压层看不到"电流直流环流"（两模块输出电流各偏 1% 时输出电压仍为 0）
  电流层看不到"变压器磁通"（原边直流分量取决于伏秒不平衡，与电感电流平均值不同）
  变压器层必须用磁通估计或原边电流直流分量做被测量，不能复用前两层的误差信号

带宽三层的取值依据（统一原则：必须远低于基波 50Hz，且互相错开）
  电压层 1Hz、电流层 0.5Hz、变压器层 0.2Hz → 时间常数 159ms / 318ms / 796ms
  若带宽接近，三层会互相"抢动作"，表现为输出直流缓慢来回摆（亚赫兹振荡）
被测量与实现要点：
  ① 电压层：输出瞬时电压的 1s 滑动平均，与 0 比较，极慢积分修正调制量
  ② 电流层：各模块电感电流的 1s 滑动平均差（相对系统平均），修正该模块指令
  ③ 变压器层：由伏秒计算磁通（∫v·dt），或用原边电流的直流分量估计，超阈值时在调制上叠加反向偏置
判据：输出直流 ≤0.5%；模块间电流直流分量差 ≤0.5%；变压器原边电流直流分量 ≤1% 额定；连续 8h 不漂移
```

> [!CAUTION]
> 失败案例复盘（只做电压层）：并机系统只实现了输出直流抑制（电压层），运行 3 个月后两台模块的电感出现可听偏磁噪声、散热器温差 9℃。核查：各模块输出电流的直流分量差 1.2%（超 0.5% 判据），电压层对此完全无感。补上电流层（0.5Hz 慢环）后偏磁噪声消失、温差降到 3℃（与第38章 38.10 复盘同一项目）。结论：直流分量不是"一个量"，而是三层不同的量；被测量选错，环路再稳也治不了病。
