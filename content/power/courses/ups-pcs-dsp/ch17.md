**本章要解决的问题：** 把第11~14章的"一个个算"变成**可复用的方法与脚本**。给出闭式解（含延迟）一步算出 Kp/Ki、用约束型自动整定处理"PM / GM 好看但 GM 为负"的陷阱、以及参数敏感度表。

### 17.1 整定的三段式（本章主线）

```text
① 定指标：穿越频率 fc（带宽）与 PM 目标 → 见 17.2 的三条上限
② 闭式解：由对象 K、fc、PM 直接算出 Kp、Ki（17.3 / 17.4）
③ 校验：GM、参数敏感度、饱和与延迟（17.5 / 17.6）——任一项不过就回到 ①

顺序不能颠倒：先写脚本"搜参数"再想指标，会得到"数学最优、物理不可用"的结果（17.7 复盘）。
```

### 17.2 闭式解一：无延迟（对象为纯积分 K/s）

```text
对象：Gp(s) = K/s（本课程最常见：1/(sC)、u_bus/(sL) 折算成"控制量→被控量"）
控制器：Gc(s) = Kp + Ki/s

在穿越频率 ωc 处：
  幅值条件：√(Kp² + (Ki/ωc)²) · K/ωc = 1
  相位条件：−90°(积分) − atan(Ki/(Kp·ωc)) = −180° + PM
           → atan(Ki/(Kp·ωc)) = 90° − PM
联立解出：
  Kp = ωc·sin(PM)/K
  Ki = ωc²·cos(PM)/K

回算验证（与第12、14章的数字对齐）：
  第12章 PFC 电压环：K = 220/(C·V) = 220/(1000e-6×700) = 314.3 V/(A·s)，fc = 10Hz
    Kp = 62.83×sin(90°)/314.3 = 0.1999  ✓（正文取值 0.2000）
    Ki = 62.83²×cos(90°)/314.3 = 0（PM=90° 时 Ki 退化为 0，所以实际取零点 2Hz 给低频增益）
  第14章 三相电流环：K = Kmod/L1 = 350/800e-6 = 437,500 A/(m·s)，fc = 1kHz（Kmod = u_bus/2 = 350V，平台口径）
    Kp = 6283.2×sin(90°)/437500 = 1.436e-2  ✓（正文取值 1.44e-2）
```

> [!IMPORTANT]
> 这条闭式解的价值：它把"整定"从"试参数"变成"算参数"。PM 取 90° 意味着"不留延迟余量"；工程上取 60°~75° 给延迟与参数漂移留余地：PM = 60° 时 Kp 比 90° 情形小 13.4%（sin60° = 0.866）。

### 17.3 闭式解二：含 1.5Ts 延迟（本课程默认口径）

```text
把延迟 e^{−sTd}（Td = 1.5Ts）的相位扣进来：
  相位条件：−180° + atan(Kp·ωc/Ki) − ωc·Td = −180° + PM
  令 θ = PM + ωc·Td（角度制），r = tan θ
  幅值条件：√(Kp² + (Ki/ωc)²)·K/ωc = 1
解得：
  Kp = ωc / (K·√(1 + 1/r²))
  Ki = Kp·ωc/r

回算验证（第14章同一对象，K = 437,500 A/(m·s)）：
  Ts = 55.6µs，Td = 1.5Ts = 83.3µs，fc = 1kHz → ωc·Td = 6283.2×83.3e-6 = 0.523 rad = 30.0°
  目标 PM = 50° → θ = 50° + 30.0° = 80.0° → r = tan(80.0°) = 5.671
  √(1 + 1/r²) = √(1 + 1/32.16) = 1.01543
  Kp = 6283.2/(437500×1.01543) = 1.414e-2   （第14章零点取 fc/10 时得 1.44e-2，差 1.8%）
  Ki = 1.414e-2 × 6283.2/5.671 = 15.67 → Ki·Ts = 15.67×55.6e-6 = 8.71e-4
       （闭式解把零点放在 ωc/r = 1108 rad/s ≈ 176Hz；第14章工程取法零点在 fc/10 = 100Hz、
        Ki·Ts = 5.02e-4——Ki 的差异来自零点位置不同，两者 PM 均为 50°，不是谁算错）
```

> [!WARNING]
> 两种取法的差别要清楚："零点取 fc/10"是工程习惯（好记、好调），"闭式解"是精确满足 PM 目标。Kp 两种取法相差通常只有几个百分点（本例 1.8%）；Ki 因零点位置不同可差几十个百分点（176Hz vs 100Hz）——这不是数值误差而是设计选择。所以现场调试的第一步不是重算，而是先量实际 fc 与 PM（扫频），再决定是否需要用闭式解修正。

### 17.4 算例 17-1：自动整定的第一个陷阱——PM 漂亮、GM 为负

```text
对象（第10章 Buck）：48/(1 + s/(Q·ω0) + (s/ω0)²)，f0 = 23.2kHz，Q = 5.84
控制器：PI，零点固定 200Hz，1.5Ts = 7.5µs
本配置有两个可手算的特征量：
  低频段：|T| ≈ 48·Kp/(116.08·x)，x = f/f0 → 穿越频率 ≈ 9,599·Kp (Hz)
  谐振点：|T(f0)| = 48×Q×Kp = 280.1·Kp  →  GM(dB) = −20·log10(280.1·Kp)

  Kp      穿越频率   PM      |T(f0)|   GM        判决
  0.0010     9.6 Hz   88°     0.280    +11.1 dB  稳定但太慢（9.6Hz 带宽）
  0.0020    19.2 Hz   88°     0.560     +5.0 dB  GM 不足 6dB ✗
  0.0025    24.0 Hz   88°     0.700     +3.1 dB  ✗
  0.0050    48.0 Hz   88°     1.400     −2.9 dB  不稳定 ✗
  0.0210   201.6 Hz   87°     5.880    −15.4 dB  不稳定 ✗（PM 却"最漂亮"）

结论：PM 一栏从 88° 到 87° 看起来完美，GM 却从 +11dB 掉到 −15dB。
      想用 Kp 把带宽提到 2kHz（需 Kp = 0.2084）→ |T(f0)| = 58.4 → GM = −35dB。
      → 单电压环 + 平坦高频增益的 PI 在这个对象上**无可行解**。
      必须换结构：电流内环（第11章 11-2/11-3）、类型 III 补偿、或加大阻尼。
```

> [!IMPORTANT]
> 这就是"自动整定"必须带约束的原因：只搜 PM 的脚本会兴高采烈地返回 Kp = 0.021（PM 87°），上电即振荡。任何自动整定脚本的第一行约束都应该是"谐振点增益 ≤ −6dB"。

### 17.5 算例 17-2：二分法搜 Kp（8 次迭代收敛到 1%）

```text
约束：|T(f0)| ≤ 0.5012（= −6dB）  →  Kp* = 0.5012/280.1 = 1.789e-3
搜索区间取 [0.0010, 0.0040]（区间宽 3.0e-3）

  迭代   mid(Kp)      |T(f0)|   是否超约束   新区间
   1    0.002500      0.700      超       [0.001000, 0.002500]
   2    0.001750      0.490      未超     [0.001750, 0.002500]
   3    0.002125      0.595      超       [0.001750, 0.002125]
   4    0.001938      0.543      超       [0.001750, 0.001938]
   5    0.001844      0.516      超       [0.001750, 0.001844]
   6    0.001797      0.503      超       [0.001750, 0.001797]
   7    0.001773      0.497      未超     [0.001773, 0.001797]
   8    0.001785      0.500      收敛 ✓（误差 0.2% < 1%）

迭代次数通用算式：区间宽 W，目标精度 ε·Kp*：
  n = log2(W/(ε·Kp*)) = log2(3.0e-3/(0.01×1.789e-3)) = log2(167.7) = 7.4 → 取 8 ✓

但注意：Kp* = 1.789e-3 对应的带宽只有 9,599×1.789e-3 = 17.2 Hz
→ 脚本必须把结论报成"约束下最优点 = 1.789e-3，带宽 17.2Hz，**不建议使用**"
```

### 17.6 算例 17-3：参数敏感度表（用第14章的整定结果做体检）

```text
敏感度关系（含延迟的主导项，一阶近似）：
  L 变化改变对象增益 K = 1/L，而 ωc = Kp·K 随 K 同比例移动：
  ΔPM ≈ +(ωc·Td)·(ΔL/L) − (ωc·Td)·(ΔTd/Td) + Δ(零点相位项)
  即：L 增大 → 交越下降 → 延迟相位损失变小 → PM 变好；**L 减小才是危险方向**。
  对第14章：ωc·Td = 30.0°，零点相位 |atan(ωz/ωc)| = 5.7°，名义 PM = 54.3°

  电感 +20%（磁芯饱和/温升）：交越降到 1/1.2 倍 ≈ 833Hz
    ωc·Td = 25.0°，零点相位 6.8° → PM = 180 − 90 − 6.8 − 25.0 = 58.2° ✓（改善 +3.9°）
  电感 −20%（容差下限）：交越升到 1/0.8 倍 ≈ 1250Hz
    ωc·Td = 37.5°，零点相位 4.6° → PM = 180 − 90 − 4.6 − 37.5 = 47.9° ✗ 逼近 45° 门槛
  采样延迟 +1 拍（1.5Ts → 2.5Ts，Td = 138.9µs）：
    ωc·Td = 6283.2×138.9e-6 = 50.0° → PM = 54.3 − 20.0 = 34.3° ✗ 严重超标
  Ts 减半（载波 18kHz → 36kHz，fc 不变，Td = 41.7µs）：
    ωc·Td 减半 → 15.0° → PM = 180 − 90 − 5.7 − 15.0 = 69.3° ✓（这就是"提高开关频率"的收益）

结论：**电感下偏与延迟拍数是最敏感的两个参数**（L+20% 反而改善，勿把复核方向调反）。
      设计时必须按"最坏组合（L −20%、延迟 2.5Ts）"复核：
      ωc = 6283.2/0.8 = 7854 rad/s → ωc·Td = 7854×138.9µs = 62.5°，
      PM = 180 − 90 − 4.6 − 62.5 = 22.9° ✗
      → 正确做法：把设计点 PM 定在 60°~70°，或把 fc 从 1kHz 降到 700Hz。
```

### 17.7 代码：带约束的自动整定脚本 + 固件常量校验

```matlab
% auto_tune.m —— 带约束的自动整定（放 规范与大纲/sim/）
% 目的｜参数版本 v1｜依赖 Control System Toolbox（或自写 freqresp）
function res = auto_tune(Gp, wc_target, pm_target, Td, Gm_min_dB)
    % 约束：穿越频率接近 wc_target、PM ≥ pm_target、谐振点增益 ≤ -Gm_min_dB
    if nargin < 5, Gm_min_dB = 6; end
    Kp = sin(deg2rad(pm_target)) / abs(evalfr(Gp, 1i*wc_target));   % 17.2 闭式解
    wv = logspace(2, 5, 400)';                  % 扫 |Gp| 找谐振峰（对象已知时可直接传入 w_pk）
    [~, ix] = max(abs(freqresp(Gp, wv)));  w_pk = wv(ix);
    for it = 1:40                                  % 最多 40 次，每次用扫频精修
        Gc = tf([Kp 0],[1 0]);                     % 示意：PI 的 s 域形式（Kp、Ki 由 17.2/17.3 给出）
        T = Gc * Gp;  T.InputDelay = Td;           % 含 1.5Ts 延迟链（tf 的 InputDelay 属性）
        [Gm, Pm, Wcg, Wcp] = margin(T);
        if Wcp < 0.5*wc_target
            res = struct('feasible', false, 'reason', '带宽不足');  return;
        end
        if Pm < pm_target
            Kp = Kp*0.9;  continue;
        end
        if Gm < Gm_min_dB
            % 用二分法收 Kp（17.5 的算法），而不是"减小 10% 试试"
            Kp = bisect_gm(Gp, Td, Gm_min_dB, w_pk);
            res = check_feasible(Gp, Td, Kp, wc_target, pm_target, Gm_min_dB);
            return;
        end
        break;
    end
    res = struct('Kp', Kp, 'Pm', Pm, 'Gm', Gm, 'Wcp', Wcp, 'feasible', true);
end

function Kp = bisect_gm(Gp, Td, Gm_min_dB, w_pk)
% 二分收敛"|T(j·w_pk)| = 10^(-Gm_min_dB/20)"（算法同 17.5；lo/hi 需包围解）
    lim = 10^(-Gm_min_dB/20);  lo = 1e-6;  hi = 1;
    for it = 1:40
        mid = 0.5*(lo + hi);
        Tk = tf([mid 0],[1 0]) * Gp;   Tk.InputDelay = Td;
        if abs(evalfr(Tk, 1i*w_pk)) > lim, hi = mid; else, lo = mid; end
    end
    Kp = 0.5*(lo + hi);
end
```

```text
/* ---------- tun_check.c：固件侧常量与整定结果的交叉校验（上线自检） ---------- */
/* 常量来自 param_table.h，与正文算例同值；本函数在 1ms 慢任务里每次上电跑一次 */
typedef struct { const char *name; float kp; float ki_ts; float ref_kp; float ref_ki_ts; } tun_rec_t;

static const tun_rec_t TUN_TABLE[] = {
    { "g3_id_pi",  G3_KP_I,   G3_KI_I_TS,  1.44e-2f,  5.02e-4f },  /* 第14章算例 14-3（Kmod=Vdc/2=350V 口径） */
    { "pfc_id_pi", PFC_KI_KP, PFC_KI_KI_TS, 0.0217f, 4.93e-4f },   /* 第12章算例 12-2 */
    { "pfc_vd_pi", PFC_KV_KP, PFC_KV_KI_TS, 0.2000f, 1.40e-4f },   /* 第12章算例 12-3 */
    { "dc_il_pi",  DC_KI_KP,  DC_KI_KI_TS,  0.2938f, 9.23e-3f },   /* 第11章算例 11-2 */
};

uint8_t tun_selfcheck(void)
{
    uint8_t bad = 0;
    for (uint8_t k = 0; k < ARRAY_LEN(TUN_TABLE); k++) {
        const tun_rec_t *r = &TUN_TABLE[k];
        const float tol_kp = 0.02f * r->ref_kp, tol_ki = 0.02f * r->ref_ki_ts;
        if (fabsf(r->kp - r->ref_kp) > tol_kp || fabsf(r->ki_ts - r->ref_ki_ts) > tol_ki) {
            g_prot.fault |= PROT_F_TUN_MISMATCH;      /* 参数表被误改 → 记故障码并上报 */
            bad++;
        }
    }
    return bad;   /* 0 = 一致；非 0 = 参数表与整定文档不符，禁止并网/带载 */
}
```

> [!TIP]
> 为什么固件里也要校验参数：现场最常见的事故之一是"参数表被改过一个系数"（为临时压某个波形），改完忘记改回。tun_selfcheck()把"整定文档"变成可执行断言：参数漂移超过 2% 即报故障码并禁止带载。这条与第41章的黑匣子日志配合，可回溯"某次故障时的参数状态"。

| --- | --- | --- |
| 扫频实测 fc / PM / GM | 与闭式解预期一致 | fc 偏差 ≤20%，PM ≥45°，GM ≥6dB |

### 17.9 失败案例复盘：自动整定给出 PM = 87° 的"最优解"，上电就振荡

> [!CAUTION]
> 现象：自动化脚本报告"整定完成：fc = 202Hz、PM = 87°、Kp = 0.021"，上电后出现约 23kHz 的等幅振荡（正好是谐振频率）。定位路径：①抓振荡频率 23.2kHz = f0→ ②回算脚本指标（只搜了 PM，没有 GM 约束）→ ③按算例 17-1 的表算 |T(f0)| = 5.88 → GM = −15.4dB → ④加 GM ≥6dB 约束后脚本返回"无可行解"，据此改用电流内环。根因：目标函数定义错误（只有 PM），而该对象的真正约束是谐振点增益；PM 在远低于 f0的交越点处必然"漂亮"，属于虚假安全感。预防措施：①整定目标必须是"约束集合"（PM、GM、带宽、饱和、延迟）而不是单一指标；②脚本必须在无可行解时返回 infeasible；③整定评审检查表必须包含"谐振点增益"一行；④上机核对先做扫频复核，再带载。
