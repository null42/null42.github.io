**本章要解决的问题：** 用**一个** 控制器把 3、5、7、9、11…所有次谐波一起压下去。重复控制的理论依据是内模原理，代价是"慢"和"对频率敏感"。三个算例算清 N、Q、以及频率失配的后果。

### 27.1 结构与时序（一次讲清）

```text
        e(z) ──►[ S(z) ]──►[ kr·z^−m ]──┐
                                        ├──► u_rc(z) ──► 加到基波指令上
        ┌───────────────────────────────┘
        │   z^−N（延迟一个工频周期）
        └──[ Q(z) ] ◄── 低通（提高鲁棒性）

u_rc(z) = kr · z^−m · Q(z) · z^−N / (1 − Q(z)·z^−N) · e(z)

  N：一个工频周期的拍数 = fs/f0 = 18000/50 = 360
  Q(z)：低通/略小于 1 的常数（本例 0.95）——把"无限增益"放宽成"有限增益"，换取鲁棒性
  z^−m：相位补偿（数字延迟 1.5Ts + S(z) 滞后），m = 4 拍（27.6 手算）
  kr：增益（本例 0.3），越大收敛越快但稳定性越紧
```

### 27.2 算例 27-1：N 与稳态抑制能力（26dB 从哪来）

```text
稳态：对周期信号，1/(1 − Q·z^−N) 在基波整数倍频率处提供增益
  抑制倍数 = 1/(1 − Q)，Q = 0.95 → 1/0.05 = 20 倍 = 26.0 dB
  对照：3 次残余 1.33%/20 = 0.067%，5 次 0.80%/20 = 0.040%，7 次 0.57%/20 = 0.028%，
        9/11 次 0.21%/20 = 0.011%、0.15%/20 = 0.008%
  → 判据按实算：3/5/7 次各 ≤0.07%、9/11 次更低；
    五项 RSS = √(0.067²+0.040²+0.028²+0.011²+0.008²) ≈ 0.084%（判据 RSS ≤0.1%）
  → 对比第26章多点 PR：3~7 次残余 0.16%~0.26%，9/11 次压不动（环路增益仅 1.5/1.06）
  结论：重复控制对"高次"的优势明显；代价是动态（27.3）

N 的取值校验：N = fs/f0 = 18000/50 = 360（整数 ✓）
  若 f0 = 50.5Hz → N = 18000/50.5 = 356.44（非整数）→ 必须用"分数延迟/变长缓冲"或变采样
```

### 27.3 算例 27-2：收敛速度——秒级的代价

```text
误差每周期的衰减系数 α ≈ Q·|1 − kr·P(z)|（P 为对象在关键频率的增益）
  取 Q = 0.95、kr = 0.3、主要频段 |kr·P| ≈ 0.2：
    α ≈ 0.95×0.80 = 0.76 → 每周期（20ms）残余降到 76%

  达到 5% 残余所需周期数：0.76^n = 0.05 → n = ln0.05/ln0.76 = 3.00/0.2744 = 10.9 → 11 个周期 = 0.22 s
  达到 1% 残余：n = 4.61/0.2744 = 16.8 → 17 周期 = 0.34 s

  对照：阶跃扰动（非周期）时重复控制**帮不上忙**（它只认周期信号）
  → 正确的分工：动态由 PI/PR 负责（ms 级），稳态谐波由重复控制负责（百 ms 级）
  → 两条回路并联，重复控制只动"周期性误差"，不抢动态

判据：投入重复控制后 0.5s 内 THDu 落到稳态值（±10%）
```

### 27.4 算例 27-3：频率失配会让高频次"反向放大"

```text
电网 50.5Hz、N 仍取 360：
  每个周期相位错位 Δφ_h = 2π·h·(Δf/f0) = 360°·h·(0.5/50) = 3.6°·h
  h = 5：18°；h = 15：54°；h = 25：90°

抑制倍数 = 1/|1 − Q·e^{jΔφ_h}|
  h = 5 （18°）：|1 − 0.95∠18°| = |1−0.9036−j0.2936| = |0.0964−j0.2936| = 0.309 → 抑制 3.2（10.2dB）
  h = 15（54°）：|1 − 0.95∠54°| = |1−0.5584−j0.7685| = |0.4416−j0.7685| = 0.886 → 抑制 1.13（1.1dB）
  h = 25（90°）：|1 − 0.95∠90°| = |1−0−j0.95| = 1.379 → 抑制 0.73（**放大 1.37 倍**）✗

  → 没有频率自适应时，重复控制会把高次谐波（h≈25，1250Hz）放大 1.37 倍
  → 这也解释了"投入重复控制后某些高次反而变差"的现象

对策：
  ① 用 PLL 频率在线重算 N（推荐）：N = round(fs/f_grid)，并同时重算缓冲长度与相位补偿 m
  ② 把 Q 降到 0.9（抑制从 20 降到 10，但失配容忍度提高）
  ③ 限制重复控制的有效频段（只投入经过稳定判据确认的次数）
```

### 27.5 设计判据：圆心距稳定性 |Q − kr·S·P| < 1（逐频成立）

```text
重复控制收敛的逐频判据（对每个关心的谐波频率 ωh 都要成立，27.4 对策③ 的"稳定判据"即此式）：
  |Q(jωh) − kr·S(jωh)·P(jωh)| < 1
  几何含义：以 Q 为圆心画单位圆，kr·S·P 的频率轨迹必须整体落在圆内；
  P：被控对象在 ωh 处的频率响应（含内环），S：串联补偿器（27.6），kr：重复控制增益

本课程对象口径（第13章）：u_rc 以调制量增量（标幺）注入，从 u_rc 到误差 e 的等效对象
  P(jω) = (V_bus/2)/V_base × H_LC(jω)，V_base = 311V、H_LC = 1/(1 − ω²LC + jωL/R)
  （L = 1.5mH、C = 10µF、R = 24.2Ω，LC 谐振 1.3kHz；50/150Hz 远低于谐振 → 增益平坦）

判例 1（50Hz 基波）：
  ω²LC = 0.00148、ωL/R = 0.0195 → H_LC = 1.001∠−1.1°
  P = (400/2)/311 × 1.001∠−1.1° = 0.644∠−1.1°；kr·P = 0.3×0.644∠−1.1° = 0.193∠−1.1°
  |Q − kr·P| = |0.95 − 0.193∠−1.1°| = |0.757 + j0.004| = 0.757 < 1 ✓（圆心距 0.76）
  收敛率 α = Q·|1 − kr·P| = 0.95×0.807 = 0.77（27.3 取的 0.76 即由此而来）

判例 2（150Hz 3 次）：
  ω²LC = 0.0133、ωL/R = 0.0584 → H_LC = 1.012∠−3.4°
  P = 0.651∠−3.4°；kr·P = 0.195∠−3.4°
  |Q − kr·P| = |0.755 + j0.012| = 0.756 < 1 ✓（与基波几乎相同：150Hz 仍远离 LC 谐振）

两条工程纪律：
  ① 注入点与 kr 的单位必须配套：若 u_rc 改为以电流指令（A）注入，P 变成第13章外环口径的
     1/(sC)（50Hz 处 318.3∠−90°，13.2），kr 必须缩到 0.312/318 ≈ 1e-3 量级——
     单位不配套是重复控制"一投就发散"的第一大原因（0.312 = √(1−Q²)，P 呈 −90° 时的模长上限）
  ② 高频段靠 S(z) 收紧：|S| 随频率下降（27.6，1kHz 截止，1250Hz 处 0.62）把 25 次以上的
     kr·S·P 拉回圆内；扫频验收时逐次检查 |Q − kr·S·P|，任一次 >1 即禁止投入该频段
```

### 27.6 S(z) 设计与相位补偿拍数 m 的手算

```text
S(z) 取一阶低通（Tustin + 预畸变，第20章口径），兼顾"高频衰减"与"相位补偿基准"：
  S(z) = (1−q)/2 · (1 + z⁻¹)/(1 − q·z⁻¹)，q = (1 − tan(π·fc·Ts))/(1 + tan(π·fc·Ts))
  直流增益恒为 1；fc 越低高频衰减越强、相位滞后越大
  （内模 Q(z) 若不用常数 0.95，也可取同构一阶低通，q 同式：fc_Q 越低失配容忍越好、
    稳态抑制 1/(1−Q) 越小——与 27.4 对策② 是同一笔账）

算例：截止 1kHz、Ts = 55.6µs：
  tan(π×1000×55.6e-6) = tan(0.1747) = 0.1765
  q = (1 − 0.1765)/(1 + 0.1765) = 0.700
  → S(z) = 0.150×(1 + z⁻¹)/(1 − 0.700·z⁻¹)（0.150 = (1−q)/2；直流增益 0.150×2/0.300 = 1 ✓）
  在 25 次（1250Hz）处：|S| = 0.62、滞后 51.3°（= atan(1250/1000)，预畸变后与连续域一致）

相位补偿拍数 m（把"总滞后"折算成拍数再取整，按 25 次 = 1250Hz 设计点）：
  总滞后 = 数字延迟 1.5Ts（1.5 拍）+ S(z) 滞后 51.3°/(360°×1250×55.6e-6) = 51.3/25.0 = 2.05 拍
  m = round(1.5 + 2.05) = round(3.55) = 4
  （群延迟口径复核：τ_S = 1/(2π×1000) = 159µs = 2.86 拍 → 1.5+2.86 = 4.36 → 同样取 4）
  残留误差：250Hz 处欠补 0.31 拍（≈1.5°）、1250Hz 处过补 0.45 拍（≈11°）——
  单一 m 对全频段是折中，验收以"3/5/7 次相位差 ≤10°"为准（27.8）
```

### 27.7 代码：重复控制器（变长缓冲 + 自适应 N）

```c
/* ---------- rc.c：重复控制（Q=0.95、kr=0.3、m=4，N 由 PLL 频率决定） ---------- */
#define RC_N_MAX   400            /* 缓冲上限（覆盖 45Hz 以上：18000/400） */
#define RC_Q       0.95f          /* 低通系数（27.4 ②） */
#define RC_KR      0.30f          /* 增益（27.3） */
#define RC_M       4u             /* 相位补偿拍数（1.5Ts + S(z) 滞后 → 27.6 手算 m=4） */

typedef struct {
    float buf[RC_N_MAX];
    uint16_t n;                   /* 当前 N（= fs/f_grid） */
    uint16_t idx;
} rc_t;
static rc_t g_rc;
static float g_rc_delay[RC_M + 1];   /* +1：z^−m 移位要写到下标 RC_M，返回抽头也取 [RC_M] */

void rc_init(float f_grid_hz)
{
    uint16_t n = (uint16_t)(CTRL_FSW_HZ / f_grid_hz + 0.5f);
    if (n > RC_N_MAX) n = RC_N_MAX;
    g_rc.n = n;  g_rc.idx = 0;
    for (uint16_t k = 0; k < RC_N_MAX; k++) g_rc.buf[k] = 0.0f;
}

/* 每拍调用：输入周期误差 e（= 给定 − 反馈），输出修正量 u_rc */
float rc_step(float e)
{
    const float delayed = g_rc.buf[g_rc.idx];        /* z^−N */
    const float inner   = e + RC_Q * delayed;        /* 1/(1 − Q z^−N) 的等效状态更新 */
    g_rc.buf[g_rc.idx] = inner;
    g_rc.idx = (uint16_t)((g_rc.idx + 1) % g_rc.n);

    float out = RC_KR * inner;                       /* kr 增益 */
    for (uint8_t k = RC_M; k > 0; k--) {             /* z^−m 相位补偿：整条延迟链后移一拍 */
        g_rc_delay[k] = g_rc_delay[k-1];             /* k = RC_M..1，数组长度必须为 RC_M+1 */
    }
    g_rc_delay[0] = out;
    return g_rc_delay[RC_M];                          /* z^−m 抽头：本拍返回 m 拍前的 out */
}

/* 频率变化时重算 N（27.4 对策①）；缓冲清零避免错位冲击 */
void rc_retune(float f_grid_hz)
{
    const uint16_t n_new = (uint16_t)(CTRL_FSW_HZ / f_grid_hz + 0.5f);
    if (n_new == g_rc.n || n_new > RC_N_MAX) return;
    rc_init(f_grid_hz);
}
```

### 27.9 失败案例复盘：N 固定 + 电网偏移，高次谐波被放大

> [!CAUTION]
> 现象：投入重复控制后 THDu 总体从 1.1% 降到 0.4%，但 1250Hz 附近出现明显凸起，THD（宽频口径）反而升高；现场电网长期 50.4~50.6Hz。定位路径：①看频谱（25 次附近凸起）→ ②按 27.4 计算相位失配（50.5Hz、h=25 时 Δφ = 90° → 抑制 0.73 = 放大）→ ③确认代码中 N 固定为 360 → ④加频率自适应后凸起消失。根因：重复控制的内模周期与实际电网周期不匹配，相位条件在高次失效并进入放大区。预防措施：①N 必须由 PLL 频率在线重算（rc_retune()）；②投入前先用 27.4 的公式扫一遍 2~50 次，确认无放大区；③把"高次不放大"写进验收判据（本课程列入 LAB3）；④保留"一键退出重复控制"的调试通道（第37章）。

### 27.11 练习

1. **E1** Q 从 0.95 降到 0.90：算稳态抑制倍数与"h=25 在 50.5Hz 下的放大倍数"；说明 Q 的取值是"抑制能力 vs 频率容忍度"的折中。
