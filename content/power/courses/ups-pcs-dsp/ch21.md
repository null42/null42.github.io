**本章要解决的问题：** 双环结构在第11~14章反复使用，本章把它讲透：内外环带宽比为什么必须 ≥5、采样时刻与 PWM 更新时序能省多少相位、功率前馈与母线前馈的收益边界。

### 21.1 双环的三个"必须"

| 要求 | 理由 | 违反后果 | 本章算例 |
| --- | --- | --- | --- |
| 内环带宽 ≥ 外环 5 倍 | 外环设计时才能把内环近似为"1" | 外环相位裕度被内环吃掉十几度 | 21-1 |
| 内环采样必须与载波对齐 | 采到的是平均电流而非纹波峰谷（第5章） | 过零/轻载畸变，且闭环增益修不掉 | 21-2 |
| 内环限幅先于外环限幅 | 内环指令是物理电流的"承诺" | 外环积分器冲过头 → 退饱和迟缓（第11章 11-4） | 21-4 |

### 21.2 算例 21-1：内外环带宽比差 2.5 倍，白送 15.3° 相位

```text
外环把内环闭环近似为 1/(1 + s/ωci)，在内环带宽处的相位滞后直接影响外环：
 比值 5（内环 10kHz、外环 2kHz）：滞后 = atan(2/10) = 11.31°
 比值 2（内环 4kHz、外环 2kHz）： 滞后 = atan(2/4) = 26.57°
 比值 1（内环 = 外环）： 滞后 = 45.00°
→ 带宽比从 5 掉到 2，就白送 15.3° 相位裕度；比值 1 时几乎不可能稳定

对本课程（18kHz 平台）的实用取值：
 外环电压环 ~350~500Hz（第13章 455Hz）；内环电流环 1~1.8kHz（受 1.5Ts 延迟限制）
 → 比值只有 2~4.5 倍，已经进入"要吃相位"的区间
 → 这正是"必须把延迟压下来"的根本原因（见 21-3）
```

### 21.3 算例 21-2：单更新 vs 双更新，省 27°

```text
延迟链（第10章）：ZOH 0.5Ts + 计算延迟 1.0Ts = 1.5Ts = 83.3µs（18kHz）

单更新（每个载波周期算一次、在周期起点更新）：
 在 1.8kHz 处的相位滞后 = 360°×1800×83.3e-6 = 54.0°

双更新（在载波峰、谷各算一次并立即更新）：
 等效延迟 = 0.75Ts = 41.7µs
 在 1.8kHz 处的相位滞后 = 360°×1800×41.7e-6 = 27.0° ← 省下 27°

双更新的三个前提（缺一不可）：
 ① ADC 采样也必须在峰谷对齐（否则采到的是纹波峰/谷）
 ② ISR 必须在半个载波周期内算完：18kHz → 半周期 3,333 周期，
 第3章实测 ISR 平均 2,020、最坏 2,600 周期 → 满足 （余量 733 周期）
 ③ 双更新下 dq 变换用的角度必须用"当前拍"的角度，不能再用上一拍缓存

收益换算：同样的 PM 下，外环交越可提高约 1.3 倍；或反过来把第13章的 46.4° 提到 55° 以上。
```

### 21.4 算例 21-3：母线前馈——把"环路要干的活"送给前馈

```text
场景：母线电压从 400V 跌到 380V（−5%），要求输出电压变化 ≤1%
 ① 靠环路抑制：输出变化 = 5%/(1+T)
 需要 T ≥ 4 才能压到 1%；要压到 0.25% 需要 T = 20
 在 400V 母线上，逆变器的输入扰动传递函数近似直通 → 提高 T 意味着提高带宽 → 与延迟矛盾
 ② 加母线前馈（调制量 = 环路输出 / u_bus，即 d_ff = v_ref/u_bus）：
 残余 = 5% × 前馈通道精度（含采样标定 0.5%）= 5%×0.5% = 0.025% 
 且这个收益与"环路带宽"无关——前馈是"开环补偿"，不依赖增益

前馈的三条纪律：
 ① 前馈通道必须与反馈通道同时标定（增益误差直接变成输出误差）
 ② 前馈不改变环路稳定性，但会改变"限幅前的指令"，必须一起参与限幅
 ③ 前馈量必须限幅（母线极低时 d_ff 会超过 1）
```

### 21.5 算例 21-4：双环限幅的配合与退饱和

```text
三层限幅（第11章代码的结构，本章给出参数配合规则）：
 ① 内环输出（调制量）限幅：|m| ≤ 0.95（第13章）——保证线性调制区
 ② 内环指令（电流）限幅：|i_ref| ≤ 1.4×I_pk（第13章 18A）
 ③ 外环输出（即内环指令）先被 ② 限幅，再交给内环

配合规则（用数字验证）：
 启动时外环误差 311V（满载峰值），PR 增益 0.6314 → 外环输出 = 196A，远超限幅 18A
 → 内环指令被限在 18A（约 1.4 倍额定峰值），启动电流可控 
 → 外环积分器必须同时被"冻结/反算"（否则退饱和要 0.44s，第11章 11-4）

判据：启动电流峰值 ≤1.5×I_pk；启动到稳态 ≤20ms（验收表 A 组）
```

### 21.6 代码：双环 ISR 的时序骨架

```c
/* ---------- 21.6 双更新双环 ISR 骨架（18kHz 载波 → 双更新下 ISR 实际执行 36kHz 等效） ---------- */
/* 时序：载波峰/谷 → ADC SOC 触发 → ISR → 立即更新比较值（双更新） */
void inv_dual_isr(void)
{
 /* ① 读采样（峰/谷对齐采到的是平均值，第5章） */
 const float v_out = adc_to_volt(g_adc.raw_vout, &g_adc.cal_vout);
 const float i_l = adc_to_amp (g_adc.raw_il, &g_adc.cal_il);
 const float i_c = adc_to_amp (g_adc.raw_ic, &g_adc.cal_ic);
 const float u_bus = adc_to_volt(g_adc.raw_vbus, &g_adc.cal_vbus);

 /* ② 角度：双更新必须用当前拍角度（不能用上一拍的缓存） */
 const float th = pll_get_theta();
 const float v_ref = INV_VREF_RMS * SQRT2_F * sinf(th);

 /* ③ 外环 PR：电压 → 电流指令（含 ② 限幅与抗饱和） */
 float i_ref = pr_step(v_ref - v_out);
 i_ref = clampf(i_ref, -INV_ILIM_A, INV_ILIM_A);

 /* ④ 内环 P + 有源阻尼 + 母线前馈（21-3） */
 const float inv_ubus = 1.0f / (u_bus + 1.0f); /* +1V 防除零 */
 float m = (INV_KP_I * (i_ref - i_l) - INV_KD_DAMP * i_c) * inv_ubus * INV_UBUS_V;
 m = clampf(m, -INV_M_LIMIT, INV_M_LIMIT); /* ① 调制量限幅 */

 pwm_set_unipolar(pwm_inv, m);
 adc_clear_soc_flag();
 Interrupt_clearACKGroup(ISR_INV);
}

/* 双更新配置自检：确认 ADC 触发点与载波峰/谷对齐、ISR 在半周期内完成 */
uint8_t dual_update_check(void)
{
 if (EPWM_getCounterMode(EPWM_INV) != EPWM_COUNT_MODE_UP_DOWN) return 1u; /* 必须增减计数 */
 if (!ADC_socIsTriggeredAtPeakAndValley(ADC_INV)) return 2u;
 if (task_get_isr_cycles_max() > 3333u) return 3u; /* 半周期预算：双更新下 ISR 必须在半载波（3333 计数）内完成，全载波 6667 */
 return 0u;
}
```

### 21.7 上机核对（LAB0/LAB1）

| 步骤 | 该看到什么 | 判据 |
| --- | --- | --- |
| 延迟标定（单/双更新） | GPIO 打点测"指令→生效"延迟 | 单更新 83.3µs、双更新 41.7µs（±0.2Ts） |
| 内环扫频 | PM/带宽与设计一致 | 内环 PM ≥45°、带宽 1~1.8kHz |
| 带宽比核算 | 用实测两环带宽算比值 | ≥2（本平台）并记录进裕度表 |
| 母线阶跃（400→380V） | 输出变化 | 加前馈后 ≤0.1%（预测 0.025%） |
| 启动电流 | 峰值电流 | ≤1.5×I_pk 且 ≤20ms 到稳态 |
| 双更新自检 | `dual_update_check()` 返回 0 | 三项配置逐条通过 |

### 21.8 失败案例复盘：内环用"上一拍角度"，双更新反而变差

> [!CAUTION]
> 现象：把单更新改成双更新后，理论上应多出 27° 相位裕度，实测却出现约 1.8kHz 的振荡，THDu 反而恶化。定位路径：①对比改动前后代码（发现 dq/正弦查表仍用"上一拍缓存的角度"）→ ②双更新下同拍两次运算用同一个角度 → 等效引入 0.5Ts 的角度误差（50Hz 下虽小，但电流环看到的旋转矢量滞后被放大）→ ③改为"每拍重新取角度"后振荡消失。根因：双更新改变了"每拍的物理含义"（一拍 = 半个载波周期），但角度更新频率没跟上。预防措施：①双更新必须成对修改：采样触发、角度、PWM 装载三处；②改动后必须重跑延迟标定与扫频；③把"角度来源与更新频率"写进设计说明（第29章会给出 PLL 的更新接口约定）。

### 21.10 练习

1. **E1** 内环 1.8kHz、外环 455Hz：算内环在外环交越处的相位滞后，并与"内环 1kHz"的情况比较，说明第13章 PM 46.4° 中内环贡献了多少。
2. **E2** 双更新下 ISR 最坏 2,600 周期、半周期预算 3,333（18kHz 半载波计数）：算余量百分比；若把载波提高到 32kHz（半周期 1,875 周期），哪些功能必须移出 ISR（提示：第4章五件事与第37章任务划分）。
3. **E3** 母线前馈精度 1%（标定偏差翻倍）：重算 21-3 的残余误差；若要求 ≤0.05%，前馈通道精度必须做到多少？（参考答案见 [练习参考答案](/posts/power/courses/ups-pcs-dsp/docs/answers/)）

### 21.11 补充：硬件延迟补偿（对照参考工程 Alg_HardwareDelayCmpn）

本书第10章把延迟算清楚了（1.5Ts = 83.3µs），第21章把延迟降下来了（双更新 0.75Ts）。参考工程还有第三种做法：**不去减延迟，而是在控制里把它补掉**（`Alg_HardwareDelayCmpn`）。三者不冲突，可以叠加使用。

```text
延迟链的完整构成（比 1.5Ts 更细）：
 ADC 采样保持 + 转换 0.37µs（第5章 5.10）
 控制计算到比较值生效 1.0Ts = 55.6µs
 ZOH（脉宽保持） 0.5Ts = 27.8µs
 采样通道模拟滤波（第9章 9-3：2kHz 一阶 → 1.8kHz 处 42° 相位）+ 驱动传输延迟 ~1µs
 → 总等效延迟 T_d ≈ 83.3µs + 滤波器相位（折算时延）

三种补偿做法与定量：
 ① 相位前移（最常用，成本最低）：把参考角度/指令按其谐波频率提前 θ = 2πf·T_d
 50Hz：θ = 2π×50×83.3e-6 = 1.50°；250Hz：7.49°；1.8kHz：54°（到带宽处已无法"前移"，只能改结构）
 参考工程用固定补偿角实现：cos(1.9°) = 0.99945022、sin(1.9°) = 0.03315518
 1.9° @50Hz ⇔ 105.6µs 等效时延 ≈ 1.5Ts(83.3µs) + 模拟滤波与驱动延迟 与本书账目一致
 ② 一步预测（对直流/缓变量有效）：x̂[k] = 2x[k] − x[k−1]，等效超前 0.5Ts = 27.8µs
 1.8kHz 处补偿 atan(2π×1800×27.8e-6) = 17.7°；噪声放大 √(1+(2πf·Ts)²) = √(1+0.6283²) = 1.18 倍
 → 收益是"省 17.7° 相位"，代价是"多 18% 噪声"，必须在第18章滤波器设计里抵扣
 ③ 模型补偿：用已知延迟与对象模型估计"延迟造成的误差"，在指令上叠加修正项
 适用：延迟固定而对象已知的场合（DC-DC 的固定计算延迟）；不适合延迟随负载变化的场合

收益换算（本平台口径）：
 把等效延迟从 1.5Ts 补偿到 0.55Ts：1.8kHz 处相位从 54° 降到 19.8°
 → 同样 PM 下交越可提高约 1.5 倍；或在原交越下把 PM 从 30° 提到 64°
纪律（三条，缺一不可）：
 ① 补偿量必须限幅（建议 ≤10° 等效相移），否则参数漂移时变成"过补偿"→ 反向滞后
 ② 补偿依赖"延迟已知"，必须由延迟标定（第10章 LAB0 打点）给出，并随温度/工况复核
 ③ 补偿后必须重扫频：比较 1.8kHz 处相位与设计值（±3°），并确认 THDu 与动态指标不变差
判据：补偿前后各扫一次频，1.8kHz 处相位改善与设计值偏差 ≤3°；THDu 不上升；阶跃恢复时间不延长
```
