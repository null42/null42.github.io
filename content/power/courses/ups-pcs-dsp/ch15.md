**本章要解决的问题：** 把第8章的拓扑全景推进到三电平：器件电压应力减半带来的收益有多大、代价是什么（中点电位）、以及为什么**大功率 UPS/PCS 的主流是三电平**。三个算例分别算器件应力与损耗、中点电位波动、零序注入的电压利用率，并给出三电平调制 + 中点平衡的可编译代码。

### 15.1 三种三电平拓扑（本章的选型表）

| 拓扑 | 每相器件 | 器件电压 | 通态损耗 | 典型用途 |
| --- | --- | --- | --- | --- |
| NPC | 4 管 + 2 钳位二极管 | Vdc/2 | 较高（外管串 2 只） | 中大功率逆变、整流 |
| TNPC | 2 高压管 + 2 低压管 | 外管 Vdc、内管 Vdc/2 | 低（通态路径短） | ≥10kW 逆变（本课程推荐） |
| Vienna | 1 管 + 4 二极管 | Vdc/2 | 低 | 三相三电平 PFC（单向） |

> [!IMPORTANT]
> 共同结构基础：分裂母线—— 正端 P、中点 O、负端 M，中点电位必须主动平衡。三电平的"额外难度"几乎全部来自这一个字的差别：多了一个要控的状态。

### 15.2 算例 15-1：器件应力、dv/dt 与通态损耗（接第8章 8-1 续算）

```text
系统口径：母线 700V（第8章），输出 380V/50kW（I_rms = 76A，I_pk = 107.5A）

① 器件耐压与裕量
 两电平：阻断 700V → 选 1200V，裕量 1200/700 = 1.71
 三电平：阻断 350V → 选 650V，裕量 650/350 = 1.86 更好

② dv/dt（同一关断时间 t_f = 100ns 下比较）
 两电平：700V/100ns = 7.0 V/ns
 三电平：350V/100ns = 3.5 V/ns
 → 共模干扰与绝缘应力下降一半；对 G4 组"漏电流 ≤3.5mA"这类指标直接有利

③ 通态电阻（SiC MOSFET 的 R_ds(on) 近似 ∝ V_BR^2.5）
 (1200/650)^2.5 = 1.846^2.5 = 4.63
 即 650V 器件的比导通电阻约为 1200V 的 1/4.63
 若 1200V 取 40mΩ，则 650V 对应约 8.6mΩ
 同电流下通态损耗比 = 8.6/40 = 0.215；考虑三电平通态路径的器件数增加（约 2 倍）
 → 相桥臂总通态损耗约为两电平的 0.43 倍（量级估算，精确值需按器件手册逐段积分）

④ 关断尖峰（杂散电感 100nH、di/dt = 500A/µs）
 ΔV = L_stray·di/dt = 100e-9 × 500e6 = 50 V
 两电平：(700+50)/1200 = 62.5% 占耐压比
 三电平：(350+50)/650 = 61.5% 占耐压比（基本持平，说明"三电平不需要更小的杂散电感"是误判）
```

### 15.3 算例 15-2：中点电位波动与电容容量（与第1章跨章对照）

```text
中点电流：三电平 O 状态时负载电流流入/流出中点，三相合成的低频分量为 3 次（150Hz）
保守估计取 O 状态电流幅值 I_O = 0.5·I_pk（精确波形需仿真，本处给量级）

 半周电荷吞吐 ΔQ = 2·I_O/(2π·3f) = 2×53.75/(2π×150) = 107.5/942.5 = 0.114 C
 中点波动 ΔV_O = ΔQ/(2·C_half) ← 口径依据（保留 /2 的原因）：中点电流使上下两只串联
 电容流过等量反号电荷（各 ΔQ/2，中点节点 KCL 严格结果），
 每只电容电压变化 ΔQ/(2·C_half)，中点偏移等于该值

第1章已算：50kW/20ms 保持时间 → 母线总电容 28.6mF → 每半母线 C_half = 14.3mF
 ΔV_O = 0.114/(2×14.3e-3) = 3.98 V = 350V 的 1.14% 远优于 ≤3% 的常规门槛

反算：若只按纹波要求设计（ΔV_O ≤3% = 10.5V），最少需要
 C_half ≥ ΔQ/(2×10.5) = 0.114/21 = 5.43 mF（总 10.9mF）
→ 保持时间（28.6mF）比中点平衡（10.9mF）更苛刻，所以"按保持时间选电容"同时满足中点要求
```

> [!IMPORTANT]
> 这是一条可复用的设计规则：先按保持时间定电容，再用中点波动校核（多数情况下自动满足）。若中点波动超标，优先用平衡控制而不是加电容——加电容会同时增加体积、成本与预充难度（第35章）。

### 15.4 算例 15-3：零序（三次谐波）注入把电压利用率提高 15.5%

```text
SPWM 线性区上限：相电压基波峰值 = Vdc/2 = 350V
三次谐波注入（幅值取基波的 1/6）后：
 v(θ) = A1·[sinθ + (1/6)sin3θ]
 求极值：f'(θ) = cosθ + 0.5cos3θ = cosθ(2cos²θ − 0.5) = 0
 θ = 90°：f = 1 − 1/6 = 0.8333
 θ = 60°：f = 0.866 + 0 = 0.8660 ← 峰值出现在这里
 → 峰值 = 0.866·A1 = (√3/2)·A1
 令峰值不超过 350V：A1 ≤ 350/0.866 = 404.1 V = Vdc/√3 （与 SVPWM 线性区上限一致）

收益换算：
 输出能力：350V → 404V 峰值，提升 404/350 = 1.155（+15.5%）
 或同样输出 311V 峰值时，调制比从 311/350 = 0.889 降到 311/404 = 0.770
 → 动态余量从 11% 提高到 23%（对"母线跌落 + 死区损失"的容忍度翻倍）
```

> [!TIP]
> 为什么"三次谐波"不算污染：三相三线制中三次谐波（零序）在中点处相互抵消，线电压与负载电流中不含它。这就是零序注入"白拿"15.5% 的原理——注入的是共模量，不进入差模输出。注意在四线制（第32章）里没有这个便利。

### 15.5 Vienna 三电平 PFC 的逐状态分析（单向整流的代表）

Vienna 归入本章的原因是它与 NPC/TNPC 共用分裂母线与中点，但它是**单向** 的：每相只有一个双向开关管（通常是两只 MOSFET 共源串联，实现双向电压阻断）与四个二极管，电流路径由二极管决定，因此只能整流、不能逆变。用在三相 PFC 上，器件数比两电平六管少，且每管只承受 Vdc/2。

```text
每相的两种动作（以 A 相、相电压正半周 i_a > 0 为例）：
 开关导通（S=1）：输入经开关管接到中点 O，电感电流由 O 提供（上半母线基本不参与）
 开关关断（S=0）：电感电流经上二极管流入 P，给上电容充电（抬升输入电压）
负半周对偶：开关导通 → 接 O；关断 → 经下二极管流入 M

三相组合 = 3³ = 27 种状态，但每相只有"接 O / 接 P（或 M）"两种有效选择
中点电流：i_O = Σ d_O,x · i_x —— 与 NPC 逆变器同结构，因此中点平衡问题与手段完全一致（15.3/15.7）

工程要点：
 ① 电流方向决定路径：正半周关断才充电、负半周关断才充电（对偶），因此
 **正负半周的控制增益天然对称，但中点电流的符号随电流方向翻转**
 ② 器件电压应力 V_dc/2 = 350V（700V 母线）→ 可用 650V 器件，裕量 1.86（第8章 8-1 同口径）
 ③ 无反向功率能力：电池放电或需要双向运行时不能选 Vienna（改用该章的 NPC/TNPC 或第16章 DAB/CLLC）
 ④ 器件级连接与钳位细节以原理图与器件手册为准（本书不凭记忆写死拓扑细节）
```

### 15.6 并联三电平：总流-差流分解与交错候选方案

大功率机型常把两套（或多套）三电平桥臂并联，以降低单套电流应力、分摊热、并实现 N+1。并联之后必须把电流拆成两个量来管理，这是与第38章"模块并联"最本质的区别（那里管的是环流度，这里管的是**支路差流**）。

```text
定义（以两套并联为例）：
 总流 i_Σ = i_1 + i_2 ← 供给负载/电网的有效电流
 差流 i_Δ = (i_1 − i_2)/2 ← 在两套桥臂之间循环，不经过负载，占容量、发热

差流的激励与回路：
 激励 = 两套桥臂之间的平均电压差 ΔV（来自 PWM 相位差、占空比差异、器件压降差、中点电位差异）
 回路阻抗 Z_Δ = 两套桥臂的输出感抗之和（同一 LCL 参数下 = L1 + L1'）

 数值（50kW/380V，第14章 LCL：L1 = 800µH、L2 = 200µH、fsw = 18kHz）：
 同相并联（两套载波同相）：
 Z_Δ(50Hz) = 2π×50×(0.8m+0.8m) = 0.503 Ω
 ΔV = 5V（器件压降与相位误差的综合量级）→ i_Δ = 9.9 A（13% 额定 76A） 需主动抑制
 交错并联（两套载波错开 180°）：
 差流回路的激励变成"2 倍载波频率的纹波差"（2fsw = 36kHz）
 Z_Δ(36kHz) = 2π×36000×1.6m = 362 Ω
 同量级的纹波电压（≈5V）→ i_Δ = 13.8 mA（可忽略）
 → 交错把差流从"低频大电流"变成"高频小纹波"，靠感抗天然抑制

三种候选方案对比（做方案书时按此表逐项填数）：
 方案 差流成分 总流纹波 采样窗口 均流手段
 同相并联 含基波与低频 与单套相同 宽松（开关时刻相同） 通信均流 + 差流阻尼环
 交错并联 以 2fsw 为主 按 N·D 抵消 窄（须避开两套开关沿） 通信均流（差流已很小）
 多支路交错 以 N·fsw 为主 最优 最窄 同上 + 相数投切（第11章）

选择依据（本课程口径）：
 ① 差流度 ≤5%（与第38章环流度同量级要求）
 ② 总流纹波：设计点尽量落在 N·D ≈ 整数附近（第11章 11-8 的公式直接套用）
 ③ 采样窗口：交错后必须重排 ADC 触发时刻，保证采样点与最近开关沿间隔 ≥1µs
 ④ 单套故障退出：剩余套电流上升 ≤2 倍额定、差流在 2ms 内重新分配
```

### 15.7 有源中点平衡与三开关双电感直流支路

15.4 的零序注入属于"软平衡"：它只能在调制上调整 O 状态的时间占比，靠负载电流本身把电荷搬过去。当负载电流很小（空载不平衡）、或上下电容漏电流不等、或需要快速修正较大的直流偏差时，软平衡能力不足，需要"硬平衡"——在中点上挂一条独立的双向 DC-DC 支路，直接在两电容之间搬运电荷。

```text
功能定义（三开关双电感直流支路）：
 两个电感分别跨接在 P–O 与 O–M 之间，三个开关管把能量在两段母线之间搬运
 （具体是"中点半桥 + 电感"还是"双向 Buck/Boost + 第三管"取决于偏差范围与损耗要求；
 器件级连接以原理图为据，本书只给功能与定量）

定量设计（以 50kW 机型、第1章 28.6mF 母线电容为基准：C_half = 14.3mF）：
 要把中点偏差 ΔV = 20V 在 t = 1s 内消除：
 需搬运电荷 Q = C_half·ΔV = 14.3e-3 × 20 = 0.286 C
 平均搬运电流 I_bal = Q/t = 0.286 A
 若要求在 100ms 内消除（应对突加不平衡）：I_bal = 2.86 A
 → 支路功率 = 350V × 2.86A = 1.0 kW（瞬时），持续器件可小得多（按 10% 占空比选）
 → 电感选择（18kHz、ΔI = 20%×2.86A = 0.57A、D = 0.5）：
 L = V·D(1−D)/(ΔI·fsw) = 350×0.25/(0.57×18000) = 8.5 mH
 （电流小、电感大，磁件体积与 50kW 主电感相比可忽略）

控制：
 平衡环为 PI（中点偏差 → 搬运电流指令），带宽 20~50Hz
 带宽上限的理由：必须远低于 3 次谐波（150Hz），否则会与零序注入/谐振器抢动作；
 下限的理由：要快于电容漏电流与轻载不平衡引起的最慢漂移（秒级）

与零序注入的分工（两者同时使用，不互相替代）：
 零序注入（软）：每拍可动、无需额外硬件；受负载电流与调制比限制，轻载时失效
 直流支路（硬）：与负载电流无关，能修正空载不平衡与电容参数差异；需要额外器件与控制环
 判据：中点偏差在任何负载（含空载）下 ≤1%；偏差修正到 0 的时间 ≤100ms
```

### 15.8 代码：三电平调制 + 零序注入 + 中点平衡

```c
/* ---------- param_table.h：常量来源（15.3~15.4） ---------- */
#define TL_UBUS_V     700.0f        // V，母线（第8章）
#define TL_VHALF_V    350.0f        // V，半母线（= 0.5×TL_UBUS_V）
#define TL_FSW_HZ     18000.0f      // Hz，平台统一
#define TL_KBAL       0.02f         // 中点平衡比例增益（1/V，量级由 15.3 的波动幅值定）
#define TL_VBAL_LIM   0.05f         // 平衡偏置限幅（归一化，≤0.05 即 ≤5% 调制量）
#define TL_SOC_LO     0.20f         // P/N 状态归一化阈值：|x| ≤ 0.20 → O，否则 P/N（与 tl_pick 一致）

/* 三电平状态：N=0 / O=1 / P=2 */
typedef enum { TL_N = 0, TL_O = 1, TL_P = 2 } tl_state_t;

/* ① 由归一化参考（−1~1，以半母线为基准）判定状态：|x| ≤ 0.20（TL_SOC_LO）→ O */
static tl_state_t tl_pick(float x)
{
 if (x > TL_SOC_LO) return TL_P;
 if (x < -TL_SOC_LO) return TL_N;
 return TL_O;
}

/* ② 零序注入：min-max 中点法（等效 SVPWM，15.4 的 +15.5% 就是它带来的） */
static void tl_zero_seq(const float vabc[3], float vout[3])
{
 float vmax = vabc[0], vmin = vabc[0];
 for (uint8_t k = 1; k < 3; k++) {
 if (vabc[k] > vmax) vmax = vabc[k];
 if (vabc[k] < vmin) vmin = vabc[k];
 }
 const float off = -0.5f * (vmax + vmin); // 注入量与基波同频的共模
 vout[0] = vabc[0] + off; vout[1] = vabc[1] + off; vout[2] = vabc[2] + off;
}

/* ③ 中点平衡：把上下母线电压差折成零序偏置 */
static float tl_balance_offset(void)
{
 const float vp = adc_to_volt(g_adc.raw_vp, &g_adc.cal_vp); // P–O
 const float vn = adc_to_volt(g_adc.raw_vn, &g_adc.cal_vn); // O–M
 float off = TL_KBAL * (vp - vn) / TL_VHALF_V; // 归一化
 return clampf(off, -TL_VBAL_LIM, TL_VBAL_LIM); // 限幅：别把调制吃掉
}

/* ④ 三相一次算完，写入三电平 PWM（本课程用 ePWM + 状态表，第8章 8.5） */
void tl_modulate(const float vref[3])
{
 float v0[3];
 tl_zero_seq(vref, v0); // 零序注入
 const float bal = tl_balance_offset(); // 中点平衡偏置
 for (uint8_t k = 0; k < 3; k++) {
 const float x = v0[k] + bal; // 平衡量也走零序（共模）
 const tl_state_t st = tl_pick(x);
 pwm_write_leg_tl((pwm_leg_t)k, st, fabsf(x)); // 状态 + 占空比残量
 }
}
```

> [!WARNING]
> 方向性与校核：中点平衡的符号方向与电流方向、拓扑（NPC/TNPC）相关，代码里的off符号必须在台架上用"人为制造 20V 中点偏差"验证：接通平衡后偏差应在 1s 内收敛到 0 附近。极性写反会变成正反馈，中点偏差会发散直到器件过压（见 15.7 复盘）。

### 15.10 失败案例复盘：平衡极性写反，中点偏差发散炸管

> [!CAUTION]
> 现象：低压台架正常，上高压运行约 40s 后报上下管过压，拆机发现 A 相上管击穿，上下母线电压分别为 355V / 345V（偏差已到保护边界）。定位路径：①录中点电压（发现偏差 |VP− VN| 从 5V 缓慢单调增长到 10V，对应上下母线 355V / 345V，无自愈）→ ②检查平衡代码（off的符号与设计文档相反）→ ③查设计文档发现"符号方向"只在注释里写了一句"以实测为准"，没有验证记录 → ④改正符号并做偏差注入测试后收敛。根因：中点平衡的符号方向未经验证；反向即正反馈，偏差单调发散。预防措施：①平衡环必须做"人为偏差注入 + 收敛验证"（本课程列为 LAB5 固定项）；②中点电压纳入保护矩阵（第36章）：|VP− VN| 超过 10% 即降额、超过 15% 即停机；③上下母线分别采样（不能只测总母线），否则无法发现偏差；④平衡偏置必须限幅，避免"为了平衡把调制吃掉"。
