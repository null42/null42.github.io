**本章要解决的问题：** 同一台 50kW 变流器在不同场景要扮演不同角色：跟网（PQ 控制）、离网（VF 模式）、无通信并联（下垂控制）、跌压穿越（LVRT）。三个算例给出功率指令换算、下垂系数与 LVRT 电流分配。

### 33.1 四种策略的适用与切换

| 模式 | 需要电网提供 | 控制量 | 切换触发 |
| --- | --- | --- | --- |
| PQ（跟网） | 相位基准（PLL） | id/iq 指令 | 并网开关合闸 |
| 下垂（并联离网） | 无（无通信） | f、V 的 P/Q 修正 | 孤岛/并机 |
| VF（单机离网/黑启动） | 无 | v 与 f 基准 | 孤岛检测动作/孤岛后 |
| VVVF | — | v/f 比恒定（电机类负载） | 特定负载需求 |

### 33.2 算例 33-1：PQ 指令换算（把 kW/kVar 变成 id/iq）

```text
等幅 dq 约定下（第14章）：P = 1.5·V_d·i_d，Q = −1.5·V_d·i_q（V_d 为相电压峰值）
 380V 线电压 → 相电压峰值 311V（V_d = 311V，锁定后 V_q ≈ 0）
 P = 50kW → i_d = 2P/(3·V_d) = 100000/(3×311) = 107.2 A（峰值）
 对应有效值 = 107.2/√2 = 75.8 A （与 76A 一致，交叉校验通过）
 Q = 30kVar（感性）→ i_q = −2Q/(3·V_d) = −60000/933 = −64.3 A（峰值）

限幅：|i_dq| ≤ 1.1×107.2 = 118A（峰值），并按"优先有功"分配（LVRT 时反过来优先无功）
```

### 33.3 算例 33-2：下垂系数（无通信并联的均分精度）

```text
P–f 下垂：f = f0 − m·(P − P0)，m 单位 Hz/W
 要求：满载（50kW）时频率下垂 ≤0.5%（0.25Hz，避免影响负载）
 m = 0.25/50000 = 5.0e-6 Hz/W
 两个模块功率差 ΔP 时的频率差 = m·ΔP → 环流由"频率差 → 相位差 → 电流差"决定
 若两模块功率分配偏差 10%（5kW）→ 频率差 = 5e-6×5000 = 0.025Hz → 相对相位缓慢漂移
 → 均分精度靠"频率差积分成相位差"的自平衡机制保证，稳态误差取决于 m 与线路阻抗

Q–V 下垂：V = V0 − n·Q，取额定 30kVar 时压降 ≤2%（4.4V）
 n = 4.4/30000 = 1.47e-4 V/Var

判据：并机功率不平衡度 ≤5%（验收表 E 组）；下垂 + 通信均流（第38章）配合时可达 ≤2%
```

### 33.4 算例 33-3：LVRT 的电流分配与限幅

```text
要求（IEEE 1547 口径）：电网跌压期间不脱网，按跌压深度注入无功
 无功电流指令：i_q,ref = k·(0.9 − V_pu)·I_N，k 取 2（典型 2~4），限幅 ≤1.0·I_N
 有功电流：i_d,ref = √(I_max² − i_q,ref²)，I_max = 1.1·I_N（总电流不超过 1.1 倍额定）

数值（I_N,peak = 107.2A）：
 V_pu = 0.5（跌 50%）：i_q = 2×(0.9−0.5)×107.2 = 85.8A（峰值）
 i_d = √(1.1×107.2)² − 85.8² = √(13909−7362) = 80.9A
 V_pu = 0.2（深跌）：i_q = 2×0.7×107.2 = 150.1A → 限幅到 107.2A（1.0 pu）
 i_d = √(13909−11492) = 49.2A
 V_pu = 0（零电压穿越）：i_q = 107.2A（全部无功），i_d → 0
 注：直流侧必须能在"有功无法外送"时吸收能量（母线电压上升），否则过压保护动作
 → 与第16章 DC-DC 的协同：多余能量转充电池（这就是"PCS + 储能"的优势）
```

### 33.5 代码：模式管理与指令生成

```c
/* ---------- grid_mode.c ---------- */
typedef enum { GM_PQ = 0, GM_DROOP, GM_VF, GM_LVRT } gmode_t;
#define GM_IN_LIM_A    118.0f        /* 峰值电流限幅 1.1×107.2（33-1） */
#define GM_LVRT_K      2.0f          /* 无功支撑系数（33-3） */
#define GM_DROOP_M     5.0e-6f       /* P–f 下垂（Hz/W，33-2） */
#define GM_DROOP_N     1.47e-4f      /* Q–V 下垂（V/Var） */
#define GM_F0_HZ       50.0f         /* 下垂空载频率基准（33-2） */
#define GM_V0_PK       311.0f        /* 下垂空载电压峰值基准（33-2） */
#define GM_P0_W        0.0f          /* 下垂基准有功 */
#define GM_Q0_VAR      0.0f          /* 下垂基准无功 */

static gmode_t g_mode = GM_PQ;

/* 每拍（或 1ms 任务）计算 dq 参考指令 */
void grid_mode_step(float v_pu, float p_ref_w, float q_ref_var, float *id_ref, float *iq_ref)
{
 float id, iq;
 switch (g_mode) {
 case GM_PQ:
 id = 2.0f * p_ref_w / (3.0f * G3_VD_PK);
 iq = -2.0f * q_ref_var / (3.0f * G3_VD_PK);
 break;
 case GM_DROOP: { /* 下垂：P–f / Q–V 修正 f、V 基准（33-2） */
 const float f_ref = clampf(GM_F0_HZ - GM_DROOP_M*(grid_p_meas_w() - GM_P0_W),
 GM_F0_HZ - 0.25f, GM_F0_HZ + 0.25f); /* 限幅 ±0.25Hz（满载 50kW 下垂量） */
 const float v_ref = clampf(GM_V0_PK - GM_DROOP_N*(grid_q_meas_var() - GM_Q0_VAR),
 GM_V0_PK - 4.4f, GM_V0_PK + 4.4f); /* 限幅 ±2%（30kVar 压降 4.4V） */
 grid_vf_set_ref(f_ref, v_ref);
 grid_vf_step(id_ref, iq_ref); /* 下垂与 VF 同路：id/iq 由电压环给出，不走 PQ 公式 */
 return;
 }
 case GM_LVRT: { /* 33-3 的电流分配 */
 const float iq_lim = GM_IN_LIM_A;
 iq = GM_LVRT_K * (0.9f - v_pu) * (GM_IN_LIM_A / 1.1f);
 iq = clampf(iq, -iq_lim, iq_lim);
 const float id_sq = GM_IN_LIM_A*GM_IN_LIM_A - iq*iq;
 id = 0.0f;
 if (id_sq > 0.0f) id = sqrtf(id_sq); /* 有功按"总电流不超限"反算 */
 break;
 }
 case GM_VF: /* 离网：由电压/频率环给出，不用 PQ 公式 */
 default:
 grid_vf_step(id_ref, iq_ref);
 return;
 }
 id = clampf(id, -GM_IN_LIM_A, GM_IN_LIM_A);
 iq = clampf(iq, -GM_IN_LIM_A, GM_IN_LIM_A);
 *id_ref = id; *iq_ref = iq;
}

/* 模式切换必须清空指令相关积分/谐振器（第34章状态机统一管理） */
void grid_mode_switch(gmode_t m) { g_mode = m; grid_ctrl_reset(); }
```

### 33.7 失败案例复盘：LVRT 期间有功无处可去，母线过压脱网

> [!CAUTION]
> 现象：电网跌压试验中，电网跌到 0.3pu 后 15ms 内母线电压冲到 1.25 倍，过压保护动作脱网，不满足 LVRT 要求。定位路径：①看波形（i_q 正常注入、i_d 下降，但母线上升）→ ②核算能量（光伏/整流侧仍在送 40kW，而输出有功降到 50×0.3 = 15kW）→ ③确认多余 25kW 只能进母线电容 → ④启用"储能吸收"（第16章 DC-DC 反向给电池充电）+ 光伏/整流侧快速降功率后通过。根因：LVRT 只考虑了"电流指令"，没有做"功率平衡"的协同（能量流没规划）。预防措施：①LVRT 必须与 DC-DC/BMS 协同（第34/43章）；②把"母线过压"作为 LVRT 的联锁条件并记录；③验收时必须做"跌压 + 满功率"的最严工况（不是空载）。

### 33.10 补充：VSG（虚拟同步机）演进方向

下垂只有"静态斜率"：功率一变，f/V 沿斜率滑动，电网扰动瞬间没有惯性可借。VSG（虚拟同步机）把同步机的转子运动方程搬进控制器：**J·dω/dt = Pm/Pu − Pe/Pu − D·Δω**——虚拟惯量 J 决定扰动瞬间的频率变化率（先"扛"住 RoCoF），阻尼系数 D 决定稳态频差与振荡衰减；稳态 dω/dt = 0 时退化为与下垂同形的静差斜率。与下垂的差别一句话：** 下垂是静态斜率，VSG 在斜率之外还给系统加了"质量"——暂态有惯量支撑，稳态与下垂一致**。参数取向下限：J 按允许 RoCoF 反推，D 按稳态频差 ≤0.1Hz 取（与 33-2 的下垂量同量级）。完整演进路径（自适应 J/D、构网型标准与储能容量约束）详见第47章构网型。
