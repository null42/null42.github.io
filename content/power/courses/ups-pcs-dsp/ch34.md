**本章要解决的问题：** 把所有子系统串起来：**谁在什么时候有权控制母线电压**。核心是"母线电压的所有权"与"切换的前后条件"，以及三条能量流（市电→负载、电池→负载、负载→电池）如何协同而不打架。

### 34.1 母线电压的"所有权"表（本章最关键的一张表）

| 模式 | 母线电压由谁维持 | 其他支路的状态 | 切换前后条件 |
| --- | --- | --- | --- |
| 整流运行（在线/并网） | PFC/整流器电压环（第12章） | DC-DC 待机（可充电池） | 母线达 700V±5% 且整流环稳定 100ms |
| 电池放电 | DC-DC 电压环（第16章） | 整流器停机/降功率 | DC-DC 先建压、整流器后释放（避免两头抢） |
| 静置/待机 | 无（母线由电容维持） | 全部封波 | 母线降到阈值以下才允许停机 |
| 旁路（逆变退让） | 不需要（负载由电网供电） | 逆变做同步跟踪备用 | 第30章三同步判据 |

> [!IMPORTANT]
> 一条铁律：任何时刻只能有一个电压源控制母线。两个环同时"想控电压"会互相追逐（现象：母线低频振荡、功率来回摆）。所有切换都必须遵守"新接手者先建压、旧控制者后退出"的顺序。

### 34.2 算例 34-1：母线所有权交叠的时间代价

```text
若整流器与 DC-DC 同时控母线（都有电压环）：
  两个积分器各自累积误差 → 输出在 0~100% 之间来回推
  观察到的现象：母线出现 5~20Hz 的低频振荡，幅值可达 ±30V（±4%）
  定量：两个电压环带宽接近（10Hz 与 8Hz）时，耦合振荡频率 ≈ √(f1·f2) ≈ 9Hz

正确顺序（"先建压后释放"）：
  ① DC-DC 以电流限幅方式建压（I_lim = 0.5×额定 = 19A），母线保持 ≥95%
  ② 检测到母线由 DC-DC 稳定维持 ≥50ms（误差 ≤1%）
  ③ 整流器退出电压环（切为电流环/PQ）、DC-DC 接任电压环
  ④ 过渡时间预算：DC-DC 建立 20ms + 判定 50ms + 退出 10ms ≈ 80ms（对负载无影响，因母线未跌落）
  验收口径：市电↔电池切换 0ms（负载侧电压无中断，因为母线始终有源）
```

### 34.3 算例 34-2：能量流平衡的三种工况

```text
能量守恒：P_整流 + P_电池放电 = P_负载 + P_电池充电 + P_损耗

  ① 正常在线（负载 50kW）：P_整流 = 50/0.956 = 52.3kW，电池浮充 ≈0.1kW，损耗 2.3kW
  ② 电池放电（市电失电，负载 50kW）：P_电池 = 50/(0.956×0.98) = 53.4kW
     电流：53.4kW/384V = 139A（第0章跨章一致值）✓
  ③ 回充（市电恢复，负载 30kW）：先给负载 30kW，余量 52.3−30 = 22.3kW 用于充电
     充电电流上限（0.1C，384V/100Ah 电池组）：10A → 充电功率 3.84kW → 剩余 18.5kW 无处去
     → 必须由整流器降功率（电流环指令下调）→ 否则母线过压
  判据：任何工况下 |P_in − P_out − P_chg| ≤ 5% 额定（否则母线电压漂移）
```

### 34.4 算例 34-3：切换过渡的状态机时序（带数字）

```text
市电失电 → 电池放电（要求 0ms 负载中断）：
  限流口径（先算后定）：负载 50kW、电池 384V（34-3 ②）→ 承接满载需要 I ≥ 50000/384 = 130A
    → DC-DC 放电限流 I_lim 取额定 139A（34-3 ②：139×384 = 53.4kW，余量 6.8%）
    ⚠ 若限流取 0.5×额定（70A → 70×384 = 26.9kW）甚至更小，都承接不了 50kW，
      母线只会一路跌穿 −10% 限值——"限流值必须按最重负载校核"是本时间线的第一结论

  t=0      市电失电，检测启动（PLL 失锁或电压跌 20% 判据，第29章）
  t=10ms   判定失电（≤10ms，第29章口径）→ DC-DC 门极使能，电流从 0 向 139A 爬升
  t=10~15ms 电流建立段：缺口全部由母线电容补：50kW×5ms = 250J
           → V² = 700² − 2×250/0.0286 = 472,517 → V ≈ 687V（−1.8%）
  t=15~40ms DC-DC 功率从 0 线性爬到 53.4kW：缺口从 50kW 收窄（t≈38ms 过零）
           段内缺口能量 ≈ 25kW×23ms ≈ 583J → 累计 833J
           → V² = 490,000 − 2×833/0.0286 = 431,748 → V ≈ 657V（−6.1%，母线 ±10% 内 ✓）
  t≈40ms   DC-DC 功率 ≥ 负载（53.4kW > 50kW）→ 母线触底 ≈657V，开始回升
  t=40ms 起 剩余 3.4kW 回充电容：补回 833J 需 833/3400 ≈ 245ms → 约 t=285ms 回到 700V
           （过 95% = 665V 在 t≈85ms；"接管完成" = ≥95% 且稳定 50ms → 约 t=135ms）
  负载侧全程无感：母线 657V 时调制比 0.889 → 0.889×700/657 = 0.947（仍 ≤0.95 限幅）
           → 输出跌落 ≤1.5% ✓；0ms 指标考核的是负载电压，不是接管判定时刻
  关键：**母线电容的储能撑住这 30ms 缺口**（第1章 28.6mF；能量链每步可复算）

反例（不检测、等到母线跌到 600V 才动作）：母线跌 14% → 输出跌落 ≥10% ✗ 超差
```

### 34.5 代码：整机状态机骨架

```c
/* ---------- sys_fsm.c：整机模式状态机（1ms 任务运行，不做重活） ---------- */
typedef enum {
    SYS_OFF = 0, SYS_PRECHARGE, SYS_STANDBY, SYS_RECT, SYS_BATT,
    SYS_BYPASS, SYS_FAULT, SYS_MAINT
} sys_state_t;

typedef struct {
    sys_state_t st;
    const char *owner;              /* 当前"母线电压所有者" */
    uint32_t t_in_state_ms;
    uint16_t cond_ok_ms;
} sys_fsm_t;
static sys_fsm_t g_fsm = { SYS_OFF, "none", 0, 0 };

/* 状态转移表（条件全部来自"可测的量"，不依赖人工判断） */
static uint8_t sys_transition_ok(sys_state_t from, sys_state_t to)
{
    const float vbus = adc_to_volt(g_adc.raw_vbus, &g_adc.cal_vbus);
    switch (to) {
    case SYS_RECT:  return (vbus > 600.0f) && (pll_locked()) && (g_prot.fault == 0u);
    case SYS_BATT:  return (vbus > 600.0f) && (batt_voltage_ok()) && (bms_ready());
    case SYS_BYPASS:return scr_sync_ok();                     /* 第30章三同步判据 */
    default:        return 1u;
    }
}

void task_sys_fsm(void)
{
    const sys_state_t want = sys_decide_next_state();         /* 由故障/指令/电网状态决定 */
    if (want == g_fsm.st) {
        g_fsm.cond_ok_ms++;
        sys_on_state_hold(g_fsm.st, g_fsm.cond_ok_ms);        /* 稳定判定计数 */
        return;
    }
    if (!sys_transition_ok(g_fsm.st, want)) {                 /* 条件不满足 → 拒绝并告警 */
        g_status.trans_reject = (uint8_t)want;
        return;
    }
    sys_exit_state(g_fsm.st);                                 /* ① 退出：清积分/谐振器/前馈 */
    g_fsm.st = want;
    g_fsm.t_in_state_ms = 0;  g_fsm.cond_ok_ms = 0;
    sys_enter_state(want);                                    /* ② 进入：预置积分器、建压 */
    log_fault_event(EV_MODE_CHANGE, (uint16_t)want);           /* ③ 黑匣子记录（第36章） */
}
```

### 34.6 上机核对（LAB5）

| 步骤 | 该看到什么 | 判据 |
| --- | --- | --- |
| 市电失电（满载） | 负载电压与母线 | 负载无中断；母线最低 ≥−10% |
| 市电恢复回充 | 母线电压与充电电流 | 母线 ≤1.05 倍；充电 ≤0.1C |
| 所有权的唯一性 | 任一时刻只有一个电压环在动 | 用代码断言 + 母线无 5~20Hz 振荡 |
| 非法转移拒绝 | 条件不满足时 | 拒绝并记录 EV_MODE_CHANGE 拒绝码 |
| 切换 100 次 | 状态与故障计数 | 无异常、无累积错误 |

### 34.7 失败案例复盘：两个电压环同时抢母线，低频振荡烧电容

> [!CAUTION]
> 现象：市电恢复瞬间母线出现 9Hz、±35V 的振荡，持续约 2s，之后一只母线电容鼓包。定位路径：①录母线波形（9Hz 振荡）→ ②看两个电压环的输出（同时在大幅摆动）→ ③核算（34-2：整流器与 DC-DC 同时带电压环）→ ④改为"先建压、后释放"的所有权移交后振荡消失。根因：母线所有权冲突 → 两个积分器互相追逐 → 母线低频振荡 → 电容纹波电流超标发热。预防措施：①母线所有权做成"互斥信号"（同一时刻只有一个环使能），并在代码里加断言；②切换必须有"稳定判定计数"（≥50ms）；③把"母线低频振荡（<50Hz）"纳入上机核对与保护（第36章）；④母线电容纹波电流按最坏工况校核（第8章 8-3）。

### 34.9 练习

1. **E1** 母线电容 28.6mF、负载 50kW、允许母线跌 10%：算"能撑多久"；与 34-4 的 30ms 缺口（833J，可复算）比较。
2. **E2** 回充工况下充电限流 0.1C（10A）：算整流器应降到多少功率才不让母线过压；若整流器降功率需要 200ms，母线会升到多少（用 28.6mF 估算）。
3. **E3** 用 34.5 的代码，补一个"状态停留时间超限告警"（例如 PRECHARGE 超过 5s 未完成即告警），并说明为什么每个状态都需要超时保护。（参考答案见 [练习参考答案](/posts/power/courses/ups-pcs-dsp/docs/answers/)）
