**本章要解决的问题：** 电池组（384V）与母线（700V）之间既要**双向** 又要**隔离**。本章给出三种可用拓扑的定量对比、四个算例（移相角的功率传输、环流代价、LLC 谐振腔与死区、CLLC 对称条件），以及 PFM/移相控制的代码。

### 16.1 为什么必须隔离，为什么必须双向

| 需求 | 来源 | 不满足的后果 |
| --- | --- | --- |
| 电气隔离 | 电池组电压等级与安规（附录 A：耐压 2000VAC/1min） | 无法通过安规；维护时电池侧与电网侧不能等电位 |
| 双向功率流 | 电池放电（母线←电池）与充电（母线→电池） | 只能用两套单向变换器，成本与体积翻倍 |
| 宽范围电压匹配 | 电池 320~440V（充放电全程），母线 700V | 硬开关 DC-DC 无法在全范围保持效率与稳压 |
| 软开关 | 效率 ≥95.5%/96.5%（验收表 B 组） | 硬开关损耗导致散热与效率双输 |

| 拓扑 | 控制量 | 双向 | 软开关范围 | 适用 |
| --- | --- | --- | --- | --- |
| DAB | 移相角 φ | 天然双向 | 匹配电压时全范围 | 宽范围、大功率双向（本课程采用） |
| LLC | 频率 fsw（PFM） | 单向（副边整流） | 宽（fsw 附近） | 单向高效隔离（充电器） |
| CLLC | 频率（PFM） | 双向对称 | 宽 | 双向高效隔离 |

### 16.2 算例 16-1：DAB 的功率与移相角（单移相 SPS）

```text
条件：变压器变比折算后两侧电压匹配 V = 700V（母线）、fsw = 50kHz、L = 245µH（含漏感与外串电感）
公式：P = n·V1·V2·D·(1−D)/(2·fsw·L)，D = φ/180°（单移相，0 ≤ D ≤ 0.5 为常用区）

  D = 0.5（φ = 90°）：P_max = V²·0.25/(2·fsw·L) = 700²×0.25/(2×50000×245e-6)
                          = 122,500/24.5 = 5,000 W  ← 额定点
  D = 0.2（φ = 36°）：P = 700²×0.16/24.5 = 78,400/24.5 = 3,200 W
  D = 0.1（φ = 18°）：P = 700²×0.09/24.5 = 44,100/24.5 = 1,800 W

→ 折算：5000W ↔ 90°，3200W ↔ 36°，1800W ↔ 18°
→ 灵敏度：满载附近 dP/dφ 已很小（D(1−D) 在 0.5 处斜率为 0），轻载附近灵敏度高
```

> [!IMPORTANT]
> 设计含义：DAB 的功率-移相曲线是抛物线，在 D = 0.5 处斜率为零——这既是"额定点稳定"（抗扰动）的优点，也是"轻载调节分辨率差"的缺点。工程上把额定点放在 D ≈ 0.4~0.5、把最小功率点放在 D ≈ 0.1。

### 16.3 算例 16-2：环流是多少，为什么 DAB 轻载效率差

```text
电压匹配时（折算后两侧都是 V），电感电流在一个周期内的行为：
  区间 1（时长 D·T/2）：两侧电压叠加 → di/dt = 2V/L
  区间 2（时长 (1−D)·T/2）：两侧电压抵消 → di/dt = 0（平台）
  → 斜坡幅值 Δi = 2V·(D·T/2)/L = V·D/(fsw·L)
     Δi = 700×0.2/(50000×245e-6) = 140/12.25 = 11.43 A

  波形对称性 → 平台高度 = Δi/2 = 5.71 A（峰值 ±5.71A）
  额定输出电流（5kW/700V）I_out = 5000/700 = 7.14 A
  → 峰值环流 5.71A 与输出电流 7.14A 同量级，且这部分电流不传输净功率
    （真正传输的净功率来自波形"不对称"的那部分）

结论：DAB 的电流应力与输出电流同量级，且 Δi 只与 D、V、fsw、L 有关、与负载无关
      → 轻载时同样的环流照旧流动 → 轻载效率低
      对策：① 提高 L（降低 Δi，但限制最大功率）；② 三移相/双移相调制（在轻载时缩小环流）；
            ③ 轻载切"半桥模式"或间歇工作（burst mode）
```

### 16.4 算例 16-3：LLC 谐振腔设计与死区时间（与第6章对照）

```text
目标：700V → 384V 隔离降压，5kW，fsw(nom) = f_r = 100kHz
  折算负载：R_L = 384²/5000 = 29.5 Ω
  交流等效电阻：R_ac = (8/π²)·n²·R_L，n = 700/384 = 1.823
    = 0.8106 × 1.823² × 29.5 = 0.8106×3.323×29.5 = 79.4 Ω

  取满载 Q = 0.45（典型 0.4~0.5）：
    Z0 = Q·R_ac = 0.45×79.4 = 35.7 Ω
    由 f_r = 1/(2π√(Lr·Cr)) 与 Z0 = √(Lr/Cr) 解出：
      Lr = Z0/(2π·f_r) = 35.7/(2π×1e5) = 56.8 µH
      Cr = 1/(2π·f_r·Z0) = 1/(2π×1e5×35.7) = 44.6 nF
    校核：f_r = 1/(2π√(56.8e-6×44.6e-9)) = 1/(2π√(2.533e-12)) = 100.0 kHz ✓
          Z0 = √(56.8e-6/44.6e-9) = √1273.5 = 35.7 Ω ✓
  励磁电感：取 Lm/Lr = 6 → Lm = 6×56.8 = 341 µH

死区时间（LLC 的 ZVS 换流，机制与第6章"防直通"完全不同）：
  励磁电流峰值 I_Lm = V/(4·Lm·fsw) = 700/(4×341e-6×1e5) = 700/136.4 = 5.13 A
  换流所需死区：t_dead ≥ 2·C_oss·V/I_Lm，取 C_oss = 200pF（单管）
    = 2×200e-12×700/5.13 = 2.8e-7/5.13 = 54.6 ns（理论下限）
  留 5 倍余量 → 取 300 ns（工程取值）
  ⚠ 与第6章逆变器死区 3µs 相差 7 倍：那里是"防止上下管同时导通"（按器件 t_off 算），
    这里是"保证谐振电流把结电容充放完"（按 C_oss 与励磁电流算）——两笔账别混
```

### 16.5 算例 16-4：CLLC 的对称条件

```text
双向运行时若只有一侧有谐振腔，反向工作的增益曲线与软开关范围完全变样
  → CLLC 把谐振腔"按变比折算"对称复制到副边：
     Lr2 = Lr1/n²       Cr2 = n²·Cr1
  代入本算例（n = 1.823）：
     Lr2 = 56.8µH/3.323 = 17.1 µH
     Cr2 = 3.323 × 44.6nF = 148.2 nF
  校核副边谐振频率：1/(2π√(17.1e-6×148.2e-9)) = 1/(2π√(2.534e-12)) = 100.0 kHz ✓
     （与正边一致 → 两个方向都能在设计频率附近软开关）

代价：多一个谐振电感与电容（体积、成本），且参数容差会让两个方向的增益出现差异
      → 双向都要单独标定频率-增益曲线（附录 B）
```

> [!WARNING]
> 频率下限是保命参数：LLC 在 f < fp（并联谐振点）后进入容性区，此时原边电流超前电压，开关管在体二极管导通期间开通 → 硬开关 + 反向恢复 → 效率骤降并可能击穿。必须硬件限频（比较器/寄存器钳位）而不只是软件限幅，因为软件限幅在故障（跑飞、参数错）时可能失效。

### 16.8 失败案例复盘：LLC 轻载进入容性区，一次开机炸四管

> [!CAUTION]
> 现象：满载测试良好（效率 97.2%），空载开机一次即在 5s 内报过流并炸掉原边四管；拆机后体二极管有反向恢复烧痕。定位路径：①看开机频率（软启动从 160kHz 缓降，但空载时电压环要求很小的增益 → 频率继续降到 70kHz）→ ②70kHz < fp（并联谐振点，本算例中 fp= fr/√(1+Lr/Lm) = 100/√1.167 = 92.6kHz）→ ③进入容性区 → 硬开关 + 体二极管反向恢复 → ④原边电流出现反相，随即过流。根因：频率下限设为 0.75·fr= 75kHz，低于容性区边界 92.6kHz；且只有软件限幅，未做硬件钳位。预防措施：①频率下限必须 > fp（本例应为 95kHz 以上），并按"最大 Lm 容差 + 最小 Cr 容差"的最坏组合复算；②空载时用间歇模式（burst）而不是继续降频；③硬件限频 + 软件限幅双保险；④上机核对必须包含"空载开机"与"突甩载"两个方向；⑤把"是否进入容性区"做成可观测判据（原边电流与桥臂电压的相位关系），写入 LAB5。

### 16.10 练习

1. **E1** DAB 的 L 从 245µH 增到 490µH：重算 Pmax、Δi（D=0.2）与额定点移相角；说明"增大 L 换软开关范围"的代价。
2. **E2** 计算本算例 LLC 的 fp（并联谐振频率 = 1/(2π√((Lr+Lm)·Cr))）与容性区边界，并给出安全频率下限（考虑 Lm +10%、Cr −5% 的最坏组合）。
3. **E3** 用 16.6 的代码，补一个"空载时自动进入间歇模式"的逻辑（提示：检测到 f 已到上限而输出仍偏高 → 关闭若干周期的门极，出现误差后再恢复），并说明为什么间歇模式比继续降频安全。（参考答案见 [练习参考答案](/posts/power/courses/ups-pcs-dsp/docs/answers/)）
