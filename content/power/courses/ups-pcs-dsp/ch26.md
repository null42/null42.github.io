**本章要解决的问题：** 把第22章的谐振器组扩到 3/5/7/9/11 次，算清"每个谐振器能压掉多少谐波、总共要付出多少相位"；并回答一个关键问题：**提取环节的相位误差能不能靠小超前环节补回来**（答案：不能，必须换提取方法）。

### 26.1 Kr 怎么分配（先定策略再取数）

| 次数 | 典型占比 | Kr（相对 Kp=0.0314） | 理由 |
| --- | --- | --- | --- |
| 3 次 | 最大（1.33%） | 0.05（160%） | 死区与非线性负载的主要成分 |
| 5 次 | 次大（0.80%） | 0.03（96%） | 同样重要，但交越处相位代价相同 |
| 7 次 | 0.57% | 0.02（64%） | 逐次递减：越靠后缀余量越少 |
| 9/11 次 | 0.2%/0.15% | 0.015/0.01 | 环路增益本身已低，Kr 收益递减 |

### 26.2 算例 26-1：五个谐振器的总相位代价（用第22章公式复核）

```text
交越频率 fc = 455Hz，ωc = 6.28 rad/s（1Hz 半带宽），Kp = 0.0314
 IΣ = 2ωc·ΣKr/(2π·fc) = 2×6.28×(0.6+0.05+0.03+0.02+0.015+0.01)/(2π×455)
 = 2×6.28×0.725/2858.8 = 3.19e-3
 Δφ = atan(3.19e-3/0.0314) = 5.8° 仍在 ≤11.3°（0.2Kp）的规则内
 → 与只有 3/5/7 次时的 5.6° 相比只多 0.2°：**多加两次谐振器的相位代价几乎可以忽略**

各次的环路增益与残余（原始值取第23章量级，311V 峰值口径）：
 次数 |G_v(f)|（含内环 0.94~0.88） |Gc|≈Kp+Kr |环路增益 |残余
 3 106.1×0.99 = 105.0 0.0814 8.55 1.33%/8.55 = 0.156%
 5 63.66×0.97 = 61.8 0.0614 3.79 0.80%/3.79 = 0.210%
 7 45.47×0.94 = 42.7 0.0514 2.19 0.57%/2.19 = 0.259%
 9 35.37×0.91 = 32.2 0.0464 1.49 0.21%/1.49 = 0.141%
 11 28.94×0.88 = 25.5 0.0414 1.06 0.15%/1.06 = 0.142%
 RSS = √(0.156²+0.210²+0.259²+0.141²+0.142²) = 0.42%

结论：3/5/7 次残余 0.156%/0.210%/0.259%（三者 RSS≈0.37%）；9/11 次的环路增益只有 1.5 与 1.06
 → 谐振器对高次"压不动"（环路增益接近 1 = 没有抑制能力）
 → 高次谐波要靠"提高 Kp"（吃相位）或"重复控制"（第27章，对全谱有效）
```

### 26.3 算例 26-2：低通提取的代价（建立时间与泄漏）超前环节补不回来

```text
用第24章的 ip-iq + 10Hz 低通提取：真实代价是什么（24.3 修正口径）
 稳态：基波在 dq 系是直流，低通对直流增益 1、相移 0 → 稳态相位误差 ≈ 0；
 真正的代价是——
 ① 建立时间 3τ = 3/(2π×10) ≈ 47.7ms：负载突变后谐波指令"追着旧基波"补几十 ms
 ② 幅值泄漏：300Hz（5/7 次在 dq 系的位置）以 |H| = 1/√(1+30²) = 0.033 漏进基波估计
 → 谐波指令稳态幅相偏差仅 ≈0.06%/1.9°（泄漏不是稳态主害，动态才是）
 能否用小超前环节补偿：
 数字预测 x̂[k] = 2x[k] − x[k−1] → 等效超前 0.5Ts = 27.8µs
 在 250Hz 处相位超前 = 360×250×27.8e-6 = 2.5°
 即使把预测器加到 (3x[k] − 3x[k−1] + x[k−2])（等效超前 1Ts）也只 5.0°
 → 结论：**低通提取的代价是"建立时间 + 泄漏"，不是固定时延——
 超前/预测环节只能补固定时延，对建立时间与泄漏无能为力**

正确做法（第25章）：
 用多同步旋转坐标系（MSRF）：把每次谐波旋转成直流后再低通
 → 稳态下低通对"直流"没有相位影响 → 稳态幅相误差 = 0（只有动态建立时间）
 建立时间 = 3τ = 3/(2π×20Hz) = 23.9ms（比 ip-iq 的 47.7ms 快一倍，且可按次分配带宽）
 注意区别：ip-iq 的低通作用于"基波 dq"，谐波在那里是 300Hz 交流 → 幅相都被改变；
 MSRF 的低通作用于"谐波自己的 dq"，谐波在那里是直流 → 只影响动态，不影响稳态相位
```

### 26.4 算例 26-3：补偿容量的账（不能白拿）

```text
负载电流总 RMS = 76A，含 5 次 20%（15.2A）、7 次 10%（7.6A）、11 次 5%（3.8A）
 补偿电流（全补）RMS = √(15.2²+7.6²+3.8²) = √(231+57.8+14.4) = 17.4 A

 这 17.4A 必须由变流器"额外"输出 → 输出容量占用 = 17.4/76 = 22.9%
 两种做法：
 ① 降额运行：带载能力降到 76×0.78 = 59A（承认 22% 用于补偿）
 ② 部分补偿（只补到单次限值以内）：按 23.2 的限值 5% 只需补掉 (20%−5%) = 15% 的 5 次
 → 补偿电流 = 11.4A/√2×...（按峰值比例折算）≈ 8.7A → 占用 11.5%
 判据：补偿后 THDi 达标且"补偿电流 RMS ≤ 15% 额定"（本课程口径，避免过度降额）

限幅设计（三条一起做）：
 ① 补偿电流指令限幅 15% 额定（11.4A）
 ② 总电流（基波+补偿）限幅 1.2×额定峰值
 ③ 补偿功能在过载（>110%）时自动退出（优先保供电）
```

### 26.5 代码：多点 PR 组 + MSRF 提取 + 限幅

```c
/* ---------- harm_comp.c：谐波补偿指令生成 ---------- */
#define HC_KR_BASE   0.6f        /* 基波谐振器 Kr（第13章） */
#define HC_KR3       0.05f       /* 3 次（26.1） */
#define HC_KR5       0.03f
#define HC_KR7       0.02f
#define HC_KR9       0.015f
#define HC_KR11      0.01f
#define HC_WC        6.2832f     /* 1Hz 半带宽，全部谐振器一致（第22章规则） */
#define HC_ILIM_A    11.4f       /* 补偿电流限幅 = 15%×76A（算例 26-3） */

static reso_t g_hc[3][5]; /* [相][谐振器]：每相每谐振器独立状态，防止三相同拍串用同一状态 */
static float g_hc_out[3]; /* 各相补偿电流指令 */

void harm_comp_init(void)
{
 /* 三相共用同一组系数（26.1），状态各自独立；reso_init 内部按第13章公式算 b0/a1/a2 */
 for (uint8_t ph = 0; ph < 3; ph++) {
 reso_init(&g_hc[ph][0], HC_KR3, HC_WC, 3);
 reso_init(&g_hc[ph][1], HC_KR5, HC_WC, 5);
 reso_init(&g_hc[ph][2], HC_KR7, HC_WC, 7);
 reso_init(&g_hc[ph][3], HC_KR9, HC_WC, 9);
 reso_init(&g_hc[ph][4], HC_KR11, HC_WC, 11);
 }
}

/* 在基波指令上叠加谐波补偿项（同样的误差源：负载电流的谐波分量） */
void harm_comp_step(const float ih_abc[3], float out_abc[3])
{
 for (uint8_t k = 0; k < 3; k++) {
 float y = 0.0f;
 for (uint8_t h = 0; h < 5; h++) y += reso_step(&g_hc[k][h], ih_abc[k]); /* 用本相自己的状态 */
 y = clampf(y, -HC_ILIM_A, HC_ILIM_A); /* ① 补偿电流限幅 */
 out_abc[k] = y;
 }
}

/* 使能条件：过载退出、故障退出（优先保供电，第36章） */
uint8_t harm_comp_enable(void)
{
 if (g_prot.fault != 0u) return 0u;
 if (g_meas.overload_pct > 110.0f) return 0u; /* ② 过载自动退出 */
 return 1u;
}
```

| 步骤 | 该看到什么 | 判据 |

| 逐次投入谐振器 | 3→5→7→9→11 次依次下降 | 每次残余与 26.2 表预测偏差 ≤20% |

| MSRF 稳态相位 | 补偿电流与谐波实测相位差 | ≤10°（ip-iq+低通的短板是建立时间 3τ≈48ms 与泄漏，非稳态相位——24.3/26.3） |
| 补偿容量 | 补偿电流 RMS | ≤15% 额定（26-3） |
| 过载退出 | 加载到 120% 时补偿功能 | 自动退出，输出不失真 |

### 26.7 失败案例复盘：用 ip-iq 提取 + 小超前环节"硬补"相位

> [!CAUTION]
> 现象：采用 ip-iq 提取并加了两级数字预测器做相位补偿，投入后 THDi 只从 28% 降到 24%，远不如仿真（预期 8%）。定位路径：①录波对比补偿电流与谐波（负载波动段平均相位差仍有约 65°，稳态段仅 ≈2°——指向动态跟随时差）→ ②用 22.3/26.3 手算：预测器最多提供 1Ts = 5.0° 的固定超前，而低通提取的代价是建立时间 3τ≈47.7ms 与幅值泄漏（24.3 修正口径）→ ③确认"建立时间与泄漏不是固定时延，有限阶超前补不了" → ④改用 MSRF 提取后 THDi 降到 7%。根因：把低通提取的代价误当成固定时延来补：真实代价是建立时间与泄漏，负载波动时指令长期滞后于真实谐波，预测器对此无能为力。预防措施：①补偿指令必须采用"谐波自身 dq 系"的提取（MSRF/滑窗），不用 ip-iq+低通；②提取环节的评价口径用"建立时间 + 泄漏"，相位补偿能力的量化（能超前几度）必须写进设计说明；③把"补偿电流与谐波相位差 ≤10°"列入上机核对判据。
