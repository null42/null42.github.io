**本章要解决的问题：** 把损耗变成温度、把温度变成寿命：热阻 RθJA 链、降额 表、以及 MTBF / MTTR 的工程算法。

### 46.1 热阻链（从结到空气）

```text
T_j = T_a + P_loss × (Rθ_jc + Rθ_cs + Rθ_sa)
 典型值（TO-247 SiC + 铝散热器 + 强制风冷）：
 Rθ_jc = 0.4 K/W（器件）
 Rθ_cs = 0.3 K/W（绝缘垫 + 导热硅脂）
 Rθ_sa = 0.8 K/W（散热器 + 风冷，按 2 m/s 风速）
 合计 = 1.5 K/W
```

### 46.2 算例 46-1：结温核算与降额

```text
单管损耗（第39章 39-1 分配）：通态 620W/24 管 = 25.8W；开关 480W/24 = 20W
 单管总损耗 P = 45.8 W
 环境 40℃（机房上限）：T_j = 40 + 45.8×1.5 = 108.7 ℃
 器件 T_j(max) = 175℃（SiC）→ 余量 66℃；但按工程降额要求（≤0.8×T_jmax = 140℃）也满足 

 风险工况校核（过载 125% 时损耗 ∝ I² → 1.56 倍）：
 P' = 45.8×1.56 = 71.4 W → T_j = 40 + 107.1 = 147.1 ℃ 超过 140℃ 降额线
 → 结论：必须按"125% 过载 10min"设计散热（验收表 C 组），即散热器要按 1.6 倍损耗选
 或者过载时提高风速（风扇双速）→ Rθ_sa 从 0.8 降到 0.6 → T_j = 40+71.4×1.3 = 132.8℃ 
 判据：最坏工况（40℃ 环温 + 125% 负载）下 T_j ≤ 0.8×175 = 140℃
```

### 46.3 算例 46-2：电解电容寿命（最短板）

```text
母线电解电容：额定 105℃/5000h，实际工作壳温 T_c
 寿命模型（Arrhenius，每降 10℃ 寿命翻倍）：
 L = L0 × 2^((T_rated − T_c)/10) × K_R（K_R 为纹波电流修正）
 本例：T_rated = 105℃，实测壳温 55℃（含自身发热）：
 L = 5000 × 2^((105−55)/10) = 5000 × 2^5 = 160,000 h = 18.3 年 
 若散热不良壳温升到 75℃：
 L = 5000 × 2^3 = 40,000 h = 4.6 年 （达不到 10 年设计寿命）

 → 电容是寿命最短板：必须实测壳温（不是估算），并在设计评审中给出"预计更换周期"
 纹波电流修正（K_R）：实际纹波电流/额定纹波电流的比值每超 1 倍，寿命约降一半
 第8章算例 8-3 的 6.4A、额定 8A → K_R ≈ 0.9 → 寿命打 9 折
 判据：设计寿命 10 年（87,600h）→ 壳温 ≤63.7℃
 （反算：87,600/5,000 = 17.5 = 2^4.13 → 105 − 41.3 = 63.7℃；
 65℃ 时仅 2^4×5,000 = 80,000 h ≈ 9.1 年，达不到 10 年）
```

### 46.4 算例 46-3：MTBF 估算与薄弱环节

```text
要求：模块 ≥5×10⁵h、系统 ≥1×10⁵h、MTTR ≤0.5h（验收表 F 组）
 串联可靠性模型（部件失效率相加）：
 λ_模块 = Σ λ_i，MTBF = 1/λ

 典型失效率（FIT，1 FIT = 1e-9/h，工程典型值，精确值须按附录 C 的预计方法）：
 功率器件（24 只） 24 × 20 = 480
 电容（母线+吸收） 12 × 30 = 360
 风扇（2 只） 2 × 500 = 1,000 ← 最大项
 控制板（含 DSP） 1 × 300 = 300
 采样/驱动/继电器 1 × 400 = 400
 其他（端子/PCB） 1 × 200 = 200
 ────────────────────────────────────────
 λ ≈ 2,740 FIT → MTBF = 1/2740e-9 = 365,000 h ≈ 41.7 年
 模块级 MTBF 36.5 万 h 低于 50 万 h 要求 → 系统级靠 N+1 并联冗余保证可用性；
 若要求模块级本身达标，须器件升级（风扇为主要项）或进一步降额

 系统级（4 模块 + 旁路 + 监控，串联）：
 λ_sys ≈ 4×2,740 + 800 + 500 = 12,260 FIT → MTBF ≈ 81,600 h
 低于 1×10⁵h 门槛 → 必须靠 N+1 冗余改善"可用性"（系统不停机概率）：
 4+1 配置的系统级"供电中断"MTBF ≈ λ_sys/(冗余改善因子) → 量级提升 10 倍以上 
 → 结论：整机 MTBF 的薄弱环节是风扇（占 36%）与电容；
 改进优先级：风扇（换长寿命/无刷直流 + 智能调速）→ 电容（降壳温）→ 器件降额
```

### 46.5 代码：温度监视与寿命统计

```c
/* ---------- thermal.c ---------- */
#define TH_TJ_MAX_C     175.0f        /* 器件 Tj 上限 */
#define TH_TJ_DERATE_C  140.0f        /* 降额线 0.8×Tj(max)（46-2） */
#define TH_RTH_JC_CS    0.7f          /* 结-壳+界面热阻 Rθ_jc+Rθ_cs = 0.4+0.3（46-1，°C/W） */
#define TH_HS_WARN_C    85.0f         /* 散热器告警 */
#define TH_HS_TRIP_C    95.0f         /* 散热器停机 */
#define TH_CAP_LIFE_H   160000.0f     /* 电容预计寿命（46-3） */

/* 1s 任务：结温估计 + 风扇调速 + 寿命统计 */
void task_thermal(void)
{
 /* ① 结温估计（用热模型，不必装传感器在器件上） */
 const float t_hs = temp_hs_c();
 const float p_loss = power_loss_estimate_w();
 const float t_j = t_hs + p_loss * TH_RTH_JC_CS; /* 器件到散热器 */
 if (t_j > TH_TJ_DERATE_C) derate_set(0.85f); /* 超降额线 → 降容 */
 if (t_hs > TH_HS_WARN_C) fan_set_speed(2u); /* 双速风扇（46-2） */
 if (t_hs > TH_HS_TRIP_C) { g_prot.fault |= PROT_F_TEMP_HI; }

 /* ② 电容寿命消耗（按壳温与纹波电流，1s 累计） */
 const float t_cap = temp_cap_c();
 const float life_h = TH_CAP_LIFE_H * powf(2.0f, (105.0f - t_cap)/10.0f) * cap_ripple_factor();
 g_life.cap_consumed += 1.0f/3600.0f/life_h; /* 已消耗寿命比例 */
 if (g_life.cap_consumed > 0.8f) g_prot.warn |= PROT_W_CAP_LIFE;

 /* ③ 风扇/继电器动作计数（寿命统计，第41章遥测上报） */
 g_life.fan_hours += 1.0f/3600.0f;
 if (fan_changed()) g_life.fan_starts++;
}
```

### 46.6 上机核对（LAB5）

| 步骤 | 该看到什么 | 判据 |
| --- | --- | --- |
| 满载温升（40℃ 环境） | 散热器与结温估计 | T_j ≤140℃（46-2） |
| 125% 过载 10min | 温度曲线是否稳定 | 不超降额线；风扇提速生效 |
| 电容壳温 | 热电偶实测 | ≤63.7℃（对应 10 年寿命） |
| 高海拔/高温降容 | 模拟 45℃ | 自动降容 ≥15% 且输出指标不变 |
| 风扇故障 | 拔出风扇插头 | 告警 + 降容 + 降额运行（不停机） |

### 46.7 失败案例复盘：满载温度正常，过载 10min 就过温停机

> [!CAUTION]
> 现象：125% 过载试验跑到第 7 分钟就报过温停机，而满载连续运行完全正常。定位路径：①录温度（散热器从 78℃ 升到 96℃）→ ②核算（46-2：过载时损耗 1.56 倍，热阻未变 → T_j 超降额线）→ ③检查散热设计（按满载选型，未按 125% 校核）→ ④改双速风扇 + 过载时降容 15%，通过试验。根因：散热按"额定工况"设计，而验收要求 125% 负载 ≥10min（验收表 C 组）；损耗随电流平方增长。预防措施：①散热必须按"最坏工况（最高环温 + 125% 负载 + 风扇降速）"校核；②过载时主动降容 + 提速风扇（软件配合）；③把"过载 10min 温度曲线"列为固定试验项。
