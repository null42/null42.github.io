**本章要解决的问题：** 把第11~14章用过的两种调节器写成"工程规格"：PI 的三项实现与口径陷阱、抗饱和、准 PR 的三个参数各管什么、以及微分项的处理。

### 19.1 两种调节器的分工

| 调节器 | 被跟踪量 | 零稳态误差条件 | 本课程用在哪 |
| --- | --- | --- | --- |
| PI | 直流量（dq 下的 id/iq、vbus） | 开环含积分环节即可 | 第11/12/14章（DC-DC、PFC、三相 dq） |
| 准 PR | 指定频率的正弦量（50Hz、150Hz…） | 开环在该频率增益有限高（Kr） | 第13章（单相）、第26章（谐波） |
| PID（含微分） | 快速抑制扰动 | — | 慎用：微分放大噪声（19.5） |

### 19.2 算例 19-1：Ki 与 Ki·Ts 混用，差了 20 万倍

```text
第11章电流内环的整定结果（连续域）：Kp = 0.2938，Ki = 1846 (1/s)
固件里必须用"已乘 Ts"的形式：
  Ki·Ts = 1846 × 5e-6 = 9.23e-3

若代码里误写 Ki = 1846（未乘 Ts）：
  a = Ts/(τ+Ts) 口径下积分每拍增量 = Ki × e（本应 Ki·Ts × e）
  → 积分增益放大 1/Ts = 1/5e-6 = 200,000 倍
  验算第一拍：误差 e = 1 A
    正确：比例项 0.2938，积分每拍增量 9.23e-3（0.9% 于比例项，符合"积分慢慢补"）
    错误：积分每拍增量 1846（比例项的 6283 倍）→ 第一拍输出就撞限幅，系统立刻等幅振荡

识别方法：整定文档里同时写"Ki = xxxx (1/s)"与"Ki·Ts = xxxx"，代码里只允许出现后者；
          上机核对时看"阶跃响应第一拍的输出增量"，与手算对不上就是口径错了。
```

### 19.3 算例 19-2：准 PR 的三个参数各管什么（ωc 就是 −3dB 半带宽）

```text
准 PR：Gc(s) = Kp + 2Kr·ωc·s/(s² + 2ωc·s + ω0²)
  在 ω0 处：|Gc| = Kp + Kr（谐振峰值精确等于 Kr）
  在半带宽 ωc 处（即 f0 ± ωc/2π）：谐振项降到 0.707×Kr → 相位 −45°

第13章取值（5Hz 演示口径，用于讲"频率容忍度"；最终设计取 ωc = 6.28 即 1Hz，见 13.7/22.3）：
Kp = 0.0314、Kr = 0.6、ωc = 31.4 rad/s（= 5Hz）
  50Hz 处总增益 = 0.6314 → 基波环路增益 200.9 → 误差 0.5%
  50Hz ± 5Hz 处：谐振项 = 0.707×0.6 = 0.424 → 总增益 0.456 → 环路增益 145 → 误差 0.69%
  → 结论：电网频率偏移 ±5Hz 时误差从 0.5% 变 0.69%，仍达标；
          ωc 是"频率容忍度"的旋钮：ωc = 15.7（2.5Hz）时 ±5Hz 处
          谐振项 = Kr·ωc/√(Δω²+ωc²) = 0.6×15.7/√(31.4²+15.7²) = 0.27
          → 总增益 0.30 → 环路增益 95 → 误差 1.05%

参数职责小结：
  Kp：决定高频段增益与交越频率（对基波精度贡献很小）
  Kr：决定基波（或某次谐波）的零稳态误差能力
  ωc：决定"能容忍多少频率偏移"与谐振器引入的相位代价宽度
```

### 19.4 算例 19-3：抗饱和的三种做法与恢复时间

```text
场景（第11章算例 11-4）：启动误差 12V，Ki_v = 157.1 (1/s)，限幅 I_max = 5A
  做法① 无抗饱和：饱和 10ms 后积分器累积到 18.85A，
        退出饱和需 (18.85−5)/(157.1×0.2) = 0.44 s   ✗
  做法② 条件积分（clamping）：输出越限且误差同向 → 冻结积分
        退饱和时间 ≈ 0（积分器没超量）✓
  做法③ 反算（back-calculation）：把 (out_sat − out_unsat) 按 1/Tt 反馈回积分器
        Tt 取 1/(2π·fc) = 1/(2π×200) = 0.8 ms → 积分器在 ~2.4ms（3 倍时间常数）内回退到位 ✓
        比② 更平滑，但多两行代码与一个 kt 系数

判据：启动到稳态 ≤20ms（验收表 A 组）；甩载偏移 ≤±5%
      两种做法都能满足，本课程统一用 ②+③ 组合（代码见 11.7）
```

### 19.5 算例 19-4：微分项为什么默认不用

```text
纯微分 D(s) = Kd·s 的幅频是 +20dB/dec：
  Kd = 1e-4，在 1.8kHz 处 |D| = 1e-4×2π×1800 = 1.005
  在 18kHz（开关频率）处 |D| = 1e-4×2π×18000 = 10.05
  → 开关纹波与量化噪声被放大 10 倍，直接进调制量

带一阶滤波的微分 D(s) = Kd·s/(1+s/ωd)，取 ωd = 2π×5kHz：
  1.8kHz 处：|D| = 1.005/√(1+0.1024) = 0.958（几乎不变，控制效果保留）
  18kHz 处：|D| = 10.05/√(1+10.24) = 3.00（噪声放大降到 1/3.35）✓

结论：本课程的控制回路默认只用 PI / PR；确需微分（如某些 DC-DC 电压环）时必须带滤波，
      且滤波极点放在 fsw/3 以下并复核噪声（第18章滤波器纪律）。
```

### 19.6 代码：调节器规格与"口径断言"

```text
/* ---------- ctrl_spec.h：把整定口径写死在类型里，避免混用 ---------- */
typedef struct {
    float kp;        /* 比例增益（无量纲或 A/V、m/A 等，见各章算例） */
    float ki_ts;     /* 积分增益【已乘 Ts】——只允许这个口径进代码 */
    float ki_1s;     /* 连续域 Ki（1/s）：仅用于文档与校验，代码里不得参与运算 */
    float out_min, out_max;
    float integ, out, kt;
} ctrl_pi_t;

/* 口径纪律：结构体里只有 ki_ts 参与运算；ki_1s 仅作文档字段，代码中禁止引用 */

/* ---------- PI 单拍（条件积分 + 反算，第11章 11.7 的同一份实现） ---------- */
float ctrl_pi_step(ctrl_pi_t *p, float err);

/* ---------- 准 PR 单拍 ---------- */
typedef struct { float kp, kr; reso_t r; } ctrl_pr_t;   /* reso_t 见第13章 13.8 */

float ctrl_pr_step(ctrl_pr_t *p, float err)
{
    return p->kp * err + reso_step(&p->r, err);
}

/* ---------- 口径自检：与整定文档对拍（可放上电自检） ---------- */
uint8_t ctrl_spec_check(void)
{
    uint8_t bad = 0;
    /* 逐条核对"代码常量 = 算例数值"，容差 2% */
    if (fabsf(DC_KI_KI_TS - 9.23e-3f) > 2e-4f) bad |= 1u;   /* 第11章算例 11-2 */
    if (fabsf(PFC_KV_KI_TS - 1.40e-4f) > 3e-6f) bad |= 2u;   /* 第12章算例 12-3 */
    if (fabsf(G3_KI_I_TS  - 2.82e-4f) > 6e-6f) bad |= 4u;    /* 第14章算例 14-3 */
    return bad;      /* 0 = 一致 */
}
```

### 19.7 上机核对（LAB1/LAB3）

| 步骤 | 该看到什么 | 判据 |
| --- | --- | --- |
| PI 阶跃首拍增量 | 与手算 Kp·e + Ki·Ts·e 一致 | 偏差 ≤5%（识别 Ki 口径错误） |
| 饱和恢复 | 启动/甩载两个方向 | 偏移 ≤±5%、恢复 ≤20ms |
| 准 PR 基波增益 | 50Hz 处增益 ≈ Kp+Kr | 偏差 ≤10% |
| 频率偏移容忍 | 48Hz/52Hz 下误差变化 | 与 ωc 预测一致（19.3） |
| 微分噪声复核 | 若使用微分，量 18kHz 处噪声 | 放大 ≤3.4 倍（19.5） |

### 19.8 失败案例复盘：一次"Ki 未乘 Ts"的整定事故

> [!CAUTION]
> 现象：新同事按整定文档把 Ki 填进代码，上电后电流环立即等幅振荡（约 3kHz），改小 Kp 也没用。定位路径：①量第一拍输出增量（是 Kp·e 的 6000 倍）→ ②核对代码（积分项写成 Ki·e 而不是 Ki·Ts·e）→ ③按 19.2 换算后恢复正常。根因：连续域 Ki（1/s）与离散域 Ki·Ts 混用，等效积分增益放大 1/Ts = 200,000 倍。预防措施：①结构体里只保留ki_ts参与运算，ki_1s仅作文档字段；②上机核对必查"首拍增量"；③整定文档统一写成"Ki·Ts"，同时在括号里给 Ki（1/s）供手算。

### 19.9 验收量化单

| 项目 | 判据 | 测量/校验方式 | 关联实验 |
| --- | --- | --- | --- |
| 口径正确 | 首拍增量与手算一致（偏差 ≤5%） | 阶跃录波 | LAB1 |
| 抗饱和 | 启动/甩载 ≤±5%、≤20ms | 录波 | LAB2 |
