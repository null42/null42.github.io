**本章要解决的问题：** 在建模之前，先把"哪个器件在什么时候导通、承受多少电压、流过多大电流"搞清楚。本章给出整机拓扑与三种模式的能量流、三个器件级算例（器件耐压、调制裕量、母线电容纹波电流），并用**状态表驱动** 的方式把开关组合写成代码——这张表是后面 SVPWM（第31章）、保护矩阵（第36章）与换流分析的共同基础。

### 8.1 整机拓扑与三种工作模式

```text
输入 ──EMI──► 整流器(PFC) ──┬── 直流母线(P/O/M) ──┬── 逆变器(三相) ──► LCL ──► 负载
 │ │
 双向DC-DC(电池支路) 静态旁路(SCR) ◄── 旁路输入
 │
 电池开关箱(BAT+/BAT−)
```

| 模式 | 能量路径 | 母线电压由谁维持 | 关键代价 | 对应章 |
| --- | --- | --- | --- | --- |
| 在线（市电正常） | 市电→整流→母线→逆变→负载 | 整流器电压环 | 双变换损耗（效率 ≤96.5%） | 12 / 13 |
| 电池放电 | 电池→DC-DC→母线→逆变→负载 | DC-DC 电流/电压环 | 电池侧大电流（140A 级） | 16 / 43 |
| 旁路（故障/维护/ECO） | 市电→静态开关→负载 | 不再维持（逆变退让） | 失去净化与不间断能力 | 30 / 39 |

> [!IMPORTANT]
> 拓扑视角的一句话总结：UPS/PCS 的全部控制难点都来自"三处换路 + 一处维持"——换路指市电/电池、旁路/逆变、预充/运行；维持指母线电压（电池支路与整流器共同承担）。本章的开关状态表就是"换路"的安全底线。

### 8.2 算例 8-1：器件耐压核算（两电平 vs 三电平）

```text
条件：380V 线电压输出 → 相电压峰值 311V（第0章 0.A）
 母线 P–M 取 700V（为保证调制裕量，见算例 8-2）

两电平半桥（每相 2 管）：
 关断器件承受母线电压 Vdc = 700V
 → 器件需 ≥1200V 档（裕量 1200/700 = 1.71）；或 900V 档（1.29，偏低）

三电平 NPC/TNPC（每相 4 管）：
 每管承受 Vdc/2 = 350V
 → 可用 650V 档（裕量 650/350 = 1.86）
 附加收益：dv/dt 减半、可用更低 Rg 与更低开关损耗；代价是器件数翻倍 + 中点平衡

判据：器件电压裕量 ≥1.5（工程惯例），本算例三电平 1.86 、两电平 1.71 （但损耗与 dv/dt 更差）
```

### 8.3 算例 8-2：调制裕量核算（母线电压为什么取 700V）

```text
SPWM 线性区上限：相电压基波峰值 ≤ Vdc/2（两电平与三电平相同，都是"半母线"为上限）

要求：输出相电压峰值 311V（220V 有效值）
 m = 311 / (700/2) = 311/350 = 0.889 ← 留 11% 余量给：
 ① 母线跌落（算例 1-3 的 2.9%）
 ② 死区损失（第6章算例 6-3：21.6V，占基波峰值 311V 的 6.9%）
 ③ 闭环调节与不平衡工况

若母线只取 620V：m = 311/310 = 1.00 → 已到限幅边界，任何跌落都会进入过调制（THD 激增）
若母线取 800V：m = 0.778 → 余量更大，但器件耐压与电容数量上升
```

> [!WARNING]
> 注意两个"裕量"不要混：器件耐压裕量（算例 8-1，是安全）与调制裕量（算例 8-2，是波形质量）。前者不足会炸管，后者不足会让 THDu 超标——两者都要算，账要分开记。

### 8.4 算例 8-3：母线电容的纹波电流（选型最容易被忽略的一项）

```text
单相逆变器（2kW/220V，输出电流有效值 9.1A）：
 母线电容承担二倍频（100Hz）纹波电流，量级 ≈ I_out/√2 = 9.1/1.414 = 6.4 A(rms)
 → 选电解电容时不能只看容量，必须查"100Hz 纹波电流额定值"并按温度降额

三相逆变器（50kW/380V，76A）：
 三相输出瞬时功率恒定 → 理想情况下母线电流无低频脉动
 实际纹波主要来自开关频率分量，量级与调制方式、母线电容 ESR 相关（第15章细算）
```

> [!IMPORTANT]
> 选型顺序：①按保持时间/纹波电压算容量（算例 1-2）→ ②按纹波电流选型号（本算例）→ ③按 ESR 与温度算寿命（第46章）→ ④最后校核体积与成本。只算容量是最常见的漏项。

### 8.5 开关状态表：把换流写成数据而不是 if-else

#### 单相全桥（4 管，2 个有效状态 + 2 个零状态）

| 状态 | S1 | S2 | S3 | S4 | 桥臂输出 vab | 用途 |
| --- | --- | --- | --- | --- | --- | --- |
| 正 | 1 | 0 | 0 | 1 | +Vdc | 输出正半周 |
| 负 | 0 | 1 | 1 | 0 | −Vdc | 输出负半周 |
| 零（上） | 1 | 0 | 1 | 0 | 0 | 单极性调制的零电平 |
| 零（下） | 0 | 1 | 0 | 1 | 0 | 单极性调制的零电平 |
| **非法（必须硬件互锁禁止）**：S1&S2 同臂直通、S3&S4 同臂直通 | 母线短路 | — | | | | |

#### 三电平 NPC 单相桥臂（4 管，3 个有效状态）

| 状态 | S1 | S2 | S3 | S4 | 输出 | 中点 O 电流 |
| --- | --- | --- | --- | --- | --- | --- |
| P（正） | 1 | 1 | 0 | 0 | +Vdc/2 | 0 |
| O（零） | 0 | 1 | 1 | 0 | 0 | iO = iout（影响中点电位） |
| N（负） | 0 | 0 | 1 | 1 | −Vdc/2 | 0 |
| **非法**：S1&S3、S2&S4、S1&S4 等任何跨位组合 | 电容短路/母线短路 | — | | | | |

```text
/* ---------- sw_state.h：把状态表写成数据 ---------- */
typedef struct {
 uint8_t s[4]; // S1..S4 门极（1=开）
 int8_t level; // 输出电平：+1/0/-1
 uint8_t npc_ok; // 三电平合法性
 const char *name;
} sw_state_t;

static const sw_state_t HBRIDGE_ST[4] = {
 {{1,0,0,1}, +1, 1, "POS"},
 {{0,1,1,0}, -1, 1, "NEG"},
 {{1,0,1,0}, 0, 1, "ZERO_H"},
 {{0,1,0,1}, 0, 1, "ZERO_L"},
};

static const sw_state_t NPC_LEG_ST[3] = {
 {{1,1,0,0}, +1, 1, "P"},
 {{0,1,1,0}, 0, 1, "O"},
 {{0,0,1,1}, -1, 1, "N"},
};

/* 合法性检查：任何"跨位"组合直接判定非法（软件冗余，硬件由互锁/TZ 保证） */
uint8_t sw_state_legal_npc(uint8_t s1, uint8_t s2, uint8_t s3, uint8_t s4)
{
 const uint8_t pattern = (uint8_t)(s1 | (s2 << 1) | (s3 << 2) | (s4 << 3));
 switch (pattern) {
 case 0x3: // 0011 → P
 case 0x6: // 0110 → O
 case 0xC: // 1100 → N
 return 1;
 default:
 return 0; // 其余组合（含直通）一律非法
 }
}

/* 应用状态前先检查，非法则封波并记录故障码（慢任务里上报） */
uint8_t sw_apply_npc(sw_state_t st)
{
 if (!sw_state_legal_npc(st.s[0], st.s[1], st.s[2], st.s[3])) {
 g_prot.fault |= PROT_F_GATE_ILLEGAL; // 第36章保护矩阵
 pwm_force_safe_level(); // 立即封波（TZ 或强制电平）
 return 0;
 }
 pwm_write_gates(st.s);
 return 1;
}
```

> [!TIP]
> 为什么用查表而不是 if-else：①状态数有限且固定，查表最直观；②合法性检查变成"有限集合判定"，评审时一眼看得出漏了哪个组合；③后面做 SVPWM（第31章）时，扇区→矢量→状态 的映射天然是查表结构；④三电平的"冗余矢量选择"本质就是在合法集合里挑一个（第15章）。

### 8.6 换流过程：为什么"同时导通"之外还有"同时关断"问题

```text
关断瞬间的换流路径（以两电平半桥为例，感性负载）：
 S1 关断 → 电感电流被迫转到 S2 的反并联二极管 → 桥臂电位由 P 跌到 N
 该过程取决于：器件关断速度、母线回路杂散电感 L_stray、二极管反向恢复

关键约束：
 ① 死区必须覆盖 t_off(max)（第6章算例 6-2：3µs）
 ② 母线回路杂散电感越小，关断过压越低 → 叠层母排（laminate busbar）、就近吸收电容
 ③ 续流二极管的反向恢复电荷会导致"上下管瞬态同时导通"的等效效应
 → 必须靠死区 + 负压关断 + 必要时用 SiC 器件（第47章器件落位表）
```

| 换流相关的失效率点 | 现象 | 对策 |
| --- | --- | --- |
| 死区不足 | 上下管瞬态交叠 → 母线尖峰电流 | 按器件极值算死区（第6章） |
| 反向恢复 | 关断过压、EMI 恶化 | 选低 Qrr 器件、限制 di/dt、RC 吸收 |
| 杂散电感 | 关断尖峰 V = L_stray·di/dt（例：100nH、500A/µs → 50V 尖峰） | 母排叠层、缩短回路、就近电容 |
| 门极互锁缺失 | 软件错误组合直接短路 | 硬件互锁 + 状态表合法性检查（8.5） |

### 8.7 上机核对（LAB0/LAB5，低压台架分步验证）

| 步骤 | 该看到什么 | 判据 |
| --- | --- | --- |
| 逐状态静态验证（低压、直流） | 按 8.5 表逐个给状态，量桥臂输出电平 | 四个状态电平与表一致（±2%） |
| 非法组合注入 | 故意写非法门极组合 | `sw_apply_npc()` 拒绝 + 封波 + 故障码 |
| 死区与换流 | 门极波形交叠处有死区；母线电流无尖峰 | 死区 ≥3µs；尖峰 <1.5 倍额定 |
| 母线电容温升 | 满载运行 30min，电容表面温升 | ≤20K（壳温）且无鼓包 |
| 调制裕量实测 | 输出满载时 m 值（由母线电压与输出峰值反算） | m ≤0.95（对应算例 8-2 的 0.889 + 工况余量） |

### 8.8 失败案例复盘：忽略反向恢复导致的"偶发直通"

> [!CAUTION]
> 现象：低压调试正常，上高压后在特定负载点偶发过流保护动作（每几小时一次）。定位路径：①抓过流波形（母线电流出现单一尖脉冲，非持续短路）→ ②同步看门极波形（死区内无交叠）→ ③查器件（续流二极管反向恢复慢、Qrr 大）→ ④降低门极关断 di/dt 并加大死区后消失。根因：死区按"门极信号"算够了，但没考虑反向恢复期间二极管仍导通、另一管已开通的等效交叠。预防措施：①死区计算必须包含器件反向恢复时间（不只是 toff）；②选低 Qrr 器件或加 RC 吸收；③换流分析（8.6）纳入设计评审；④保护必须能承受"偶发尖峰"而不误报（第36章的滤波/去抖）。
