**本章要解决的问题：** 现场最常见的失效场景：单相满载、不平衡负载、非线性负载。核心是三个量：零序、负序、不平衡度。

### 32.1 四线制与三线制的差别（一句话）

```text
三线制：零序分量无处流 → 只能靠中点/母线电容吸收 → 不平衡体现为母线中点漂移
四线制：零序经中线流通 → i_N = −(ia+ib+ic) → 中线必须按"最坏情况"设计
判据（验收表 D 组）：三相电压不平衡度 ≤3%、相位差 ≤1°、输出电流峰值系数 ≥3:1
```

### 32.2 算例 32-1：单相满载时的中线电流

```text
50kW/380V 系统（每相额定 76A），A 相满载、B/C 空载：
 iA = 107.5·sin(ωt)（峰值），iB = iC = 0
 i_N = −(iA+iB+iC) = −107.5·sin(ωt) → 中线电流有效值 = 107.5/√2 = 76 A
 → **中线容量必须等于相线容量**（而不是常设的"中线 = 相线的 1/2"）

若三相都带单相整流负载（各相 3 次谐波 20%，峰值因数 3）：
 各相 3 次谐波 15.2A（rms）在中线上同相叠加 → i_N,3 = 3×15.2 = 45.6A
 叠加基波不平衡后，中线总电流可达 √(76² + 45.6²) = 88.6A **超过相线额定！**
 → 四线制 UPS 的中线必须按 1.2~1.5 倍相线电流设计（或强制三相平衡输出）
```

### 32.3 算例 32-2：不平衡度与负序补偿

```text
不平衡度定义：负序/正序（用对称分量法或"最大偏差法"）
 单相满载工况下电压不平衡度：由输出阻抗与中线阻抗共同决定
 ΔU = I_单相 × (Z_out + Z_N)，允许 ≤3%U_ph = 0.03×220 = 6.6V
 若 I = 76A → 允许 (Z_out+Z_N) ≤ 6.6/76 = 0.087Ω
 → 负序补偿（在 dq 加负序谐振器，ω0 = 2ω）可把等效 Z_out 降到 1/5 以下
 补偿次数：负序 2ω 谐振器（100Hz）+ 零序 3 次
 定量：加负序谐振器后，不平衡电压从 6.6V 降到 ≤1.3V（不平衡度 ≤0.6%）
```

### 32.4 算例 32-3：峰值系数与限幅设计

```text
非线性负载（整流+容性）电流波形峰值因数 CF 可达 3:1（规范要求 ≥3:1）
 额定有效值 76A → 峰值可达 3×76×√2 /√2 …按定义 CF = I_pk/I_rms = 3
 → I_pk = 3×76 = 228 A（不是通常的 √2×76 = 107.5A！）

 → 电流环限幅必须 ≥228A（否则削顶 → 波形畸变 → 更差的 CF）
 → 器件电流应力按 228A 峰值选（并留 20% 余量 → 274A）
 → 与第14章的 HA_ILIM_A（110A）冲突：那个是"基波+补偿"限幅，
 非线性负载须用"瞬时值限幅 274A" + "有效值限幅 76A×1.1" 双限幅
判据：CF = 3 时 THDu ≤3%（验收表 A 组）；限幅触发时输出波形不得削顶
```

### 32.5 代码：零序/负序补偿与双限幅

```c
/* ---------- unbal.c：四线制零序/负序补偿（可运行版） ---------- */
/* 原版"各相谐振器输出求和后仅注入 A 相、零序取各相谐振器平均"不成立：
 对称分量必须先分解、再按对应相注入。本版原理（等幅 Clarke，第14章同一约定）：
 ① 零序：i0 = (ia+ib+ic)/3（三相共模信号）→ 单谐振器取 3 次（150Hz，32-2 主导次数），
 输出对三相相同（共模注入）
 ② 负序：Clarke → αβ，旋转 +θ 得 dq⁻（负序基波→直流，正序→2ω 交流）→ 双路低通隔离
 直流（即负序幅值）→ 反旋转回 αβ → 反 Clarke 得三相指令，对应相注入
 （低通截止 5Hz：正序@2ω 残留 ≈ ωc/2ω ≈ 5%，需更净可加 DDSRF 解耦，第26章框架） */
static reso_t g_zero3; /* 零序 3 次谐振器（作用于 i0，三相共用） */
static float g_dlp[2]; /* dq⁻ 双路低通状态：[0]=d⁻、[1]=q⁻ */
static float g_ineg_abc[3]; /* 负序补偿的三相指令（状态数组 [3] 维） */
#define UB_WC_LPF      31.4f         /* dq⁻ 低通截止 5Hz（ωc = 2π×5） */
#define UB_NEG_LIM_A   11.4f         /* 负序补偿限幅 = 15%×76A（第26章同口径） */
#define UB_IPK_LIM_A   274.0f        /* 瞬时值限幅（CF=3 峰值 + 20%，32-4） */
#define UB_IRMS_LIM_A  83.6f         /* 有效值限幅（1.1×76A） */

void unbal_init(void)
{
 reso_init(&g_zero3, 0.05f, 6.2832f, 3); /* Kr、wc、h 按第13/26章公式 */
}

/* 每拍（控制中断）调用：iabc = 测量电流，th = PLL 角度，icmd += 零序/负序修正 */
void unbal_comp_step(const float iabc[3], float th, float icmd[3])
{
 /* ① 对称分量分解：i0 与 αβ（等幅 Clarke） */
 const float i0 = (iabc[0] + iabc[1] + iabc[2]) * 0.3333333f;
 const float ial = 0.6666667f * (2.0f*iabc[0] - iabc[1] - iabc[2]);
 const float ibe = 0.5773503f * (iabc[1] - iabc[2]);

 /* ② 零序：单谐振器作用于 i0，输出对三相相同 */
 const float izero_cmd = reso_step(&g_zero3, i0);

 /* ③ 负序：+θ 旋转得 dq⁻，双路低通取直流（=负序幅值），再 −θ 反旋转回 αβ */
 const float c = cosf(th), s = sinf(th);
 const float dn = ial*c - ibe*s; /* Park(−θ)：负序→直流 */
 const float qn = ial*s + ibe*c;
 g_dlp[0] += UB_WC_LPF * CTRL_TS * (dn - g_dlp[0]);
 g_dlp[1] += UB_WC_LPF * CTRL_TS * (qn - g_dlp[1]);
 const float ual = g_dlp[0]*c + g_dlp[1]*s; /* 反旋转（×e^-jθ） */
 const float ube = -g_dlp[0]*s + g_dlp[1]*c;

 /* ④ 反 Clarke 到三相，对应相注入（零序共模 + 负序各相） */
 g_ineg_abc[0] = ual;
 g_ineg_abc[1] = -0.5f*ual + 0.8660254f*ube;
 g_ineg_abc[2] = -0.5f*ual - 0.8660254f*ube;
 for (uint8_t k = 0; k < 3; k++) {
 icmd[k] += izero_cmd + clampf(g_ineg_abc[k], -UB_NEG_LIM_A, UB_NEG_LIM_A);
 }
}

/* 双限幅：瞬时值 + 有效值（32-4） */
uint8_t unbal_double_limit(float i_pk, float i_rms)
{
 if (fabsf(i_pk) > UB_IPK_LIM_A) { g_prot.flag_lim_pk = 1u; return 1u; }
 if (i_rms > UB_IRMS_LIM_A) { g_prot.flag_lim_rms = 1u; return 2u; }
 return 0u;
}
```

### 32.7 失败案例复盘：中线按相线一半设计，非线性负载下烧中线

> [!CAUTION]
> 现象：投运 3 个月后端子排中线发热变色，检测发现中线电流长期 95A（超过相线额定）。定位路径：①量三相与中线电流（A 相 70A、B 相 65A、C 相 68A，但中线 95A）→ ②做频谱（中线以 3 次 150Hz 为主，幅值 ≈ 3×各相 3 次）→ ③核算（32-2：3 次同相叠加）。根因：设计按"中线 = 相线 1/2"的旧经验，未考虑四线制中 3 次谐波在中线的算术叠加。预防措施：①四线制中线按 ≥1.2 倍相线设计；②把"中线电流"纳入遥测与保护（第36章）；③负载侧尽量平衡分配，并把"单相满载 + 非线性"写入测试矩阵。

### 32.10 补充：分裂母线中点平衡方案（NPC 三电平，衔接第15/31章）

三电平 NPC 的分裂母线（第15章：Chalf = 14.3mF/只）在零序电流无处可去时会上下漂移。中点电流 iO（自中点节点流向桥臂）与上下电容电荷差的关系：**ΔV = (1/C)·∫iO·dt**（C 为单只半母线电容；ΔV 为中点电位偏移，上下压差变化为其 2 倍）。小矢量对是唯一的"可控电荷搬运通道"——同一对冗余小矢量对中点电流反号：

| 矢量（大扇区 I，ia>0 为例） | iO | 方向记号 |
| --- | --- | --- |
| 正小矢量 [POO] | ib+ic = −ia | −1 |
| 负小矢量 [ONN] | +ia | +1 |
| 零矢量 [OOO]/[PPP]、大矢量 | 不接中点 | 0 |
| 中矢量（如 [PON]） | = ib，无冗余对可选 | 不可控（—） |

```text
冗余时间分配因子 α（0~1）：每拍把小矢量总时间 t_sm 拆成
 t_正 = α·t_sm，t_负 = (1−α)·t_sm → 每拍平均中点电流 i_O,avg = (1−2α)·i_x
 平衡律：α = 0.5 − K·ΔV（K>0，ΔV = V_C1 − V_C2；压偏大的电容被放电），α 限幅 [0,1]
 判据：|ΔV| < 2%（半母线 350V 的 7V），超限交 15.5 的硬平衡 DC-DC

算例 32-4：i_O = 5A 持续 1ms 的扰动（C = 14.3mF，第15章同值）
 ΔV = 5×1e-3/14.3e-3 = 0.35V（半母线的 0.10%；上下压差变化 0.70V）→ 未超 2% 判据，但需闭环拉回
 需搬走的电荷 ΔQ = C·ΔV = 14.3mF×0.35V = 5.0mC
 每拍最大可控电荷 = t_sm×i_x：中高调制比取 t_sm = 10µs、i_x = 76A → 0.76mC/拍
 → α 全偏（0↔1）约 7 拍（0.39ms）拉回 
 高调制比（31.12 算例 m=0.99）时 t_sm ≈ 1.1µs → 每拍仅 0.086mC → 约 58 拍（3.2ms）且接近饱和
 → 中点平衡授权随调制比升高而下降，这就是判据必须留 2% 裕量的原因
```

**与第15章的分工口径：** 第15章的电荷积分环负责"给出 ΔV 补偿需求"（慢环，含漂移与温漂），15.4 的零序注入与本节 α 因子都是"每拍执行分配"的软平衡（零序注入改调制波形、α 分冗余小矢量时间，可叠加），都不够时上 15.5 的硬平衡 DC-DC——需求与执行分离，两层不抢动作。
