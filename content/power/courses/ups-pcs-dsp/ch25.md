**本章要解决的问题：** 低通提取法（第24章）的毛病是"残余谐波 + 相位延迟"。本章给出两条更精确的路线：**滑窗递推 DFT**（一个工频窗内精确分离各次）与** 多同步旋转坐标系**（每次谐波各建一个 dq 系），并用三个算例比较计算量、延迟与频率敏感性。

### 25.1 三种提取方法的对照（先看结论选方法）

| 方法 | 提取精度 | 延迟 | 计算量 | 频率偏移敏感 | 用在哪 |
| --- | --- | --- | --- | --- | --- |
| 低通（第24章） | ±3%~17% | 0.8ms（可补偿） | 极低 | 不敏感 | 粗略提取、保护 |
| 滑窗递推 DFT | 高（整周期精确） | ≈1 个窗长（20ms） | 低（每拍 4 乘加/次） | 敏感（需同步） | 遥测、谐波计量 |
| 多同步旋转坐标 | 高（按次数可调） | 由低通决定（可到 1ms） | 中（每次 2 三角 + 4 乘加） | 敏感（需自适应 θ） | 谐波补偿指令 |

### 25.2 算例 25-1：滑窗递推 DFT 的计算量（比全 DFT 省 72 倍）

```text
滑窗递推 DFT（N 点窗，当前点 x[k] 进入、最老点 x[k−N] 退出）：
 X_h[k] = X_h[k−1] + (x[k] − x[k−N])·e^{−j·h·ω·k}·(2/N)

单次更新：1 次复数旋转（查表得 cos/sin → 2 次乘）+ 2 次乘加 + 环形缓冲访问
 实际约 8~10 周期（C28x，含查表）

对照"每拍重算全 DFT"：
 每拍 1 次 = N 次乘加（N = 360，18000/50）→ 约 720 周期
 → 递推法省 72 倍以上

取 N = 360（18kHz 采样、一个工频周期）：
 递推法对 5 次（250Hz）一次更新 ≈ 10 周期 → 若算 2~25 次共 24 个谐波 = 240 周期
 占 ISR（6,667 周期）3.6% 可放 ISR；若算到 50 次（49 个，约 490 周期、7.4%）建议放 1ms 慢任务
```

### 25.3 算例 25-2：窗长与动态响应

```text
窗长 N 决定"多久出一次正确的谐波值"：
 N = 360（1 个工频周期，20ms）：阶跃后需 20ms 才完全更新 → 动态慢，但稳态精确
 N = 180（半周期，10ms）：更新快一倍，但对偶次谐波与直流无法区分（窗长不足）
 N = 720（2 周期）：更平滑，但动态 40ms

工程折中（本课程口径）：
 补偿指令用"多同步旋转坐标（延迟 1ms）"，计量/遥测用"滑窗 DFT（20ms，精确）"
 → 两者并存，各取所长；这也是第41章遥测体系里"谐波计量"的实现方式
```

### 25.4 算例 25-3：频率偏移对滑窗法的影响（必须同步）

```text
窗长固定 N = 360（按 50Hz 整周期）时，若电网变成 50.5Hz：
 实际周期点数 = 18000/50.5 = 356.44 点 → 窗内多出 3.56 点 ≈ 1% 窗长
 基波泄漏到相邻谱线的比例 ≈ 1% × 基波幅值 = 1%（相对基波）
 → 5 次谐波读数被基波泄漏"抬高"约 1% → 0.5% 的谐波会读成 1.5% 判定失效

对策（按代价排序）：
 ① 用 PLL 实时频率重算 N（N = fs/f_grid），并同步重算旋转因子表（推荐）
 ② 用 N = 360 固定 + 窗函数（Hanning）→ 泄漏降一档，但主瓣加宽、动态更慢
 ③ 只用于"变化缓慢的遥测"，明确标注频率偏移下的不确定度

判据：频率偏移 ±4%（48~52Hz）时，谐波计量误差 ≤±0.1%（相对基波）
```

### 25.5 代码：滑窗递推 DFT + 多同步旋转坐标系

```c
/* ---------- hdft.c：滑窗递推 DFT（用于遥测/计量） ---------- */
#define HDFT_N_MAX   360                 /* 一个工频周期（18000/50 = 360） */
typedef struct {
 float buf[HDFT_N_MAX];
 uint16_t n, idx; /* n = 当前窗长（由 PLL 频率决定） */
 float re, im; /* 指定次数的累加结果 */
 uint8_t order; /* 次数 h */
} hdft_t;

void hdft_step(hdft_t *d, float x, float cos_tab, float sin_tab)
{
 const uint16_t i_old = d->idx; /* idx 指向窗内最老样本（即将被覆盖的位置） */
 const float x_old = d->buf[i_old]; /* 必须在写入新样本之前取出：N 点窗递推减的是最老点 */
 const float dlt = (x - x_old) * (2.0f / (float)d->n);
 d->re += dlt * cos_tab; /* 旋转因子由查表给出（h·ω·k） */
 d->im -= dlt * sin_tab;
 d->buf[i_old] = x; /* 覆盖最老样本 */
 d->idx = (uint16_t)((i_old + 1u) % d->n);
}

/* 窗长随电网频率重算（25.4 对策①） */
void hdft_retune(hdft_t *d, float f_grid_hz, float fs_hz)
{
 const uint16_t n_new = (uint16_t)(fs_hz / f_grid_hz + 0.5f);
 if (n_new != d->n && n_new <= HDFT_N_MAX) { d->n = n_new; d->idx = 0; d->re = 0.0f; d->im = 0.0f; }
}

/* ---------- msrf.c：多同步旋转坐标系（用于补偿指令，延迟约 1ms） ---------- */
#define MSRF_MAX  8
typedef struct { uint8_t order; float wc_hz; biquad_t lp_d, lp_q; float id_dc, iq_dc; } msrf_t;
static msrf_t g_msrf[MSRF_MAX] = {
 /* 5、7、11、13 次（典型补偿对象；5/11 为负序、7/13 为正序，见 msrf_harmonic 序别口径；
 3 次常由 PR 直接处理） */
 { 5, 20.0f }, { 7, 20.0f }, { 11, 20.0f }, { 13, 20.0f },
};
static uint8_t g_msrf_n = 4;

void msrf_init(void)
{
 for (uint8_t k = 0; k < g_msrf_n; k++) {
 disc_lpf1_init(&g_msrf[k].lp_d, g_msrf[k].wc_hz); /* 第20章接口 */
 disc_lpf1_init(&g_msrf[k].lp_q, g_msrf[k].wc_hz);
 }
}

/* 输入三相电流与 θ，输出各次谐波在 abc 系的瞬时值之和（供前馈/补偿用） */
void msrf_harmonic(const float iabc[3], float th, float ih_sum[3])
{
 const float ia = (2.0f*iabc[0] - iabc[1] - iabc[2]) / 3.0f;
 const float ib = (iabc[1] - iabc[2]) / 1.7320508f;
 ih_sum[0] = ih_sum[1] = ih_sum[2] = 0.0f;
 for (uint8_t k = 0; k < g_msrf_n; k++) {
 msrf_t *m = &g_msrf[k];
 /* 序别口径：h=6k−1（5,11,17…）为负序谐波，同步角取 −hθ；
 h=6k+1（7,13,19…）为正序谐波，同步角取 +hθ（3 次零序不入此表）。
 正/逆变换必须用同一个 s/c，否则反变换回 abc 时旋转方向对不上 */
 const float ang = ((m->order % 6u) == 5u) ? -(float)m->order * th
 : (float)m->order * th;
 const float s = sinf(ang), c = cosf(ang);
 const float id = ia * s - ib * c;
 const float iq = ia * c + ib * s;
 m->id_dc = biquad_step(&m->lp_d, id); /* 该次谐波在各自 dq 系里变直流 */
 m->iq_dc = biquad_step(&m->lp_q, iq);
 const float xa = m->id_dc * s + m->iq_dc * c;
 const float xb = -m->id_dc * c + m->iq_dc * s;
 ih_sum[0] += xa;
 ih_sum[1] += -0.5f*xa + 0.8660254f*xb;
 ih_sum[2] += -0.5f*xa - 0.8660254f*xb;
 }
}
```

### 25.6 上机核对（LAB4）

| 步骤 | 该看到什么 | 判据 |
| --- | --- | --- |
| 递推 DFT 与仪表对比 | 谐波幅值一致性 | 偏差 ≤±0.05%（23.4 口径） |
| 频率 48/49/51/52Hz | 开启/关闭窗长自适应对比 | 开启后误差 ≤±0.1% |
| MSRF 提取延迟 | 注入谐波到指令输出的时延 | ≤1.5ms |
| 计算量 | HDFT 24 次 + MSRF 4 次的周期数 | ≤500 周期（可放 ISR） |
| 窗长切换瞬态 | 频率变化时读数不跳变 | 切换后 1 个窗长内稳定 |

### 25.7 失败案例复盘：窗长不随频率更新，谐波读数整体虚高

> [!CAUTION]
> 现象：现场（电网长期 50.3Hz）遥测显示 5 次谐波 1.9%，超过 5% 的单次限值判定；用功率分析仪同点测量只有 0.5%。定位路径：①对比仪表数据（差 1.4%）→ ②核算窗长（固定 360 点，实际需要 358 点 → 泄漏）→ ③按 25.4 的开窗长自适应后读数 0.48%，与仪表吻合。根因：滑窗 DFT 的窗长按标称 50Hz 固定，电网频率偏移导致非整周期截断、基波泄漏到谐波谱线。预防措施：①窗长必须由 PLL 频率实时计算（hdft_retune()）；②计量类算法在报告中标注频率适用范围；③把"与仪表比对"列为谐波功能的固定验收项（LAB4）。
