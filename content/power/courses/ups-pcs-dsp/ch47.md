**本章要解决的问题：** 知道"下一代会往哪走"，以及**每一项新技术的落地条件**。三个算例：SiC 的收益量化、VSG 的惯量支撑能力、MPC 的算力账。

### 47.1 三项技术的落地条件（先看条件，再看指标）

| 技术 | 收益 | 落地条件（缺一不可） |
| --- | --- | --- |
| GaN / SiC | 损耗降 30~60%、频率提 2~4 倍、效率 +1~2% | 低杂散电感母排、负压/低阻关断驱动、C_oss 与 dv/dt 管理、EMC 重做 |
| 构网型（VSG/下垂） | 提供惯量与频率支撑，可独立组网 | 储能容量与能量管理、限流与故障穿越、多机稳定性（第33/38章） |
| 无差拍/MPC | 动态响应快、可多目标优化 | 算力（18kHz 内完成优化）、模型精度、稳定性证明 |

### 47.2 算例 47-1：SiC 替换 IGBT 的定量收益

```text
同容量对比（50kW 三相逆变、700V 母线、18kHz，损耗框架与第39章一致）：
  第39章口径：整机开关损耗 480 W → 单管平均 480/24 = 20 W
    → 单管每次开关能量 E ≈ 20 W / 18 kHz ≈ 1.11 mJ（E_on+E_off，@700V/76A 折算）
  换 SiC 的收益只能在"480 W 开关损耗盘子"内按器件手册 ΔE 实算：
    开关损耗(SiC) = 24 × 18000 × E_sic，必须 < 480 W
    例：E_sic = 0.5 mJ → 24×18000×0.5e-3 = 216 W（在 480 W 盘子内削减 55%）✓
    ⚠ 不可能"省 3,000 W"——480 W 就是全部开关损耗的上限

  效率改善量级（与第48章 95.6%/96.2% 口径一致）：
    开关损耗每降 100 W → 额定效率约 +0.2pp（100/50000）
    → 合理预期 +0.2~0.5pp 量级，而非"+1.8%"
  ⚠ 前提：母排杂散电感必须 ≤20nH（否则关断尖峰吃掉收益甚至炸管）
     ΔV = L_s·di/dt = 20nH×1000A/µs = 20V（可接受）；若 L_s = 100nH → 100V（危险）
```

### 47.3 算例 47-2：VSG 的惯量支撑能力（构网型的核心指标）

```text
VSG 转子运动方程：J·dω/dt = (P_ref − P_e)/ω − D·(ω − ω0)
  惯量时间常数 H = J·ω0²/(2·S_n)，工程上常用 H 表示

  取 H = 4 s（典型 2~6 s）、S_n = 50 kVA：
    频率变化率 RoCoF：ΔP = 50kW 突加时
      dω/dt = (P_ref − P_e)/(J·ω0) → 用 H 表示：dΔf/dt = −ΔP/(2H·S_n)·f0
      = −50e3/(2×4×50e3)×50 = −6.25 Hz/s
    对比纯跟网（无惯量）：频率跌落可达 20~30 Hz/s（由电网惯量决定）
    → VSG 把 RoCoF 降低 3~5 倍，为一次调频争取时间

  能量需求（关键约束）：
    若要求支撑 2s，需要能量 = ΔP×t = 50kW×2s = 100 kJ = 0.0278 kWh
    → **构网型的真正瓶颈不是控制算法，而是储能容量**（这正是 PCS+电池的优势）
  判据：并网导则（如 GB/T 34120 类）对 RoCoF 与频率支撑时间的要求
```

### 47.4 算例 47-3：MPC 的算力账（为什么 18kHz 用不了全 MPC）

```text
有限集 MPC（FCS-MPC）电流环：
  候选矢量：两电平三相 8 个（含零矢量）；三电平每相 3 状态 → 27 个
  每个候选需：预测 1 步（3 次乘加 ×2 拍）+ 代价函数（3 项比较）
    单候选 ≈ 60 周期（含除法/平方）
  三步滚动：8³ = 512 个序列 × 60 = 30,720 周期/拍 ✗ 远超 13,333 周期预算
  （口径：控制中断 9kHz、13,333 计数@120MHz，与第48章表16 一致）

  可行方案（按代价排序）：
    ① 单步 FCS-MPC：8×60 = 480 周期 ✓（占 3.6% = 480/13,333）
    ② 两步 + 分支定界剪枝：约 2,000 周期 ✓（占 15% = 2,000/13,333，需专用优化）
    ③ 显式 MPC（离线求解成分段仿射查表）：运行期仅查表 ✓✓ 但离线计算量大
    ④ 无差拍 + 延时补偿：约 300 周期 ✓ 动态接近 MPC，但对模型误差敏感

  本课程建议：**先用无差拍/显式 MPC 取得 80% 的收益，把算力留给保护与诊断**
  判据：任何新增算法必须让"ISR 最坏 ≤2,600 周期（19.5%）"这一条仍然成立（第37章）
```

### 47.5 代码：VSG 核心（可直接编译）

```c
/* ---------- vsg.c：虚拟同步机的转子运动与一次调频 ---------- */
#define VSG_H_S        4.0f            /* 惯量时间常数（47-3） */
#define VSG_D          20.0f           /* 阻尼系数（pu） */
#define VSG_F0_HZ      50.0f
#define VSG_DROOP_R    0.05f           /* 一次调频下垂 5%（第33章） */
#define VSG_PMAX_W     50000.0f        /* 额定（用于标么化） */

typedef struct { float w, delta; float p_ref, p_fb; } vsg_t;   /* w: rad/s，delta: 功角 */
static vsg_t g_vsg;

void vsg_step(float p_meas_w, float dt_s)
{
    const float S_n   = VSG_PMAX_W;
    const float w0    = 6.2831853f * VSG_F0_HZ;
    const float J     = 2.0f * VSG_H_S * S_n / (w0*w0);       /* 由 H 反算 J */
    const float dw    = w0 - g_vsg.w;                         /* 频率偏差 */

    /* ① 一次调频：频率下垂叠加到功率指令 */
    const float p_droop = VSG_DROOP_R * S_n * (dw / w0) / 0.05f;
    const float p_err   = (g_vsg.p_ref + p_droop) - p_meas_w;

    /* ② 转子运动方程 */
    const float acc = (p_err / g_vsg.w - VSG_D * dw * S_n / w0) / J;
    g_vsg.w += acc * dt_s;
    g_vsg.w  = clampf(g_vsg.w, w0*0.95f, w0*1.05f);           /* 频率限幅（保护） */

    /* ③ 功角积分 → 作为电流环的相位基准（与第29章 PLL 二选一或融合） */
    g_vsg.delta += g_vsg.w * dt_s;
    if (g_vsg.delta > 6.2831853f) g_vsg.delta -= 6.2831853f;
}

/* 与跟网模式切换：切换时必须做相位预同步（第30章三同步判据） */
void vsg_mode_switch(uint8_t grid_connected)
{
    if (grid_connected) { vsg_presync_enable(); }              /* 先同步再并网 */
    else                { g_vsg.delta = pll_get_theta(); }      /* 孤岛：直接自建 */
    ctrl_pi_reset_all();                                       /* 清积分/谐振器 */
}
```

### 47.7 失败案例复盘：直接换 SiC 器件，效率没提升反而炸管

> [!CAUTION]
> 现象：把 Si IGBT 直接换成 SiC MOSFET（驱动与母排未改），效率只提升 0.2%，两周后一批器件失效（过压击穿）。定位路径：①测关断波形（关断尖峰 980V，超过 1200V 器件的 82%，且振荡）→ ②测母排杂散电感（约 120nH，47-2 要求 ≤20nH）→ ③确认驱动也未改（关断电阻过大、无负压）→ ④整改母排（叠层）+ 驱动（低阻、负压）后效率提升 0.5pp（47-2 口径内），失效率归零。根因：把 SiC 当成"同封装替换件"，忽略其开关速度对回路寄生参数与驱动的极端敏感性。预防措施：①换 SiC 必须同步完成"母排 L_s 测量 + 驱动波形验证 + 关断尖峰 ≤80% 耐压"三项；②把 L_s 与关断尖峰列入器件替换的评审清单；③先做小功率验证再到整机（附录 C 的 DFMEA 流程）。
