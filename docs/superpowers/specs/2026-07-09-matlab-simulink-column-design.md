# Matlab/Simulink 仿真全教程栏目设计

## 目标

新增一个公开的中文学习栏目 `matlab-simulink`，面向刚开始做控制仿真的读者。栏目不采用扁平文章列表，而是按“先会跑、再会搭、再会封装、最后会整定”的顺序组织，避免新手直接被 Matlab、Simulink、求解器、采样时间和自定义模块概念淹没。

## 内容结构

栏目路径为 `content/matlab-simulink/`，配置文件为 `content/matlab-simulink/column.config.json`。栏目使用 `layout: map` 和 `allowFlat: false`，显式声明路线与阶段：

- 仿真基础：总览、环境与最小模型、采样时间与离散化
- Matlab 离散控制仿真：差分方程、离散 PID、状态空间循环
- Simulink 离散控制仿真：离散模块、求解器、采样时间继承、多速率边界
- 自定义模块：Matlab Function、S-Function
- 整定与验证：参数自整定、参数扫描、日志记录、结果对比

## 新手友好规则

每篇文章使用同一套阅读节奏：先讲使用场景，再给最小可运行模型，然后解释关键参数，最后给常见错误和检查表。代码片段保持短小，表格用于对比工具选择，公式只放必要的离散化关系，Mermaid 图只用于流程关系。

## 验收

- 新栏目出现在栏目注册表、文章库筛选和搜索筛选中。
- 首页学习地图提供入口。
- 新栏目至少包含总览与五篇 curated 教程。
- 所有公开文章无 emoji。
- 新增文章能通过 Markdown 渲染、搜索索引、栏目层级和构建验证。
